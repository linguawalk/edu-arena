서열로 거리 재기

두 종의 DNA 서열을 맞춰 놓고 다른 자리의 비율을 p 거리라 합니다. 100자리 가운데 12자리가 다르면 p = 0.12입니다.

시간이 오래 지나면 같은 자리에서 여러 번 치환이 일어나 실제 치환 수보다 다른 자리가 적게 보입니다. 쥬크스–칸토어 보정 d = −(3/4) ln(1 − 4p/3)으로 실제 치환 수를 추정합니다.

p가 작으면 d ≈ p이지만 p가 클수록 d가 p보다 훨씬 커집니다. p는 0.75를 넘을 수 없습니다(무작위 서열의 기대값).

길이 250자리인 두 서열에서 35자리가 다르면 p 거리는? (소수로)

문제 2

p = 0.3일 때 쥬크스–칸토어 거리 d = −(3/4) ln(1 − 4p/3)는? (ln 0.6 = −0.511, 소수 셋째 자리까지)

UPGMA

UPGMA는 거리 행렬에서 가장 가까운 두 무리를 차례로 묶어 나무를 만듭니다. 두 무리를 묶은 마디의 높이는 둘 사이 거리의 절반입니다.

묶은 무리와 다른 종의 거리는 구성원과의 거리의 평균입니다. 분자 시계(모든 계통의 치환 속도가 같음)를 가정합니다.

예: d(A, B) = 4, d(A, C) = 10, d(B, C) = 12이면 A와 B를 높이 2에서 묶고, d((A, B), C) = (10 + 12)/2 = 11이므로 뿌리 높이는 5.5입니다.

예제

d(A, B) = 6, d(A, C) = 14, d(B, C) = 16, d(A, D) = 20, d(B, D) = 22, d(C, D) = 18인 네 종으로 UPGMA를 할 때 첫 두 번의 묶음과 그 높이를 구하세요.

  1. 가장 작은 거리는 d(A, B) = 6이므로 A와 B를 높이 3에서 묶습니다.
  2. d((A, B), C) = (14 + 16)/2 = 15, d((A, B), D) = (20 + 22)/2 = 21, d(C, D) = 18입니다.
  3. 가장 작은 15로 (A, B)와 C를 높이 7.5에서 묶습니다.
  4. 마지막으로 D와의 거리 (20 + 22 + 18)/3 = 20으로 뿌리 높이 10에서 묶습니다.

답: (A, B) 높이 3, ((A, B), C) 높이 7.5

어떤 유전자를 쓸까

빨리 변하는 서열(미토콘드리아 DNA, 비암호화 부위)은 가까운 종이나 같은 종의 개체군을 비교할 때, 천천히 변하는 서열(rRNA, 히스톤 유전자)은 아주 먼 생물을 비교할 때 씁니다.

빨리 변하는 서열로 먼 생물을 비교하면 치환이 너무 많이 겹쳐 p가 0.75 근처에서 포화되어 정보가 사라집니다.

외군으로 뿌리를 정하거나, UPGMA처럼 분자 시계를 가정해 뿌리를 정합니다.

문제 7

UPGMA에서 A, B를 묶은 뒤 d(A, C) = 9, d(B, C) = 13이면 d((A, B), C)는?

정리

p 거리 = 다른 자리/전체 자리. 쥬크스–칸토어 d = −(3/4) ln(1 − 4p/3)으로 여러 번 치환을 보정(p 클수록 d ≫ p, p < 0.75).

UPGMA: 가장 가까운 무리를 묶고 높이 = 거리/2, 새 거리는 평균. 분자 시계 가정.

가까운 종은 빨리 변하는 서열, 먼 생물은 천천히 변하는 서열(rRNA)로 비교합니다.
