생성 엔탈피로 반응열 구하기

표준 생성 엔탈피 ΔH_f°는 표준 상태(1 bar)의 성분 원소(가장 안정한 형태)에서 물질 1 mol이 생기는 반응의 ΔH입니다. 가장 안정한 원소(O₂(g), C(흑연), H₂(g) 등)의 ΔH_f°는 0입니다.

헤스 법칙으로 모든 반응의 ΔH° = Σn ΔH_f°(생성물) − Σn ΔH_f°(반응물)입니다. 반응물을 원소로 분해했다가 다시 생성물로 조립하는 경로를 생각하면 됩니다.

ΔH_f°: CO₂(g) −393.5, H₂O(l) −285.8, CH₄(g) −74.8 kJ/mol이면 메테인의 연소 ΔH° = −393.5 + 2(−285.8) − (−74.8) = −890.3 kJ입니다.

문제 1

O₂(g)의 표준 생성 엔탈피는 몇 kJ/mol인가요?

문제 2

반응의 ΔH° = Σ ΔH_f°(＿＿＿) − Σ ΔH_f°(반응물)입니다.

계수를 잊지 말 것

ΔH_f°는 1 mol 기준이므로 반응식의 계수를 곱해야 합니다. 2NH₃(g) → N₂(g) + 3H₂(g)은 ΔH_f°(NH₃) = −46.1 kJ/mol이면 ΔH° = 0 − 2(−46.1) = +92.2 kJ입니다.

물질의 상태에 따라 값이 다릅니다: H₂O(l) −285.8, H₂O(g) −241.8 kJ/mol입니다.

거꾸로 연소열을 재어 생성 엔탈피를 구할 수도 있습니다. 연소 반응식에 알려진 값을 넣고 모르는 하나를 풉니다.

예제

ΔH_f°: C₂H₅OH(l) −277.7, CO₂(g) −393.5, H₂O(l) −285.8 kJ/mol로 에탄올의 연소열을 구하세요.

  1. 연소 반응식: C₂H₅OH(l) + 3O₂(g) → 2CO₂(g) + 3H₂O(l)입니다.
  2. Σ 생성물 = 2(−393.5) + 3(−285.8) = −787.0 − 857.4 = −1644.4 kJ입니다.
  3. Σ 반응물 = −277.7 + 3(0) = −277.7 kJ입니다.
  4. ΔH° = −1644.4 − (−277.7) = −1366.7 kJ입니다.

답: −1366.7 kJ/mol

문제 3

ΔH_f°(NH₃(g)) = −46.1 kJ/mol일 때 2NH₃(g) → N₂(g) + 3H₂(g)의 ΔH°는 몇 kJ인가요? (소수로)

문제 4

ΔH_f°: NO(g) +90.3, NO₂(g) +33.2 kJ/mol일 때 2NO(g) + O₂(g) → 2NO₂(g)의 ΔH°는 몇 kJ인가요? (소수로)

연소열에서 생성 엔탈피로

에텐 C₂H₄(g)의 연소열이 −1411 kJ/mol이면 C₂H₄ + 3O₂ → 2CO₂ + 2H₂O(l)에서 −1411 = 2(−393.5) + 2(−285.8) − ΔH_f°(C₂H₄)입니다.

풀면 ΔH_f°(C₂H₄) = −787.0 − 571.6 + 1411 = +52.4 kJ/mol입니다. 양수이므로 에텐은 원소보다 엔탈피가 높습니다.

ΔH_f°가 양수인 물질도 실온에서 안정하게 존재할 수 있습니다. 분해가 매우 느리기 때문입니다(반응 속도는 4챕터).

문제 5

에텐 C₂H₄(g)의 연소열이 −1411 kJ/mol일 때 ΔH_f°(C₂H₄)는 몇 kJ/mol인가요? (CO₂ −393.5, H₂O(l) −285.8, 소수로)

문제 6

ΔH_f°: Fe₂O₃(s) −824.2, Al₂O₃(s) −1675.7 kJ/mol일 때 2Al + Fe₂O₃ → Al₂O₃ + 2Fe의 ΔH°는 몇 kJ인가요? (소수로)

문제 7

ΔH_f°: CaCO₃(s) −1206.9, CaO(s) −635.1, CO₂(g) −393.5 kJ/mol일 때 CaCO₃ → CaO + CO₂의 ΔH°는 몇 kJ인가요? (소수로)

정리

ΔH_f°: 표준 상태 원소에서 1 mol이 생기는 ΔH, 가장 안정한 원소는 0입니다.

ΔH° = Σ n ΔH_f°(생성물) − Σ n ΔH_f°(반응물). 계수와 물질의 상태를 확인합니다.

연소열을 재면 같은 식으로 모르는 생성 엔탈피를 구할 수 있습니다. ΔH_f°가 양수인 물질은 원소보다 엔탈피가 높은 물질입니다.
