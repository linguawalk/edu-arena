상대 연령

과학 올림피아드 S1 예선 · 지질 · 4. 지질 시대와 연대 측정 · 심화 · 약 20분 · 문제 11개

어느 것이 먼저인가

상대 연령은 지층과 암석이 만들어진 순서만 정하는 것입니다. 지층이 뒤집히지 않았다면 아래 지층이 위 지층보다 먼저 쌓였습니다(지층 누중의 법칙).

다른 암석을 자르고 들어간 관입암이나 단층은 잘린 암석보다 나중에 생겼습니다(관입·절단의 법칙). 어떤 암석 속에 포획된 조각은 그 암석보다 먼저 있었습니다(포획의 법칙).

퇴적이 멈추고 침식된 뒤 다시 퇴적이 일어난 면을 부정합이라 합니다. 부정합은 그 사이에 긴 시간 간격이 있었음을 뜻합니다.

문제 1

지층이 뒤집히지 않았다면 아래 지층이 위 지층보다 먼저 쌓였다는 법칙을 지층 ＿＿＿의 법칙이라 합니다.

예제

지층 A(맨 아래), B, C(맨 위)가 있고, 화성암 D가 A와 B를 뚫고 들어갔지만 C에는 닿지 않고 C 아래 침식면에서 잘려 있습니다. 생성 순서를 정하세요.

  1. 지층 누중의 법칙으로 A → B → C 순서입니다.
  2. D는 A, B를 자르므로 A, B보다 나중입니다.
  3. D는 C 아래 침식면에서 잘렸으므로 C보다 먼저입니다.
  4. 순서는 A → B → D → C입니다.

답: A → B → D → C

문제 2

앞 예제에서 화성암 D는 몇 번째로 생겼나요?

문제 3

앞 예제의 모든 지층과 D를 자르는 단층 F가 있다면, F는 몇 번째로 생겼나요?

문제 4

사암층 속에 화강암 조각(역)이 들어 있습니다. 화강암이 사암보다 오래되었으면 1, 젊으면 2를 쓰세요.

부정합

부정합 면 위아래 지층이 나란하면 평행 부정합, 아래 지층이 기울어져 있으면 경사 부정합, 아래가 화성암이나 변성암이면 난정합입니다.

경사 부정합은 퇴적 → 습곡이나 경동 → 융기 → 침식 → 침강 → 퇴적의 순서로 만들어집니다.

부정합 면 바로 위에는 아래 암석의 조각이 섞인 기저 역암이 있는 경우가 많습니다. 이것은 부정합을 찾는 단서입니다.

문제 5

평행 부정합, 경사 부정합, 난정합 가운데 부정합 면 아래가 화성암이나 변성암인 것은 몇 번째로 쓴 것인가요?

화석과 지층 대비

생물은 진화하며 시대마다 다른 종이 나타났다 사라지므로, 같은 화석을 가진 지층은 같은 시대에 쌓였습니다(동물군 천이의 법칙).

표준 화석은 넓은 지역에 많이 살았고 짧은 기간만 존재해 시대를 정하는 데 좋은 화석입니다(삼엽충, 암모나이트, 화폐석). 시상 화석은 특정 환경에서만 살아 당시 환경을 알려 줍니다(산호: 따뜻하고 얕은 바다, 고사리: 따뜻하고 습한 육지).

멀리 떨어진 지역의 지층을 화석이나 화산재층 같은 열쇠층으로 맞추어 보는 것을 지층 대비라 합니다.

문제 6

삼엽충, 암모나이트, 화폐석, 산호, 고사리 중 주로 시상 화석으로 쓰이는 것은 몇 개인가요?

문제 7

두 지역의 지층에서 같은 화산재층을 찾았습니다. 화산재층 바로 아래 지층은 지역 A에서 3번째, 지역 B에서 5번째 층(아래에서부터)입니다. 지역 B에서 화산재층보다 아래에 있는 지층은 몇 개인가요?

정리

상대 연령은 지층 누중·관입·절단·포획의 법칙으로 생성 순서를 정합니다. 자르는 것은 잘린 것보다, 포획된 것은 포획한 것보다 각각 나중·먼저입니다.

부정합은 퇴적 중단과 침식의 시간 간격을 나타내며 평행·경사 부정합과 난정합이 있습니다.

표준 화석은 시대를, 시상 화석은 환경을 알려 주며, 화석과 열쇠층으로 멀리 떨어진 지층을 대비합니다.

문제 8

지층 P(아래), Q, R(위)이 차례로 쌓인 뒤 습곡되고, 침식된 뒤 지층 S가 그 위에 쌓였습니다. 이때 생긴 부정합은? 평행 부정합이면 1, 경사 부정합이면 2, 난정합이면 3을 쓰세요.

문제 9

화강암 G가 지층 A와 B를 관입하고, 지층 B와 화강암 G를 모두 단층 F가 자르며, 그 위를 지층 C가 덮고 있습니다(A가 맨 아래). 단층 F는 몇 번째로 생겼나요?

문제 10

문제 11

표준 화석이 되기 좋은 생물의 조건을 쓰고, 그 이유를 설명하세요.
