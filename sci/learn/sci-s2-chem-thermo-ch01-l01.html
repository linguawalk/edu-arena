반응열과 엔탈피

압력이 일정할 때 반응이 주고받는 열은 엔탈피 변화 ΔH와 같습니다. 열을 내놓는 발열 반응은 ΔH < 0, 열을 흡수하는 흡열 반응은 ΔH > 0입니다.

열화학 반응식은 물질의 상태와 ΔH를 함께 씁니다. CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l), ΔH = −890 kJ는 메테인 1 mol이 탈 때 890 kJ를 내놓는다는 뜻입니다.

반응식을 2배 하면 ΔH도 2배, 역반응은 ΔH의 부호가 바뀝니다. ΔH는 물질의 양에 비례하는 크기 성질입니다.

문제 1

CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l), ΔH = −890 kJ입니다. 메테인 8.0 g(몰질량 16 g/mol)이 탈 때 내놓는 열은 몇 kJ인가요?

문제 2

열을 흡수하는 흡열 반응의 ΔH는 ＿＿＿입니다.

열량계

커피컵 열량계(압력 일정)에서는 용액이 받은 열 q = mcΔT로 반응열을 구합니다. 용액이 데워졌다면 반응은 그만큼 열을 내놓았으므로 q_반응 = −q_용액입니다.

50 mL 1.0 M HCl과 50 mL 1.0 M NaOH(합 100 g, c = 4.18 J/(g·K))를 섞어 6.7 K 올랐다면 q_용액 = 100 × 4.18 × 6.7 = 2800.6 J입니다. 물 0.050 mol이 생겼으므로 중화 엔탈피는 −2800.6/0.050 ≈ −56.0 kJ/mol입니다.

통 열량계(부피 일정)는 열량계 전체의 열용량 C로 q = CΔT를 씁니다.

예제

물 100 g이 든 열량계에서 반응물 0.050 mol이 반응해 온도가 6.0 K 올랐습니다(c = 4.18 J/(g·K)). 반응의 몰당 ΔH를 구하세요.

  1. 용액이 받은 열은 q = mcΔT = 100 × 4.18 × 6.0 = 2508 J입니다.
  2. 반응은 이만큼 열을 내놓았으므로 q_반응 = −2508 J입니다.
  3. 몰당으로 나누면 −2508/0.050 = −50160 J/mol입니다.
  4. ≈ −50.2 kJ/mol입니다.

답: 약 −50.2 kJ/mol

문제 3

50 mL 1.0 M HCl과 50 mL 1.0 M NaOH(합 100 g, c = 4.18 J/(g·K))를 섞었더니 6.7 K 올랐습니다. 중화 엔탈피는 몇 kJ/mol인가요? (소수 첫째 자리까지)

문제 4

열용량 10.0 kJ/K인 통 열량계에서 시료가 타며 온도가 2.50 K 올랐습니다. 내놓은 열은 몇 kJ인가요?

반응식과 ΔH 다루기

2H₂(g) + O₂(g) → 2H₂O(l), ΔH = −571.6 kJ이면 H₂(g) + ½O₂(g) → H₂O(l)은 −285.8 kJ이고, 역반응 2H₂O(l) → 2H₂(g) + O₂(g)은 +571.6 kJ입니다.

물질의 상태도 중요합니다. H₂O(l) → H₂O(g)는 +44.0 kJ이므로 수증기가 생기는 반응은 액체 물이 생기는 반응보다 열을 덜 내놓습니다.

ΔH는 반응식에 쓰인 몰수 그대로의 양입니다. '몰당'이라면 어느 물질 1 mol당인지 밝혀야 합니다.

문제 5

2H₂(g) + O₂(g) → 2H₂O(l), ΔH = −571.6 kJ일 때 H₂O(l) 1 mol을 분해하는 반응의 ΔH는 몇 kJ인가요? (소수로)

문제 6

수소 4.0 g(몰질량 2.0 g/mol)이 완전히 타서 액체 물이 될 때 내놓는 열은 몇 kJ인가요? (H₂ 1 mol당 285.8 kJ, 소수로)

문제 7

물 200 g(c = 4.18 J/(g·K))을 25.0 °C에서 75.0 °C로 데우는 데 필요한 열은 몇 kJ인가요? (소수로)

정리

압력 일정에서 반응열 = ΔH. 발열 ΔH < 0, 흡열 ΔH > 0이며, 반응식을 n배 하면 ΔH도 n배, 역반응은 부호가 바뀝니다.

커피컵 열량계: q_반응 = −mcΔT(용액), 통 열량계: q = −CΔT(열량계).

물질의 상태(s, l, g)에 따라 ΔH가 달라지므로 반응식에 반드시 씁니다.

문제 8

CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l), ΔH = −890 kJ입니다. 이 반응으로 2225 kJ의 열을 얻으려면 메테인 몇 g이 필요한가요? (몰질량 16 g/mol)

문제 9

물 150 g이 든 열량계에서 반응물 0.10 mol이 반응해 온도가 4.0 K 내려갔습니다(c = 4.18 J/(g·K)). 반응의 몰당 ΔH는 몇 kJ/mol인가요? (소수 첫째 자리까지)

문제 10

커피컵 열량계에서 용액의 온도가 올랐을 때 반응의 ΔH가 음수인 이유와 계산 방법을 설명하세요.

문제 11

H₂(g) + ½O₂(g) → H₂O(g)의 ΔH가 H₂O(l)이 생기는 반응보다 덜 음수인 이유를 쓰세요(H₂O(l) → H₂O(g), ΔH = +44.0 kJ).
