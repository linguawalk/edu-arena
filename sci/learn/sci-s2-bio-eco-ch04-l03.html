변화가 가장 적은 나무

최대 절약법은 형질 변화의 총 횟수가 가장 적은 계통수를 가장 그럴듯한 나무로 고릅니다. 같은 변화가 여러 번 따로 일어났다고 보는 것보다 한 번 일어났다고 보는 것이 더 간단하기 때문입니다.

네 종 W, X, Y, Z의 뿌리 없는 계통수는 ((W, X), (Y, Z)), ((W, Y), (X, Z)), ((W, Z), (X, Y))의 3가지입니다. 각 형질이 나무 위에서 최소 몇 번 바뀌어야 하는지 세어 더합니다.

형질 상태가 0, 0, 1, 1(W, X, Y, Z 순)이면 ((W, X), (Y, Z))에서는 가운데 가지에서 1번 바뀌면 되지만, 나머지 두 나무에서는 2번이 필요합니다.

문제 1

W, X, Y, Z의 형질 상태가 0, 1, 0, 1일 때 나무 ((W, X), (Y, Z))에서 필요한 최소 변화 횟수는?

문제 2

한 종에서만 상태가 다른 형질(예: 0, 0, 0, 1)은 네 종의 뿌리 없는 계통수 3가지에서 모두 몇 번 변화가 필요한가요?

정보가 있는 형질

모든 나무에서 변화 횟수가 같은 형질은 나무를 가리는 데 쓸모가 없습니다. 적어도 두 상태가 각각 두 종 이상에 나타나야 정보가 있는 형질(계통 정보 형질)입니다.

아래 자료에서 c1, c2는 0011, c3는 0101, c4는 0001(W, X, Y, Z 순)입니다. c4는 정보가 없는 형질입니다.

나무 ((W, X), (Y, Z))의 길이: c1 1 + c2 1 + c3 2 + c4 1 = 5입니다. ((W, Y), (X, Z))는 2 + 2 + 1 + 1 = 6, ((W, Z), (X, Y))는 2 + 2 + 2 + 1 = 7입니다.

예제

위 자료(c1 0011, c2 0011, c3 0101, c4 0001)에서 최대 절약 나무와 그 길이를 구하세요.

  1. ((W, X), (Y, Z)): 5번입니다.
  2. ((W, Y), (X, Z)): 6번입니다.
  3. ((W, Z), (X, Y)): 7번입니다.
  4. 가장 짧은 ((W, X), (Y, Z))가 최대 절약 나무이고 길이는 5입니다.

답: ((W, X), (Y, Z)), 5

문제 3

위 자료에서 나무 ((W, Y), (X, Z))의 길이(변화 횟수의 합)는?

문제 4

형질 상태가 0, 1, 1, 0(W, X, Y, Z 순)일 때 최소 변화가 1번인 나무는? ① ((W, X), (Y, Z)) ② ((W, Y), (X, Z)) ③ ((W, Z), (X, Y))

세 상태 이상의 형질

한 자리의 DNA 염기(A, C, G, T)처럼 상태가 여러 개인 형질도 같은 방법으로 셉니다. 네 종의 염기가 A, A, G, T이면 어느 나무에서든 적어도 2번 바뀌어야 합니다(상태 3가지 → 최소 2번).

피치 방법: 끝에서부터 두 자식의 상태 집합이 겹치면 교집합을, 안 겹치면 합집합을 쓰고 변화를 1 더합니다.

예: ((W, X), (Y, Z))에서 A, A, G, T이면 (W, X) → {A}, (Y, Z) → {G, T}로 1번, 두 집합이 안 겹쳐 1번 더해 모두 2번입니다.

문제 5

네 종의 한 자리 염기가 A, C, G, T로 모두 다르면 어느 나무에서든 필요한 최소 변화 횟수는?

문제 6

((W, X), (Y, Z))에서 W, X, Y, Z의 한 자리 염기가 G, A, G, A이면 피치 방법으로 센 최소 변화 횟수는?

문제 7

형질 네 개가 모두 0, 0, 1, 1(W, X, Y, Z 순)일 때 나무 ((W, Y), (X, Z))의 길이는?

정리

최대 절약법: 형질 변화 총횟수(나무 길이)가 가장 작은 나무를 고름.

정보 있는 형질: 두 상태가 각각 두 종 이상에 나타나야 합니다. 한 종만 다른 형질은 모든 나무에서 1번이라 나무를 가리지 못합니다.

피치 방법: 자식 집합이 겹치면 교집합, 아니면 합집합 + 변화 1. 상태 k가지면 최소 k − 1번.

문제 8

자료 c1 0011, c2 0101, c3 0101, c4 0110(W, X, Y, Z 순)에서 나무 ((W, Y), (X, Z))의 길이는?

문제 9

형질 상태가 1, 1, 0, 0, 0(V, W, X, Y, Z 순)일 때 V와 W가 단계통군인 나무에서 필요한 최소 변화 횟수는?

문제 10

최대 절약법이 수렴 진화가 많은 형질에서 잘못된 나무를 고를 수 있는 이유를 쓰세요.
