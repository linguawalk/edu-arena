열기관과 냉동기

과학 올림피아드 S2 본선 · 열역학 · 3. 열기관과 엔트로피 · 심화 · 약 25분 · 문제 11개

이 레슨 풀어 보기

열을 일로 바꾸는 장치

열기관은 고온 열원에서 열 Q_H를 받아 일 W를 하고 남은 열 Q_C를 저온 열원에 버리며 순환합니다. 에너지 보존으로 Q_H = W + Q_C입니다.

효율은 e = W/Q_H = 1 − Q_C/Q_H입니다. 버리는 열이 0인 기관은 만들 수 없습니다(켈빈–플랑크의 제2법칙).

그림의 화살표를 반대로 하면 냉동기가 됩니다. 일 W를 들여 저온에서 Q_C를 뽑아 고온에 Q_H = Q_C + W를 버립니다.

문제 1

그림의 열기관이 한 번 돌 때 Q_H = 1000 J를 받아 300 J의 일을 합니다. 버리는 열 Q_C는 몇 J인가요?

문제 2

열을 모두 일로 바꾸는 순환 기관은 만들 수 없다는 것이 열역학 제＿＿＿법칙의 한 표현입니다.

냉동기와 열펌프

냉동기의 성능 계수는 COP = Q_C/W(뽑아낸 열 / 들인 일)입니다. 열펌프(난방)는 Q_H/W로 정의하며, 같은 장치라면 Q_H/W = Q_C/W + 1입니다.

성능 계수는 1보다 클 수 있습니다. 열을 만들어 내는 것이 아니라 옮기기 때문입니다. 그래서 열펌프 난방은 전기 히터보다 효율적입니다.

열은 저절로 저온에서 고온으로 가지 않으므로 냉동기에는 반드시 일이 필요합니다(클라우지우스의 제2법칙).

예제

냉동기가 한 번 돌 때 일 150 J를 들여 냉장고 안에서 열 600 J를 뽑아냅니다. 성능 계수와 부엌에 버리는 열을 구하세요.

  1. 냉동기의 성능 계수는 COP = Q_C/W입니다.
  2. 600/150 = 4입니다.
  3. 부엌에 버리는 열은 Q_H = Q_C + W = 600 + 150입니다.
  4. = 750 J입니다.

답: 4, 750 J

문제 3

효율 0.25인 엔진이 한 번 돌 때 500 J의 일을 합니다. 받는 열은 몇 J인가요?

문제 4

성능 계수 4인 냉동기를 열펌프(난방)로 쓰면 성능 계수 Q_H/W는?

일률로 보기

기관을 한 번 돌 때의 양 대신 1초 동안의 양(일률)으로 써도 같은 관계가 성립합니다: 받는 열률 = 출력 + 버리는 열률.

출력 40 kW, 효율 40%인 발전기는 연료에서 100 kW의 열을 받아 60 kW를 버립니다. 발전소 냉각탑과 강물로 나가는 열이 이 버리는 열입니다.

효율이 높아지면 같은 출력에서 버리는 열이 줄어 환경 부담도 줄어듭니다.

문제 5

출력 40 kW, 효율 0.4인 기관이 1초에 버리는 열은 몇 kJ인가요?

문제 6

열펌프가 전기 2 kW를 써서 집 안에 7 kW의 열을 공급합니다. 바깥에서 뽑아 오는 열은 몇 kW인가요?

문제 7

앞 문제 열펌프의 난방 성능 계수 Q_H/W는? (소수로)

정리

열기관: Q_H = W + Q_C, 효율 e = W/Q_H = 1 − Q_C/Q_H < 1(켈빈–플랑크).

냉동기: COP = Q_C/W, 열펌프: Q_H/W = COP + 1. 열을 저온에서 고온으로 옮기려면 일이 필요합니다(클라우지우스).

한 번 돌 때의 양 대신 일률로 써도 같은 관계가 성립합니다.

문제 8

한 번 돌 때 Q_H = 2500 J를 받고 Q_C = 1750 J를 버리는 기관의 효율은? (소수로)

문제 9

성능 계수 5인 냉동기로 1초에 1000 J의 열을 뽑아내려면 필요한 전력은 몇 W인가요?

문제 10

같은 장치를 냉동기와 열펌프로 쓸 때 열펌프 성능 계수가 냉동기 성능 계수보다 정확히 1 큼을 보이세요.

문제 11

클라우지우스 표현(일 없이 열이 저온에서 고온으로 가지 않는다)이 깨지면 켈빈–플랑크 표현도 깨짐을 보이세요.
