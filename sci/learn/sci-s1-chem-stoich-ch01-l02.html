기체의 몰 부피와 밀도

과학 올림피아드 S1 예선 · 화학양론 · 1. 몰과 화학식 · 심화 · 약 20분 · 문제 11개

같은 부피 속의 같은 분자 수

아보가드로 법칙: 온도와 압력이 같으면 같은 부피의 기체에는 종류와 관계없이 같은 수의 분자가 들어 있습니다.

그래서 기체 1몰의 부피(몰 부피)는 기체 종류와 관계없이 일정합니다. 0 °C, 1기압에서는 22.4 L입니다.

기체의 몰수는 n = V/22.4(0 °C, 1기압, L 단위)입니다. 11.2 L는 0.5몰, 2.24 L는 0.1몰입니다. 온도나 압력이 다르면 다음 챕터의 기체 법칙을 씁니다.

문제 1

0 °C, 1기압에서 산소 기체 11.2 L의 질량은 몇 g인가요?

문제 2

0 °C, 1기압에서 기체 1몰의 부피는 ＿＿＿ L입니다.

질량과 부피 잇기

기체의 질량에서 부피를 구하려면 질량 → 몰 → 부피 순서로 바꿉니다. CO₂ 4.4 g은 0.1몰이고, 0 °C, 1기압에서 2.24 L입니다.

같은 조건에서 부피의 비는 몰수의 비입니다. 그래서 기체 반응에서는 계수의 비가 곧 부피의 비가 됩니다(다음 챕터).

주의: 22.4 L는 기체에만 씁니다. 0 °C의 물은 액체이므로 물 1몰은 약 18 mL입니다.

예제

0 °C, 1기압에서 CO₂ 8.8 g의 부피와 분자 수를 구하세요.

  1. CO₂의 몰 질량은 44 g/mol이므로 8.8/44 = 0.2몰입니다.
  2. 부피는 0.2 × 22.4 = 4.48 L입니다.
  3. 분자 수는 0.2 × 6.0 × 10²³입니다.
  4. = 1.2 × 10²³개입니다.

답: 4.48 L, 1.2 × 10²³개

문제 3

0 °C, 1기압에서 CO₂ 4.4 g의 부피는 몇 L인가요? 소수로 쓰세요.

문제 4

0 °C, 1기압에서 메테인(CH₄) 44.8 L의 질량은 몇 g인가요?

기체의 밀도와 분자량

0 °C, 1기압에서 기체의 밀도는 d = M/22.4(g/L)입니다. 1몰의 질량을 1몰의 부피로 나눈 값이기 때문입니다.

거꾸로 밀도를 재면 분자량을 구할 수 있습니다: M = 22.4 × d. 밀도가 1.25 g/L이면 M = 28이고, N₂나 CO일 수 있습니다.

같은 조건에서 두 기체의 밀도의 비는 분자량의 비와 같습니다. 그래서 분자량이 29(공기의 평균 분자량)보다 큰 기체는 공기보다 무거워 아래로 가라앉습니다.

문제 6

같은 온도와 압력에서 어떤 기체의 밀도가 산소의 2배입니다. 이 기체의 분자량은?

기체 혼합물의 평균 분자량

여러 기체가 섞인 혼합물의 평균 분자량은 각 분자량을 몰 분율로 가중한 평균입니다.

공기를 N₂ 80%, O₂ 20%(몰 비율)로 보면 평균 분자량은 0.8 × 28 + 0.2 × 32 = 28.8, 약 29입니다.

평균 분자량을 알면 혼합물의 밀도나 몰수를 하나의 기체처럼 계산할 수 있습니다.

문제 7

N₂와 O₂가 몰 비 4 : 1로 섞인 기체의 평균 분자량은? 소수로 쓰세요.

정리

같은 온도와 압력에서 같은 부피의 기체에는 같은 수의 분자가 있습니다(아보가드로 법칙).

0 °C, 1기압에서 기체 1몰은 22.4 L입니다. 기체의 질량과 부피는 몰을 거쳐 바꿉니다.

기체의 밀도는 d = M/22.4이고, 같은 조건에서 밀도의 비는 분자량의 비입니다. 혼합물은 몰 분율로 가중한 평균 분자량을 씁니다.
