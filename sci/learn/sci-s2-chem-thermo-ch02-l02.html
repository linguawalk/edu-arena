반응이 저절로 일어날까

온도와 압력이 일정할 때 반응이 저절로 일어나는지는 깁스 자유 에너지 변화 ΔG = ΔH − TΔS로 판단합니다. ΔG < 0이면 자발적, ΔG > 0이면 비자발적(역반응이 자발적), ΔG = 0이면 평형입니다.

ΔG < 0은 계와 주위를 합친 전체 엔트로피가 늘어난다는 뜻입니다: ΔS_전체 = ΔS − ΔH/T = −ΔG/T.

그림의 암모니아 합성은 ΔH < 0, ΔS < 0이라 낮은 온도에서만 ΔG < 0입니다. 298 K에서 ΔG° = −92.2 − 298 × (−0.1987) ≈ −33.0 kJ입니다.

문제 1

그림에서 ΔG° = 0이 되는 온도는 약 몇 K인가요? (ΔH° = −92.2 kJ, ΔS° = −198.7 J/K, 반올림해 정수로)

문제 2

온도와 압력이 일정할 때 ΔG ＿＿＿ 0이면 반응이 자발적으로 일어납니다.

네 가지 경우

ΔH < 0, ΔS > 0: 모든 온도에서 ΔG < 0(항상 자발). ΔH > 0, ΔS < 0: 모든 온도에서 비자발.

ΔH < 0, ΔS < 0: 낮은 온도에서 자발(T < ΔH/ΔS). ΔH > 0, ΔS > 0: 높은 온도에서 자발(T > ΔH/ΔS). 얼음이 0 °C 위에서 녹는 것이 이 경우입니다.

ΔH와 ΔS의 단위를 맞춰야 합니다. ΔH는 kJ, ΔS는 J/K로 주어지는 경우가 많아 ΔS를 1000으로 나눕니다.

예제

CaCO₃ → CaO + CO₂(ΔH° = +178.3 kJ, ΔS° = +160.5 J/K)가 자발적으로 일어나기 시작하는 온도를 구하세요.

  1. ΔH > 0, ΔS > 0이므로 높은 온도에서 자발적입니다.
  2. ΔG° = 0인 온도는 T = ΔH°/ΔS° = 178300/160.5입니다.
  3. ≈ 1111 K입니다.
  4. 약 1111 K(838 °C)보다 높으면 석회석이 분해됩니다.

답: 약 1111 K

문제 3

298 K에서 N₂ + 3H₂ → 2NH₃(ΔH° = −92.2 kJ, ΔS° = −198.7 J/K)의 ΔG°는 몇 kJ인가요? (소수 첫째 자리까지)

문제 4

ΔH° = +30 kJ, ΔS° = +100 J/K인 반응이 자발적이 되는 최저 온도는 몇 K인가요?

자유 에너지의 다른 뜻

ΔG는 계가 할 수 있는 최대 유용한 일(팽창 일 제외)입니다. 연료 전지나 생물의 ATP 가수 분해는 ΔG만큼 전기 일이나 화학 일을 할 수 있습니다.

표준 생성 자유 에너지 ΔG_f°로 ΔG° = Σn ΔG_f°(생성물) − Σn ΔG_f°(반응물)을 구할 수도 있습니다(원소는 0).

ΔG < 0이라도 반응이 빨리 일어난다는 뜻은 아닙니다. 다이아몬드 → 흑연은 ΔG < 0이지만 매우 느립니다.

문제 5

ΔG_f°: CO₂(g) −394.4, H₂O(l) −237.1, CH₄(g) −50.8 kJ/mol일 때 CH₄ + 2O₂ → CO₂ + 2H₂O(l)의 ΔG°는 몇 kJ인가요? (소수로)

문제 6

ΔH° = −50 kJ, ΔS° = +40 J/K인 반응의 500 K에서 ΔG°는 몇 kJ인가요?

문제 7

얼음의 융해(ΔH = +6.01 kJ/mol, ΔS = +22.0 J/(mol·K))에서 263 K일 때 ΔG는 몇 kJ/mol인가요? (소수 둘째 자리까지)

정리

ΔG = ΔH − TΔS(일정한 T, P). ΔG < 0 자발, = 0 평형, > 0 비자발. ΔS_전체 = −ΔG/T입니다.

부호 조합에 따라 항상·낮은 온도·높은 온도에서만 자발이며, 경계 온도는 T = ΔH/ΔS입니다(단위를 맞출 것).

ΔG는 최대 유용한 일이며, ΔG < 0이라도 반응 속도는 따로 정해집니다.
