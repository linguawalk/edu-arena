ΔG°와 K

표준 상태가 아닌 조건에서는 ΔG = ΔG° + RT ln Q입니다(Q는 반응 지수). 평형에서는 ΔG = 0, Q = K이므로 ΔG° = −RT ln K입니다.

ΔG° < 0이면 K > 1(생성물 쪽), ΔG° > 0이면 K < 1(반응물 쪽), ΔG° = 0이면 K = 1입니다.

298 K에서 RT ln 10 = 8.314 × 298 × 2.303 ≈ 5.71 kJ이므로 ΔG°가 5.71 kJ 더 음수일 때마다 K는 10배씩 커집니다.

문제 2

반응 지수와 반응의 방향

현재 상태의 Q가 K보다 작으면 ΔG = RT ln(Q/K) < 0이라 정반응이 진행하고, Q > K이면 역반응이 진행합니다.

ΔG°는 '모든 물질이 표준 상태일 때'의 값이고, 실제로 반응이 어느 쪽으로 가는지는 ΔG로 판단합니다. ΔG° > 0인 반응도 생성물을 계속 치우면(Q를 작게) 진행할 수 있습니다.

예: ΔG° = −10.0 kJ인 반응이 Q = 100인 상태에 있으면 298 K에서 ΔG = −10.0 + RT ln 100 = −10.0 + 11.41 = +1.41 kJ로 역반응이 진행합니다.

예제

298 K에서 ΔG° = −33.0 kJ인 암모니아 합성의 평형 상수를 구하세요.

  1. ln K = −ΔG°/(RT) = 33000/(8.314 × 298)입니다.
  2. = 33000/2477.6 ≈ 13.32입니다.
  3. K = e^13.32입니다.
  4. ≈ 6.1 × 10⁵입니다.

답: 약 6.1 × 10⁵

문제 4

298 K에서 ΔG° = −10.0 kJ인 반응이 Q = 100인 상태에 있습니다. ΔG는 몇 kJ인가요? (소수 둘째 자리까지)

K의 크기 감각

298 K에서 ΔG°와 K의 관계는 K = 10^(−ΔG°/5.71 kJ)로 어림할 수 있습니다. ΔG° = −57.1 kJ이면 K ≈ 10¹⁰, +11.4 kJ이면 K ≈ 10⁻²입니다.

ΔG°가 수십 kJ만 되어도 K는 엄청나게 크거나 작습니다. 그래서 대부분의 반응은 거의 완결되거나 거의 일어나지 않습니다.

K가 1에 가까운 반응(|ΔG°|가 수 kJ)만 평형 혼합물에 반응물과 생성물이 둘 다 상당히 남습니다.

문제 7

298 K에서 ΔG° = +5.71 kJ인 반응의 평형 상수는? (소수로)

정리

ΔG = ΔG° + RT ln Q. 평형에서 ΔG = 0, Q = K이므로 ΔG° = −RT ln K입니다.

Q < K이면 정반응, Q > K이면 역반응이 진행합니다. 방향은 ΔG°가 아니라 ΔG로 판단합니다.

298 K에서 ΔG°가 5.71 kJ 줄 때마다 K가 10배가 됩니다. 그래서 ΔG°가 수십 kJ이면 반응은 거의 완결되거나 거의 일어나지 않습니다.
