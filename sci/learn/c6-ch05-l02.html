반응 지수와 평형의 방향

화학Ⅱ · 5. 화학 평형 · 레벨1 · 약 15분 · 문제 16개

어느 쪽으로 반응할까

어떤 혼합물이 평형에 있는지, 아니라면 정반응과 역반응 중 어느 쪽으로 진행할지 어떻게 알 수 있을까요?

현재 농도로 평형 상수와 같은 식을 계산해 K와 비교하면 됩니다.

문제 1

평형이 아닌 임의의 상태에서 평형 상수 식에 현재 농도를 넣어 계산한 값을 반응 ＿＿＿(Q)라고 합니다.

Q와 K의 비교

Q < K이면 생성물이 평형보다 적으므로 정반응이 일어나 평형에 도달합니다.

Q > K이면 생성물이 평형보다 많으므로 역반응이 일어납니다.

Q = K이면 이미 평형 상태입니다.

문제 2

Q < K이면 ＿＿＿이 우세하게 일어나 평형에 도달합니다.

문제 3

Q > K이면 ＿＿＿이 우세하게 일어납니다.

문제 4

H₂ + I₂ ⇌ 2HI(K = 64)에서 현재 [H₂] = 0.2 M, [I₂] = 0.2 M, [HI] = 0.4 M입니다. 반응 지수 Q는 얼마일까요?

예제

위 혼합물(Q = 4, K = 64)은 어느 방향으로 반응할까요?

  1. Q = 4 < K = 64입니다.
  2. 생성물(HI)이 평형보다 적습니다.
  3. 정반응이 일어나 HI가 늘어납니다.

답: 정반응

문제 5

Q = 4, K = 64인 혼합물에서는 ＿＿＿이 일어납니다.

평형 농도 구하기

K와 처음 농도를 알면 평형 농도를 구할 수 있습니다. 변화량을 x로 두고 평형 농도를 x로 나타낸 뒤 K 식에 넣어 풉니다.

예: A ⇌ B, K = 4, 처음 [A] = 1 M이면 평형에서 [A] = 1 − x, [B] = x입니다. x ÷ (1 − x) = 4에서 x = 0.8 M입니다.

문제 6

A ⇌ B(K = 4)에서 처음 [A] = 1 M, [B] = 0이면 평형에서 [B]는 몇 M일까요?

문제 7

A ⇌ B(K = 1)에서 처음 [A] = 2 M, [B] = 0이면 평형에서 [B]는 몇 M일까요?

문제 8

Q = K이면 반응은 이미 ＿＿＿ 상태입니다.

예제

빈 용기에 생성물만 넣으면 어느 방향으로 반응할까요?

  1. 반응물 농도가 0이므로 Q의 분모가 0이 되어 Q는 매우 큽니다(무한대).
  2. Q > K입니다.
  3. 역반응이 일어나 반응물이 생겨납니다.

답: 역반응

반응 방향 정리

Q < K → 정반응, Q > K → 역반응, Q = K → 평형.

평형 농도는 변화량 x로 나타내 K 식에 넣어 구합니다.

문제 9

반응 지수 Q는 평형 농도가 아닌 ＿＿＿의 농도로 계산합니다.

예제

A ⇌ B(K = 0.5)에서 현재 [A] = 1 M, [B] = 2 M이면?

  1. Q = [B]/[A] = 2입니다.
  2. Q = 2 > K = 0.5입니다.
  3. 역반응이 일어나 B가 줄고 A가 늘어납니다.

답: 역반응

문제 10

A ⇌ B에서 현재 [A] = 1 M, [B] = 2 M입니다. 반응 지수 Q는 얼마일까요?

문제 11

위 반응의 K가 0.5라면 ＿＿＿이 일어납니다.

문제 12

H₂ + I₂ ⇌ 2HI(K = 64)의 평형에서 [H₂] = [I₂] = 0.1 M입니다. [HI]는 몇 M일까요?

문제 13

빈 용기에 생성물만 넣으면 ＿＿＿이 일어납니다.

문제 14

A ⇌ B + C에서 현재 [A] = [B] = [C] = 0.5 M입니다. 반응 지수 Q는 얼마일까요?

문제 15

평형 상수가 매우 큰 반응은 거의 ＿＿＿까지 진행합니다.

문제 16

반응 지수 Q와 평형 상수 K를 비교해 반응의 진행 방향을 예측하는 방법을 설명해 보세요.
