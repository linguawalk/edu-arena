지수 생장

자원이 무한하면 개체군은 일정한 비율로 늘어납니다. 연속 모형은 dN/dt = rN, 해는 N = N₀e^(rt)이고 r은 내적 증가율(출생률 − 사망률)입니다.

개체 수가 두 배가 되는 시간은 ln 2/r ≈ 0.693/r입니다. r = 0.1/일이면 약 6.9일마다 두 배가 됩니다.

해마다 번식하는 생물은 이산 모형 Nₜ = N₀λᵗ로 나타냅니다. λ는 한 해의 증가 배율입니다(λ > 1이면 증가).

문제 1

내적 증가율 r = 0.1/일인 개체군이 두 배가 되는 데 걸리는 시간은 약 몇 일인가요? (소수 첫째 자리까지)

문제 2

20분마다 분열하는 세균 1마리는 2시간 뒤 몇 마리가 되나요? (자원 무한)

로지스틱 생장

실제로는 자원이 한정되어 개체 수가 늘수록 증가율이 줄어듭니다. 로지스틱 모형 dN/dt = rN(1 − N/K)에서 K는 환경이 지탱할 수 있는 최대 개체 수(환경 수용력)입니다.

그림처럼 S자 곡선이 되고, 증가 속도는 N = K/2에서 가장 큽니다(최대값 rK/4). N = K이면 증가가 멈춥니다.

어업에서 개체군을 K/2 근처로 유지하면 해마다 가장 많이 잡을 수 있습니다(최대 지속 생산량).

예제

그림의 개체군(r = 0.5/일, K = 1000)에서 N = 200일 때와 N = 500일 때의 증가 속도를 구하세요.

  1. dN/dt = rN(1 − N/K)입니다.
  2. N = 200: 0.5 × 200 × (1 − 0.2) = 80마리/일입니다.
  3. N = 500: 0.5 × 500 × (1 − 0.5) = 125마리/일입니다.
  4. N = K/2에서의 125 = rK/4가 최대 증가 속도입니다.

답: 80마리/일, 125마리/일

문제 4

한 해 증가 배율 λ = 1.2인 개체군이 처음 100마리라면 3년 뒤에는 몇 마리인가요? (소수 첫째 자리까지)

밀도 의존과 생활사

먹이 부족, 질병, 포식처럼 밀도가 높을수록 강해지는 요인을 밀도 의존 요인, 날씨나 화재처럼 밀도와 관계없는 요인을 밀도 독립 요인이라 합니다.

r 전략(빠른 생장, 많은 자손, 짧은 수명: 쥐, 잡초)은 불안정한 환경에, K 전략(느린 생장, 적은 자손, 긴 수명과 보살핌: 코끼리)은 안정된 환경에 알맞습니다.

로지스틱 모형에서 1 − N/K는 남은 자원의 비율처럼 생각할 수 있습니다.

문제 5

환경 수용력이 K = 4000인 개체군에서 증가 속도가 가장 큰 개체 수는?

문제 6

K = 4000, r = 0.3/년인 물고기 개체군에서 지속적으로 잡을 수 있는 최대량(최대 증가 속도)은 몇 마리/년인가요?

문제 7

가뭄으로 개체군 밀도와 관계없이 30%가 죽었습니다. 이 요인은? ① 밀도 의존 요인 ② 환경 수용력 ③ 밀도 독립 요인

정리

지수 생장: N = N₀e^(rt), 두 배 시간 ln 2/r. 이산: Nₜ = N₀λᵗ.

로지스틱: dN/dt = rN(1 − N/K). S자 곡선, N = K/2에서 최대 증가 rK/4, N = K에서 멈춤.

밀도 의존 요인(먹이·질병·포식)과 밀도 독립 요인(날씨·재해). r 전략과 K 전략.

문제 9
