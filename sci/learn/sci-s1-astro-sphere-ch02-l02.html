구면 코사인 법칙

구면 삼각형의 세 변을 a, b, c(중심각), 각 변의 맞은편 각을 A, B, C라 하면 cos a = cos b cos c + sin b sin c cos A가 성립합니다. 이것을 구면 코사인 법칙이라 합니다.

두 변과 그 사이의 각을 알면 나머지 한 변을 구할 수 있습니다.

b = c = 90°이면 cos a = cos A가 되어 a = A입니다. 북극에서 두 경선이 이루는 각이 적도 위 두 점 사이의 각거리와 같은 것과 같습니다.

문제 1

구면 삼각형에서 b = c = 90°, A = 60°일 때 변 a는 몇 °인가요?

문제 2

두 별 사이의 각거리를 구할 때는 두 별과 천구의 ＿＿＿을 꼭짓점으로 하는 구면 삼각형을 씁니다.

두 별 사이의 각거리

별 1(α₁, δ₁)과 별 2(α₂, δ₂)를 천구의 북극과 이으면, 두 변은 90° − δ₁, 90° − δ₂이고 그 사이의 각은 Δα입니다.

구면 코사인 법칙에 넣으면 cos d = sin δ₁ sin δ₂ + cos δ₁ cos δ₂ cos Δα입니다. d가 두 별 사이의 각거리입니다.

Δα는 각도로 바꿔 넣어야 합니다(1h = 15°).

예제

적위가 모두 60°이고 적경이 12h 차이 나는 두 별 사이의 각거리를 구하세요.

  1. Δα = 12h = 180°이므로 cos Δα = −1입니다.
  2. cos d = sin²60° + cos²60° × (−1) = 0.75 − 0.25입니다.
  3. = 0.5이므로 d = 60°입니다.
  4. 검산: 천구의 북극을 지나는 경로로 30° + 30° = 60°입니다.

답: 60°

문제 3

앞 예제에서 두 별 사이의 각거리는 몇 °인가요?

문제 4

천구의 적도 위에 있고 적경이 3h 차이 나는 두 별 사이의 각거리는 몇 °인가요?

특별한 경우

적경이 같으면(Δα = 0) cos d = sin δ₁ sin δ₂ + cos δ₁ cos δ₂ = cos(δ₁ − δ₂)이므로 d = |δ₁ − δ₂|입니다. 같은 시간권 위의 두 별입니다.

한 별이 천구의 북극(δ = 90°)에 있으면 cos d = sin δ₂이므로 d = 90° − δ₂입니다.

일반적인 경우에는 계산기로 cos d를 구한 뒤 역코사인을 취합니다. δ₁ = δ₂ = 30°, Δα = 6h이면 cos d = 0.25이므로 d ≈ 75.5°입니다.

문제 6

문제 7

천구의 북극과 적위 40°인 별 사이의 각거리는 몇 °인가요?

정리

구면 코사인 법칙 cos a = cos b cos c + sin b sin c cos A로 두 변과 끼인각에서 나머지 변을 구합니다.

두 별 사이의 각거리는 cos d = sin δ₁ sin δ₂ + cos δ₁ cos δ₂ cos Δα입니다.

적경이 같으면 d = |δ₁ − δ₂|, 둘 다 천구의 적도 위에 있으면 d = Δα, 한 별이 천구의 북극이면 d = 90° − δ입니다.
