무질서의 척도

엔트로피 S는 계가 가질 수 있는 미시 상태의 수(에너지가 퍼지는 정도)를 나타냅니다. 고체 < 액체 < 기체 순으로 크고, 같은 상에서는 온도가 높을수록, 분자가 복잡할수록 큽니다.

표준 몰 엔트로피 S°는 절대값을 표로 줄 수 있습니다(완전한 결정은 0 K에서 S = 0, 열역학 제3법칙). 원소의 S°도 0이 아닙니다.

반응의 ΔS° = Σn S°(생성물) − Σn S°(반응물)입니다. 기체의 몰수가 줄어드는 반응은 대개 ΔS° < 0입니다.

문제 1

S°: N₂(g) 191.6, H₂(g) 130.7, NH₃(g) 192.5 J/(mol·K)일 때 N₂ + 3H₂ → 2NH₃의 ΔS°는 몇 J/K인가요? (소수로)

문제 2

완전한 결정의 엔트로피는 0 K에서 0이라는 것이 열역학 제＿＿＿법칙입니다.

상전이의 엔트로피

녹는점이나 끓는점에서는 두 상이 평형이라 가역적으로 열이 드나듭니다. 그래서 ΔS = ΔH/T입니다.

물의 증발(ΔH = 40.7 kJ/mol, 373 K): ΔS = 40700/373 ≈ 109 J/(mol·K). 얼음의 융해(6.01 kJ/mol, 273 K): ΔS ≈ 22.0 J/(mol·K)입니다. 증발이 융해보다 엔트로피 증가가 훨씬 큽니다.

많은 액체는 끓는점에서 ΔS_증발 ≈ 88 J/(mol·K)입니다(트루턴 규칙). 물은 수소 결합 때문에 이보다 큽니다.

예제

벤젠의 증발 엔탈피가 30.8 kJ/mol입니다. 트루턴 규칙(ΔS_증발 ≈ 88 J/(mol·K))으로 끓는점을 어림하세요.

  1. 끓는점에서 ΔS = ΔH/T이므로 T = ΔH/ΔS입니다.
  2. T ≈ 30800/88입니다.
  3. = 350 K입니다.
  4. 실제 끓는점 353 K와 가깝습니다.

답: 약 350 K

문제 3

물의 증발 엔탈피가 40.7 kJ/mol일 때 373 K에서 증발의 몰 엔트로피 변화는 약 몇 J/(mol·K)인가요? (반올림해 정수로)

문제 4

얼음의 융해 엔탈피가 6.01 kJ/mol일 때 273 K에서 융해의 몰 엔트로피 변화는 몇 J/(mol·K)인가요? (소수 첫째 자리까지)

ΔS의 부호 어림

기체 몰수가 늘면 ΔS > 0, 줄면 ΔS < 0인 경우가 대부분입니다. 2H₂(g) + O₂(g) → 2H₂O(l)은 기체 3 mol이 사라져 크게 음수입니다.

고체가 녹거나 용해되면 대개 ΔS > 0입니다. 다만 이온이 물 분자를 강하게 붙잡아 질서가 생기면 음수가 될 수도 있습니다.

기체 몰수가 같으면 부호를 어림하기 어렵고 S° 값으로 계산해야 합니다.

문제 5

CaCO₃(s) → CaO(s) + CO₂(g)에서 기체 몰수의 변화는 몇 mol인가요? (그래서 ΔS° > 0)

문제 6

S°: CaCO₃(s) 92.9, CaO(s) 38.2, CO₂(g) 213.7 J/(mol·K)일 때 CaCO₃ → CaO + CO₂의 ΔS°는 몇 J/K인가요? (소수로)

문제 7

S°: H₂(g) 130.7, O₂(g) 205.2, H₂O(l) 70.0 J/(mol·K)일 때 2H₂ + O₂ → 2H₂O(l)의 ΔS°는 몇 J/K인가요? (소수로)

정리

엔트로피는 에너지가 퍼지는 정도(미시 상태 수)의 척도: 기체 > 액체 > 고체, 고온, 복잡한 분자일수록 큽니다.

ΔS° = Σn S°(생성물) − Σn S°(반응물), 원소의 S°도 0이 아닙니다(제3법칙이 기준).

상전이: ΔS = ΔH/T. 트루턴 규칙 ΔS_증발 ≈ 88 J/(mol·K). 기체 몰수 변화로 부호를 어림합니다.

문제 8

에탄올의 증발 엔탈피가 38.6 kJ/mol, 끓는점이 351 K입니다. 증발의 몰 엔트로피 변화는 약 몇 J/(mol·K)인가요? (반올림해 정수로)

문제 9

S°: NO(g) 210.8, O₂(g) 205.2, NO₂(g) 240.1 J/(mol·K)일 때 2NO + O₂ → 2NO₂의 ΔS°는 몇 J/K인가요? (소수로)

문제 10

끓는점에서 증발의 엔트로피 변화가 ΔS = ΔH_증발/T임을 설명하세요.

문제 11
