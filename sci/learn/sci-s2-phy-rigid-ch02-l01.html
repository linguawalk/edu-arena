단진동의 기술

사인 함수로 쓰는 운동

단진동은 x(t) = A cos(ωt + φ)로 쓰는 운동입니다. A는 진폭, ω는 각진동수, φ는 처음 위상이고 주기는 T = 2π/ω, 진동수는 f = 1/T = ω/(2π)입니다.

그래프는 x = 10 cos(5πt) cm, 곧 x = 0.1 cos(5πt) m로 A = 0.1 m, ω = 5π rad/s, 주기 T = 2π/(5π) = 0.4 s입니다.

미분하면 v = −Aω sin(ωt + φ), a = −Aω² cos(ωt + φ) = −ω²x입니다. 최대 속력은 Aω(평형점), 최대 가속도는 Aω²(양 끝)입니다.

문제 1

그래프의 단진동에서 1초 동안 몇 번 왕복하나요? (소수로)

문제 2

단진동에서 가속도는 변위에 비례하고 방향은 반대입니다: a = ＿＿＿x.

속력과 위치의 관계

x = A cos θ, v = −Aω sin θ(θ = ωt + φ)에서 sin² + cos² = 1을 쓰면 v² = ω²(A² − x²)입니다.

그래서 평형점(x = 0)에서 속력이 최대 Aω이고 양 끝(x = ±A)에서 0입니다. 위치만 알면 시각을 몰라도 속력을 구할 수 있습니다.

예: A = 0.2 m, ω = 10 rad/s인 진동에서 x = 0.12 m일 때 v = 10√(0.04 − 0.0144) = 10 × 0.16 = 1.6 m/s입니다.

예제

진폭 0.05 m, 각진동수 20 rad/s인 단진동의 최대 속력과 최대 가속도를 구하세요.

  1. 최대 속력은 평형점에서 v_max = Aω입니다.
  2. v_max = 0.05 × 20 = 1 m/s입니다.
  3. 최대 가속도는 양 끝에서 a_max = Aω² = 0.05 × 400입니다.
  4. = 20 m/s²입니다.

답: 1 m/s, 20 m/s²

문제 4

진폭 0.2 m, 각진동수 10 rad/s인 단진동에서 x = 0.12 m일 때 속력은 몇 m/s인가요? (소수로)

원운동의 그림자

반지름 A인 원 위를 각속도 ω로 등속 원운동하는 점을 지름에 투영하면 그 그림자는 x = A cos(ωt + φ)로 단진동합니다.

그래서 각진동수 ω는 대응하는 원운동의 각속도이고, 위상 θ = ωt + φ는 원 위 점의 각입니다.

x = A/2인 순간은 위상이 60°(또는 300°)이고, 평형점에서 x = A/2까지 가는 시간은 30°에 해당하는 T/12입니다.

문제 5

주기 1.2 s인 단진동이 평형점에서 출발해 x = A/2까지 가는 데 걸리는 가장 짧은 시간은 몇 s인가요? (소수로)

문제 6

진동수 5 Hz인 단진동의 주기는 몇 s인가요? (소수로)

문제 7

최대 속력이 2 m/s, 최대 가속도가 8 m/s²인 단진동의 진폭은 몇 m인가요? (소수로)

정리

단진동 x = A cos(ωt + φ): T = 2π/ω, f = 1/T입니다.

v_max = Aω(평형점), a_max = Aω²(양 끝), a = −ω²x, v² = ω²(A² − x²)입니다.

등속 원운동의 투영으로 보면 위상은 원 위의 각이고, 시간 문제를 각의 비율로 풀 수 있습니다.
