곡선을 직선으로 바꾸기

변수 사이 관계가 직선이 아니면 변수를 바꿔 직선으로 만듭니다(선형화). 단진자 T = 2π√(L/g)는 T² = (4π²/g)L이므로 T²을 L에 대해 그리면 직선이고 기울기가 4π²/g입니다.

그림의 기울기 4.0 s²/m에서 g = 4π²/4.0 = π² ≈ 9.87 m/s²입니다.

거듭제곱 관계 y = axⁿ은 log y = log a + n log x이므로 로그–로그 그래프의 기울기가 지수 n입니다. 지수 관계 y = y₀e^(−λt)는 ln y = ln y₀ − λt이므로 ln y–t 그래프의 기울기가 −λ입니다.

문제 1

그림에서 T²–L 그래프의 기울기가 4.0 s²/m일 때 g는 몇 m/s²인가요? (소수 둘째 자리까지)

문제 2

y = axⁿ 관계는 log y를 log x에 대해 그리면 직선이 되고, 그 기울기가 ＿＿＿입니다.

지수 감쇠의 선형화

방사성 붕괴의 계수율 N = N₀e^(−λt)는 ln N = ln N₀ − λt로 직선이 됩니다. 그림의 기울기 −0.139 s⁻¹에서 λ = 0.139 s⁻¹, 반감기 t½ = ln 2/λ = 0.693/0.139 ≈ 5 s입니다.

그래프에서는 ln N이 0.693 줄어드는 시간 간격이 반감기입니다. 그림에서 ln N은 5 s마다 0.693씩 줄어듭니다.

축전기의 방전, 감쇠 진동의 진폭, 빛의 흡수도 같은 방법으로 감쇠 상수를 구합니다.

예제

자료 (x, y) = (10, 2), (1000, 20)이 y = axⁿ 관계에 맞습니다. n과 a를 구하세요.

  1. log y = log a + n log x이므로 로그–로그 기울기가 n입니다.
  2. n = (log 20 − log 2)/(log 1000 − log 10) = 1/2입니다.
  3. a = y/x^n = 2/√10 ≈ 0.632입니다.
  4. 그래서 y ≈ 0.632√x입니다.

답: n = 1/2, a ≈ 0.632

문제 4

v² = v₀² + 2as 관계에서 v²–s 그래프의 기울기가 6 m/s²입니다. 가속도는 몇 m/s²인가요?

어떤 축을 고를까

y = a/x는 y를 1/x에 대해 그리면 원점을 지나는 직선이고 기울기가 a입니다. 보일 법칙 P = nRT/V는 P–1/V 그래프의 기울기가 nRT입니다.

케플러 제3법칙 T² ∝ a³은 log T–log a 그래프의 기울기가 3/2입니다.

모르는 상수가 기울기나 절편에 오도록 축을 고르는 것이 핵심입니다. 이론식에서 측정할 양을 한쪽에, 바꾸는 양을 다른 쪽에 두고 일차식이 되게 정리합니다.

문제 5

기체의 압력 P를 1/V에 대해 그렸더니 원점을 지나는 기울기 600 kPa·L인 직선이 되었습니다. nRT는 몇 J인가요?

문제 6

행성의 궤도 장반경 a와 주기 T를 로그–로그 그래프로 그리면 기울기는? (소수로)

문제 7

빛이 흡수체를 지날 때 I = I₀e^(−μx)입니다. ln I–x 그래프에서 ln I가 3 cm 동안 1.2 줄었습니다. μ는 몇 cm⁻¹인가요? (소수로)

정리

선형화: 이론식을 (측정량의 함수) = (기울기) × (바꾸는 양의 함수) + (절편) 꼴로 정리해 축을 고릅니다.

y = axⁿ → 로그–로그 기울기 n. y = y₀e^(−λt) → ln y–t 기울기 −λ, 반감기 ln 2/λ. y = a/x → y–1/x 기울기 a.

단진자는 T²–L 기울기 4π²/g, 등가속도 운동은 v²–s 기울기 2a입니다.
