진자의 주기를 차원으로 구하기

진자의 주기 T가 줄의 길이 L, 추의 질량 m, 중력가속도 g에만 의존한다고 합시다. T = C L^a m^b g^c로 놓고 양변의 차원을 맞춥니다.

[T] = T¹이고 우변은 L^a M^b (LT⁻²)^c = L^(a + c) M^b T^(−2c)입니다. 지수를 비교하면 L: a + c = 0, M: b = 0, T: −2c = 1이므로 c = −1/2, a = 1/2, b = 0입니다.

따라서 T = C√(L/g)입니다. 미분방정식을 풀지 않고도 주기가 질량과 무관하고 길이의 제곱근에 비례한다는 것을 알아냈습니다. 상수 C(실제로는 2π)는 차원 분석으로 정할 수 없습니다.

문제 1

진자의 길이를 4배로 하면 주기는 몇 배가 되나요?

문제 2

차원 분석으로 정할 수 없는 것은 식 앞에 붙는 ＿＿＿ 상수입니다.

예제

줄을 따라 가는 파동의 속력 v가 장력 F와 줄의 선밀도 μ(단위 길이당 질량)에만 의존할 때 식의 꼴을 구하세요.

  1. v = C F^a μ^b로 놓습니다. [F] = MLT⁻², [μ] = ML⁻¹입니다.
  2. 우변의 차원은 M^(a + b) L^(a − b) T^(−2a)이고 좌변은 LT⁻¹입니다.
  3. M: a + b = 0, L: a − b = 1, T: −2a = −1이므로 a = 1/2, b = −1/2입니다.
  4. 따라서 v = C√(F/μ)입니다.

답: v = C√(F/μ)

문제 3

줄의 장력을 9배로 하면 파동의 속력은 몇 배가 되나요?

문제 4

높이 h에서 자유낙하하는 시간을 t = C h^a g^b로 쓸 때 b를 분수로 쓰세요.

무차원 조합이 남는 경우

변수 중 같은 차원이 둘 이상 있으면 차원 분석만으로 식이 정해지지 않습니다. 예를 들어 진자가 진폭 θ₀(무차원)에도 의존하면 T = √(L/g) × f(θ₀)이고, 함수 f는 알 수 없습니다.

일반적으로 물리량이 n개이고 기본 차원이 k개이면 서로 독립인 무차원 조합이 n − k개 생깁니다(버킹엄 π 정리). 식은 '무차원 조합 하나 = 나머지 무차원 조합들의 함수' 꼴이 됩니다.

그래서 차원 분석은 변수가 적을 때 강력합니다. 경시 문제에서는 '어떤 양에만 의존한다'는 조건이 주어지는지 먼저 확인하세요.

문제 5

어떤 현상이 물리량 5개로 기술되고 기본 차원이 M, L, T 3개일 때 독립인 무차원 조합은 몇 개인가요?

문제 6

원운동의 구심가속도를 a = C v^p r^q로 쓸 때 p는?

폭발의 반지름

핵폭발 사진만 보고 폭발 에너지를 어림한 테일러의 계산이 유명합니다. 불덩이의 반지름 R이 에너지 E, 시간 t, 공기 밀도 ρ에만 의존한다고 놓습니다.

R = C E^a t^b ρ^c에서 [E] = ML²T⁻², [ρ] = ML⁻³입니다. M: a + c = 0, L: 2a − 3c = 1, T: −2a + b = 0을 풀면 a = 1/5, b = 2/5, c = −1/5입니다.

따라서 R = C(Et²/ρ)^(1/5)입니다. 사진에서 R과 t를 읽으면 E를 구할 수 있습니다. 이처럼 차원 분석은 실제 연구에서도 첫 어림으로 쓰입니다.

문제 7

앞 설명에서 R ∝ E^a t^b ρ^c일 때 b를 분수로 쓰세요.

정리

구하는 양을 '상수 × 변수들의 거듭제곱'으로 놓고 M, L, T의 지수를 비교하면 연립일차방정식이 됩니다.

차원 분석은 무차원 상수(2π 등)를 정하지 못합니다. 같은 차원의 변수가 여럿이면 무차원 조합의 함수가 남습니다.

결과로 얻는 비례 관계(T ∝ √L, v ∝ √F 등)만으로도 '몇 배가 되는가' 문제는 바로 풀 수 있습니다.

문제 8

행성의 공전 주기 T가 궤도 반지름 r, 중력 상수 G, 태양 질량 M에만 의존할 때, r을 4배로 하면 T는 몇 배가 되나요?

문제 9

물방울의 진동수 f가 표면장력 σ(차원 MT⁻²), 밀도 ρ, 반지름 r에만 의존할 때 f ∝ σ^a ρ^b r^c입니다. c를 분수로 쓰세요.

문제 10

진자의 주기 T가 길이 L, 질량 m, 중력가속도 g에만 의존한다고 할 때 T = C√(L/g)임을 차원 분석으로 보이세요.

문제 11

줄을 따라 가는 파동의 속력 v가 장력 F와 선밀도 μ에만 의존할 때 v = C√(F/μ)임을 보이세요.
