전하를 모아 두는 장치

카메라 플래시는 전지로 천천히 모아 둔 전기 에너지를 한순간에 방출해 밝게 빛납니다.

전하를 저장했다가 필요할 때 내보내는 장치가 축전기입니다.

문제 1

두 도체판을 마주 보게 놓아 전하를 저장하는 장치를 ＿＿＿라고 합니다.

전기 용량

축전기에 저장되는 전하량 Q는 걸어 준 전압 V에 비례합니다: Q = CV. 비례 상수 C를 전기 용량이라고 하며 단위는 F(패럿)입니다. 1 μF = 10⁻⁶ F입니다.

평행판 축전기의 전기 용량은 판의 넓이 A에 비례하고 판 사이 간격 d에 반비례합니다: C = εA ÷ d.

판 사이에 유전체(절연체)를 넣으면 유전율 ε이 커져 전기 용량이 커집니다. 진공에 대한 유전율의 비를 유전 상수라고 합니다.

문제 2

평행판 축전기의 판 넓이가 클수록 전기 용량이 ＿＿＿니다.

문제 3

전기 용량 2 μF인 축전기에 10 V의 전압을 걸면 저장되는 전하량은 몇 μC일까요?

문제 4

평행판 축전기의 판 간격을 2배로 하면 전기 용량은 몇 배가 될까요?

예제

판 넓이를 2배, 간격을 절반으로 하면 전기 용량은?

  1. C = εA/d입니다.
  2. 넓이 2배 → 2배, 간격 1/2 → 2배입니다.
  3. 2 × 2 = 4배입니다.

답: 4배

문제 5

평행판 축전기 사이에 유전 상수가 3인 유전체를 채우면 전기 용량은 몇 배가 될까요?

축전기의 에너지와 연결

축전기에 저장된 전기 에너지는 U = ½QV = ½CV² = Q² ÷ 2C입니다.

축전기를 병렬로 연결하면 각 축전기의 전압이 같고, 합성 전기 용량은 C = C₁ + C₂입니다.

직렬로 연결하면 각 축전기의 전하량이 같고, 합성 전기 용량은 1/C = 1/C₁ + 1/C₂입니다. 저항의 연결과 반대입니다.

문제 6

전기 용량 2 F인 축전기에 3 V의 전압을 걸면 저장되는 에너지는 몇 J일까요?

문제 7

2 μF과 3 μF인 축전기를 병렬로 연결하면 합성 전기 용량은 몇 μF일까요?

문제 8

3 μF과 6 μF인 축전기를 직렬로 연결하면 합성 전기 용량은 몇 μF일까요?

예제

전지에 연결된 채로 평행판 축전기의 간격을 2배로 하면 전하량과 에너지는?

  1. 전지에 연결되어 있으므로 전압 V는 일정합니다.
  2. C가 1/2이 되므로 Q = CV도 1/2이 됩니다.
  3. U = ½CV²도 1/2이 됩니다.

답: 전하량과 에너지 모두 1/2

축전기 정리

Q = CV, C = εA/d, U = ½CV². 병렬 C = C₁ + C₂(전압 같음), 직렬 1/C = 1/C₁ + 1/C₂(전하량 같음).

축전기는 전하와 에너지를 저장하고, 전원의 흔들림을 줄이거나 신호를 거르는 데 쓰입니다.

문제 9

병렬로 연결된 축전기들은 걸리는 ＿＿＿이 같습니다.

예제

4 μF 축전기 두 개를 직렬로 연결하면 합성 전기 용량은?

  1. 1/C = 1/4 + 1/4 = 1/2입니다.
  2. C = 2 μF입니다. 같은 축전기 두 개를 직렬로 이으면 절반이 됩니다.

답: 2 μF
