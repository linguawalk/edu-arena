가장 잘 맞는 직선

측정점들이 대략 직선 위에 있으면 y = bx + a인 직선을 맞춥니다. 각 점의 세로 차이(잔차) yᵢ − (bxᵢ + a)의 제곱의 합을 가장 작게 하는 직선이 최소제곱 직선입니다.

기울기는 b = Σ(xᵢ − x̄)(yᵢ − ȳ)/Σ(xᵢ − x̄)², 절편은 a = ȳ − b x̄입니다. 최소제곱 직선은 반드시 점 (x̄, ȳ)를 지납니다.

그림의 자료에서 x̄ = 3, ȳ = 6.0이고 Σ(xᵢ − x̄)(yᵢ − ȳ) = 19.8, Σ(xᵢ − x̄)² = 10이므로 b = 1.98, a = 6.0 − 1.98 × 3 = 0.06입니다.

문제 2

최소제곱 직선은 항상 자료의 평균점 (x̄, ＿＿＿)를 지납니다.

기울기의 물리적 의미

그래프의 기울기와 절편에는 단위가 있고 물리적 의미가 있습니다. 위치–시간 그래프의 기울기는 속도, 힘–늘어난 길이 그래프의 기울기는 용수철 상수입니다.

기울기는 맞춘 직선 위의 멀리 떨어진 두 점으로 구합니다. 측정점 두 개를 바로 쓰면 그 두 점의 우연 오차가 그대로 들어갑니다.

최소제곱 직선의 잔차 합은 0이므로, 점들이 직선 위아래에 고르게 흩어져 있는지 확인합니다. 잔차에 규칙적인 모양이 있으면 직선이 아닌 관계일 수 있습니다.

예제

자료 (0, 1), (1, 2), (2, 2), (3, 5)에 최소제곱 직선을 맞추세요.

  1. x̄ = 1.5, ȳ = 2.5입니다.
  2. x − x̄ = −1.5, −0.5, 0.5, 1.5이고 y − ȳ = −1.5, −0.5, −0.5, 2.5입니다.
  3. Σ(x − x̄)(y − ȳ) = 2.25 + 0.25 − 0.25 + 3.75 = 6, Σ(x − x̄)² = 5이므로 b = 1.2입니다.
  4. a = 2.5 − 1.2 × 1.5 = 0.7이므로 y = 1.2x + 0.7입니다.

답: y = 1.2x + 0.7

문제 4

용수철을 0.02 m 늘이면 1.0 N, 0.10 m 늘이면 5.0 N이 되는 맞춤 직선 위의 두 점이 있습니다. 용수철 상수는 몇 N/m인가요?

최소제곱 직선의 계산 순서

① x̄, ȳ를 구하고 ② 각 점의 x − x̄, y − ȳ를 표로 만든 뒤 ③ 곱의 합과 x − x̄ 제곱의 합을 구합니다. ④ 기울기 b를 나누어 구하고 ⑤ a = ȳ − b x̄입니다.

x 값이 1, 2, 3, 4, 5처럼 고르게 떨어져 있으면 x − x̄가 −2, −1, 0, 1, 2로 대칭이라 계산이 쉽습니다.

계산기에 '선형 회귀' 기능이 있어도 한 번은 손으로 해 보면 무엇을 최소화하는지 이해하게 됩니다.

문제 7

위치–시간 그래프에서 맞춤 직선이 (1 s, 3 m)와 (5 s, 23 m)를 지납니다. 물체의 속도는 몇 m/s인가요?

정리

최소제곱 직선: b = Σ(x − x̄)(y − ȳ)/Σ(x − x̄)², a = ȳ − b x̄이며 (x̄, ȳ)를 지납니다.

기울기와 절편에는 단위와 물리적 의미가 있고, 기울기는 맞춘 직선 위의 멀리 떨어진 두 점으로 구합니다.

잔차는 직선 위아래에 고르게 흩어져야 하며, 규칙적인 모양은 직선이 아닌 관계를 뜻할 수 있습니다.
