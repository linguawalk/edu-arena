감수 분열

과학 올림피아드 S1 예선 · 유전 · 1. 세포 분열과 염색체 · 심화 · 약 20분 · 문제 11개

두 번 나누는 분열

감수 분열은 생식세포를 만드는 분열로, DNA를 한 번 복제한 뒤 두 번 연속 나뉘어 염색체 수가 절반인 세포 4개를 만듭니다. 사람이면 2n = 46에서 n = 23입니다.

감수 1분열에서는 상동 염색체가 짝을 지어 2가 염색체를 이룬 뒤 서로 분리됩니다. 그래서 염색체 수가 절반이 됩니다.

감수 2분열은 체세포 분열과 비슷하게 자매 염색 분체가 분리됩니다. 염색체 수는 그대로 n이고 DNA 양이 절반이 됩니다.

문제 1

사람의 감수 1분열이 끝난 세포 하나에 있는 염색 분체는 몇 개인가요?

문제 2

감수 1분열에서는 ＿＿＿ 염색체가 분리됩니다.

예제

2n = 4인 세포가 감수 분열할 때 각 시기의 염색체 수와 DNA 양(G₁기 = 2C)을 정리하세요.

  1. G₁기: 염색체 4개, DNA 2C입니다. S기 뒤: 염색체 4개, DNA 4C입니다.
  2. 감수 1분열 후: 세포마다 염색체 2개, DNA 2C입니다.
  3. 감수 2분열 후: 세포마다 염색체 2개, DNA 1C입니다.
  4. 결국 염색체 수 n = 2, DNA 1C인 세포 4개가 생깁니다.

답: n = 2인 세포 4개

문제 3

앞 예제에서 감수 2분열이 끝난 세포 하나의 DNA 양은 몇 C인가요?

다양한 생식세포

감수 1분열 중기에 상동 염색체 쌍들은 서로 독립적으로 배열되어, 각 쌍에서 어느 쪽이 어느 극으로 갈지가 무작위로 정해집니다.

상동 염색체가 n쌍이면 교차 없이도 2ⁿ가지 생식세포가 만들어집니다. 사람은 2²³ ≈ 840만 가지입니다.

감수 1분열 전기에 상동 염색체의 염색 분체 사이에서 일어나는 교차는 대립유전자 조합을 더 섞어 다양성을 훨씬 크게 합니다.

문제 4

2n = 8인 초파리가 교차 없이 만들 수 있는 생식세포의 염색체 조합은 몇 가지인가요?

문제 5

2n = 6인 생물의 암수가 교차 없이 만드는 생식세포가 수정할 때 가능한 자손의 염색체 조합은 몇 가지인가요?

정자와 난자 형성

정자 형성에서는 1차 정모세포 1개가 감수 분열로 정자 4개를 만듭니다.

난자 형성에서는 세포질이 불균등하게 나뉘어, 1차 난모세포 1개가 큰 난자 1개와 작은 극체(최대 3개)를 만듭니다. 영양분을 난자 하나에 몰아 주기 위해서입니다.

사람의 난자 형성은 감수 1분열 전기에서 멈춰 있다가 사춘기 이후 배란 때 재개되고, 감수 2분열은 수정될 때 완료됩니다.

문제 6

1차 정모세포 50개가 모두 감수 분열을 마치면 정자는 몇 개 생기나요?

문제 7

1차 난모세포 20개가 모두 감수 분열을 마치면 난자는 몇 개 생기나요?

정리

감수 분열은 DNA를 한 번 복제하고 두 번 나뉘어 n, 1C인 세포 4개를 만듭니다. 감수 1분열에서 상동 염색체가, 감수 2분열에서 자매 염색 분체가 분리됩니다.

상동 염색체 n쌍의 독립적 배열로 교차 없이 2ⁿ가지 생식세포가 생기고, 교차가 다양성을 더 늘립니다.

1차 정모세포 1개는 정자 4개를, 1차 난모세포 1개는 난자 1개와 극체를 만듭니다.

문제 8

사람의 감수 2분열 후기 세포 하나에 있는 염색체는 몇 개인가요?

문제 9

2n = 10인 생물이 교차 없이 만들 수 있는 생식세포의 염색체 조합은 몇 가지인가요?

문제 10

감수 분열과 체세포 분열의 차이를 염색체의 행동과 결과로 비교하세요.

문제 11

상동 염색체가 3쌍인 생물이 교차 없이 2³ = 8가지 생식세포를 만드는 이유를 설명하세요.

문제의 정답과 해설, 힌트는 레슨을 풀면서 확인할 수 있습니다.
