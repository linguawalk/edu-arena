적합도와 선택

자연 선택은 유전적 변이가 있고, 그 변이가 생존과 번식에 차이를 만들며, 그 차이가 자손에게 유전될 때 일어납니다. 유전자형마다 다음 세대에 남기는 자손의 상대적인 수를 적합도 w라 합니다.

열성 동형 접합자(aa)의 적합도가 1 − s이고 AA, Aa는 1이면 한 세대 뒤 q' = (pq + q²(1 − s))/(1 − sq²)입니다.

aa가 전혀 번식하지 못하면(s = 1) q' = q/(1 + q)이고 n세대 뒤 qₙ = q₀/(1 + nq₀)입니다.

문제 1

aa가 전혀 번식하지 못하고(s = 1) 현재 q = 0.5이면 한 세대 뒤 q는? (소수 셋째 자리까지)

문제 2

자연 선택이 일어나기 위한 조건이 아닌 것은? ① 개체가 일생 동안 얻은 형질의 유전 ② 유전적 변이 ③ 번식 성공의 차이

느려지는 선택

그림처럼 aa를 완전히 제거해도 q는 처음에는 빨리 줄지만 작아질수록 매우 느리게 줄어듭니다. 대부분의 a가 선택을 받지 않는 보인자 속에 있기 때문입니다.

qₙ = q₀/(1 + nq₀)를 고쳐 쓰면 1/qₙ = 1/q₀ + n입니다. q를 0.1에서 0.01로 줄이려면 n = 100 − 10 = 90세대가 걸립니다.

그래서 우생학처럼 열성 유전병 환자의 번식을 막아 대립유전자를 없애려는 시도는 효과가 거의 없습니다.

예제

그림처럼 aa가 번식하지 못할 때 q₀ = 0.5에서 8세대 뒤 q를 구하고, q가 0.05가 되는 데 몇 세대가 걸리는지 구하세요.

  1. qₙ = q₀/(1 + nq₀)에 n = 8을 넣으면 0.5/(1 + 4) = 0.1입니다.
  2. 1/qₙ = 1/q₀ + n을 씁니다.
  3. 1/0.05 = 20 = 2 + n이므로 n = 18입니다.
  4. 18세대가 걸립니다.

답: 0.1, 18세대

문제 4

AA와 Aa의 적합도가 1, aa의 적합도가 0.5이고 현재 q = 0.4이면 한 세대 뒤 q는? (소수 셋째 자리까지)

이형 접합자 우위

이형 접합자의 적합도가 두 동형 접합자보다 높으면 두 대립유전자가 모두 유지됩니다. AA의 적합도 1 − s, Aa 1, aa 1 − t이면 평형 빈도 q = s/(s + t)입니다.

낫 모양 적혈구 대립유전자(HbS)는 동형 접합자에게 심한 빈혈을 일으키지만, 이형 접합자는 말라리아에 강해 말라리아 지역에서 높은 빈도로 유지됩니다.

예: 말라리아로 AA의 적합도가 0.9(s = 0.1), 빈혈로 SS의 적합도가 0.2(t = 0.8)이면 q = 0.1/0.9 ≈ 0.11입니다.

문제 7

AA의 적합도 0.9, Aa 1, aa 0.7일 때 평형에서 a의 빈도는? (소수 셋째 자리까지)

정리

자연 선택의 조건: 유전적 변이, 생존·번식 차이, 유전. 적합도 w = 상대적인 자손 수.

aa에 대한 선택: q' = (pq + q²(1 − s))/(1 − sq²). 완전 선택이면 1/qₙ = 1/q₀ + n으로 q가 작을수록 매우 느림.

이형 접합자 우위(AA 1 − s, aa 1 − t): 평형 q = s/(s + t). 예: 낫 모양 적혈구와 말라리아.
