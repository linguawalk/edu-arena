수분 퍼텐셜

과학 올림피아드 S1 예선 · 세포 · 2. 생체막과 물질 수송 · 심화 · 약 20분 · 문제 11개

물은 수분 퍼텐셜이 낮은 쪽으로

식물 생리학에서는 물의 이동을 수분 퍼텐셜 ψ(프사이, 단위 MPa)로 설명합니다. 물은 언제나 ψ가 높은 곳에서 낮은 곳으로 이동합니다.

ψ = ψs + ψp입니다. 용질 퍼텐셜 ψs는 용질이 녹아 있을수록 음수로 작아지고, 압력 퍼텐셜 ψp는 세포벽이 세포를 누르는 압력(팽압)이 있으면 양수가 됩니다.

순수한 물이 대기압에 있으면 ψ = 0 MPa입니다. 그래서 용액이나 세포의 ψ는 보통 음수입니다.

문제 1

물은 수분 퍼텐셜이 ＿＿＿ 곳에서 낮은 곳으로 이동합니다.

문제 2

어떤 세포의 ψs = −0.8 MPa, ψp = 0.3 MPa입니다. 이 세포의 수분 퍼텐셜은 몇 MPa인가요? 소수로 쓰세요.

용질 퍼텐셜 계산

용질 퍼텐셜은 ψs = −iCRT로 구합니다. i는 이온화 상수(입자 수), C는 몰농도, R = 0.0083 L·MPa/(mol·K), T는 절대 온도입니다.

계산을 쉽게 하려고 이 레슨에서는 RT = 2.5 L·MPa/mol(약 27 °C)로 씁니다. 0.1 M 설탕 용액이면 ψs = −1 × 0.1 × 2.5 = −0.25 MPa입니다.

0.1 M NaCl이면 i = 2이므로 ψs = −0.5 MPa입니다. 열린 용기의 용액은 ψp = 0이므로 ψ = ψs입니다.

예제

열린 비커에 담긴 0.2 M 설탕 용액의 수분 퍼텐셜을 구하세요. (RT = 2.5 L·MPa/mol)

  1. 설탕은 이온화하지 않으므로 i = 1입니다.
  2. ψs = −iCRT = −1 × 0.2 × 2.5 = −0.5 MPa입니다.
  3. 열린 용기이므로 ψp = 0입니다.
  4. ψ = −0.5 MPa입니다.

답: −0.5 MPa

문제 3

앞 예제의 수분 퍼텐셜은 몇 MPa인가요? 소수로 쓰세요.

문제 4

열린 비커에 담긴 0.1 M CaCl₂ 용액의 수분 퍼텐셜은 몇 MPa인가요? (완전히 이온화, RT = 2.5) 소수로 쓰세요.

세포와 용액 사이의 물 이동

ψ = −0.5 MPa인 세포를 ψ = −0.3 MPa인 용액에 넣으면 물은 ψ가 높은 용액에서 세포로 들어갑니다. 세포가 팽창하면서 ψp가 커지고, 세포의 ψ가 −0.3 MPa이 되면 이동이 멈춥니다.

용질이 거의 이동하지 않는다면 세포의 ψs는 거의 그대로이므로, 평형에서 ψp = −0.3 − (−0.8) = 0.5 MPa가 됩니다(ψs = −0.8일 때).

반대로 세포보다 ψ가 낮은 용액에 넣으면 물이 빠져나가 ψp가 0까지 떨어지고, 더 빠지면 원형질 분리가 일어납니다.

문제 5

ψs = −0.8 MPa, ψp = 0.3 MPa인 세포를 ψ = −0.3 MPa인 용액에 넣었습니다. 물은 세포 안으로 들어가나요, 나오나요? 들어가면 1, 나오면 2를 쓰세요.

문제 6

앞 문제에서 평형에 이르렀을 때 세포의 ψp는 몇 MPa인가요? (ψs는 변하지 않는다고 가정) 소수로 쓰세요.

원형질 분리 직전

세포를 점점 진한 용액에 넣으면 ψp가 0이 되는 순간이 원형질 분리가 막 시작되는 지점(초발 원형질 분리)입니다. 이때 세포의 ψ = ψs입니다.

그래서 여러 농도의 설탕 용액에 조직을 넣고 세포의 절반이 원형질 분리되는 농도를 찾으면, 그 용액의 ψs가 곧 세포액의 ψs입니다.

예를 들어 0.4 M 설탕 용액에서 절반이 원형질 분리되면 세포액의 ψs = −0.4 × 2.5 = −1.0 MPa입니다.

문제 7

ψs = −0.7 MPa이고 ψp = 0인 세포를 순수한 물에 넣었습니다. 평형에서 ψp는 몇 MPa인가요? (ψs는 변하지 않는다고 가정) 소수로 쓰세요.

정리

물은 수분 퍼텐셜 ψ가 높은 곳에서 낮은 곳으로 이동하며, ψ = ψs + ψp입니다. 순수한 물은 ψ = 0입니다.

ψs = −iCRT로 용질이 많을수록 음수로 작아지고, ψp는 팽압이 있으면 양수입니다. 열린 용기의 용액은 ψp = 0입니다.

세포와 용액의 ψ가 같아지면 물의 이동이 멈춥니다. 초발 원형질 분리에서 ψp = 0이므로 세포액의 ψs를 잴 수 있습니다.

문제 8

0.4 M 설탕 용액에서 감자 조직 세포의 절반이 원형질 분리되었습니다. 세포액의 ψs는 몇 MPa인가요? (RT = 2.5) 소수로 쓰세요.

문제 9

ψs = −1.2 MPa인 세포가 ψ = −0.4 MPa인 용액과 평형을 이루었습니다. ψp는 몇 MPa인가요? 소수로 쓰세요.

문제 10

ψs = −0.8 MPa, ψp = 0.3 MPa인 세포를 ψ = −0.3 MPa인 용액에 넣으면 물이 세포 안으로 들어가고, 평형에서 ψp = 0.5 MPa가 됨을 보이세요.

문제 11

여러 농도의 설탕 용액으로 식물 세포액의 용질 퍼텐셜을 재는 방법과 그 원리를 설명하세요.
