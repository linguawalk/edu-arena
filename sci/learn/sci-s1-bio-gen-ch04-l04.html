평형을 깨는 요인

과학 올림피아드 S1 예선 · 유전 · 4. 집단 유전 · 심화 · 약 20분 · 문제 12개

다섯 가지 요인

하디-바인베르크 평형의 조건이 깨지면 대립유전자 빈도가 변합니다. 돌연변이, 이주(유전자 흐름), 유전적 부동, 비무작위 교배, 자연 선택이 그 요인입니다.

이주는 다른 집단의 대립유전자가 들어오는 것입니다. 이주 비율이 m, 들어오는 집단의 빈도가 q_m이면 다음 세대 빈도는 q' = (1 − m)q + m·q_m입니다.

q = 0.2인 섬 집단에 q_m = 0.6인 본토 개체가 10%(m = 0.1) 들어오면 q' = 0.9 × 0.2 + 0.1 × 0.6 = 0.24입니다.

문제 1

q = 0.2인 집단에 q_m = 0.6인 개체가 10% 이주해 왔습니다. 다음 세대의 q는? 소수로 쓰세요.

문제 2

작은 집단에서 우연에 의해 대립유전자 빈도가 무작위로 변하는 현상을 유전적 ＿＿＿라 합니다.

열성 치사 대립유전자에 대한 선택

aa가 자손을 전혀 남기지 못하면(적응도 0) 다음 세대의 a 빈도는 q' = q/(1 + q)가 됩니다. aa가 사라지고 Aa에 있는 a만 남기 때문입니다.

이 식을 반복하면 t세대 뒤 q_t = q₀/(1 + t·q₀), 곧 1/q_t = 1/q₀ + t입니다.

q가 작아질수록 a는 대부분 보인자 속에 숨어 선택을 받지 않으므로 줄어드는 속도가 아주 느려집니다. q₀ = 0.01을 절반으로 줄이는 데 100세대가 걸립니다.

예제

열성 치사 대립유전자의 빈도가 q = 0.5인 집단에서 한 세대 뒤의 q를 구하세요.

  1. aa(빈도 0.25)는 모두 죽고 AA 0.25, Aa 0.5만 자손을 남깁니다.
  2. 살아남은 개체 중 Aa의 비율은 0.5/0.75 = 2/3입니다.
  3. a는 Aa에만 1개씩 있으므로 q' = (2/3)/2 = 1/3입니다.
  4. 식으로는 q' = 0.5/(1 + 0.5) = 1/3입니다.

답: 1/3

문제 4

열성 치사 대립유전자의 빈도를 0.1에서 0.05로 줄이려면 몇 세대가 걸리나요?

근친 교배

근친 교배는 대립유전자 빈도는 바꾸지 않지만 동형 접합자를 늘리고 이형 접합자를 줄입니다. 근교 계수 F는 한 개체의 두 대립유전자가 같은 조상에게서 온 확률입니다.

근친 교배 집단에서 aa = q² + Fpq, Aa = 2pq(1 − F), AA = p² + Fpq입니다. 사촌 간 결혼의 자녀는 F = 1/16입니다.

q = 0.1이면 무작위 교배에서 aa = 0.01이지만, 사촌 간 결혼의 자녀는 0.01 + 0.09/16 ≈ 0.0156으로 약 1.6배가 됩니다. 희귀한 열성 질환일수록 이 배율이 커집니다.

문제 5

q = 0.1인 집단에서 사촌 간 결혼(F = 1/16)의 자녀가 aa일 확률은? 소수로 쓰세요.

문제 6

p = q = 0.5인 집단에서 근교 계수 F = 0.5이면 이형 접합자(Aa)의 빈도는? 소수로 쓰세요.

이형 접합자 우세와 돌연변이

말라리아가 흔한 지역에서는 겸형 적혈구 보인자(AS)가 정상(AA)보다 말라리아에 강해 가장 잘 살아남습니다. 이런 이형 접합자 우세가 있으면 두 대립유전자가 모두 유지되는 평형이 생깁니다.

AA의 적응도가 1 − s, SS의 적응도가 1 − t이면 평형에서 S의 빈도는 q̂ = s/(s + t)입니다. s = 0.1, t = 0.9이면 q̂ = 0.1입니다.

돌연변이는 새로운 대립유전자를 만드는 근원이지만 속도가 느립니다. 세대당 돌연변이율이 10⁻⁵이면 A가 거의 전부인 집단에서 1000세대 동안 a의 빈도가 약 0.01 늘어납니다.

문제 7

이형 접합자 우세에서 AA의 적응도 감소 s = 0.1, SS의 적응도 감소 t = 0.9입니다. 평형에서 S의 빈도는? 소수로 쓰세요.

문제 8

A → a 돌연변이율이 세대당 1 × 10⁻⁵이고 처음에 a가 없는 집단에서, 1000세대 뒤 a의 빈도는 약 얼마인가요? (p ≈ 1로 근사) 소수로 쓰세요.

정리

돌연변이, 이주, 유전적 부동, 비무작위 교배, 자연 선택이 하디-바인베르크 평형을 깹니다. 이주는 q' = (1 − m)q + m·q_m입니다.

열성 치사에 대한 선택은 q' = q/(1 + q), 1/q_t = 1/q₀ + t로 빈도가 낮아질수록 느리게 줄어듭니다.

근친 교배는 aa = q² + Fpq로 동형 접합자를 늘립니다. 이형 접합자 우세는 q̂ = s/(s + t)의 평형을 만듭니다.
