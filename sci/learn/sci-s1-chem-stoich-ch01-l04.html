태워서 성분 알아내기

C, H(와 O)로 이루어진 화합물을 완전히 태우면 C는 모두 CO₂로, H는 모두 H₂O로 바뀝니다. 생긴 CO₂와 H₂O의 질량을 재면 원래 화합물의 C와 H의 양을 알 수 있습니다.

CO₂ 44 g에는 C 12 g(1몰)이, H₂O 18 g에는 H 2 g(2몰)이 들어 있습니다. 그래서 C의 몰수 = CO₂의 몰수, H의 몰수 = H₂O의 몰수 × 2입니다.

화합물에 O가 있으면, 원래 질량에서 C와 H의 질량을 뺀 나머지가 O의 질량입니다. 연소에 쓰인 산소 기체와 헷갈리지 마세요.

문제 1

어떤 탄화수소를 태웠더니 CO₂ 8.8 g이 생겼습니다. 원래 화합물에 들어 있던 탄소는 몇 g인가요? 소수로 쓰세요.

문제 2

연소 분석에서 H의 몰수는 생긴 H₂O의 몰수의 ＿＿＿배입니다.

예제

어떤 탄화수소를 완전히 태웠더니 CO₂ 8.8 g과 H₂O 5.4 g이 생겼습니다. 실험식을 구하세요.

  1. C: 8.8/44 = 0.2몰입니다.
  2. H: H₂O 5.4/18 = 0.3몰이므로 H는 0.6몰입니다.
  3. C : H = 0.2 : 0.6 = 1 : 3입니다.
  4. 실험식은 CH₃입니다.

답: CH₃

문제 3

앞 예제의 탄화수소의 분자량이 30이면 분자식에서 H의 수는?

문제 4

앞 예제에서 태운 탄화수소의 질량은 몇 g인가요? 소수로 쓰세요.

산소가 들어 있는 화합물

C, H, O로 이루어진 화합물 4.6 g을 태워 CO₂ 8.8 g과 H₂O 5.4 g을 얻었다면 C 2.4 g(0.2몰), H 0.6 g(0.6몰)입니다.

나머지 4.6 − 2.4 − 0.6 = 1.6 g이 O이고, 0.1몰입니다. C : H : O = 0.2 : 0.6 : 0.1 = 2 : 6 : 1이므로 실험식은 C₂H₆O(에탄올의 실험식)입니다.

O의 양은 반드시 '원래 질량 − C − H'로 구합니다. 연소에 쓰인 O₂는 바깥에서 들어온 것이라 원래 화합물의 O가 아닙니다.

문제 5

C, H, O로 된 화합물 4.6 g을 태워 CO₂ 8.8 g과 H₂O 5.4 g을 얻었습니다. 화합물에 들어 있던 산소는 몇 g인가요? 소수로 쓰세요.

수화물

황산 구리 결정 CuSO₄·5H₂O처럼 물 분자를 일정한 비율로 품고 있는 결정을 수화물이라고 합니다. 가열하면 물이 빠져나가 무수물이 됩니다.

가열 전후의 질량 차이가 빠져나간 물의 질량입니다. 무수물의 몰수와 물의 몰수의 비가 화학식의 x입니다.

CuSO₄·xH₂O 25.0 g을 가열해 16.0 g이 남았다면 물은 9.0 g(0.5몰), CuSO₄(160 g/mol)는 0.1몰이므로 x = 5입니다.

문제 6

CuSO₄·xH₂O 25.0 g을 가열해 무수 CuSO₄ 16.0 g을 얻었습니다. x는? (CuSO₄ = 160 g/mol)

문제 7

어떤 탄화수소를 태웠더니 CO₂ 17.6 g과 H₂O 7.2 g이 생겼습니다. 실험식에서 H/C의 비는?

정리

연소 분석: C의 몰수 = CO₂의 몰수, H의 몰수 = H₂O 몰수 × 2입니다.

화합물에 O가 있으면 O의 질량 = 원래 질량 − C의 질량 − H의 질량입니다. 몰수의 비로 실험식을 구하고, 분자량으로 분자식을 정합니다.

수화물 X·xH₂O는 가열 전후의 질량 차이로 물의 몰수를 구하고, 무수물 몰수와의 비로 x를 구합니다.
