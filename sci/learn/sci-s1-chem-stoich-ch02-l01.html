화학 반응식 맞추기

원자는 사라지지 않는다

화학 반응에서는 원자들의 결합이 바뀔 뿐 원자가 새로 생기거나 없어지지 않습니다. 그래서 반응식의 양쪽에서 각 원소의 원자 수가 같아야 합니다(질량 보존).

화학식 앞의 숫자(계수)를 조절해 원자 수를 맞춥니다. 화학식의 아래 첨자는 물질 자체를 바꾸므로 절대 바꾸면 안 됩니다.

프로페인의 연소: C₃H₈ + O₂ → CO₂ + H₂O에서 C를 맞추면 3CO₂, H를 맞추면 4H₂O, 그러면 오른쪽 O가 6 + 4 = 10개이므로 5O₂입니다: C₃H₈ + 5O₂ → 3CO₂ + 4H₂O.

문제 1

C₃H₈ + aO₂ → 3CO₂ + 4H₂O가 맞는 반응식이 되도록 하는 a는?

문제 2

화학 반응 전후에 각 원소의 원자 ＿＿＿는 같습니다.

맞추는 순서

가장 복잡한 화학식의 계수를 1로 두고 시작합니다. 한 화합물에만 나오는 원소(C, H)부터 맞추고, 여러 곳에 나오는 원소(O)는 마지막에 맞춥니다.

O₂의 계수가 분수(예: 7/2)로 나오면 전체에 2를 곱해 정수로 만듭니다. 마지막에 모든 원소의 원자 수를 다시 세어 검산합니다.

에테인의 연소: C₂H₆ + O₂ → 2CO₂ + 3H₂O에서 오른쪽 O가 7개이므로 O₂ 7/2개입니다. 2를 곱하면 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O입니다.

예제

에테인의 연소 반응식 C₂H₆ + O₂ → CO₂ + H₂O를 가장 간단한 정수 계수로 맞추세요.

  1. C₂H₆의 계수를 1로 두면 C: 2CO₂, H: 3H₂O입니다.
  2. 오른쪽 O는 4 + 3 = 7개이므로 O₂는 7/2입니다.
  3. 전체에 2를 곱해 정수로 만듭니다.
  4. 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O입니다.

답: 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O

문제 3

에테인의 연소 반응식을 가장 간단한 정수 계수로 맞추었을 때 O₂의 계수는?

문제 4

aAl + bO₂ → cAl₂O₃를 가장 간단한 정수 계수로 맞추었을 때 a + b + c는?

미지수로 맞추기

눈으로 맞추기 어려우면 계수를 미지수로 놓고 원소마다 식을 세웁니다. aFe₂O₃ + bCO → cFe + dCO₂에서 Fe: 2a = c, C: b = d, O: 3a + b = 2d입니다.

a = 1로 두면 c = 2이고, 3 + b = 2b에서 b = 3, d = 3입니다. 그래서 Fe₂O₃ + 3CO → 2Fe + 3CO₂입니다.

미지수가 원소 수보다 하나 많으므로 하나를 1로 두면 나머지가 정해집니다. 분수가 나오면 분모를 곱해 정수로 만듭니다.

문제 6

aNH₃ + bO₂ → cNO + dH₂O를 가장 간단한 정수 계수로 맞추었을 때 b는?

이온 반응식과 전하

이온이 참여하는 반응식에서는 원자 수뿐 아니라 전하의 합도 양쪽이 같아야 합니다. 전하도 보존되기 때문입니다.

Cu + Ag⁺ → Cu²⁺ + Ag는 원자 수는 맞지만 전하가 왼쪽 +1, 오른쪽 +2로 다릅니다. Ag⁺와 Ag에 2를 붙여 Cu + 2Ag⁺ → Cu²⁺ + 2Ag로 맞춥니다.

산화·환원 반응에서 잃은 전자 수와 얻은 전자 수가 같다는 것과 같은 조건입니다. S2에서 산화수로 더 체계적으로 맞추는 방법을 배웁니다.

문제 7

aZn + bFe³⁺ → cZn²⁺ + dFe를 가장 간단한 정수 계수로 맞추었을 때 a는?

정리

반응식의 양쪽에서 각 원소의 원자 수가 같아야 하고, 계수만 조절합니다. 아래 첨자는 바꾸지 않습니다.

복잡한 화학식을 1로 두고 한 곳에만 나오는 원소부터 맞춥니다. O는 마지막에, 분수가 나오면 정수를 곱합니다. 어려우면 계수를 미지수로 놓고 원소별 식을 세웁니다.

이온 반응식은 전하의 합도 같아야 합니다. 마지막에 모든 원소와 전하를 다시 세어 검산하세요.
