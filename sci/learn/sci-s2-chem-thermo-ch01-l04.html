결합을 끊고 만드는 에너지

결합 엔탈피는 기체 상태 분자의 결합 1 mol을 끊는 데 필요한 에너지입니다(항상 양수). 결합을 만들 때는 같은 크기의 에너지가 나옵니다.

그래서 기체 반응의 ΔH ≈ Σ(끊는 결합 엔탈피) − Σ(만드는 결합 엔탈피)입니다. 표의 값은 여러 분자의 평균이라 생성 엔탈피로 구한 값보다 덜 정확합니다.

H–H 436, Cl–Cl 242, H–Cl 431 kJ/mol이면 H₂ + Cl₂ → 2HCl의 ΔH ≈ (436 + 242) − 2 × 431 = 678 − 862 = −184 kJ입니다.

문제 1

H–H 436, Br–Br 193, H–Br 366 kJ/mol일 때 H₂(g) + Br₂(g) → 2HBr(g)의 ΔH는 약 몇 kJ인가요?

문제 2

결합을 끊는 과정은 항상 ＿＿＿ 과정입니다.

메테인의 연소

C–H 413, O=O 498, C=O 799, O–H 463 kJ/mol을 씁니다. CH₄ + 2O₂ → CO₂ + 2H₂O(g)에서 끊는 결합은 C–H 4개, O=O 2개입니다.

끊는 데 4 × 413 + 2 × 498 = 1652 + 996 = 2648 kJ, 만드는 결합은 C=O 2개와 O–H 4개로 2 × 799 + 4 × 463 = 1598 + 1852 = 3450 kJ입니다.

ΔH ≈ 2648 − 3450 = −802 kJ로 생성 엔탈피로 구한 −802.3 kJ(수증기)과 잘 맞습니다. 결합 엔탈피는 기체 반응에만 바로 씁니다.

예제

N≡N 945, H–H 436, N–H 391 kJ/mol로 N₂(g) + 3H₂(g) → 2NH₃(g)의 ΔH를 어림하세요.

  1. 끊는 결합: N≡N 1개, H–H 3개 → 945 + 3 × 436 = 2253 kJ입니다.
  2. 만드는 결합: NH₃ 2개에 N–H 6개 → 6 × 391 = 2346 kJ입니다.
  3. ΔH ≈ 2253 − 2346입니다.
  4. = −93 kJ로 생성 엔탈피 값 −92.2 kJ와 가깝습니다.

답: 약 −93 kJ

문제 3

C–H 413, O=O 498, C=O 799, O–H 463 kJ/mol로 CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(g)의 ΔH를 어림하면 몇 kJ인가요?

문제 4

H₂(g) + Cl₂(g) → 2HCl(g)의 ΔH가 −184 kJ이고 H–H 436, H–Cl 431 kJ/mol일 때 Cl–Cl 결합 엔탈피는 몇 kJ/mol인가요?

결합 엔탈피의 쓰임과 한계

결합이 강할수록(결합 엔탈피가 클수록) 분자가 안정합니다. N≡N(945)이 매우 강해 질소가 잘 반응하지 않습니다.

C–C 348, C=C 614 kJ/mol처럼 같은 원자 사이라도 결합 차수가 클수록 결합 엔탈피가 큽니다.

액체나 고체가 있는 반응은 먼저 기체로 바꾸는 엔탈피(증발열 등)를 고려해야 합니다. 결합 엔탈피는 평균값이라 오차가 수 % 생길 수 있습니다.

문제 5

C=C 614, H–H 436, C–C 348, C–H 413 kJ/mol로 C₂H₄(g) + H₂(g) → C₂H₆(g)의 ΔH를 어림하면 몇 kJ인가요?

문제 6

H–H 436, O=O 498, O–H 463 kJ/mol로 2H₂(g) + O₂(g) → 2H₂O(g)의 ΔH를 어림하면 몇 kJ인가요?

문제 7

앞 문제에서 얻은 값을 H₂O(g) 1 mol당으로 나타내면 몇 kJ/mol인가요?

정리

결합 엔탈피(기체, 양수): 끊을 때 흡수, 만들 때 방출. ΔH ≈ Σ(끊는 결합) − Σ(만드는 결합).

결합 차수가 클수록 결합 엔탈피가 크고, 강한 결합은 분자를 안정하게 합니다.

평균값이라 어림값이며, 기체가 아닌 물질은 상태 변화 엔탈피를 함께 고려합니다. 정확한 값이 필요하면 생성 엔탈피를 씁니다.

문제 8

문제 9
