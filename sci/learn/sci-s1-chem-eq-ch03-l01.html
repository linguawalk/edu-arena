분압으로 쓰는 평형 상수

기체 반응은 농도 대신 각 기체의 분압(atm)으로 평형 상수를 쓸 수 있습니다. 이것을 압력 평형 상수 Kp라 하고, 농도로 쓴 것은 Kc라고 구분합니다.

N₂O₄ ⇌ 2NO₂이면 Kp = P_NO₂²/P_N₂O₄입니다. P_NO₂ = 0.4 atm, P_N₂O₄ = 0.8 atm이면 Kp = 0.16/0.8 = 0.2입니다.

분압은 몰 분율 × 전체 압력이므로, 기체의 몰수와 전체 압력을 알면 Kp를 구할 수 있습니다. 고체와 액체는 Kc처럼 Kp에도 넣지 않습니다.

문제 1

N₂O₄ ⇌ 2NO₂의 평형에서 P_NO₂ = 0.4 atm, P_N₂O₄ = 0.8 atm입니다. Kp는? 소수로 쓰세요.

문제 2

압력 평형 상수 Kp는 각 기체의 ＿＿＿으로 나타냅니다.

몰수에서 분압으로

평형에서 각 기체의 몰수와 전체 압력을 알면 분압 Pᵢ = (nᵢ/n_전체) × P_전체로 구합니다.

NO₂ 0.2몰과 N₂O₄ 0.8몰이 전체 압력 2 atm으로 평형을 이루면 P_NO₂ = 0.2 × 2 = 0.4 atm, P_N₂O₄ = 0.8 × 2 = 1.6 atm입니다.

Kp = 0.16/1.6 = 0.1입니다. 같은 몰수라도 전체 압력이 다르면 분압이 달라지므로 반드시 몰 분율과 전체 압력을 함께 씁니다.

예제

NO₂ 0.2몰과 N₂O₄ 0.8몰이 전체 압력 2 atm에서 평형을 이룹니다. Kp를 구하세요.

  1. 몰 분율은 NO₂ 0.2, N₂O₄ 0.8입니다.
  2. 분압은 P_NO₂ = 0.4 atm, P_N₂O₄ = 1.6 atm입니다.
  3. Kp = 0.4²/1.6 = 0.16/1.6입니다.
  4. = 0.1입니다.

답: 0.1

문제 4

H₂ + I₂ ⇌ 2HI의 평형에서 P_H₂ = P_I₂ = 0.2 atm, P_HI = 1.6 atm입니다. Kp는?

분압으로 처음-변화-평형 표 만들기

부피와 온도가 일정하면 분압은 몰수에 비례하므로, 분압을 몰수처럼 써서 처음-변화-평형 표를 만들 수 있습니다.

N₂O₄ ⇌ 2NO₂(Kp = 2)에서 처음 P_N₂O₄ = 1 atm이면, x만큼 해리할 때 평형에서 P_N₂O₄ = 1 − x, P_NO₂ = 2x입니다. (2x)²/(1 − x) = 2에서 2x² + x − 1 = 0, x = 0.5입니다.

평형에서 P_N₂O₄ = 0.5 atm, P_NO₂ = 1 atm이고 전체 압력은 1.5 atm입니다. 분자 수가 늘어나는 반응이라 전체 압력이 처음보다 커졌습니다.

문제 5

부피가 일정한 용기에서 N₂O₄ ⇌ 2NO₂(Kp = 2)가 처음 P_N₂O₄ = 1 atm에서 평형에 이르렀습니다. 전체 압력은 몇 atm인가요? 소수로 쓰세요.

문제 6

앞 문제에서 평형의 P_NO₂는 몇 atm인가요?

반응물과 생성물이 모두 있을 때

처음에 반응물과 생성물이 모두 있으면 먼저 Qp와 Kp를 비교해 방향을 정합니다.

A(g) ⇌ B(g)(Kp = 3)에서 P_A = P_B = 1 atm로 시작하면 Qp = 1 < 3이므로 정반응 쪽입니다. (1 + x)/(1 − x) = 3에서 x = 0.5이고 P_B = 1.5 atm입니다.

농도로 풀 때와 방법이 완전히 같습니다. 단위만 M 대신 atm을 씁니다.

문제 7

정리

기체 반응은 분압으로 쓴 압력 평형 상수 Kp를 쓸 수 있습니다. 고체와 액체는 넣지 않습니다.

분압은 몰 분율 × 전체 압력입니다. 몰수와 전체 압력에서 분압을 구해 Kp를 계산합니다.

부피와 온도가 일정하면 분압을 몰수처럼 써서 처음-변화-평형 표를 만듭니다. 반응물과 생성물이 모두 있으면 Qp로 방향을 먼저 정합니다.
