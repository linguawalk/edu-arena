반응은 여러 단계로 일어난다

전체 반응식은 여러 기본 반응(실제로 한 번에 일어나는 분자 충돌)의 합입니다. 기본 반응에서는 계수가 곧 차수이며, 참여하는 분자 수를 분자도라 합니다(단분자, 이분자, 드물게 삼분자).

가장 느린 단계(속도 결정 단계)가 전체 속도를 정합니다. 그 단계의 속도 법칙이 전체 속도 법칙이 됩니다.

예: NO₂ + CO → NO + CO₂는 ① 2NO₂ → NO₃ + NO(느림) ② NO₃ + CO → NO₂ + CO₂(빠름)로 일어나 속도 = k[NO₂]²이고 CO에 대해 0차입니다.

문제 1

앞의 NO₂ + CO 반응(속도 = k[NO₂]²)에서 [CO]를 2배로 하면 속도는 몇 배가 되나요?

문제 2

여러 단계 반응에서 가장 느린 단계를 ＿＿＿ 단계라 합니다.

빠른 평형이 앞에 있을 때

2NO + O₂ → 2NO₂의 메커니즘: ① 2NO ⇌ N₂O₂(빠른 평형, K₁) ② N₂O₂ + O₂ → 2NO₂(느림, k₂).

느린 단계의 속도는 k₂[N₂O₂][O₂]이지만 중간체 N₂O₂의 농도는 속도 법칙에 쓸 수 없습니다. 빠른 평형에서 [N₂O₂] = K₁[NO]²이므로 속도 = k₂K₁[NO]²[O₂]입니다.

그래서 관찰되는 속도 법칙은 NO에 2차, O₂에 1차, 전체 3차입니다. 삼분자 충돌 없이도 3차가 나올 수 있습니다.

예제

메커니즘 ① 2NO ⇌ N₂O₂(빠름) ② N₂O₂ + H₂ → N₂O + H₂O(느림) ③ N₂O + H₂ → N₂ + H₂O(빠름)의 전체 반응식과 속도 법칙을 구하세요.

  1. 세 단계를 더하면 N₂O₂와 N₂O가 지워져 2NO + 2H₂ → N₂ + 2H₂O입니다.
  2. 느린 단계 ②의 속도는 k₂[N₂O₂][H₂]입니다.
  3. 빠른 평형 ①에서 [N₂O₂] = K₁[NO]²입니다.
  4. 속도 = k₂K₁[NO]²[H₂]로 전체 3차입니다.

답: 속도 = k[NO]²[H₂]

문제 3

앞 예제 메커니즘의 중간체는 몇 가지인가요?

문제 4

2NO + O₂ → 2NO₂(속도 = k[NO]²[O₂])의 전체 차수는?

메커니즘의 검증

제안한 메커니즘은 ① 단계를 더하면 전체 반응식이 되고 ② 유도한 속도 법칙이 실험과 맞고 ③ 각 단계가 그럴듯한(대개 이분자 이하) 기본 반응이어야 합니다.

실험과 맞는다고 메커니즘이 증명되는 것은 아닙니다. 같은 속도 법칙을 주는 다른 메커니즘이 있을 수 있어 중간체 검출 등 다른 증거로 확인합니다.

촉매는 앞 단계에서 쓰였다가 뒤 단계에서 다시 생기는 물질로, 중간체와 반대입니다.

문제 7

O₃ 분해 메커니즘 ① O₃ ⇌ O₂ + O(빠름) ② O + O₃ → 2O₂(느림)의 속도 법칙은 속도 = k[O₃]^a[O₂]^b입니다. b는?

정리

전체 반응은 기본 반응의 합이고, 기본 반응에서는 계수가 차수입니다. 속도 결정 단계가 전체 속도 법칙을 정합니다.

속도 결정 단계에 중간체가 있으면 앞의 빠른 평형으로 반응물 농도로 바꿉니다.

메커니즘은 단계의 합 = 전체 반응식, 속도 법칙 일치, 그럴듯한 기본 반응이라는 조건을 만족해야 합니다.
