지금 어느 쪽으로 가는가

평형이 아닌 임의의 순간에 평형 상수식과 같은 꼴로 계산한 값을 반응 지수 Q라고 합니다. Q와 K를 비교하면 반응이 어느 방향으로 진행할지 알 수 있습니다.

Q < K이면 생성물이 부족하므로 정반응 쪽으로, Q > K이면 생성물이 너무 많으므로 역반응 쪽으로 진행합니다. Q = K이면 이미 평형입니다.

H₂ + I₂ ⇌ 2HI(K = 64)에서 [H₂] = [I₂] = 0.5 M, [HI] = 1 M이면 Q = 1/0.25 = 4 < 64이므로 HI가 더 생기는 쪽으로 갑니다.

문제 1

H₂ + I₂ ⇌ 2HI에서 [H₂] = [I₂] = 0.5 M, [HI] = 1 M인 순간의 반응 지수 Q는?

문제 2

Q < K이면 반응은 ＿＿＿ 쪽으로 진행합니다.

예제

N₂O₄ ⇌ 2NO₂(K = 0.2)에서 [N₂O₄] = 0.5 M, [NO₂] = 0.5 M일 때 반응의 진행 방향을 정하세요.

  1. Q = [NO₂]²/[N₂O₄] = 0.25/0.5 = 0.5입니다.
  2. K = 0.2입니다.
  3. Q > K이므로 생성물이 너무 많습니다.
  4. 역반응 쪽(NO₂가 N₂O₄로 바뀌는 쪽)으로 진행합니다.

답: 역반응 쪽

문제 3

앞 예제에서 반응 지수 Q는? 소수로 쓰세요.

문제 4

A ⇌ 2B에서 [A] = 2 M, [B] = 4 M인 순간의 반응 지수 Q는?

Q로 방향을 정한 뒤 평형 계산

처음에 반응물과 생성물이 모두 있으면 먼저 Q와 K를 비교해 방향을 정하고, 그 방향으로 x만큼 변한다고 놓습니다.

A ⇌ B(K = 3)에서 [A] = [B] = 1 M로 시작하면 Q = 1 < 3이므로 정반응 쪽입니다. (1 + x)/(1 − x) = 3에서 x = 0.5이고 [B] = 1.5 M, [A] = 0.5 M입니다.

방향을 반대로 잡아도 x가 음수로 나와 같은 답이 되지만, Q로 방향을 먼저 정하면 실수가 줄어듭니다.

문제 5

A ⇌ B(K = 3)에서 [A] = [B] = 1 M로 시작했습니다. 평형의 [B]는 몇 M인가요? 소수로 쓰세요.

평형 상수와 반응 속도

정반응과 역반응이 모두 한 단계로 일어나는 반응 A ⇌ B에서 정반응 속도는 k_f[A], 역반응 속도는 k_r[B]입니다.

평형에서는 두 속도가 같으므로 k_f[A] = k_r[B], 곧 K = [B]/[A] = k_f/k_r입니다. 평형 상수는 정반응과 역반응의 속도 상수의 비입니다.

그래서 정반응 속도 상수만 키우고 역반응을 그대로 두는 방법은 K를 바꾸지만, 촉매처럼 두 속도 상수를 같은 비율로 키우면 K는 변하지 않습니다.

문제 6

A ⇌ B(한 단계 반응)에서 정반응 속도 상수가 6, 역반응 속도 상수가 2입니다. K는?

문제 7

A ⇌ B(한 단계 반응)에서 k_f = 0.4, k_r = 0.1이면 K는?

정리

반응 지수 Q는 임의의 순간에 평형 상수식과 같은 꼴로 계산한 값입니다.

Q < K이면 정반응 쪽, Q > K이면 역반응 쪽으로 진행하고, Q = K이면 평형입니다. 반응물과 생성물이 모두 있으면 Q로 방향을 먼저 정합니다.

한 단계 반응에서 K = k_f/k_r입니다. 두 속도 상수가 같은 비율로 변하면 K는 그대로입니다.
