한 단계씩 열을 따라가기

순환 과정은 단계마다 W, ΔU, Q를 표로 정리하면 실수가 줄어듭니다. 그림의 단원자 기체 순환을 예로 들면 다음과 같습니다(1 kPa·L = 1 J).

A→B(등적): W = 0, Q = ΔU = (3/2)VΔP = 1.5 × 1 × 100 = 150 J. B→C(등압): W = 200 × 2 = 400 J, ΔU = 1.5 × 400 = 600 J, Q = 1000 J.

C→D(등적): Q = 1.5 × 3 × (−100) = −450 J. D→A(등압): W = −200 J, ΔU = −300 J, Q = −500 J. 합하면 W_net = 200 J, ΔU 합 = 0입니다.

문제 1

그림의 순환에서 기체가 열을 받는 단계(A→B, B→C)에서 받은 열의 합 Q_in은 몇 J인가요?

문제 2

순환 과정 열기관의 효율은 한 번 돌 때의 알짜 일을 ＿＿＿ 열 Q_in으로 나눈 값입니다.

효율 계산

그림의 순환은 Q_in = 1150 J, W_net = 200 J이므로 효율 e = 200/1150 = 4/23 ≈ 17%입니다. 버린 열은 Q_out = 450 + 500 = 950 J이고 Q_in − Q_out = W_net입니다.

효율을 계산할 때 열을 '받는' 단계만 Q_in에 넣어야 합니다. 열을 내보내는 단계를 빼서 알짜 열로 나누면 안 됩니다.

순환 방향을 바꾸면(시계 반대) 외부가 일을 해 주고 낮은 쪽에서 열을 뽑아 높은 쪽으로 보내는 냉동기가 됩니다.

예제

그림의 순환에서 기체가 내보낸 열의 합과 효율을 구하세요.

  1. C→D(등적 냉각)에서 Q = (3/2) × 3 × (−100) = −450 J입니다.
  2. D→A(등압 압축)에서 Q = (5/2) × 100 × (−2) = −500 J입니다.
  3. Q_out = 950 J이고 Q_in − Q_out = 1150 − 950 = 200 J = W_net입니다.
  4. 효율 e = 200/1150 = 4/23 ≈ 0.17입니다.

답: 950 J, 4/23

문제 4

그림의 순환에서 B→C 단계의 내부 에너지 변화는 몇 J인가요?

다른 모양의 순환

삼각형이나 등온 구간이 들어간 순환도 같은 방식으로 풉니다. 등온 구간은 ΔU = 0, Q = W = nRT ln(V₂/V₁)을 씁니다.

온도를 알면 단계별 ΔU = nC_VΔT를 바로 쓸 수 있고, PV를 알면 단원자 기체는 (3/2)Δ(PV)입니다.

마지막에 ΔU의 합이 0, Q의 합이 W_net인지 확인하면 계산 실수를 잡을 수 있습니다.

문제 7

그림의 순환을 반대 방향(A→D→C→B→A)으로 돌리면 외부가 기체에 해 주어야 하는 알짜 일은 몇 J인가요?

정리

순환 과정은 단계마다 W, ΔU, Q를 표로 정리하고 ΔU 합 = 0, Q 합 = W_net으로 검산합니다.

효율 e = W_net/Q_in에서 Q_in은 열을 받는 단계의 합만 넣습니다. Q_in − Q_out = W_net입니다.

방향을 바꾸면 냉동기가 되어 외부가 W_net의 일을 해 줍니다.
