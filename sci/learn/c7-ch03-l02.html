포도당 쪼개기

세균부터 사람까지 거의 모든 생물은 포도당을 똑같은 방식으로 반으로 쪼개며 에너지를 얻기 시작합니다.

이 공통된 첫 단계가 해당 과정입니다.

문제 1

세포질에서 포도당 1분자가 피루브산 2분자로 분해되는 과정을 ＿＿＿ 과정이라고 합니다.

해당 과정의 결과

해당 과정에서 탄소 6개인 포도당은 여러 단계를 거쳐 탄소 3개인 피루브산 2분자가 됩니다.

처음에 ATP 2분자를 써서 포도당을 활성화하고(투자 단계), 뒤에 ATP 4분자와 NADH 2분자를 만듭니다(회수 단계). 따라서 순수하게 얻는 ATP는 2분자입니다.

해당 과정의 ATP는 기질 분자의 인산을 ADP에 직접 옮겨 만드는데, 이를 기질 수준 인산화라고 합니다. 산소가 필요 없습니다.

문제 2

해당 과정에서 포도당 1분자당 순수하게 얻는 ATP는 몇 분자일까요?

문제 3

해당 과정에서 포도당 1분자당 생성되는 NADH는 몇 분자일까요?

문제 4

해당 과정에는 산소가 ＿＿＿.

예제

해당 과정의 반응을 요약하면?

  1. 포도당(C₆) 1분자 → 피루브산(C₃) 2분자입니다.
  2. 2ATP를 쓰고 4ATP를 만들어 순 2ATP입니다.
  3. 2NAD⁺가 2NADH가 됩니다.

답: 포도당 → 2피루브산 + 2ATP(순) + 2NADH

문제 5

피루브산 1분자에는 탄소가 몇 개 있을까요?

투자 단계와 회수 단계

해당 과정의 앞부분에서는 ATP 2분자의 인산을 포도당에 붙여 불안정하게 만든 뒤 탄소 3개짜리 분자 둘로 쪼갭니다(에너지 투자).

뒷부분에서는 두 분자를 산화하며 NADH를 만들고, 기질 수준 인산화로 ATP를 4분자 만듭니다(에너지 회수).

해당 과정은 모든 생물에 공통으로 있는 매우 오래된 대사 경로입니다.

문제 6

기질 분자의 인산을 ADP에 직접 옮겨 ATP를 만드는 것을 기질 수준 ＿＿＿라고 합니다.

문제 7

해당 과정의 투자 단계에서 쓰는 ATP는 몇 분자일까요?

문제 8

해당 과정의 회수 단계에서 만드는 ATP는 모두 몇 분자일까요?

예제

해당 과정이 모든 생물에 공통으로 있다는 것은 무엇을 뜻할까요?

  1. 세균, 식물, 동물 모두 같은 효소로 해당 과정을 합니다.
  2. 해당 과정은 산소가 없어도 되고 막성 소기관도 필요 없습니다.
  3. 지구에 산소가 거의 없던 오래전 공통 조상 때부터 있던 경로라고 봅니다.

답: 매우 오래된 공통 경로

해당 과정 정리

장소: 세포질. 포도당(C₆) → 피루브산(C₃) 2분자. ATP: 2 투자, 4 생성, 순 2. NADH 2. 산소 불필요.

피루브산은 산소가 있으면 미토콘드리아로, 없으면 발효로 갑니다.

문제 9

해당 과정은 세균부터 사람까지 거의 모든 생물에 ＿＿＿으로 있습니다.

예제

포도당 3분자가 해당 과정을 거치면 순수하게 얻는 ATP는?

  1. 포도당 1분자당 순 2 ATP입니다.
  2. 3 × 2 = 6 ATP입니다.

답: 6 ATP
