포도당을 태워 ATP로

세포 호흡은 포도당 같은 유기물을 산화해 그 에너지로 ATP를 만드는 과정입니다. 전체 반응식은 C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O이고, 포도당 1몰당 약 2870 kJ의 에너지가 나옵니다.

호흡은 해당 과정(세포질), 피루브산 산화와 TCA 회로(미토콘드리아 기질), 산화적 인산화(미토콘드리아 내막)의 단계로 진행됩니다.

에너지는 한꺼번에 나오지 않고, 전자가 NAD⁺와 FAD에 실려 NADH와 FADH₂로 옮겨진 뒤 전자 전달계에서 차례로 쓰입니다.

문제 1

포도당 1분자가 완전히 산화될 때 소비되는 O₂는 몇 분자인가요?

문제 2

포도당 180 g이 완전히 산화되면 CO₂는 몇 g 생기나요? (C 12, O 16)

해당 과정

해당 과정은 세포질에서 포도당(탄소 6개) 1분자를 피루브산(탄소 3개) 2분자로 쪼개는 10단계 반응입니다. 산소가 필요 없습니다.

앞부분에서 ATP 2개를 써서 포도당을 활성화하고, 뒷부분에서 ATP 4개와 NADH 2개를 만듭니다. 그래서 순수하게 ATP 2개와 NADH 2개가 남습니다.

이때 ATP는 기질 수준 인산화로, 인산기를 가진 유기물이 ADP에 인산기를 직접 넘겨 만들어집니다.

문제 3

해당 과정에서 포도당 1분자는 ＿＿＿ 2분자로 쪼개집니다.

예제

포도당 3분자가 해당 과정을 거칠 때 순수하게 생기는 ATP와 NADH의 수를 구하세요.

  1. 포도당 1분자당 ATP 4개가 생기고 2개가 쓰여 순수하게 2개입니다.
  2. 포도당 1분자당 NADH는 2개입니다.
  3. 3분자이면 ATP 3 × 2 = 6개입니다.
  4. NADH는 3 × 2 = 6개입니다.

답: ATP 6개, NADH 6개

문제 4

앞 예제에서 순수하게 생기는 ATP는 몇 개인가요?

산소가 없으면: 발효

산소가 없으면 전자 전달계가 멈춰 NADH가 NAD⁺로 돌아가지 못합니다. NAD⁺가 바닥나면 해당 과정도 멈추므로, 세포는 피루브산에 전자를 넘겨 NAD⁺를 재생합니다. 이것이 발효입니다.

젖산 발효(근육, 젖산균)는 피루브산을 젖산으로, 알코올 발효(효모)는 피루브산을 에탄올과 CO₂로 바꿉니다. 포도당 1분자에서 에탄올 2분자와 CO₂ 2분자가 생깁니다.

발효는 해당 과정의 ATP 2개만 얻으므로, 같은 양의 ATP를 얻으려면 유산소 호흡보다 훨씬 많은 포도당을 써야 합니다.

문제 5

효모가 포도당 5분자를 알코올 발효하면 CO₂는 몇 분자 생기나요?

호흡률

호흡할 때 내놓은 CO₂의 부피를 소비한 O₂의 부피로 나눈 값을 호흡률(RQ)이라 합니다. 무엇을 호흡 기질로 쓰는지 알려 줍니다.

탄수화물은 C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O이므로 RQ = 6/6 = 1입니다. 지방은 산소가 적어 O₂가 더 필요하므로 RQ가 약 0.7, 단백질은 약 0.8입니다.

트라이팔미틴(C₅₁H₉₈O₆)은 2C₅₁H₉₈O₆ + 145O₂ → 102CO₂ + 98H₂O로 RQ = 102/145 ≈ 0.70입니다.

문제 6

어떤 생물이 O₂ 100 mL를 소비하고 CO₂ 70 mL를 내놓았습니다. 호흡률은? 소수로 쓰세요.

문제 7

포도당 4분자가 해당 과정을 거칠 때 '만들어지는' ATP(쓰인 것을 빼기 전)는 모두 몇 개인가요?

정리

세포 호흡은 C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O로, 해당 과정, 피루브산 산화와 TCA 회로, 산화적 인산화를 거칩니다.

해당 과정은 세포질에서 포도당 1분자를 피루브산 2분자로 쪼개며 순수하게 ATP 2개와 NADH 2개를 만듭니다.

산소가 없으면 발효로 NAD⁺를 재생하며 ATP는 2개만 얻습니다. 호흡률은 탄수화물 1, 지방 약 0.7, 단백질 약 0.8입니다.

문제 8

포도당 1분자를 유산소 호흡하면 ATP를 약 32개, 젖산 발효하면 2개 얻습니다. 같은 양의 ATP를 얻으려면 발효는 유산소 호흡보다 포도당이 몇 배 필요한가요?

문제 9

젖산 발효로 포도당 1분자에서 생기는 젖산(C₃H₆O₃)은 몇 분자인가요?

문제 10

산소가 없을 때 세포가 발효를 하는 이유를 NAD⁺의 재생과 연결해 설명하세요.

문제 11

탄수화물의 호흡률이 1이고 지방의 호흡률이 1보다 작은 이유를 설명하세요.
