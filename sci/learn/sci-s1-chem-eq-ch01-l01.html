동적 평형과 평형 상수

멈춘 것처럼 보이는 반응

정반응과 역반응이 모두 일어나는 가역 반응에서는 시간이 지나면 두 반응의 속도가 같아져 각 물질의 농도가 더 이상 변하지 않습니다. 이 상태를 화학 평형이라고 합니다(그림).

평형은 반응이 멈춘 것이 아니라 정반응과 역반응이 같은 속도로 계속 일어나는 동적 상태입니다. 그래서 동적 평형이라고 부릅니다.

aA + bB ⇌ cC + dD의 평형에서 K = [C]ᶜ[D]ᵈ/([A]ᵃ[B]ᵇ)는 온도가 일정하면 처음 농도와 관계없이 항상 같은 값입니다. 이 값을 평형 상수라고 합니다.

문제 1

H₂ + I₂ ⇌ 2HI의 평형에서 [H₂] = [I₂] = 0.1 M, [HI] = 0.8 M입니다. 평형 상수 K는?

문제 2

순수한 고체와 액체의 농도는 평형 상수식에 ＿＿＿.

평형 상수식 쓰기

평형 상수식은 '생성물 농도의 곱 ÷ 반응물 농도의 곱'이고, 각 농도에 반응식의 계수를 지수로 붙입니다.

N₂ + 3H₂ ⇌ 2NH₃이면 K = [NH₃]²/([N₂][H₂]³)입니다. CaCO₃(s) ⇌ CaO(s) + CO₂(g)이면 고체를 빼고 K = [CO₂]입니다.

물이 용매로 쓰이는 수용액 반응에서는 물의 농도도 거의 변하지 않으므로 빼고 씁니다. 평형 상수에는 보통 단위를 붙이지 않습니다.

예제

N₂ + 3H₂ ⇌ 2NH₃의 평형에서 [N₂] = 0.5 M, [H₂] = 1 M, [NH₃] = 0.5 M입니다. K를 구하세요.

  1. K = [NH₃]²/([N₂][H₂]³)입니다.
  2. 분자: 0.5² = 0.25입니다.
  3. 분모: 0.5 × 1³ = 0.5입니다.
  4. K = 0.25/0.5 = 0.5입니다.

답: 0.5

문제 3

N₂ + 3H₂ ⇌ 2NH₃의 평형에서 [N₂] = 0.5 M, [H₂] = 1 M, [NH₃] = 0.5 M일 때 K는? 소수로 쓰세요.

문제 4

CaCO₃(s) ⇌ CaO(s) + CO₂(g)의 평형에서 [CO₂] = 0.02 M입니다. K는? 소수로 쓰세요.

반응식을 바꾸면 K도 바뀐다

반응식을 거꾸로 쓰면 평형 상수는 역수가 됩니다: K' = 1/K. H₂ + I₂ ⇌ 2HI의 K가 64이면 2HI ⇌ H₂ + I₂의 K는 1/64입니다.

반응식 전체에 n을 곱하면 K는 n제곱이 됩니다. 계수를 절반으로 하면 K는 제곱근입니다: (1/2)H₂ + (1/2)I₂ ⇌ HI의 K는 √64 = 8입니다.

두 반응식을 더하면 평형 상수는 곱이 됩니다. A ⇌ B(K₁)와 B ⇌ C(K₂)를 더한 A ⇌ C의 K는 K₁K₂입니다.

H₂ + I₂ ⇌ 2HI의 K가 64일 때 2HI ⇌ H₂ + I₂의 K를 분수로 쓰세요.

H₂ + I₂ ⇌ 2HI의 K가 64일 때 (1/2)H₂ + (1/2)I₂ ⇌ HI의 K는?

문제 7

A ⇌ B의 K₁ = 2, B ⇌ C의 K₂ = 3일 때 A ⇌ C의 K는?

K의 크기가 말해 주는 것

K가 아주 크면(예: 10³ 이상) 평형에서 생성물이 대부분이고, 반응이 거의 끝까지 진행합니다. K가 아주 작으면(예: 10⁻³ 이하) 반응물이 대부분이고 거의 진행하지 않습니다.

K가 1 근처이면 반응물과 생성물이 비슷한 양으로 함께 있습니다.

K는 '얼마나 많이 진행하는가'를 알려 줄 뿐, '얼마나 빨리 진행하는가'는 알려 주지 않습니다. K가 커도 반응이 매우 느릴 수 있습니다.

정리

화학 평형은 정반응과 역반응의 속도가 같아 농도가 일정한 동적 상태입니다.

K = 생성물 농도의 곱/반응물 농도의 곱이고, 계수를 지수로 씁니다. 순수한 고체·액체와 용매인 물은 빼고 씁니다.

반응식을 거꾸로 쓰면 1/K, n배하면 Kⁿ, 두 식을 더하면 K₁K₂입니다. K가 크면 생성물 쪽, 작으면 반응물 쪽으로 치우칩니다.

문제 9
