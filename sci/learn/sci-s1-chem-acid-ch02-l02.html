약산의 이온화 평형

약산 HA는 물에서 일부만 이온화해 HA ⇌ H⁺ + A⁻의 평형을 이룹니다. 이 평형 상수 Ka = [H⁺][A⁻]/[HA]를 산 이온화 상수라고 합니다.

Ka가 클수록 강한 산입니다. 아세트산의 Ka는 약 1.8 × 10⁻⁵이고, 이 챕터에서는 계산하기 쉽게 Ka = 1 × 10⁻⁵인 약산을 자주 씁니다.

pKa = −log Ka로 나타내기도 합니다. Ka = 10⁻⁵이면 pKa = 5이고, pKa가 작을수록 강한 산입니다.

문제 2

pKa가 작을수록 ＿＿＿ 산입니다.

[H⁺] ≈ √(Ka·C)

농도 C인 약산이 x만큼 이온화하면 [H⁺] = [A⁻] = x, [HA] = C − x이므로 Ka = x²/(C − x)입니다.

약산은 조금만 이온화하므로 x ≪ C이면 C − x ≈ C로 근사해 x² = Ka·C, [H⁺] ≈ √(Ka·C)입니다.

0.1 M, Ka = 10⁻⁵인 약산이면 [H⁺] = √(10⁻⁶) = 10⁻³ M, pH = 3입니다. x = 10⁻³은 0.1의 1%이므로 근사가 잘 맞습니다.

예제

Ka = 1 × 10⁻⁵인 약산 HA의 0.1 M 용액의 pH와 이온화도를 구하세요.

  1. [H⁺] ≈ √(Ka·C) = √(10⁻⁵ × 0.1) = √(10⁻⁶)입니다.
  2. = 10⁻³ M이므로 pH = 3입니다.
  3. 이온화도 α = x/C = 10⁻³/0.1 = 0.01입니다.
  4. 곧 1%만 이온화했습니다.

답: pH 3, 1%

문제 5

0.1 M 약산 HA 용액의 pH가 3입니다. Ka = 1 × 10ⁿ일 때 n은? (x ≪ C로 근사)

묽힐수록 이온화도가 커진다

이온화도 α = x/C ≈ √(Ka·C)/C = √(Ka/C)입니다. 약산을 묽히면 C가 작아지므로 이온화도는 커집니다.

Ka = 10⁻⁵인 약산을 0.1 M에서 0.001 M로 100배 묽히면 α는 √100 = 10배 커져 1%에서 10%가 됩니다.

르샤틀리에 원리로도 이해할 수 있습니다. 물을 더하면 입자 수가 많은 이온 쪽으로 평형이 이동합니다. 다만 [H⁺] 자체는 작아지므로 pH는 커집니다.

문제 6

Ka = 1 × 10⁻⁵인 약산을 0.1 M에서 0.001 M로 묽혔습니다. 이온화도는 몇 배가 되나요?

근사가 안 될 때

Ka가 크거나 C가 작아서 x가 C의 5%를 넘으면 근사하지 않고 Ka = x²/(C − x)의 이차방정식을 풉니다.

Ka = 0.1인 약산의 0.2 M 용액이면 x²/(0.2 − x) = 0.1에서 x² + 0.1x − 0.02 = 0, x = (−0.1 + √0.09)/2 = 0.1 M입니다.

근사했다면 √(0.02) ≈ 0.14 M로 크게 틀렸을 것입니다. 이온화도가 50%라서 x ≪ C가 성립하지 않습니다.

문제 7

Ka = 0.1인 약산 HA의 0.2 M 용액에서 [H⁺]는 몇 M인가요? (이차방정식을 푸세요) 소수로 쓰세요.

정리

약산 HA의 이온화 평형 상수 Ka = [H⁺][A⁻]/[HA]이고 pKa = −log Ka입니다. Ka가 클수록, pKa가 작을수록 강한 산입니다.

x ≪ C이면 [H⁺] ≈ √(Ka·C), 이온화도 α ≈ √(Ka/C)입니다. 묽힐수록 이온화도는 커집니다.

x가 C의 5%를 넘으면 근사하지 않고 이차방정식을 풉니다.
