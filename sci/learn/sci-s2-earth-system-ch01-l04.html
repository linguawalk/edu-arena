변화를 키우거나 줄이거나

지구계는 기권, 수권, 지권, 생물권, 빙권이 서로 영향을 주고받습니다. 어떤 변화가 다른 권역을 거쳐 처음 변화를 키우면 양성 되먹임, 줄이면 음성 되먹임입니다.

얼음–반사율 되먹임: 기온이 오르면 얼음이 녹아 어두운 땅과 바다가 드러나고, 햇빛을 덜 반사해 더 따뜻해집니다(양성).

수증기 되먹임: 기온이 오르면 대기가 수증기를 더 많이 머금고, 수증기도 온실 기체라 더 따뜻해집니다(양성). 구름은 햇빛 반사(냉각)와 온실 효과(가열)를 함께 해 효과가 복잡합니다.

문제 1

기온 상승 → 해빙 감소 → 반사율 감소 → 기온 상승으로 이어지는 되먹임은? ① 음성 되먹임 ② 되먹임 아님 ③ 양성 되먹임

문제 2

기온이 오를 때 지구가 내보내는 적외선 복사가 늘어 다시 식는 되먹임은 ＿＿＿ 되먹임입니다.

되먹임의 크기

되먹임이 없을 때의 온도 변화를 ΔT₀, 되먹임 이득을 f라 하면 실제 온도 변화는 ΔT = ΔT₀/(1 − f)입니다. f > 0이면 양성 되먹임으로 변화가 커지고, f < 0이면 음성 되먹임으로 작아집니다.

f = 0.5이면 변화가 2배, f = 0.6이면 2.5배가 됩니다. f가 1에 가까워지면 변화가 매우 커집니다(폭주).

이 식은 '처음 변화가 되먹임을 거쳐 f배만큼 더해지고, 그것이 다시 f배만큼…'을 모두 더한 등비급수 ΔT₀(1 + f + f² + …)입니다.

예제

되먹임이 없을 때 1.2 °C 오르는 변화에 수증기 되먹임(f = +0.4)과 구름·기타 되먹임(f = +0.1)이 함께 작용하면 실제 온도 변화를 구하세요(이득은 더해짐).

  1. 전체 이득 f = 0.4 + 0.1 = 0.5입니다.
  2. ΔT = ΔT₀/(1 − f) = 1.2/(1 − 0.5)입니다.
  3. = 1.2/0.5입니다.
  4. = 2.4 °C입니다.

답: 2.4 °C

되먹임이 없을 때 1.0 °C 오르는 변화에 되먹임 이득 f = 0.6이 작용하면 실제 온도 변화는 몇 °C인가요? (소수로)

문제 4

되먹임 이득 f = −0.25인 음성 되먹임에서 ΔT₀ = 2 °C이면 실제 온도 변화는 몇 °C인가요? (소수로)

권역 사이의 상호작용

화산 폭발(지권)은 성층권에 황산염 에어로졸을 올려(기권) 햇빛을 반사하고 1~2년 동안 지구를 식힙니다. 1991년 피나투보 화산 뒤 지구 평균 기온이 약 0.5 °C 내려갔습니다.

영구 동토층(빙권)이 녹으면 갇혀 있던 유기물이 분해되어 CO₂와 메테인(기권)이 나와 더 따뜻해집니다(양성 되먹임).

식물 플랑크톤(생물권)은 바다(수권)에서 CO₂를 흡수하고, 죽어서 가라앉으며 탄소를 깊은 바다로 옮깁니다(생물 펌프).

문제 5

영구 동토층이 녹아 메테인이 나오고 기온이 더 오르는 과정은? ① 양성 되먹임 ② 음성 되먹임 ③ 되먹임 아님

문제 6

되먹임 이득 f에서 온도 변화가 되먹임이 없을 때의 4배가 되려면 f는? (소수로)

문제 7

대규모 화산 폭발 직후 1~2년 동안 지구 평균 기온은? ① 올라간다 ② 내려간다 ③ 변화 없다

정리

지구계 = 기권·수권·지권·생물권·빙권의 상호작용. 양성 되먹임(얼음–반사율, 수증기, 동토층 메테인)은 변화를 키우고 음성 되먹임(복사 증가, 풍화)은 줄입니다.

ΔT = ΔT₀/(1 − f) = ΔT₀(1 + f + f² + …). f > 0 증폭, f < 0 감쇠.

화산 에어로졸(냉각), 생물 펌프(탄소를 깊은 바다로) 등 권역 사이의 상호작용이 기후를 조절합니다.
