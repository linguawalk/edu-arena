압력과 부피 변화

기체 분자 수가 적은 쪽으로

기체 반응의 평형에서 부피를 줄여(압축해) 압력을 높이면, 계는 압력을 줄이는 쪽, 곧 기체 분자 수가 적은 쪽으로 이동합니다.

N₂O₄ ⇌ 2NO₂는 오른쪽 기체가 더 많으므로 압축하면 왼쪽(N₂O₄)으로, N₂ + 3H₂ ⇌ 2NH₃는 오른쪽이 적으므로 압축하면 오른쪽(NH₃)으로 이동합니다.

양쪽 기체 분자 수가 같으면(H₂ + I₂ ⇌ 2HI) 압력을 바꾸어도 평형이 이동하지 않습니다. 이동 여부는 기체의 계수 변화 Δn으로 판단합니다.

문제 1

N₂O₄ ⇌ 2NO₂의 평형에서 부피를 절반으로 줄이면 그 순간 반응 지수 Q는 몇 배가 되나요?

문제 2

기체 반응의 평형에서 압력을 높이면 기체 분자 수가 ＿＿＿ 쪽으로 이동합니다.

예제

N₂O₄ ⇌ 2NO₂(K = 0.2)의 평형([N₂O₄] = 0.8 M, [NO₂] = 0.4 M)에서 부피를 절반으로 줄인 직후의 Q와 이동 방향을 구하세요.

  1. 부피가 절반이면 [N₂O₄] = 1.6 M, [NO₂] = 0.8 M가 됩니다.
  2. Q = 0.8²/1.6 = 0.64/1.6 = 0.4입니다.
  3. Q = 0.4 > K = 0.2입니다.
  4. 따라서 역반응(N₂O₄) 쪽으로 이동합니다.

답: Q = 0.4, 역반응 쪽

문제 4

H₂ + I₂ ⇌ 2HI의 평형에서 부피를 절반으로 줄인 직후 Q/K의 값은?

Δn으로 Q의 변화 계산하기

기체의 계수 변화 Δn = (생성물 기체 계수 합) − (반응물 기체 계수 합)입니다. 부피를 1/k로 줄이면 모든 농도가 k배가 되어 Q는 k^Δn배가 됩니다.

N₂ + 3H₂ ⇌ 2NH₃는 Δn = 2 − 4 = −2이므로 부피를 절반(k = 2)으로 하면 Q는 2⁻² = 1/4배가 되어 Q < K, 정반응 쪽으로 이동합니다.

Δn > 0이면 압축할 때 Q가 커져 역반응 쪽, Δn < 0이면 Q가 작아져 정반응 쪽입니다. 르샤틀리에 원리의 결론과 같습니다.

문제 6

2SO₂ + O₂ ⇌ 2SO₃의 평형에서 부피를 절반으로 줄인 직후 Q는 몇 배가 되나요? 분수로 쓰세요.

반응하지 않는 기체를 넣으면

부피를 고정한 채 아르곤 같은 반응하지 않는 기체를 넣으면 전체 압력은 높아지지만, 각 반응 기체의 농도(분압)는 변하지 않습니다. 그래서 Q가 그대로이고 평형이 이동하지 않습니다.

반대로 전체 압력을 일정하게 유지하며 넣으면 부피가 커지므로 각 기체의 농도가 줄어듭니다. 이것은 부피를 늘린 것과 같아 기체 분자 수가 많은 쪽으로 이동합니다.

'압력이 높아졌다'는 말만 보고 판단하지 말고, 반응에 참여하는 기체의 농도가 실제로 변했는지를 보세요.

문제 7

부피를 고정한 평형 용기에 아르곤을 넣어 전체 압력을 2배로 높였습니다. 그 순간 Q는 몇 배가 되나요?

정리

압축(부피 감소, 압력 증가)하면 기체 분자 수가 적은 쪽으로, 팽창하면 많은 쪽으로 이동합니다. Δn = 0이면 이동하지 않습니다.

부피를 1/k로 하면 Q는 k^Δn배가 됩니다. 이것과 K를 비교해 방향을 정할 수 있습니다.

부피가 일정할 때 반응하지 않는 기체를 넣으면 평형이 이동하지 않습니다. 압력이 일정할 때 넣으면 부피가 커진 것과 같습니다.
