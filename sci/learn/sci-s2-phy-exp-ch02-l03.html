기울기에도 불확도가 있다

오차 막대가 있는 그래프에서는 모든 오차 막대를 지나는 가장 가파른 직선과 가장 완만한 직선을 그립니다. 기울기가 b_max, b_min이면 b = (b_max + b_min)/2, δb = (b_max − b_min)/2로 어림합니다.

최소제곱에서는 점들의 세로 흩어짐이 σ_y일 때 기울기의 불확도가 σ_b = σ_y/√Σ(x − x̄)²입니다. x를 넓은 범위에서 재면 Σ(x − x̄)²이 커져 기울기가 정확해집니다.

그림의 진자 자료에서 기울기가 4.00 ± 0.08 s²/m이면 g = 4π²/b의 상대 불확도도 2%라 g = 9.87 ± 0.20 m/s²입니다.

문제 1

그림의 기울기가 4.00 ± 0.08 s²/m일 때 g의 불확도는 몇 m/s²인가요? (소수 둘째 자리까지)

문제 2

x 값을 넓은 범위에서 측정할수록 맞춘 직선의 기울기 불확도는 ＿＿＿집니다.

절편이 알려 주는 것

이론상 원점을 지나야 하는 직선의 절편이 0이 아니면 계통 오차를 의심합니다. 그림의 T²–L 직선은 절편이 0.08 s²입니다.

진자 길이를 매번 c만큼 짧게 쟀다면(예: 줄 길이만 재고 추의 반지름을 빠뜨림) 참 길이는 L + c이고 T² = (4π²/g)(L + c)이므로 절편 = 기울기 × c입니다.

0.08 = 4.0 × c에서 c = 0.02 m, 곧 길이를 2 cm씩 짧게 잰 것입니다. 기울기로 구한 g는 이 계통 오차의 영향을 받지 않습니다.

예제

최대 기울기 2.2, 최소 기울기 1.8인 두 직선이 모든 오차 막대를 지납니다. 기울기와 불확도를 구하세요.

  1. 기울기의 어림값은 두 기울기의 평균입니다.
  2. (2.2 + 1.8)/2 = 2.0입니다.
  3. 불확도는 두 기울기 차이의 절반입니다.
  4. (2.2 − 1.8)/2 = 0.2이므로 2.0 ± 0.2입니다.

답: 2.0 ± 0.2

문제 3

그림의 진자 자료에서 길이를 매번 몇 cm씩 짧게 잰 것인가요?

문제 4

x = 1, 2, 3, 4, 5인 자료에서 각 y의 불확도가 0.1일 때 최소제곱 기울기의 불확도는? (소수 셋째 자리까지)

변수를 바꾸면 불확도도 바뀐다

선형화로 y 대신 ln y를 그리면 오차 막대도 바꿔야 합니다. δ(ln y) = δy/y이므로 y = 50 ± 2이면 ln y의 불확도는 0.04입니다.

y² 축이면 δ(y²) = 2y δy입니다. T = 2.00 ± 0.01 s이면 T² = 4.00 ± 0.04 s²입니다.

변수를 바꾼 뒤 오차 막대 크기가 점마다 달라지면, 작은 오차 막대를 가진 점을 더 믿고 맞추는 가중 맞춤이 더 좋습니다.

문제 5

측정값 y = 50 ± 2를 ln y로 바꾸면 ln y의 불확도는? (소수로)

문제 6

주기 T = 2.00 ± 0.01 s일 때 T²의 불확도는 몇 s²인가요? (소수로)

문제 7

같은 자료 수와 흩어짐으로 x의 측정 범위(각 x − x̄)를 모두 3배로 넓히면 기울기 불확도는 몇 분의 1이 되나요?

정리

오차 막대 그래프: 가장 가파른·완만한 직선으로 b = (b_max + b_min)/2, δb = (b_max − b_min)/2. 최소제곱: σ_b = σ_y/√Σ(x − x̄)².

기울기에서 구한 양의 불확도는 오차 전파로 구합니다(g = 4π²/b이면 상대 불확도가 같음).

원점을 지나야 할 직선의 절편은 계통 오차를 알려 주며, 변수를 바꾸면 오차 막대도 δ(ln y) = δy/y, δ(y²) = 2yδy처럼 바꿉니다.
