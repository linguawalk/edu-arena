원소마다 다른 빛

네온사인은 붉은빛, 나트륨등은 주황빛을 냅니다. 불꽃 반응에서도 리튬은 빨간색, 구리는 청록색을 냅니다.

이 빛을 프리즘으로 나누면 연속된 무지개가 아니라 몇 개의 밝은 선만 보입니다. 원소마다 선의 위치가 달라 원소의 '지문'이라고 불립니다.

문제 1

기체 원소가 내는 빛을 분광기로 나누었을 때 나타나는 몇 개의 밝은 선을 ＿＿＿ 스펙트럼이라고 합니다.

스펙트럼의 종류

햇빛이나 백열등의 빛을 분광기로 나누면 모든 색이 끊김 없이 이어진 연속 스펙트럼이 나타납니다.

뜨거운 기체는 특정 파장의 빛만 내어 밝은 선들로 된 방출 스펙트럼(선 스펙트럼)을 만듭니다. 연속 스펙트럼의 빛이 차가운 기체를 지나면 기체가 특정 파장을 흡수해 검은 선이 나타나는 흡수 스펙트럼이 생깁니다.

같은 원소의 흡수선과 방출선은 파장이 같습니다. 별빛의 흡수선을 분석하면 별의 대기를 이루는 원소를 알 수 있습니다.

문제 2

햇빛이나 백열등의 빛처럼 모든 색이 끊김 없이 이어진 스펙트럼을 ＿＿＿ 스펙트럼이라고 합니다.

문제 3

별빛의 흡수 스펙트럼을 분석하면 별의 대기를 이루는 ＿＿＿를 알아낼 수 있습니다.

보어의 원자 모형과 에너지 준위

보어는 원자 속 전자가 아무 에너지나 가질 수 없고, 특정한 에너지 값(에너지 준위)만 가질 수 있다고 했습니다. 이처럼 물리량이 띄엄띄엄한 값만 가지는 것을 양자화라고 합니다.

전자가 높은 준위에서 낮은 준위로 옮겨 가면(전이) 두 준위의 에너지 차이만큼의 광자를 방출합니다: hf = E높은 − E낮은. 반대로 그만큼의 광자를 흡수하면 높은 준위로 올라갑니다.

수소 원자의 에너지 준위는 Eₙ = −13.6 ÷ n² eV입니다(n = 1, 2, 3, …). n = 1이 가장 낮은 바닥상태이고, E₁ = −13.6 eV, E₂ = −3.4 eV, E₃ = −1.51 eV, E₄ = −0.85 eV입니다.

문제 4

전자의 에너지처럼 물리량이 띄엄띄엄한 특정 값만 가지는 것을 ＿＿＿라고 합니다.

예제

수소 원자의 전자가 n = 2에서 n = 1로 전이할 때 방출하는 광자의 에너지는?

  1. E₂ = −3.4 eV, E₁ = −13.6 eV입니다.
  2. 광자 에너지 = E₂ − E₁ = −3.4 − (−13.6) = 10.2 eV입니다.
  3. 1240 ÷ 10.2 ≈ 122 nm이므로 자외선입니다.

답: 10.2 eV

문제 5

수소 원자의 전자가 n = 3(−1.51 eV)에서 n = 2(−3.4 eV)로 전이할 때 방출하는 광자의 에너지는 몇 eV일까요?

문제 6

바닥상태(n = 1, −13.6 eV)의 수소 원자에서 전자를 완전히 떼어 내려면(E = 0) 최소 몇 eV가 필요할까요?

문제 7

전자가 높은 에너지 준위에서 낮은 에너지 준위로 전이하면 빛을 ＿＿＿합니다.

수소의 스펙트럼 계열

수소의 방출선은 전자가 도착하는 준위에 따라 계열로 나뉩니다. n = 1로 내려오는 라이먼 계열은 자외선, n = 2로 내려오는 발머 계열은 주로 가시광선, n = 3으로 내려오는 파셴 계열은 적외선입니다.

준위 사이의 에너지 차이가 클수록 광자 에너지가 크고 파장이 짧습니다. 발머 계열의 빨간 선(656 nm)은 n = 3 → 2, 파란 선(486 nm)은 n = 4 → 2 전이에서 나옵니다.

예제

파장 656 nm인 수소의 빨간 방출선은 어떤 전이에서 나올까요? (hc = 1240 eV·nm, 곧 광자 에너지(eV) = 1240 ÷ 파장(nm))

  1. 광자 에너지 = 1240 ÷ 656 ≈ 1.89 eV입니다.
  2. E₃ − E₂ = −1.51 − (−3.4) = 1.89 eV로 일치합니다.
  3. 따라서 n = 3에서 n = 2로의 전이입니다(발머 계열).

답: n = 3 → n = 2

문제 8

수소 원자에서 n = 2로 전이하는 발머 계열의 빛은 주로 ＿＿＿ 영역에 있습니다.

문제 9

에너지 준위 차이가 2.48 eV인 전이에서 방출되는 빛의 파장은 몇 nm일까요? (hc = 1240 eV·nm, 곧 광자 에너지(eV) = 1240 ÷ 파장(nm))

문제 10

수소 원자에서 방출되는 광자의 에너지가 작은 전이부터 순서대로 배열하세요.

에너지 준위의 이용

네온사인과 형광등은 기체 원자의 전자를 들뜨게 한 뒤 내려오며 빛을 내게 합니다. 과학자들은 스펙트럼으로 물질의 성분을 분석하고, 먼 별과 은하를 이루는 원소를 알아냅니다.

원자의 에너지 준위가 불연속이라는 사실은 원자가 특정 색의 빛만 내는 이유이자, 레이저와 원자시계 같은 기술의 바탕입니다.

예제

수소 원자의 전자가 n = 4(−0.85 eV)에서 n = 2(−3.4 eV)로 전이할 때 방출하는 빛의 파장은? (hc = 1240 eV·nm, 곧 광자 에너지(eV) = 1240 ÷ 파장(nm))

  1. 광자 에너지 = −0.85 − (−3.4) = 2.55 eV입니다.
  2. λ = 1240 ÷ 2.55 ≈ 486 nm입니다.
  3. 파란빛입니다.

답: 약 486 nm

문제 12

문제 13

같은 원소의 흡수 스펙트럼의 검은 선과 방출 스펙트럼의 밝은 선의 파장은 서로 ＿＿＿.

문제 14

전이하는 두 준위의 에너지 차이가 클수록 방출되는 빛의 파장이 ＿＿＿습니다.

문제 15

광자 에너지가 3.1 eV인 빛의 파장은 몇 nm일까요? (hc = 1240 eV·nm, 곧 광자 에너지(eV) = 1240 ÷ 파장(nm))

문제 16

기체 원소가 연속 스펙트럼이 아니라 선 스펙트럼을 내는 까닭을 에너지 준위로 설명해 보세요.
