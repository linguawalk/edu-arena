미분을 거꾸로

v(t)를 알 때 x(t)를 구하는 것은 '미분하면 v가 되는 함수'를 찾는 일입니다. 이것을 원시함수 또는 부정적분이라 하고 ∫v dt로 씁니다.

∫tⁿ dt = tⁿ⁺¹/(n + 1) + C (n ≠ −1)입니다. 상수 C는 미분하면 사라지므로 어떤 값이든 될 수 있습니다.

C는 초기 조건으로 정합니다. v = 6t이고 x(0) = 2이면 x = 3t² + C에서 C = 2이므로 x = 3t² + 2입니다. 물리 문제에서 '처음 위치', '처음 속도'가 주어지는 이유입니다.

문제 1

v = 6t(m/s)이고 x(0) = 2 m인 물체의 t = 2 s에서의 위치는 몇 m인가요?

문제 2

적분 상수 C는 ＿＿＿ 조건으로 정합니다.

가속도에서 위치까지

가속도 a(t)가 주어지면 두 번 적분합니다. 처음 적분에서 v = ∫a dt + C₁, 두 번째 적분에서 x = ∫v dt + C₂가 나오고, 두 상수는 v(0) = v₀, x(0) = x₀으로 정합니다.

a가 상수이면 v = v₀ + at, x = x₀ + v₀t + (1/2)at²으로 등가속도 공식이 그대로 나옵니다.

운동 방정식 F = ma에서 힘을 알면 가속도를 알고, 적분하면 운동 전체를 알 수 있습니다. 이것이 뉴턴 역학의 기본 계산 방법입니다.

예제

a = 6t(m/s²), v(0) = 2 m/s, x(0) = 0인 물체의 t = 2 s에서의 위치를 구하세요.

  1. v = ∫6t dt = 3t² + C₁이고 v(0) = 2이므로 v = 3t² + 2입니다.
  2. x = ∫(3t² + 2) dt = t³ + 2t + C₂이고 x(0) = 0이므로 C₂ = 0입니다.
  3. x(2) = 8 + 4입니다.
  4. = 12 m입니다.

답: 12 m

문제 3

a = 12t²(m/s²)이고 v(0) = 0, x(0) = 0인 물체의 t = 2 s에서의 위치는 몇 m인가요?

문제 4

a = 2 m/s²(일정), v(0) = −4 m/s, x(0) = 0인 물체가 출발점으로 다시 돌아오는 시각은 몇 s인가요?

삼각함수의 적분

∫cos(ωt) dt = sin(ωt)/ω + C, ∫sin(ωt) dt = −cos(ωt)/ω + C입니다. 미분할 때 곱해졌던 ω로 이번에는 나눕니다.

v = Aω cos(ωt)이고 x(0) = 0이면 x = A sin(ωt)입니다. 진폭은 최대 속력을 ω로 나눈 값입니다.

적분 결과는 미분해서 원래 함수가 나오는지 확인하는 것이 가장 확실한 검산입니다. 계수 ω를 곱할지 나눌지 헷갈릴 때 특히 유용합니다.

문제 6

a = −8 sin(2t)(m/s²)이고 v(0) = 4 m/s인 물체의 최대 속력은 몇 m/s인가요?

힘이 시간에 따라 변할 때

질량 m인 물체에 시간에 따라 변하는 힘 F(t)가 작용하면 a(t) = F(t)/m이고, 이것을 적분해 속도와 위치를 구합니다.

예를 들어 2 kg인 물체에 F = 6t(N)가 작용하면 a = 3t, 정지에서 출발하면 v = 1.5t², x = 0.5t³입니다.

힘이 일정할 때만 등가속도 공식을 쓸 수 있다는 점에 주의하세요. 힘이 변하면 반드시 적분해야 합니다. 등가속도 공식을 습관처럼 쓰는 것이 경시 문제에서 가장 흔한 실수입니다.

문제 7

2 kg인 물체가 정지 상태에서 F = 6t(N)를 받습니다. t = 2 s에서의 속력은 몇 m/s인가요?

문제 8

앞 문제에서 t = 2 s까지 이동한 거리는 몇 m인가요?

정리

∫tⁿ dt = tⁿ⁺¹/(n + 1) + C이고, ∫cos(ωt) dt = sin(ωt)/ω + C입니다.

가속도에서 위치를 구하려면 두 번 적분하고, 두 적분 상수는 v₀, x₀으로 정합니다.

힘이 변하면 a = F(t)/m을 적분해야 합니다. 등가속도 공식은 힘이 일정할 때만 씁니다. 적분한 결과는 다시 미분해서 검산합니다.
