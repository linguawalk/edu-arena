연관된 개체끼리의 교배

재조합 빈도 r인 AB/ab끼리 교배하면 각 부모가 ab 생식세포를 (1 − r)/2 비율로 만듭니다. r = 0.2이면 0.4이므로 aabb 자손은 0.4 × 0.4 = 0.16입니다.

두 유전자 모두 완전 우성이면 A_B_의 비율은 0.5 + aabb 비율로 구할 수 있습니다. 0.5 + 0.16 = 0.66입니다. 이 관계는 연관 여부와 관계없이 성립합니다.

상반 배열 Ab/aB끼리라면 ab는 재조합형으로 r/2 = 0.1이므로 aabb는 0.01입니다. 같은 r이라도 배열에 따라 결과가 크게 다릅니다.

카이제곱 검정

실험 결과가 기대한 비율에서 벗어났을 때, 그 차이가 우연인지 아닌지를 판단하는 데 카이제곱(χ²) 검정을 씁니다. χ² = Σ(관찰값 − 기대값)²/기대값입니다.

자유도는 범주 수 − 1입니다. 자유도 1에서 χ² > 3.84이면, 자유도 3에서 χ² > 7.81이면 유의 수준 5%에서 기대 비율을 기각합니다.

검정 교배 자손 100마리가 60 : 40이었다면 기대 50 : 50에 대해 χ² = 10²/50 + 10²/50 = 4입니다. 3.84보다 크므로 1 : 1에서 벗어났다고 판단합니다.

문제 4

카이제곱 검정의 자유도는 범주 수에서 ＿＿＿을 뺀 값입니다.

예제

검정 교배 자손 100마리가 우성 60, 열성 40이었습니다. 1 : 1 가설에 대한 χ²를 구하세요.

  1. 기대값은 50, 50입니다.
  2. 우성: (60 − 50)²/50 = 2입니다.
  3. 열성: (40 − 50)²/50 = 2입니다.
  4. χ² = 2 + 2 = 4입니다.

답: 4

문제 6

양성 잡종 검정 교배 자손을 표현형 4종류로 나누어 카이제곱 검정을 할 때 자유도는?

9 : 3 : 3 : 1의 검정

AaBb 자가 교배 자손 160마리의 기대값은 90 : 30 : 30 : 10입니다. 관찰값이 96 : 24 : 30 : 10이면 χ² = 6²/90 + 6²/30 + 0 + 0 = 0.4 + 1.2 = 1.6입니다.

자유도 3의 기준값 7.81보다 작으므로, 이 차이는 우연으로 볼 수 있어 9 : 3 : 3 : 1 가설을 기각하지 않습니다.

χ²가 크게 나와 독립 가설이 기각되면, 두 유전자가 연관되어 있을 가능성을 검토합니다.

문제 7

AaBb 자가 교배 자손 160마리가 96 : 24 : 30 : 10이었습니다. 9 : 3 : 3 : 1 가설에 대한 χ²는? 소수로 쓰세요.

문제 8

앞 문제에서 χ² = 1.6, 자유도 3의 기준값이 7.81일 때 가설을 받아들이면 1, 기각하면 2를 쓰세요.

정리

재조합 빈도 r인 AB/ab끼리 교배하면 aabb = ((1 − r)/2)², Ab/aB끼리면 aabb = (r/2)²입니다. 완전 우성이면 A_B_ = 0.5 + aabb입니다.

χ² = Σ(관찰 − 기대)²/기대이고 자유도는 범주 수 − 1입니다. 자유도 1은 3.84, 자유도 3은 7.81을 넘으면 5% 수준에서 기각합니다.

독립 가설이 기각되면 연관을 의심하고 재조합 빈도로 지도 거리를 구합니다.
