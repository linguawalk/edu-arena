탄소 골격

탄소는 원자가 전자가 4개라 결합 4개를 만들고, 탄소끼리 길게 이어져 사슬과 고리를 이룹니다. 단일 결합만 있는 사슬 모양 탄화수소(알케인)는 CₙH₂ₙ₊₂입니다.

분자식이 같지만 원자의 연결 순서가 다른 화합물을 구조 이성질체라 합니다. C₄H₁₀은 뷰테인과 2-메틸프로페인 두 가지, C₅H₁₂는 세 가지, C₆H₁₄는 다섯 가지입니다.

구조를 셀 때는 같은 분자를 돌리거나 뒤집어 두 번 세지 않도록 가장 긴 사슬부터 정리해 셉니다.

불포화도

불포화도(수소 결핍 지수)는 같은 탄소 수의 알케인보다 수소가 몇 쌍 모자란지를 나타냅니다. CₐHᵦNᵧXᵤ(X는 할로젠)에서 불포화도 = (2a + 2 + c − b − d)/2이고 산소는 무시합니다.

이중 결합 하나 또는 고리 하나가 불포화도 1, 삼중 결합은 2입니다. 벤젠 C₆H₆은 (14 − 6)/2 = 4로 고리 1개와 이중 결합 3개입니다.

구조를 추리할 때 먼저 불포화도를 계산하면 가능한 구조가 크게 줄어듭니다.

예제

분자식 C₅H₈의 불포화도를 구하고 가능한 구조의 예를 드세요.

  1. 불포화도 = (2 × 5 + 2 − 8)/2입니다.
  2. = 4/2 = 2입니다.
  3. 이중 결합 2개, 삼중 결합 1개, 고리 1개 + 이중 결합 1개 등이 가능합니다.
  4. 예: 펜트-1-인(삼중 결합), 사이클로펜텐(고리 + 이중 결합)입니다.

치환 생성물의 수 세기

알케인의 수소 하나를 염소로 바꾸는 반응에서 생기는 구조 이성질체의 수는 '서로 다른 종류의 수소'의 수와 같습니다.

프로페인 CH₃CH₂CH₃은 끝의 CH₃ 수소(6개)와 가운데 CH₂ 수소(2개) 두 종류라 1-클로로프로페인, 2-클로로프로페인 두 가지가 생깁니다.

2,2-다이메틸프로페인은 수소 12개가 모두 같은 종류라 한 가지만 생깁니다. 대칭을 찾는 것이 핵심입니다.

정리

알케인 CₙH₂ₙ₊₂. 같은 분자식에서 연결 순서가 다르면 구조 이성질체이며, 가장 긴 사슬부터 체계적으로 셉니다.

불포화도 = (2C + 2 + N − H − X)/2(O 무시). 이중 결합·고리 1, 삼중 결합 2입니다.

치환 생성물의 수 = 대칭으로 구별되는 수소 종류의 수입니다. 분자의 대칭면과 대칭축을 먼저 찾으면 셀 때 실수가 줄어듭니다.
