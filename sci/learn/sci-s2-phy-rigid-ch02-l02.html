용수철 진자

과학 올림피아드 S2 본선 · 강체와 진동 · 2. 단진동 · 심화 · 약 25분 · 문제 11개

이 레슨 풀어 보기

복원력이 변위에 비례하면

그림처럼 용수철에 매단 물체에는 F = −kx의 복원력이 작용합니다. 운동 방정식 m x″ = −kx는 x″ = −(k/m)x이므로 단진동이고 ω = √(k/m)입니다.

주기는 T = 2π√(m/k)로 진폭과 무관합니다(등시성). 질량이 4배면 주기는 2배, 용수철 상수가 4배면 주기는 1/2배입니다.

역학적 에너지는 E = ½kA²으로 일정하며, 평형점에서 모두 운동 에너지(½mv_max²), 양 끝에서 모두 탄성 에너지입니다.

문제 1

그림에서 k = 100 N/m, m = 1 kg일 때 각진동수는 몇 rad/s인가요?

문제 2

용수철 진자의 주기 T = 2π√(m/k)는 ＿＿＿과 무관합니다.

연직 용수철과 용수철 연결

용수철을 연직으로 매달면 평형점에서 늘어난 길이 Δ = mg/k만큼 내려갈 뿐, 평형점을 기준으로 재면 똑같이 ω = √(k/m)로 진동합니다. 이때 ω² = k/m = g/Δ입니다.

두 용수철을 나란히(병렬) 연결하면 k = k₁ + k₂, 이어서(직렬) 연결하면 1/k = 1/k₁ + 1/k₂입니다.

용수철을 반으로 자르면 같은 힘에 절반만 늘어나므로 용수철 상수는 2배가 됩니다.

예제

용수철 상수 200 N/m인 용수철에 2 kg 물체를 연직으로 매달았습니다(g = 10 m/s²). 평형점에서 늘어난 길이와 진동의 각진동수를 구하세요.

  1. 평형점에서 kΔ = mg이므로 Δ = 20/200 = 0.1 m입니다.
  2. 평형점을 기준으로 하면 운동 방정식은 m x″ = −kx로 같습니다.
  3. ω = √(k/m) = √100 = 10 rad/s입니다.
  4. 확인: ω² = g/Δ = 10/0.1 = 100으로 같습니다.

답: 0.1 m, 10 rad/s

문제 3

용수철에 물체를 연직으로 매달았더니 평형점에서 0.4 m 늘어났습니다(g = 10 m/s²). 진동의 각진동수는 몇 rad/s인가요?

문제 4

용수철 상수 60 N/m와 30 N/m인 두 용수철을 직렬로 이었습니다. 합성 용수철 상수는 몇 N/m인가요?

에너지로 보는 용수철 진자

E = ½mv² + ½kx² = ½kA²이 보존됩니다. 이로부터 v_max = A√(k/m) = Aω가 나옵니다.

x = A/2일 때 탄성 에너지는 ½k(A/2)² = E/4이므로 운동 에너지는 3E/4입니다. 운동 에너지와 탄성 에너지가 같아지는 곳은 x = A/√2입니다.

한 주기 동안 평균하면 운동 에너지와 탄성 에너지의 평균은 각각 E/2로 같습니다.

문제 5

용수철 상수 200 N/m인 용수철 진자의 진폭이 0.1 m일 때 역학적 에너지는 몇 J인가요?

문제 6

용수철 진자의 변위가 진폭의 절반일 때 운동 에너지는 전체 에너지의 몇 배인가요? (분수로)

문제 7

용수철 진자의 질량을 9배로 늘리면 주기는 몇 배가 되나요?

정리

F = −kx이면 단진동이고 ω = √(k/m), T = 2π√(m/k)이며 주기는 진폭과 무관합니다.

연직 용수철은 평형점(늘어난 길이 Δ = mg/k)을 기준으로 같은 ω로 진동하고 ω² = g/Δ입니다. 병렬 k₁ + k₂, 직렬 1/k = 1/k₁ + 1/k₂입니다.

에너지 ½mv² + ½kx² = ½kA²이 보존됩니다.

문제 8

질량 2 kg인 물체가 용수철 상수 50 N/m인 용수철 진자로 진폭 0.4 m 진동할 때 최대 속력은 몇 m/s인가요?

문제 9

용수철 상수 40 N/m인 용수철을 반으로 잘라 두 조각을 병렬로 연결했습니다. 합성 용수철 상수는 몇 N/m인가요?

문제 10

용수철 상수 k₁, k₂인 두 용수철을 직렬로 이은 합성 용수철 상수가 1/k = 1/k₁ + 1/k₂임을 보이세요.

문제 11

연직으로 매단 용수철 진자가 평형점을 기준으로 수평 용수철 진자와 같은 각진동수로 진동함을 보이세요.
