거듭제곱의 미분

d/dt(tⁿ) = n tⁿ⁻¹입니다. 상수는 미분하면 0이고, 상수배와 합은 그대로 따라갑니다: d/dt(af + bg) = af' + bg'.

그래서 다항식은 항별로 미분합니다. x = 4t³ + 2t − 7이면 v = 12t² + 2입니다.

물리에서는 시간 미분을 점으로 쓰기도 합니다: ẋ = dx/dt, ẍ = d²x/dt². 국제 대회 문제에서 자주 보는 표기이니 익숙해지세요.

다항식으로 주어진 운동

등가속도 운동의 위치 x = x₀ + v₀t + (1/2)at²를 미분하면 v = v₀ + at입니다. 미분이 등가속도 공식들을 하나로 묶어 줍니다.

물체가 방향을 바꾸는 순간은 v = 0인 순간입니다. 이때 x는 극댓값이나 극솟값을 가집니다. 위로 던진 공의 최고점이 대표적인 예입니다.

x(t)가 주어진 문제는 (1) 미분해서 v(t)를 구하고, (2) v = 0인 시각을 찾고, (3) 그 시각의 위치를 구하는 순서로 풀면 대부분 해결됩니다.

예제

x = 2 + 3t − t²(m)인 물체가 멈추는 시각과 그때의 위치를 구하세요.

  1. v = dx/dt = 3 − 2t입니다.
  2. v = 0이면 t = 1.5 s입니다.
  3. x(1.5) = 2 + 4.5 − 2.25 = 4.25 m입니다.
  4. 이 순간 물체는 방향을 바꾸고, x는 최댓값 4.25 m입니다.

답: t = 1.5 s, x = 4.25 m

문제 4

앞 문제에서 물체가 멈출 때의 위치는 몇 m인가요?

진동하는 운동의 미분

d/dt sin(ωt) = ω cos(ωt), d/dt cos(ωt) = −ω sin(ωt)입니다. 안쪽의 ω가 바깥으로 곱해져 나옵니다.

x = A sin(ωt)로 진동하면 v = Aω cos(ωt)이므로 최대 속력은 Aω이고, 평형점(x = 0)을 지날 때 나옵니다. 양 끝(x = ±A)에서는 속력이 0입니다.

용수철 진자, 단진자의 작은 진동이 모두 이런 꼴이라 S2의 '단진동' 챕터의 기초가 됩니다. 진폭 A의 단위가 m이고 ω의 단위가 1/s이면 Aω는 m/s로 차원도 맞습니다.

문제 6

x = 3 cos(2t)(m)인 물체의 t = 0에서의 속도는 몇 m/s인가요?

연쇄 법칙

합성함수의 미분은 d/dt f(g(t)) = f'(g(t)) × g'(t)입니다. 바깥 함수를 미분하고 안쪽 함수의 미분을 곱합니다.

예: x = (1 + 2t)³이면 v = 3(1 + 2t)² × 2 = 6(1 + 2t)²입니다. s = √(t² + 9)이면 ds/dt = t/√(t² + 9)입니다.

물리에서는 거리가 좌표들의 제곱근으로 주어질 때 자주 씁니다. 두 물체 사이 거리가 변하는 빠르기를 구하는 문제가 대표적입니다.

문제 8

거리 s = √(t² + 9)(m)가 t = 4 s에서 변하는 빠르기 ds/dt를 분수로 쓰세요.

정리

d/dt(tⁿ) = ntⁿ⁻¹, 합과 상수배는 항별로 미분합니다. 등가속도 위치식을 미분하면 v = v₀ + at입니다.

d/dt sin(ωt) = ω cos(ωt), d/dt cos(ωt) = −ω sin(ωt)이고, x = A sin(ωt)의 최대 속력은 Aω입니다.

합성함수는 연쇄 법칙으로 미분합니다. 방향을 바꾸는 순간은 v = 0인 순간입니다.
