엔탈피와 반응열

반응과 열

가스레인지의 불꽃은 열을 내고, 냉찜질 팩은 주위의 열을 빼앗아 차가워집니다.

화학 반응은 물질만 바꾸는 것이 아니라 에너지도 주고받습니다.

문제 1

화학 반응이 일어날 때 방출하거나 흡수하는 열을 ＿＿＿이라고 합니다.

엔탈피 변화

물질이 가진 에너지를 엔탈피(H)라고 하며, 반응열은 ΔH = H_생성물 − H_반응물입니다.

발열 반응은 생성물의 엔탈피가 작아 ΔH < 0이고, 흡열 반응은 생성물의 엔탈피가 커서 ΔH > 0입니다.

반응식에 물질의 상태와 ΔH를 함께 쓴 것을 열화학 반응식이라고 합니다. 예: CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l), ΔH = −890 kJ. 계수를 2배로 하면 ΔH도 2배, 반응을 거꾸로 쓰면 ΔH의 부호가 바뀝니다.

문제 2

발열 반응의 ΔH는 ＿＿＿의 값을 가집니다.

문제 3

메테인의 연소는 ＿＿＿ 반응입니다.

문제 4

CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l)의 ΔH가 −890 kJ일 때, 메테인 2 mol이 연소하면 ΔH는 몇 kJ일까요?

예제

H₂(g) + ½O₂(g) → H₂O(l), ΔH = −286 kJ일 때 물의 분해 반응의 ΔH는?

  1. 물의 분해는 생성 반응을 거꾸로 쓴 것입니다: H₂O(l) → H₂(g) + ½O₂(g).
  2. 반응을 거꾸로 쓰면 ΔH의 부호가 바뀝니다.
  3. ΔH = +286 kJ로 흡열 반응입니다.

답: +286 kJ

문제 5

CH₄의 연소 ΔH가 −890 kJ일 때, 그 역반응(CO₂와 H₂O에서 CH₄와 O₂가 생기는 반응)의 ΔH는 몇 kJ일까요?

생성 엔탈피

25 °C, 1 atm에서 가장 안정한 성분 원소로부터 화합물 1 mol이 생성될 때의 엔탈피 변화를 표준 생성 엔탈피(ΔH_f)라고 합니다. 가장 안정한 홑원소 물질(O₂, H₂, 흑연 등)의 생성 엔탈피는 0입니다.

반응열은 생성 엔탈피로 계산할 수 있습니다: ΔH = Σ(생성물의 ΔH_f) − Σ(반응물의 ΔH_f).

같은 물질이라도 상태에 따라 엔탈피가 달라 H₂O(l)과 H₂O(g)의 생성 엔탈피는 다릅니다. 그래서 열화학 반응식에는 상태를 꼭 표시합니다.

문제 6

O₂(g), H₂(g)처럼 가장 안정한 홑원소 물질의 표준 생성 엔탈피는 ＿＿＿입니다.

문제 7

ΔH_f가 CH₄ −75, CO₂ −394, H₂O(l) −286 kJ/mol일 때 CH₄ + 2O₂ → CO₂ + 2H₂O(l)의 ΔH는 몇 kJ일까요?

문제 8

열화학 반응식에 물질의 상태를 표시하는 것은 상태에 따라 ＿＿＿가 다르기 때문입니다.

예제

흡열 반응의 에너지 도표는 어떤 모양일까요?

  1. 흡열 반응은 주위에서 에너지를 흡수합니다.
  2. 생성물의 엔탈피가 반응물보다 높은 곳에 그려집니다.
  3. 화살표는 위쪽을 향하고 그 높이 차이가 ΔH(> 0)입니다.

답: 생성물이 반응물보다 높다

반응열 정리

ΔH = H_생성물 − H_반응물. 발열 ΔH < 0, 흡열 ΔH > 0.

계수 n배 → ΔH n배, 역반응 → 부호 반대. ΔH = ΣΔH_f(생성물) − ΣΔH_f(반응물).

문제 9

흡열 반응에서는 생성물의 엔탈피가 반응물보다 ＿＿＿니다.

예제

H₂(g) + ½O₂(g) → H₂O(l), ΔH = −286 kJ일 때 물 2 mol이 생성되면 ΔH는?

  1. 계수를 2배로 하면 2H₂ + O₂ → 2H₂O(l)입니다.
  2. ΔH = 2 × (−286) = −572 kJ입니다.

답: −572 kJ
