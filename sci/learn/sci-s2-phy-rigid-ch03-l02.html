임계 감쇠와 과감쇠

세 가지 감쇠

특성 방정식 r² + 2γr + ω₀² = 0의 판별식에 따라 운동이 달라집니다. γ < ω₀이면 약한 감쇠(진동하며 감소), γ = ω₀이면 임계 감쇠, γ > ω₀이면 과감쇠입니다.

임계 감쇠의 해는 x = (A + Bt)e^(−γt)로 진동하지 않고 가장 빨리 평형으로 돌아옵니다. 저항 계수로 쓰면 b_c = 2√(mk)입니다.

과감쇠의 해는 두 지수 함수의 합 x = A e^(r₁t) + B e^(r₂t)(r₁, r₂ < 0)이며, 천천히 줄어드는 항 때문에 임계 감쇠보다 늦게 돌아옵니다.

문제 1

질량 4 kg, 용수철 상수 100 N/m인 진동자를 임계 감쇠시키는 저항 계수 b는 몇 kg/s인가요?

문제 2

진동하지 않으면서 가장 빨리 평형점으로 돌아오는 감쇠를 ＿＿＿ 감쇠라 합니다.

과감쇠의 느린 항

질량 1 kg, k = 4 N/m, b = 5 kg/s이면 r² + 5r + 4 = 0, r = −1, −4입니다. 해는 A e^(−t) + B e^(−4t)이고 오래 지나면 느린 항 e^(−t)가 남습니다.

같은 계를 임계 감쇠(b = 4)로 하면 r = −2(중근)이라 e^(−2t)로 줄어 더 빠릅니다.

그래서 자동차 완충기, 저울 바늘, 문 닫힘 장치는 임계 감쇠 근처로 설계합니다.

예제

질량 1 kg, k = 6 N/m, b = 5 kg/s인 진동자의 운동을 분류하고, 오래 지난 뒤 줄어드는 비율(느린 근의 크기)을 구하세요.

  1. γ = 2.5 s⁻¹, ω₀ = √6 ≈ 2.45 rad/s이므로 γ > ω₀, 과감쇠입니다.
  2. 특성 방정식 r² + 5r + 6 = 0입니다.
  3. r = −2, −3입니다.
  4. 오래 지나면 e^(−2t) 항이 남아 감소율은 2 s⁻¹입니다.

답: 과감쇠, 2 s⁻¹

문제 3

질량 1 kg, k = 4 N/m, b = 5 kg/s인 과감쇠 진동자에서 오래 지난 뒤 변위는 e^(−ct) 꼴로 줄어듭니다. c는?

문제 4

질량 2 kg, 용수철 상수 18 N/m인 진동자의 임계 저항 계수 b_c는 몇 kg/s인가요?

감쇠의 판별

판별은 γ와 ω₀ 또는 b와 b_c = 2√(mk)를 비교하면 됩니다. b < b_c이면 진동, b = b_c이면 임계, b > b_c이면 과감쇠입니다.

Q = ω₀/(2γ)로 쓰면 Q > 1/2이 약한 감쇠, Q = 1/2이 임계 감쇠, Q < 1/2이 과감쇠입니다.

임계 감쇠에서는 특성 방정식이 중근을 가져 e^(−γt) 하나만으로는 부족하므로 te^(−γt)가 두 번째 해가 됩니다.

문제 5

질량 1 kg, k = 9 N/m인 진동자에 b = 4 kg/s인 저항이 있습니다. b_c는 몇 kg/s인가요? (그래서 이 진동자는 b < b_c로 진동합니다)

문제 6

임계 감쇠일 때 품질 인자 Q의 값은? (소수로)

문제 7

질량 0.5 kg, 용수철 상수 50 N/m인 진동자를 임계 감쇠시키는 저항 계수는 몇 kg/s인가요?

정리

γ < ω₀(약한 감쇠): 진동하며 감소, γ = ω₀(임계): (A + Bt)e^(−γt), γ > ω₀(과감쇠): 두 지수 함수의 합입니다.

임계 저항 계수 b_c = 2√(mk), Q = 1/2이 경계입니다.

임계 감쇠가 진동 없이 가장 빨리 평형으로 돌아오며, 과감쇠는 느린 근 때문에 더 늦습니다.
