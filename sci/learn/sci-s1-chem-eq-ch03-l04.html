고체가 섞인 평형

고체와 기체가 함께 있는 평형을 불균일 평형이라고 합니다. 순수한 고체는 Kp에 넣지 않으므로 식이 간단해집니다.

CaCO₃(s) ⇌ CaO(s) + CO₂(g)의 Kp = P_CO₂입니다. 일정한 온도에서 CO₂의 평형 압력은 고체의 양과 관계없이 정해진 값입니다.

NH₄Cl(s) ⇌ NH₃(g) + HCl(g)를 고체만으로 시작하면 두 기체가 같은 양 생기므로 P_NH₃ = P_HCl = P_전체/2이고 Kp = (P_전체/2)²입니다.

문제 1

NH₄Cl(s)만 넣고 가열해 NH₄Cl(s) ⇌ NH₃(g) + HCl(g)가 평형에 이르렀더니 전체 압력이 0.4 atm이었습니다. Kp는? 소수로 쓰세요.

문제 2

CaCO₃(s) ⇌ CaO(s) + CO₂(g)의 Kp는 ＿＿＿의 분압과 같습니다.

예제

NH₄HS(s) ⇌ NH₃(g) + H₂S(g)의 Kp = 0.09입니다. 고체만 넣고 시작하면 평형의 전체 압력은 얼마인가요?

  1. 두 기체가 같은 양 생기므로 P_NH₃ = P_H₂S = x입니다.
  2. Kp = x² = 0.09입니다.
  3. x = 0.3 atm입니다.
  4. 전체 압력은 2x = 0.6 atm입니다.

답: 0.6 atm

문제 3

앞 예제에서 평형의 전체 압력은 몇 atm인가요? 소수로 쓰세요.

문제 4

같은 반응(Kp = 0.09)에서 처음 NH₃ 0.8 atm이 있는 용기에 NH₄HS(s)를 넣었습니다. 평형의 P_H₂S는 몇 atm인가요? 소수로 쓰세요.

분해가 일어나는가

고체를 기체가 있는 용기에 넣었을 때 분해가 일어날지는 Qp와 Kp로 판단합니다. CaCO₃의 Kp = 0.2 atm인데 용기의 CO₂ 압력이 0.5 atm이면 Qp > Kp이므로 CaCO₃는 분해되지 않고, 오히려 CaO가 있으면 CO₂를 흡수합니다.

CO₂ 압력이 Kp보다 낮으면 CaCO₃가 분해되어 CO₂ 압력이 Kp가 될 때까지 진행합니다(고체가 충분하면).

석회 가마에서 CO₂를 계속 빼내는 이유가 이것입니다. CO₂를 빼면 Qp < Kp가 유지되어 분해가 끝까지 진행합니다.

문제 5

CaCO₃(s) ⇌ CaO(s) + CO₂(g)의 Kp = 0.2 atm입니다. CO₂ 압력이 0.5 atm인 용기에서 Qp/Kp는? 소수로 쓰세요.

증기 압력도 평형 상수

밀폐 용기 속의 물과 수증기 H₂O(l) ⇌ H₂O(g)의 평형에서 Kp = P_H₂O이고, 이것이 그 온도의 증기 압력입니다.

액체가 남아 있는 한 용기의 부피를 바꾸어도 증기 압력은 변하지 않습니다. 압축하면 수증기 일부가 응결하고, 늘리면 물이 더 증발할 뿐입니다.

결정수를 가진 고체의 탈수 CuSO₄·5H₂O(s) ⇌ CuSO₄·3H₂O(s) + 2H₂O(g)도 Kp = P_H₂O²으로, 일정한 수증기 압력에서 평형을 이룹니다.

문제 6

물과 수증기가 평형을 이룬 밀폐 용기의 수증기 압력이 0.03 atm입니다. 온도를 유지한 채 부피를 절반으로 줄였습니다(물은 남아 있음). 새 평형의 수증기 압력은 몇 atm인가요? 소수로 쓰세요.

문제 7

CuSO₄·5H₂O(s) ⇌ CuSO₄·3H₂O(s) + 2H₂O(g)의 Kp = 1 × 10⁻⁴입니다. 평형의 수증기 압력은 몇 atm인가요? 소수로 쓰세요.

정리

불균일 평형에서는 순수한 고체와 액체를 Kp에 넣지 않습니다. CaCO₃ 분해의 Kp = P_CO₂처럼 간단해집니다.

고체만으로 시작해 두 기체가 같은 양 생기면 각 분압은 √Kp입니다. 공통 기체가 미리 있으면 처음-변화-평형 표로 풉니다.

Qp와 Kp를 비교해 분해 여부를 판단합니다. 증기 압력도 평형 상수이므로 액체가 남아 있으면 부피와 관계없이 일정합니다.

문제 8

C(s) + CO₂(g) ⇌ 2CO(g)의 평형에서 P_CO = 0.6 atm, P_CO₂ = 0.4 atm입니다. Kp는? 소수로 쓰세요.

문제 9

NH₄Cl(s) ⇌ NH₃(g) + HCl(g)의 Kp = 0.25입니다. 고체만 넣고 시작하면 평형의 전체 압력은 몇 atm인가요?

문제 10
