Kp와 Kc의 관계

과학 올림피아드 S1 예선 · 화학 평형 · 3. 기체 평형 · 심화 · 약 20분 · 문제 11개

이 레슨 풀어 보기

Kp = Kc(RT)^Δn

기체의 분압과 농도는 P = (n/V)RT = [기체]RT로 연결됩니다. 이것을 Kp식에 넣으면 Kp = Kc(RT)^Δn입니다. Δn은 기체 생성물의 계수 합 − 기체 반응물의 계수 합입니다.

Δn = 0(예: H₂ + I₂ ⇌ 2HI)이면 Kp = Kc입니다. 기체 분자 수가 늘면 Kp > Kc가 되기 쉽고, 줄면 Kp < Kc가 되기 쉽습니다.

R은 0.082 L·atm/(mol·K)를 써야 Kp가 atm 기준이 됩니다. T = 500 K이면 RT = 41입니다.

H₂ + I₂ ⇌ 2HI에서 Kp/Kc의 값은?

문제 2

Δn = 0이면 Kp = ＿＿＿입니다.

예제

N₂O₄ ⇌ 2NO₂의 Kc = 0.2일 때 500 K에서의 Kp를 구하세요.

  1. Δn = 2 − 1 = 1입니다.
  2. RT = 0.082 × 500 = 41입니다.
  3. Kp = Kc × (RT)¹ = 0.2 × 41입니다.
  4. = 8.2입니다.

답: 8.2

문제 4

N₂ + 3H₂ ⇌ 2NH₃의 500 K에서 Kc = 1681입니다. Kp는?

Δn은 기체만 센다

Δn을 셀 때는 기체만 셉니다. CaCO₃(s) ⇌ CaO(s) + CO₂(g)는 Δn = 1 − 0 = 1이므로 Kp = Kc × RT입니다.

2SO₂ + O₂ ⇌ 2SO₃는 Δn = 2 − 3 = −1, PCl₅ ⇌ PCl₃ + Cl₂는 Δn = 2 − 1 = 1입니다.

1000 K에서 CaCO₃ 분해의 Kc = 0.01이면 RT = 82이므로 Kp = 0.82 atm입니다. 이것이 1000 K에서 CO₂의 평형 압력입니다.

문제 6

2SO₂ + O₂ ⇌ 2SO₃의 Δn은?

Kp에서 Kc로

Kc = Kp/(RT)^Δn입니다. 500 K에서 A(g) ⇌ 2B(g)의 Kp = 4.1이면 Δn = 1이므로 Kc = 4.1/41 = 0.1입니다.

Kp와 Kc는 같은 평형을 다른 단위로 나타낸 것일 뿐입니다. 어느 쪽을 쓰든 평형 농도(분압) 계산 결과는 같습니다.

엄밀하게는 평형 상수는 표준 상태(1 atm 또는 1 M)로 나눈 값이라 단위가 없습니다. 그래서 Kp와 Kc의 값이 다를 수 있습니다.

문제 7

500 K에서 A(g) ⇌ 2B(g)의 Kp = 4.1입니다. Kc는? 소수로 쓰세요.

정리

Kp = Kc(RT)^Δn이고, Δn은 기체 생성물 계수 합 − 기체 반응물 계수 합입니다. 고체와 액체는 세지 않습니다.

Δn = 0이면 Kp = Kc입니다. R = 0.082 L·atm/(mol·K)를 써서 Kp를 atm 기준으로 맞춥니다.

Kc = Kp/(RT)^Δn으로 거꾸로 바꿀 수 있습니다. 두 상수는 같은 평형을 다른 방식으로 나타낸 것입니다.
