X 연관 유전자

X 연관 유전자에서 남자는 X가 하나뿐이므로 열성 형질을 가진 남자의 빈도가 곧 대립유전자 빈도 q입니다.

여자는 X가 둘이라 평형에서 열성 형질 빈도는 q², 보인자 빈도는 2pq입니다.

남자 색맹 빈도가 8%이면 q = 0.08이므로 여자 색맹은 0.08² = 0.0064(0.64%), 여자 보인자는 2 × 0.92 × 0.08 = 0.1472입니다.

문제 1

남자의 색맹 빈도가 0.08인 평형 집단에서 여자의 색맹 빈도는? 소수로 쓰세요.

문제 2

같은 집단에서 여자 보인자의 빈도는? 소수로 쓰세요.

문제 3

X 연관 열성 형질을 가진 남자의 빈도는 그 대립유전자의 빈도 ＿＿＿와 같습니다.

복대립: ABO 혈액형

대립유전자가 셋(Iᴬ, Iᴮ, i)이면 빈도를 p, q, r(p + q + r = 1)이라 하고 (p + q + r)²을 전개합니다.

O형 = r², A형 = p² + 2pr, B형 = q² + 2qr, AB형 = 2pq입니다.

O형 빈도에서 r을 구하고, A형 + O형 = (p + r)²을 이용하면 p를 구할 수 있습니다.

예제

평형 집단에서 O형이 0.36, A형이 0.45입니다. Iᴬ, Iᴮ, i의 빈도를 구하세요.

  1. r² = 0.36이므로 r = 0.6입니다.
  2. A형 + O형 = (p + r)² = 0.81이므로 p + r = 0.9입니다.
  3. p = 0.9 − 0.6 = 0.3입니다.
  4. q = 1 − 0.3 − 0.6 = 0.1입니다.

답: p = 0.3, q = 0.1, r = 0.6

문제 4

앞 예제에서 Iᴬ의 빈도 p는? 소수로 쓰세요.

문제 5

앞 예제의 집단에서 B형의 빈도는? 소수로 쓰세요.

문제 6

앞 예제의 집단에서 AB형의 빈도는? 소수로 쓰세요.

평형인지 검정하기

관찰한 유전자형 수에서 p를 구하고 기대값 Np², 2Npq, Nq²를 계산해 카이제곱 검정을 합니다. 대립유전자가 2개이면 자유도는 3 − 1 − 1 = 1입니다(p를 자료에서 추정했으므로 하나 더 뺌).

AA 50, Aa 20, aa 30(100명)이면 p = (100 + 20)/200 = 0.6이고 기대값은 36, 48, 16입니다.

χ² = 14²/36 + 28²/48 + 14²/16 ≈ 5.4 + 16.3 + 12.3 ≈ 34로 3.84보다 훨씬 크므로 평형이 아닙니다. 이형 접합자가 너무 적은 것은 근친 교배나 집단 구조를 의심하게 합니다.

문제 7

AA 50명, Aa 20명, aa 30명인 집단에서 평형이라면 기대되는 Aa는 몇 명인가요?

문제 8

앞 문제에서 χ² ≈ 34이고 자유도 1의 기준값이 3.84입니다. 이 집단이 평형이면 1, 평형이 아니면 2를 쓰세요.

정리

X 연관 열성 형질은 남자 빈도 = q, 여자 빈도 = q², 여자 보인자 = 2pq입니다.

ABO 혈액형은 (p + q + r)²로 O = r², A = p² + 2pr, B = q² + 2qr, AB = 2pq이며, A + O = (p + r)²을 이용해 p를 구합니다.

평형 여부는 기대값을 구해 카이제곱 검정으로 판단하며, 대립유전자 2개면 자유도는 1입니다.
