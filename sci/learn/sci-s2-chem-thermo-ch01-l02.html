경로와 관계없는 ΔH

엔탈피는 상태 함수이므로 반응물에서 생성물로 가는 ΔH는 경로와 관계없습니다. 그래서 반응식들을 더하면 ΔH도 더해집니다(헤스 법칙).

그림에서 C(s) + ½O₂ → CO(g)의 ΔH는 직접 재기 어렵지만(CO₂도 함께 생김), C → CO₂(−393.5 kJ)와 CO → CO₂(−283.0 kJ)를 재면 구할 수 있습니다.

C + O₂ → CO₂는 C + ½O₂ → CO와 CO + ½O₂ → CO₂의 합이므로 −393.5 = ΔH + (−283.0), 곧 ΔH = −110.5 kJ입니다.

문제 1

그림에서 CO₂(g) → CO(g) + ½O₂(g)의 ΔH는 몇 kJ인가요? (소수로)

문제 2

반응의 ΔH가 경로와 관계없이 처음과 나중 상태로만 정해진다는 법칙을 ＿＿＿ 법칙이라 합니다.

반응식을 맞추는 요령

① 목표 반응식의 각 물질이 주어진 식 어디에 있는지 찾고 ② 반응물 쪽에 와야 하면 식을 그대로, 생성물 쪽이면 뒤집습니다. ③ 계수가 맞도록 식에 수를 곱하고 ④ 더해서 필요 없는 물질이 지워지는지 확인합니다.

식을 뒤집으면 ΔH의 부호를, 곱하면 ΔH에 같은 수를 곱합니다.

한 번만 나오는 물질부터 맞추면 쉽습니다. 여러 식에 나오는 물질(O₂ 등)은 마지막에 저절로 맞춰집니다.

예제

N₂(g) + O₂(g) → 2NO(g), ΔH = +180.6 kJ과 2NO(g) + O₂(g) → 2NO₂(g), ΔH = −114.1 kJ로 N₂(g) + 2O₂(g) → 2NO₂(g)의 ΔH를 구하세요.

  1. 목표 반응식은 두 식을 그대로 더한 것입니다.
  2. 2NO는 첫 식의 생성물, 둘째 식의 반응물이라 지워집니다.
  3. ΔH = +180.6 + (−114.1)입니다.
  4. = +66.5 kJ입니다.

답: +66.5 kJ

문제 4

C(흑연) + O₂ → CO₂, ΔH = −393.5 kJ과 C(다이아몬드) + O₂ → CO₂, ΔH = −395.4 kJ로 C(흑연) → C(다이아몬드)의 ΔH는 몇 kJ인가요? (소수로)

세 개 이상의 식

식이 셋 이상이면 목표 반응식의 물질 하나씩을 맞춰 가며 각 식의 배수와 방향을 정합니다.

예: C₂H₄의 수소화 C₂H₄ + H₂ → C₂H₆의 ΔH는 세 물질의 연소열로 구합니다. 반응물의 연소식은 그대로, 생성물의 연소식은 뒤집어 더합니다.

연소열이 C₂H₄ −1411, H₂ −285.8, C₂H₆ −1560 kJ/mol이면 ΔH = −1411 + (−285.8) − (−1560) = −136.8 kJ입니다.

문제 5

연소열이 C₂H₄ −1411, H₂ −285.8, C₂H₆ −1560 kJ/mol일 때 C₂H₄ + H₂ → C₂H₆의 ΔH는 몇 kJ인가요? (소수로)

문제 6

A → B, ΔH = +40 kJ과 B → C, ΔH = −90 kJ일 때 2C → 2A의 ΔH는 몇 kJ인가요?

문제 7

S + O₂ → SO₂, ΔH = −296.8 kJ과 2SO₂ + O₂ → 2SO₃, ΔH = −197.8 kJ로 S + 3/2 O₂ → SO₃의 ΔH는 몇 kJ인가요? (소수로)

정리

헤스 법칙: ΔH는 상태 함수의 변화라 경로와 무관하므로 반응식을 더하면 ΔH도 더합니다.

식을 뒤집으면 부호를 바꾸고, n배 하면 ΔH도 n배 합니다. 한 번만 나오는 물질부터 맞춥니다.

연소열로 구할 때는 ΔH = Σ(반응물 연소열) − Σ(생성물 연소열)입니다. 생성 엔탈피 공식과 순서가 반대인 점에 주의합니다.
