화학의 요리법

요리법에는 어떤 재료를 얼마나 넣어 무엇을 만드는지 적혀 있습니다. 화학 반응에도 이런 요리법이 있습니다.

어떤 물질이 반응해 어떤 물질이 얼마만큼 생기는지를 화학식과 기호로 나타낸 식이 화학 반응식입니다.

문제 1

화학 반응을 화학식과 기호, 숫자로 나타낸 식을 ＿＿＿이라고 합니다.

화학 반응식 쓰는 법

화살표 왼쪽에 반응물, 오른쪽에 생성물의 화학식을 씁니다. 물질의 상태는 고체 (s), 액체 (l), 기체 (g), 수용액 (aq)로 표시합니다.

화학 반응에서 원자는 새로 생기거나 없어지지 않고 재배열될 뿐입니다. 그래서 반응 전후 원자의 종류와 수가 같도록 화학식 앞에 계수를 붙입니다. 이는 질량 보존 법칙과 같은 뜻입니다.

계수는 가장 간단한 정수비로 쓰며, 1은 생략합니다.

문제 2

반응 전후 원자의 종류와 수가 변하지 않으므로 반응 전후 전체 질량도 같습니다. 이것을 ＿＿＿ 법칙이라고 합니다.

예제

수소와 산소가 반응해 물이 생기는 반응식을 완성해 보세요. H₂ + O₂ → H₂O

  1. O 원자가 왼쪽 2개, 오른쪽 1개이므로 H₂O 앞에 2를 붙입니다: H₂ + O₂ → 2H₂O.
  2. 이제 H 원자가 왼쪽 2개, 오른쪽 4개이므로 H₂ 앞에 2를 붙입니다.
  3. 2H₂ + O₂ → 2H₂O로, 원자 수가 모두 같습니다.

답: 2H₂ + O₂ → 2H₂O

문제 3

메테인의 연소 반응식을 완성하세요. CH₄ + ＿＿＿O₂ → CO₂ + 2H₂O

문제 4

암모니아 합성 반응식을 완성하세요. N₂ + ＿＿＿H₂ → 2NH₃

문제 5

반응식을 완성하세요. ＿＿＿Na + Cl₂ → 2NaCl

복잡한 반응식 맞추기

원자 수를 눈으로 맞추기 어려우면 가장 복잡한 화학식의 계수를 1로 두고, 그 속에 든 원자부터 차례로 맞춥니다.

예를 들어 프로페인 연소 C₃H₈ + O₂ → CO₂ + H₂O에서 C₃H₈의 계수를 1로 두면 C 3개 → 3CO₂, H 8개 → 4H₂O가 됩니다. 오른쪽 O는 6 + 4 = 10개이므로 5O₂가 됩니다.

계수로 분수가 나오면 전체에 같은 수를 곱해 정수로 만듭니다.

예제

프로페인의 연소 반응식을 완성해 보세요. C₃H₈ + O₂ → CO₂ + H₂O

  1. C₃H₈의 계수를 1로 둡니다. C 3개 → 3CO₂입니다.
  2. H 8개 → 4H₂O입니다.
  3. 오른쪽 O 원자는 3 × 2 + 4 = 10개이므로 5O₂입니다: C₃H₈ + 5O₂ → 3CO₂ + 4H₂O.

답: C₃H₈ + 5O₂ → 3CO₂ + 4H₂O

문제 6

에테인의 연소 반응식을 완성하세요. 2C₂H₆ + ＿＿＿O₂ → 4CO₂ + 6H₂O

문제 7

화학 반응식에서 물에 녹아 있는 물질은 화학식 뒤에 ＿＿＿로 표시합니다.

문제 8

화학 반응식의 계수는 가장 간단한 ＿＿＿비로 나타냅니다.

반응식이 알려 주는 것

화학 반응식의 계수비는 반응하거나 생성되는 물질의 분자 수 비, 곧 몰비와 같습니다. 기체끼리는 같은 온도와 압력에서 부피비와도 같습니다.

하지만 계수비는 질량비와는 일반적으로 다릅니다. 물질마다 몰 질량이 다르기 때문입니다. 2H₂ + O₂ → 2H₂O에서 몰비는 2 : 1 : 2이지만 질량비는 4 : 32 : 36입니다.

문제 9

2H₂ + O₂ → 2H₂O 반응에서 수소 4 mol이 모두 반응하면 물은 몇 mol 생길까요?

문제 10

화학 반응식의 계수비는 몰비와 같지만 ＿＿＿비와는 일반적으로 다릅니다.

문제 11

화학 반응식을 쓰는 순서대로 배열하세요.

예제

광합성의 반응식을 완성해 보세요. CO₂ + H₂O → C₆H₁₂O₆ + O₂

  1. C₆H₁₂O₆의 계수를 1로 둡니다. C 6개 → 6CO₂, H 12개 → 6H₂O입니다.
  2. 왼쪽 O는 12 + 6 = 18개, 오른쪽 포도당 속 O는 6개입니다.
  3. 나머지 12개는 O₂로 나가므로 6O₂: 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂입니다.

답: 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂

문제 14
