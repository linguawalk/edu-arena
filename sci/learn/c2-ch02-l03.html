현대 원자 모형과 오비탈

화학Ⅰ · 2. 원소의 기원과 원자 구조 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

궤도에서 구름으로

보어의 원자 모형은 전자가 원자핵 주위의 정해진 궤도를 돈다고 보았습니다. 이 모형은 수소의 선 스펙트럼을 잘 설명했지만, 전자가 여러 개인 원자의 스펙트럼은 설명하지 못했습니다.

현대 원자 모형에서는 전자의 정확한 위치와 경로를 말하지 않고, 전자가 어디에 있을 확률이 높은지를 나타냅니다.

문제 1

원자핵 주위에서 전자가 발견될 확률 분포를 나타낸 것을 ＿＿＿이라고 합니다.

보어 모형의 전자 껍질

보어 모형에서 전자는 원자핵에서 가까운 것부터 n = 1, 2, 3, … 인 전자 껍질에 있습니다. 각 껍질을 K, L, M, N 껍질이라고 부릅니다.

n이 클수록 원자핵에서 멀고 에너지가 높습니다. 전자가 껍질 사이를 옮겨 갈 때 에너지 차이만큼 빛을 흡수하거나 방출합니다.

문제 2

보어 모형에서 주양자수 n = 1인 전자 껍질을 ＿＿＿ 껍질이라고 합니다.

문제 3

주양자수 n = 3인 전자 껍질을 ＿＿＿ 껍질이라고 합니다.

오비탈과 양자수

오비탈은 양자수로 구별합니다. 주양자수 n은 오비탈의 크기와 에너지를, 방위(부) 양자수 l은 모양을, 자기 양자수 mₗ은 공간에서의 방향을 나타냅니다.

s 오비탈은 공 모양(구형)이고 방향이 하나라 1개입니다. p 오비탈은 아령 모양이고 x, y, z 방향으로 3개, d 오비탈은 5개입니다.

한 오비탈에는 전자가 최대 2개 들어가며, 두 전자는 스핀 방향이 반대입니다. 주양자수 n인 껍질에는 오비탈이 n²개, 전자는 최대 2n²개 들어갑니다.

문제 6

s 오비탈의 모양은 ＿＿＿입니다.

문제 7

주양자수가 같은 p 오비탈은 모두 몇 개일까요?

예제

n = 2인 전자 껍질의 오비탈 종류와 최대 전자 수는?

  1. n = 2에는 2s 오비탈 1개와 2p 오비탈 3개가 있습니다.
  2. 오비탈은 모두 4개입니다.
  3. 오비탈 하나에 전자가 2개씩 들어가므로 최대 8개입니다.

답: 2s 1개, 2p 3개, 최대 8개

양자수의 관계

방위 양자수 l은 0부터 n − 1까지의 값을 가지며, l = 0, 1, 2, 3을 각각 s, p, d, f로 부릅니다. 그래서 n = 1에는 1s만, n = 2에는 2s와 2p, n = 3에는 3s, 3p, 3d가 있습니다.

자기 양자수 mₗ은 −l부터 +l까지의 정수이므로 오비탈 수는 s 1개, p 3개, d 5개, f 7개입니다. 스핀 양자수는 +1/2과 −1/2의 두 값입니다.

주양자수 1인 전자 껍질에는 ＿＿＿ 오비탈만 있습니다.

문제 9

주양자수가 같은 d 오비탈은 모두 몇 개일까요?

문제 10

오비탈 하나에 들어갈 수 있는 전자는 최대 몇 개일까요?

예제

3d 오비탈은 존재할까요? 2d 오비탈은?

  1. d 오비탈은 l = 2입니다.
  2. n = 3이면 l은 0, 1, 2가 가능하므로 3d가 존재합니다.
  3. n = 2이면 l은 0, 1뿐이므로 2d는 존재하지 않습니다.

답: 3d는 있고 2d는 없다

오비탈의 에너지

수소 원자처럼 전자가 1개인 원자에서는 오비탈의 에너지가 주양자수 n으로만 정해집니다. 2s와 2p의 에너지가 같습니다.

전자가 여러 개인 원자에서는 전자끼리의 반발 때문에 같은 n이라도 s < p < d 순으로 에너지가 높아집니다. 이것이 다음 레슨의 전자 배치 순서를 정합니다.

예제

n = 4인 전자 껍질의 오비탈 수와 최대 전자 수는?

  1. 오비탈 수 = n² = 16개입니다(4s 1 + 4p 3 + 4d 5 + 4f 7).
  2. 최대 전자 수 = 2n² = 32개입니다.

답: 16개, 32개
