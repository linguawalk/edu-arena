결합 에너지

화학Ⅱ · 4. 반응열 · 레벨1 · 약 15분 · 문제 16개

결합을 끊고 잇는 에너지

화학 반응은 반응물의 결합이 끊어지고 생성물의 새 결합이 만들어지는 과정입니다.

결합을 끊고 잇는 데 드는 에너지로 반응열을 추정할 수 있습니다.

문제 1

기체 상태의 분자에서 공유 결합 1 mol을 끊는 데 필요한 에너지를 ＿＿＿라고 합니다.

결합 에너지와 반응열

결합을 끊으려면 에너지를 흡수해야 하고(흡열), 결합이 만들어지면 같은 크기의 에너지를 방출합니다(발열).

그래서 기체 반응의 반응열은 ΔH = Σ(끊어지는 결합의 에너지) − Σ(생성되는 결합의 에너지)입니다.

생성되는 결합이 더 강하면 방출하는 에너지가 커서 발열 반응이 됩니다.

문제 2

결합을 끊으려면 에너지를 ＿＿＿해야 합니다.

문제 3

결합 에너지가 H–H 436, Cl–Cl 243, H–Cl 432 kJ/mol일 때 H₂ + Cl₂ → 2HCl의 ΔH는 몇 kJ일까요?

문제 4

결합 에너지가 큰 결합일수록 끊기 어려워 더 ＿＿＿합니다.

예제

결합 에너지(N≡N 945, H–H 436, N–H 391 kJ/mol)로 N₂ + 3H₂ → 2NH₃의 ΔH를 구하면?

  1. 끊는 결합: N≡N 1개 + H–H 3개 = 945 + 3 × 436 = 2253 kJ입니다.
  2. 생기는 결합: N–H 6개 = 6 × 391 = 2346 kJ입니다.
  3. ΔH = 2253 − 2346 = −93 kJ로 발열 반응입니다.

답: −93 kJ

문제 5

결합 에너지가 N≡N 945, H–H 436, N–H 391 kJ/mol일 때 N₂ + 3H₂ → 2NH₃의 ΔH는 몇 kJ일까요?

결합의 종류와 결합 에너지

같은 원자 사이의 결합은 단일 결합 < 이중 결합 < 삼중 결합 순으로 결합 에너지가 크고 결합 길이가 짧습니다. 예: C–C 348, C=C 614, C≡C 839 kJ/mol.

질소 분자(N≡N)는 결합 에너지가 945 kJ/mol로 매우 커서 반응성이 매우 작습니다. 반면 F–F는 159 kJ/mol로 작아 플루오린은 반응성이 큽니다.

문제 6

같은 원자 사이의 결합에서 삼중 결합은 단일 결합보다 결합 길이가 짧고 결합 에너지가 ＿＿＿니다.

문제 7

결합 에너지가 작은 것부터 순서대로 배열하세요.

문제 8

공기의 78%인 질소가 잘 반응하지 않는 것은 N≡N ＿＿＿ 결합이 매우 강하기 때문입니다.

예제

결합 에너지만 보고 반응이 발열인지 흡열인지 판단하는 방법은?

  1. 반응물에서 끊어지는 결합 에너지의 합과 생성물에서 생기는 결합 에너지의 합을 비교합니다.
  2. 생기는 결합의 합이 더 크면 방출이 흡수보다 커서 발열입니다.
  3. 끊는 결합의 합이 더 크면 흡열입니다.

답: 생성 결합 에너지 합이 크면 발열

결합 에너지 정리

ΔH = Σ(끊는 결합 에너지) − Σ(생성 결합 에너지). 결합 에너지로 구한 값은 평균값을 쓰므로 근삿값입니다.

결합 에너지가 클수록 결합이 강하고 짧으며, 분자가 안정합니다.

문제 9

생성되는 결합의 에너지 합이 끊어지는 결합의 에너지 합보다 크면 ＿＿＿ 반응입니다.

예제

결합 에너지(C–H 413, O=O 498, C=O 799, O–H 463 kJ/mol)로 CH₄ + 2O₂ → CO₂ + 2H₂O(g)의 ΔH를 구하면?

  1. 끊는 결합: C–H 4개 + O=O 2개 = 1652 + 996 = 2648 kJ입니다.
  2. 생기는 결합: C=O 2개 + O–H 4개 = 1598 + 1852 = 3450 kJ입니다.
  3. ΔH = 2648 − 3450 = −802 kJ입니다.

답: −802 kJ
