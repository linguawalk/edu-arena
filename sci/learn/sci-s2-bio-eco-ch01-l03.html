나이별로 따라가기

생명표는 같은 때 태어난 무리(코호트)가 나이별로 얼마나 살아남고 자손을 낳는지 정리한 표입니다. lₓ는 태어난 개체 가운데 나이 x까지 살아남은 비율, mₓ는 나이 x인 암컷 하나가 낳는 암컷 자손 수입니다.

순번식률 R₀ = Σ lₓmₓ는 암컷 한 마리가 평생 낳는 암컷 자손의 기대 수입니다. R₀ > 1이면 개체군이 늘고, R₀ < 1이면 줄어듭니다.

나이 x에서 x + 1까지 살아남을 확률은 lₓ₊₁/lₓ입니다.

문제 1

생명표에서 l₀ = 1, l₁ = 0.5, l₂ = 0.2, l₃ = 0이고 m₁ = 2, m₂ = 3입니다(m₀ = 0). 순번식률 R₀는? (소수로)

문제 2

같은 생명표에서 1살인 개체가 2살까지 살아남을 확률은? (소수로)

생존 곡선

나이에 따른 lₓ를 로그 눈금으로 그린 것이 생존 곡선입니다. Ⅰ형은 늙어서 대부분 죽고(사람, 큰 포유류), Ⅱ형은 나이와 관계없이 일정한 비율로 죽으며(많은 새), Ⅲ형은 어려서 대부분 죽습니다(굴, 많은 물고기·식물).

Ⅱ형은 해마다 같은 비율 p가 살아남으므로 lₓ = pˣ입니다. 로그 눈금에서 직선이 됩니다.

Ⅲ형 생물은 자손을 아주 많이 낳아 높은 사망률을 견딥니다.

예제

해마다 60%가 살아남는(Ⅱ형) 새 1000마리가 태어났습니다. 3살까지 살아남는 수를 구하세요.

  1. Ⅱ형이므로 lₓ = 0.6ˣ입니다.
  2. l₃ = 0.6³ = 0.216입니다.
  3. 1000 × 0.216 = 216입니다.
  4. 3살까지 약 216마리가 살아남습니다.

답: 216마리

문제 3

해마다 50%가 살아남는 Ⅱ형 생물 1600마리가 태어났습니다. 4살까지 살아남는 수는?

문제 4

굴처럼 알을 매우 많이 낳고 어릴 때 대부분 죽는 생물의 생존 곡선은? ① Ⅰ형 ② Ⅲ형 ③ Ⅱ형

세대 시간과 증가율

평균 세대 시간 T = Σ x lₓmₓ/R₀입니다. 자손을 낳는 평균 나이로 볼 수 있습니다.

내적 증가율은 대략 r ≈ ln R₀/T입니다. R₀가 같아도 일찍 번식하면(T가 작으면) r이 큽니다.

앞의 생명표(R₀ = 1.6)에서 T = (1 × 0.5 × 2 + 2 × 0.2 × 3)/1.6 = 2.2/1.6 ≈ 1.375년입니다.

문제 5

앞의 생명표(l₁ = 0.5, m₁ = 2, l₂ = 0.2, m₂ = 3, R₀ = 1.6)에서 평균 세대 시간 T는 몇 년인가요? (소수 셋째 자리까지)

문제 6

R₀ = 0.8인 개체군은? ① 줄어든다 ② 늘어난다 ③ 일정하다

문제 7

R₀ = 2, 세대 시간 T = 5년일 때 r ≈ ln R₀/T는 약 몇 /년인가요? (소수 셋째 자리까지)

정리

lₓ: 나이 x까지 살아남은 비율, mₓ: 나이 x의 출산 수. R₀ = Σ lₓmₓ(> 1 증가, < 1 감소).

생존 곡선: Ⅰ형(늙어서 죽음), Ⅱ형(일정 비율, lₓ = pˣ), Ⅲ형(어려서 죽음).

세대 시간 T = Σ x lₓmₓ/R₀, r ≈ ln R₀/T. 일찍 번식할수록 r이 큽니다.
