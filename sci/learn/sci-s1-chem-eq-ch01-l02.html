처음-변화-평형 표

평형 농도는 '처음 → 변화 → 평형' 표로 구합니다. 반응한 양을 x로 놓고, 계수비에 맞추어 각 물질의 변화량을 씁니다. 반응물은 줄고(−) 생성물은 늘어납니다(+).

평형 농도를 K식에 넣어 x에 대한 방정식을 풉니다. 양변의 제곱근을 취할 수 있으면 일차식이 되어 쉽고, 아니면 이차방정식을 풉니다.

답이 물리적으로 맞는지 확인하세요. 농도는 음수가 될 수 없으므로 반응물이 처음보다 많이 줄어드는 해는 버립니다.

문제 1

H₂ + I₂ ⇌ 2HI의 K = 64입니다. H₂와 I₂를 1 M씩 넣고 시작하면 평형에서 [HI]는 몇 M인가요? 소수로 쓰세요.

문제 2

처음-변화-평형 표에서 각 물질의 변화량의 비는 반응식의 ＿＿＿비와 같습니다.

예제

A ⇌ B의 K = 4입니다. [A]₀ = 1 M로 시작할 때 평형 농도를 구하세요.

  1. 처음: [A] = 1, [B] = 0. 변화: −x, +x. 평형: 1 − x, x입니다.
  2. K = x/(1 − x) = 4입니다.
  3. x = 4 − 4x에서 x = 0.8입니다.
  4. [A] = 0.2 M, [B] = 0.8 M입니다.

답: [A] = 0.2 M, [B] = 0.8 M

평형 농도에서 K 구하기

평형에서 한 물질의 농도만 알아도 표를 채워 K를 구할 수 있습니다.

1 L 용기에 A 2몰을 넣어 A ⇌ 2B가 평형에 이르렀을 때 [B] = 2 M이면, 생긴 B 2몰은 A 1몰에서 왔으므로 [A] = 1 M이고 K = 2²/1 = 4입니다.

N₂O₄ ⇌ 2NO₂에서 처음 1 M의 20%가 해리했다면 [N₂O₄] = 0.8 M, [NO₂] = 0.4 M이므로 K = 0.16/0.8 = 0.2입니다.

N₂O₄ ⇌ 2NO₂에서 처음 N₂O₄ 1 M 중 20%가 해리해 평형에 이르렀습니다. K는? 소수로 쓰세요.

해리도

처음 물질 중 해리한 비율을 해리도 α라고 합니다. 처음 농도가 c이면 해리한 양은 cα입니다.

PCl₅ ⇌ PCl₃ + Cl₂에서 처음 농도 c, 해리도 α이면 K = (cα)²/(c(1 − α)) = cα²/(1 − α)입니다.

c = 1 M, K = 0.5이면 α²/(1 − α) = 0.5, 곧 α² + 0.5α − 0.5 = 0에서 α = 0.5입니다. 이차방정식의 해 중 0 < α < 1인 것만 고릅니다.

문제 7

PCl₅ ⇌ PCl₃ + Cl₂의 K = 0.5입니다. PCl₅ 1 M로 시작하면 해리도는? 소수로 쓰세요.

정리

평형 농도는 처음-변화-평형 표로 구합니다. 반응한 양을 x로 놓고 계수비로 변화량을 씁니다.

K식에 넣어 x를 구합니다. 양변이 완전제곱이면 제곱근을 취하고, 아니면 이차방정식을 풀어 0 < (농도)인 해만 고릅니다.

평형에서 한 물질의 농도나 해리도 α를 알면 표를 채워 K를 구할 수 있습니다. 해리 반응에서는 K = cα²/(1 − α) 꼴이 자주 나옵니다.
