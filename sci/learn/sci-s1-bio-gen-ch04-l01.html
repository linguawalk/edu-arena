유전자풀과 대립유전자 빈도

한 집단이 가진 모든 대립유전자를 유전자풀이라 합니다. 두 대립유전자 A와 a의 빈도를 각각 p, q라 하면 p + q = 1입니다.

이배체 개체는 대립유전자를 2개씩 가지므로, 개체 N명의 집단에는 대립유전자가 2N개 있습니다. AA는 A를 2개, Aa는 A와 a를 1개씩 가집니다.

AA 36, Aa 48, aa 16인 집단(100명)에서 A의 수는 2 × 36 + 48 = 120이고, 전체 200개 중이므로 p = 0.6, q = 0.4입니다.

문제 1

AA 36명, Aa 48명, aa 16명인 집단에서 A의 빈도 p는? 소수로 쓰세요.

문제 2

두 대립유전자의 빈도 p와 q 사이에는 p + q = ＿＿＿이 성립합니다.

예제

MN 혈액형은 공동 우성이라 표현형으로 유전자형을 알 수 있습니다. MM 490명, MN 420명, NN 90명인 집단에서 M의 빈도를 구하세요.

  1. 전체 1000명이므로 대립유전자는 2000개입니다.
  2. M의 개수는 2 × 490 + 420 = 1400개입니다.
  3. M의 빈도 = 1400/2000입니다.
  4. = 0.7입니다.

답: 0.7

문제 3

앞 예제에서 M의 빈도는? 소수로 쓰세요.

문제 4

앞 예제에서 N의 빈도는? 소수로 쓰세요.

유전자형 빈도와 대립유전자 빈도

유전자형 빈도는 각 유전자형을 가진 개체의 비율이고, 대립유전자 빈도는 유전자풀에서 각 대립유전자의 비율입니다. 둘은 다른 양입니다.

대립유전자 빈도는 유전자형 빈도로 구할 수 있습니다. p = f(AA) + f(Aa)/2입니다. f(AA) = 0.36, f(Aa) = 0.48이면 p = 0.36 + 0.24 = 0.6입니다.

그러나 반대로 대립유전자 빈도만으로는 유전자형 빈도를 알 수 없습니다. 같은 p = 0.5라도 AA 0.5, aa 0.5일 수도, Aa만 있을 수도 있습니다.

문제 5

f(AA) = 0.49, f(Aa) = 0.42, f(aa) = 0.09인 집단에서 A의 빈도는? 소수로 쓰세요.

문제 6

대립유전자가 셋인 유전자에서 A₁A₁ 10, A₁A₂ 20, A₁A₃ 30, A₂A₂ 15, A₂A₃ 15, A₃A₃ 10명(모두 100명)입니다. A₁의 빈도는? 소수로 쓰세요.

진화는 대립유전자 빈도의 변화

집단 유전학에서 진화는 세대에 따라 유전자풀의 대립유전자 빈도가 변하는 것으로 정의합니다. 개체는 진화하지 않고 집단이 진화합니다.

X 염색체 유전자는 남자가 1개, 여자가 2개를 가지므로 대립유전자 수를 셀 때 이 점을 반영해야 합니다.

남자 100명(Xᴬ 80, Xᵃ 20)과 여자 100명(XᴬXᴬ 64, XᴬXᵃ 32, XᵃXᵃ 4)이면 X 대립유전자는 100 + 200 = 300개이고, a는 20 + 32 + 2 × 4 = 60개라 q = 0.2입니다.

문제 7

어떤 집단에서 a의 빈도가 한 세대 만에 0.3에서 0.25로 바뀌었습니다. 빈도 변화량(나중 − 처음)은? 소수로 쓰세요.

문제 8

남자 100명(Xᴬ 80명, Xᵃ 20명)과 여자 100명(XᴬXᴬ 64명, XᴬXᵃ 32명, XᵃXᵃ 4명)인 집단에서 Xᵃ의 빈도는? 소수로 쓰세요.

정리

유전자풀에서 대립유전자 빈도는 p + q = 1이고, 개체 N명이면 대립유전자는 2N개입니다.

p = f(AA) + f(Aa)/2이며, 공동 우성이면 표현형으로 바로 셀 수 있습니다. 대립유전자 빈도만으로는 유전자형 빈도를 알 수 없습니다.

진화는 대립유전자 빈도의 변화입니다. X 연관 유전자는 남자 1개, 여자 2개로 셉니다.

문제 9

AA 50명, Aa 100명, aa 50명인 집단에서 a의 빈도는? 소수로 쓰세요.

문제 10

500명인 집단에서 a의 빈도가 0.4입니다. 집단 전체의 a 대립유전자는 몇 개인가요?

문제 11

p = f(AA) + f(Aa)/2가 성립하는 이유를 설명하세요.

문제 12

대립유전자 빈도가 같아도 유전자형 빈도는 다를 수 있음을 예를 들어 설명하세요.
