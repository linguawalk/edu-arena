개체군 크기 추정

모두 셀 수 없을 때

개체군은 같은 지역에 사는 같은 종의 무리입니다. 움직이지 않는 식물은 방형구(정해진 넓이의 틀)를 여러 곳에 놓고 세어 밀도를 구한 뒤 전체 넓이를 곱합니다.

움직이는 동물은 표지–재포획법을 씁니다. 처음 M마리를 잡아 표지하고 풀어 준 뒤, 다시 n마리를 잡아 그중 표지된 개체 m마리를 셉니다. 표지 비율이 전체와 같다고 보면 m/n = M/N이므로 N = Mn/m입니다.

이 방법은 표지가 떨어지지 않고, 표지된 개체가 잘 섞이며, 그사이 출생·사망·이주가 없다고 가정합니다.

문제 1

연못에서 붕어 60마리를 잡아 표지하고 풀어 준 뒤 다시 50마리를 잡았더니 10마리가 표지되어 있었습니다. 추정 개체 수는?

문제 2

넓이 1 m²인 방형구 10개에서 민들레를 모두 45포기 셌습니다. 넓이 2000 m²인 풀밭 전체의 민들레는 약 몇 포기인가요?

가정이 깨지면

표지가 떨어지면 재포획 때 표지된 개체가 적게 세어져 m이 작아지고 N이 실제보다 크게 추정됩니다.

표지된 개체가 덫을 피하게 되면(덫 기피) 역시 m이 작아져 과대 추정, 덫에 끌리면(덫 선호) 과소 추정이 됩니다.

두 번 조사 사이에 새로 태어난 개체가 들어오면 표지되지 않은 개체가 늘어 과대 추정이 됩니다.

예제

들쥐 120마리를 표지해 풀어 주고 일주일 뒤 80마리를 잡았더니 16마리가 표지되어 있었습니다. 추정 개체 수와, 표지 개체 4마리가 표지를 잃었다면 실제에 가까운 값을 구하세요.

  1. N = 120 × 80/16 = 600마리입니다.
  2. 표지를 잃은 4마리도 사실은 표지 개체이므로 m은 16 + 4 = 20이어야 합니다.
  3. N = 120 × 80/20 = 480마리입니다.
  4. 표지 소실을 무시하면 600으로 과대 추정됩니다.

답: 600마리(과대), 약 480마리

문제 3

나비 200마리를 표지해 풀어 주고 다시 150마리를 잡았더니 25마리가 표지되어 있었습니다. 추정 개체 수는?

문제 4

표지된 개체가 덫을 피하게 되면 표지–재포획법의 추정값은? ① 실제보다 작다 ② 실제보다 크다 ③ 영향 없다

밀도와 분포

개체군 밀도 = 개체 수/넓이(또는 부피)입니다. 개체들이 퍼져 있는 방식에는 고른 분포(세력권), 무작위 분포, 몰린 분포(무리, 자원이 몰린 곳)가 있습니다.

방형구 조사에서 방형구마다 개체 수의 분산과 평균을 비교하면 분포를 짐작할 수 있습니다. 분산/평균이 1에 가까우면 무작위, 1보다 크면 몰린 분포, 1보다 작으면 고른 분포입니다.

몰린 분포는 방형구 수가 적으면 추정 오차가 커집니다.

문제 5

방형구 5개에서 센 개체 수가 2, 4, 3, 5, 6입니다. 방형구 하나(1 m²)당 평균 밀도는 몇 개체/m²인가요?

문제 6

방형구 조사에서 개체 수의 분산/평균이 3.2였습니다. 이 개체군의 분포는? ① 몰린 분포 ② 고른 분포 ③ 무작위 분포

문제 7

첫 조사에서 표지한 개체 수 M, 두 번째에 잡은 수 n, 그중 표지 개체 m이 각각 50, 40, 8일 때 추정 개체 수는?

정리

방형구법: 밀도 = 센 개체 수/방형구 넓이 합, 전체 = 밀도 × 넓이.

표지–재포획법: N = Mn/m. 가정: 표지 유지, 고르게 섞임, 출생·사망·이주 없음.

표지 소실·덫 기피·출생 유입은 과대 추정, 덫 선호는 과소 추정. 분산/평균 > 1 몰린, ≈ 1 무작위, < 1 고른 분포.

문제 8

거북 30마리를 표지해 풀어 주고 다시 45마리를 잡았더니 6마리가 표지되어 있었습니다. 그사이 거북 수는 변하지 않았다면 추정 개체 수는?

문제 9

넓이 0.25 m²인 방형구 8개에서 모두 36포기를 셌습니다. 넓이 500 m²인 땅 전체의 포기 수는?

문제 10

표지–재포획법의 식 N = Mn/m이 성립하는 이유와 필요한 가정을 쓰세요.

문제 11

두 조사 사이에 새끼가 많이 태어나 개체군에 섞이면 표지–재포획법의 추정이 어떻게 달라지는지 쓰세요.
