이항분포의 정규근사

확률과 통계 · 6. 연속확률분포 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

정규분포로 근사하기

n이 충분히 크면 이항분포 B(n, p)는 평균 np, 분산 np(1 − p)인 정규분포에 가까워집니다.

왜 정규분포에 가까워질까요? 이항분포는 독립적인 성공(1)과 실패(0)를 n번 더한 것입니다. 많은 독립적인 값을 더하면 그 합의 분포는 원래 분포와 관계없이 종 모양에 가까워진다는 성질(중심극한정리)이 있습니다. 그래서 n이 크면 복잡한 nCr 계산 대신 정규분포표로 확률을 구할 수 있습니다.

문제 1

X ~ B(100, 1/2)일 때 근사하는 정규분포의 평균은?

문제 2

그 표준편차는?

근사해서 계산하기

평균과 표준편차를 구해 표준화한 뒤 표의 값을 씁니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

근사할 정규분포의 평균과 분산은 이항분포의 평균 np와 분산 np(1 − p)를 그대로 씁니다. 표준편차는 √(np(1 − p))입니다. 그다음은 앞 레슨의 표준화와 똑같이 계산합니다. 표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772.

예제

동전을 100번 던질 때 앞면이 40번 이상 60번 이하일 확률의 근삿값을 구하세요.

  1. X ~ B(100, 1/2): 평균 50, 표준편차 5
  2. Z = (40 − 50)/5 = −2, Z = (60 − 50)/5 = 2
  3. P(−2 ≤ Z ≤ 2) = 2 × 0.4772
  4. = 0.9544

답: 0.9544

문제 4

주사위의 예

주사위를 180번 던질 때 1의 눈이 나오는 횟수 X는 B(180, 1/6)을 따릅니다.

주사위를 180번 던지면 1의 눈이 평균 30번 나오지만 매번 정확히 30번은 아닙니다. 표준편차 5는 '대개 25번에서 35번 사이'라는 흩어짐을 알려 줍니다. 40번 이상은 평균에서 2σ 이상 벗어난 드문 일(약 2.3%)입니다.

예제

주사위를 720번 던질 때 6의 눈이 130번 이상 나올 확률의 근삿값을 구하세요.

  1. X ~ B(720, 1/6): 평균 120, 분산 720 × 1/6 × 5/6 = 100, 표준편차 10
  2. Z = (130 − 120)/10 = 1
  3. P(Z ≥ 1) = 0.5 − 0.3413
  4. = 0.1587

답: 0.1587

근사의 조건

np와 n(1 − p)가 모두 충분히 클 때(대략 5 이상) 근사가 잘 맞습니다.

n이 커도 p가 0이나 1에 아주 가까우면 분포가 한쪽으로 치우쳐 종 모양이 되기 어렵습니다. 그래서 np와 n(1 − p)가 모두 충분히 커야 합니다. 이 조건이 맞지 않으면 원래의 이항분포로 계산해야 합니다.

정리

이항분포 → 평균·표준편차 → 표준화 → 표 순서로 계산합니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

이항분포의 정규근사는 여론조사, 품질 관리, 의약품 시험처럼 많은 수를 다루는 실제 통계의 기초입니다. 다음 챕터의 통계적 추정도 이 아이디어를 바탕으로 합니다. 표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772.

예제

어떤 씨앗의 발아율이 0.75입니다. 300개를 심을 때 발아하는 씨앗이 210개 이하일 확률의 근삿값은?

  1. X ~ B(300, 0.75): 평균 225, 분산 300 × 0.75 × 0.25 = 56.25, 표준편차 7.5
  2. Z = (210 − 225)/7.5 = −2
  3. P(Z ≤ −2) = 0.5 − 0.4772
  4. = 0.0228

답: 0.0228
