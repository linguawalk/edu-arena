규칙을 추측하기

작은 경우를 몇 개 계산해 규칙을 추측하고, 수학적 귀납법으로 그 추측을 증명합니다.

1 = 1, 1 + 3 = 4, 1 + 3 + 5 = 9처럼 홀수의 합은 제곱수가 됩니다.

수학의 많은 공식은 이렇게 발견됩니다. 작은 경우에서 규칙을 추측하는 것을 귀납적 추론이라 하고, 그 추측이 모든 경우에 맞는지 확인하는 것이 수학적 귀납법입니다. 추측만으로는 틀릴 수 있으므로 반드시 증명이 필요합니다.

예제

1, 1 + 2, 1 + 2 + 4, 1 + 2 + 4 + 8, …을 계산해 규칙을 추측하세요.

  1. 1 = 2 − 1
  2. 3 = 4 − 1, 7 = 8 − 1
  3. 15 = 16 − 1
  4. 추측: 1 + 2 + … + 2ⁿ⁻¹ = 2ⁿ − 1 (등비수열의 합 공식과 일치)

답: 2ⁿ − 1

문제 2

1³ + 2³ + … + n³ = (1 + 2 + … + n)²을 이용하면 n = 5일 때 합은?

몇 개만 확인하면 안 되는 이유

n² + n + 41은 n = 1부터 39까지 모두 소수지만 n = 40이면 41²이 되어 소수가 아닙니다.

39개의 사례가 모두 맞아도 40번째에서 틀릴 수 있다는 것이 이 예의 교훈입니다. n = 40이면 40² + 40 + 41 = 40(40 + 1) + 41 = 41 × 41이 되어 합성수입니다. 유한 개를 확인하는 것은 증명이 아니라 추측의 근거일 뿐입니다.

문제 4

도형에서 찾는 귀납

n각형의 대각선은 n(n − 3)/2개입니다. 꼭짓점이 하나 늘 때 대각선이 몇 개 늘어나는지 보면 점화식이 됩니다.

왜 n(n − 3)/2일까요? 한 꼭짓점에서 자기 자신과 이웃한 두 꼭짓점을 뺀 n − 3개의 꼭짓점으로 대각선을 그을 수 있고, n개의 꼭짓점 모두에서 세면 각 대각선이 두 번씩 세어지므로 2로 나눕니다.

예제

n각형의 대각선 수 aₙ에 대해 aₙ₊₁ − aₙ을 구하세요.

  1. 꼭짓점을 하나 더하면 새 꼭짓점에서 n − 2개의 대각선이 새로 생깁니다.
  2. 원래 변 하나가 대각선으로 바뀌어 1개 더 생깁니다.
  3. aₙ₊₁ − aₙ = n − 1
  4. 확인: a₄ = 2, a₅ = 5 (차 3 = 4 − 1)

답: n − 1

악수 문제

n명이 서로 한 번씩 악수하면 n(n − 1)/2번입니다. 한 명이 새로 오면 그 사람이 기존 n명과 악수하므로 n번 늘어납니다.

악수 문제는 n명 중 2명을 고르는 조합 nC2와 같습니다. 점화식으로 보면 aₙ₊₁ = aₙ + n이고, a₁ = 0에서 시작해 더하면 aₙ = 0 + 1 + 2 + … + (n − 1) = n(n − 1)/2가 됩니다. 같은 문제를 두 가지 방법으로 푼 것입니다.

증명 단계 채우기

n = k일 때의 식을 그대로 쓰고, 새로 더하거나 곱해지는 부분만 계산합니다.

증명의 빈칸 채우기 문제는 결국 식 변형 연습입니다. 새로 더해지거나 곱해지는 부분을 정확히 계산한 뒤, 목표 식(n = k + 1을 넣은 식)과 같아지도록 묶거나 통분합니다. 통분한 분자가 인수분해되는 경우가 많습니다.

예제

1/(1·2) + … + 1/(k(k + 1)) = k/(k + 1)을 가정할 때 n = k + 1일 때의 식을 정리하세요.

  1. 좌변 = k/(k + 1) + 1/((k + 1)(k + 2))
  2. 통분: (k(k + 2) + 1)/((k + 1)(k + 2))
  3. 분자 k² + 2k + 1 = (k + 1)²
  4. = (k + 1)/(k + 2)이므로 n = k + 1일 때도 성립

답: (k + 1)/(k + 2)
