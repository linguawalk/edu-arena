|x|와 거리

|x|는 수직선에서 x와 0 사이의 거리입니다.

a > 0일 때 |x| < a ⇔ −a < x < a, |x| > a ⇔ x < −a 또는 x > a

왜 이렇게 될까요? |x| < a는 '0에서의 거리가 a보다 가깝다'는 뜻이라 −a와 a 사이의 범위입니다. |x| > a는 '거리가 a보다 멀다'는 뜻이라 양쪽 바깥 범위입니다.

문제 3

|x| ≥ 2의 해는 x ≤ −2 또는 x ≥ ＿＿＿

|x − a| 꼴

|x − a|는 x와 a 사이의 거리입니다. |x − a| < b는 a에서 거리가 b보다 가까운 범위입니다.

|x − a| < b를 풀 때는 −b < x − a < b로 바꾼 뒤 각 변에 a를 더합니다. 수직선에서 a를 중심으로 양쪽 b만큼 펼친 구간이 해입니다.

예제

|x + 2| ≥ 3을 푸세요.

  1. |x − (−2)| ≥ 3: −2에서의 거리가 3 이상
  2. x + 2 ≤ −3 또는 x + 2 ≥ 3
  3. x ≤ −5 또는 x ≥ 1

답: x ≤ −5 또는 x ≥ 1

문제 6

|2x + 1| ≤ 5의 해는 ＿＿＿ ≤ x ≤ ＿＿＿

절댓값이 두 개일 때

절댓값 안이 0이 되는 x를 기준으로 범위를 나누고, 각 범위에서 절댓값을 벗겨 풉니다.

왜 기준점에서 나눌까요? 절댓값은 안의 값이 양수인지 음수인지에 따라 벗기는 방법이 달라집니다. 안이 0이 되는 점을 경계로 범위를 나누면 각 범위에서 부호가 정해져 절댓값을 없앨 수 있습니다.

예제

|x| + |x − 4| < 6을 푸세요.

  1. x < 0일 때: −x − x + 4 < 6 → −2x < 2 → x > −1 → −1 < x < 0
  2. 0 ≤ x < 4일 때: x − x + 4 = 4 < 6 → 항상 성립 → 0 ≤ x < 4
  3. x ≥ 4일 때: 2x − 4 < 6 → x < 5 → 4 ≤ x < 5
  4. 합치면 −1 < x < 5

답: −1 < x < 5

문제 9

|x| + |x − 2| ≤ 2를 만족하는 정수는 몇 개일까요?

해에서 거꾸로

|x − a| < b의 해는 a − b < x < a + b이므로, 해의 가운데가 a, 폭의 절반이 b입니다.

해의 범위 p < x < q를 보면 가운데 (p + q)/2가 기준점 a, 폭의 절반 (q − p)/2가 b입니다. 거꾸로 읽으면 모르는 계수를 쉽게 찾을 수 있습니다.

정리

절댓값은 '거리'로 읽으면 부등식의 해를 수직선에서 바로 떠올릴 수 있습니다.

|x − a| + |x − b|는 x에서 a까지의 거리와 b까지의 거리의 합입니다. x가 a와 b 사이에 있으면 이 합은 항상 |a − b|로 가장 작습니다.

예제

|x − a| ≤ 3을 만족하는 정수가 정확히 7개일 때, 정수 a에 대해 이 범위의 정수의 합을 a로 나타내세요.

  1. a − 3 ≤ x ≤ a + 3
  2. 정수 a − 3, …, a + 3의 7개
  3. 가운데가 a이므로 합은 7a

답: 7a
