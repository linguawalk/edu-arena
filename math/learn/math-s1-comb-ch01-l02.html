순서 없이 고르기

서로 다른 n개에서 순서 없이 k개를 고르는 방법은 C(n, k) = n!/(k!(n − k)!)가지입니다.

순서 있게 고르는 n!/(n − k)!가지에서, 같은 k개를 늘어놓는 k!가지를 한 번으로 보기 때문입니다.

C(n, k) = C(n, n − k)도 바로 알 수 있습니다. k개를 고르는 것은 남길 n − k개를 고르는 것과 같기 때문입니다. 이처럼 식을 계산하지 않고 '무엇을 세는가'로 등식을 증명하는 방법을 조합적 증명이라고 하며, 올림피아드에서 매우 자주 씁니다.

문제 2

격자 위의 최단 경로

격자에서 (0, 0)에서 (a, b)까지 오른쪽과 위쪽으로만 가는 최단 경로는 C(a + b, a)개입니다.

경로는 '오른쪽' a번과 '위쪽' b번을 늘어놓은 것이므로, a + b번의 이동 중 오른쪽이 될 a번을 고르면 정해집니다.

반드시 지나야 하는 점이 있으면 두 구간으로 나누어 곱하고, 지나면 안 되는 점이 있으면 전체에서 그 점을 지나는 경로를 뺍니다. 경로를 문자열로 바꾸는 이 생각은 레슨 4의 일대일대응과 챕터 4의 카탈랑 수에서 다시 나옵니다.

예제

(0, 0)에서 (4, 4)까지의 최단 경로 중 (2, 2)를 지나지 않는 것의 개수를 구하세요.

  1. 전체 최단 경로는 C(8, 4) = 70개입니다.
  2. (2, 2)를 지나는 경로는 (0, 0)→(2, 2)가 C(4, 2) = 6개, (2, 2)→(4, 4)가 6개이므로 36개입니다.
  3. 지나지 않는 경로는 70 − 36입니다.
  4. 따라서 34개입니다.

답: 34

파스칼의 삼각형

C(n, k) = C(n − 1, k − 1) + C(n − 1, k)입니다. n명 중 k명을 고를 때 특정한 한 사람 A가 뽑히는 경우와 뽑히지 않는 경우로 나누면 바로 나옵니다.

A가 뽑히면 나머지 n − 1명 중 k − 1명을, 뽑히지 않으면 n − 1명 중 k명을 고릅니다.

이 등식이 파스칼의 삼각형을 만듭니다. 각 줄의 합은 C(n, 0) + ⋯ + C(n, n) = 2ⁿ인데, n개 원소 집합의 부분집합을 크기별로 센 것이기 때문입니다. kC(n, k)의 합은 n2ⁿ⁻¹로, '위원회를 뽑고 그중 위원장을 정하는 방법'을 두 순서로 세어 증명합니다.

문제 7

1 × C(5, 1) + 2 × C(5, 2) + ⋯ + 5 × C(5, 5)의 값은?

정리

C(n, k) = n!/(k!(n − k)!)는 n개에서 k개를 순서 없이 고르는 수이고, C(n, k) = C(n, n − k)입니다.

격자의 최단 경로는 C(a + b, a)이고, 지나야 할 점은 곱으로, 지나면 안 될 점은 빼기로 처리합니다.

파스칼 등식 C(n, k) = C(n − 1, k − 1) + C(n − 1, k), Σ C(n, k) = 2ⁿ, Σ kC(n, k) = n2ⁿ⁻¹은 모두 '같은 것을 두 방법으로 세기'로 증명합니다.
