타원의 뜻

두 초점까지의 거리의 합

평면 위의 두 점 F, F′까지의 거리의 합이 일정한 점들의 모임을 타원이라고 합니다. F, F′은 초점입니다.

끈의 양 끝을 두 핀에 고정하고 연필로 팽팽하게 당기며 돌리면 타원이 그려집니다.

끈으로 그리는 방법이 정의를 그대로 보여 줍니다. 끈의 길이가 일정하므로 연필에서 두 핀까지의 거리의 합이 항상 끈의 길이와 같습니다. 두 핀이 가까울수록 원에 가깝고, 멀수록 납작한 타원이 됩니다. 두 핀이 한 점에 겹치면 원이 됩니다.

문제 2

그 타원 위의 점 P와 F 사이의 거리가 3이면 PF′은?

장축, 단축, 초점

장축의 길이를 2a, 단축의 길이를 2b, 두 초점 사이의 거리를 2c라 하면 a² = b² + c²입니다.

왜 a² = b² + c²일까요? 단축의 끝점 B는 두 초점에서 같은 거리에 있으므로 각각 a입니다(합이 2a). 중심 O, 초점 F, 단축의 끝점 B가 만드는 직각삼각형에서 OF = c, OB = b, FB = a이므로 피타고라스 정리로 a² = b² + c²입니다. 원과 달리 빗변이 a라는 점에 주의합니다.

예제

장축의 길이가 26, 두 초점 사이의 거리가 24인 타원의 단축의 길이를 구하세요.

  1. 2a = 26에서 a = 13, 2c = 24에서 c = 12
  2. b² = a² − c² = 169 − 144 = 25
  3. b = 5
  4. 단축의 길이 2b = 10

답: 10

끈으로 그리기

끈의 길이가 장축의 길이 2a, 두 핀 사이의 거리가 2c입니다.

끈 그리기로 장축과 초점을 바로 연결할 수 있습니다. 연필이 장축의 끝에 있을 때 끈은 두 핀 사이를 지나 한쪽으로 늘어져, 장축의 길이가 끈의 길이와 같아집니다. 그래서 끈의 길이 = 2a, 핀 사이의 거리 = 2c입니다.

문제 7

장축의 길이가 12인 타원의 a의 값은?

이심률

e = c/a를 이심률이라 합니다. 타원은 0 < e < 1이고, e가 0에 가까울수록 원에 가깝습니다.

이심률 e = c/a는 타원이 얼마나 납작한지를 나타내는 수입니다. c = 0이면 두 초점이 중심에 겹쳐 원(e = 0)이 되고, c가 a에 가까워질수록 납작해집니다. 지구 궤도의 이심률은 약 0.017로 거의 원에 가깝습니다.

예제

단축의 길이가 6, 이심률이 4/5인 타원의 장축의 길이를 구하세요.

  1. b = 3, c/a = 4/5에서 c = 4a/5
  2. a² = b² + c² = 9 + 16a²/25
  3. 9a²/25 = 9에서 a² = 25, a = 5
  4. 장축의 길이 10

답: 10

문제 9

두 초점이 한 점으로 겹친 경우(원)의 이심률은?

정리

타원 위 어디에서든 두 초점까지 거리의 합은 2a로 같습니다.

타원 문제는 대부분 세 가지 사실로 풀립니다: 두 초점까지 거리의 합은 2a, a² = b² + c², 이심률 e = c/a. 그림에 a, b, c를 표시하고 이 관계를 적용하면 됩니다. 특히 중심, 초점, 단축의 끝이 만드는 직각삼각형을 그려 두면 편리합니다.

예제

두 초점이 F, F′이고 장축의 길이가 10, FF′ = 8인 타원 위의 점 P에서 PF = 2일 때 삼각형 PFF′의 둘레와 PF′을 구하세요.

  1. PF + PF′ = 10이므로 PF′ = 8
  2. 둘레 = PF + PF′ + FF′
  3. = 10 + 8
  4. = 18

답: PF′ = 8, 둘레 18
