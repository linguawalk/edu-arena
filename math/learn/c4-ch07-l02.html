오목·볼록과 변곡점

미적분 · 7. 미분법의 활용 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

볼록

어떤 구간에서 f″(x) > 0이면 그래프는 아래로 볼록, f″(x) < 0이면 위로 볼록입니다.

왜 f″ > 0이면 아래로 볼록일까요? f″ > 0이면 기울기 f′이 증가하므로, 왼쪽에서 오른쪽으로 갈수록 접선이 점점 가팔라집니다(또는 덜 가파르게 내려갑니다). 그러면 곡선은 그릇처럼 아래로 볼록해집니다. 반대로 f″ < 0이면 기울기가 줄어들어 뒤집힌 그릇 모양(위로 볼록)이 됩니다.

문제 1

y = x²의 그래프는 아래로 볼록할까요? (그렇다 1, 아니다 0)

문제 2

y = −x²의 그래프는 아래로 볼록할까요? (그렇다 1, 아니다 0)

변곡점

볼록한 방향이 바뀌는 점을 변곡점이라고 합니다. f″(a) = 0이고 그 양쪽에서 f″의 부호가 바뀌면 (a, f(a))가 변곡점입니다.

변곡점은 곡선이 휘어지는 방향이 바뀌는 점입니다. 자동차로 S자 도로를 달릴 때 핸들을 왼쪽으로 꺾다 오른쪽으로 꺾기 시작하는 순간과 같습니다. 변곡점에서는 접선이 곡선을 뚫고 지나가는 특징이 있습니다.

예제

y = x³ − 6x² + 5의 볼록한 방향과 변곡점을 조사하세요.

  1. y″ = 6x − 12
  2. x < 2: y″ < 0 → 위로 볼록 / x > 2: y″ > 0 → 아래로 볼록
  3. x = 2에서 부호가 바뀌므로 변곡점
  4. y(2) = 8 − 24 + 5 = −11, 변곡점 (2, −11)

답: 변곡점 (2, −11)

변곡점의 개수

f″(x) = 0의 근 중 부호가 실제로 바뀌는 곳만 변곡점입니다. y = x⁴은 f″(0) = 0이지만 변곡점이 아닙니다.

f″(a) = 0은 변곡점의 필요조건일 뿐입니다. y = x⁴은 f″(x) = 12x²이라 x = 0에서 0이지만, 양쪽 모두 f″ > 0이라 계속 아래로 볼록하므로 변곡점이 아닙니다. f′ = 0과 극값의 관계와 똑같은 구조입니다.

예제

y = x⁵의 변곡점을 조사하세요.

  1. y″ = 20x³
  2. x < 0: y″ < 0, x > 0: y″ > 0
  3. x = 0에서 부호가 바뀌므로 변곡점 (0, 0)
  4. 비교: y = x⁴은 y″ = 12x² ≥ 0이라 변곡점이 없음

답: 변곡점 (0, 0)

변곡점 조건으로 계수 찾기

변곡점 (p, q)가 주어지면 f″(p) = 0과 f(p) = q, 두 식을 세웁니다.

변곡점 (p, q)라는 조건에는 두 가지 정보가 들어 있습니다. 변곡점이라는 것에서 f″(p) = 0, 그래프 위의 점이라는 것에서 f(p) = q입니다. 모르는 계수가 두 개이면 이 두 식으로 구할 수 있습니다. 삼차함수의 변곡점은 그래프의 대칭의 중심이기도 합니다.

예제

y = x³ + ax² + bx + c의 변곡점이 (−1, 2)이고 그 점에서 접선의 기울기가 −3일 때 a, b, c를 구하세요.

  1. y″ = 6x + 2a, y″(−1) = 0에서 a = 3
  2. y′ = 3x² + 6x + b, y′(−1) = 3 − 6 + b = −3에서 b = 0
  3. y(−1) = −1 + 3 + 0 + c = 2에서 c = 0
  4. y = x³ + 3x²

답: a = 3, b = 0, c = 0

문제 10

정리

f′로 증가·감소, f″로 볼록과 변곡점을 판단합니다.

f′과 f″을 함께 쓰면 그래프의 모양을 네 가지로 나눌 수 있습니다: 증가하며 아래로 볼록(점점 가파르게 올라감), 증가하며 위로 볼록(점점 완만하게 올라감), 감소하며 아래로 볼록, 감소하며 위로 볼록. 이 조합이 그래프의 개형을 결정합니다.
