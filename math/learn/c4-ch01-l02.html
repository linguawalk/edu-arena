극한의 성질

극한이 있으면 합, 차, 곱, 몫(분모의 극한 ≠ 0)의 극한은 각 극한의 합, 차, 곱, 몫입니다.

다항함수는 x = a를 넣은 값이 극한입니다.

극한의 성질 덕분에 복잡한 식을 작은 조각으로 나눠 각각의 극한을 구한 뒤 합치면 됩니다. 다만 이 성질은 각 극한이 '존재할 때'만 쓸 수 있고, 몫의 경우 분모의 극한이 0이 아니어야 합니다. 분모가 0으로 가면 인수분해나 유리화가 필요합니다.

문제 1

lim(x→2) (x² + 3x)의 값은?

문제 2

lim f(x) = 3, lim g(x) = −2일 때 lim (2f(x) − g(x))의 값은?

문제 3

같은 조건에서 lim f(x)g(x)의 값은?

0/0 꼴: 인수분해

분모, 분자가 모두 0에 가까워지면 인수분해해 공통인수를 약분한 뒤 극한을 구합니다.

0/0 꼴은 '분모와 분자가 함께 0에 가까워지는 속도의 비'를 묻는 것입니다. 분모와 분자에 공통인 인수 (x − a)가 있기 때문에 둘 다 0이 되므로, 그 인수를 약분하면 0이 되는 원인이 사라져 극한을 구할 수 있습니다. 약분은 x ≠ a일 때만 가능하지만 극한은 x ≠ a인 값만 보므로 문제없습니다.

예제

lim(x→2) (x² − 3x + 2)/(x² − 4)를 구하세요.

  1. x = 2를 넣으면 0/0
  2. 인수분해: (x − 1)(x − 2)/((x + 2)(x − 2)) = (x − 1)/(x + 2)
  3. x → 2이면 1/4
  4. 확인: x = 2.01이면 1.01/4.01 ≈ 0.252

답: 1/4

문제 6

lim(x→2) (x³ − 8)/(x − 2)의 값은?

0/0 꼴: 유리화

근호가 있으면 분모나 분자를 유리화해 약분합니다.

근호가 있으면 인수분해가 어렵습니다. 이때 (√A − B)(√A + B) = A − B²을 이용해 근호를 없애면 숨어 있던 공통인수가 드러납니다. 분모나 분자 중 근호가 있는 쪽의 켤레를 분모, 분자에 모두 곱합니다. 근호가 없는 쪽은 전개하지 말고 그대로 두어야 약분이 잘 보입니다.

예제

lim(x→3) (x − 3)/(√(x + 1) − 2)를 구하세요.

  1. 분모의 켤레 √(x + 1) + 2를 분모, 분자에 곱합니다.
  2. 분모: (x + 1) − 4 = x − 3
  3. 약분하면 √(x + 1) + 2
  4. x → 3이면 2 + 2 = 4

답: 4

문제 8

lim(x→1) (√x − 1)/(x − 1)의 값은? (기약분수로)

∞/∞ 꼴

x → ∞일 때는 분모의 최고차항으로 분모, 분자를 나눕니다.

분자 차수 < 분모 차수이면 0, 같으면 최고차항 계수의 비, 크면 발산입니다.

왜 최고차항으로 나눌까요? x가 한없이 커지면 최고차항이 나머지 항보다 압도적으로 커져서 식의 크기를 결정합니다. 분모의 최고차항으로 나누면 나머지 항들은 모두 0으로 가서, 결국 최고차항끼리의 비교만 남습니다.

문제 11

lim(x→∞) (x² + 1)/(3x² − x)의 값은? (기약분수로)

극한에서 계수 찾기

lim(x→1) (x² + ax + b)/(x − 1) = 3처럼 분모 → 0인데 극한이 있으면 분자도 0으로 가야 합니다.

왜 분자도 0으로 가야 할까요? 분모가 0으로 가는데 분자가 0이 아닌 수로 가면 분수의 절댓값이 한없이 커져 발산합니다. 극한이 유한한 값으로 존재하려면 분자도 반드시 0으로 가야 합니다. 이 조건으로 식 하나를 얻고, 약분한 뒤의 극한값으로 식 하나를 더 얻습니다.

예제

lim(x→2) (x² + ax + b)/(x − 2) = 5일 때 a, b를 구하세요.

  1. 분모 → 0이므로 분자 → 0: 4 + 2a + b = 0, 즉 b = −2a − 4
  2. 분자 = x² + ax − 2a − 4 = (x − 2)(x + a + 2)
  3. 약분 후 극한: 2 + a + 2 = 5에서 a = 1
  4. b = −6

답: a = 1, b = −6
