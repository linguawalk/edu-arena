함수의 연속

미적분 · 1. 함수의 극한 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

연속

함수 f(x)가 x = a에서 연속이려면 ① f(a)가 정의되고 ② 극한이 존재하며 ③ 그 극한이 f(a)와 같아야 합니다.

그래프로는 x = a에서 끊어지지 않는다는 뜻입니다.

왜 세 조건이 모두 필요할까요? ①이 없으면 그 점에 값이 없어 구멍이 생기고, ②가 없으면 양쪽이 서로 다른 높이로 향해 점프가 생기며, ③이 없으면 극한과 함숫값이 달라 한 점만 튀어나온 그래프가 됩니다. 세 조건이 모두 맞아야 연필을 떼지 않고 그릴 수 있습니다.

문제 1

f(x) = x²은 x = 1에서 연속일까요? (그렇다 1, 아니다 0)

문제 2

f(x) = 1/x는 x = 0에서 연속일까요? (그렇다 1, 아니다 0)

범위마다 식이 다른 함수

경계에서 좌극한, 우극한, 함숫값이 모두 같아야 연속입니다.

경계에서의 연속 조건은 '왼쪽 식으로 계산한 값 = 오른쪽 식으로 계산한 값 = 함숫값'입니다. 대부분 경계에서 두 식의 값을 같게 놓는 방정식 하나가 나오고, 이를 풀어 모르는 계수를 구합니다. 경계에서 등호가 어느 쪽 식에 붙어 있는지로 함숫값을 계산하는 식을 고릅니다.

예제

f(x) = ax + 1 (x < 2), x² − a (x ≥ 2)가 x = 2에서 연속일 때 a를 구하세요.

  1. 좌극한: 2a + 1
  2. 우극한 = 함숫값: 4 − a
  3. 연속이려면 2a + 1 = 4 − a
  4. 3a = 3, a = 1

답: a = 1

연속함수의 성질

연속함수끼리 더하고 빼고 곱한 함수, 분모가 0이 아닌 곳에서 나눈 함수는 연속입니다.

다항함수는 모든 실수에서 연속입니다.

연속함수의 성질은 극한의 성질에서 바로 나옵니다. 두 함수의 극한이 각각 함숫값과 같으면, 합이나 곱의 극한도 합이나 곱의 함숫값과 같습니다. 그래서 유리함수는 분모가 0이 되는 점에서만 불연속입니다.

예제

f(x) = (x + 2)/(x² − x − 6)이 불연속인 점을 모두 구하세요.

  1. 유리함수는 분모가 0인 곳에서만 불연속
  2. x² − x − 6 = (x − 3)(x + 2) = 0
  3. x = 3, x = −2
  4. 주의: x = −2에서 약분되어도 함숫값이 없으므로 불연속

답: x = −2, 3

최대·최소 정리

닫힌구간 [a, b]에서 연속인 함수는 그 구간에서 반드시 최댓값과 최솟값을 가집니다.

왜 '닫힌구간'이 중요할까요? 열린구간 (0, 1)에서 f(x) = x는 1에 한없이 가까워지지만 1이 되지는 않아 최댓값이 없습니다. 끝점을 포함하고 끊기지 않아야 가장 높은 점과 가장 낮은 점이 반드시 존재합니다.

예제

[0, 3]에서 f(x) = x² − 2x + 3의 최댓값과 최솟값을 구하세요.

  1. 닫힌구간에서 연속이므로 최댓값, 최솟값이 존재
  2. f(x) = (x − 1)² + 2, 꼭짓점 x = 1은 구간 안
  3. f(1) = 2, f(0) = 3, f(3) = 6
  4. 최댓값 6, 최솟값 2

답: 최댓값 6, 최솟값 2

문제 9

문제 10

정리

끊어질 수 있는 곳은 분모가 0인 곳, 식이 바뀌는 경계입니다. 그곳만 확인하면 됩니다.

연속성을 확인하는 요령은 '의심스러운 곳만 본다'입니다. 다항함수, 지수함수처럼 원래 연속인 함수들로 이루어진 식은 분모가 0이 되는 곳과 식이 바뀌는 경계에서만 끊어질 수 있습니다. 절댓값 |x − a|는 연속이지만 x = a에서 뾰족해질 뿐입니다.
