인수분해로 풀기

삼차 이상의 방정식은 인수정리와 조립제법으로 인수분해한 뒤 AB = 0을 이용합니다.

왜 인수분해를 할까요? 삼차 이상은 이차방정식의 근의 공식처럼 쉽게 쓸 수 있는 공식이 없습니다. 인수정리로 일차식을 하나씩 떼어 내면 결국 일차식과 이차식의 곱이 되어 풀 수 있습니다.

문제 2

x³ − 6x² + 11x − 6 = 0의 근은 1, 2, ＿＿＿

치환해서 풀기

x⁴ + ax² + b = 0은 x² = t로 놓으면 t에 대한 이차방정식이 됩니다.

t는 x²이므로 t < 0이면 실근이 생기지 않습니다.

왜 t < 0이면 실근이 없을까요? x² = t에서 x²은 항상 0 이상이므로 t가 음수이면 이를 만족하는 실수 x가 없습니다. t ≥ 0인 근 하나에서는 x = ±√t로 실근이 두 개씩 나옵니다.

예제

x³ − 2x² − x + 2 = 0을 푸세요.

  1. 상수항 2의 약수를 넣어 봅니다: f(1) = 1 − 2 − 1 + 2 = 0
  2. x − 1로 나누면 몫 x² − x − 2 = (x − 2)(x + 1)
  3. (x − 1)(x − 2)(x + 1) = 0
  4. x = −1, 1, 2

답: x = −1, 1, 2

문제 5

x⁴ − 3x² − 4 = 0의 실근은 몇 개일까요?

삼차방정식의 근과 계수

ax³ + bx² + cx + d = 0의 세 근을 α, β, γ라 하면

α + β + γ = −b/a, αβ + βγ + γα = c/a, αβγ = −d/a

이차방정식과 같은 원리입니다. ax³ + bx² + cx + d = a(x − α)(x − β)(x − γ)를 전개해 계수를 비교하면 세 식이 나옵니다. 부호가 +, −, +로 번갈아 바뀝니다.

예제

x⁴ − 13x² + 36 = 0의 실근을 모두 구하세요.

  1. x² = t로 놓으면 t² − 13t + 36 = 0
  2. (t − 4)(t − 9) = 0에서 t = 4 또는 9 (둘 다 0 이상)
  3. x² = 4에서 ±2, x² = 9에서 ±3

답: x = ±2, ±3

문제 8

두 근끼리 곱한 것의 합은?

x³ = 1의 허근 ω

x³ − 1 = (x − 1)(x² + x + 1)이므로 허근 ω는 ω² + ω + 1 = 0을 만족합니다.

ω³ = 1이므로 ω의 거듭제곱은 세 개씩 반복됩니다.

ω는 실수가 아니지만 ω³ = 1이라는 성질 덕분에 큰 거듭제곱을 쉽게 줄일 수 있습니다. 지수를 3으로 나눈 나머지만 보면 됩니다. ω² + ω + 1 = 0도 함께 쓰면 대부분의 식이 간단해집니다.

한 근이 주어질 때

주어진 근을 대입해 계수를 구한 뒤, 조립제법으로 나머지 근을 찾습니다.

한 근을 알면 인수정리로 (x − 근)이라는 인수를 떼어 낼 수 있습니다. 남은 이차식은 인수분해나 근의 공식으로 풀면 되므로, 삼차방정식이 이차방정식으로 줄어듭니다.

예제

ω가 x³ = 1의 허근일 때 ω²⁰ + ω¹⁰ + 1의 값을 구하세요.

  1. ω³ = 1이므로 지수를 3으로 나눈 나머지만 봅니다.
  2. 20 = 3 × 6 + 2 → ω²⁰ = ω², 10 = 3 × 3 + 1 → ω¹⁰ = ω
  3. ω² + ω + 1 = 0

답: 0
