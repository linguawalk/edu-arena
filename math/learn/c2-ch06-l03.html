데이터에 함수 맞추기

이 레슨 풀어 보기연습 문제에세이 과제

차이가 일정하면 일차함수

x가 1씩 늘 때 y가 일정하게 늘거나 줄면 일차함수로 나타낼 수 있습니다. 그 일정한 차이가 기울기입니다.

왜 차이가 일정하면 일차함수일까요? 일차함수 y = ax + b에서 x가 1 늘면 y는 항상 a만큼 늘기 때문입니다. 표에서 이웃한 y값의 차이(계차)가 모두 같으면 그 차이가 기울기 a입니다.

문제 1

x = 0, 1, 2, 3일 때 y = 5, 8, 11, 14입니다. 일차함수로 나타낼 때 기울기는?

문제 2

같은 규칙이면 x = 10일 때 y는?

차이의 차이가 일정하면 이차함수

y의 차이가 일정하지 않아도, 그 차이들의 차이가 일정하면 이차함수입니다.

이차함수 y = ax² + bx + c에서는 y의 차이가 일정하게 늘어납니다. 그래서 차이를 한 번 더 구하면(2차 계차) 일정한 값 2a가 나옵니다. 1, 4, 9, 16의 차이는 3, 5, 7, 그 차이는 2, 2입니다.

예제

x = 1, 2, 3, 4일 때 y = 3, 7, 13, 21입니다. 어떤 함수에 가까울까요?

  1. y의 차이: 4, 6, 8 (일정하지 않음)
  2. 차이의 차이: 2, 2 (일정)
  3. 이차함수 (실제로 y = x² + x + 1)

답: 이차함수

문제 3

x = 1, 2, 3, 4일 때 y = 1, 4, 9, 16입니다. 같은 규칙이면 x = 6일 때 y는?

문제 4

x = 1, 2, 3, 4일 때 y = 2, 5, 10, 17입니다. 같은 규칙이면 x = 5일 때 y는?

곱이 일정하면 반비례

x와 y의 곱이 늘 같으면 y = k/x로 나타낼 수 있습니다.

표에서 x × y를 모두 계산해 보는 것이 가장 빠른 판단법입니다. 모두 같으면 반비례이고, 그 곱이 y = k/x의 k입니다. x가 2배가 될 때 y가 1/2배가 되는지로도 확인할 수 있습니다.

예제

x = 2, 3, 4, 6일 때 y = 18, 12, 9, 6입니다. 관계를 식으로 나타내세요.

  1. xy를 계산: 36, 36, 36, 36
  2. 곱이 일정하므로 반비례
  3. y = 36/x

답: y = 36/x

문제 6

이 자료에서 일정한 xy의 값은?

비율이 일정하면 지수적 변화

x가 1씩 늘 때 y가 일정한 배수로 늘거나 줄면 지수적 변화입니다. 대수 코스에서 지수함수로 다시 배웁니다.

지수적 변화는 차이가 아니라 '비율'이 일정합니다. 1, 2, 4, 8은 차이가 1, 2, 4로 계속 커지지만 비율은 항상 2배입니다. 인구, 세균, 복리처럼 '몇 배씩' 늘어나는 현상이 여기에 속합니다.

문제 9

모델과 예측

자료에 맞는 함수를 찾으면 아직 재지 않은 값을 예측할 수 있습니다. 예측과 실제의 차이를 오차라고 합니다.

모델은 자료를 완벽하게 설명하지 못할 수도 있습니다. 예측값과 실제값의 차이(오차)가 작을수록 좋은 모델이며, 오차가 크면 다른 종류의 함수를 시도해 봅니다.

예제

x = 0, 1, 2일 때 y = 5, 15, 45입니다. x = 4일 때 y를 예측하세요.

  1. y의 비율: 15/5 = 3, 45/15 = 3 (일정)
  2. 지수적 변화: y = 5 × 3ˣ
  3. x = 4이면 5 × 81 = 405

답: 405
