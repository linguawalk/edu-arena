포물선 위의 점에서의 접선

포물선 y² = 4px 위의 점 (x₁, y₁)에서의 접선은 y₁y = 2p(x + x₁)입니다.

접선 공식은 음함수 미분(코스 4)으로 유도할 수 있습니다. y² = 4px의 양변을 x로 미분하면 2y × y′ = 4p이므로 점 (x₁, y₁)에서의 기울기는 2p/y₁입니다. 접선 y − y₁ = (2p/y₁)(x − x₁)을 정리하고 y₁² = 4px₁을 쓰면 y₁y = 2p(x + x₁)이 됩니다.

문제 1

y² = 4x 위의 점 (1, 2)에서의 접선은 y = x + ＿＿＿

문제 2

y² = 8x 위의 점 (2, 4)에서의 접선은 y = x + ＿＿＿

기울기가 주어진 접선

y² = 4px에 접하고 기울기가 m인 직선은 y = mx + p/m입니다.

기울기가 m인 접선은 y = mx + k로 놓고 y² = 4px에 대입해 판별식이 0이 되는 k를 구하면 k = p/m이 나옵니다. 공식으로 외워 두면 빠르지만, 잊었을 때는 판별식으로 언제든 다시 구할 수 있습니다.

예제

y² = 12x 위의 점 (3, −6)에서의 접선의 방정식을 구하세요.

  1. 4p = 12에서 p = 3
  2. 공식 y₁y = 2p(x + x₁): −6y = 6(x + 3)
  3. y = −x − 3
  4. 확인: x = 3이면 y = −6

답: y = −x − 3

문제 4

y² = 8x에 접하고 기울기가 1인 직선의 y절편은?

x² = 4py의 접선

x² = 4py 위의 점 (x₁, y₁)에서의 접선은 x₁x = 2p(y + y₁)입니다.

x² = 4py의 접선 공식은 y² = 4px의 공식에서 x와 y를 바꾼 것입니다. x² = 4py는 y = x²/(4p)로 쓸 수 있으므로 코스 4의 방법대로 미분해 기울기 x₁/(2p)를 구해도 같은 결과가 나옵니다.

예제

y² = 8x에 접하고 기울기가 2인 직선을 판별식으로 구하세요.

  1. y = 2x + k를 대입: (2x + k)² = 8x
  2. 4x² + (4k − 8)x + k² = 0
  3. D/4 = (2k − 4)² − 4k² = −16k + 16 = 0
  4. k = 1이므로 y = 2x + 1 (공식 p/m = 2/2 = 1과 같음)

답: y = 2x + 1

준선 위의 점에서 그은 두 접선

포물선의 준선 위의 점에서 그은 두 접선은 항상 서로 수직입니다.

준선 위의 점에서 그은 두 접선이 수직인 이유: 준선 위의 점 (−p, t)를 지나는 접선 y = mx + p/m에 대입하면 t = −pm + p/m, 즉 pm² + tm − p = 0입니다. 두 근(두 접선의 기울기)의 곱은 근과 계수의 관계에 의해 −p/p = −1입니다.

문제 8

그 두 접선 중 기울기가 양수인 것의 기울기는?

판별식으로 접할 조건

직선의 식을 포물선에 대입한 이차방정식의 판별식이 0이면 접합니다.

판별식 방법은 모든 이차곡선의 접선에 통하는 기본 방법입니다. 직선과 포물선을 연립한 이차방정식이 중근을 가지면 교점이 하나, 즉 접합니다(축에 평행한 직선은 제외). 공식을 모를 때도 이 방법으로 풀 수 있습니다. 코스 2의 원과 직선의 위치 관계와 같은 원리입니다.

예제

y² = 4x의 준선 위의 점 (−1, 2)에서 그은 두 접선의 기울기를 구하고 수직인지 확인하세요.

  1. 접선 y = mx + 1/m이 (−1, 2)를 지남: 2 = −m + 1/m
  2. m² + 2m − 1 = 0
  3. m = −1 ± √2
  4. 두 기울기의 곱 = −1이므로 수직

답: m = −1 ± √2, 수직
