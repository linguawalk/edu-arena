순간변화율

평균변화율에서 출발

x가 a에서 a + h까지 변할 때 평균변화율은 (f(a + h) − f(a))/h입니다.

평균변화율은 구간의 처음과 끝만 보는 '평균적인' 변화 속도입니다. 자동차가 2시간 동안 120km를 가면 평균 시속 60km이지만, 그 사이 속도계의 숫자는 계속 바뀝니다. 한 순간의 속도를 알고 싶다면 구간의 폭 h를 점점 줄여 가야 합니다.

문제 1

f(x) = x²에서 x가 1에서 3까지 변할 때 평균변화율은?

문제 2

f(x) = x²에서 x가 1에서 1.1까지 변할 때 평균변화율은?

미분계수

h → 0일 때 평균변화율의 극한을 x = a에서의 순간변화율 또는 미분계수라 하고 f′(a)로 씁니다.

f′(a) = lim(h→0) (f(a + h) − f(a))/h

h를 0으로 바로 놓으면 0/0이 되어 계산할 수 없습니다. 그래서 h가 0에 '한없이 가까워질 때'의 극한을 봅니다. 앞 챕터에서 배운 0/0 꼴의 극한이 바로 여기서 쓰입니다. 이 극한값이 존재하면 x = a에서 미분가능하다고 합니다.

예제

f(x) = x² − 3x일 때 정의를 이용해 f′(2)를 구하세요.

  1. f(2 + h) = (2 + h)² − 3(2 + h) = 4 + 4h + h² − 6 − 3h = −2 + h + h²
  2. f(2) = −2이므로 f(2 + h) − f(2) = h + h²
  3. h로 나누면 1 + h
  4. h → 0이면 f′(2) = 1

답: 1

문제 3

f(x) = x²일 때 f′(1)의 값은?

문제 4

f(x) = x²일 때 f′(3)의 값은?

정의로 계산하기

f(a + h) − f(a)를 전개하면 h로 나누어떨어지고, 남은 식에 h = 0을 넣습니다.

f(x) = x²에서 f(1 + h) − f(1) = 2h + h²이므로 h로 나누면 2 + h이고, h → 0이면 2입니다. 다항함수는 f(a + h) − f(a)를 전개하면 모든 항에 h가 곱해져 있어 항상 h로 약분됩니다. 약분한 뒤 남은 식에 h = 0을 넣으면 됩니다.

예제

f(x) = x³일 때 정의를 이용해 f′(1)을 구하세요.

  1. f(1 + h) = 1 + 3h + 3h² + h³
  2. f(1 + h) − f(1) = 3h + 3h² + h³
  3. h로 나누면 3 + 3h + h²
  4. h → 0이면 3

답: 3

순간 속도

위치가 s(t)일 때 시각 t = a에서의 순간 속도는 s′(a)입니다.

속도는 위치의 순간변화율입니다. 위치가 시간에 따라 어떻게 변하는지가 s(t)로 주어지면, 그 미분계수가 그 순간 속도계에 찍히는 값입니다. 같은 방법으로 속도의 순간변화율은 가속도가 됩니다. 물리에서 쓰는 속도와 가속도가 모두 미분으로 정의됩니다.

문제 9

s(t) = t² + 2t일 때 t = 3에서의 순간 속도는?

정의를 변형한 극한

lim(h→0) (f(a + 2h) − f(a))/h = 2f′(a), lim(h→0) (f(a + h) − f(a − h))/h = 2f′(a)

lim(x→a) (f(x) − f(a))/(x − a) = f′(a)

변형된 극한은 모두 정의 모양으로 맞추는 것이 핵심입니다. (f(a + 2h) − f(a))/h = 2 × (f(a + 2h) − f(a))/(2h)로 쓰면, 2h를 새로운 h로 볼 수 있어 뒤의 부분이 f′(a)가 됩니다. 분모의 변화량과 f 안의 변화량을 같게 맞춰 주면 됩니다.

예제

f′(2) = 4일 때 lim(h→0) (f(2 + 3h) − f(2 − h))/h를 구하세요.

  1. f(2)를 빼고 더해 둘로 나눕니다: {f(2 + 3h) − f(2)}/h − {f(2 − h) − f(2)}/h
  2. 첫째: 3 × {f(2 + 3h) − f(2)}/(3h) → 3f′(2) = 12
  3. 둘째: −{f(2 − h) − f(2)}/(−h) × (−1) → 둘째 항은 −(−f′(2)) = 4
  4. 합: 12 + 4 = 16

답: 16
