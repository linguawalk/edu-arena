확률의 덧셈정리

확률과 통계 · 3. 확률의 뜻 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

덧셈정리

P(A ∪ B) = P(A) + P(B) − P(A ∩ B). A와 B가 서로 배반이면 P(A ∪ B) = P(A) + P(B)입니다.

왜 P(A ∩ B)를 뺄까요? P(A)와 P(B)를 더하면 A와 B가 겹치는 부분이 두 번 더해집니다. 한 번만 세려고 겹친 부분을 한 번 뺍니다. 코스 1의 n(A ∪ B) = n(A) + n(B) − n(A ∩ B)를 전체 n(S)로 나눈 것과 같습니다. 배반이면 겹침이 없어 그냥 더합니다.

문제 1

P(A) = 0.5, P(B) = 0.4, P(A ∩ B) = 0.2일 때 P(A ∪ B)는?

문제 2

A, B가 서로 배반이고 P(A) = 1/3, P(B) = 1/4일 때 P(A ∪ B)는? (기약분수로)

배수의 확률

'a의 배수 또는 b의 배수'는 두 사건의 합사건이고, 겹치는 부분은 최소공배수의 배수입니다.

'2의 배수 또는 3의 배수'에서 6의 배수는 두 사건에 모두 들어 있어 두 번 세어집니다. 겹치는 부분은 두 수의 최소공배수의 배수이므로 그 확률을 한 번 뺍니다. 두 사건이 배반인지 먼저 확인하는 습관을 들이세요.

예제

1부터 50까지 중 하나를 고를 때 4의 배수 또는 6의 배수일 확률을 구하세요.

  1. 4의 배수 12개, 6의 배수 8개
  2. 겹침: 12의 배수 4개
  3. 12 + 8 − 4 = 16
  4. 확률 16/50 = 8/25

답: 8/25

문제 3

1부터 20까지의 카드 중 한 장을 뽑을 때 2의 배수 또는 3의 배수일 확률은? (기약분수로)

문제 4

주사위 두 개를 던질 때 눈의 합이 3 또는 11일 확률은? (기약분수로)

거꾸로 구하기

덧셈정리의 네 값 중 세 개를 알면 나머지 하나를 구할 수 있습니다. P(A ∩ Bᶜ) = P(A) − P(A ∩ B)

P(A ∩ Bᶜ)는 'A는 일어나고 B는 일어나지 않는' 확률로, 벤 다이어그램에서 A 중 B와 겹치지 않는 부분입니다. A 전체에서 겹친 부분을 빼면 되므로 P(A) − P(A ∩ B)입니다. 벤 다이어그램에 확률을 적어 넣으면 이런 문제를 쉽게 풀 수 있습니다.

예제

P(A) = 0.6, P(B) = 0.5, P(A ∪ B) = 0.8일 때 A와 B 중 정확히 하나만 일어날 확률은?

  1. P(A ∩ B) = 0.6 + 0.5 − 0.8 = 0.3
  2. A만: 0.6 − 0.3 = 0.3, B만: 0.5 − 0.3 = 0.2
  3. 정확히 하나: 0.3 + 0.2 = 0.5
  4. 다른 방법: P(A ∪ B) − P(A ∩ B) = 0.5

답: 0.5

문제 6

같은 조건에서 P(A ∩ Bᶜ)는?

세 사건과 같은 종류

세 사건의 합은 셋을 더하고, 둘씩 겹친 것을 빼고, 셋 모두 겹친 것을 더합니다.

같은 색을 뽑는 사건은 색깔별 사건의 합사건(서로 배반)입니다.

세 사건의 덧셈정리는 코스 1에서 배운 세 집합의 원소의 개수 공식과 같은 구조입니다. '같은 색'처럼 여러 경우 중 하나가 일어나는 사건은 각 경우가 서로 배반이므로 그냥 더하면 됩니다.

예제

빨간 공 3개, 파란 공 2개, 노란 공 2개 중 2개를 뽑을 때 두 공의 색이 다를 확률은?

  1. 전체 ₇C₂ = 21
  2. 같은 색: 빨강 ₃C₂ = 3, 파랑 1, 노랑 1 → 5 (서로 배반이라 더함)
  3. 다른 색 = 1 − 5/21
  4. = 16/21

답: 16/21

1부터 30까지 중 하나를 고를 때 2, 3, 5 중 적어도 하나의 배수일 확률은? (기약분수로)

문제 8

흰 공 2개, 검은 공 3개, 빨간 공 1개 중 2개를 뽑을 때 두 공의 색이 같을 확률은? (기약분수로)

정리

합사건은 '또는', 곱사건은 '그리고'입니다. 겹침을 한 번 빼는 것을 잊지 않습니다.

덧셈정리로 확률의 범위도 알 수 있습니다. P(A ∪ B) ≤ 1이므로 P(A ∩ B) ≥ P(A) + P(B) − 1이고, P(A ∩ B) ≤ P(A), P(B)입니다. 두 사건이 반드시 겹칠 수밖에 없는 최소한의 양을 구하는 문제에 씁니다.
