수학적 확률

각 근원사건이 일어날 가능성이 같을 때, 사건 A의 확률은 P(A) = n(A)/n(S)입니다.

수학적 확률의 핵심 조건은 '각 결과가 일어날 가능성이 같다'는 것입니다. 공정한 주사위의 여섯 눈은 모두 같은 가능성이므로 경우의 수의 비로 확률을 구할 수 있습니다. 가능성이 다른 결과들(예: 두 주사위의 눈의 합 2와 7)을 같은 무게로 세면 틀린 답이 나옵니다.

문제 1

주사위 한 개를 던질 때 짝수의 눈이 나올 확률은? (기약분수로)

문제 2

동전 두 개를 던질 때 모두 앞면이 나올 확률은? (기약분수로)

주사위 두 개

주사위 두 개의 표본공간은 36개의 순서쌍입니다. 조건에 맞는 순서쌍을 셉니다.

두 주사위의 눈의 합은 2부터 12까지 11가지이지만, 이 11가지는 가능성이 같지 않습니다. 합 7은 6가지 순서쌍으로, 합 2는 (1, 1) 하나로만 나오기 때문입니다. 그래서 반드시 가능성이 같은 36개의 순서쌍을 기준으로 셉니다.

예제

주사위 두 개를 던질 때 두 눈의 차가 3 이상일 확률을 구하세요.

  1. 차 3: (1,4), (2,5), (3,6)과 순서를 바꾼 것 → 6개
  2. 차 4: (1,5), (2,6)과 반대 → 4개, 차 5: (1,6)과 반대 → 2개
  3. 모두 12개
  4. 확률 12/36 = 1/3

답: 1/3

조합으로 세기

여러 개를 동시에 뽑을 때는 전체와 조건에 맞는 경우를 모두 조합으로 셉니다.

여러 개를 동시에 뽑을 때는 순서가 없으므로 전체도, 조건에 맞는 경우도 조합으로 셉니다. 순서를 세고 싶다면 분모와 분자를 모두 순열로 세어도 확률은 같습니다. 중요한 것은 분모와 분자를 같은 방식으로 세는 것입니다.

예제

빨간 공 4개, 파란 공 3개 중 3개를 뽑을 때 빨간 공 2개, 파란 공 1개일 확률은?

  1. 전체: ₇C₃ = 35
  2. 빨간 공 2개: ₄C₂ = 6, 파란 공 1개: ₃C₁ = 3
  3. 6 × 3 = 18
  4. 확률 18/35

답: 18/35

문제 7

5명 중 2명을 뽑을 때 A가 뽑힐 확률은? (기약분수로)

통계적 확률

같은 시행을 n번 반복해 사건 A가 r번 일어났을 때, n이 충분히 크면 상대도수 r/n을 A의 확률로 봅니다.

동전을 몇 번만 던지면 앞면의 비율이 1/2에서 크게 벗어날 수 있지만, 던지는 횟수를 늘릴수록 비율은 1/2에 가까워집니다(큰 수의 법칙). 압정처럼 가능성이 같은지 알 수 없는 경우에는 이렇게 실험으로 확률을 정합니다.

문제 10

어떤 사건의 확률이 0.3일 때 200번 시행하면 약 몇 번 일어날까요?

확률의 기본 성질

0 ≤ P(A) ≤ 1, P(S) = 1, P(∅) = 0

확률은 전체 중 일부의 비율이므로 0과 1 사이의 값입니다. 절대 일어나지 않는 사건은 0, 반드시 일어나는 사건은 1입니다. 계산 결과가 1을 넘거나 음수가 나오면 어딘가에서 잘못 센 것이므로 다시 확인합니다. 이것이 가장 간단한 검산 방법입니다.

예제

A, B, C, D 네 명을 일렬로 세울 때 A가 B보다 앞에 설 확률은?

  1. 전체 4! = 24
  2. A와 B의 순서만 보면 앞, 뒤가 대칭
  3. A가 앞인 경우 12가지
  4. 확률 1/2 (계산 없이 대칭으로도 알 수 있음)

답: 1/2
