f(a) = f(b)이면 a = b

함수 f가 단사라는 것은 f(a) = f(b)이면 a = b라는 뜻입니다. 전사라는 것은 공역의 모든 값이 어떤 x의 f(x)로 나온다는 뜻입니다.

f(f(x)) = x + 1이면 f는 단사입니다. f(a) = f(b)이면 f(f(a)) = f(f(b))이므로 a + 1 = b + 1, a = b입니다.

단사성을 알면 'f(무엇) = f(무엇)' 꼴의 식에서 f를 떼어 낼 수 있어 매우 강력합니다.

문제 1

f(f(x)) = x + 1인 함수 f에서 f(a) = f(b)이면 a − b는?

문제 2

f(a) = f(b)이면 언제나 a = b인 함수를 ＿＿＿ 함수라 합니다.

일차함수로 추측하기

f(f(x)) = 4x + 3처럼 오른쪽이 일차식이면 f(x) = ax + b로 두고 계수를 비교해 후보를 찾습니다. f(f(x)) = a(ax + b) + b = a²x + ab + b입니다.

a² = 4, ab + b = 3이므로 a = 2이면 b = 1, a = −2이면 b = −3입니다. 그래서 f(x) = 2x + 1, f(x) = −2x − 3이 해입니다.

주의: 이것은 '일차함수 해'를 찾은 것이고, 다른 해가 없다는 것은 따로 증명해야 합니다. 대회 답안에서는 이 점을 분명히 구별합니다.

예제

f(f(x)) = 4x + 3을 만족하는 일차함수 f를 모두 구하세요.

  1. f(x) = ax + b로 두면 f(f(x)) = a²x + (a + 1)b입니다.
  2. 계수를 비교하면 a² = 4, (a + 1)b = 3입니다.
  3. a = 2이면 b = 1, a = −2이면 −b = 3이라 b = −3입니다.
  4. 해: f(x) = 2x + 1, f(x) = −2x − 3입니다.

답: 2x + 1, −2x − 3

문제 4

f(f(x)) = 9x − 8인 일차함수 f(x) = ax + b에서 a > 0일 때 b는?

고정점과 전사

f(x) = x인 점을 고정점이라 합니다. f(f(x)) = x이면 f는 전사이자 단사(전단사)입니다. 어떤 y도 y = f(f(y))로 f의 값이 되기 때문입니다.

f(x + f(y)) = f(x) + y 같은 식에서는 x = 0을 넣어 f(f(y)) = y + f(0)을 얻고, 여기서 f가 전단사임을 알 수 있습니다.

전사성을 알면 'f(t) = 0인 t'처럼 원하는 값을 내는 점을 골라 대입할 수 있습니다.

문제 7

f(x + f(y)) = f(x) + y에 x = 0을 넣으면 f(f(y)) = y + f(0)입니다. f(x) = x + c 꼴의 해에서 c는?

정리

f(f(x)) = (단사인 식)이면 f는 단사이고, f(무엇) = f(무엇)에서 f를 떼어 낼 수 있습니다. 어떤 y도 f의 값으로 나오면 전사입니다.

일차식 꼴의 식은 f(x) = ax + b로 두고 계수를 비교해 후보를 찾되, 다른 해가 없음은 따로 증명해야 합니다.

고정점 f(x) = x, 전사성으로 고른 점(f(t) = 0 등)을 대입하면 식이 크게 단순해집니다.
