치환적분

∫ f(g(x))g′(x) dx에서 g(x) = t로 놓으면 g′(x)dx = dt이므로 ∫ f(t) dt가 됩니다. 합성함수 미분을 거꾸로 한 것입니다.

왜 성립할까요? F′ = f이면 합성함수의 미분법으로 {F(g(x))}′ = f(g(x))g′(x)입니다. 따라서 f(g(x))g′(x)를 적분하면 F(g(x)) + C이고, 이는 ∫ f(t) dt에 t = g(x)를 넣은 것과 같습니다. dt = g′(x)dx는 'x가 조금 변할 때 t가 g′(x)배로 변한다'는 뜻입니다.

문제 2

∫ cos 2x dx = (1/＿＿＿) sin 2x + C

자주 쓰는 꼴

∫ f′(x)/f(x) dx = ln|f(x)| + C, ∫ e^(ax) dx = (1/a)e^(ax) + C

∫ f′/f dx = ln|f| + C는 분자가 분모의 도함수일 때 쓰는 공식입니다. 분모를 t로 치환하면 ∫ dt/t = ln|t|가 되기 때문입니다. e^(ax)의 적분에 1/a이 붙는 것은 미분할 때 곱해지는 a를 되돌리기 위해서입니다.

예제

∫ x²(x³ − 2)⁴ dx를 구하세요.

  1. t = x³ − 2로 놓으면 dt = 3x² dx, x² dx = dt/3
  2. ∫ t⁴ × (1/3) dt = t⁵/15 + C
  3. t를 되돌리면 (x³ − 2)⁵/15 + C
  4. 확인: 미분하면 5(x³ − 2)⁴ × 3x²/15 = x²(x³ − 2)⁴

답: (x³ − 2)⁵/15 + C

정적분의 치환

치환하면 적분 구간도 t의 범위로 바꿉니다. x = 0 → t = g(0), x = 1 → t = g(1)

정적분을 치환할 때는 적분 구간도 반드시 t의 값으로 바꿉니다. 구간을 바꿔 두면 마지막에 x로 되돌릴 필요 없이 t의 식에 바로 위끝, 아래끝을 넣으면 됩니다. 구간을 바꾸지 않고 x의 구간을 그대로 쓰는 것이 가장 흔한 실수입니다.

예제

∫₀¹ x/(x² + 1) dx를 구하세요.

  1. t = x² + 1: dt = 2x dx, x = 0 → t = 1, x = 1 → t = 2
  2. ∫₁² (1/2)(1/t) dt = (1/2)[ln t]₁²
  3. = (1/2) ln 2
  4. 원리: 구간을 t로 바꾸면 x로 되돌리지 않아도 됩니다.

답: (1/2) ln 2

문제 7

∫₀^(π/2) sin x cos x dx의 값은? (기약분수로)

근호와 삼각치환

√(1 − x²)은 x = sin θ로 치환하면 cos θ가 되어 적분할 수 있습니다. ∫₀¹ √(1 − x²) dx는 사분원의 넓이입니다.

√(1 − x²)처럼 근호 안에 1 − x²이 있으면 sin² θ + cos² θ = 1을 이용해 x = sin θ로 놓습니다. 그러면 √(1 − sin² θ) = cos θ가 되어 근호가 사라집니다. 기하학적으로는 원의 일부의 넓이를 구하는 것과 같아 결과에 π가 나타납니다.

문제 9

∫₁ᵉ (ln x)/x dx의 값은? (기약분수로)

정리

속에 있는 식의 도함수가 곱해져 있는지 찾는 것이 치환의 핵심입니다.

치환할 식을 고르는 요령: 괄호 안의 식, 지수 부분, 근호 안, 분모처럼 '속에 들어 있는 식'을 t로 놓아 보고, 그 도함수가 곱해져 있는지 확인합니다. 상수배만 다르면 상수를 곱하고 나눠 맞출 수 있습니다. 치환 후 적분 결과는 미분해서 원래 식이 나오는지 확인합니다.

예제

∫₀^(π/2) sin³ x cos x dx를 구하세요.

  1. t = sin x: dt = cos x dx, x = 0 → t = 0, x = π/2 → t = 1
  2. ∫₀¹ t³ dt
  3. = [t⁴/4]₀¹ = 1/4
  4. 원리: cos x가 sin x의 도함수로 곱해져 있음

답: 1/4
