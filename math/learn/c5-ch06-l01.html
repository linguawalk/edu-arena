확률밀도함수

키나 시간처럼 어떤 구간의 모든 실수 값을 가질 수 있는 확률변수를 연속확률변수라고 합니다.

확률은 확률밀도함수 f(x)의 그래프와 x축 사이의 넓이로 나타냅니다. f(x) ≥ 0이고 전체 넓이는 1입니다.

왜 넓이로 확률을 나타낼까요? 키가 정확히 170.000…cm일 확률은 사실상 0이라, 연속적인 값에서는 '한 값의 확률'이 아니라 '구간의 확률'만 의미가 있습니다. 코스 0의 히스토그램에서 계급의 폭을 한없이 좁히면 막대들의 윗부분이 매끄러운 곡선이 되는데, 그 곡선이 확률밀도함수이고 막대 넓이의 합이 확률입니다.

문제 1

f(x) = 1/4 (0 ≤ x ≤ 4)일 때 P(1 ≤ X ≤ 3)은? (기약분수로)

문제 2

f(x) = k (0 ≤ x ≤ 5)가 확률밀도함수일 때 k는? (기약분수로)

한 점의 확률은 0

연속확률변수에서 한 점의 넓이는 0이므로 P(X = a) = 0입니다. 그래서 P(a ≤ X ≤ b) = P(a < X < b)입니다.

한 점은 폭이 0인 선분이라 그 위의 넓이는 0입니다. 그래서 연속확률변수에서는 부등호에 등호가 있든 없든 확률이 같습니다. 이산확률변수에서는 P(X = a)가 0이 아닐 수 있어 등호를 조심해야 하는 것과 대조됩니다.

삼각형 모양의 밀도함수

직선 모양의 밀도함수는 넓이를 삼각형이나 사다리꼴로 계산하면 됩니다.

직선 모양의 밀도함수는 적분 대신 도형의 넓이 공식으로 계산할 수 있습니다. 먼저 전체 넓이가 1이라는 조건으로 모르는 상수를 정하고, 구하는 구간의 삼각형이나 사다리꼴 넓이를 구합니다. 여사건을 쓰면 더 간단한 도형으로 계산할 수 있는 경우가 많습니다.

예제

f(x) = k(4 − x) (0 ≤ x ≤ 4)가 확률밀도함수일 때 k와 P(X ≤ 2)를 구하세요.

  1. 그래프는 높이 4k, 밑변 4인 직각삼각형: 넓이 8k = 1, k = 1/8
  2. P(X ≥ 2): 밑변 2, 높이 2k = 1/4인 삼각형 넓이 1/4
  3. P(X ≤ 2) = 1 − 1/4
  4. = 3/4

답: k = 1/8, P = 3/4

연속확률변수의 기댓값

E(X) = ∫ x f(x) dx. 이산확률변수의 합이 적분으로 바뀐 것입니다.

이산확률변수의 기댓값 Σ xᵢpᵢ에서, 값이 연속적으로 바뀌면 합 Σ가 적분 ∫으로, 각 값의 확률 pᵢ가 '아주 좁은 구간의 확률' f(x)dx로 바뀝니다. 그래서 E(X) = ∫ x f(x) dx입니다. 균일한 밀도이면 기댓값은 구간의 가운데 값입니다.

예제

f(x) = 3x² (0 ≤ x ≤ 1)일 때 E(X)를 구하세요.

  1. E(X) = ∫₀¹ x × 3x² dx = ∫₀¹ 3x³ dx
  2. = [3x⁴/4]₀¹
  3. = 3/4
  4. 확인: 큰 값 쪽의 밀도가 커서 평균이 1/2보다 큼

답: 3/4

문제 8

f(x) = 2x (0 ≤ x ≤ 1)일 때 E(X)는? (기약분수로)

문제 9

f(x) = 1/4 (0 ≤ x ≤ 4)일 때 E(X)는?

정리

연속확률변수의 확률은 넓이, 기댓값은 x f(x)의 적분입니다.

연속확률변수의 계산은 코스 4의 정적분과 코스 5의 확률분포가 만나는 곳입니다. 확률은 밀도함수의 정적분, 기댓값은 x f(x)의 정적분이며, 전체 넓이가 1이라는 조건이 확률분포의 '합이 1' 조건을 대신합니다. 이산과 연속의 대응을 기억해 두면 공식을 새로 외울 필요가 없습니다.

예제

버스가 10분 간격으로 옵니다. 아무 때나 정류장에 가면 기다리는 시간 X(분)는 0 ≤ X ≤ 10에서 균일합니다. 3분 이하로 기다릴 확률과 기다리는 시간의 기댓값은?

  1. f(x) = 1/10 (0 ≤ x ≤ 10)
  2. P(X ≤ 3) = 3 × 1/10 = 3/10
  3. E(X) = ∫₀¹⁰ x/10 dx = 5
  4. 균일분포의 평균은 구간의 가운데

답: 3/10, 5분
