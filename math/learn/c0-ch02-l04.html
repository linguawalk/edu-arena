정사각형을 네 조각으로

한 변이 a + b인 정사각형을 가로세로로 나누면 a², ab, ab, b² 네 조각이 생깁니다.

그래서 (a + b)²은 이 네 조각의 넓이를 모두 더한 것과 같습니다.

문제 1

(a + b)² = a² + ＿＿＿ab + b²

곱셈공식

(a + b)² = a² + 2ab + b², (a − b)² = a² − 2ab + b²

(a + b)(a − b) = a² − b²

(x + a)(x + b) = x² + (a + b)x + ab

예제

(2x + 3)²을 전개하세요.

  1. (a + b)² = a² + 2ab + b²에서 a = 2x, b = 3
  2. a² = 4x²
  3. 2ab = 2 × 2x × 3 = 12x
  4. b² = 9

답: 4x² + 12x + 9

인수분해

전개를 거꾸로 해서 다항식을 곱의 꼴로 나타내는 것을 인수분해라고 합니다.

모든 항에 공통으로 들어 있는 인수가 있으면 먼저 묶어 냅니다. 4x² + 6x = 2x(2x + 3)

제곱의 차는 합과 차의 곱으로 바꿉니다. a² − b² = (a + b)(a − b)

예제

3x² − 12를 인수분해하세요.

  1. 공통인수 3을 묶습니다: 3(x² − 4)
  2. x² − 4 = x² − 2²은 제곱의 차
  3. x² − 2² = (x + 2)(x − 2)

답: 3(x + 2)(x − 2)

합과 곱으로 찾기

x² + px + q를 (x + a)(x + b)로 인수분해하려면 더해서 p, 곱해서 q가 되는 두 수 a, b를 찾습니다.

예: x² + 5x + 6은 더해서 5, 곱해서 6인 2와 3을 찾아 (x + 2)(x + 3)

예제

x² − x − 12를 인수분해하세요.

  1. 더해서 −1, 곱해서 −12인 두 수를 찾습니다.
  2. 곱이 음수이므로 부호가 다릅니다: (3, −4), (−3, 4), (2, −6) …
  3. 3 + (−4) = −1이므로 3과 −4
  4. (x + 3)(x − 4)

답: (x + 3)(x − 4)
