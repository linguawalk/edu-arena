급수와 부분합

a₁ + a₂ + a₃ + …처럼 수열의 항을 끝없이 더한 것을 급수라고 합니다.

첫째항부터 제n항까지의 합 Sₙ을 부분합이라 하고, lim Sₙ이 수렴하면 그 값이 급수의 합입니다.

끝없이 더한다는 것은 직접 할 수 없으므로, n개까지 더한 부분합 Sₙ을 구하고 n → ∞일 때의 극한으로 정의합니다. 즉 급수의 합은 '수열 Sₙ의 극한'입니다. 부분분수로 나뉘는 급수는 Sₙ에서 가운데 항이 지워져 극한을 쉽게 구할 수 있습니다.

문제 1

Σ(n=1~∞) 1/(n(n + 1))의 합은?

문제 2

Σ(n=1~∞) 1/((2n − 1)(2n + 1))의 합은? (기약분수로)

발산하는 급수

부분합이 한없이 커지거나 진동하면 급수는 발산합니다.

끝없이 더하는데 합이 유한할 수 있다는 것이 급수의 신기한 점입니다. 1/2 + 1/4 + 1/8 + …은 2를 넘지 못합니다. 반대로 1 + 1 + 1 + …처럼 더하는 항이 줄지 않으면 합은 한없이 커집니다. 수렴 여부는 항상 부분합의 극한으로 판단합니다.

예제

Σ(n=1~∞) 1/(n(n + 3))의 합을 구하세요.

  1. 부분분수: 1/(n(n + 3)) = (1/3)(1/n − 1/(n + 3))
  2. 부분합에서 세 칸씩 떨어진 항끼리 지워져 1, 1/2, 1/3과 끝의 세 항만 남음
  3. 끝의 세 항은 n → ∞이면 0
  4. 합 = (1/3)(1 + 1/2 + 1/3) = 11/18

답: 11/18

문제 4

Σ(n=1~∞) (1/n − 1/(n + 1))의 합은?

수렴하면 항은 0으로

급수가 수렴하면 lim aₙ = 0입니다. 대우를 쓰면 lim aₙ ≠ 0인 급수는 발산합니다.

하지만 lim aₙ = 0이라고 급수가 수렴하는 것은 아닙니다.

왜 lim aₙ = 0일까요? aₙ = Sₙ − Sₙ₋₁이고, 급수가 S로 수렴하면 Sₙ과 Sₙ₋₁이 모두 S로 가므로 aₙ → S − S = 0입니다. 하지만 역은 거짓입니다. 1/n → 0이지만 1 + 1/2 + 1/3 + …은 발산하는 유명한 예(조화급수)가 있습니다.

예제

Σ(n=1~∞) (2n + 1)/(n + 3)이 수렴하는지 판정하세요.

  1. 일반항의 극한: (2n + 1)/(n + 3) → 2
  2. lim aₙ = 2 ≠ 0
  3. 수렴하면 항이 0으로 가야 하므로 발산
  4. 원리: 일반항이 0으로 가지 않으면 반드시 발산

답: 발산

문제 7

Σ n/(n + 1)은 수렴할까요? (그렇다 1, 아니다 0)

부분합과 일반항

Sₙ이 주어지면 급수의 합은 lim Sₙ이고, aₙ = Sₙ − Sₙ₋₁입니다.

부분합 Sₙ이 식으로 주어지면 두 가지를 알 수 있습니다. 급수의 합은 lim Sₙ, 각 항은 aₙ = Sₙ − Sₙ₋₁ (n ≥ 2), a₁ = S₁입니다. 수열의 합과 일반항 사이의 관계를 그대로 쓰는 것입니다.

예제

부분합이 Sₙ = n/(2n + 1)인 급수의 합과 a₃을 구하세요.

  1. 급수의 합 = lim Sₙ = 1/2
  2. a₃ = S₃ − S₂ = 3/7 − 2/5
  3. = 15/35 − 14/35 = 1/35
  4. 확인: 일반항 aₙ = 1/((2n − 1)(2n + 1))

답: 합 1/2, a₃ = 1/35

문제 10

정리

부분분수로 나눠 소거되는 꼴이면 부분합을 구해 극한을 계산합니다.

급수가 수렴하면 상수배와 합에 대해 Σ(paₙ + qbₙ) = pΣaₙ + qΣbₙ이 성립합니다. 다만 두 급수가 모두 수렴할 때만 이렇게 나눌 수 있습니다. 발산하는 급수끼리의 합은 따로 조사해야 합니다. 부분분수로 소거되는 급수는 부분합을 먼저 식으로 구한 뒤 극한을 취합니다.
