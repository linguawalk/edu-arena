나눗셈을 하지 않고 나머지 구하기

다항식 P(x)를 x − a로 나눈 나머지는 P(a)입니다. P(x) = (x − a)Q(x) + r에 x = a를 넣으면 r = P(a)이기 때문입니다.

그래서 x¹⁰⁰ + 1을 x + 1로 나눈 나머지는 직접 나누지 않고 (−1)¹⁰⁰ + 1 = 2로 구합니다.

올림피아드에서는 차수가 큰 다항식이나 이차식으로 나누는 문제가 많이 나옵니다. 핵심은 같습니다. 나누는 식이 0이 되는 x 값을 넣으면 몫 부분이 사라지고 나머지만 남습니다. 이 레슨에서는 이 생각을 이차식으로 나누는 경우, 계수 구하기, 거듭제곱 나머지로 넓힙니다.

문제 1

P(x) = x³ − 2x + 5를 x − 2로 나눈 나머지는?

문제 2

x¹⁰⁰ + 1을 x + 1로 나눈 나머지는?

이차식으로 나눈 나머지

P(x)를 이차식 (x − a)(x − b)로 나누면 나머지는 일차 이하의 식 px + q입니다. P(x) = (x − a)(x − b)Q(x) + px + q로 쓸 수 있습니다.

x = a, x = b를 넣으면 P(a) = pa + q, P(b) = pb + q라는 두 식이 생기고, 이것을 풀어 p, q를 구합니다.

왜 나머지가 일차 이하일까요? 나눗셈에서 나머지의 차수는 나누는 식의 차수보다 작아야 하기 때문입니다. 그래서 미지수가 두 개이고, 나누는 식의 두 근을 넣어 얻는 두 식이면 정확히 풀립니다. 세제곱식으로 나누면 나머지는 이차 이하이고, 세 근을 넣어 세 미지수를 구합니다.

예제

P(x)를 x − 1로 나눈 나머지가 3, x − 2로 나눈 나머지가 5일 때, (x − 1)(x − 2)로 나눈 나머지를 구하세요.

  1. P(x) = (x − 1)(x − 2)Q(x) + px + q로 놓습니다.
  2. x = 1을 넣으면 P(1) = p + q = 3, x = 2를 넣으면 P(2) = 2p + q = 5입니다.
  3. 두 식을 빼면 p = 2이고, q = 1입니다.
  4. 따라서 나머지는 2x + 1입니다.

답: 2x + 1

문제 4

x¹⁰을 x² − 1로 나눈 나머지는 상수입니다. 그 값은?

인수 정리로 계수 구하기

P(a) = 0이면 P(x)는 x − a로 나누어떨어지고, 거꾸로 x − a로 나누어떨어지면 P(a) = 0입니다. 이것을 인수 정리라고 합니다.

그래서 '…로 나누어떨어진다'는 조건은 '그 근을 넣으면 0'이라는 식으로 바뀝니다.

x³ + ax² + bx − 6이 (x − 1)(x − 2)로 나누어떨어지면 P(1) = 0, P(2) = 0이라는 두 식이 생겨 a, b를 구할 수 있습니다. 구한 뒤 남은 인수를 찾으면 다항식 전체를 인수분해할 수 있습니다. 상수항 −6과 이미 찾은 두 근 1, 2의 곱에서 세 번째 근이 3임을 근과 계수의 관계로 바로 알 수도 있습니다.

문제 7

앞 문제의 다항식 x³ − 6x² + 11x − 6 = (x − 1)(x − 2)(x − ＿＿＿)입니다.

거듭제곱의 나머지

x¹⁰⁰을 x² + x + 1로 나눈 나머지는 실수 근을 넣는 방법으로는 구하기 어렵습니다. 대신 x³ − 1 = (x − 1)(x² + x + 1)을 씁니다.

x² + x + 1로 나눈 나머지만 보면 x³은 1과 같게 취급됩니다(x³ − 1이 x² + x + 1의 배수이므로). 그래서 x⁹⁹ = (x³)³³은 1과, x¹⁰⁰은 x와 같은 나머지를 가집니다.

이처럼 '나누는 식의 배수가 되는 간단한 식'을 찾으면 큰 지수를 작게 줄일 수 있습니다. 정수론의 합동식과 같은 생각입니다. x¹⁰¹은 x²과 같은 나머지이고, x² = (x² + x + 1) − x − 1이므로 나머지는 −x − 1입니다.

문제 8

x¹⁰¹을 x² + x + 1로 나눈 나머지를 px + q라 할 때 p + q의 값은?

정리

P(x)를 x − a로 나눈 나머지는 P(a)이고, P(a) = 0이면 x − a가 인수입니다.

이차식 (x − a)(x − b)로 나눈 나머지는 px + q로 놓고, x = a, b를 넣어 두 식을 세웁니다.

근을 넣기 어려운 나눗셈은 나누는 식의 배수가 되는 간단한 식(x² + x + 1에 대해 x³ − 1)을 찾아 지수를 줄입니다. 계수의 합은 P(1), 상수항은 P(0), 짝수 차수 계수의 합은 (P(1) + P(−1))/2라는 것도 같은 '값 넣기' 생각에서 나옵니다.
