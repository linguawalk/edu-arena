문제에서 답안까지 네 단계

처음 보는 문제는 네 단계로 다룹니다. 실험: 작은 값을 넣어 본다. 추측: 규칙을 찾는다. 증명: 맞는 방법을 골라 증명한다. 답안: 앞의 두 레슨 기준으로 정리해 쓴다.

이 레슨에서는 '2 이상의 자연수 n에 대해 n⁴ + 4는 합성수이다'를 이 네 단계로 풀어 봅니다.

왜 실험부터 할까요? 실험은 무엇을 증명해야 하는지와 어디서 조건이 필요한지를 알려 줍니다. n = 1이면 n⁴ + 4 = 5로 소수라서, 문제에 'n ≥ 2'가 붙은 이유가 보입니다. 실험에서 얻은 인수 5, 17 같은 숫자는 인수분해 꼴을 추측하는 단서가 됩니다. 실험 자체는 답안에 쓰지 않아도 되지만, 생략하면 증명의 방향을 잡기 어렵습니다.

문제 1

n = 3일 때 n⁴ + 4의 값은?

문제 2

n⁴ + 4 = (n² + 2)² − (＿＿＿)²입니다.

실험에서 추측으로

n = 2, 3, 4, 5에서 n⁴ + 4는 20, 85, 260, 629입니다. 이 값들을 인수분해하면 85 = 5 × 17, 629 = 17 × 37처럼 두 인수가 보입니다.

n = 3에서 5와 17은 n² − 2n + 2 = 5, n² + 2n + 2 = 17과 같습니다. 이로부터 일반적인 인수분해를 추측할 수 있습니다.

추측을 얻으면 바로 증명으로 넘어가기 전에 다른 값 하나로 확인합니다. n = 5이면 n² − 2n + 2 = 17, n² + 2n + 2 = 37이고 17 × 37 = 629로 맞습니다. 추측이 틀렸다면 이 단계에서 걸러집니다. 증명은 앞 문제에서 본 완전제곱의 차로 합니다.

문제 3

n = 3일 때 n² − 2n + 2의 값은?

문제 4

'n ≥ 2이면 n⁴ + 4는 합성수이다'의 답안을 올바른 순서로 배열하세요.

결론의 꼴로 방법 고르기

증명 방법은 결론의 꼴을 보고 고릅니다. '모든 자연수 n에 대해 …'이고 n과 n + 1 사이의 관계가 보이면 수학적 귀납법을 먼저 떠올립니다.

'…인 정수는 없다', '…는 무리수이다'는 귀류법, '…가 존재한다'는 구성, 정수의 성질은 나머지로 경우 나누기, 'p이면 q'에서 p가 다루기 어려우면 대우가 1순위입니다.

합성수임을 보이는 문제라면 '1이 아닌 두 인수의 곱'으로 인수분해하는 것이 거의 항상 답입니다. 이 목록은 출발점일 뿐이고, 하나가 막히면 다음 후보로 넘어갑니다. 방법을 골랐다면 답안 첫 줄에 '귀류법으로 보이자'처럼 밝혀 두면 채점자가 따라가기 쉽습니다.

문제 5

'…를 만족하는 정수는 없다'를 보일 때 가장 먼저 떠올릴 방법은 ＿＿＿법입니다.

문제 6

'모든 자연수 n에 대해 …'이고 n일 때와 n + 1일 때의 관계가 보이면 수학적 ＿＿＿법을 먼저 떠올립니다.

검산하고 마무리하기

답안을 다 쓰면 세 가지를 확인합니다. 문제의 조건을 모두 썼는가, 경계값에서 맞는가, 결론이 문제가 묻는 것과 정확히 같은가.

n⁴ + 4 문제에서는 'n ≥ 2'를 작은 인수가 2 이상이라는 줄에서 썼습니다. 조건을 한 번도 쓰지 않았다면 증명에 빠진 것이 있다는 신호입니다.

경계값 n = 1을 넣으면 작은 인수가 1이 되어 합성수가 아님을 확인할 수 있습니다. 조건이 왜 필요한지 경계에서 확인하면 증명이 조건을 제대로 썼는지 함께 점검됩니다. 마지막으로 결론 문장이 '합성수이다'처럼 문제의 말과 같은지 봅니다.

문제 8

연속한 세 자연수 n − 1, n, n + 1의 제곱의 합 3n² + 2를 3으로 나눈 나머지는?

정리

처음 보는 문제는 실험, 추측, 증명, 답안의 네 단계로 다룹니다. 실험한 값은 추측의 단서이자 추측을 확인하는 도구입니다.

결론의 꼴로 방법을 고릅니다. '모든 n'은 귀납법, '없다'는 귀류법, '존재'는 구성, 정수의 성질은 나머지, '합성수'는 인수분해입니다.

답안을 다 쓰면 조건을 모두 썼는지, 경계값에서 맞는지, 결론이 문제의 말과 같은지 확인합니다. 증명의 기초 트랙은 여기까지이고, 다음 트랙부터는 이 방법들이 대수·정수론·조합·기하 문제에서 반복해 쓰입니다.
