공간벡터

공간의 벡터도 성분으로 a = (a₁, a₂, a₃)라 쓰고, 크기는 √(a₁² + a₂² + a₃²)입니다.

공간벡터는 평면벡터에 z 성분이 하나 더해진 것입니다. 크기 공식도 공간의 두 점 사이의 거리 공식과 같습니다. AB = (x₂ − x₁, y₂ − y₁, z₂ − z₁)처럼 끝점에서 시작점을 빼는 것도 평면과 같습니다.

문제 1

벡터 (1, 2, 2)의 크기는?

문제 2

A(1, 0, 2), B(3, 4, 5)일 때 AB = (2, 4, ＿＿＿)

연산

덧셈, 뺄셈, 실수배는 평면벡터처럼 성분끼리 계산합니다.

성분끼리 더하고 빼고 실수배하는 규칙도 평면과 똑같습니다. 세 방향의 움직임이 서로 독립이라 각 방향을 따로 계산하면 되기 때문입니다. 평행 조건도 세 성분의 비가 모두 같다는 것으로 넓어집니다. 두 성분의 비만 같고 나머지가 다르면 평행이 아닙니다.

예제

a = (2, −1, 3), b = (1, 4, −2)일 때 2a − b와 그 크기를 구하세요.

  1. 2a = (4, −2, 6)
  2. 2a − b = (3, −6, 8)
  3. |2a − b| = √(9 + 36 + 64)
  4. = √109

답: (3, −6, 8), √109

내적

a·b = a₁b₁ + a₂b₂ + a₃b₃ = |a||b|cos θ. 내적이 0이면 수직입니다.

공간벡터의 내적도 성분의 곱의 합 a₁b₁ + a₂b₂ + a₃b₃이며, 코사인법칙으로 유도하는 과정도 평면과 같습니다. 공간에서도 내적이 0이면 두 벡터가 수직입니다. 좌표축 방향의 벡터 (1, 0, 0), (0, 1, 0), (0, 0, 1)은 서로 수직입니다.

예제

a = (1, 2, −1), b = (3, −1, k)가 수직일 때 k를 구하세요.

  1. a·b = 3 − 2 − k
  2. = 1 − k
  3. 수직이면 0: k = 1
  4. 확인: (1, 2, −1)·(3, −1, 1) = 3 − 2 − 1 = 0

답: 1

각 구하기

cos θ = a·b / (|a||b|)

두 벡터가 이루는 각은 공간에서도 cos θ = a·b/(|a||b|)로 구합니다. 정육면체의 대각선과 모서리가 이루는 각처럼 그림으로는 재기 어려운 각도 성분을 쓰면 간단히 계산됩니다. 정육면체의 한 꼭짓점을 원점에 두고 모서리를 좌표축에 맞추면 모든 꼭짓점의 좌표가 0과 1로 나타나 계산이 쉬워집니다.

예제

한 변이 1인 정육면체에서 대각선 AG = (1, 1, 1)과 모서리 AB = (1, 0, 0)이 이루는 각의 코사인을 구하세요.

  1. AG·AB = 1
  2. |AG| = √3, |AB| = 1
  3. cos θ = 1/√3
  4. = √3/3 (θ ≈ 54.7°)

답: √3/3

정리

평면벡터의 성질이 공간에서도 그대로 성립합니다. 성분이 하나 늘어날 뿐입니다.

평면벡터에서 배운 모든 성질(연산 법칙, 내적, 평행·수직 조건, 위치벡터)이 공간에서 그대로 성립합니다. 레벨 2 이후에 배울 공간의 직선과 평면의 방정식, 3차원 그래픽, 물리의 힘 계산이 모두 공간벡터 위에서 이루어집니다.
