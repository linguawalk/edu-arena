정규분포

키, 시험 점수처럼 평균 근처에 많고 멀어질수록 적은 자료는 종 모양의 정규분포를 따릅니다.

평균이 m, 표준편차가 σ인 정규분포를 N(m, σ²)으로 씁니다. 그래프는 직선 x = m에 대하여 대칭입니다.

정규분포는 자연과 사회에서 가장 흔히 나타나는 분포입니다. 키, 측정 오차, 시험 점수처럼 많은 작은 요인이 더해져 생기는 값은 대부분 종 모양으로 분포합니다. 평균 m이 가운데 봉우리의 위치를, 표준편차 σ가 퍼진 정도를 정하므로 두 수만 알면 분포가 완전히 결정됩니다.

문제 2

σ에 따른 모양

σ가 커지면 그래프가 낮고 넓게 퍼지고, 작아지면 높고 좁아집니다. m이 바뀌면 모양은 그대로 평행이동합니다.

곡선 아래의 전체 넓이는 항상 1이어야 합니다. 그래서 σ가 커져 옆으로 넓게 퍼지면 높이는 낮아지고, σ가 작아져 좁아지면 높이는 높아집니다. 모래를 같은 양으로 쌓을 때 넓게 펴면 낮아지는 것과 같습니다.

문제 4

평균만 바뀌면 곡선은 모양이 같고 평행이동할까요? (그렇다 1, 아니다 0)

σ 단위의 넓이

평균에서 σ 이내에 약 68%, 2σ 이내에 약 95%가 들어갑니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

68–95 규칙은 정규분포의 특징을 대표하는 숫자입니다. 평균에서 σ 안쪽에 약 68%, 2σ 안쪽에 약 95%, 3σ 안쪽에 약 99.7%가 있습니다. 그래서 평균에서 2σ 이상 떨어진 값은 드문 경우(약 5%)로 봅니다.

예제

키가 N(170, 6²)을 따르는 집단에서 158cm 이상 182cm 이하인 사람의 비율을 구하세요.

  1. 158 = 170 − 2 × 6, 182 = 170 + 2 × 6
  2. 평균에서 양쪽으로 2σ 이내
  3. 0.4772 × 2 = 0.9544
  4. 약 95.4%

답: 약 95.4%

P(m − 2σ ≤ X ≤ m + 2σ)는?

대칭을 이용한 계산

아래 문제는 X ~ N(60, 10²)입니다. 평균 60을 기준으로 σ = 10의 몇 배인지 보고 표의 값을 씁니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

정규분포는 평균을 기준으로 좌우 대칭이라 P(X ≤ m) = P(X ≥ m) = 0.5입니다. 이 사실과 표의 값(평균에서 한쪽으로 간 넓이)을 조합하면 거의 모든 구간의 확률을 구할 수 있습니다. 먼저 구하는 구간을 그림으로 그리면 더하고 빼는 방향이 분명해집니다.

예제

X ~ N(60, 10²)일 때 P(45 ≤ X ≤ 80)을 구하세요.

  1. 45는 평균보다 1.5σ 아래, 80은 2σ 위
  2. 평균을 사이에 끼므로 두 넓이를 더함
  3. 0.4332 + 0.4772
  4. = 0.9104

답: 0.9104

정리

평균보다 큰 쪽과 작은 쪽의 넓이가 각각 0.5라는 점과 좌우 대칭을 함께 씁니다.

계산 요령: 평균의 어느 쪽인지 확인 → 평균에서 몇 σ 떨어졌는지 계산 → 표의 값(평균에서 그 점까지의 넓이)에 0.5를 더하거나 뺍니다. 평균을 사이에 끼면 양쪽 넓이를 더하고, 한쪽에 있으면 뺍니다.

예제

X ~ N(60, 10²)일 때 P(65 ≤ X ≤ 75)를 구하세요.

  1. 65는 평균보다 0.5σ 위, 75는 1.5σ 위
  2. 둘 다 평균의 같은 쪽이므로 넓이를 뺌
  3. 0.4332 − 0.1915
  4. = 0.2417

답: 0.2417
