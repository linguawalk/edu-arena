AM-GM을 쓰기 전 두 가지 점검

AM-GM을 쓰려면 두 조건이 맞아야 합니다. 첫째, 곱(또는 합)이 상수가 되어야 합니다. 둘째, 등호가 문제의 조건 안에서 실제로 가능해야 합니다.

x > 1일 때 x + 1/(x − 1)은 그대로는 두 항의 곱 x/(x − 1)이 상수가 아닙니다. x를 (x − 1) + 1로 바꾸면 (x − 1) + 1/(x − 1) + 1이 되어 앞의 두 항의 곱이 1입니다.

이처럼 식을 살짝 바꾸어 곱이 상수인 짝을 만드는 것이 항 쪼개기의 핵심입니다. 분모에 x − a가 있으면 분자 쪽 x도 x − a로 맞추고, 남은 상수는 따로 둡니다. 이 레슨은 두 번째 조건, 곧 등호가 실제로 가능한지를 맞추는 연습도 함께 합니다.

문제 1

x > 1일 때 x + 1/(x − 1)의 최솟값은?

문제 2

x > 1에서 x + 1/(x − 1) = (x − 1) + 1/(x − 1) + ＿＿＿입니다.

상수 맞추기

x > 2일 때 x + 4/(x − 2)도 같은 방법입니다. x = (x − 2) + 2로 바꾸면 (x − 2) + 4/(x − 2) + 2입니다.

앞의 두 항의 곱이 4이므로 (x − 2) + 4/(x − 2) ≥ 2√4 = 4이고, 전체는 6 이상입니다. 등호는 x − 2 = 2, 곧 x = 4일 때입니다.

분수식 (x² + 5x + 4)/x처럼 다항식을 x로 나눈 꼴도 먼저 나누어 x + 5 + 4/x로 바꾸면 같은 방법이 됩니다. 원칙은 하나입니다. 변하는 부분을 '곱이 상수인 두 항'으로 모으고, 상수는 밖으로 뺍니다.

문제 3

x > 2일 때 x + 4/(x − 2)의 최솟값은?

곱의 최댓값: 합이 상수가 되게

곱의 최댓값을 구할 때는 반대로 '합이 상수'가 되도록 인수를 조정합니다.

0 < x < 3일 때 x²(3 − x)의 최댓값을 보세요. x × x × (3 − x)의 합은 x + 3이라 상수가 아닙니다. x/2 × x/2 × (3 − x)로 바꾸면 세 인수의 합이 3으로 상수입니다.

그러면 (x/2)(x/2)(3 − x) ≤ 1이고, x²(3 − x) ≤ 4입니다. 등호는 세 인수가 같을 때, 곧 x/2 = 3 − x인 x = 2입니다. 계수를 고를 때는 '합에서 x가 사라지게'를 먼저 맞추고, 그 값으로 등호가 0 < x < 3 안에 있는지 확인합니다.

예제

0 < x < 3일 때 x²(3 − x)의 최댓값을 구하세요.

  1. x²(3 − x) = 4 × (x/2)(x/2)(3 − x)로 바꿉니다.
  2. 세 인수 x/2, x/2, 3 − x는 양수이고 합이 3입니다.
  3. AM-GM에서 (x/2)(x/2)(3 − x) ≤ (3/3)³ = 1이므로 x²(3 − x) ≤ 4입니다.
  4. 등호는 x/2 = 3 − x, 곧 x = 2일 때이고 4 × 1 = 4이므로 최댓값은 4입니다.

답: 4

문제 5

앞 문제에서 최댓값이 나오는 x의 값을 분수로 쓰세요.

등호가 조건 밖에 있을 때

x ≥ 2일 때 x + 1/x의 최솟값은 2가 아닙니다. AM-GM의 등호 x = 1이 조건 x ≥ 2 밖에 있기 때문입니다.

이때는 등호가 x = 2에서 성립하도록 항을 다시 나눕니다. x + 1/x = (x/4 + 1/x) + 3x/4로 쓰면, x/4 + 1/x ≥ 2√(1/4) = 1이고 등호는 x/4 = 1/x인 x = 2입니다. 또 x ≥ 2에서 3x/4 ≥ 3/2입니다.

두 부등식의 등호가 모두 x = 2에서 성립하므로 최솟값은 1 + 3/2 = 5/2입니다. 핵심은 '최솟값이 나올 것 같은 경계값'을 먼저 짐작하고, 그 값에서 두 항이 같아지도록 계수를 정하는 것입니다. x/k + 1/x에서 x = 2일 때 두 항이 같으려면 2/k = 1/2, 곧 k = 4입니다.

고쳐 쓰기

x ≥ 2일 때 x + 1/x의 최솟값이 2라고 쓴 답안의 문제를 고치세요.

  1. AM-GM의 등호 x = 1은 x ≥ 2를 만족하지 않으므로 2는 최솟값이 아닙니다.
  2. x + 1/x = (x/4 + 1/x) + 3x/4로 나눕니다.
  3. x/4 + 1/x ≥ 1 (등호 x = 2)이고, x ≥ 2이면 3x/4 ≥ 3/2 (등호 x = 2)입니다.
  4. 따라서 x + 1/x ≥ 5/2이고, x = 2에서 2 + 1/2 = 5/2이므로 최솟값은 5/2입니다.

답: 5/2

문제 7

정리

AM-GM을 쓰기 전에 곱(또는 합)이 상수가 되도록 항을 바꿉니다. 분모에 x − a가 있으면 x를 (x − a) + a로, 곱의 최댓값이면 인수에 계수를 곱해 합을 상수로 만듭니다.

쓴 뒤에는 등호가 되는 값이 문제의 조건 안에 있는지 확인합니다.

등호가 조건 밖에 있으면 최솟값이 나올 경계값을 짐작하고, 그 값에서 두 항이 같아지도록 계수를 정해 다시 나눕니다. 이 '등호 맞추기'는 올림피아드 부등식에서 가장 많이 쓰는 기술 중 하나입니다.
