함수의 뜻

함수

집합 X의 각 원소에 집합 Y의 원소가 오직 하나씩 대응할 때 이 대응을 X에서 Y로의 함수라 하고 f : X → Y로 씁니다.

'오직 하나씩'에는 두 가지 뜻이 있습니다. X의 모든 원소에 대응하는 값이 반드시 있어야 하고(빠짐 없음), 한 원소에 두 개 이상의 값이 대응하면 안 됩니다(중복 없음). 자판기 버튼마다 음료가 정확히 하나 나오는 것과 같습니다.

문제 1

X = {1, 2, 3}에서 Y = {a, b}로의 함수는 모두 몇 개일까요?

문제 2

함숫값 전체의 집합을 ＿＿＿이라고 합니다.

정의역, 공역, 치역

X를 정의역, Y를 공역, 실제로 나오는 함숫값 전체를 치역이라고 합니다. 치역은 공역의 부분집합입니다.

정의역이 따로 없으면 식이 정의되는 실수 전체를 정의역으로 봅니다.

공역은 '나올 수 있다고 정해 둔 범위', 치역은 '실제로 나온 값'입니다. 예를 들어 f(x) = x²을 실수에서 실수로 정의하면 공역은 실수 전체이지만 치역은 0 이상의 실수입니다.

예제

정의역이 {−1, 0, 1, 2}인 f(x) = x² − 1의 치역을 구하세요.

  1. f(−1) = 0, f(0) = −1
  2. f(1) = 0, f(2) = 3
  3. 같은 값은 한 번만: 치역 {−1, 0, 3}

답: {−1, 0, 3}

서로 같은 함수

두 함수는 정의역이 같고, 정의역의 모든 원소에서 함숫값이 같을 때 서로 같습니다.

식이 같아도 정의역이 다르면 다른 함수입니다. 반대로 식이 달라도 정의역의 모든 원소에서 값이 같으면 같은 함수입니다. 함수는 식이 아니라 '대응 관계'로 판단하기 때문입니다.

문제 6

정의역이 {−1, 0, 1}일 때 f(x) = x³과 g(x) = x는 서로 같은 함수일까요? (같다 1, 다르다 0)

문제 7

실수에서 정의된 f(x) = x²/x와 g(x) = x는 서로 같은 함수일까요? (같다 1, 다르다 0)

여러 가지 함수

서로 다른 x에 서로 다른 함숫값이 대응하면 일대일함수, 여기에 치역과 공역이 같으면 일대일대응입니다.

f(x) = x는 항등함수, f(x) = c는 상수함수입니다.

일대일대응이 중요한 이유는 거꾸로 대응시켜도 함수가 되기 때문입니다. 이 성질이 뒤에서 배울 역함수가 존재할 조건이 됩니다. 원소가 n개인 집합에서 자기 자신으로의 일대일대응은 n!개입니다.

예제

X = {1, 2, 3}에서 Y = {a, b, c, d}로의 일대일함수의 개수를 구하세요.

  1. 1에 대응할 값: 4가지
  2. 2에는 1과 다른 값: 3가지, 3에는 앞의 둘과 다른 값: 2가지
  3. 곱의 법칙: 4 × 3 × 2 = 24

답: 24개

함숫값으로 식 구하기

f(x) = ax + b에서 두 함숫값을 알면 연립방정식으로 a, b를 구합니다.

f(x + 1)처럼 식이 주어지면 괄호 안이 원하는 값이 되는 x를 넣습니다.

f(x + 1) = 2x + 3에서 f(3)을 구할 때는 괄호 안 x + 1이 3이 되도록 x = 2를 넣습니다. f 안에 무엇이 들어가는지와 식에 넣는 x를 구별하는 것이 핵심입니다.

예제

f(2x − 1) = 4x + 3일 때 f(5)를 구하세요.

  1. 괄호 안 2x − 1이 5가 되는 x를 찾습니다: 2x − 1 = 5, x = 3
  2. x = 3을 우변에 넣습니다: 4 × 3 + 3
  3. f(5) = 15

답: 15
