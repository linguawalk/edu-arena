등비수열

첫째항부터 차례로 일정한 수 r을 곱해 만든 수열을 등비수열, r을 공비라고 합니다.

등비수열은 '몇 배씩' 변하는 수열입니다. 등차수열이 매번 같은 수를 더하는 것과 달리, 등비수열은 매번 같은 수를 곱합니다. 공비는 뒤 항을 앞 항으로 나눠 구하며, 공비가 음수이면 부호가 번갈아 바뀌고, 0과 1 사이이면 점점 작아집니다.

일반항

첫째항이 a, 공비가 r인 등비수열의 일반항은 aₙ = arⁿ⁻¹입니다.

왜 rⁿ⁻¹일까요? 첫째항에서 제n항까지 가는 동안 공비를 곱하는 횟수는 n − 1번입니다. 그래서 aₙ = arⁿ⁻¹입니다. 이 식은 n에 대한 지수함수이므로, 등비수열은 지수적 변화를 자연수에서만 본 것과 같습니다.

예제

제2항이 −6, 제5항이 48인 등비수열의 일반항을 구하세요.

  1. a₅/a₂ = r³ = 48/(−6) = −8
  2. r = −2
  3. a₂ = ar = −2a = −6에서 a = 3
  4. aₙ = 3 × (−2)ⁿ⁻¹

답: aₙ = 3(−2)ⁿ⁻¹

등비중항

세 수 a, b, c가 이 순서로 등비수열을 이루면 b² = ac이고, b를 등비중항이라고 합니다.

등비수열에서 가운데 항은 양옆 항의 기하평균입니다. b/a = c/b = r이므로 b² = ac입니다. 세 수가 등비수열이면 가운데 수를 기준으로 a/r, a, ar로 놓으면 곱이 a³이 되어 계산이 간단해집니다.

등비수열의 합

r ≠ 1일 때 Sₙ = a(rⁿ − 1)/(r − 1)입니다. r = 1이면 Sₙ = na입니다.

왜 이 공식일까요? Sₙ = a + ar + … + arⁿ⁻¹에 r을 곱한 rSₙ = ar + … + arⁿ을 빼면 가운데 항이 모두 지워지고 rSₙ − Sₙ = arⁿ − a만 남습니다. 그래서 Sₙ = a(rⁿ − 1)/(r − 1)입니다. r < 1이면 분모와 분자에 −1을 곱한 a(1 − rⁿ)/(1 − r)가 편합니다.

예제

첫째항이 81, 공비가 1/3인 등비수열의 첫째항부터 제5항까지의 합을 구하세요.

  1. r < 1이므로 Sₙ = a(1 − rⁿ)/(1 − r)
  2. S₅ = 81 × (1 − 1/243)/(2/3)
  3. = 81 × (242/243) × (3/2) = 121
  4. 확인: 81 + 27 + 9 + 3 + 1 = 121

답: 121

원리합계

매년 초에 같은 금액을 복리로 적립하면 각 해의 원리합계가 등비수열을 이루고, 그 합이 전체 원리합계입니다.

원리합계 문제는 각 해에 넣은 돈이 몇 년 동안 이자를 받는지 따로 계산하는 것이 핵심입니다. 3년 적립이면 첫해 돈은 3년, 둘째 해 돈은 2년, 셋째 해 돈은 1년 동안 불어나므로 1.1³, 1.1², 1.1¹배가 되고, 이것이 등비수열입니다.

예제

매년 초 200만 원씩 연 5% 복리로 2년 적립하면 2년 말 원리합계는?

  1. 첫해 돈: 2년 불어남 → 200 × 1.05² = 220.5
  2. 둘째 해 돈: 1년 불어남 → 200 × 1.05 = 210
  3. 합: 220.5 + 210 = 430.5
  4. 원리: 200 × 1.05 × (1.05² − 1)/(1.05 − 1)과 같습니다.

답: 430.5만 원
