모든 항의 차수를 맞추기

모든 항의 차수가 같은 식을 동차식이라 합니다. a² + b² + c²은 2차 동차식, a²b + b²c + c²a는 3차 동차식입니다.

조건이 있는 부등식은 조건을 이용해 동차식으로 바꿀 수 있습니다(동차화). a + b + c = 3일 때 a² + b² + c² ≥ 3은, 3 = (a + b + c)²/3이므로 a² + b² + c² ≥ (a + b + c)²/3, 곧 3(a² + b² + c²) ≥ (a + b + c)²과 같습니다.

동차 부등식은 조건 없이 성립하므로 재배열, SOS 같은 도구를 그대로 쓸 수 있습니다.

a²b + b²c + c²a는 몇 차 동차식인가요?

문제 2

모든 항의 차수가 같은 다항식을 ＿＿＿식이라 합니다.

정규화: 조건을 마음대로 정하기

d차 동차식 f는 f(ta, tb, tc) = tᵈf(a, b, c)입니다. 그래서 동차 부등식 f ≥ g(둘 다 d차)는 a, b, c를 모두 t배해도 그대로입니다.

이 성질을 이용해 a + b + c = 3이나 abc = 1처럼 편리한 조건을 덧붙여도 됩니다(정규화). 덧붙인 조건 아래에서 증명하면 원래 부등식이 모든 경우에 증명됩니다.

동차화와 정규화는 서로 반대 방향의 작업입니다. 조건이 주어지면 동차화하고, 조건이 없으면 정규화로 편한 조건을 고릅니다.

예제

a + b + c = 3인 양수에서 ab + bc + ca ≤ 3을 동차화해 증명하세요.

  1. 3 = (a + b + c)²/3이므로 부등식은 ab + bc + ca ≤ (a + b + c)²/3과 같습니다.
  2. 양변에 3을 곱하면 3(ab + bc + ca) ≤ a² + b² + c² + 2(ab + bc + ca)입니다.
  3. 정리하면 ab + bc + ca ≤ a² + b² + c²이며, 이는 SOS로 참입니다.
  4. 등호는 a = b = c = 1일 때입니다.

답: 동차화 → SOS

문제 4

2차 동차식 f에 대해 f(1, 1, 1) = 3이면 f(3, 3, 3)은?

곱이 1인 정규화

abc = 1 조건이 있으면 a = x/y, b = y/z, c = z/x로 바꾸거나, 동차화할 때 1을 (abc)^(k/3)로 바꿉니다.

예: abc = 1인 양수에서 a + b + c ≥ 3은, 3 = 3(abc)^(1/3)이므로 a + b + c ≥ 3∛(abc), 곧 산술-기하 평균 부등식입니다.

조건의 차수와 식의 차수를 맞추려면 몇 제곱을 곱해야 하는지 계산하는 것이 핵심입니다.

문제 7

a + b + c = 6인 실수에서 ab + bc + ca의 최댓값은?

정리

모든 항의 차수가 같은 식이 동차식이며, d차 동차식은 f(ta, tb, tc) = tᵈf(a, b, c)입니다.

조건이 있으면 조건을 써서 차수를 맞추는 동차화를, 조건이 없는 동차 부등식이면 a + b + c = 3, abc = 1처럼 편리한 조건을 고르는 정규화를 합니다.

동차화한 뒤에는 SOS, 재배열, 산술-기하 같은 조건 없는 도구를 그대로 씁니다.
