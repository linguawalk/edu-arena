대칭이동

점의 대칭이동

점 (x, y)를 x축에 대하여 대칭이동하면 (x, −y), y축에 대하여는 (−x, y), 원점에 대하여는 (−x, −y), 직선 y = x에 대하여는 (y, x)입니다.

대칭이동은 거울에 비친 모습입니다. x축에 대한 대칭이면 위아래만 뒤집히므로 y좌표의 부호만 바뀌고, 직선 y = x에 대한 대칭이면 x와 y의 역할이 서로 바뀝니다.

도형의 대칭이동

x축 대칭은 y 대신 −y, y축 대칭은 x 대신 −x, 원점 대칭은 둘 다, 직선 y = x 대칭은 x와 y를 서로 바꿉니다.

도형의 대칭이동은 점의 대칭이동을 식에 적용한 것입니다. 새 도형 위의 점 (x, y)를 거꾸로 대칭이동한 점이 원래 도형 위에 있어야 하므로, 식의 x나 y를 바꿔 넣습니다.

예제

원 (x − 3)² + (y + 2)² = 5를 x축, y축, 원점에 대하여 각각 대칭이동한 원의 중심을 구하세요.

  1. x축 대칭: y의 부호가 바뀜 → (3, 2)
  2. y축 대칭: x의 부호가 바뀜 → (−3, −2)
  3. 원점 대칭: 둘 다 바뀜 → (−3, 2)

답: (3, 2), (−3, −2), (−3, 2)

점에 대한 대칭

점 P를 점 M에 대하여 대칭이동한 점 P′은 M이 PP′의 중점이 되는 점입니다.

점 M에 대한 대칭은 M을 중심으로 180° 돌린 것과 같습니다. 중점 공식을 거꾸로 쓰면 P′ = 2M − P(좌표끼리)로 바로 구할 수 있습니다.

직선에 대한 대칭

점 P를 직선 l에 대하여 대칭이동한 점 P′은 PP′의 중점이 l 위에 있고, PP′이 l에 수직입니다.

직선 y = −x에 대한 대칭은 (x, y) → (−y, −x)입니다.

직선에 대한 대칭점을 구할 때는 두 조건을 식으로 세웁니다. ① PP′의 중점이 직선 위에 있다 ② PP′이 직선에 수직이다(기울기의 곱 −1). 두 식을 연립하면 대칭점이 나옵니다.

예제

점 P(1, 4)를 직선 y = x − 1에 대하여 대칭이동한 점을 구하세요.

  1. P′(a, b)라 하면 중점 ((1 + a)/2, (4 + b)/2)가 직선 위: (4 + b)/2 = (1 + a)/2 − 1
  2. PP′의 기울기 (b − 4)/(a − 1)이 −1 (직선 기울기 1과 수직)
  3. 정리하면 a − b = 5, a + b = 5
  4. a = 5, b = 0

답: (5, 0)

대칭이동과 평행이동을 이어서

여러 이동을 이어서 할 때는 순서대로 하나씩 적용합니다.

여러 이동을 이어서 할 때는 순서가 중요합니다. 대칭이동 후 평행이동한 결과와 평행이동 후 대칭이동한 결과는 일반적으로 다르므로, 문제에 적힌 순서대로 하나씩 적용합니다.

예제

A(2, 3), B(6, 1)이고 P가 x축 위를 움직일 때 AP + PB의 최솟값을 구하세요.

  1. B를 x축에 대하여 대칭이동: B′(6, −1), PB = PB′
  2. AP + PB = AP + PB′ ≥ AB′
  3. AB′ = √(16 + 16) = 4√2

답: 4√2
