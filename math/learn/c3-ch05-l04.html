높이 재기

직접 오를 수 없는 건물의 높이는, 떨어진 거리와 올려본각으로 높이 = 거리 × tan(올려본각)을 이용해 구합니다.

건물, 관측자, 건물 밑이 직각삼각형을 이루므로, 올려본각의 tan가 (높이)/(거리)입니다. 실제 측량에서는 관측자의 눈높이만큼을 더해야 하지만, 문제에서 '눈높이를 무시'하면 그대로 곱하면 됩니다. 45°이면 tan 45° = 1이라 높이와 거리가 같습니다.

강 건너 거리

건너갈 수 없는 두 지점 사이의 거리는, 이쪽에서 잰 한 변과 두 각으로 사인법칙을 씁니다.

강 건너 C를 직접 잴 수 없어도, 이쪽의 두 점 A, B 사이의 거리와 두 점에서 C를 바라본 각을 재면 삼각형 ABC가 정해집니다. 나머지 각 C = 180° − A − B를 구한 뒤 사인법칙으로 필요한 변을 계산합니다.

예제

건물에서 50m 떨어진 곳에서 꼭대기를 올려본각이 30°입니다. 눈높이 1.5m를 포함한 건물의 높이는?

  1. 눈높이 위의 부분: 50 × tan 30° = 50/√3 = 50√3/3
  2. ≈ 28.87m
  3. 건물 높이 ≈ 28.87 + 1.5 = 30.37m
  4. 주의: 눈높이를 더하는 것을 잊기 쉽습니다.

답: 약 30.4m

호수 양 끝 사이의 거리

한 지점에서 두 끝까지의 거리와 그 사이의 각을 재면 코사인법칙으로 구할 수 있습니다.

호수 양 끝처럼 그 사이를 지나갈 수 없을 때는 호수 밖의 한 점 P에서 양 끝까지의 거리와 사잇각을 잽니다. 두 변과 끼인각을 아는 상황이므로 코사인법칙으로 AB를 구합니다. 사잇각이 90°라면 피타고라스 정리로 충분합니다.

예제

AB = 80m, ∠A = 45°, ∠B = 75°일 때 A에서 강 건너 C까지의 거리를 구하세요.

  1. C = 180° − 45° − 75° = 60°
  2. AC는 ∠B와 마주 보는 변이므로 AC = AB × sin 75° / sin 60°
  3. sin 75° ≈ 0.966, sin 60° ≈ 0.866
  4. AC ≈ 80 × 1.115 ≈ 89.2m

답: 약 89m

두 번 재서 높이 구하기

밑까지의 거리를 모를 때는 두 지점에서 올려본각을 재고, 두 지점 사이의 거리와 함께 사인법칙이나 tan을 씁니다.

두 지점에서 잰 올려본각의 차이로 삼각형을 만듭니다. 첫 지점, 둘째 지점, 탑 꼭대기가 이루는 삼각형에서 한 변(두 지점 사이의 거리)과 두 각을 알므로 사인법칙으로 둘째 지점에서 꼭대기까지의 거리를 구하고, 다시 sin으로 높이를 구합니다.

예제

탑을 향해 가면서 A에서 30°, 30m 더 가까운 B에서 45°로 꼭대기를 올려봤습니다. 탑의 높이는?

  1. B에서 탑 밑까지의 거리를 x라 하면 h = x tan 45° = x
  2. A에서는 h = (x + 30) tan 30° = (x + 30)/√3
  3. x = (x + 30)/√3에서 x(√3 − 1) = 30, x = 15(√3 + 1)
  4. h = 15(√3 + 1) ≈ 41m

답: 15(√3 + 1)m ≈ 41m

문제 8

배가 북쪽으로 3km, 이어서 동쪽으로 4km 갔습니다. 출발점과의 거리는 몇 km일까요?

정리

직각이 있으면 tan과 sin, 직각이 없으면 사인법칙과 코사인법칙을 씁니다. 넓이는 (1/2)ab sin C로 구합니다.

측량 문제의 핵심은 그림을 그려 알고 있는 것(변, 각)을 표시하는 것입니다. 직각삼각형이면 삼각비, 두 각과 한 변이면 사인법칙, 두 변과 끼인각이면 코사인법칙을 고르면 됩니다.
