위치벡터로 나타내기

A, B의 위치벡터가 a, b이면 AB의 중점은 (a + b)/2, AB를 m : n으로 내분하는 점은 (mb + na)/(m + n)입니다.

위치벡터는 한 점 O를 기준으로 각 점의 위치를 벡터로 나타낸 것입니다. 내분점 공식은 AP = (m/(m + n))AB에서 p − a = (m/(m + n))(b − a)를 정리한 것으로, 코스 2의 내분점 좌표 공식과 같은 모양입니다. 좌표 대신 벡터로 쓰면 평면이든 공간이든 똑같이 적용됩니다.

무게중심

삼각형 ABC의 무게중심의 위치벡터는 (a + b + c)/3입니다.

무게중심은 한 중선을 꼭짓점 쪽에서 2 : 1로 내분하는 점입니다. BC의 중점 M의 위치벡터 (b + c)/2와 A를 2 : 1로 내분하면 (2 × (b + c)/2 + a)/3 = (a + b + c)/3이 나옵니다. 세 꼭짓점의 위치벡터의 평균입니다.

예제

A(1, 2), B(7, 2), C(4, 8)인 삼각형의 무게중심과 AB를 1 : 2로 내분하는 점을 구하세요.

  1. 무게중심: ((1 + 7 + 4)/3, (2 + 2 + 8)/3) = (4, 4)
  2. 1 : 2 내분점: (1 × b + 2 × a)/3
  3. = ((7 + 2)/3, (2 + 4)/3)
  4. = (3, 2)

답: (4, 4), (3, 2)

증명의 흐름

도형의 성질을 위치벡터의 식으로 바꾸고, 두 식이 같음을 계산으로 보입니다.

벡터 증명의 핵심은 '같은 점을 두 가지 방법으로 나타내 비교하기'입니다. 평행사변형에서 두 대각선의 중점을 각각 위치벡터로 쓰고, 평행사변형의 조건 b − a = c − d를 써서 두 식이 같음을 보이면, 두 중점이 같은 점이므로 대각선이 서로를 이등분합니다.

문제 6

삼각형의 두 변의 중점을 이은 선분의 길이는 나머지 한 변의 길이의 1/2입니다. 나머지 한 변이 10이면 그 선분의 길이는?

수직 증명

마름모 ABCD에서 AB = a, AD = b이면 두 대각선은 a + b, b − a이고 (a + b)·(b − a) = |b|² − |a|² = 0이라 수직입니다.

수직을 보이려면 내적이 0임을, 길이가 같음을 보이려면 크기의 제곱이 같음을 계산합니다. 마름모는 |a| = |b|이므로 대각선의 내적이 |b|² − |a|² = 0이 되어 수직입니다. 직사각형은 a·b = 0이므로 |a + b|² = |a − b|²이 되어 두 대각선의 길이가 같습니다.

예제

삼각형 ABC에서 AB = 4, AC = 6, BC = 8일 때 중선 AM의 길이를 벡터로 구하세요.

  1. AM = (AB + AC)/2이므로 |AM|² = (|AB|² + 2AB·AC + |AC|²)/4
  2. |BC|² = |AC − AB|² = 36 − 2AB·AC + 16 = 64에서 AB·AC = −6
  3. |AM|² = (16 − 12 + 36)/4 = 10
  4. AM = √10

답: √10

문제 8

직사각형의 두 대각선의 길이는 같을까요? (그렇다 1, 아니다 0)

정리

중점, 내분점, 무게중심을 위치벡터로 나타내면 도형의 성질을 식의 계산으로 증명할 수 있습니다.

AP = sAB + tAC에서 s + t = 1이면 P는 직선 BC 위에 있고, s, t가 모두 양수이면 선분 BC 위에 있습니다. 이때 BP : PC = t : s입니다. 이 성질로 점의 위치를 계산으로 판단할 수 있습니다.

예제

삼각형 ABC에서 AP = (3/5)AB + (2/5)AC일 때 BP : PC를 구하세요.

  1. 계수의 합 3/5 + 2/5 = 1이므로 P는 직선 BC 위
  2. 두 계수가 모두 양수이므로 선분 BC 위
  3. BP : PC = (AC의 계수) : (AB의 계수)
  4. = 2 : 3

답: 2 : 3
