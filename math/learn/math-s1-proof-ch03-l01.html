채점자는 답안만 본다

올림피아드 서술형은 보통 부분 점수로 채점합니다. 채점자는 머릿속 생각이 아니라 종이에 적힌 것만 보고 점수를 줍니다.

좋은 답안은 다섯 부분으로 이루어집니다. 무엇을 보일지 밝히기, 쓰는 문자 정의하기, 핵심 계산, 각 단계의 근거, 결론 문장.

왜 이렇게까지 써야 할까요? 'n = 2k + 1'이라고만 쓰면 k가 정수인지, 실수인지, 자연수인지 채점자는 알 수 없습니다. '따라서 성립한다'는 마지막 문장이 없으면 무엇을 증명했는지 흐려집니다. 맞는 생각을 하고도 점수를 잃는 경우의 대부분은 이런 빈칸에서 생깁니다. 이 챕터는 맞는 증명을 맞는 답안으로 바꾸는 연습입니다.

문제 1

답안에 'n = 2k + 1'이라고 쓸 때는 k가 ＿＿＿라는 말을 함께 써야 합니다.

문제 2

'n이 3의 배수가 아니면 n² − 1은 3의 배수이다'의 답안을 올바른 순서로 배열하세요.

한 줄에 한 주장, 주장마다 근거

답안의 각 줄은 하나의 주장과 그 근거로 이루어집니다. '(a − b)² ≥ 0이다. (실수의 제곱은 0 이상이므로)'처럼 씁니다.

등식을 길게 이을 때는 각 등호가 왜 성립하는지 한눈에 보이게, 바뀌는 부분이 한 번에 하나만 되도록 씁니다.

부등식을 이을 때 더 주의해야 합니다. 'A = B ≥ C = D'에서 ≥가 어디서 나왔는지, 등호는 언제 성립하는지 적어야 합니다. 최댓값·최솟값 문제라면 등호가 실제로 성립하는 경우를 찾아 쓰는 것까지가 답안입니다. 기호 ∴(따라서)와 ∵(왜냐하면)는 써도 되지만, 문장으로 쓰는 편이 오해가 적습니다.

예제

양수 a, b가 a + b = 1을 만족하면 ab ≤ 1/4임을 보이세요.

  1. 보일 것: 1/4 − ab ≥ 0.
  2. b = 1 − a이므로 1/4 − ab = 1/4 − a + a² = (a − 1/2)²이다.
  3. 실수의 제곱은 0 이상이므로 (a − 1/2)² ≥ 0이고, 따라서 ab ≤ 1/4이다.
  4. 등호는 a = 1/2, 곧 a = b = 1/2일 때 성립한다.

답: ab ≤ 1/4 (등호: a = b = 1/2)

문제 5

'a² − 2a + 1 ≥ 0'의 근거로 쓰는 문장: a² − 2a + 1 = (＿＿＿)²이고, 실수의 제곱은 0 이상이다.

자주 쓰는 표현

'임의의 x에 대해'는 '어떤 x를 골라도'라는 뜻이고, '적어도 하나 있다'는 '하나 이상 존재한다'는 뜻입니다. '서로소'는 최대공약수가 1이라는 뜻입니다.

식이 문자에 대해 대칭이면 '일반성을 잃지 않고 a ≤ b라 하자'라고 쓰고 한 경우만 다룰 수 있습니다.

왜 그래도 될까요? 식에서 a와 b를 바꾸어도 똑같다면, a > b인 경우는 이름만 바꾸면 a ≤ b인 경우와 같아집니다. 세 문자 a, b, c가 대칭이면 크기 순서 6가지를 a ≤ b ≤ c 하나로 줄일 수 있습니다. 단, 식이 정말 대칭인지 확인하고, 대칭이 아니면 이 표현을 쓰면 안 됩니다.

문제 7

서로 다른 세 실수 a, b, c를 크기 순서로 늘어놓는 방법은 모두 몇 가지인가요?

정리

답안은 보일 것, 문자 정의, 계산, 근거, 결론의 다섯 부분으로 씁니다. 문자는 범위(정수, 양수 등)와 함께 정의합니다.

한 줄에 한 주장을 쓰고, 부등호마다 근거를 적습니다. 최댓값·최솟값은 '항상 이하'와 '실제로 그 값이 됨'을 모두 보입니다.

대칭인 식은 '일반성을 잃지 않고'로 경우를 줄입니다. 답안을 다 쓰면 처음 보는 사람이 읽는다고 생각하고 한 번 다시 읽어 보세요. 정의되지 않은 문자, 근거 없는 부등호, 결론 문장 누락이 가장 흔한 빈칸입니다.
