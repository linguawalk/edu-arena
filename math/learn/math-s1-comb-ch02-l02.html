나머지를 상자로

정수를 n으로 나눈 나머지는 0, 1, …, n − 1의 n가지입니다. 그래서 정수 n + 1개 중에는 나머지가 같은 두 수가 반드시 있고, 그 두 수의 차는 n의 배수입니다.

정수 5개를 아무렇게나 골라도 차가 4의 배수인 두 수가 있습니다.

나머지를 상자로 잡는 것은 정수 문제에서 가장 흔한 비둘기집 원리의 사용법입니다. '차가 n의 배수', '합이 n의 배수'처럼 나누어떨어짐에 관한 조건은 나머지로 바꾸면 상자가 자연스럽게 정해집니다. 합이 조건이면 나머지 r과 n − r을 한 상자로 묶습니다.

문제 1

정수를 몇 개 고르면 차가 4의 배수인 두 수가 반드시 있나요? (최솟값)

문제 2

정수를 7로 나눈 나머지는 모두 ＿＿＿가지입니다.

부분합에 비둘기집 원리

정수 a₁, a₂, …, aₙ이 있으면, 연속한 몇 개(1개 이상)를 골라 합이 n의 배수가 되게 할 수 있습니다.

Sₖ = a₁ + ⋯ + aₖ (k = 1, …, n)를 봅니다. 어떤 Sₖ가 n의 배수이면 끝입니다. 아니면 n개의 Sₖ가 나머지 1, …, n − 1의 n − 1개 상자에 들어가므로, Sᵢ ≡ Sⱼ (i < j)인 두 부분합이 있습니다.

그러면 aᵢ₊₁ + ⋯ + aⱼ = Sⱼ − Sᵢ가 n의 배수입니다. 수 자체가 아니라 부분합을 상자에 넣는다는 아이디어가 핵심이고, 이 기법은 올림피아드 조합과 정수론에서 매우 자주 나옵니다.

예제

정수 a₁, …, a₅ 중 연속한 몇 개의 합이 5의 배수가 되는 것이 있음을 보이세요.

  1. 부분합 S₁ = a₁, S₂ = a₁ + a₂, …, S₅ = a₁ + ⋯ + a₅를 만듭니다.
  2. 어떤 Sₖ가 5의 배수이면 a₁ + ⋯ + aₖ가 답입니다.
  3. 아니면 다섯 개의 Sₖ가 나머지 1, 2, 3, 4의 네 상자에 들어가므로 Sᵢ ≡ Sⱼ (i < j)인 것이 있습니다.
  4. 그러면 aᵢ₊₁ + ⋯ + aⱼ = Sⱼ − Sᵢ가 5의 배수입니다.

문제 3

수열 1, 2, 4, 6, 7에서 연속한 몇 개의 합이 5의 배수가 되는 경우 중 가장 짧은 것의 길이는?

배수 관계와 홀수 부분

1부터 200까지에서 101개를 고르면 한 수가 다른 수의 배수인 두 수가 반드시 있습니다. 1부터 2n까지에서 n + 1개를 고르는 경우도 같습니다.

모든 수는 2ᵏ × m (m은 홀수)으로 하나뿐인 방법으로 쓸 수 있습니다. 홀수 부분 m을 상자로 잡으면, 1~2n의 홀수 부분은 1, 3, …, 2n − 1의 n가지입니다.

n + 1개를 고르면 홀수 부분이 같은 두 수 2ᵃm, 2ᵇm (a < b)이 있고, 작은 쪽이 큰 쪽을 나눕니다. n개로는 n + 1, n + 2, …, 2n처럼 서로 배수가 아니게 고를 수 있으므로 n + 1이 최솟값입니다. 상자를 '홀수 부분'으로 잡는 생각이 이 문제의 전부입니다.

문제 4

1부터 100까지에서 몇 개를 고르면 한 수가 다른 수의 배수인 두 수가 반드시 있나요? (최솟값)

문제 5

1부터 100까지에서 어느 수도 다른 수의 배수가 아니도록 고를 수 있는 수의 최대 개수는?

합의 조건은 짝지어 묶기

1부터 100까지에서 어느 두 수의 합도 7의 배수가 아니도록 최대한 많이 고르는 문제를 봅시다. 7로 나눈 나머지 r과 7 − r인 수는 함께 고를 수 없습니다.

나머지 1과 6, 2와 5, 3과 4를 묶으면 각 묶음에서 한쪽 나머지만 고를 수 있고, 나머지 0인 수는 하나까지만 고를 수 있습니다.

100 = 7 × 14 + 2이므로 나머지 1, 2인 수는 15개씩, 나머지 3~6과 0인 수는 14개씩입니다. 묶음마다 많은 쪽을 고르면 15 + 15 + 14 + 1 = 45개입니다. 이것이 최대이고, 46개를 고르면 비둘기집 원리에 의해 조건을 어기는 두 수가 반드시 생깁니다.

문제 6

1부터 100까지에서 어느 두 수의 합도 7의 배수가 아니도록 고를 수 있는 수의 최대 개수는?

문제 7

1부터 20까지에서 어느 두 수의 합도 4의 배수가 아니도록 고를 수 있는 수의 최대 개수는?

정리

나머지를 상자로 잡으면, 정수 n + 1개 중 차가 n의 배수인 두 수가 있습니다. 합이 조건이면 나머지 r과 n − r을 한 상자로 묶습니다.

부분합 S₁, …, Sₙ을 상자에 넣으면, 연속한 몇 개의 합이 n의 배수가 되는 것을 찾을 수 있습니다.

수를 2ᵏ × (홀수)로 쓰고 홀수 부분을 상자로 잡으면 배수 관계를 다룰 수 있습니다. 최댓값 문제는 상자마다 고를 수 있는 최대 개수를 더합니다.
