강한 귀납법

바로 앞 하나로는 부족할 때

강한 귀납법은 귀납 단계에서 'n = k일 때'만이 아니라 '1부터 k까지의 모든 n에서 성립한다'고 가정하고 n = k + 1을 보이는 방법입니다.

점화식이 두 항 전을 쓰거나, 수를 더 작은 수 여러 개로 쪼개는 문제에서 필요합니다.

왜 이렇게 가정해도 될까요? 도미노로 말하면, k + 1번째가 넘어질 때 바로 앞 것만이 아니라 앞의 모든 도미노가 이미 넘어져 있습니다. 그러니 그중 어느 것을 근거로 써도 됩니다. 보통의 귀납법과 증명하는 힘은 같지만, 가정을 더 넉넉히 쓸 수 있어 편리합니다.

문제 1

피보나치 수열 F₁ = 1, F₂ = 1, Fₙ = Fₙ₋₁ + Fₙ₋₂에서 F₁₀의 값은?

문제 2

강한 귀납법의 가정: '1 이상 ＿＿＿ 이하의 모든 자연수 n에 대해 P(n)이 성립한다'

기저는 몇 개 필요할까

점화식 aₙ = aₙ₋₁ + 2aₙ₋₂처럼 두 항 전까지 쓰면, 귀납 단계에서 aₖ와 aₖ₋₁이 모두 필요합니다.

그래서 기저도 a₁, a₂ 두 개를 확인해야 합니다. 하나만 확인하면 a₃을 구할 때 쓸 a₂에 대한 보장이 없습니다.

일반적으로 귀납 단계가 몇 칸 뒤를 쓰는지 세어 그만큼 기저를 확인합니다. 3원·5원 우표 문제처럼 3칸 뒤를 쓰면 기저도 3개입니다. 기저 개수가 모자라면 증명에 구멍이 생기므로, 답안에서 기저를 쓰기 전에 귀납 단계를 먼저 설계해 두는 것이 좋습니다.

예제

a₁ = 1, a₂ = 5, aₙ = aₙ₋₁ + 2aₙ₋₂ (n ≥ 3)일 때 aₙ = 2ⁿ + (−1)ⁿ임을 증명하세요.

  1. 기저: a₁ = 2 − 1 = 1, a₂ = 4 + 1 = 5로 두 개 모두 성립합니다.
  2. 강한 귀납 가정: k ≥ 2일 때 aₖ = 2ᵏ + (−1)ᵏ, aₖ₋₁ = 2ᵏ⁻¹ + (−1)ᵏ⁻¹이라고 가정합니다.
  3. aₖ₊₁ = aₖ + 2aₖ₋₁ = 2ᵏ + 2ᵏ + (−1)ᵏ + 2(−1)ᵏ⁻¹ = 2ᵏ⁺¹ − (−1)ᵏ = 2ᵏ⁺¹ + (−1)ᵏ⁺¹입니다.
  4. 따라서 n = k + 1일 때도 성립하고, 모든 자연수 n에서 성립합니다.

답: aₙ = 2ⁿ + (−1)ⁿ

문제 3

앞 예제의 수열에서 a₆의 값은?

우표 문제

'3원과 5원 우표만으로 8원 이상의 모든 금액을 만들 수 있다'는 강한 귀납법의 대표 예입니다.

n원을 만들 수 있으면 3원을 하나 더해 n + 3원도 만들 수 있습니다. 그래서 연속한 세 금액 8, 9, 10원만 만들면 그 뒤는 모두 따라옵니다.

강한 귀납법으로 쓰면 이렇습니다. n ≥ 11이면 n − 3 ≥ 8이고, 귀납 가정으로 n − 3원을 만들 수 있으니 3원을 더해 n원을 만듭니다. 귀납 단계가 3칸 뒤(n − 3)를 쓰므로 기저는 8, 9, 10의 세 개입니다. 일반적으로 두 우표의 금액이 서로소인 a, b이면 만들 수 없는 가장 큰 금액은 ab − a − b입니다.

예제

3원과 5원 우표로 8원 이상의 모든 금액을 만들 수 있음을 보이세요.

  1. 기저: 8 = 3 + 5, 9 = 3 + 3 + 3, 10 = 5 + 5입니다.
  2. n ≥ 11이고, 8원 이상 n원 미만의 모든 금액을 만들 수 있다고 가정합니다.
  3. n − 3은 8 이상 n 미만이므로 만들 수 있고, 여기에 3원 하나를 더하면 n원이 됩니다.
  4. 따라서 8원 이상의 모든 금액을 만들 수 있습니다.

답: 기저 8, 9, 10원

문제 7

'2 이상의 모든 자연수는 소수의 곱으로 나타낼 수 있다'의 강한 귀납법 증명을 올바른 순서로 배열하세요.

정리

강한 귀납법은 1부터 k까지의 모든 경우를 가정하고 k + 1을 보입니다. 점화식이 여러 항 전을 쓰거나 수를 더 작은 여러 수로 쪼갤 때 씁니다.

귀납 단계가 몇 칸 뒤를 쓰는지 세어 그만큼 기저를 확인합니다. 두 항 점화식이면 두 개, 3원 우표를 더하면 세 개입니다.

답안에서는 '2 이상 k 이하의 모든 n에 대해 성립한다고 가정하자'처럼 가정의 범위를 정확히 쓰고, 그 범위 안의 어떤 수에 가정을 쓰는지(n − 3 ≥ 8 등) 확인하는 줄을 넣으세요.
