덧셈과 뺄셈

동류항끼리 모아 계산합니다. 빼는 식은 괄호를 풀 때 모든 항의 부호가 바뀝니다.

아래 문제에서 A = x² + 2x − 1, B = 2x² − x + 3입니다.

왜 부호가 모두 바뀔까요? −(B)는 (−1) × B이므로 분배법칙에 따라 B의 모든 항에 −1이 곱해집니다. 첫 항만 바꾸고 나머지를 그대로 두는 실수가 가장 흔합니다.

예제

A = 2x² − x + 3, B = x² + 4x − 1일 때 A − 2B를 계산하세요.

  1. 2B = 2x² + 8x − 2
  2. A − 2B = (2x² − x + 3) − (2x² + 8x − 2)
  3. 괄호를 풀면 빼는 식의 모든 부호가 바뀝니다: 2x² − x + 3 − 2x² − 8x + 2
  4. 동류항 정리: −9x + 5

답: −9x + 5

곱셈공식 넓히기

(a + b)³ = a³ + 3a²b + 3ab² + b³

(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)

(a + b)(a² − ab + b²) = a³ + b³

이 공식들은 새로 외울 것이 아니라 분배법칙을 끝까지 적용한 결과입니다. (a + b)³ = (a + b)²(a + b)로 전개해 보면 3a²b와 3ab²이 어디서 나오는지 확인할 수 있습니다.

곱셈공식의 변형

a² + b² = (a + b)² − 2ab

a³ + b³ = (a + b)³ − 3ab(a + b)

x² + 1/x² = (x + 1/x)² − 2

왜 변형이 필요할까요? a, b를 직접 구하지 않아도 합과 곱만으로 여러 식의 값을 구할 수 있기 때문입니다. (a + b)² = a² + 2ab + b²에서 2ab를 옮기면 첫 번째 식이 나옵니다.

예제

a − b = 2, ab = 4일 때 a² + b²과 a³ − b³을 구하세요.

  1. a² + b² = (a − b)² + 2ab = 4 + 8 = 12
  2. a³ − b³ = (a − b)³ + 3ab(a − b)
  3. = 8 + 3 × 4 × 2 = 32

답: a² + b² = 12, a³ − b³ = 32

다항식의 나눗셈

A를 B로 나눈 몫을 Q, 나머지를 R이라 하면 A = BQ + R입니다.

나머지 R의 차수는 B의 차수보다 작아야 합니다.

왜 나머지의 차수가 더 작아야 할까요? 나머지의 차수가 나누는 식 이상이면 한 번 더 나눌 수 있기 때문입니다. 수의 나눗셈에서 나머지가 나누는 수보다 작아야 하는 것과 같습니다.

예제

(x³ − 2x + 4) ÷ (x + 2)의 몫과 나머지를 구하세요.

  1. x² 항이 없으므로 0x²을 채워 자리를 맞춥니다: x³ + 0x² − 2x + 4
  2. x³ ÷ x = x² → x²(x + 2) = x³ + 2x²을 빼면 −2x² − 2x + 4
  3. −2x² ÷ x = −2x → 빼면 2x + 4
  4. 2x ÷ x = 2 → 빼면 0

답: 몫 x² − 2x + 2, 나머지 0
