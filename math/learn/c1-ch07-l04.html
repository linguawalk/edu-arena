행렬과 연립일차방정식

수학의 기초 · 7. 행렬 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

연립방정식을 행렬로

x + 2y = 5, 3x + 4y = 6은 [1 2 ; 3 4][x ; y] = [5 ; 6]으로 쓸 수 있습니다.

계수만 모은 행렬 A와 미지수 행렬 X, 상수 행렬 B로 AX = B가 됩니다.

왜 행렬로 쓸까요? 계수만 모아 두면 연립방정식의 구조가 한눈에 보이고, 역행렬을 이용해 한 번의 곱셈으로 해를 구할 수 있습니다. AX를 곱해 보면 원래의 두 식이 그대로 나옵니다.

문제 1

x + 2y = 5, 3x + 4y = 6 → [1 2 ; 3 ＿＿＿][x ; y] = [5 ; 6]

문제 2

2x − y = 1, x + y = 5 → [2 −1 ; 1 ＿＿＿][x ; y] = [1 ; 5]

역행렬

AX = XA = E인 행렬 X를 A의 역행렬 A⁻¹이라고 합니다.

A = [a b ; c d]에서 ad − bc ≠ 0이면 A⁻¹ = 1/(ad − bc) × [d −b ; −c a]이고, ad − bc = 0이면 역행렬이 없습니다.

왜 ad − bc로 나눌까요? [a b ; c d][d −b ; −c a]를 곱하면 (ad − bc)E가 나옵니다. 그래서 ad − bc로 나눠 주면 E가 되고, ad − bc = 0이면 나눌 수 없어 역행렬이 없습니다.

예제

A = [3 2 ; 4 3]의 역행렬을 구하세요.

  1. ad − bc = 3 × 3 − 2 × 4 = 1
  2. A⁻¹ = (1/1) × [3 −2 ; −4 3]
  3. 확인: AA⁻¹ = [9 − 8 −6 + 6 ; 12 − 12 −8 + 9] = E

답: [3 −2 ; −4 3]

문제 5

A = [1 2 ; 2 4]의 역행렬이 있을까요? (있다 1, 없다 0)

역행렬로 풀기

AX = B의 양변 왼쪽에 A⁻¹을 곱하면 X = A⁻¹B입니다.

왜 왼쪽에 곱할까요? 행렬의 곱은 순서가 중요해서 AX = B의 양변 '왼쪽'에 A⁻¹을 곱해야 A⁻¹AX = EX = X가 됩니다. 오른쪽에 곱하면 A가 사라지지 않습니다.

예제

3x + 2y = 8, 4x + 3y = 11을 역행렬로 푸세요.

  1. A = [3 2 ; 4 3], A⁻¹ = [3 −2 ; −4 3]
  2. X = A⁻¹B = [3 × 8 − 2 × 11 ; −4 × 8 + 3 × 11]
  3. = [2 ; 1]이므로 x = 2, y = 1

답: x = 2, y = 1

문제 7

x + y = 3, x − y = 1의 해는 x = ＿＿＿, y = ＿＿＿

해가 하나로 정해질 조건

ad − bc ≠ 0이면 해가 하나뿐입니다.

ad − bc = 0이면 해가 없거나 무수히 많습니다. 두 직선이 평행하거나 일치하는 경우입니다.

ad − bc = 0이면 두 방정식의 x, y 계수의 비가 같아 두 직선의 기울기가 같습니다. 평행하면 만나지 않아 해가 없고, 일치하면 겹쳐서 해가 무수히 많습니다.

예제

kx + 3y = 2, 2x + 6y = 5의 해가 없을 때 k를 구하세요.

  1. 해가 하나로 정해지지 않으려면 ad − bc = 6k − 6 = 0, k = 1
  2. k = 1이면 x + 3y = 2와 2x + 6y = 5
  3. 첫 식의 2배는 2x + 6y = 4 ≠ 5이므로 평행 → 해가 없음

답: k = 1

문제 10

정리

AA⁻¹ = A⁻¹A = E. 대각선만 있는 행렬 [p 0 ; 0 q]의 역행렬은 [1/p 0 ; 0 1/q]입니다.

역행렬은 수의 역수와 같은 역할을 합니다. 수에서 a × (1/a) = 1이듯 AA⁻¹ = E입니다. 대각선만 있는 행렬은 대각선 성분의 역수를 취하면 됩니다.
