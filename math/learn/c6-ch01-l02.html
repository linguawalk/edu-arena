포물선의 방정식

기하 · 1. 포물선 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

y² = 4px

초점이 (p, 0), 준선이 x = −p인 포물선의 방정식은 y² = 4px입니다. 꼭짓점은 원점이고 x축이 축입니다.

왜 y² = 4px일까요? 점 (x, y)에서 초점 (p, 0)까지의 거리와 준선 x = −p까지의 거리를 같게 놓으면 √((x − p)² + y²) = |x + p|입니다. 양변을 제곱해 정리하면 x² − 2px + p² + y² = x² + 2px + p²이 되고, y² = 4px가 남습니다. p > 0이면 오른쪽, p < 0이면 왼쪽으로 열립니다.

문제 3

포물선 y² = −8x의 초점의 x좌표는?

x² = 4py

초점이 (0, p), 준선이 y = −p인 포물선은 x² = 4py입니다. y축이 축입니다.

x² = 4py는 y² = 4px에서 x와 y의 역할을 바꾼 것이라 직선 y = x에 대하여 대칭인 모양입니다. 초점과 준선도 x, y를 바꿔 (0, p), y = −p가 됩니다. p > 0이면 위로, p < 0이면 아래로 열립니다.

예제

포물선 x² = −6y의 초점과 준선을 구하세요.

  1. x² = 4py와 비교: 4p = −6, p = −3/2
  2. 초점 (0, p) = (0, −3/2)
  3. 준선 y = −p = 3/2
  4. p < 0이므로 아래로 열림

답: 초점 (0, −3/2), 준선 y = 3/2

문제 5

방정식 세우기

초점과 준선이 주어지면 p를 찾아 바로 쓰고, 지나는 점이 주어지면 대입해 p를 구합니다.

방정식을 세울 때는 '4p가 얼마인가'만 찾으면 됩니다. 초점이 주어지면 p는 꼭짓점에서 초점까지의 부호 있는 거리이고, 지나는 점이 주어지면 대입해 p를 구합니다. 계수 4p와 p를 혼동하지 않도록 주의합니다.

문제 8

꼭짓점이 원점이고 축이 x축이며 점 (2, 4)를 지나는 포물선의 초점의 x좌표는?

평행이동한 포물선

(y − b)² = 4p(x − a)는 y² = 4px를 x축 방향으로 a, y축 방향으로 b만큼 옮긴 것입니다. 꼭짓점 (a, b), 초점 (a + p, b)

평행이동하면 꼭짓점, 초점, 준선이 모두 함께 이동합니다. 일반형 y² + Ay + Bx + C = 0이 주어지면 y에 대해 완전제곱식을 만들어 (y − b)² = 4p(x − a) 꼴로 바꿉니다. 코스 2의 원의 방정식을 표준형으로 바꾼 것과 같은 방법입니다.

예제

y² + 2y − 4x + 9 = 0의 꼭짓점, 초점, 준선을 구하세요.

  1. y에 대해 완전제곱식: (y + 1)² − 1 − 4x + 9 = 0
  2. (y + 1)² = 4x − 8 = 4(x − 2), p = 1
  3. 꼭짓점 (2, −1), 초점 (3, −1)
  4. 준선 x = 2 − 1 = 1

답: 꼭짓점 (2, −1), 초점 (3, −1), 준선 x = 1

문제 11

y² − 4y − 8x + 12 = 0의 꼭짓점의 x좌표는?

정리

y²이 있으면 좌우로, x²이 있으면 위아래로 열리는 포물선입니다. 4p의 부호가 열리는 방향을 정합니다.

모양을 빠르게 판단하는 요령: 제곱된 문자가 y이면 x축 방향(좌우)으로 열리고, x이면 y축 방향(위아래)으로 열립니다. 4p가 양수이면 양의 방향, 음수이면 음의 방향입니다. 초점은 항상 포물선이 열린 쪽 안에 있습니다.

예제

꼭짓점이 원점이고 축이 y축이며 점 (6, −3)을 지나는 포물선의 방정식과 초점을 구하세요.

  1. 축이 y축이므로 x² = 4py
  2. (6, −3) 대입: 36 = −12p, p = −3
  3. x² = −12y
  4. 초점 (0, −3)

답: x² = −12y, 초점 (0, −3)
