회로가 없는 연결 그래프

회로가 없는 연결 그래프를 트리라 합니다. 꼭짓점이 n개인 트리의 변은 정확히 n − 1개입니다.

꼭짓점이 2개 이상인 트리에는 차수가 1인 꼭짓점(잎)이 적어도 2개 있습니다. 가장 긴 경로의 양 끝이 잎이기 때문입니다(극단 원리).

그래서 트리에서 잎 하나를 떼어 내면 꼭짓점 n − 1개인 트리가 되고, 귀납법으로 변이 n − 1개임을 보일 수 있습니다.

문제 1

꼭짓점이 20개인 트리의 변은 몇 개인가요?

문제 2

회로가 없는 연결 그래프를 ＿＿＿라 합니다.

트리의 여러 성질

꼭짓점 n개인 그래프에 대해 다음은 서로 같습니다: ① 트리이다 ② 연결이고 변이 n − 1개 ③ 회로가 없고 변이 n − 1개 ④ 두 꼭짓점 사이 경로가 정확히 하나.

트리의 차수의 합은 2(n − 1)입니다. 꼭짓점 10개인 트리의 차수 합은 18입니다.

연결 성분이 c개인 숲(회로가 없는 그래프)의 변은 n − c개입니다.

예제

차수가 3인 꼭짓점이 4개이고 나머지는 모두 잎(차수 1)인 트리의 꼭짓점 수를 구하세요.

  1. 잎의 수를 L이라 하면 꼭짓점은 4 + L개, 변은 3 + L개입니다.
  2. 차수의 합은 4 × 3 + L = 12 + L입니다.
  3. 악수 정리로 12 + L = 2(3 + L)이므로 L = 6입니다.
  4. 꼭짓점은 4 + 6 = 10개입니다.

답: 10개

문제 3

차수가 3인 꼭짓점이 4개이고 나머지는 모두 잎인 트리의 잎은 몇 개인가요?

문제 4

꼭짓점 30개, 연결 성분 4개인 숲의 변은 몇 개인가요?

케일리 공식

꼭짓점에 1부터 n까지 번호를 붙인 트리(번호 붙은 트리)의 개수는 nⁿ⁻²입니다(케일리 공식).

n = 3이면 3개(가운데 꼭짓점을 고르는 3가지), n = 4이면 4² = 16개입니다. n = 4의 16개는 별 모양 4개와 일직선 모양 12개입니다.

증명은 프뤼퍼 수열(트리와 길이 n − 2인 수열의 일대일 대응)로 합니다.

문제 5

꼭짓점 5개에 번호를 붙인 트리는 모두 몇 개인가요?

문제 6

꼭짓점 4개에 번호를 붙인 트리 가운데 일직선(경로) 모양은 몇 개인가요?

문제 7

꼭짓점 10개인 트리의 차수의 합은?

정리

트리는 회로가 없는 연결 그래프이며, 꼭짓점 n개이면 변은 n − 1개, 차수 합은 2(n − 1)입니다. 꼭짓점이 2개 이상이면 잎이 적어도 2개 있습니다.

연결 + 변 n − 1개, 회로 없음 + 변 n − 1개, 경로가 하나뿐인 것은 모두 트리와 같은 조건입니다. 성분 c개인 숲의 변은 n − c개입니다.

번호 붙은 트리는 nⁿ⁻²개입니다(케일리 공식).
