주기와 유계

수학 올림피아드 S1 예선 · 대수 · 4. 수열과 점화식 · 심화 · 약 20분 · 문제 12개

되풀이되는 수열

a₁ = 2, aₙ₊₁ = 1/(1 − aₙ)인 수열을 계산하면 2, −1, 1/2, 2, −1, 1/2, …로 세 항마다 되풀이됩니다. 이런 수열을 주기수열이라고 합니다.

주기를 알면 아주 뒤의 항도 바로 구할 수 있습니다. a₁₀₀은 100을 3으로 나눈 나머지 1에 해당하므로 a₁ = 2입니다.

주기는 직접 몇 항을 계산해서 찾는 것이 보통입니다. 다만 '처음 몇 항이 되풀이된다'는 관찰만으로는 증명이 아닙니다. aₙ₊₃ = aₙ이 모든 n에서 성립함을 식으로 보여야 합니다. f(x) = 1/(1 − x)라 하면 f(f(f(x))) = x임을 계산으로 보이면 됩니다.

문제 1

a₁ = 2, aₙ₊₁ = 1/(1 − aₙ)일 때 a₁₀₀의 값은?

문제 2

앞 수열의 주기는 ＿＿＿입니다.

aₙ₊₂ = aₙ₊₁ − aₙ은 주기 6

aₙ₊₂ = aₙ₊₁ − aₙ인 수열은 어떤 a₁, a₂에서 출발해도 주기가 6입니다.

aₙ₊₃ = aₙ₊₂ − aₙ₊₁ = (aₙ₊₁ − aₙ) − aₙ₊₁ = −aₙ이므로, aₙ₊₆ = −aₙ₊₃ = aₙ입니다.

이 성질 덕분에 한 주기의 합이 0이라는 것도 바로 나옵니다. a₁ + a₂ + ⋯ + a₆에서 a₄ = −a₁, a₅ = −a₂, a₆ = −a₃이기 때문입니다. 그래서 처음 100항의 합은 100을 6으로 나눈 나머지 4만큼, 곧 a₁ + a₂ + a₃ + a₄만 남습니다.

문제 3

a₁ = 1, a₂ = 3, aₙ₊₂ = aₙ₊₁ − aₙ일 때 a₂₀₂₆의 값은?

문제 4

앞 수열에서 a₁ + a₂ + ⋯ + a₁₀₀의 값은?

올라가지만 넘지 못하는 수열

a₁ = 1, aₙ₊₁ = √(aₙ + 6)인 수열은 1, √7, √(√7 + 6), …로 커지지만 3을 넘지 못합니다.

aₖ < 3이면 aₖ₊₁ = √(aₖ + 6) < √9 = 3이므로, 귀납법으로 모든 aₙ < 3입니다. 또 aₙ < 3이면 aₙ² − aₙ − 6 = (aₙ − 3)(aₙ + 2) < 0이라서 aₙ₊₁² = aₙ + 6 > aₙ², 곧 aₙ₊₁ > aₙ입니다.

이처럼 '증가하고 위로 막힌' 수열은 어떤 값으로 수렴하고, 그 값은 고정점 α = √(α + 6), 곧 α = 3입니다. 올림피아드 S1 단계에서는 수렴 자체보다 '항상 3보다 작다', '항상 증가한다'를 귀납법으로 보이는 문제가 주로 나옵니다.

예제

a₁ = 1, aₙ₊₁ = √(aₙ + 6)일 때 모든 n에 대해 0 < aₙ < 3임을 보이세요.

  1. 기저: a₁ = 1이므로 0 < a₁ < 3입니다.
  2. 귀납 가정: 0 < aₖ < 3이라고 가정합니다.
  3. 그러면 6 < aₖ + 6 < 9이므로 √6 < aₖ₊₁ < 3이고, 특히 0 < aₖ₊₁ < 3입니다.
  4. 귀납법에 의해 모든 n에 대해 0 < aₙ < 3입니다.

답: 0 < aₙ < 3

문제 5

aₙ₊₁ = √(aₙ + 6)의 양수 고정점 α는?

문제 6

aₙ₊₁ = √(2aₙ + 8)의 양수 고정점 α는?

곱으로 정의된 수열의 망원합

a₁ = 2, aₙ₊₁ = aₙ² − aₙ + 1인 수열은 2, 3, 7, 43, …으로 빠르게 커집니다. 이 수열의 역수 합 1/a₁ + 1/a₂ + ⋯에는 깔끔한 공식이 있습니다.

aₙ₊₁ − 1 = aₙ(aₙ − 1)이므로 1/(aₙ₊₁ − 1) = 1/(aₙ − 1) − 1/aₙ, 곧 1/aₙ = 1/(aₙ − 1) − 1/(aₙ₊₁ − 1)입니다.

그래서 1/a₁ + ⋯ + 1/aₙ = 1/(a₁ − 1) − 1/(aₙ₊₁ − 1) = 1 − 1/(aₙ₊₁ − 1)입니다. 점화식에서 망원합을 만들어 내는 이 기법은 레슨 1의 쪼개기와 같은 생각입니다. 점화식을 'aₙ₊₁ − (상수) = 곱' 꼴로 바꿀 수 있는지 살펴보세요.

정리

주기수열은 처음 몇 항으로 주기를 찾고, aₙ₊ₚ = aₙ을 식으로 증명한 뒤 나머지로 먼 항을 구합니다. aₙ₊₂ = aₙ₊₁ − aₙ은 주기 6, 한 주기의 합 0입니다.

증가하거나 위로 막힌 수열은 귀납법으로 '항상 α보다 작다', '항상 증가한다'를 보입니다. α는 대개 고정점입니다.

점화식을 aₙ₊₁ − c = (곱) 꼴로 바꾸면 역수 합이 망원합이 되는 경우가 있습니다. 수열 문제가 막히면 처음 5~6항을 계산해 주기, 단조성, 규칙을 먼저 찾아보세요.
