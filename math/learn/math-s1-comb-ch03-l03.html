빈 상자 없이 나누기

서로 다른 공 n개를 서로 다른 상자 k개에 빈 상자가 없게 넣는 방법의 수를 포함-배제로 구합니다. 빈 상자를 허용하면 kⁿ가지입니다.

Aᵢ를 'i번째 상자가 빈 경우'라 하면, 특정 j개 상자가 비는 경우는 (k − j)ⁿ가지입니다. 그래서 빈 상자가 없는 경우는 Σ (−1)ʲ C(k, j)(k − j)ⁿ입니다.

공 4개를 상자 3개에 빈 상자 없이 넣는 방법은 3⁴ − 3 × 2⁴ + 3 × 1⁴ = 81 − 48 + 3 = 36입니다. 함수의 말로 하면 크기 4인 집합에서 크기 3인 집합으로 가는 전사함수의 개수입니다. 공과 상자가 '서로 다른지'를 먼저 확인해야 하고, 같은 공이면 별과 막대를 씁니다.

문제 1

서로 다른 공 4개를 서로 다른 상자 3개에 빈 상자가 없게 넣는 방법은 몇 가지인가요?

문제 2

서로 다른 공 4개를 서로 다른 상자 3개에 넣는 방법은 빈 상자를 허용하면 3^＿＿＿가지입니다.

예제

서로 다른 공 5개를 서로 다른 상자 3개에 빈 상자가 없게 넣는 방법의 수를 구하세요.

  1. 빈 상자를 허용하면 3⁵ = 243가지입니다.
  2. 특정 상자 하나가 비면 2⁵ = 32가지이고, 상자를 고르는 방법이 3가지입니다.
  3. 특정 상자 두 개가 비면 1⁵ = 1가지이고, 고르는 방법이 3가지입니다.
  4. 따라서 243 − 3 × 32 + 3 × 1 = 150가지입니다.

답: 150

문제 3

서로 다른 공 4개를 서로 다른 상자 2개에 빈 상자가 없게 넣는 방법은 몇 가지인가요?

문제 4

서로 다른 공 5개를 서로 다른 상자 4개에 빈 상자가 없게 넣는 방법은 몇 가지인가요?

상한이 있는 별과 막대

x + y + z = 10, 0 ≤ x, y, z ≤ 4의 정수 해를 셉니다. 상한이 없으면 C(12, 2) = 66개입니다.

x ≥ 5인 해는 x' = x − 5로 바꾸면 x' + y + z = 5의 해이므로 C(7, 2) = 21개이고, y, z도 같습니다. 두 변수가 모두 5 이상이면 합이 10이 되려면 나머지가 0이어야 하므로 1개씩입니다.

따라서 66 − 3 × 21 + 3 × 1 = 6개입니다. 이처럼 '상한을 넘는 경우'를 집합으로 잡아 포함-배제를 쓰면, 별과 막대만으로는 다룰 수 없던 상한 조건을 처리할 수 있습니다. 주사위 눈의 합처럼 각 변수가 1~6인 문제가 대표적입니다.

문제 7

x + y + z = 12, 0 ≤ x, y, z ≤ 5를 만족하는 정수 해는 몇 개인가요?

'적어도 한 번씩 나타나는' 문자열

0~9로 만든 네 자리 비밀번호 중 0, 1, 2가 각각 적어도 한 번씩 나오는 것을 셉니다. 'i가 한 번도 나오지 않는다'를 Aᵢ로 잡습니다.

특정 j개의 숫자가 나오지 않으면 남은 10 − j개 숫자로 4자리를 채우므로 (10 − j)⁴가지입니다.

따라서 10⁴ − 3 × 9⁴ + 3 × 8⁴ − 7⁴ = 10000 − 19683 + 12288 − 2401 = 204가지입니다. 전사함수 세기와 같은 구조로, '모든 것이 적어도 한 번'이라는 조건은 언제나 '어떤 것이 빠진 경우'를 빼는 방식으로 셉니다.

문제 8

0~9로 만든 네 자리 비밀번호(0으로 시작해도 됨) 중 0, 1, 2가 각각 적어도 한 번씩 나오는 것은 몇 개인가요?

정리

서로 다른 공 n개를 서로 다른 상자 k개에 빈 상자 없이 넣는 방법은 Σ (−1)ʲ C(k, j)(k − j)ⁿ입니다.

상한 조건이 있는 x₁ + ⋯ + xₖ = n은 '상한을 넘는 변수'를 집합으로 잡아 별과 막대와 포함-배제를 함께 씁니다. 주사위의 합은 각 눈에서 1을 빼고 상한 5로 계산합니다.

'모든 것이 적어도 한 번'은 '어떤 것이 빠진 경우'를 포함-배제로 빼서 셉니다.
