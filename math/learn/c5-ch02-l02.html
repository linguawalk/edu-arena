이항정리

(a + b)ⁿ = Σ nCr aⁿ⁻ʳbʳ. 각 괄호에서 a 또는 b를 하나씩 고를 때 b를 r번 고르는 방법이 nCr가지이기 때문입니다.

(a + b)ⁿ은 괄호 n개를 곱한 것이고, 전개하면 각 괄호에서 a나 b 중 하나를 골라 곱한 항들이 모두 나옵니다. b를 r개의 괄호에서, a를 나머지에서 고르면 aⁿ⁻ʳbʳ이 되고, b를 고를 괄호를 정하는 방법이 nCr가지이므로 그 항의 계수가 nCr입니다. 계수를 조합으로 구하는 이유가 여기에 있습니다.

문제 1

(x + 1)⁴의 전개식에서 x²의 계수는?

문제 2

(x + 2)⁵의 전개식에서 x³의 계수는?

일반항

(a + b)ⁿ의 일반항은 nCr aⁿ⁻ʳbʳ입니다. 원하는 차수가 나오는 r을 먼저 찾습니다.

원하는 항을 찾을 때는 일반항 nCr aⁿ⁻ʳbʳ에서 문자의 지수를 r로 나타낸 뒤, 목표 차수와 같게 놓아 r을 구합니다. a, b에 계수나 음수가 붙어 있으면 그것까지 거듭제곱해야 합니다. (2x − 1)⁵에서 a = 2x, b = −1입니다.

예제

(3x − 2)⁴의 전개식에서 x²의 계수를 구하세요.

  1. 일반항 ₄Cᵣ(3x)⁴⁻ʳ(−2)ʳ
  2. x²이 되려면 4 − r = 2, r = 2
  3. ₄C₂ × 3² × (−2)² = 6 × 9 × 4
  4. = 216

답: 216

(x² + 1/x)⁶의 전개식에서 상수항은?

계수의 합

x = 1을 넣으면 모든 계수의 합, x = −1을 넣으면 부호가 번갈아 바뀐 합이 나옵니다.

nC0 + nC1 + … + nCn = 2ⁿ

(1 + x)ⁿ = Σ nCr xʳ에 x = 1을 넣으면 Σ nCr = 2ⁿ입니다. n개 원소의 부분집합의 개수가 2ⁿ인 것과 같은 이야기입니다. x = −1을 넣으면 부호가 번갈아 바뀐 합이 0이 되어, 짝수 번째와 홀수 번째 계수의 합이 같다는 것을 알 수 있습니다.

예제

(1 + x)¹⁰의 전개식에서 계수가 짝수 번째인 항들의 합(₁₀C₁ + ₁₀C₃ + … + ₁₀C₉)을 구하세요.

  1. x = 1: 전체 합 2¹⁰
  2. x = −1: (짝수 항 합) − (홀수 항 합) = 0
  3. 두 합이 같으므로 각각 2¹⁰ ÷ 2
  4. = 512

답: 512

두 식의 곱

두 전개식을 곱할 때는 원하는 차수를 만드는 항의 짝을 모두 찾아 계수를 곱해 더합니다.

두 식의 곱에서 특정 차수의 계수를 구할 때는, 첫째 식의 xᵖ 항과 둘째 식의 xᵠ 항을 짝지어 p + q가 목표 차수가 되는 경우를 모두 찾습니다. 각 짝의 계수를 곱해 더하면 됩니다. 두 식이 같은 꼴이면 합쳐서 하나로 계산할 수도 있습니다.

나머지와 근사

11ⁿ = (10 + 1)ⁿ으로 보고 전개하면 앞의 몇 항만으로 나머지나 근삿값을 알 수 있습니다.

11¹⁰ = (10 + 1)¹⁰을 전개하면 10², 10³, …이 곱해진 항은 모두 100으로 나누어떨어집니다. 그래서 100으로 나눈 나머지는 앞의 두 항 1 + 10 × 10 = 101에서 결정되고, 101을 100으로 나눈 나머지는 1입니다. 복잡한 거듭제곱의 나머지를 구하는 강력한 방법입니다.

예제

9¹⁰을 8로 나눈 나머지를 구하세요.

  1. 9¹⁰ = (8 + 1)¹⁰
  2. 전개하면 8이 곱해진 항은 모두 8의 배수
  3. 마지막 항 ₁₀C₁₀ × 1¹⁰ = 1만 남음
  4. 나머지 1

답: 1
