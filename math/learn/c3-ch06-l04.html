여러 가지 수열의 합

대수 · 6. 수열 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

부분분수로 나누기

1/(k(k + 1)) = 1/k − 1/(k + 1)로 나누면 합에서 가운데 항이 연달아 지워집니다.

왜 가운데 항이 지워질까요? (1 − 1/2) + (1/2 − 1/3) + … + (1/n − 1/(n + 1))을 늘어놓으면 앞 괄호의 뒤쪽 항과 다음 괄호의 앞쪽 항이 서로 부호만 달라 차례로 사라집니다. 결국 처음 1과 마지막 −1/(n + 1)만 남습니다. 이런 합을 망원급수라고도 합니다.

예제

Σ(k=1~n) 1/(k(k + 2))를 n으로 나타내세요.

  1. 부분분수: 1/(k(k + 2)) = (1/2)(1/k − 1/(k + 2))
  2. 합을 늘어놓으면 두 칸 떨어진 항끼리 지워져 앞의 1, 1/2과 뒤의 1/(n + 1), 1/(n + 2)가 남음
  3. (1/2){1 + 1/2 − 1/(n + 1) − 1/(n + 2)}
  4. 주의: 두 칸씩 지워지므로 남는 항이 네 개

답: (1/2){3/2 − 1/(n + 1) − 1/(n + 2)}

계차수열

이웃한 두 항의 차 bₙ = aₙ₊₁ − aₙ으로 만든 수열을 계차수열이라고 합니다.

aₙ = a₁ + Σ(k=1~n−1) bₖ

왜 이 식일까요? a₂ = a₁ + b₁, a₃ = a₂ + b₂ = a₁ + b₁ + b₂처럼 a₁에 계차를 차례로 더해 가면 aₙ = a₁ + b₁ + … + bₙ₋₁입니다. 계차수열이 등차수열이나 등비수열이면 그 합을 공식으로 구할 수 있어 원래 수열의 일반항을 얻습니다.

예제

2, 3, 5, 9, 17, …의 일반항을 구하세요.

  1. 계차: 1, 2, 4, 8, … (공비 2인 등비수열, bₖ = 2ᵏ⁻¹)
  2. aₙ = 2 + Σ(k=1~n−1) 2ᵏ⁻¹ = 2 + (2ⁿ⁻¹ − 1)
  3. aₙ = 2ⁿ⁻¹ + 1
  4. 확인: n = 5이면 16 + 1 = 17

답: aₙ = 2ⁿ⁻¹ + 1

근호가 있는 합

1/(√(k + 1) + √k) = √(k + 1) − √k로 유리화하면 역시 가운데 항이 지워집니다.

분모에 근호가 있으면 켤레를 곱해 유리화합니다. (√(k + 1) + √k)(√(k + 1) − √k) = 1이므로 분수가 √(k + 1) − √k라는 차로 바뀝니다. 차의 꼴이 되면 부분분수처럼 이웃한 항끼리 지워집니다.

규칙 찾기

묶음으로 반복되는 수열은 몇 번째 묶음의 몇 번째 수인지 찾습니다.

부호가 번갈아 바뀌면 두 항씩 묶어 봅니다.

묶음 수열은 각 묶음의 끝이 몇 번째 항인지 먼저 구합니다. 묶음 크기가 1, 2, 3, …이면 m번째 묶음의 끝은 1 + 2 + … + m = m(m + 1)/2번째 항입니다. 부호가 번갈아 바뀌는 합은 두 항씩 묶으면 규칙적인 수열이 됩니다.

예제

1, 2, 2, 3, 3, 3, 4, 4, 4, 4, …에서 제30항을 구하세요.

  1. 숫자 m이 m번 나옵니다. m까지의 끝은 m(m + 1)/2번째 항
  2. m = 7이면 28번째 항까지가 7
  3. 29번째부터 8이 8번 나오므로 제30항은 8

답: 8

여러 수열이 섞인 합

Σ 안이 등비수열과 다항식의 합이면 각각 따로 더합니다.

Σ의 성질 Σ(aₖ + bₖ) = Σaₖ + Σbₖ 덕분에, 섞여 있는 합은 종류별로 나눠 각각의 공식으로 계산할 수 있습니다. 등비수열 부분은 등비수열의 합 공식, 다항식 부분은 Σk, Σk² 공식을 씁니다. 부분분수 꼴이 섞여 있으면 그 부분만 망원급수로 계산합니다.
