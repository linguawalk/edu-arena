정적분 계산

f의 부정적분 하나를 F라 하면 ∫ₐᵇ f(x) dx = F(b) − F(a)입니다. 넓이를 원시함수의 차로 구할 수 있다는 뜻입니다.

왜 F(b) − F(a)일까요? 넓이 함수 S(x) = ∫ₐˣ f(t) dt를 생각하면, x가 조금 늘 때 늘어나는 넓이는 높이 f(x) × 폭이므로 S′(x) = f(x)입니다. 즉 넓이 함수는 f의 부정적분이고, S(x) = F(x) − F(a)입니다. x = b를 넣으면 넓이 = F(b) − F(a)가 됩니다. 넓이(적분)와 기울기(미분)가 연결되는 미적분의 핵심입니다.

적분으로 정의된 함수의 미분

d/dx ∫ₐˣ f(t) dt = f(x). 넓이 함수를 미분하면 원래 함수가 됩니다.

∫ₐˣ f(t) dt는 x가 위끝에 있는 '넓이 함수'입니다. x가 조금 커지면 넓이가 f(x)만큼의 높이로 늘어나므로 미분하면 f(x)가 됩니다. 아래끝 a가 무엇이든 결과는 같고, 변수 이름이 t인 것은 x와 구별하기 위해서입니다.

예제

∫₁³ (x² − 2x) dx를 계산하세요.

  1. 원시함수 F(x) = x³/3 − x²
  2. F(3) = 9 − 9 = 0
  3. F(1) = 1/3 − 1 = −2/3
  4. F(3) − F(1) = 2/3

답: 2/3

계산 연습

원시함수를 구하고 위끝, 아래끝을 차례로 넣어 뺍니다. 부호에 주의합니다.

계산은 두 단계입니다. 먼저 부정적분(원시함수)을 구하고, [F(x)]ₐᵇ로 쓴 뒤 위끝을 넣은 값에서 아래끝을 넣은 값을 뺍니다. 적분상수 C는 빼면서 사라지므로 쓰지 않아도 됩니다. 음수를 넣을 때 괄호를 쓰는 것을 잊지 마세요.

대칭성 이용

y축에 대칭인 함수(짝수 차수)는 ∫₋ₐᵃ f = 2∫₀ᵃ f, 원점에 대칭인 함수(홀수 차수)는 ∫₋ₐᵃ f = 0입니다.

왜 홀수 차수는 0일까요? y = x³처럼 원점 대칭인 그래프는 −a부터 0까지의 부분이 0부터 a까지의 부분을 뒤집은 모양이라, 정적분에서 서로 상쇄됩니다. 짝수 차수는 y축 대칭이라 양쪽이 같으므로 한쪽의 2배입니다. 식을 짝수 차수 항과 홀수 차수 항으로 나누면 계산이 크게 줄어듭니다.

예제

∫₋₂² (x⁵ + 3x² − x + 1) dx를 계산하세요.

  1. 홀수 차수 항 x⁵, −x는 대칭 구간에서 0
  2. 짝수 차수 항만 남음: 2∫₀² (3x² + 1) dx
  3. = 2[x³ + x]₀² = 2 × 10
  4. = 20

답: 20

정적분이 포함된 식

∫₀ˣ f(t) dt = g(x)이면 양변을 미분해 f(x) = g′(x)를 얻고, x = 0(아래끝)을 넣어 조건을 얻습니다.

∫ₐˣ f(t) dt = g(x) 꼴이 나오면 두 가지 정보를 뽑아냅니다. 양변을 미분하면 f(x) = g′(x), 양변에 x = a를 넣으면 좌변이 0이 되어 g(a) = 0입니다. 적분 구간이 상수인 ∫₀¹ f(t) dt는 하나의 수이므로 문자 k로 놓고 풉니다.

예제

f(x) = 3x² + 2∫₀¹ f(t) dt일 때 f(x)를 구하세요.

  1. ∫₀¹ f(t) dt = k (상수)로 놓으면 f(x) = 3x² + 2k
  2. k = ∫₀¹ (3t² + 2k) dt = 1 + 2k
  3. k = −1
  4. f(x) = 3x² − 2

답: f(x) = 3x² − 2
