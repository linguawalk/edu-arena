몇 개 확인은 증명이 아니다

가장 흔한 실수는 몇 가지 경우만 확인하고 '항상 성립한다'고 쓰는 것입니다. n² + n + 41은 n = 0, 1, …, 39에서 모두 소수이지만 n = 40이면 40² + 40 + 41 = 1681 = 41²입니다.

2^(2ⁿ) + 1은 n = 0, 1, 2, 3, 4에서 소수(3, 5, 17, 257, 65537)이지만 n = 5이면 2³² + 1 = 641 × 6700417입니다(오일러).

작은 경우의 확인은 추측을 세우는 데 쓰고, 답안에서는 반드시 일반적인 증명을 씁니다.

문제 1

n² + n + 41이 처음으로 소수가 아니게 되는 0 이상의 정수 n은?

문제 2

명제가 거짓임을 보이려면 성립하지 않는 경우 하나, 곧 ＿＿＿를 들면 됩니다.

0으로 나누기와 거짓 귀납

'a = b이면 a² = ab, a² − b² = ab − b², (a + b)(a − b) = b(a − b), a + b = b, 2b = b, 2 = 1'은 a − b = 0으로 나눈 단계에서 틀렸습니다. 식을 나눌 때는 나누는 수가 0이 아님을 밝혀야 합니다.

'모든 말은 같은 색이다'의 거짓 귀납: k마리 무리에서 한 마리를 빼고 같은 색, 다른 한 마리를 빼고 같은 색이므로 k + 1마리 모두 같은 색이라는 논증은, k + 1 = 2일 때 두 무리(각각 한 마리)에 겹치는 말이 없어 무너집니다.

귀납 단계는 모든 k에서 통해야 합니다. 특히 가장 작은 k에서 확인하세요.

예제

'2 = 1' 논증에서 잘못된 단계를 찾고 고치세요.

  1. a = b에서 a − b = 0입니다.
  2. (a + b)(a − b) = b(a − b)의 양변을 a − b로 나누면 0으로 나누는 것입니다.
  3. 0으로 나누는 것은 정의되지 않으므로 이 단계가 틀렸습니다.
  4. 답안에서 식을 나눌 때는 '(a − b ≠ 0이므로)'처럼 나누는 수가 0이 아님을 반드시 밝힙니다.

답: a − b로 나눈 단계

문제 3

'모든 말은 같은 색' 거짓 귀납에서 귀납 단계(k → k + 1)가 무너지는 k는?

문제 4

2^(2⁵) + 1 = 4294967297의 가장 작은 소인수는?

역과 이를 혼동하지 않기

'p이면 q'가 참이어도 역 'q이면 p'는 참이 아닐 수 있습니다. 'n이 4의 배수이면 n은 짝수'는 참이지만, '짝수이면 4의 배수'는 거짓(n = 2)입니다.

답안에서 '필요충분조건'(⇔)을 보이라고 하면 두 방향을 모두 증명해야 합니다. 한 방향만 쓰면 절반만 증명한 것입니다.

식 변형을 '⇔'로 이어 쓸 때는 각 단계가 거꾸로도 성립하는지 확인합니다. 양변을 제곱하는 단계는 거꾸로 성립하지 않을 수 있습니다(x = −2이면 x² = 4이지만 x ≠ 2).

문제 5

'p가 소수이면 2ᵖ − 1도 소수이다'의 반례가 되는 가장 작은 소수 p는?

문제 6

'x² = 4이면 x = 2'가 거짓임을 보이는 반례 x는?

문제 7

'A ⇔ B'를 증명하라는 문제에서 'A ⇒ B'만 증명했다면 증명한 방향은 몇 개인가요? (필요한 방향은 2개)

정리

몇 가지 경우만 확인하는 것은 증명이 아닙니다(n² + n + 41은 n = 40, 2^(2⁵) + 1은 641로 나누어떨어짐). 거짓임을 보일 때는 반례 하나면 충분합니다.

0으로 나누지 않았는지, 귀납 단계가 가장 작은 k에서도 통하는지 확인합니다.

역을 혼동하지 말고, 필요충분조건은 두 방향을 모두 증명하며, '⇔'로 이은 각 단계가 거꾸로도 성립하는지 확인합니다.
