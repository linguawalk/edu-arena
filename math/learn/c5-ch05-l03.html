이항분포

성공 확률이 p인 독립시행을 n번 할 때 성공 횟수 X의 분포를 이항분포 B(n, p)라고 합니다.

P(X = r) = nCr pʳ(1 − p)ⁿ⁻ʳ

이항분포는 앞 챕터에서 배운 독립시행의 확률을 확률분포로 정리한 것입니다. '성공'과 '실패' 두 가지(二項)만 있는 시행을 같은 조건에서 서로 영향 없이 n번 반복할 때, 성공 횟수 X가 이항분포를 따릅니다. 동전 던지기, 불량품 검사, 자유투 성공 횟수 등이 대표적인 예입니다.

문제 2

X ~ B(3, 1/3)일 때 P(X = 0)은? (기약분수로)

평균과 분산

X ~ B(n, p)이면 E(X) = np, V(X) = np(1 − p)입니다.

왜 np일까요? 한 번의 시행에서 성공 횟수(0 또는 1)의 평균은 p이고 분산은 p(1 − p)입니다. n번의 시행은 서로 독립이라 평균도 분산도 n번 더해지므로 np, np(1 − p)가 됩니다. 성공 확률 0.3으로 100번 하면 평균 30번 성공한다는 직관과도 맞습니다.

예제

자유투 성공률이 80%인 선수가 25번 던질 때 성공 횟수의 평균과 표준편차를 구하세요.

  1. X ~ B(25, 0.8)
  2. E(X) = 25 × 0.8 = 20
  3. V(X) = 25 × 0.8 × 0.2 = 4
  4. σ(X) = 2

답: 평균 20, 표준편차 2

평균과 분산으로 n, p 찾기

np와 np(1 − p)를 알면 나눠서 1 − p를 먼저 구합니다.

np와 np(1 − p)가 주어지면 둘을 나누어 np(1 − p)/np = 1 − p를 먼저 구합니다. 그러면 p가 나오고, np에 넣어 n을 구합니다. n은 자연수여야 하므로 계산 결과를 확인하고, p가 0과 1 사이인지도 확인합니다.

예제

이항분포에서 E(X) = 12, V(X) = 3일 때 n과 p를 구하세요.

  1. np = 12, np(1 − p) = 3
  2. 나누면 1 − p = 1/4, p = 3/4
  3. n = 12 ÷ (3/4) = 16
  4. 확인: 16 × 3/4 × 1/4 = 3

답: n = 16, p = 3/4

생활 속 이항분포

반복해서 같은 확률로 일어나는 일의 횟수는 이항분포로 봅니다.

이항분포인지 판단하는 세 가지 질문: 시행 횟수 n이 정해져 있는가? 매번 성공 확률 p가 같은가? 시행끼리 서로 영향이 없는가? 공을 꺼내고 다시 넣지 않으면 매번 확률이 바뀌므로 엄밀하게는 이항분포가 아닙니다. 다만 전체가 아주 크면 거의 같다고 보고 이항분포로 계산하기도 합니다.

불량률이 0.05인 제품 200개 중 불량품 수의 기댓값은?

정리

n번, 확률 p, 서로 독립이라는 세 조건이 맞으면 이항분포입니다.

이항분포의 확률 계산에는 nCr이 들어가 번거롭지만, 평균과 분산은 np와 np(1 − p)로 바로 구할 수 있습니다. n이 크면 다음 챕터에서 배울 정규분포로 근사해 확률을 계산합니다. 그때도 평균 np와 분산 np(1 − p)가 핵심 재료가 됩니다.

예제

X ~ B(6, 1/3)일 때 P(X ≤ 1)과 E(X²)을 구하세요.

  1. P(X = 0) = (2/3)⁶ = 64/729, P(X = 1) = 6(1/3)(2/3)⁵ = 192/729
  2. P(X ≤ 1) = 256/729
  3. E(X) = 2, V(X) = 6 × 1/3 × 2/3 = 4/3
  4. E(X²) = 4/3 + 4 = 16/3

답: 256/729, 16/3
