이 가이드에서 다룰 도구

국제 대회의 다항식 문제는 S2까지의 근과 계수의 관계에 더해 다섯 가지 도구를 자주 씁니다: ① 정수 계수 다항식의 나눗셈 성질 a − b | P(a) − P(b) ② 차수 논증(차수 n인 0이 아닌 다항식의 근은 n개 이하) ③ 보간과 유한 차분 ④ 기약성 판정(유리근 정리, 아이젠슈타인 판정법, 소수를 법으로 줄이기) ⑤ 복소근과 켤레, 대칭식과 뉴턴 항등식.

선수 지식은 S1 '다항식', S2 '함수방정식'과 'SOS와 부등식 전략'입니다. 나머지 정리와 인수 정리, 근과 계수의 관계가 익숙하지 않다면 S1부터 복습하세요.

각 도구를 짧게 정리한 뒤 예제를 보고, 증명 문제 여섯 개를 풀어 보세요.

정수 계수와 차수 논증

P가 정수 계수 다항식이면 정수 a, b에 대해 a − b는 P(a) − P(b)를 나눕니다. aᵏ − bᵏ = (a − b)(aᵏ⁻¹ + ⋯ + bᵏ⁻¹)이므로 항마다 a − b로 나누어떨어지기 때문입니다. 특히 P(a) mod m은 a mod m에만 달려 있습니다.

차수 논증: 차수가 n 이하인 두 다항식이 n + 1개의 서로 다른 점에서 값이 같으면 두 다항식은 같습니다. 그 차가 n + 1개의 근을 갖는 차수 n 이하의 다항식이 되므로 0이어야 하기 때문입니다.

그래서 'P(k) = (어떤 값)이 k = 0, 1, …, n에서 성립'하는 문제는 Q(x) = P(x) − (예상 식)을 만들거나, 알려진 근을 인수로 꺼내 P(x) = (예상 식) + c(x − 0)(x − 1)⋯(x − n) 꼴로 씁니다.

예제

삼차 다항식 P가 P(1) = 1, P(2) = 2, P(3) = 3, P(4) = 5를 만족할 때 P(5)를 구하세요.

  1. Q(x) = P(x) − x는 차수 3 이하이고 x = 1, 2, 3에서 0이므로 Q(x) = c(x − 1)(x − 2)(x − 3)입니다.
  2. P(4) = 4 + c · 3 · 2 · 1 = 5에서 c = 1/6입니다.
  3. P(5) = 5 + (1/6) · 4 · 3 · 2 = 5 + 4 = 9입니다.

답: 9

문제 1

위 예제의 P에서 P(0)의 값은?

유리근과 기약성

유리근 정리: 정수 계수 다항식 aₙxⁿ + ⋯ + a₀의 유리근 p/q(기약분수)는 p | a₀, q | aₙ을 만족합니다. 그래서 유리근 후보는 유한 개이고, 하나씩 대입해 확인할 수 있습니다.

아이젠슈타인 판정법: 소수 p가 최고차 계수를 제외한 모든 계수를 나누고, 최고차 계수를 나누지 않으며, p²이 상수항을 나누지 않으면 그 다항식은 유리수 계수 범위에서 더 낮은 차수의 곱으로 인수분해되지 않습니다(기약).

왜 그런가: 인수분해 g·h가 있다고 하고 p를 법으로 줄이면 우변이 aₙxⁿ이 되어 ḡ, h̄가 모두 x의 거듭제곱(상수배)이어야 합니다. 그러면 g, h의 상수항이 모두 p의 배수가 되어 상수항이 p²의 배수가 되므로 모순입니다. 이 논증 자체가 대회 답안에 그대로 쓰입니다.

문제 2

2x³ − 3x² − 3x + 2의 유리근은 모두 몇 개인가요?

대칭식과 뉴턴 항등식

근이 a, b, c인 삼차식 x³ − e₁x² + e₂x − e₃에서 e₁ = a + b + c, e₂ = ab + bc + ca, e₃ = abc입니다. 거듭제곱 합 pₖ = aᵏ + bᵏ + cᵏ는 근을 직접 구하지 않고 pₖ = e₁pₖ₋₁ − e₂pₖ₋₂ + e₃pₖ₋₃ (k ≥ 3)로 구합니다. 각 근이 x³ = e₁x² − e₂x + e₃을 만족하므로 양변에 xᵏ⁻³을 곱해 더하면 됩니다.

처음 값은 p₀ = 3, p₁ = e₁, p₂ = e₁² − 2e₂입니다.

복소근: 실수 계수 다항식의 복소근은 켤레끼리 짝을 이룹니다. 그래서 (x − z)(x − z̄) = (x − Re z)² + (Im z)²처럼 실수 범위의 이차 인수로 묶을 수 있고, 이 사실이 '음이 아닌 다항식' 문제의 열쇠가 됩니다.

예제

x³ − 6x² + 11x − 6의 세 근을 a, b, c라 할 때 a² + b² + c²를 근을 구하지 않고 구하세요.

  1. e₁ = 6, e₂ = 11, e₃ = 6입니다.
  2. p₂ = e₁² − 2e₂ = 36 − 22입니다.
  3. = 14입니다(실제로 근은 1, 2, 3이고 1 + 4 + 9 = 14로 확인됩니다).

답: 14

독학 순서와 참고 자료

추천 순서: ① 문제 1·3·5로 기본 도구를 손에 익히고 ② 문제 2로 기약성 논증을 외워 쓰듯 연습한 뒤 ③ 문제 4·6처럼 '보조 다항식을 만드는' 문제로 넘어갑니다. 막힌 문제는 '어떤 보조 다항식을 만들어야 했나'를 노트에 남기세요.

더 공부할 주제: 체비쇼프 다항식, 단위근 필터(ω를 대입해 계수의 일부만 더하기), 정수값 다항식(이항계수의 정수 결합), 근의 위치와 크기 추정(코시 상한, 루셰 정리 없이 쓰는 초등적 방법).

참고 자료(영문): Titu Andreescu·Navid Safaei 『Polynomials』 계열의 올림피아드 다항식 문제집, Arthur Engel 『Problem-Solving Strategies』의 다항식 장, AoPS의 'Polynomials' 주제 토론. 문제를 고를 때는 각국 대회와 IMO 예비 문제의 대수 분야를 참고하세요.
