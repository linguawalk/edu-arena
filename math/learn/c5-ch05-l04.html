큰수의 법칙

같은 시행을 많이 반복할수록 사건이 일어난 비율(상대도수)은 그 사건의 확률에 가까워집니다.

큰수의 법칙은 통계적 확률이 왜 믿을 만한지 알려 줍니다. 동전을 10번 던지면 앞면이 7번 나올 수도 있지만, 10,000번 던지면 비율이 0.5에서 크게 벗어나기 어렵습니다. 보험료나 카지노의 수익이 안정적인 것도 아주 많은 시행에서 비율이 확률에 가까워지기 때문입니다.

문제 1

동전을 10,000번 던질 때 앞면이 나오는 비율은 어떤 값에 가까울까요?

문제 2

주사위를 6,000번 던질 때 1의 눈은 약 몇 번 나올까요?

비율의 흩어짐

X ~ B(n, p)일 때 비율 X/n의 평균은 p, 분산은 p(1 − p)/n입니다. n이 커질수록 분산이 작아져 p 근처에 모입니다.

X/n의 평균과 분산은 앞에서 배운 E(aX), V(aX) 공식에서 나옵니다. a = 1/n이면 E(X/n) = np/n = p, V(X/n) = np(1 − p)/n² = p(1 − p)/n입니다. 분모에 n이 있어 n이 커질수록 분산이 0에 가까워지고, 비율이 p 근처로 모입니다.

예제

동전을 100번 던질 때와 10,000번 던질 때 앞면 비율의 표준편차를 비교하세요.

  1. σ(X/n) = √(p(1 − p)/n) = 0.5/√n
  2. n = 100: 0.5/10 = 0.05
  3. n = 10,000: 0.5/100 = 0.005
  4. 100배 많이 던지면 표준편차는 1/10

답: 0.05, 0.005

n과 표준편차

비율의 표준편차는 √n에 반비례합니다. n을 4배 하면 표준편차는 1/2배가 됩니다.

표준편차는 분산의 제곱근이므로 분산의 분모 n이 √n이 됩니다. 그래서 정확도를 2배로 높이려면(표준편차를 1/2로 줄이려면) 시행 횟수를 4배로 늘려야 합니다. 여론조사의 표본 크기를 정할 때 이 관계를 이용합니다.

예제

어떤 조사에서 비율의 표준편차를 0.02에서 0.01로 줄이려면 표본을 몇 배로 늘려야 할까요?

  1. 표준편차는 1/√n에 비례
  2. 1/2로 줄이려면 √n을 2배로
  3. n을 4배로
  4. 원리: 정확도를 높이는 데는 비용이 제곱으로 듦

답: 4배

확률을 모를 때

수학적 확률을 알 수 없으면 충분히 많이 반복한 상대도수로 확률을 추정합니다.

압정, 찌그러진 주사위, 새 약의 효과처럼 가능성이 같은 경우로 나눌 수 없는 사건은 수학적 확률을 구할 수 없습니다. 이때 큰수의 법칙에 기대어 많이 반복한 상대도수를 확률로 삼습니다. 반복 횟수가 많을수록 추정이 믿을 만해집니다.

문제 7

압정을 1,000번 던져 바늘이 위로 향한 것이 640번이었습니다. 추정 확률은?

문제 8

그 확률로 50번 던지면 바늘이 위로 향하는 횟수는 약 몇 번일까요?

정리

많이 반복할수록 비율은 확률에 가까워지지만, 횟수 자체의 차이는 오히려 커질 수 있습니다.

주의할 점: 앞면의 '비율'은 0.5에 가까워지지만, 앞면과 뒷면의 '횟수의 차'가 0에 가까워지는 것은 아닙니다. 횟수의 표준편차 √(np(1 − p))는 n이 커질수록 오히려 커집니다. 또 지금까지 뒷면이 많이 나왔다고 다음에 앞면이 나올 확률이 커지지는 않습니다(도박사의 오류).

예제

동전을 n번 던질 때 앞면의 '횟수'의 표준편차는 n = 100과 n = 10,000에서 각각 얼마일까요?

  1. σ(X) = √(n × 1/2 × 1/2) = √n/2
  2. n = 100: 5
  3. n = 10,000: 50
  4. 비율의 흩어짐은 줄어도 횟수의 흩어짐은 커짐

답: 5, 50
