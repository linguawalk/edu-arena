함수의 그래프

그래프

함수 y = f(x)의 그래프는 순서쌍 (x, f(x))를 좌표평면에 모두 나타낸 것입니다.

그래프는 함수를 그림으로 보여 줍니다. 점 (a, b)가 그래프 위에 있다는 것은 f(a) = b라는 뜻이므로, 그래프 위의 점 문제는 대입으로 바꿔 풀 수 있습니다.

문제 1

f(x) = 2x − 1의 그래프 위에서 x좌표가 2인 점을 표시하세요.

문제 2

f(x) = 2x − 1의 그래프가 점 (a, 7)을 지날 때 a의 값은?

함수의 그래프인지 판단하기

y축에 평행한 직선을 그었을 때 그래프와 두 점 이상에서 만나는 곳이 있으면 함수의 그래프가 아닙니다.

왜 세로선으로 판단할까요? 세로선 x = a와 그래프가 만나는 점들은 x = a에 대응하는 값들입니다. 두 점 이상에서 만나면 한 x에 값이 여러 개 대응해 함수의 정의에 어긋납니다.

문제 3

원 x² + y² = 1은 x에 대한 함수의 그래프일까요? (그렇다 1, 아니다 0)

문제 4

y = |x|의 그래프는 x에 대한 함수의 그래프일까요? (그렇다 1, 아니다 0)

절댓값 함수

y = |x − a| + b의 그래프는 꼭짓점이 (a, b)인 V자 모양입니다.

y = |x − a| + b는 y = |x|를 x축 방향으로 a, y축 방향으로 b만큼 평행이동한 그래프입니다. 꼭짓점에서 최솟값 b를 가지고, 꼭짓점 양쪽의 기울기는 −1과 1입니다.

예제

y = |x + 2| − 3의 꼭짓점과 최솟값을 구하세요.

  1. y = |x − a| + b 꼴에서 a = −2, b = −3
  2. 꼭짓점 (−2, −3)
  3. V자이므로 꼭짓점에서 최솟값 −3

답: 꼭짓점 (−2, −3), 최솟값 −3

문제 7

y = |x| + |x − 4|의 최솟값은?

범위에 따라 식이 다른 함수

범위마다 식이 다르면 각 범위에 맞는 식에 넣어 계산합니다.

그래프가 끊기지 않으려면 경계에서 두 식의 값이 같아야 합니다.

경계에서 끊기지 않으려면 왼쪽 식으로 계산한 경계값과 오른쪽 식으로 계산한 경계값이 같아야 합니다. 이 조건이 미적분에서 배울 '연속'의 기초가 됩니다.

예제

f(x) = 3x − 1 (x < 2), x² + a (x ≥ 2)의 그래프가 끊기지 않을 때 a를 구하세요.

  1. x = 2에서 왼쪽 식의 값: 3 × 2 − 1 = 5
  2. 오른쪽 식의 값: 4 + a
  3. 같아야 하므로 4 + a = 5, a = 1

답: a = 1

문제 8

f(x) = x + 1 (x < 0), x² (x ≥ 0)일 때 f(−3) + f(2)의 값은?

문제 9

f(x) = 2x (x ≤ 1), x + a (x > 1)의 그래프가 끊기지 않을 때 a의 값은?

그래프 읽기

그래프가 x축과 만나는 점의 x좌표가 f(x) = 0의 해이고, 가장 낮은 점의 y좌표가 최솟값입니다.

방정식 f(x) = k의 해는 y = f(x)와 직선 y = k의 교점의 x좌표입니다. 그래서 해의 개수를 셀 때 그래프를 그리고 직선이 몇 번 만나는지 보면 됩니다.

예제

y = |x − 2|의 그래프와 직선 y = 3의 교점의 x좌표를 모두 구하세요.

  1. |x − 2| = 3
  2. x − 2 = 3 또는 x − 2 = −3
  3. x = 5 또는 x = −1

답: x = −1, 5
