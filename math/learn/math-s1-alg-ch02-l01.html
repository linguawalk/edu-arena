곱의 합과 제곱의 합

실수 a, b, x, y에 대해 (a² + b²)(x² + y²) ≥ (ax + by)²이 성립합니다. 이것을 코시-슈바르츠 부등식이라고 합니다.

등호는 a : b = x : y, 곧 ay = bx일 때 성립합니다.

왜 성립할까요? 라그랑주 항등식 (a² + b²)(x² + y²) − (ax + by)² = (ay − bx)²이 있기 때문입니다. 오른쪽이 제곱이라 항상 0 이상입니다. AM-GM이 '합과 곱'을 잇는다면, 코시-슈바르츠는 '곱의 합과 제곱의 합'을 잇습니다. 그래서 x² + y²이 정해졌을 때 3x + 4y 같은 일차식의 최댓값을 구하는 데 특히 강합니다.

문제 1

a = 1, b = 2, x = 3, y = 4일 때 (a² + b²)(x² + y²) − (ax + by)²의 값은?

문제 2

(a² + b²)(x² + y²) − (ax + by)² = (ay − ＿＿＿)²입니다.

원 위에서 일차식의 최댓값

x² + y² = 1일 때 3x + 4y의 최댓값을 구해 봅시다. 코시-슈바르츠에서 (3² + 4²)(x² + y²) ≥ (3x + 4y)²이므로 (3x + 4y)² ≤ 25입니다.

따라서 3x + 4y ≤ 5이고, 등호는 x : y = 3 : 4일 때입니다. x² + y² = 1과 함께 풀면 x = 3/5, y = 4/5입니다.

기하로 보면 원 x² + y² = 1 위의 점과 직선 3x + 4y = k가 만나는 가장 큰 k를 구한 것입니다. 이처럼 제곱의 합이 정해져 있고 일차식을 묻는다면 계수들을 짝으로 잡아 코시-슈바르츠를 씁니다. 최솟값은 등호를 반대 방향, 곧 x : y = −3 : −4로 잡아 −5입니다.

예제

x² + y² = 1일 때 3x + 4y의 최댓값을 구하세요.

  1. 코시-슈바르츠에서 (3² + 4²)(x² + y²) ≥ (3x + 4y)²입니다.
  2. x² + y² = 1이므로 (3x + 4y)² ≤ 25, 곧 3x + 4y ≤ 5입니다.
  3. 등호는 x/3 = y/4일 때이고, x² + y² = 1과 함께 풀면 x = 3/5, y = 4/5입니다.
  4. 이때 9/5 + 16/5 = 5이므로 최댓값은 5입니다.

문제 5

x² + y² = 1에서 3x + 4y가 최대일 때 x의 값을 분수로 쓰세요.

일차식이 정해졌을 때 제곱합의 최솟값

반대로 2x + 3y = 13일 때 x² + y²의 최솟값도 같은 부등식으로 구합니다. (x² + y²)(2² + 3²) ≥ (2x + 3y)² = 169이므로 x² + y² ≥ 13입니다.

등호는 x : y = 2 : 3일 때이고, 2x + 3y = 13과 함께 풀면 x = 2, y = 3입니다.

기하로는 원점에서 직선 2x + 3y = 13까지의 거리의 제곱을 구한 것입니다. 직선 ax + by = c에서 원점까지 거리가 |c|/√(a² + b²)라는 공식은 사실 코시-슈바르츠의 등호 조건과 같은 이야기입니다. 한 부등식이 최댓값과 최솟값 문제를 모두 해결해 준다는 점이 코시-슈바르츠의 장점입니다.

정리

(a² + b²)(x² + y²) ≥ (ax + by)²이고, 등호는 a : b = x : y일 때입니다. 증명은 라그랑주 항등식 (a² + b²)(x² + y²) − (ax + by)² = (ay − bx)²입니다.
