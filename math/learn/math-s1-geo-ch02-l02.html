원에 내접하는 사각형

수학 올림피아드 S1 예선 · 기하 · 2. 원의 성질 · 심화 · 약 20분 · 문제 11개

마주 보는 각의 합은 180°

원에 내접하는 사각형 ABCD에서 마주 보는 두 각의 합은 180°입니다. ∠A와 ∠C는 각각 호 BCD와 호 BAD에 대한 원주각이고, 두 호를 합하면 원 전체(중심각 360°)이기 때문입니다.

거꾸로 사각형의 마주 보는 두 각의 합이 180°이면 그 사각형은 원에 내접합니다.

그래서 '네 점이 한 원 위에 있다'를 보이고 싶을 때 마주 보는 각의 합이 180°임을 보이면 됩니다. 또 한 꼭짓점의 외각은 마주 보는 내각과 같습니다. 이 사실들은 그림에서 보이지 않는 원을 찾아 각을 옮기는 데 매우 자주 씁니다.

문제 1

원에 내접하는 사각형 ABCD에서 ∠A = 75°일 때 ∠C는 몇 도인가요?

문제 2

원에 내접하는 사각형의 마주 보는 두 각의 합은 ＿＿＿°입니다.

문제 3

원에 내접하는 사각형 ABCD에서 ∠B = 95°일 때 ∠D는 몇 도인가요?

외각과 마주 보는 내각

원에 내접하는 사각형 ABCD에서 변 BC를 C 쪽으로 늘이면, C에서의 외각은 180° − ∠C = ∠A입니다.

곧 한 꼭짓점의 외각은 그와 마주 보는 꼭짓점의 내각과 같습니다.

사각형의 세 각의 비가 주어진 문제도 이 성질로 풉니다. ∠A : ∠B : ∠C = 2 : 3 : 4이면 ∠A + ∠C = 180°에서 2k + 4k = 180°, k = 30°이므로 ∠B = 90°이고, ∠D = 180° − ∠B = 90°입니다. 마주 보는 각끼리 짝지어 식을 세우는 것이 요령입니다.

예제

원에 내접하는 사각형 ABCD에서 ∠A : ∠B : ∠C = 2 : 3 : 4일 때 ∠D를 구하세요.

  1. ∠A = 2k, ∠B = 3k, ∠C = 4k로 놓습니다.
  2. ∠A + ∠C = 180°이므로 6k = 180°, k = 30°입니다.
  3. ∠B = 90°입니다.
  4. ∠D = 180° − ∠B = 90°입니다.

답: 90°

원에 내접하는 사각형 ABCD에서 꼭짓점 C의 외각이 80°일 때 ∠A는 몇 도인가요?

문제 5

원에 내접하는 사각형 ABCD에서 ∠ABD = 30°, ∠DBC = 40°일 때 ∠CAD는 몇 도인가요?

네 점이 한 원 위에 있을 조건

네 점 A, B, C, D가 한 원 위에 있을 조건은 두 가지로 확인합니다. 사각형 ABCD의 마주 보는 각의 합이 180°이거나, 선분 BC를 A와 D가 같은 쪽에서 같은 각으로 바라보면(∠BAC = ∠BDC) 됩니다.

예를 들어 삼각형 ABC에서 B, C에서 마주 보는 변에 내린 수선의 발을 E, F라 하면 ∠BEC = ∠BFC = 90°이므로 B, C, E, F는 BC를 지름으로 하는 원 위에 있습니다.

그러면 내접사각형 BCEF에서 ∠AEF = ∠ABC (외각 = 마주 보는 내각)입니다. 그림에 원이 그려져 있지 않아도 이런 '숨은 원'을 찾으면 각을 쉽게 옮길 수 있습니다. 올림피아드 기하에서 가장 자주 쓰는 기술 중 하나입니다.

문제 6

삼각형 ABC에서 B, C에서 마주 보는 변에 내린 수선의 발을 각각 E, F라 하고 ∠ABC = 70°일 때 ∠AEF는 몇 도인가요?

프톨레마이오스 정리

원에 내접하는 사각형 ABCD에서 AC × BD = AB × CD + AD × BC입니다. 두 대각선의 곱은 마주 보는 변의 곱의 합과 같습니다.

직사각형에서는 피타고라스 정리가 됩니다. 대각선이 d, 변이 a, b이면 d × d = a × a + b × b이기 때문입니다.

정삼각형 ABC의 외접원에서 호 BC 위의 점 P에 대해 이 정리를 쓰면 PA × BC = PB × CA + PC × AB이고, 세 변이 같으므로 PA = PB + PC가 됩니다. 증명은 S2에서 닮음으로 다루고, 여기서는 계산에 써 봅니다.

문제 7

정삼각형 ABC의 외접원에서 A를 포함하지 않는 호 BC 위의 점 P에 대해 PB = 3, PC = 5일 때 PA의 길이는?

정리

원에 내접하는 사각형에서 마주 보는 두 각의 합은 180°이고, 한 꼭짓점의 외각은 마주 보는 내각과 같습니다.

네 점이 한 원 위에 있음은 마주 보는 각의 합 180° 또는 같은 쪽에서 같은 각으로 바라보는 것으로 보입니다. 직각 두 개가 같은 선분을 바라보면 그 선분을 지름으로 하는 원이 있습니다.

원에 내접하는 사각형에서 AC × BD = AB × CD + AD × BC입니다(프톨레마이오스 정리).
