수열의 귀납적 정의

대수 · 7. 수학적 귀납법 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

귀납적 정의

첫째항 a₁과, 이웃한 항 사이의 관계식(점화식)으로 수열을 정하는 것을 귀납적 정의라고 합니다.

a₁ = 2, aₙ₊₁ = aₙ + 3이면 2, 5, 8, 11, …입니다.

일반항이 '몇 번째 항은 얼마'를 바로 알려 주는 식이라면, 귀납적 정의는 '앞 항에서 다음 항을 만드는 규칙'입니다. 첫째항이 정해지고 규칙이 있으면 둘째 항, 셋째 항이 차례로 모두 정해지므로 수열 전체가 하나로 결정됩니다. 컴퓨터 프로그램의 반복문과 같은 생각입니다.

문제 1

a₁ = 2, aₙ₊₁ = aₙ + 3일 때 a₄의 값은?

문제 2

a₁ = 1, aₙ₊₁ = 2aₙ일 때 a₅의 값은?

등차·등비수열의 점화식

aₙ₊₁ − aₙ = d이면 등차수열, aₙ₊₁ = raₙ이면 등비수열입니다.

2aₙ₊₁ = aₙ + aₙ₊₂이면 등차수열, aₙ₊₁² = aₙaₙ₊₂이면 등비수열입니다.

2aₙ₊₁ = aₙ + aₙ₊₂는 '가운데 항이 양옆의 평균'이라는 등차중항의 조건이 모든 곳에서 성립한다는 뜻이고, aₙ₊₁² = aₙaₙ₊₂는 등비중항의 조건입니다. 점화식의 모양만 보고 등차·등비수열을 알아보면 일반항 공식을 바로 쓸 수 있습니다.

예제

a₁ = 4, aₙ₊₁ = aₙ − 3으로 정의된 수열의 일반항과 제10항을 구하세요.

  1. aₙ₊₁ − aₙ = −3이므로 공차 −3인 등차수열
  2. aₙ = 4 + (n − 1)(−3) = 7 − 3n
  3. a₁₀ = 7 − 30 = −23
  4. 확인: 4, 1, −2, −5, …

답: aₙ = 7 − 3n, a₁₀ = −23

문제 5

a₁ = 1, a₂ = 4이고 2aₙ₊₁ = aₙ + aₙ₊₂일 때 a₆의 값은?

aₙ₊₁ = aₙ + f(n)

n = 1, 2, 3, …을 차례로 넣어 더해 가면 aₙ = a₁ + f(1) + f(2) + … + f(n − 1)입니다.

a₂ = a₁ + f(1), a₃ = a₂ + f(2) = a₁ + f(1) + f(2)처럼 더해진 것이 쌓여 갑니다. 제n항까지 f(1)부터 f(n − 1)까지 n − 1개가 더해지므로 aₙ = a₁ + Σ(k=1~n−1) f(k)입니다. f(n)이 계차수열의 역할을 합니다.

예제

a₁ = 2, aₙ₊₁ = aₙ + 2n + 1일 때 a₅를 구하세요.

  1. 차례로: a₂ = 2 + 3 = 5
  2. a₃ = 5 + 5 = 10, a₄ = 10 + 7 = 17
  3. a₅ = 17 + 9 = 26
  4. 일반항: aₙ = 2 + Σ(k=1~n−1)(2k + 1) = n² + 1

답: 26

문제 6

a₁ = 1, aₙ₊₁ = aₙ + n일 때 a₅의 값은?

문제 7

a₁ = 1, aₙ₊₁ = aₙ + 2n일 때 a₁₀의 값은?

aₙ₊₁ = f(n)aₙ

차례로 곱해 가면 aₙ = a₁ × f(1) × f(2) × … × f(n − 1)입니다.

곱의 꼴도 더하기와 같은 원리로 쌓입니다. a₂ = f(1)a₁, a₃ = f(2)a₂ = f(2)f(1)a₁처럼 곱해진 것이 쌓이므로 aₙ = a₁ × f(1) × f(2) × … × f(n − 1)입니다. f(n)이 분수이면 이웃한 분자와 분모가 약분되는 경우가 많습니다.

문제 9

a₁ = 1, aₙ₊₁ = 2ⁿaₙ일 때 a₄의 값은?

여러 가지 점화식

앞의 두 항으로 다음 항을 정하거나, 몇 항 계산해 보면 반복되는 경우도 있습니다.

피보나치수열처럼 두 항으로 다음 항을 정하는 점화식은 첫 두 항이 모두 주어져야 수열이 정해집니다. 규칙이 복잡해 보이면 처음 몇 항을 직접 계산해 보세요. 같은 값이 다시 나오면 그다음부터는 주기적으로 반복됩니다.

예제

a₁ = 2, aₙ₊₁ = 1 − 1/aₙ일 때 a₂₀을 구하세요.

  1. a₂ = 1 − 1/2 = 1/2
  2. a₃ = 1 − 2 = −1, a₄ = 1 + 1 = 2
  3. a₄ = a₁이므로 주기 3으로 반복
  4. 20 = 3 × 6 + 2이므로 a₂₀ = a₂ = 1/2

답: 1/2
