타원 위의 점에서의 접선

타원 x²/a² + y²/b² = 1 위의 점 (x₁, y₁)에서의 접선은 x₁x/a² + y₁y/b² = 1입니다. 원의 접선 공식과 같은 모양입니다.

왜 원의 접선과 같은 모양일까요? 타원 x²/a² + y²/b² = 1은 원 X² + Y² = 1을 가로로 a배, 세로로 b배 늘인 것입니다(X = x/a, Y = y/b). 원 위의 점 (X₁, Y₁)에서의 접선 X₁X + Y₁Y = 1을 다시 x, y로 바꾸면 x₁x/a² + y₁y/b² = 1이 됩니다. 늘이는 변환은 접하는 관계를 그대로 유지하기 때문입니다.

문제 1

타원 x²/8 + y²/2 = 1 위의 점 (2, 1)에서의 접선은 x + 2y = ＿＿＿

기울기가 주어진 접선

타원에 접하고 기울기가 m인 직선은 y = mx ± √(a²m² + b²)입니다.

기울기가 m인 접선 공식은 y = mx + k를 타원에 대입한 이차방정식의 판별식이 0이 되는 조건에서 k² = a²m² + b²을 얻어 나옵니다. 타원은 닫힌 곡선이라 같은 기울기의 접선이 위아래(또는 좌우)로 두 개 있습니다.

예제

타원 x²/16 + y²/9 = 1 위의 점 (−4, 0)과 (0, 3)에서의 접선과 두 접선의 교점을 구하세요.

  1. (−4, 0): −4x/16 + 0 = 1 → x = −4
  2. (0, 3): 0 + 3y/9 = 1 → y = 3
  3. 꼭짓점에서의 접선은 축에 수직인 직선
  4. 두 접선의 교점 (−4, 3)

답: x = −4, y = 3

판별식으로 접할 조건

직선을 타원의 방정식에 대입한 이차방정식의 판별식이 0이면 접합니다.

판별식 방법은 공식을 잊었을 때도 쓸 수 있는 기본 방법입니다. 직선의 식을 타원의 방정식에 대입하면 x에 대한 이차방정식이 되고, 중근이면 직선과 타원이 한 점에서만 만나므로 접합니다. 포물선, 원과 똑같은 방법이라 이차곡선 전체에 쓸 수 있습니다.

예제

타원 x²/9 + y²/4 = 1에 접하고 기울기가 2인 직선을 구하세요.

  1. 공식: y = 2x ± √(9 × 4 + 4)
  2. = 2x ± √40
  3. = 2x ± 2√10
  4. 확인: 판별식으로 구해도 k² = 40

답: y = 2x ± 2√10

두 접선이 수직으로 만나는 점

타원 밖에서 그은 두 접선이 수직으로 만나는 점들은 원 x² + y² = a² + b² 위에 있습니다.

두 접선이 수직으로 만나는 점들의 자취가 원이 된다는 것은 아름다운 성질입니다. 이 원을 준원이라 부르며 반지름은 √(a² + b²)입니다. 타원을 감싸는 직사각형의 꼭짓점 (±a, ±b)가 모두 이 원 위에 있는 것으로 확인할 수 있습니다.

문제 8

그 원 위의 점에서 타원에 그은 두 접선이 이루는 각은 몇 도일까요?

정리

위의 점이 주어지면 x₁x/a² + y₁y/b² = 1, 기울기가 주어지면 y = mx ± √(a²m² + b²)을 씁니다.

접선 문제의 유형은 포물선과 같습니다. 접점이 주어지면 접선 공식, 기울기가 주어지면 기울기 공식, 곡선 밖의 점이 주어지면 접점을 (x₁, y₁)로 놓거나 기울기를 m으로 놓고 조건을 세웁니다.

예제

타원 x²/5 + y²/4 = 1 밖의 점 (0, 3)에서 그은 두 접선의 기울기를 구하세요.

  1. 기울기 m인 접선 y = mx ± √(5m² + 4)이 (0, 3)을 지남
  2. 3 = √(5m² + 4)이므로 5m² + 4 = 9
  3. m² = 1
  4. m = ±1

답: ±1
