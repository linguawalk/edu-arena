유리식

분모에 문자가 있는 식을 분수식, 다항식과 분수식을 합쳐 유리식이라고 합니다.

분모가 0이 되는 값은 제외하고, 분수처럼 약분과 통분을 합니다.

유리식은 분수의 계산 규칙을 그대로 따릅니다. 다만 분모에 문자가 있어 그 문자가 특정한 값일 때 분모가 0이 될 수 있으므로, 그런 값은 항상 제외한다는 조건이 따라다닙니다.

곱셈과 나눗셈

분자는 분자끼리, 분모는 분모끼리 곱하고, 나눗셈은 뒤의 식을 뒤집어 곱합니다. 인수분해해 두면 약분이 쉽습니다.

왜 인수분해부터 할까요? 분자와 분모에 공통인 인수가 보여야 약분할 수 있기 때문입니다. x² − 4를 (x + 2)(x − 2)로 바꿔 두면 분모의 x − 2와 바로 약분됩니다.

예제

(x² − 9)/(x² + 2x) ÷ (x − 3)/x를 간단히 하세요.

  1. 나눗셈은 뒤집어 곱합니다: (x² − 9)/(x² + 2x) × x/(x − 3)
  2. 인수분해: (x + 3)(x − 3)/(x(x + 2)) × x/(x − 3)
  3. 약분하면 (x + 3)/(x + 2)

답: (x + 3)/(x + 2)

부분분수

1/(AB) = (1/(B − A))(1/A − 1/B)처럼 나눠 쓰면 여러 분수의 합이 연쇄적으로 지워집니다.

예: 1/(x(x + 1)) = 1/x − 1/(x + 1)

부분분수가 유용한 이유는 합을 구할 때 이웃한 항끼리 서로 지워지기 때문입니다. (1/1 − 1/2) + (1/2 − 1/3) + …처럼 가운데가 모두 사라지고 처음과 끝만 남습니다.

예제

1/(2·4) + 1/(4·6) + 1/(6·8)을 계산하세요.

  1. 1/(k(k + 2)) = (1/2)(1/k − 1/(k + 2))
  2. 합 = (1/2)(1/2 − 1/4 + 1/4 − 1/6 + 1/6 − 1/8)
  3. = (1/2)(1/2 − 1/8) = (1/2)(3/8) = 3/16

답: 3/16

번분수

분수 안에 분수가 있으면 분자와 분모에 같은 식을 곱해 정리합니다.

번분수는 분모와 분자에 작은 분모들의 공통배수를 곱하면 한 번에 정리됩니다. 1/(1 + 1/x)은 분모와 분자에 x를 곱해 x/(x + 1)이 됩니다.

예제

x + 1/x = 4일 때 x² + 1/x²과 x³ + 1/x³을 구하세요.

  1. x² + 1/x² = (x + 1/x)² − 2 = 16 − 2 = 14
  2. x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x)
  3. = 64 − 12 = 52

답: 14, 52
