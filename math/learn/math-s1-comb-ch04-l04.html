연속하지 않는 부분집합

{1, 2, …, n}의 부분집합 중 연속한 두 수를 포함하지 않는 것(공집합 포함)의 개수를 aₙ이라 합시다. n을 포함하지 않으면 aₙ₋₁개, 포함하면 n − 1은 빠지므로 aₙ₋₂개입니다.

그래서 aₙ = aₙ₋₁ + aₙ₋₂, a₁ = 2, a₂ = 3이고, aₙ = Fₙ₊₂ (피보나치 수)입니다.

세기 1장에서는 '연속하지 않는 k개 고르기'를 C(n − k + 1, k)로 셌습니다. 그 값을 k에 대해 모두 더한 것이 aₙ이므로, Σ C(n − k + 1, k) = Fₙ₊₂라는 항등식도 얻습니다. 같은 것을 두 방법으로 세면 항등식이 나온다는 것을 다시 확인할 수 있습니다.

문제 1

{1, 2, …, 10}의 부분집합 중 연속한 두 수를 포함하지 않는 것은 몇 개인가요? (공집합 포함)

문제 2

A, B, C로 만든 길이 n의 문자열 중 A가 짝수 번 나오는 것의 개수를 aₙ이라 하면 aₙ₊₁ = aₙ + 3^＿＿＿입니다.

짝수 번 나오는 문자열

앞 문제의 점화식 aₙ₊₁ = aₙ + 3ⁿ, a₁ = 2를 풀면 aₙ = (3ⁿ + 1)/2입니다. 계차수열이므로 aₙ = 2 + 3 + 3² + ⋯ + 3ⁿ⁻¹로 계산됩니다.

'짝수 번'과 '홀수 번'은 서로 짝을 이루므로 둘을 함께 추적하는 것이 요령입니다. 짝수 번인 것을 aₙ, 홀수 번인 것을 bₙ이라 하면 aₙ + bₙ = 3ⁿ이라 하나만 알면 됩니다.

이 결과는 (B + C + A)ⁿ과 (B + C − A)ⁿ을 생각하면 한 줄로도 나옵니다. A에 1과 −1을 넣은 3ⁿ과 1ⁿ의 평균이 짝수 번인 문자열의 수이기 때문입니다. 이 아이디어는 S2의 생성함수로 이어집니다.

예제

A, B, C로 만든 길이 3의 문자열 중 A가 짝수 번(0번 포함) 나오는 것의 개수를 구하세요.

  1. a₁ = 2 (B, C)입니다.
  2. a₂ = a₁ + 3¹ = 5입니다.
  3. a₃ = a₂ + 3² = 5 + 9 = 14입니다.
  4. 공식 (3³ + 1)/2 = 14와 같습니다.

답: 14

문제 3

A, B, C로 만든 길이 4의 문자열 중 A가 짝수 번 나오는 것은 몇 개인가요?

홀수들의 순서 있는 합

n을 홀수들의 순서 있는 합으로 나타내는 방법의 수를 oₙ이라 합시다. 4 = 3 + 1 = 1 + 3 = 1 + 1 + 1 + 1이므로 o₄ = 3입니다.

마지막 항이 1이면 앞은 n − 1의 표현이고, 마지막 항이 3 이상이면 그것을 2 줄이면 n − 2의 표현이 됩니다. 그래서 oₙ = oₙ₋₁ + oₙ₋₂, o₁ = 1, o₂ = 1이고 oₙ = Fₙ입니다.

'마지막 항을 2 줄인다'는 대응이 핵심입니다. 마지막 항이 1인 경우와 3 이상인 경우가 겹치지 않고, 줄인 뒤에도 홀수라는 조건이 유지됩니다. 점화식을 세우는 방법이 '마지막 조각을 떼어 내기'만 있는 것이 아니라 '마지막 조각을 줄이기'도 있다는 점을 기억하세요.

문제 4

8을 홀수들의 순서 있는 합으로 나타내는 방법은 몇 가지인가요?

문제 5

1원과 2원 동전으로 10원을 내는 방법은 몇 가지인가요? (동전의 순서는 상관없음)

순서가 없는 동전 세기

동전의 순서를 따지지 않으면, 가장 큰 동전부터 몇 개 쓸지 차례로 정합니다. 1원, 2원, 5원으로 10원을 내는 방법은 5원을 0, 1, 2개 쓰는 경우로 나누어 셉니다.

5원을 0개 쓰면 1, 2원으로 10원을 내는 6가지, 1개 쓰면 1, 2원으로 5원을 내는 3가지, 2개 쓰면 1가지로 모두 10가지입니다.

순서가 있으면 마지막 동전으로 점화식을 세우고(계단 문제), 순서가 없으면 동전 종류를 하나씩 늘려 가며 셉니다. 같은 '동전 문제'라도 순서가 있는지 없는지에 따라 방법이 완전히 달라지므로, 문제를 읽을 때 가장 먼저 확인해야 합니다.

문제 6

1원, 2원, 5원 동전으로 10원을 내는 방법은 몇 가지인가요? (순서는 상관없음)

문제 7

1원, 2원, 5원 동전으로 7원을 내는 방법은 몇 가지인가요? (순서는 상관없음)

정리

{1, …, n}의 연속하지 않는 부분집합은 Fₙ₊₂개, n을 홀수의 순서 있는 합으로 쓰는 방법은 Fₙ가지입니다. 둘 다 점화식 aₙ = aₙ₋₁ + aₙ₋₂에서 나옵니다.

'짝수 번'과 '홀수 번'은 함께 추적합니다. A가 짝수 번 나오는 길이 n의 3글자 문자열은 (3ⁿ + 1)/2개입니다.

점화식은 마지막 조각을 떼어 내거나 줄여서 세웁니다. 동전 문제는 순서가 있으면 점화식으로, 없으면 큰 동전부터 개수를 정해서 셉니다.
