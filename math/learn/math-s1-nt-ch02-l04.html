ax ≡ b (mod m) 풀기

ax ≡ b (mod m)는 ax + my = b와 같습니다. 그래서 gcd(a, m) | b일 때만 해가 있습니다.

gcd(a, m) = 1이면 aa' ≡ 1 (mod m)인 a'가 있고, 이것을 a의 역원이라고 합니다. 양변에 a'를 곱하면 x ≡ a'b (mod m)으로 해가 하나 정해집니다.

3의 7을 법으로 한 역원은 5입니다(3 × 5 = 15 ≡ 1). 그래서 3x ≡ 2 (mod 7)의 해는 x ≡ 5 × 2 = 10 ≡ 3입니다. 법이 작으면 0부터 m − 1까지 넣어 보는 것이 가장 빠르고, 크면 호제법으로 베주 항등식을 구하는 것이 확실합니다.

문제 1

3x ≡ 1 (mod 7)의 해 중 0 ≤ x < 7인 것은?

문제 2

3 × ＿＿＿ ≡ 1 (mod 11)입니다. (0 이상 10 이하로)

해가 여러 개일 때

d = gcd(a, m)이 b를 나누면, ax ≡ b (mod m)는 0 ≤ x < m 범위에 정확히 d개의 해를 가집니다.

양변과 법을 d로 나누면 (a/d)x ≡ b/d (mod m/d)가 되고, a/d와 m/d는 서로소라 해가 하나 정해집니다. 그 해에 m/d씩 더한 것이 원래 범위의 d개 해입니다.

예를 들어 6x ≡ 4 (mod 10)은 d = 2이므로 3x ≡ 2 (mod 5)로 바꿉니다. 3의 역원은 2이므로 x ≡ 4 (mod 5)이고, 0 ≤ x < 10에서는 x = 4, 9의 두 해입니다. 레슨 1에서 본 '나누면 법도 줄어든다'는 규칙을 그대로 쓴 것입니다.

중국인의 나머지 정리

법 m₁, m₂, …, mₖ가 서로 서로소이면, 연립합동식 x ≡ a₁ (mod m₁), …, x ≡ aₖ (mod mₖ)는 m₁m₂⋯mₖ를 법으로 정확히 하나의 해를 가집니다.

x ≡ 2 (mod 3), x ≡ 3 (mod 5)라면 15를 법으로 해가 하나 있고, 그것은 x ≡ 8입니다.

푸는 방법은 차례로 대입하는 것입니다. 첫 조건에서 x = 3k + 2로 놓고 두 번째 조건에 넣어 k의 조건을 구합니다. 법이 서로소가 아니면 해가 없거나 여러 개일 수 있으므로, 조건이 서로 모순되지 않는지 먼저 확인합니다.

예제

3으로 나누면 2, 5로 나누면 3, 7로 나누면 2가 남는 가장 작은 자연수를 구하세요.

  1. x ≡ 2 (mod 3), x ≡ 2 (mod 7)이므로 x ≡ 2 (mod 21)입니다.
  2. x = 21k + 2를 x ≡ 3 (mod 5)에 넣으면 21k + 2 ≡ k + 2 ≡ 3, 곧 k ≡ 1 (mod 5)입니다.
  3. k = 1이면 x = 23입니다.
  4. 따라서 가장 작은 자연수는 23이고, 모든 해는 x ≡ 23 (mod 105)입니다.

답: 23

문제 6

x ≡ 3 (mod 4), x ≡ 4 (mod 7)을 만족하는 가장 작은 자연수 x는?

법을 쪼개서 계산하기

중국인의 나머지 정리는 큰 법을 작은 법으로 쪼개 계산할 수 있게 해 줍니다. 100 = 4 × 25이므로 100으로 나눈 나머지는 4로 나눈 나머지와 25로 나눈 나머지로 정해집니다.

예를 들어 n ≡ 0 (mod 4), n ≡ 1 (mod 25)이면 n ≡ 76 (mod 100)입니다. 그래서 76의 거듭제곱은 마지막 두 자리가 항상 76입니다.

법이 서로소가 아니면 조건이 모순될 수 있습니다. x ≡ 1 (mod 4)이면 x는 홀수이고, x ≡ 2 (mod 6)이면 x는 짝수이므로 둘을 동시에 만족하는 정수는 없습니다. 공통 약수 2를 법으로 두 조건이 맞는지 먼저 확인하는 것이 요령입니다.

문제 8

x ≡ 1 (mod 4), x ≡ 2 (mod 6)을 동시에 만족하는 정수 x는 모두 몇 개인가요?

정리

ax ≡ b (mod m)는 gcd(a, m) | b일 때만 풀리고, 0 ≤ x < m에 gcd(a, m)개의 해가 있습니다. gcd(a, m) = 1이면 역원을 곱해 풉니다.

법이 서로 서로소인 연립합동식은 법들의 곱을 법으로 해가 하나뿐입니다(중국인의 나머지 정리). x = m₁k + a₁로 놓고 차례로 대입해 풉니다.

큰 법은 서로소인 작은 법으로 쪼개 계산하고, 법이 서로소가 아니면 공통 약수를 법으로 조건이 모순되지 않는지 먼저 확인합니다.
