카멜레온 문제

섬에 빨강 13, 초록 15, 파랑 17마리의 카멜레온이 있습니다. 색이 다른 두 마리가 만나면 둘 다 나머지 세 번째 색으로 바뀝니다. 모든 카멜레온이 한 색이 될 수 있을까요?

빨강과 초록이 만나면 (R, G, B) → (R − 1, G − 1, B + 2)입니다. 두 수의 차 R − G는 그대로이고, G − B, R − B는 3씩 변합니다. 그래서 세 차이의 3으로 나눈 나머지가 불변입니다.

한 색이 되려면 두 수가 0이 되어 그 차가 0 (mod 3)이어야 하는데, 13 − 15 ≡ 1, 15 − 17 ≡ 1, 13 − 17 ≡ 2 (mod 3)로 0이 하나도 없어 불가능합니다.

문제 1

빨강 13, 초록 15, 파랑 17마리일 때 모든 카멜레온이 같은 색이 될 수 있는 색은 몇 가지인가요?

문제 2

두 수의 차를 3으로 나눈 나머지처럼, 어떤 수로 나눈 나머지가 변하지 않는 양을 나머지 ＿＿＿이라 합니다.

가능한 경우도 확인

빨강 12, 초록 15, 파랑 18마리라면 차 12 − 15 = −3, 15 − 18 = −3, 12 − 18 = −6이 모두 3의 배수라 불변량으로는 막히지 않습니다. 실제로 세 색 모두 가능합니다.

불변량은 '불가능'을 증명하는 도구입니다. 불변량이 막지 않는다고 해서 반드시 가능한 것은 아니므로, '가능'은 실제 조작 순서를 보여 증명합니다.

예: (12, 15, 18)에서 빨강과 초록을 12번 만나게 하면 (0, 3, 42)가 되고, 파랑과 초록을 한 번 만나게 하면 (2, 2, 41), 빨강과 초록을 두 번 만나게 하면 (0, 0, 45)로 모두 파랑이 됩니다.

예제

(12, 15, 18)에서 모두 파랑으로 만드는 순서를 확인하세요.

  1. 빨강·초록이 12번 만나면 (12 − 12, 15 − 12, 18 + 24) = (0, 3, 42)입니다.
  2. 초록·파랑이 한 번 만나면 (0 + 2, 3 − 1, 42 − 1) = (2, 2, 41)입니다.
  3. 빨강·초록이 두 번 만나면 (0, 0, 45)입니다.
  4. 모두 파랑이 되었습니다.

답: (0, 0, 45)

문제 3

빨강 12, 초록 15, 파랑 18마리일 때 모든 카멜레온이 같은 색이 될 수 있는 색은 몇 가지인가요?

문제 4

카멜레온 수가 (3, 5, 7)일 때 모두 같은 색이 될 수 있는 색은 몇 가지인가요?

수의 나머지 불변량

칠판의 수들에서 한 수에 3을 더하거나 빼는 조작이라면 각 수의 mod 3이 불변입니다. 두 수를 동시에 1씩 늘리는 조작이라면 '두 수의 차'가 불변입니다.

로봇이 좌표평면에서 (x, y) → (x + 2, y + 1) 또는 (x + 1, y + 2)로만 움직이면 x + y는 3씩 늘어 x + y mod 3이 불변입니다. (0, 0)에서 출발하면 (5, 5)에는 갈 수 없습니다(10 ≢ 0 mod 3).

조작마다 '얼마만큼 변하는가'를 적어 보고, 그 변화량의 공통 약수로 나머지를 잡습니다.

문제 5

로봇이 (0, 0)에서 출발해 (x, y) → (x + 2, y + 1) 또는 (x + 1, y + 2)로만 움직일 때 (6, 9)에 도달하려면 몇 번 움직여야 하나요?

문제 6

앞 문제의 로봇이 0 ≤ x, y ≤ 10에서 도달할 수 있는 점 (x, y)는 출발점을 포함해 몇 개인가요?

문제 7

카멜레온 수가 (2, 5, 8)일 때 모두 같은 색이 될 수 있는 색은 몇 가지인가요?

정리

조작마다 어떤 양이 m의 배수만큼만 변하면, 그 양의 mod m이 불변량입니다(카멜레온의 차 mod 3, 로봇의 x + y mod 3).

목표 상태의 불변량이 처음과 다르면 불가능합니다. 조작마다 각 양이 얼마씩 변하는지 적어 보고, 변화량의 공통 약수를 법으로 잡으면 불변량을 찾기 쉽습니다.

불변량이 막지 않을 때 '가능'을 보이려면 실제 조작 순서를 보여야 합니다.

문제 8

카멜레온 수가 (4, 7, 10)일 때 모두 같은 색이 될 수 있는 색은 몇 가지인가요?

문제 9

로봇이 (x, y) → (x + 2, y + 1) 또는 (x + 1, y + 2)로 움직일 때 (0, 0)에서 (10, 11)까지 몇 번 움직이나요?

문제 10

빨강 13, 초록 15, 파랑 17마리의 카멜레온이 모두 같은 색이 될 수 없음을 증명하세요.

문제 11

로봇이 (0, 0)에서 (x, y) → (x + 2, y + 1) 또는 (x + 1, y + 2)로만 움직일 때 (5, 5)에 도달할 수 없음을 증명하세요.

문제의 정답과 해설, 힌트는 레슨을 풀면서 확인할 수 있습니다.
