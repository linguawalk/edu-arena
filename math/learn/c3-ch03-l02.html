로그함수의 그래프

로그함수

y = logₐ x (a > 0, a ≠ 1) 꼴의 함수를 로그함수라고 합니다.

정의역은 x > 0이고, 모든 로그함수의 그래프는 점 (1, 0)을 지나며 y축이 점근선입니다.

로그함수는 지수함수의 역함수이므로 성질이 x와 y를 바꾼 모양이 됩니다. 지수함수가 (0, 1)을 지나고 x축이 점근선이었으므로, 로그함수는 (1, 0)을 지나고 y축이 점근선입니다. 정의역 x > 0은 지수함수의 치역 y > 0에서 온 것입니다.

문제 1

y = log₂ x의 그래프 위에서 x = 8인 점의 y좌표는?

문제 2

y = logₐ x의 그래프가 항상 지나는 점의 x좌표는?

증가와 감소

a > 1이면 증가함수, 0 < a < 1이면 감소함수입니다. 치역은 실수 전체입니다.

밑 a > 1인 로그함수는 증가하지만 증가하는 속도가 점점 느려집니다. log₂ x가 1 커지려면 x가 2배가 되어야 하기 때문입니다. 그래도 끝없이 커지므로 치역은 실수 전체입니다. 지수함수의 치역이 y > 0으로 제한되었던 것과 대조됩니다.

예제

y = log₃ x의 그래프가 지나는 점 세 개와 점근선을 말하세요.

  1. x = 1/3이면 −1, x = 1이면 0, x = 3이면 1
  2. 밑 3 > 1이므로 증가함수
  3. x가 0에 가까워지면 y가 한없이 작아지므로 점근선 x = 0 (y축)
  4. 확인: y = 3ˣ의 점 (−1, 1/3), (0, 1), (1, 3)과 좌표가 바뀐 관계

답: (1/3, −1), (1, 0), (3, 1), 점근선 x = 0

문제 4

y = log₃ x의 그래프의 점근선은 직선 x = ?

평행이동

y = logₐ (x − p) + q는 y = logₐ x를 x축 방향으로 p, y축 방향으로 q만큼 평행이동한 그래프입니다. 점근선은 x = p입니다.

평행이동에서 가장 중요한 것은 점근선입니다. y = logₐ (x − p)의 점근선은 진수가 0이 되는 x = p이고, 정의역은 x > p입니다. y축 방향 이동은 점근선에 영향을 주지 않습니다.

예제

y = log₂ (x + 3) − 1의 정의역, 점근선, x절편을 구하세요.

  1. 진수 조건 x + 3 > 0에서 정의역 x > −3
  2. 점근선은 진수가 0이 되는 x = −3
  3. x절편: log₂ (x + 3) = 1 → x + 3 = 2 → x = −1
  4. 확인: 점 (1, 0)이 (−2, −1)로 옮겨집니다.

답: 정의역 x > −3, 점근선 x = −3, x절편 −1

대칭이동

y = −logₐ x = log_(1/a) x는 x축에 대하여, y = logₐ (−x)는 y축에 대하여 대칭이동한 그래프입니다.

logₐ의 밑을 역수로 바꾸면 부호가 바뀝니다: log_(1/a) x = log x / log (1/a) = log x / (−log a) = −logₐ x. 그래서 y = log₂ x와 y = log_(1/2) x는 x축에 대하여 대칭입니다.

문제 9

y = log₂ (−x)의 정의역에 속하는 가장 큰 정수는?

최대와 최소

증가·감소를 따져 범위의 끝에서 값을 비교합니다. 진수에 이차식이 있으면 진수의 최소부터 구합니다.

진수에 이차식이 있으면 먼저 진수의 최대·최소를 구하고, 밑의 크기로 방향을 정합니다. 밑이 1보다 크면 진수가 최소일 때 로그도 최소입니다. (logₐ x)²처럼 로그가 제곱되어 있으면 logₐ x = t로 치환해 이차함수로 풉니다.

예제

1 ≤ x ≤ 8에서 y = (log₂ x)² − 4 log₂ x + 1의 최댓값과 최솟값을 구하세요.

  1. log₂ x = t로 치환: 1 ≤ x ≤ 8이면 0 ≤ t ≤ 3
  2. y = t² − 4t + 1 = (t − 2)² − 3
  3. t = 2(x = 4)일 때 최솟값 −3, t = 0(x = 1)일 때 최댓값 1
  4. 주의: t의 범위 양 끝과 꼭짓점을 모두 비교합니다.

답: 최댓값 1, 최솟값 −3
