표본평균의 평균과 분산

모평균 m, 모분산 σ²인 모집단에서 크기 n인 표본을 임의추출하면

E(X̄) = m, V(X̄) = σ²/n, σ(X̄) = σ/√n

왜 σ²/n일까요? X̄는 서로 독립인 n개의 값을 더해 n으로 나눈 것입니다. 독립인 값을 더하면 분산이 더해져 nσ²이 되고, n으로 나누면 분산은 n²으로 나뉘어 σ²/n이 됩니다. 평균을 내면 값들의 들쭉날쭉함이 서로 상쇄되어 흩어짐이 줄어든다는 뜻입니다.

직접 확인해 보기

모집단 {1, 3, 5}에서 크기 2인 표본을 복원추출하면 9가지 표본이 같은 확률로 나옵니다.

직접 모든 표본을 나열해 X̄의 분포를 만들어 보면 E(X̄) = m, V(X̄) = σ²/n이 정말 성립하는 것을 확인할 수 있습니다. 이런 확인은 공식이 왜 맞는지 감을 잡는 데 도움이 됩니다.

예제

모집단 {2, 4, 6}에서 크기 2인 표본을 복원추출할 때 E(X̄)와 V(X̄)를 공식으로 구하세요.

  1. 모평균 m = 4
  2. 모분산 σ² = (4 + 0 + 4)/3 = 8/3
  3. E(X̄) = 4
  4. V(X̄) = (8/3)/2 = 4/3

답: E(X̄) = 4, V(X̄) = 4/3

표본평균의 분포는 정규분포

모집단이 정규분포이면 X̄ ~ N(m, σ²/n)입니다. 모집단이 정규분포가 아니어도 n이 크면 X̄는 정규분포에 가까워집니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

모집단이 어떤 모양이든 표본의 크기가 충분히 크면 표본평균의 분포는 정규분포에 가까워집니다(중심극한정리). 그래서 X̄에 관한 확률은 평균 m, 표준편차 σ/√n인 정규분포로 표준화해 구합니다. 주의할 점은 표준화할 때 σ가 아니라 σ/√n으로 나눈다는 것입니다.

예제

모집단 N(200, 30²)에서 크기 36인 표본을 뽑을 때 P(X̄ ≤ 195)를 구하세요.

  1. σ(X̄) = 30/√36 = 5
  2. Z = (195 − 200)/5 = −1
  3. P(Z ≤ −1) = 0.5 − 0.3413
  4. = 0.1587

답: 0.1587

표본의 크기와 흩어짐

표본의 크기가 클수록 X̄는 모평균 근처에 모입니다. n을 4배로 하면 σ(X̄)는 1/2배가 됩니다.

σ(X̄) = σ/√n이라 표본의 크기가 커질수록 X̄는 모평균 m 근처에 몰립니다. 그래서 큰 표본의 평균은 모평균을 더 정확하게 알려 줍니다. 다만 정확도를 2배로 하려면 표본을 4배로 늘려야 해서, 정확도를 높이는 데 비용이 빠르게 늘어납니다.

문제 10

σ = 12인 모집단에서 σ(X̄) = 2가 되게 하는 표본의 크기는?

정리

X̄의 평균은 모평균과 같고, 표준편차는 σ/√n으로 줄어듭니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

X̄에 관한 확률 문제의 순서: ① σ(X̄) = σ/√n 계산 ② Z = (X̄ − m)/(σ/√n)으로 표준화 ③ 표준정규분포표로 확률 계산. 모집단의 표준편차 σ를 그대로 쓰는 실수를 가장 조심합니다.

예제

σ = 20인 모집단에서 표본평균의 표준편차를 2 이하로 하려면 표본의 크기는 최소 얼마여야 할까요?

  1. σ/√n ≤ 2
  2. 20/√n ≤ 2에서 √n ≥ 10
  3. n ≥ 100
  4. 최소 100

답: 100
