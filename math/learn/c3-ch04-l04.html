삼각함수의 성질과 방정식

대수 · 4. 삼각함수 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

각의 변환

sin(−x) = −sin x, cos(−x) = cos x, sin(π − x) = sin x, cos(π − x) = −cos x

sin(π/2 + x) = cos x, cos(π/2 + x) = −sin x. 단위원에서 점이 어디로 옮겨 가는지 보면 알 수 있습니다.

외우기보다 단위원에서 확인하는 것이 확실합니다. 각 −x는 점 (cos x, sin x)를 x축에 대하여 대칭이동한 (cos x, −sin x)이므로 sin(−x) = −sin x, cos(−x) = cos x입니다. π − x는 y축 대칭이라 sin은 그대로, cos은 부호가 바뀝니다.

예제

sin (7π/6)과 cos (−2π/3)을 각의 변환으로 구하세요.

  1. 7π/6 = π + π/6이므로 sin (π + π/6) = −sin (π/6) = −1/2
  2. cos (−2π/3) = cos (2π/3) (cos은 음수 각에서 부호 그대로)
  3. cos (2π/3) = cos (π − π/3) = −cos (π/3) = −1/2
  4. 확인: 7π/6은 제3사분면이라 sin이 음수

답: −1/2, −1/2

삼각방정식

sin x = k는 단위원과 직선 y = k의 교점, 또는 y = sin x와 y = k의 그래프의 교점으로 풉니다.

sin x = k의 해는 단위원에서 y좌표가 k인 점을 찾는 것입니다. −1 < k < 1이면 직선 y = k가 원과 두 점에서 만나므로 한 바퀴(0 ≤ x < 2π) 안에서 해가 두 개입니다. k = ±1이면 한 개, |k| > 1이면 해가 없습니다.

예제

0 ≤ x < 2π에서 cos x = −√2/2를 푸세요.

  1. 단위원에서 x좌표가 −√2/2인 점을 찾습니다.
  2. 예각 π/4에 대응하는 제2, 제3사분면의 각
  3. x = 3π/4, 5π/4
  4. 확인: 두 해는 x축에 대하여 대칭이라 합이 2π

답: x = 3π/4, 5π/4

삼각부등식

그래프가 기준선보다 위에 있거나 아래에 있는 x의 범위를 읽습니다.

삼각부등식은 먼저 등식의 해(경계)를 구한 뒤, 그래프에서 기준선보다 위나 아래에 있는 구간을 읽습니다. sin x > 1/2이면 y = sin x가 직선 y = 1/2보다 위에 있는 구간이므로 두 해 사이입니다. 경계값을 포함하는지는 부등호에 등호가 있는지로 정합니다.

문제 9

0 ≤ x < 2π에서 cos x ≤ 0의 해는 π/2 ≤ x ≤ ＿＿＿π/2

이차식 꼴

sin x나 cos x를 t로 치환하면 이차방정식이 됩니다. 이때 −1 ≤ t ≤ 1이라는 범위를 지켜야 합니다.

왜 −1 ≤ t ≤ 1일까요? sin x와 cos x는 단위원 위의 좌표라 이 범위를 벗어날 수 없습니다. 그래서 치환한 이차방정식의 근 중 범위 밖의 것은 해가 없고, 범위 안의 근은 각각 sin x = t의 해를 따로 세어야 합니다. 이차함수의 최대·최소도 이 범위 안에서 구합니다.

예제

0 ≤ x < 2π에서 2cos² x + 3 sin x − 3 = 0을 푸세요.

  1. cos² x = 1 − sin² x를 넣으면 2 − 2sin² x + 3 sin x − 3 = 0
  2. 2sin² x − 3 sin x + 1 = 0 → (2 sin x − 1)(sin x − 1) = 0
  3. sin x = 1/2에서 π/6, 5π/6 / sin x = 1에서 π/2
  4. 해는 π/6, π/2, 5π/6

답: π/6, π/2, 5π/6

정리

각을 변환해 특수각으로 만들고, 단위원이나 그래프로 해를 셉니다.

해를 셀 때는 단위원 그림이 가장 확실합니다. 해가 몇 개인지, 대칭인 해들의 합이 얼마인지도 그림에서 바로 보입니다. 예를 들어 cos x = k의 두 해는 x축에 대하여 대칭이라 합이 2π이고, 0 < k < 1일 때 sin x = k의 두 해는 직선 x = π/2에 대하여 대칭이라 합이 π입니다(k < 0이면 합이 3π).
