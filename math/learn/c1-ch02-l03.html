합집합과 교집합

A 또는 B에 속하는 원소의 집합이 합집합 A ∪ B, A와 B에 모두 속하는 원소의 집합이 교집합 A ∩ B입니다.

아래에서 A = {1, 2, 3, 4}, B = {3, 4, 5, 6}입니다.

합집합은 '또는', 교집합은 '그리고'에 해당합니다. 벤 다이어그램에서 합집합은 두 원이 덮는 부분 전체, 교집합은 두 원이 겹치는 부분입니다.

여집합과 차집합

전체집합 U에서 A에 속하지 않는 원소의 집합이 여집합 Aᶜ입니다.

A에는 속하고 B에는 속하지 않는 원소의 집합이 차집합 A − B입니다. A ∩ B = ∅이면 A, B는 서로소입니다.

여집합은 전체집합 U가 정해져야 뜻이 있습니다. 같은 A라도 U가 무엇이냐에 따라 Aᶜ이 달라집니다. 차집합 A − B는 A에서 B와 겹치는 부분을 잘라 낸 것입니다.

예제

U = {1, 2, …, 7}, A = {1, 2, 3, 4}, B = {3, 4, 5}일 때 A ∪ B, A ∩ B, Aᶜ, A − B를 구하세요.

  1. A ∪ B: 둘 중 하나에라도 있는 원소 {1, 2, 3, 4, 5}
  2. A ∩ B: 둘 다에 있는 원소 {3, 4}
  3. Aᶜ: U에서 A에 없는 원소 {5, 6, 7}
  4. A − B: A에만 있는 원소 {1, 2}

답: {1,2,3,4,5}, {3,4}, {5,6,7}, {1,2}

연산 법칙

교환법칙, 결합법칙, 분배법칙이 성립합니다. A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

드모르간의 법칙: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ. 또 A − B = A ∩ Bᶜ

드모르간의 법칙은 말로 생각하면 쉽습니다. 'A 또는 B가 아니다'는 'A도 아니고 B도 아니다'와 같습니다. 벤 다이어그램에 색칠해 보면 양변이 같은 부분을 가리킴을 확인할 수 있습니다.

연산 연습

아래에서 U = {1, 2, …, 10}, A는 짝수의 집합, B는 3의 배수의 집합입니다.

연산 문제는 먼저 집합을 원소나열법으로 바꿔 두면 실수가 줄어듭니다. A = {2, 4, 6, 8, 10}, B = {3, 6, 9}로 적어 놓고 연산을 하나씩 적용합니다.

예제

위 예제에서 (A ∪ B)ᶜ과 Aᶜ ∩ Bᶜ을 각각 구해 비교하세요.

  1. (A ∪ B)ᶜ = U − {1, 2, 3, 4, 5} = {6, 7}
  2. Aᶜ = {5, 6, 7}, Bᶜ = {1, 2, 6, 7}
  3. Aᶜ ∩ Bᶜ = {6, 7}
  4. 두 결과가 같습니다 (드모르간의 법칙)

답: 둘 다 {6, 7}

포함 관계와 연산

A ⊂ B이면 A ∩ B = A, A ∪ B = B, A − B = ∅이 모두 성립합니다.

왜 이 세 가지가 성립할까요? A가 B 안에 통째로 들어 있으면 겹치는 부분은 A 전체이고, 합쳐도 B를 넘지 않으며, A에서 B를 빼면 남는 것이 없기 때문입니다.

예제

A = {1, 3, a}, B = {3, 5, 7}이고 A ∩ B = {3, 5}일 때 a와 A ∪ B를 구하세요.

  1. 5가 A ∩ B에 있으므로 5 ∈ A
  2. A의 원소 1, 3, a 중 5가 될 수 있는 것은 a뿐: a = 5
  3. A = {1, 3, 5}, A ∪ B = {1, 3, 5, 7}

답: a = 5, A ∪ B = {1, 3, 5, 7}
