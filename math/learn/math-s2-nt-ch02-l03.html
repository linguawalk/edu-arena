모든 원시 세 쌍의 공식

a² + b² = c²의 양의 정수해 가운데 gcd(a, b, c) = 1인 것을 원시 피타고라스 세 쌍이라 합니다. 모든 원시 세 쌍은 서로소이고 홀짝이 다른 m > n > 0으로 a = m² − n², b = 2mn, c = m² + n²입니다(a, b의 순서는 바뀔 수 있음).

m = 2, n = 1 → (3, 4, 5), m = 3, n = 2 → (5, 12, 13), m = 4, n = 1 → (15, 8, 17), m = 4, n = 3 → (7, 24, 25).

원시가 아닌 세 쌍은 원시 세 쌍의 배수입니다(예: (6, 8, 10), (9, 12, 15)).

문제 1

m = 5, n = 2로 만든 원시 피타고라스 세 쌍의 빗변 c는?

문제 2

gcd(a, b, c) = 1인 피타고라스 세 쌍을 ＿＿＿ 피타고라스 세 쌍이라 합니다.

공식을 이끄는 방법

원시 세 쌍에서 a, b 가운데 정확히 하나가 짝수입니다(둘 다 홀수이면 c² ≡ 2 (mod 4)라 불가능). b를 짝수라 하면 b² = c² − a² = (c − a)(c + a)입니다.

c − a, c + a는 모두 짝수이고 (c − a)/2와 (c + a)/2는 서로소이며, 곱이 (b/2)²인 제곱수이므로 각각 제곱수 n², m²입니다.

그래서 c = m² + n², a = m² − n², b = 2mn입니다. 이 증명은 '서로소인 두 수의 곱이 제곱수이면 각각 제곱수'라는 사실을 씁니다.

예제

빗변이 30보다 작은 원시 피타고라스 세 쌍을 모두 구하세요.

  1. m² + n² < 30, m > n, 서로소, 홀짝이 다른 (m, n)을 찾습니다.
  2. (2, 1) → 5, (3, 2) → 13, (4, 1) → 17, (4, 3) → 25, (5, 2) → 29입니다.
  3. (5, 4)는 41로 30을 넘고, (3, 1)·(5, 1)·(5, 3)은 홀짝이 같아 제외합니다.
  4. (3, 4, 5), (5, 12, 13), (15, 8, 17), (7, 24, 25), (21, 20, 29)의 5개입니다.

답: 5개

문제 4

빗변이 100보다 작은 원시 피타고라스 세 쌍은 몇 개인가요?

한 변이 정해진 세 쌍

빗변이 25인 세 쌍은 (7, 24, 25)(원시)와 (15, 20, 25) = 5 × (3, 4, 5)의 두 개입니다.

한 다리가 15인 세 쌍은 (15, 8, 17), (15, 20, 25), (15, 36, 39), (15, 112, 113)의 네 개입니다. 15² = (c − b)(c + b)로 놓고 225의 약수 쌍을 따지면 됩니다.

c − b와 c + b는 홀짝이 같아야 하므로, 225 = 1 × 225 = 3 × 75 = 5 × 45 = 9 × 25에서 네 쌍이 나옵니다(15 × 15는 b = 0).

문제 7

직각삼각형 (8, 15, 17)의 내접원의 반지름 (a + b − c)/2는?

정리

원시 피타고라스 세 쌍은 서로소이고 홀짝이 다른 m > n으로 (m² − n², 2mn, m² + n²)이며, 모든 세 쌍은 이것의 배수입니다.

증명은 b² = (c − a)(c + a)로 인수분해하고, 서로소인 두 수의 곱이 제곱수이면 각각 제곱수라는 사실을 씁니다.

한 변이 정해진 세 쌍은 n² = (c − b)(c + b)처럼 인수분해해 홀짝이 같은 약수 쌍을 셉니다.
