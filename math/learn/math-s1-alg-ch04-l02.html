aₙ₊₁ = paₙ + q 풀기

점화식 aₙ₊₁ = paₙ + q (p ≠ 1)는 고정점 α = pα + q를 찾으면 풀립니다. 두 식을 빼면 aₙ₊₁ − α = p(aₙ − α)이므로 aₙ − α는 공비 p인 등비수열입니다.

따라서 aₙ = α + (a₁ − α)pⁿ⁻¹입니다.

왜 고정점을 뺄까요? 상수 q 때문에 등비수열이 아니었는데, α를 빼면 q가 사라집니다. 수열이 α에서 얼마나 떨어져 있는지만 보면 매번 p배가 되는 것입니다. |p| < 1이면 그 거리가 0으로 줄어들어 수열이 α로 다가갑니다. 이 '평형점에서의 거리' 관점은 물리와 경제의 모형에서도 똑같이 쓰입니다.

문제 1

a₁ = 1, aₙ₊₁ = 2aₙ + 1일 때 a₅의 값은?

문제 2

aₙ₊₁ = 2aₙ + 1이면 aₙ₊₁ + 1 = 2(aₙ + ＿＿＿)입니다.

예제

a₁ = 3, aₙ₊₁ = 3aₙ − 4의 일반항을 구하세요.

  1. 고정점: α = 3α − 4에서 α = 2입니다.
  2. aₙ₊₁ − 2 = 3(aₙ − 2)이므로 aₙ − 2는 공비 3인 등비수열입니다.
  3. a₁ − 2 = 1이므로 aₙ − 2 = 3ⁿ⁻¹입니다.
  4. 따라서 aₙ = 3ⁿ⁻¹ + 2입니다. (확인: a₂ = 5, a₃ = 11)

답: aₙ = 3ⁿ⁻¹ + 2

문제 3

앞 예제의 수열에서 a₄의 값은?

문제 4

a₁ = 1, aₙ₊₁ = aₙ/2 + 1일 때 a₄의 값을 분수로 쓰세요.

문제 5

aₙ₊₁ = aₙ/3 + 4의 고정점 α는?

거듭제곱이 더해진 점화식

aₙ₊₁ = 2aₙ + 2ⁿ⁺¹처럼 상수 대신 거듭제곱이 더해지면 고정점이 없습니다. 이때는 양변을 2ⁿ⁺¹로 나눕니다.

bₙ = aₙ/2ⁿ이라 하면 bₙ₊₁ = bₙ + 1이 되어, bₙ은 공차 1인 등차수열입니다.

나누는 수는 '점화식의 계수 p의 거듭제곱'입니다. aₙ₊₁ = paₙ + f(n)을 pⁿ⁺¹로 나누면 bₙ₊₁ = bₙ + f(n)/pⁿ⁺¹이라는 계차수열이 되고, 레슨 1의 방법으로 풀 수 있습니다. 이렇게 낯선 점화식도 치환으로 아는 꼴로 바꾸는 것이 기본 전략입니다.

문제 6

a₁ = 2, aₙ₊₁ = 2aₙ + 2ⁿ⁺¹일 때 a₅의 값은?

분수 꼴은 역수로

aₙ₊₁ = aₙ/(1 + aₙ)처럼 분수 꼴인 점화식은 역수를 취하면 간단해집니다. 1/aₙ₊₁ = (1 + aₙ)/aₙ = 1/aₙ + 1입니다.

bₙ = 1/aₙ이라 하면 bₙ₊₁ = bₙ + 1로 등차수열이 됩니다.

역수를 취할 수 있으려면 aₙ ≠ 0이어야 합니다. a₁ > 0이면 귀납법으로 모든 aₙ > 0임을 바로 보일 수 있으므로, 답안에서는 이 한 줄을 먼저 씁니다. 분자에 상수배가 붙은 aₙ₊₁ = 2aₙ/(aₙ + 2)도 역수를 취하면 1/aₙ₊₁ = 1/2 + 1/aₙ이 됩니다.

문제 7

a₁ = 1, aₙ₊₁ = aₙ/(1 + aₙ)일 때 a₁₀의 값을 분수로 쓰세요.

정리

aₙ₊₁ = paₙ + q는 고정점 α = q/(1 − p)를 빼서 등비수열 aₙ − α로 바꿉니다.

aₙ₊₁ = paₙ + f(n)은 pⁿ⁺¹로 나누어 계차수열로 바꾸고, 분수 꼴은 역수를 취해 등차수열로 바꿉니다.

어떤 치환을 쓰든 결과 공식을 처음 몇 항으로 검산하는 습관을 들이세요. 공식은 귀납법으로 증명할 수도 있으므로, 답안에서는 '추측한 일반항을 귀납법으로 증명'하는 방식도 언제나 쓸 수 있습니다.

문제 9

문제 10

a₁ = 1, aₙ₊₁ = 2aₙ + 1이면 aₙ = 2ⁿ − 1임을 증명하세요.

문제 11
