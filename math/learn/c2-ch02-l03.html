평행이동

점의 평행이동

점 (x, y)를 x축 방향으로 a, y축 방향으로 b만큼 옮기면 (x + a, y + b)가 됩니다.

평행이동은 모든 점을 같은 방향, 같은 거리만큼 옮기는 것입니다. 그래서 도형의 모양, 크기, 방향은 그대로이고 위치만 바뀝니다.

문제 1

점 (1, 2)를 x축 방향으로 3, y축 방향으로 −4만큼 평행이동한 점을 표시하세요.

문제 2

점 (a, b)를 x축 방향으로 2, y축 방향으로 −1만큼 옮긴 점이 (5, 3)일 때 a = ＿＿＿, b = ＿＿＿

도형의 평행이동

도형 f(x, y) = 0을 x축 방향으로 a, y축 방향으로 b만큼 옮기면 f(x − a, y − b) = 0입니다.

x 자리에 x − a, y 자리에 y − b를 넣습니다.

도형을 옮길 때 식에 x − a를 넣는 이유는 다음 화면에서 자세히 봅니다. 여기서는 '점은 +a, 식은 x − a'라는 반대 관계를 기억해 둡니다.

예제

y = x² − 2x를 x축 방향으로 1, y축 방향으로 3만큼 평행이동한 식을 구하세요.

  1. x 자리에 x − 1, y 자리에 y − 3을 넣습니다.
  2. y − 3 = (x − 1)² − 2(x − 1)
  3. y = x² − 4x + 6

답: y = x² − 4x + 6

문제 3

y = x²을 x축 방향으로 2만큼 평행이동하면 y = (x − ＿＿＿)²

문제 4

y = 2x + 1을 y축 방향으로 3만큼 평행이동하면 y = 2x + ＿＿＿

문제 5

x² + y² = 4를 x축 방향으로 1, y축 방향으로 −2만큼 평행이동하면 (x − 1)² + (y + ＿＿＿)² = 4

부호에 주의

오른쪽으로 옮기는데 식에는 x − a가 들어가는 이유는, 새 도형의 점 (x, y)가 원래 도형의 점 (x − a, y − b)에서 왔기 때문입니다.

예를 들어 y = x²을 오른쪽으로 2만큼 옮기면, 새 그래프에서 x = 2일 때의 높이는 원래 그래프에서 x = 0일 때의 높이와 같아야 합니다. 그래서 y = (x − 2)²입니다.

문제 6

직선 y = 3x를 x축 방향으로 1, y축 방향으로 2만큼 평행이동한 직선의 y절편은?

문제 7

원 (x − 2)² + y² = 1을 평행이동했더니 x² + (y − 3)² = 1이 되었습니다. x축 방향으로 얼마만큼 옮겼을까요?

문제 8

같은 이동에서 y축 방향으로는 얼마만큼 옮겼을까요?

이동한 도형의 조건

평행이동해도 모양과 크기는 그대로이고 위치만 바뀝니다. 꼭짓점이나 중심만 따라가면 됩니다.

모양이 그대로이므로 대표점 하나만 따라가면 됩니다. 포물선은 꼭짓점, 원은 중심을 옮기고, 반지름이나 폭은 바뀌지 않는다는 점을 이용합니다.

예제

원 (x + 1)² + (y − 2)² = 9를 평행이동해 중심이 (3, 0)이 되게 했습니다. 어떻게 옮겼을까요?

  1. 중심 (−1, 2)가 (3, 0)으로 이동
  2. x축 방향: 3 − (−1) = 4
  3. y축 방향: 0 − 2 = −2

답: x축 방향으로 4, y축 방향으로 −2

문제 9

직선 y = 2x + 1을 y축 방향으로 k만큼 평행이동한 직선이 점 (1, 6)을 지날 때 k의 값은?

문제 10

y = x²을 x축 방향으로 a, y축 방향으로 b만큼 옮겼더니 꼭짓점이 (2, −3)이 되었습니다. a + b의 값은?

문제 11

원 x² + y² = 1을 x축 방향으로 a(a > 0)만큼 옮긴 원이 직선 x = 4에 접할 때 a의 값은?

문제 12

그림은 y = (x + 1)² − 2의 그래프입니다. 꼭짓점을 표시하세요.

정리

점은 좌표에 더하고, 도형의 식에는 x − a, y − b를 넣습니다.

헷갈리면 대표점으로 확인합니다. 원 x² + y² = 1을 (3, −1)만큼 옮기면 중심 (0, 0)이 (3, −1)로 가므로 (x − 3)² + (y + 1)² = 1이 되는지 보면 됩니다.

예제

직선 y = 3x + 1을 x축 방향으로 a만큼 평행이동한 직선이 원점을 지날 때 a를 구하세요.

  1. x 자리에 x − a: y = 3(x − a) + 1
  2. 원점 대입: 0 = −3a + 1
  3. a = 1/3

답: 1/3
