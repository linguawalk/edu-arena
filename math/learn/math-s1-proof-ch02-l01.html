도미노를 넘어뜨리는 두 가지 조건

수학적 귀납법은 모든 자연수 n에 대해 명제 P(n)이 참임을 보이는 방법입니다. 두 가지만 보이면 됩니다.

기저: P(1)이 참이다. 귀납 단계: P(k)가 참이면 P(k + 1)도 참이다.

왜 이 두 가지로 충분할까요? 첫 번째 도미노가 넘어지고(기저), 어느 도미노든 넘어지면 바로 다음 것을 넘어뜨린다면(귀납 단계), 결국 모든 도미노가 넘어집니다. P(1)에서 P(2)가, P(2)에서 P(3)이 차례로 나오므로 어떤 자연수 n도 빠지지 않습니다. 둘 중 하나라도 빠지면 증명이 되지 않습니다.

문제 1

1 + 3 + 5 + 7 + 9의 값은?

문제 2

1 + 3 + ⋯ + (2n − 1) = n²의 기저: n = 1일 때 좌변은 1이고 우변은 1² = ＿＿＿이므로 성립합니다.

귀납 단계를 쓰는 법

귀납 단계에서는 'n = k일 때 성립한다고 가정하자'로 시작합니다. 이 가정을 귀납 가정이라고 합니다.

그다음 n = k + 1일 때의 식을 쓰고, 그 안에서 n = k일 때의 식을 찾아 귀납 가정으로 바꿉니다.

합 공식이라면 1 + 2 + ⋯ + k + (k + 1)에서 앞부분 1 + 2 + ⋯ + k가 n = k일 때의 식입니다. 이 부분을 귀납 가정의 값으로 바꾸고 나머지를 계산해 n = k + 1일 때의 우변과 같아지는지 확인합니다. 귀납 가정을 한 번도 쓰지 않았다면 증명이 잘못되었다는 신호입니다.

예제

모든 자연수 n에 대해 1 + 2 + ⋯ + n = n(n + 1)/2임을 증명하세요.

  1. 기저: n = 1이면 좌변 1, 우변 1 × 2/2 = 1로 성립합니다.
  2. 귀납 가정: n = k일 때 1 + 2 + ⋯ + k = k(k + 1)/2라고 가정합니다.
  3. n = k + 1이면 1 + ⋯ + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2입니다.
  4. 이는 n = k + 1일 때의 우변이므로 성립하고, 귀납법에 따라 모든 자연수 n에서 성립합니다.

답: n(n + 1)/2

문제 5

귀납 단계에서 k(k + 1)/2 + (k + 1) = (k + 1)(＿＿＿)/2입니다.

귀납 가정은 '빌린 사실'이다

귀납 가정은 증명할 결론 자체가 아니라 n = k라는 한 경우에 대해 빌려 쓰는 사실입니다. 그래서 n = k + 1일 때의 식에서 n = k일 때의 식이 어디에 숨어 있는지 찾는 것이 핵심입니다.

합이라면 마지막 항을 떼어 내면 되고, 곱이나 거듭제곱이라면 인수 하나를 떼어 냅니다.

예를 들어 1 + 2 + 4 + ⋯ + 2ⁿ⁻¹ = 2ⁿ − 1에서 n = k + 1일 때의 합은 (1 + 2 + ⋯ + 2ᵏ⁻¹) + 2ᵏ입니다. 괄호 부분을 귀납 가정으로 2ᵏ − 1로 바꾸면 2ᵏ − 1 + 2ᵏ = 2 × 2ᵏ − 1 = 2ᵏ⁺¹ − 1이 되어 증명이 끝납니다.

문제 7

1 × 2 + 2 × 3 + ⋯ + n(n + 1) = n(n + 1)(n + 2)/3입니다. n = 5일 때 좌변의 값은?

정리

수학적 귀납법은 기저 P(1)과 귀납 단계 'P(k)이면 P(k + 1)'의 두 부분으로 이루어집니다.

귀납 단계에서는 n = k + 1일 때의 식에서 n = k일 때의 식을 찾아 귀납 가정으로 바꾸고, 남은 부분을 계산합니다.

답안에는 '기저', '귀납 가정', 'n = k + 1일 때', '귀납법에 의해 모든 자연수 n에 대해 성립한다'의 네 부분이 분명히 드러나야 합니다. 합 공식은 직접 몇 개를 더해 맞는지 먼저 확인하면 계산 실수를 줄일 수 있습니다.
