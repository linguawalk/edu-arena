미지수가 세 개인 연립일차방정식

한 문자를 없애 미지수가 두 개인 연립방정식으로 바꾼 뒤 풉니다.

세 식을 모두 더해 보면 빨리 풀리는 경우도 있습니다.

왜 한 문자를 없앨까요? 미지수가 세 개면 한 번에 풀 수 없지만, 두 식을 더하거나 빼서 한 문자를 없애면 이미 풀 줄 아는 미지수 두 개짜리 연립방정식이 됩니다.

일차식과 이차식의 연립

일차방정식을 한 문자에 대해 풀어 이차방정식에 대입합니다.

일차식은 한 문자에 대해 쉽게 풀리므로 이를 이차식에 넣으면 문자가 하나만 남는 이차방정식이 됩니다. 이렇게 구한 x마다 y를 다시 구해 짝을 맞춥니다.

예제

x + y = 5, x² + y² = 13을 푸세요.

  1. y = 5 − x를 대입: x² + (5 − x)² = 13
  2. 2x² − 10x + 12 = 0 → x² − 5x + 6 = 0
  3. x = 2 또는 3
  4. x = 2이면 y = 3, x = 3이면 y = 2

답: (2, 3), (3, 2)

이차식끼리의 연립

한쪽 식이 인수분해되면 두 일차식으로 나눠 각각 다른 식과 연립합니다.

x² − y² = (x + y)(x − y) = 0처럼 인수분해되면 x = y 또는 x = −y라는 두 일차식으로 나뉩니다. 각각을 나머지 식과 연립하면 일차식과 이차식의 연립이 되어 풀 수 있습니다.

공통근

두 방정식을 빼서 이차항을 없애면 공통근을 찾기 쉬워집니다.

공통근 α는 두 방정식을 모두 만족하므로 두 식에 α를 넣고 빼도 성립합니다. 빼면 이차항이 사라져 α에 대한 일차식이 남으므로 α를 구하기 쉬워집니다. 구한 α를 어느 한 식에 다시 넣으면 모르는 계수도 구할 수 있습니다.

예제

x² + ax + 3 = 0과 x² + 3x + a = 0이 공통근을 가질 때(a ≠ 3) a를 구하세요.

  1. 공통근을 α라 하고 두 식을 빼면 (a − 3)α + (3 − a) = 0
  2. (a − 3)(α − 1) = 0이고 a ≠ 3이므로 α = 1
  3. 첫 식에 α = 1을 넣으면 1 + a + 3 = 0
  4. a = −4

답: a = −4 (공통근 1)

부정방정식

미지수보다 식이 적어도, 해가 정수라는 조건이나 실수 조건이 있으면 해를 구할 수 있습니다.

(x − 1)(y − 1) = 2처럼 곱의 꼴로 바꾸거나, (완전제곱) + (완전제곱) = 0을 이용합니다.

왜 (완전제곱) + (완전제곱) = 0이면 각각 0일까요? 실수의 제곱은 0 이상이라 둘 중 하나라도 양수이면 합이 0이 될 수 없기 때문입니다. 식 하나로 두 미지수를 모두 구할 수 있는 이유입니다.

예제

실수 x, y가 x² + y² − 6x + 2y + 10 = 0을 만족할 때 x, y를 구하세요.

  1. 완전제곱식으로 묶습니다: (x − 3)² − 9 + (y + 1)² − 1 + 10 = 0
  2. (x − 3)² + (y + 1)² = 0
  3. 실수의 제곱의 합이 0이므로 x − 3 = 0, y + 1 = 0
  4. x = 3, y = −1

답: x = 3, y = −1
