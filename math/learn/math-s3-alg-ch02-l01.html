이 가이드에서 다룰 도구

S2 '함수방정식'에서는 특수값 대입, 대칭 바꾸기, 단사·전사를 배웠습니다. 국제 대회 문제는 이 도구를 여러 개 이어 붙여야 풀립니다. 이 가이드는 ① 코시 방정식으로 줄이기 ② 단사·전사로 식을 단순하게 만들기 ③ 같은 값을 두 가지 방법으로 계산하기 ④ 자연수 정의역에서 반복 적용과 점화식 ⑤ 정수 정의역에서 경우 나누기를 다룹니다.

답안의 기본 틀은 언제나 같습니다: 해를 짐작한다 → 조건에서 해의 꼴을 이끈다 → 그 꼴이 실제로 조건을 만족하는지 확인한다. 마지막 확인을 빠뜨리면 감점됩니다.

해를 짐작할 때는 f(x) = ax + b, f(x) = c(상수)를 먼저 대입해 보세요. 국제 대회 답의 대부분이 이 꼴이거나 몇 가지 해의 모음입니다.

코시 방정식과 그 함정

f(x + y) = f(x) + f(y)(코시 방정식)를 만족하는 f: ℚ → ℚ는 f(x) = cx뿐입니다. 귀납법으로 f(n) = nf(1), f(n · (1/m)) = n f(1/m)에서 f(1/m) = f(1)/m을 얻기 때문입니다.

그러나 f: ℝ → ℝ에서는 조건이 더 없으면 일차함수가 아닌 이상한 해(그래프가 평면에 빽빽한 해)가 존재합니다. 그래서 실수 문제에서는 연속, 단조, 어떤 구간에서 유계, f(x) ≥ 0 (x ≥ 0) 같은 추가 조건을 써서 f(x) = cx를 이끌어야 합니다. 연속이면 유리수에서 cx이고 유리수가 빽빽하므로 모든 실수에서 cx입니다.

많은 문제가 g(x) = f(x) − (알려진 부분)으로 바꾸면 코시 방정식이 됩니다. 예: f(x + y) = f(x) + f(y) + xy이면 g(x) = f(x) − x²/2가 코시 방정식을 만족합니다.

예제

f: ℚ → ℚ가 f(x + y) = f(x) + f(y) + xy, f(1) = 3을 만족할 때 f를 구하세요.

  1. g(x) = f(x) − x²/2라 하면 g(x + y) = f(x + y) − (x + y)²/2 = f(x) + f(y) + xy − x²/2 − xy − y²/2 = g(x) + g(y)입니다.
  2. ℚ에서 코시 방정식의 해는 g(x) = cx뿐이므로 f(x) = x²/2 + cx입니다.
  3. f(1) = 1/2 + c = 3에서 c = 5/2이고, f(x) = x²/2 + 5x/2입니다(대입하면 조건을 만족).

답: f(x) = x²/2 + 5x/2

문제 1

위 예제의 f에서 f(2)의 값은?

단사·전사와 두 가지 계산

f(f(y)) = y + c 꼴이 나오면 f는 전단사입니다. 전사이면 'f(a) = 0인 a'를 잡아 대입할 수 있고, 단사이면 f(A) = f(B)에서 A = B를 얻습니다.

같은 값을 두 가지 방법으로 계산하는 것은 가장 강력한 기법입니다. 예를 들어 f(x + 2)를 'y = 1을 두 번' 넣어 한 번, 'y = 2를 한 번' 넣어 또 한 번 계산해 같게 놓으면 f(x)에 대한 식이 바로 나옵니다.

대입할 값을 고를 때는 '괄호 안을 0이나 같은 식으로 만드는 값', '양변의 대칭을 깨는 값', '이미 아는 값(f(0), f(1))'을 차례로 시도합니다.

예제

f: ℝ → ℝ가 모든 실수 x, y에 대해 f(x + y) = f(x)f(y) − xy를 만족할 때 f(0)을 구하세요.

  1. y = 0을 넣으면 f(x) = f(x)f(0)이므로 f(x)(1 − f(0)) = 0입니다.
  2. f(0) ≠ 1이면 모든 x에서 f(x) = 0인데, 그러면 원래 식이 0 = −xy가 되어 x = y = 1에서 모순입니다.
  3. 따라서 f(0) = 1입니다(아래 문제 2에서 나머지를 완성).

답: f(0) = 1

자연수 정의역과 점화식

f: ℕ → ℕ 문제에서 f(f(n))처럼 합성이 나오면, n에서 시작해 aₖ = f를 k번 적용한 값으로 수열을 만들면 식이 점화식이 됩니다. 예: f(f(n)) + 2f(n) = 3n + 4이면 aₖ₊₂ + 2aₖ₊₁ = 3aₖ + 4입니다.

이 선형 점화식의 일반항은 aₖ = k + C + B(−3)ᵏ 꼴입니다(특성근 1, −3, 특수해 k). 모든 aₖ가 양의 정수여야 하므로 B ≠ 0이면 k가 커질 때 B(−3)ᵏ이 부호를 바꾸며 커져 어떤 aₖ가 음수가 됩니다. 따라서 B = 0입니다.

이렇게 '값이 자연수여야 한다'는 조건이 일반항의 일부를 없애는 것이 자연수 함수방정식의 전형적인 마무리입니다.

자기 점검과 흔한 감점

문제 1: 실수 코시 방정식에서 연속성을 쓰지 않고 'f(x) = cx'라고 쓰면 핵심 단계를 빠뜨린 것입니다. 문제 2: f ≡ 0을 따로 제외했는지 확인하세요. 문제 3: B = 0을 보일 때 '음수가 된다'를 구체적으로 썼는지 봅니다.

문제 4: c = 0을 보이기 전에 f(2x) = x + f(x)를 쓰면 안 됩니다. 문제 5: 해가 세 개이므로 하나라도 빠뜨리면 큰 감점입니다. 국제 대회에서 '해를 하나 빠뜨린 답안'은 대개 1~2점에 그칩니다.

다섯 문제 모두 마지막에 해를 대입해 확인하는 단락을 썼는지 확인하세요. 확인이 없으면 '필요조건'만 보인 것이 됩니다.

독학 순서와 참고 자료

추천 순서: ① 문제 1로 코시 방정식으로 줄이는 법 ② 문제 2·4로 두 가지 계산과 전단사 ③ 문제 3·5로 자연수·정수 정의역을 연습합니다. 그다음 IMO 예비 문제(Shortlist)의 대수 분야에서 A1~A3 수준 함수방정식을 골라 같은 틀로 답안을 씁니다.

더 공부할 주제: 단조성과 유계성으로 코시 방정식 풀기, f(x)·f(y) 꼴(곱셈 코시 방정식)을 로그·지수로 바꾸기, 함수 그래프의 고정점과 주기, 양의 실수 정의역에서 x = y·t 치환.

참고 자료(영문): Venkatachala 『Functional Equations: A Problem Solving Approach』, Evan Chen의 함수방정식 강의 노트(누리집 공개), AoPS의 'Functional Equations' 주제 토론.
