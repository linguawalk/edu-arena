세 수로 늘리기

양수 a, b, c에 대해 (a + b + c)/3 ≥ ∛(abc)이고, 등호는 a = b = c일 때입니다. 일반적으로 n개의 양수에 대해 (a₁ + ⋯ + aₙ)/n ≥ ⁿ√(a₁⋯aₙ)이 성립합니다.

두 수일 때와 똑같이, 합이 정해지면 곱이 최대이고 곱이 정해지면 합이 최소이며, 최선은 모든 수가 같을 때입니다.

왜 세 수 버전이 따로 필요할까요? x² + 2/x 같은 식은 두 항의 곱 x² × 2/x = 2x가 상수가 아니라서 두 수 AM-GM으로는 막힙니다. 2/x를 1/x + 1/x로 쪼개 세 항 x², 1/x, 1/x로 만들면 곱이 1이 되어 세 수 AM-GM을 쓸 수 있습니다. 항의 개수를 바꾸는 것이 곧 새로운 도구가 됩니다.

문제 2

세 수의 AM-GM에서 등호는 a = b = ＿＿＿일 때 성립합니다.

세 수 AM-GM의 증명

음이 아닌 실수 x, y, z에 대해 항등식 x³ + y³ + z³ − 3xyz = (x + y + z) × ½{(x − y)² + (y − z)² + (z − x)²}이 성립합니다.

오른쪽의 두 인수가 모두 0 이상이므로 x³ + y³ + z³ ≥ 3xyz입니다.

여기에 x = ∛a, y = ∛b, z = ∛c를 넣으면 a + b + c ≥ 3∛(abc)가 됩니다. 등호는 (x − y)², (y − z)², (z − x)²이 모두 0, 곧 x = y = z일 때입니다. 증명 자체보다 '세 제곱의 합과 세 수의 곱을 잇는 항등식'이 앞으로 다항식과 정수론에서도 다시 나온다는 점을 기억해 두세요.

예제

음이 아닌 실수 x, y, z에 대해 x³ + y³ + z³ ≥ 3xyz임을 보이세요.

  1. x³ + y³ + z³ − 3xyz = (x + y + z)(x² + y² + z² − xy − yz − zx)입니다.
  2. x² + y² + z² − xy − yz − zx = ½{(x − y)² + (y − z)² + (z − x)²} ≥ 0입니다.
  3. x + y + z ≥ 0이므로 두 인수의 곱은 0 이상입니다.
  4. 따라서 x³ + y³ + z³ ≥ 3xyz이고, 등호는 x = y = z일 때입니다.

답: x³ + y³ + z³ ≥ 3xyz

문제 3

x = 1, y = 2, z = 3일 때 x³ + y³ + z³ − 3xyz의 값은?

합이 일정할 때 곱의 최댓값

a + b + c = S이면 abc ≤ (S/3)³이고, a = b = c = S/3일 때 최대입니다.

세 모서리의 합이 정해진 직육면체 중에서는 정육면체의 부피가 가장 큽니다.

합이 정해진 n개 수의 곱도 같습니다. a + b + c + d = 20이면 abcd ≤ 5⁴입니다. 다만 문제에서 수가 자연수로 제한되면 S/n이 자연수가 아닐 수 있고, 그때는 가장 고르게 나누는 것이 답이 됩니다. 증명의 기초 3장에서 본 '합이 10인 자연수들의 곱'이 그런 예였습니다.

예제

양수 a, b, c가 a + b + c = 12를 만족할 때 abc의 최댓값을 구하세요.

  1. AM-GM에서 ∛(abc) ≤ (a + b + c)/3 = 4입니다.
  2. 양변을 세제곱하면 abc ≤ 64입니다.
  3. a = b = c = 4이면 abc = 64가 실제로 됩니다.
  4. 따라서 최댓값은 64입니다.

답: 64

문제 5

가로, 세로, 높이의 합이 30인 직육면체 부피의 최댓값은?

항을 쪼개 곱을 상수로 만들기

x > 0일 때 x² + 2/x의 최솟값을 구하려면 2/x를 1/x + 1/x로 쪼갭니다. 그러면 세 항 x², 1/x, 1/x의 곱이 1입니다.

x² + 1/x + 1/x ≥ 3∛(x² × 1/x × 1/x) = 3이고, 등호는 x² = 1/x, 곧 x = 1일 때입니다.

어떻게 쪼갤지는 '곱하면 x가 사라지도록'과 '등호가 가능하도록' 두 조건으로 정합니다. x + 32/x²이라면 x를 x/2 + x/2로 쪼개 세 항 x/2, x/2, 32/x²의 곱이 8이 되게 합니다. 쪼개는 개수와 계수는 시행착오로 찾아도 괜찮지만, 답안에는 최종 분할과 등호 조건만 깔끔하게 씁니다.

정리

n개의 양수에 대해 산술평균은 기하평균 이상이고, 등호는 모든 수가 같을 때입니다. 세 수 버전은 x³ + y³ + z³ − 3xyz의 인수분해로 증명합니다.

합이 일정하면 곱은 모두 같을 때 최대, 곱이 일정하면 합은 모두 같을 때 최소입니다.

식의 항을 쪼개 곱이 상수가 되게 만들면 두 수 AM-GM으로 안 풀리던 식도 다룰 수 있습니다. 쪼갠 뒤에는 '쪼갠 항들이 모두 같아지는 값'이 조건 안에 있는지 확인하세요.
