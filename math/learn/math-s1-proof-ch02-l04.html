모든 말은 같은 색인가

다음 '증명'을 보세요. 말 1마리 묶음은 당연히 모두 같은 색이다. k마리 묶음이 늘 같은 색이라면, k + 1마리에서 첫 번째를 뺀 k마리와 마지막을 뺀 k마리가 각각 같은 색이고, 두 묶음이 겹치므로 전체가 같은 색이다.

결론은 분명히 틀렸습니다. 어디가 잘못되었을까요?

귀납 단계는 모든 k에서 성립해야 합니다. 그런데 k = 1일 때, 말 2마리에서 첫 번째를 뺀 묶음과 마지막을 뺀 묶음은 각각 1마리이고 서로 겹치는 말이 없습니다. '두 묶음이 겹치므로'라는 근거가 k = 1에서 깨지기 때문에 P(1)에서 P(2)로 넘어가지 못합니다. 귀납 단계의 논리가 가장 작은 k에서도 통하는지 확인해야 합니다.

문제 1

앞의 '모든 말은 같은 색' 증명에서 귀납 단계가 실패하는 k의 값은?

문제 2

k = 1일 때 말 2마리에서 만든 두 묶음에 공통으로 들어 있는 말은 ＿＿＿마리입니다.

기저를 빼먹으면

귀납 단계만 성립하고 기저가 없으면 아무것도 증명되지 않습니다.

예를 들어 'n² + n + 1은 짝수이다'는 P(k)이면 P(k + 1)이 성립합니다. (k + 1)² + (k + 1) + 1 = (k² + k + 1) + 2(k + 1)이므로 짝수에 짝수를 더하면 짝수이기 때문입니다.

그런데 P(1)은 1 + 1 + 1 = 3으로 거짓이고, 사실 n² + n + 1은 n(n + 1) + 1이라 항상 홀수입니다. 넘어지지 않은 첫 도미노에서는 아무것도 시작되지 않습니다. 기저는 계산이 쉬워 보여도 반드시 써야 하는 이유가 이것입니다.

문제 3

명제 '2n + 1은 짝수이다'는 P(k)이면 P(k + 1)이 성립하지만, P(1)이 ＿＿＿이므로 어떤 자연수에서도 증명되지 않습니다. (참 또는 거짓)

명제를 강하게 바꾸어 증명하기

귀납 가정이 너무 약해서 귀납 단계가 막힐 때는, 오히려 더 강한 명제를 증명하면 풀리는 경우가 있습니다.

예를 들어 1/1² + 1/2² + ⋯ + 1/n² < 2를 그대로 귀납하면, 합이 2보다 작다는 가정에 1/(k + 1)²을 더한 값이 2보다 작다고 말할 수 없어 막힙니다.

그래서 더 강한 명제 '합 ≤ 2 − 1/n'을 증명합니다. 귀납 단계는 2 − 1/k + 1/(k + 1)² ≤ 2 − 1/(k + 1), 곧 1/(k + 1)² ≤ 1/k − 1/(k + 1) = 1/(k(k + 1))이면 되고, 이것은 k(k + 1) ≤ (k + 1)²이라 참입니다. 강한 명제는 귀납 가정도 강하게 해 주기 때문에 증명이 오히려 쉬워집니다.

예제

모든 자연수 n에 대해 1/1² + 1/2² + ⋯ + 1/n² ≤ 2 − 1/n임을 증명하세요.

  1. 기저: n = 1이면 좌변 1, 우변 2 − 1 = 1로 성립합니다.
  2. 귀납 가정: 1/1² + ⋯ + 1/k² ≤ 2 − 1/k라고 가정합니다.
  3. n = k + 1이면 좌변 ≤ 2 − 1/k + 1/(k + 1)²이고, 1/(k + 1)² < 1/(k(k + 1)) = 1/k − 1/(k + 1)이므로 좌변 < 2 − 1/(k + 1)입니다.
  4. 따라서 모든 n에서 성립하고, 특히 합은 항상 2보다 작습니다.

답: 합 ≤ 2 − 1/n < 2

문제 4

앞 예제에서 n = 4일 때 강화된 우변 2 − 1/n의 값을 분수로 쓰세요.

도형과 세기에 쓰는 귀납법

귀납법은 '하나 더 추가할 때 무엇이 늘어나는가'를 묻는 문제에 잘 맞습니다.

평면에 직선 n개를 어느 두 개도 평행하지 않고 어느 세 개도 한 점에서 만나지 않게 그으면, n번째 직선은 앞의 n − 1개와 서로 다른 n − 1개 점에서 만납니다. 이 점들이 n번째 직선을 n조각으로 나누고, 각 조각이 지나는 영역을 둘로 나누므로 영역이 n개 늘어납니다.

그래서 영역의 수 R(n)은 R(n) = R(n − 1) + n, R(0) = 1을 만족하고, 귀납법으로 R(n) = (n² + n + 2)/2임을 보일 수 있습니다. 하노이 탑의 최소 이동 횟수 T(n) = 2T(n − 1) + 1도 같은 방식으로 세웁니다. 점화식을 세우는 근거를 한두 문장으로 반드시 적으세요.

문제 6

일반적인 위치에 있는 직선 4개가 평면을 나누는 영역의 수는?

문제 7

하노이 탑에서 원판 n개를 옮기는 최소 횟수는 T(1) = 1, T(n) = 2T(n − 1) + 1입니다. T(6)은?

정리

귀납 단계의 논리는 가장 작은 k에서도 통해야 합니다. '모든 말은 같은 색'은 k = 1에서 두 묶음이 겹치지 않아 실패합니다.

기저가 없으면 귀납 단계가 성립해도 아무것도 증명되지 않습니다.

귀납 단계가 막히면 더 강한 명제(합 ≤ 2 − 1/n처럼)를 세워 증명합니다. 도형과 세기 문제는 '하나 더 추가할 때 늘어나는 양'으로 점화식을 세우고, 그 근거를 글로 적은 뒤 귀납법으로 공식을 증명합니다.
