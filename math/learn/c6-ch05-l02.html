원의 벡터방정식

원의 벡터방정식

중심의 위치벡터가 c, 반지름이 r인 원 위의 점 P는 |p − c| = r을 만족합니다. (p − c)·(p − c) = r²로도 씁니다.

|p − c|는 점 P와 중심 C 사이의 거리입니다. 그래서 |p − c| = r은 '중심에서 거리가 r인 점들', 즉 원을 그대로 옮긴 식입니다. 성분으로 쓰면 (x − c₁)² + (y − c₂)² = r²으로 코스 2에서 배운 원의 방정식과 같습니다.

문제 2

그 원의 중심을 표시하세요.

지름의 양 끝이 주어진 원

(p − a)·(p − b) = 0은 AB를 지름으로 하는 원입니다. 지름에 대한 원주각이 직각이기 때문입니다.

(p − a)·(p − b) = 0은 벡터 PA와 PB가 수직이라는 뜻입니다. 지름에 대한 원주각은 직각이므로, 점 P에서 A와 B를 바라본 각이 직각인 점들은 AB를 지름으로 하는 원 위에 있습니다. 중심은 AB의 중점, 반지름은 |AB|/2입니다.

예제

A(−1, 2), B(5, 2)에 대해 (p − a)·(p − b) = 0이 나타내는 원의 중심과 반지름을 구하세요.

  1. AB를 지름으로 하는 원
  2. 중심 = AB의 중점 = (2, 2)
  3. 반지름 = |AB|/2 = 6/2 = 3
  4. (x − 2)² + (y − 2)² = 9

답: 중심 (2, 2), 반지름 3

원의 접선

원 위의 점 Q에서의 접선 위의 점 P는 (q − c)·(p − q) = 0을 만족합니다. 반지름과 접선이 수직이기 때문입니다.

원의 접선은 접점을 지나는 반지름에 수직입니다. 그래서 반지름 벡터 q − c와 접선 위의 벡터 p − q의 내적이 0입니다. 중심이 원점이면 q·(p − q) = 0에서 q·p = |q|² = r²이 되어 x₁x + y₁y = r²이 나옵니다.

문제 6

원의 접선과 접점을 지나는 반지름이 이루는 각은 몇 도일까요?

자취

|PA| = |PB|인 점 P의 자취는 AB의 수직이등분선, |PA| = k|PB| (k ≠ 1)인 점의 자취는 원입니다.

|PA| = k|PB|인 점의 자취를 아폴로니오스의 원이라 합니다. 양변을 제곱해 성분으로 전개하면 x², y²의 계수가 같은 식이 되어 원이 됩니다. k = 1이면 제곱항이 지워져 직선(수직이등분선)이 됩니다.

예제

A(0, 0), B(6, 0)에 대해 |PA| = 2|PB|인 점 P의 자취를 구하세요.

  1. x² + y² = 4{(x − 6)² + y²}
  2. 3x² + 3y² − 48x + 144 = 0 → x² + y² − 16x + 48 = 0
  3. (x − 8)² + y² = 16
  4. 중심 (8, 0), 반지름 4인 원

답: (x − 8)² + y² = 16

문제 9

그 원의 중심의 x좌표는?

정리

원은 '중심에서 거리가 일정', 지름 원은 '양 끝을 보는 각이 직각'이라는 벡터 조건으로 나타낼 수 있습니다.

원 위의 점과 원 밖의 점 사이의 거리는 중심을 지나는 직선 위에서 최댓값과 최솟값을 가집니다. 중심까지의 거리 d에 반지름 r을 더하면 최댓값, 빼면 최솟값입니다. 점이 원 안에 있으면 최솟값은 r − d가 됩니다.

예제

원 |p − (1, 1)| = 2 위의 점과 점 (4, 5) 사이의 거리의 최댓값과 최솟값을 구하세요.

  1. 중심 (1, 1)과 (4, 5) 사이의 거리 d = √(9 + 16) = 5
  2. 반지름 r = 2
  3. 최댓값 d + r = 7
  4. 최솟값 d − r = 3

답: 7, 3
