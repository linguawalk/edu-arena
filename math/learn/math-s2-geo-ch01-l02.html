각의 이등분선과 내심

각 A의 이등분선이 BC와 만나는 점 D는 BD/DC = AB/AC를 만족합니다(각의 이등분선 정리).

세 이등분선에 대해 비를 곱하면 (AB/AC)(BC/BA)(CA/CB) = 1이므로, 체바 정리의 역에 의해 세 각의 이등분선은 한 점(내심)에서 만납니다.

AB = 6, AC = 4, BC = 5이면 BD = 5 × 6/10 = 3, DC = 2입니다.

문제 1

AB = 6, AC = 4, BC = 5인 삼각형에서 각 A의 이등분선이 BC와 만나는 점 D에 대해 BD는?

문제 2

삼각형의 세 각의 이등분선이 만나는 점을 ＿＿＿이라 합니다.

내접원의 접점 (제르곤 점)

내접원이 BC, CA, AB에 접하는 점을 D, E, F라 하면 BD = BF = s − b, CD = CE = s − c, AE = AF = s − a입니다(s는 반둘레, a = BC, b = CA, c = AB).

그래서 (BD/DC)(CE/EA)(AF/FB) = ((s − b)/(s − c))((s − c)/(s − a))((s − a)/(s − b)) = 1이고, AD, BE, CF는 한 점(제르곤 점)에서 만납니다.

a = 5, b = 4, c = 6이면 s = 7.5이고 BD = s − b = 3.5, DC = s − c = 1.5입니다.

예제

a = BC = 5, b = CA = 4, c = AB = 6인 삼각형에서 내접원이 BC에 접하는 점 D에 대해 BD/DC를 구하세요.

  1. 반둘레 s = (5 + 4 + 6)/2 = 7.5입니다.
  2. BD = s − b = 7.5 − 4 = 3.5입니다.
  3. DC = s − c = 7.5 − 6 = 1.5입니다.
  4. BD/DC = 3.5/1.5 = 7/3입니다.

답: 7/3

문제 4

AB = 9, AC = 6, BC = 10인 삼각형에서 각 A의 이등분선이 BC와 만나는 점 D에 대해 DC는?

질량점

체바 선분의 비 문제는 꼭짓점에 '질량'을 놓아 빠르게 풀 수 있습니다. BD : DC = 2 : 1이면 B에 1, C에 2를 놓아 D(질량 3)가 BC의 무게중심이 되게 합니다.

AE : EC = 1 : 1이면 A와 C의 질량이 같아야 하므로 A에도 2를 놓습니다. 그러면 E의 질량은 4입니다.

AD와 BE의 교점 P에서 AP : PD = (D의 질량) : (A의 질량) = 3 : 2, BP : PE = 4 : 1입니다.

문제 7

BD : DC = 1 : 1, AE : EC = 2 : 1일 때 AD와 BE의 교점 P에 대해 AP/PD는?

정리

각의 이등분선 정리 BD/DC = AB/AC와 체바 정리로 세 이등분선이 내심에서 만납니다.

내접원의 접선 길이는 s − a, s − b, s − c이고, 체바 정리로 AD, BE, CF가 제르곤 점에서 만납니다.

질량점: 각 변의 비가 맞도록 꼭짓점에 질량을 놓으면, 교점이 체바 선분을 나누는 비는 (반대쪽 질량) : (꼭짓점 질량)입니다.
