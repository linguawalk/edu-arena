부정적분

미적분 · 4. 적분 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

미분을 거꾸로

F′(x) = f(x)인 F(x)를 f(x)의 부정적분이라 하고 ∫ f(x) dx = F(x) + C로 씁니다.

C는 적분상수입니다. 상수는 미분하면 0이 되어 사라지므로 어떤 상수든 붙을 수 있습니다.

부정적분은 '미분하면 f(x)가 되는 함수'를 찾는 일입니다. 그런데 x² + 1, x² − 5, x² + 100은 모두 미분하면 2x가 됩니다. 상수 부분은 미분하면 사라져 원래 무엇이었는지 알 수 없으므로, 모든 가능성을 C라는 문자 하나로 나타냅니다. 부정적분이 함수 하나가 아니라 함수의 무리를 나타내는 이유입니다.

문제 1

∫ 2x dx = x^＿＿＿ + C

문제 2

∫ 3x² dx = x^＿＿＿ + C

기본 공식

∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C (n ≠ −1), ∫ k dx = kx + C

합과 차, 상수배는 항마다 따로 적분합니다.

공식은 미분을 거꾸로 한 것입니다. (xⁿ⁺¹)′ = (n + 1)xⁿ이므로, xⁿ이 나오게 하려면 xⁿ⁺¹을 (n + 1)로 나눠야 합니다. '지수를 1 올리고, 올린 지수로 나눈다'고 기억하세요. 결과를 미분해 원래 식이 나오는지 확인하는 습관이 실수를 막아 줍니다.

예제

∫ (3x² − 4x + 5) dx를 구하세요.

  1. 항마다 따로 적분합니다.
  2. ∫ 3x² dx = x³, ∫ (−4x) dx = −2x², ∫ 5 dx = 5x
  3. 결과: x³ − 2x² + 5x + C
  4. 확인: 미분하면 3x² − 4x + 5

답: x³ − 2x² + 5x + C

적분상수 정하기

f(a)의 값처럼 조건이 하나 주어지면 C가 정해져 함수가 하나로 결정됩니다.

적분상수 C 때문에 부정적분은 위아래로 평행이동한 곡선들의 모임입니다. 그중 특정한 점을 지나는 곡선은 하나뿐이므로, f(a) = b 같은 조건 하나로 C가 결정됩니다. 초기 위치가 주어진 운동 문제가 대표적인 예입니다.

예제

f′(x) = 4x³ − 2x, f(1) = 3일 때 f(x)를 구하세요.

  1. f(x) = x⁴ − x² + C
  2. f(1) = 1 − 1 + C = 3에서 C = 3
  3. f(x) = x⁴ − x² + 3
  4. 확인: f(1) = 3

답: f(x) = x⁴ − x² + 3

미분과 적분의 관계

d/dx ∫ f(x) dx = f(x), ∫ {d/dx f(x)} dx = f(x) + C

미분과 적분은 서로 되돌리는 연산이지만, 순서에 따라 결과가 조금 다릅니다. 적분한 뒤 미분하면 원래 함수가 그대로 나오지만, 미분한 뒤 적분하면 사라졌던 상수를 알 수 없어 C가 붙습니다. 두 연산의 순서에 주의하세요.

문제 9

곡선 구하기

곡선 위 각 점에서의 접선의 기울기가 주어지면, 그것을 적분하고 지나는 점으로 C를 정해 곡선을 구합니다.

접선의 기울기는 도함수이므로, 기울기를 알려 주는 식을 적분하면 곡선의 식이 나옵니다(상수 C만 모름). 곡선이 지나는 점 하나를 넣어 C를 정하면 곡선이 완전히 결정됩니다. 속도에서 위치를 구하는 것도 같은 원리입니다.

예제

점 (1, 2)를 지나고 각 점에서의 접선의 기울기가 6x² − 1인 곡선의 식을 구하세요.

  1. y = ∫ (6x² − 1) dx = 2x³ − x + C
  2. (1, 2)를 지남: 2 − 1 + C = 2에서 C = 1
  3. y = 2x³ − x + 1
  4. 확인: y′ = 6x² − 1

답: y = 2x³ − x + 1
