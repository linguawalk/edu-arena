수열의 극한

미적분 · 5. 수열의 극한과 급수 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

수렴과 발산

n이 한없이 커질 때 aₙ이 일정한 값 L에 한없이 가까워지면 수열이 L에 수렴한다고 하고 lim(n→∞) aₙ = L로 씁니다.

수렴하지 않으면 발산한다고 합니다.

함수의 극한에서 x → ∞를 다룬 것과 같지만, 수열은 n이 자연수로만 커진다는 점이 다릅니다. 수렴은 '어떤 값에 한없이 가까워지는' 것이고, 한없이 커지거나 여러 값 사이를 오가며 정착하지 않으면 발산입니다. 1/n은 0이 되지는 않지만 0에 한없이 가까워지므로 0에 수렴합니다.

문제 1

lim(n→∞) 1/n의 값은?

문제 2

lim(n→∞) (2n + 1)/n의 값은?

∞/∞ 꼴

분모의 최고차항으로 분모, 분자를 나눕니다. 차수가 같으면 최고차항 계수의 비, 분모 차수가 크면 0입니다.

n이 한없이 커지면 최고차항이 나머지 항을 압도합니다. 분모의 최고차항으로 나누면 나머지 항들은 1/n, 1/n² 꼴이 되어 0으로 사라지고 최고차항끼리의 비교만 남습니다. 분자의 차수가 더 크면 분모보다 빨리 커져 발산합니다.

예제

lim(n→∞) (3n² − 2n + 1)/(2n² + 5)를 구하세요.

  1. 분모의 최고차항 n²으로 분모, 분자를 나눕니다.
  2. (3 − 2/n + 1/n²)/(2 + 5/n²)
  3. n → ∞이면 1/n, 1/n² → 0
  4. = 3/2 (최고차항 계수의 비)

답: 3/2

발산하는 수열

한없이 커지면 양의 무한대로 발산, 1, −1, 1, −1처럼 오가면 진동한다고 합니다.

발산에는 두 종류가 있습니다. 한 방향으로 한없이 커지거나 작아지는 것(∞ 또는 −∞로 발산)과, 1, −1, 1, −1처럼 오가며 어느 한 값에도 가까워지지 않는 것(진동)입니다. 진동하는 수열도 수렴하지 않으므로 발산입니다.

문제 7

수열 (n² + 1)/n은 수렴할까요? (그렇다 1, 아니다 0)

∞ − ∞ 꼴

√가 있는 차는 유리화해 ∞/∞ 꼴로 바꿉니다. √(n² + 2n) − n = 2n/(√(n² + 2n) + n)

∞ − ∞는 '큰 수에서 큰 수를 뺀 것'이라 얼마인지 바로 알 수 없습니다. √(n² + 2n)과 n은 둘 다 커지지만 그 차는 일정한 값에 가까워질 수 있습니다. 켤레를 곱해 유리화하면 ∞/∞ 꼴이 되어 앞의 방법으로 계산할 수 있습니다.

예제

lim(n→∞) (√(n² + 6n) − n)을 구하세요.

  1. 켤레 √(n² + 6n) + n을 분모, 분자에 곱합니다.
  2. 분자: (n² + 6n) − n² = 6n
  3. 6n/(√(n² + 6n) + n)을 n으로 나누면 6/(√(1 + 6/n) + 1)
  4. → 6/2 = 3

답: 3

문제 9

lim(n→∞) (√(n² + n) − n)의 값은? (기약분수로)

극한의 성질

수렴하는 두 수열의 합, 차, 곱, 몫의 극한은 각 극한의 합, 차, 곱, 몫입니다.

aₙ ≤ cₙ ≤ bₙ이고 lim aₙ = lim bₙ = L이면 lim cₙ = L입니다.

마지막 성질은 '샌드위치 정리'라고도 합니다. 극한을 직접 구하기 어려운 수열도, 극한이 같은 두 수열 사이에 끼워 넣으면 극한을 알 수 있습니다. 예를 들어 −1/n ≤ (sin n)/n ≤ 1/n이고 양쪽이 0으로 가므로 가운데도 0으로 갑니다.

예제

lim(n→∞) (1 + 2 + … + n)/(n² + 1)을 구하세요.

  1. 분자: n(n + 1)/2 = (n² + n)/2
  2. (n² + n)/(2(n² + 1))
  3. 최고차항 계수의 비: 1/2
  4. 원리: Σ 공식으로 분자를 n의 식으로 바꿉니다.

답: 1/2
