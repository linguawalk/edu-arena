이계도함수

도함수 f′(x)를 한 번 더 미분한 것을 이계도함수라 하고 f″(x), y″, d²y/dx²로 씁니다.

도함수 f′(x)도 하나의 함수이므로 다시 미분할 수 있습니다. f′이 '기울기'라면 f″은 '기울기가 얼마나 빨리 변하는가'입니다. 운동에서는 위치 → 속도 → 가속도로, 한 번 미분할 때마다 '변화의 변화'를 보게 됩니다.

가속도

위치 x(t)를 두 번 미분하면 가속도 x″(t)입니다.

위치를 한 번 미분하면 속도, 두 번 미분하면 가속도입니다. 자동차의 가속 페달을 밟으면 가속도가 양수가 되어 속도가 커지고, 브레이크를 밟으면 가속도가 음수가 되어 속도가 줄어듭니다. 속도와 가속도의 부호가 같으면 빨라지고, 다르면 느려집니다.

예제

x(t) = 2t³ − 9t² + 12t일 때 속도가 0인 순간의 가속도를 구하세요.

  1. v(t) = 6t² − 18t + 12 = 6(t − 1)(t − 2)
  2. 속도가 0인 순간: t = 1, t = 2
  3. a(t) = 12t − 18
  4. a(1) = −6, a(2) = 6

답: t = 1에서 −6, t = 2에서 6

여러 번 미분하기

세 번, 네 번 미분한 것도 같은 방법으로 구합니다. sin x는 네 번 미분하면 다시 sin x가 됩니다.

다항함수는 차수보다 많이 미분하면 0이 됩니다(x⁵은 여섯 번 미분하면 0). 삼각함수는 sin → cos → −sin → −cos → sin으로 네 번마다 원래대로 돌아오고, eˣ는 몇 번을 미분해도 eˣ 그대로입니다.

예제

f(x) = cos x를 101번 미분한 함수를 구하세요.

  1. cos → −sin → −cos → sin → cos로 네 번마다 반복
  2. 101 = 4 × 25 + 1
  3. 한 번 미분한 것과 같음
  4. −sin x

답: −sin x

이계도함수로 극값 판정

f′(a) = 0이고 f″(a) > 0이면 x = a에서 극소, f″(a) < 0이면 극대입니다.

왜 f″로 극값을 판정할 수 있을까요? f′(a) = 0이고 f″(a) > 0이면 f′이 a 근처에서 증가하므로, a의 왼쪽에서 f′ < 0, 오른쪽에서 f′ > 0입니다. 즉 감소하다 증가하므로 극소입니다. f″(a) = 0이면 이 방법으로는 판정할 수 없어 증감표를 써야 합니다.

예제

f(x) = x⁴ − 8x²의 극값을 이계도함수로 판정하세요.

  1. f′(x) = 4x³ − 16x = 4x(x − 2)(x + 2) = 0에서 x = 0, ±2
  2. f″(x) = 12x² − 16
  3. f″(0) = −16 < 0 → 극대 f(0) = 0
  4. f″(±2) = 32 > 0 → 극소 f(±2) = −16

답: 극댓값 0, 극솟값 −16

문제 10

f(x) = −x² + 4x는 x = 2에서 극대일까요? (그렇다 1, 아니다 0)

정리

f′는 기울기, f″는 기울기가 변하는 빠르기입니다.

f′(x) > 0이면 함수가 올라가고, f″(x) > 0이면 올라가는 기울기가 점점 가팔라집니다. 두 정보를 함께 보면 그래프가 어떻게 휘어지며 움직이는지 알 수 있습니다. 다음 레슨에서 f″을 그래프의 볼록한 방향과 연결합니다. f″의 부호가 곧 곡선이 휘는 방향입니다.
