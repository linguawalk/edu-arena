평균들의 줄

양수 a, b에 대해 제곱평균 QM = √((a² + b²)/2), 산술평균 AM = (a + b)/2, 기하평균 GM = √(ab), 조화평균 HM = 2ab/(a + b)이고 QM ≥ AM ≥ GM ≥ HM입니다.

a = 1, b = 4이면 QM = √8.5 ≈ 2.92, AM = 2.5, GM = 2, HM = 8/5 = 1.6입니다.

등호는 모두 a = b일 때 성립합니다. 이 줄은 n개의 수와 일반적인 멱평균으로도 확장됩니다.

가중 산술-기하 평균

합이 일정할 때 x²y의 최댓값처럼 지수가 다른 곱을 다룰 때는 변수를 나누어 산술-기하 평균을 씁니다. x + y = 3(양수)이면 x/2 + x/2 + y = 3이고, 산술-기하로 (x/2 + x/2 + y)/3 ≥ ∛((x/2)(x/2)y) = ∛(x²y/4)입니다.

왼쪽은 1이므로 x²y ≤ 4이고, 등호는 x/2 = y, 곧 x = 2, y = 1일 때입니다.

요령: 등호에서 나누어진 조각들이 모두 같아지도록 나눕니다. xᵃyᵇ이면 x를 a조각(x/a), y를 b조각(y/b)으로 나눕니다.

예제

양수 x, y가 x + y = 6일 때 xy²의 최댓값을 구하세요.

  1. x + y/2 + y/2 = 6으로 나눕니다(y를 두 조각).
  2. 산술-기하: 6/3 ≥ ∛(x · y/2 · y/2) = ∛(xy²/4)입니다.
  3. 2³ = 8 ≥ xy²/4이므로 xy² ≤ 32입니다.
  4. 등호는 x = y/2, x + y = 6, 곧 x = 2, y = 4일 때이므로 최댓값은 32입니다.

답: 32

조화평균과 속력

같은 거리를 속력 a와 b로 한 번씩 갈 때 평균 속력은 산술평균이 아니라 조화평균 2ab/(a + b)입니다. 갈 때 60, 올 때 40이면 평균 속력은 2 × 60 × 40/100 = 48입니다.

AM ≥ HM이므로 평균 속력은 언제나 두 속력의 산술평균(50)보다 작거나 같습니다.

산술-조화 평균 부등식은 (a + b)(1/a + 1/b) ≥ 4로도 쓸 수 있습니다.

정리

양수에 대해 QM ≥ AM ≥ GM ≥ HM이며 등호는 모든 수가 같을 때입니다. 조화평균은 같은 거리를 다른 속력으로 갈 때의 평균 속력입니다.

xᵃyᵇ의 최댓값은 x를 a조각, y를 b조각으로 나누어 산술-기하 평균을 쓰고, 등호에서 조각들이 같아지도록 합니다.

산술-조화 평균은 (a + b)(1/a + 1/b) ≥ 4, n개이면 (Σaᵢ)(Σ1/aᵢ) ≥ n²으로도 씁니다.
