두 가지 평균

양수 a, b의 산술평균은 (a + b)/2, 기하평균은 √(ab)입니다. 언제나 (a + b)/2 ≥ √(ab)이고, 등호는 a = b일 때만 성립합니다. 이것을 산술·기하 평균 부등식(AM-GM)이라고 합니다.

증명은 증명의 기초 트랙에서 이미 했습니다. (√a − √b)² ≥ 0을 전개하면 a + b ≥ 2√(ab)입니다.

왜 이 부등식이 올림피아드 대수의 출발점일까요? 합과 곱을 이어 주기 때문입니다. 합이 정해지면 곱의 최댓값이, 곱이 정해지면 합의 최솟값이 바로 나옵니다. 그리고 두 경우 모두 '두 수가 같을 때'가 최선이라는 답을 함께 줍니다.

문제 1

a = 2, b = 8일 때 기하평균 √(ab)의 값은?

문제 2

a = 4, b = 9일 때 산술평균에서 기하평균을 뺀 값을 분수로 쓰세요.

합이 일정하면 곱은 언제 가장 클까

a + b = S로 정해져 있으면 AM-GM에서 √(ab) ≤ S/2, 곧 ab ≤ (S/2)²입니다.

등호는 a = b = S/2일 때 성립하므로, 곱의 최댓값은 (S/2)²이고 두 수가 같을 때 나옵니다.

둘레가 정해진 직사각형 중 넓이가 가장 큰 것이 정사각형인 이유가 바로 이것입니다. 가로를 a, 세로를 b라 하면 a + b는 둘레의 절반으로 고정되고, 넓이 ab는 a = b일 때 최대입니다. 최댓값을 답할 때는 '항상 이하'와 '등호가 실제로 성립함'을 모두 보여야 한다는 점을 잊지 마세요.

예제

둘레가 20인 직사각형 넓이의 최댓값을 구하세요.

  1. 가로를 a, 세로를 b라 하면 2(a + b) = 20이므로 a + b = 10입니다.
  2. AM-GM에서 √(ab) ≤ (a + b)/2 = 5이므로 ab ≤ 25입니다.
  3. a = b = 5이면 ab = 25가 실제로 됩니다.
  4. 따라서 최댓값은 25이고, 한 변이 5인 정사각형일 때입니다.

답: 25

문제 3

둘레가 36인 직사각형 넓이의 최댓값은?

곱이 일정하면 합은 언제 가장 작을까

ab = P로 정해져 있으면 a + b ≥ 2√P이고, 등호는 a = b = √P일 때입니다.

가장 자주 쓰는 꼴은 x > 0일 때 x + k/x ≥ 2√k입니다. 두 항 x와 k/x의 곱이 상수 k라서 AM-GM을 바로 쓸 수 있습니다.

핵심은 '곱이 상수가 되도록' 두 항을 고르는 것입니다. 4x + 9/x라면 4x × 9/x = 36이 상수이므로 4x + 9/x ≥ 2√36 = 12입니다. 등호는 두 항이 같을 때, 곧 4x = 9/x인 x = 3/2에서 성립합니다. 등호가 되는 x를 직접 구해 써 넣는 것까지가 최솟값 답안입니다.

예제

x > 0일 때 x + 25/x의 최솟값을 구하세요.

  1. x × 25/x = 25로 두 항의 곱이 상수입니다.
  2. AM-GM에서 x + 25/x ≥ 2√25 = 10입니다.
  3. 등호는 x = 25/x, 곧 x = 5일 때 성립하고, 이때 5 + 5 = 10입니다.
  4. 따라서 최솟값은 10입니다.

답: 10

문제 6

x > 0이면 x + 1/x ≥ ＿＿＿입니다.

정리

양수 a, b에 대해 (a + b)/2 ≥ √(ab)이고, 등호는 a = b일 때입니다.

합이 일정하면 곱은 두 수가 같을 때 최대이고, 곱이 일정하면 합은 두 수가 같을 때 최소입니다.

AM-GM을 쓰기 전에 두 가지를 확인하세요. 각 항이 양수인가, 그리고 곱(또는 합)이 상수가 되는가. 쓴 뒤에는 등호가 되는 값을 실제로 찾아 답안에 적습니다. 양수 조건이 없으면 x + 1/x는 x = −1에서 −2가 되어 '2 이상'이 깨집니다.
