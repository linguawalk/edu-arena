직선의 벡터방정식

기하 · 5. 벡터의 활용 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

방향벡터로 나타내기

점 A(위치벡터 a)를 지나고 방향벡터가 u인 직선 위의 점 P는 p = a + tu (t는 실수)로 나타냅니다.

성분으로 쓰면 (x − x₁)/u₁ = (y − y₁)/u₂입니다.

p = a + tu는 '점 A에서 출발해 u 방향으로 t만큼 간 위치'라는 뜻입니다. t가 모든 실수를 움직이면 그 위치들이 직선을 이룹니다. t를 시간으로 보면 일정한 속도 u로 움직이는 물체의 위치가 됩니다. 성분식에서 t를 없애면 (x − x₁)/u₁ = (y − y₁)/u₂라는 익숙한 직선의 방정식이 나옵니다.

문제 2

같은 직선에서 t = 2일 때 점의 x좌표는?

두 점을 지나는 직선

두 점 A, B를 지나는 직선의 방향벡터는 AB입니다.

두 점 A, B를 지나는 직선은 A에서 출발해 AB 방향으로 가면 되므로 p = a + t(b − a)입니다. t = 0이면 A, t = 1이면 B이고, 0 < t < 1이면 선분 AB 위의 점입니다. 방향벡터 (u₁, u₂)의 기울기는 u₂/u₁입니다.

예제

두 점 A(−1, 3), B(2, −3)을 지나는 직선의 벡터방정식과 일반형을 구하세요.

  1. 방향벡터 AB = (3, −6), 간단히 (1, −2)
  2. p = (−1, 3) + t(1, −2), 즉 x = −1 + t, y = 3 − 2t
  3. t를 없애면 y − 3 = −2(x + 1)
  4. 2x + y − 1 = 0

답: 2x + y − 1 = 0

문제 4

같은 직선의 기울기는?

법선벡터로 나타내기

점 A를 지나고 벡터 n에 수직인 직선은 n·(p − a) = 0입니다. n = (a, b)이면 ax + by + c = 0 꼴이 됩니다.

직선 ax + by + c = 0의 법선벡터는 (a, b)입니다.

법선벡터 방식은 '직선 위의 두 점을 잇는 벡터가 항상 n에 수직'이라는 조건입니다. n·(p − a) = 0을 성분으로 풀면 a(x − x₁) + b(y − y₁) = 0이 되어 일반형 ax + by + c = 0이 나옵니다. 그래서 일반형의 x, y 계수가 곧 법선벡터입니다.

예제

점 (2, −1)을 지나고 직선 3x − y + 5 = 0에 수직인 직선을 구하세요.

  1. 주어진 직선의 법선벡터 (3, −1)이 새 직선의 방향벡터
  2. (x − 2)/3 = (y + 1)/(−1)
  3. −(x − 2) = 3(y + 1)
  4. x + 3y + 1 = 0

답: x + 3y + 1 = 0

두 직선이 이루는 각

두 직선의 방향벡터(또는 법선벡터)가 이루는 각으로 구합니다. 예각 쪽을 답으로 씁니다.

두 직선이 이루는 각은 방향벡터끼리의 각으로 구하되, 직선은 방향이 없으므로 둔각이 나오면 180°에서 뺀 예각을 답으로 합니다. 내적의 절댓값을 써서 cos θ = |u·v|/(|u||v|)로 계산하면 바로 예각이 나옵니다.

문제 7

방향벡터가 (1, 0), (1, 1)인 두 직선이 이루는 각은 몇 도일까요?

문제 8

두 직선 x + y = 1, x − y = 3이 이루는 각은 몇 도일까요?

정리

방향벡터는 직선을 따라가는 방향, 법선벡터는 직선에 수직인 방향입니다.

직선을 나타내는 두 방법을 정리하면: 방향벡터 u는 직선과 평행하고, 법선벡터 n은 직선과 수직입니다. 그래서 u·n = 0이며, 기울기가 m인 직선의 방향벡터는 (1, m), 법선벡터는 (m, −1)로 잡을 수 있습니다.

예제

두 직선 x − 2y = 0, 3x + y = 5가 이루는 예각의 크기를 구하세요.

  1. 법선벡터 n₁ = (1, −2), n₂ = (3, 1)
  2. n₁·n₂ = 3 − 2 = 1, |n₁| = √5, |n₂| = √10
  3. cos θ = 1/√50 = 1/(5√2)
  4. θ ≈ 81.9° (예각)

답: cos θ = √2/10, 약 81.9°
