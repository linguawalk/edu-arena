벡터로 보는 코시-슈바르츠

벡터 u = (a, b), v = (x, y)에 대해 u · v = ax + by이고 |u| = √(a² + b²), |v| = √(x² + y²)입니다. 코시-슈바르츠는 |u · v| ≤ |u||v|라는 뜻입니다.

u · v = |u||v|cos θ이고 |cos θ| ≤ 1이기 때문입니다. 등호는 θ = 0 또는 π, 곧 두 벡터가 평행할 때입니다.

이 해석은 등호 조건을 기억하기 쉽게 해 줍니다. '계수 벡터와 변수 벡터가 같은 방향일 때 내적이 가장 크다'는 것이 곧 최댓값의 등호 조건입니다. 고등학교에서 벡터를 배웠다면, 코시-슈바르츠 문제를 '두 벡터의 사잇각을 가장 작게 만드는 문제'로 볼 수 있습니다.

직선까지의 거리

직선 3x + 4y = 25 위의 점 중 원점에 가장 가까운 점까지의 거리를 구해 봅시다. 코시-슈바르츠에서 (x² + y²)(9 + 16) ≥ (3x + 4y)² = 625이므로 x² + y² ≥ 25, 곧 거리 ≥ 5입니다.

등호는 (x, y)가 (3, 4)에 평행할 때, 곧 (x, y) = (3, 4)일 때입니다. 이 점이 원점에서 직선에 내린 수선의 발입니다.

일반적으로 원점에서 직선 ax + by = c까지의 거리는 |c|/√(a² + b²)입니다. 이 공식이 코시-슈바르츠 그 자체라는 것을 알면, 공간에서 평면까지의 거리 |d|/√(a² + b² + c²)도 같은 방식으로 이해할 수 있습니다.

문제 4

5x + 12y = 26일 때 x² + y²의 최솟값은?

근호가 있는 식의 최댓값

0 ≤ x ≤ 1일 때 3√x + 4√(1 − x)의 최댓값을 구해 봅시다. (3² + 4²)((√x)² + (√(1 − x))²) ≥ (3√x + 4√(1 − x))²이고 (√x)² + (√(1 − x))² = 1입니다.

따라서 3√x + 4√(1 − x) ≤ 5입니다. 등호는 √x : √(1 − x) = 3 : 4, 곧 16x = 9(1 − x)인 x = 9/25일 때입니다.

근호 안의 합이 상수가 되도록 √x, √(1 − x)를 '변수'로 보는 것이 요령입니다. 미분으로도 풀 수 있지만, 코시-슈바르츠는 최댓값과 그때의 x를 한 번에 줍니다. √x + √(8 − x)처럼 계수가 같으면 x = 4, 곧 가운데에서 최대가 됩니다.

예제

0 ≤ x ≤ 1일 때 3√x + 4√(1 − x)의 최댓값을 구하세요.

  1. 코시-슈바르츠에서 (3√x + 4√(1 − x))² ≤ (3² + 4²)(x + (1 − x)) = 25입니다.
  2. 따라서 3√x + 4√(1 − x) ≤ 5입니다.
  3. 등호는 √x/3 = √(1 − x)/4, 곧 16x = 9 − 9x인 x = 9/25일 때입니다.
  4. x = 9/25이면 3 × 3/5 + 4 × 4/5 = 9/5 + 16/5 = 5이므로 최댓값은 5입니다.

문제 6

0 ≤ x ≤ 8일 때 √x + √(8 − x)의 최댓값은?

역수 쌍 만들기

양수 x, y, z에 대해 (x + y + z)(1/x + 1/y + 1/z) ≥ 9는 코시-슈바르츠로도 증명됩니다. (√x, √y, √z)와 (1/√x, 1/√y, 1/√z)를 짝지으면 곱의 합이 1 + 1 + 1 = 3입니다.

그러면 (x + y + z)(1/x + 1/y + 1/z) ≥ 3² = 9입니다.

분자에 계수가 있어도 같습니다. (x + y + z)(1/x + 4/y + 9/z)는 (√x, √y, √z)와 (1/√x, 2/√y, 3/√z)를 짝지어 (1 + 2 + 3)² = 36 이상입니다. 이것은 레슨 3의 분수 꼴과 같은 결과이므로, 분수 꼴이 사실 이 짝짓기에서 나왔다는 것을 확인할 수 있습니다.

문제 7

양수 x, y, z에 대해 (x + y + z)(1/x + 4/y + 9/z)의 최솟값은?

정리

코시-슈바르츠는 벡터의 내적에 대해 |u · v| ≤ |u||v|라는 뜻이고, 등호는 두 벡터가 평행할 때입니다.

원점에서 직선이나 평면까지의 거리, 근호가 있는 식의 최댓값, 역수 쌍의 곱의 최솟값을 모두 같은 방법으로 다룹니다.

어려운 점은 언제나 '무엇과 무엇을 짝지을지'입니다. 원하는 식이 곱의 합으로 나오고, 다른 쪽의 제곱합이 상수가 되도록 짝을 고르세요. 짝을 고른 뒤에는 등호가 되는 값을 실제로 구해 확인합니다.
