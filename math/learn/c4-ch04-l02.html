정적분의 뜻

넓이를 직사각형으로

곡선 아래 넓이는 폭이 좁은 직사각형 여러 개로 채워 어림할 수 있습니다. 폭을 좁힐수록 정확해집니다.

곡선 아래 넓이는 직접 공식으로 구할 수 없지만, 직사각형의 넓이는 가로 × 세로로 쉽게 구할 수 있습니다. 그래서 구간을 잘게 나눠 직사각형으로 채우고, 나누는 개수를 늘려 가며 오차를 줄입니다. 이 아이디어가 적분의 출발점입니다.

문제 1

y = 2와 x축 사이, 0 ≤ x ≤ 3 부분의 넓이는?

문제 2

y = x와 x축 사이, 0 ≤ x ≤ 4 부분의 넓이는?

구분구적법

구간을 n등분해 직사각형 넓이의 합을 구하고 n → ∞일 때의 극한을 구하면 정확한 넓이가 됩니다.

y = x²과 x축 사이, 0 ≤ x ≤ 1의 넓이는 이렇게 1/3이 됩니다.

n등분하면 각 직사각형의 폭은 1/n, 오른쪽 끝의 높이는 (k/n)²입니다. 합은 (1/n)Σ(k/n)² = (1/n³)Σk² = (n + 1)(2n + 1)/(6n²)이고, n → ∞이면 2/6 = 1/3입니다. 코스 3에서 배운 Σk² 공식과 코스 4의 극한이 여기서 만납니다.

예제

0 ≤ x ≤ 2에서 y = x와 x축 사이의 넓이를 4등분 직사각형(오른쪽 끝 높이)으로 어림하고 참값과 비교하세요.

  1. 폭 0.5, 높이 0.5, 1, 1.5, 2
  2. 합: 0.5 × (0.5 + 1 + 1.5 + 2) = 2.5
  3. 참값은 삼각형 넓이 2 × 2 ÷ 2 = 2
  4. 오른쪽 끝을 쓰면 증가함수에서 조금 크게 어림됩니다.

답: 어림 2.5, 참값 2

문제 4

0 ≤ x ≤ 1을 4등분해 각 구간 오른쪽 끝의 높이로 만든 직사각형 넓이의 합은? (기약분수로)

정적분

f(x) ≥ 0일 때 y = f(x)와 x축 사이, a ≤ x ≤ b 부분의 넓이를 정적분 ∫ₐᵇ f(x) dx로 씁니다.

∫ₐᵇ f(x) dx에서 ∫는 합(Sum)의 S를 길게 늘인 모양이고, f(x) dx는 '높이 × 아주 얇은 폭'인 직사각형 하나의 넓이를 뜻합니다. 즉 정적분은 아주 얇은 직사각형들을 a부터 b까지 모두 더한 것입니다.

x축 아래의 부분

f(x) < 0인 부분은 정적분에서 음수로 계산됩니다. 그래서 정적분은 '넓이'가 아니라 '부호가 있는 넓이'입니다.

f(x) < 0이면 '높이 × 폭'이 음수가 되므로 그 부분은 음수로 더해집니다. 그래서 x축 위와 아래의 넓이가 같으면 정적분은 0이 될 수 있습니다. 실제 넓이를 구할 때는 절댓값을 씌워야 합니다.

예제

∫₋₂² x dx와 y = x와 x축 사이(−2 ≤ x ≤ 2)의 넓이를 비교하세요.

  1. x축 위: 0 ≤ x ≤ 2의 삼각형 넓이 2 (정적분 +2)
  2. x축 아래: −2 ≤ x ≤ 0의 삼각형 넓이 2 (정적분 −2)
  3. 정적분 = 2 + (−2) = 0
  4. 실제 넓이 = 2 + 2 = 4

답: 정적분 0, 넓이 4

정적분의 성질

∫ₐᵇ f + ∫ᵦᶜ f = ∫ₐᶜ f, ∫ᵦₐ f = −∫ₐᵇ f, ∫ₐₐ f = 0

이 성질들은 정적분을 '구간 위에서 넓이를 쌓는 것'으로 보면 자연스럽습니다. 구간을 이어 붙이면 넓이도 이어 붙고, 방향을 거꾸로 하면 부호가 바뀌며, 구간의 길이가 0이면 넓이도 0입니다. 이 성질들은 정적분의 계산을 크게 줄여 줍니다.

예제

∫₀⁵ f(x) dx = 9, ∫₂⁵ f(x) dx = 4일 때 ∫₀² f(x) dx와 ∫₅² f(x) dx를 구하세요.

  1. ∫₀⁵ = ∫₀² + ∫₂⁵이므로 ∫₀² = 9 − 4 = 5
  2. ∫₅² = −∫₂⁵
  3. = −4
  4. 원리: 위끝과 아래끝을 바꾸면 부호가 바뀜

답: 5, −4
