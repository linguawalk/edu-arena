서로 역함수

y = aˣ와 y = logₐ x는 서로 역함수입니다. 그래서 두 그래프는 직선 y = x에 대하여 대칭입니다.

왜 역함수일까요? y = aˣ를 x에 대해 풀면 x = logₐ y이고, x와 y를 바꾸면 y = logₐ x입니다. 두 함수는 서로 하는 일을 되돌리는 관계라, 한쪽 그래프를 직선 y = x에 대하여 뒤집으면 다른 쪽 그래프가 됩니다. 점근선도 y = 0과 x = 0으로 서로 바뀝니다.

문제 2

y = 3ˣ의 역함수에 x = 9를 넣은 값은?

대칭인 점

y = aˣ 위의 점 (p, q)에 대해 y = logₐ x 위에는 점 (q, p)가 있습니다.

역함수 관계를 이용하면 로그함수 위의 점을 지수 계산으로 찾을 수 있습니다. y = log₂ x 위의 점을 구하기 어려우면 y = 2ˣ 위의 점 (p, 2ᵖ)을 구한 뒤 좌표를 바꿔 (2ᵖ, p)로 쓰면 됩니다.

예제

y = 3ˣ 위의 점 (−1, 1/3), (2, 9)에 대응하는 y = log₃ x 위의 점을 구하세요.

  1. 역함수의 그래프는 좌표를 바꾼 점을 지납니다.
  2. (−1, 1/3) → (1/3, −1)
  3. (2, 9) → (9, 2)
  4. 확인: log₃ 9 = 2, log₃ (1/3) = −1

답: (1/3, −1), (9, 2)

문제 4

y = 3ˣ − 1의 역함수의 그래프의 점근선은 직선 x = ?

역함수 구하기

y = a^(x − p) + q를 x에 대해 풀어 로그로 나타낸 뒤 x와 y를 바꿉니다.

지수함수의 역함수를 구할 때는 먼저 y − q = a^(x − p)처럼 거듭제곱만 남긴 뒤, 로그 식으로 바꿔 x − p = logₐ (y − q)로 풉니다. 마지막에 x와 y를 바꾸면 역함수가 됩니다. 원래 함수의 점근선 y = q는 역함수의 점근선 x = q가 됩니다.

예제

y = 3^(x + 1) − 2의 역함수를 구하세요.

  1. y + 2 = 3^(x + 1)
  2. 로그 식으로: x + 1 = log₃ (y + 2), x = log₃ (y + 2) − 1
  3. x와 y를 바꿈: y = log₃ (x + 2) − 1
  4. 확인: 원래 점근선 y = −2가 역함수의 점근선 x = −2가 됨

답: y = log₃ (x + 2) − 1

문제 7

f(x) = 2ˣ + 1일 때 f⁻¹(9)의 값은?

크기 비교

같은 밑이면 증가·감소를 이용합니다. 밑이 1보다 크면 지수(진수)가 큰 쪽이 크고, 1보다 작으면 반대입니다.

크기 비교는 함수의 증가·감소를 쓰는 것입니다. 밑이 같으면 한 함수의 두 값이므로, 증가함수이면 입력이 큰 쪽이 크고 감소함수이면 반대입니다. 밑이 다르면 먼저 같은 밑이나 같은 지수로 맞춥니다.

여러 수 비교

지수는 같은 차수의 거듭제곱근으로, 로그는 기준값(0, 1, 2 등)과 비교해 순서를 정합니다.

로그끼리 비교할 때는 0, 1, 2 같은 기준값을 로그로 나타내 사이에 끼워 넣습니다. log₂ 3은 log₂ 2 = 1과 log₂ 4 = 2 사이, log₃ 2는 0과 1 사이이므로 log₃ 2 < 1 < log₂ 3입니다.

예제

A = log₂ 5, B = log₃ 10, C = 2를 작은 것부터 늘어놓으세요.

  1. A: 4 < 5 < 8이므로 2 < log₂ 5 < 3
  2. B: 9 < 10 < 27이므로 2 < log₃ 10 < 3
  3. A와 B 비교: log₂ 5 ≈ 2.32, log₃ 10 ≈ 2.10
  4. C < B < A

답: C < B < A
