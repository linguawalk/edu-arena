정수해를 찾는 세 가지 도구

정수해를 찾는 방정식을 디오판토스 방정식이라고 합니다. S1 단계에서는 세 가지 도구를 씁니다. 인수분해해서 곱이 정해진 수의 약수 쌍을 찾기, 크기를 제한해 경우를 유한개로 줄이기, 나머지를 보아 해가 없음을 보이기.

xy = 12의 자연수 해는 12의 약수의 개수만큼, 곧 τ(12) = 6개입니다.

대부분의 문제는 첫 번째 도구로 시작합니다. 식을 '(일차식) × (일차식) = 상수' 꼴로 만들면, 상수의 약수는 유한개라서 모든 해를 나열할 수 있습니다. 상수항을 더하거나 빼서 인수분해 꼴을 만드는 요령이 핵심입니다.

문제 1

xy = 12를 만족하는 자연수 해 (x, y)는 모두 몇 개인가요?

문제 2

xy − x − y = 3이면 (x − 1)(y − 1) = ＿＿＿입니다.

상수를 더해 인수분해하기

xy + ax + by 꼴은 (x + b)(y + a) = xy + ax + by + ab이므로, 양변에 ab를 더하면 인수분해됩니다.

xy = 2x + 3y라면 xy − 2x − 3y = 0이고, 양변에 6을 더하면 (x − 3)(y − 2) = 6입니다.

인수분해한 뒤에는 각 인수의 범위를 따져야 합니다. x, y가 자연수이면 x − 3 ≥ −2, y − 2 ≥ −1이므로, 6을 음수 두 개의 곱으로 나타내는 경우가 가능한지도 확인합니다. 이 확인을 빠뜨리면 해를 놓치거나 없는 해를 쓰게 됩니다.

예제

xy = 2x + 3y를 만족하는 자연수 해를 모두 구하세요.

  1. xy − 2x − 3y + 6 = 6이므로 (x − 3)(y − 2) = 6입니다.
  2. x ≥ 1, y ≥ 1이므로 x − 3 ≥ −2, y − 2 ≥ −1입니다. 두 인수가 모두 음수이면 곱이 6이 되려면 한쪽이 −3 이하여야 하는데, 이는 불가능합니다.
  3. 따라서 두 인수는 양수이고 (1, 6), (2, 3), (3, 2), (6, 1)입니다.
  4. 해는 (4, 8), (5, 5), (6, 4), (9, 3)의 네 개입니다.

답: (4, 8), (5, 5), (6, 4), (9, 3)

문제 4

1/x + 1/y = 1/6을 만족하는 자연수 해 (x, y)는 모두 몇 개인가요?

크기를 제한하기

1/x + 1/y + 1/z = 1처럼 변수가 여러 개이면, 일반성을 잃지 않고 x ≤ y ≤ z로 놓고 가장 작은 변수의 범위를 먼저 정합니다.

1/x가 셋 중 가장 크므로 1 ≤ 3/x, 곧 x ≤ 3입니다. x = 1이면 불가능하므로 x = 2 또는 3입니다.

x를 정하면 변수가 하나 줄어든 문제가 남고, 같은 방법으로 y의 범위를 정합니다. 이렇게 하면 무한히 많아 보이던 경우가 몇 개로 줄어듭니다. 마지막에 순서를 바꾼 해까지 셀지는 문제의 조건(x ≤ y ≤ z인지)을 보고 정합니다.

문제 6

x² − y² = 45를 만족하는 자연수 해 (x, y)는 모두 몇 개인가요?

나머지로 해가 없음을 보이기

x² − 3y² = 2를 3을 법으로 보면 x² ≡ 2 (mod 3)입니다. 그러나 제곱수를 3으로 나눈 나머지는 0 또는 1이므로 해가 없습니다.

이처럼 적당한 법에서 양변의 가능한 나머지를 비교하면, 해가 없다는 것을 몇 줄로 보일 수 있습니다.

어떤 법을 고를지는 식에 나오는 계수와 거듭제곱을 보고 정합니다. 3y²이 있으면 3을 법으로 그 항이 사라지고, 제곱이면 4나 8, 세제곱이면 7이나 9를 법으로 하면 나머지가 적게 나옵니다. 직각삼각형의 정수 변 a² + b² = c²처럼 해가 있는 경우에는 해를 직접 찾거나 인수분해로 모두 구합니다.

문제 8

x² − 3y² = 2를 만족하는 정수해 (x, y)는 모두 몇 개인가요?

정리

디오판토스 방정식은 인수분해로 '(일차식)(일차식) = 상수'를 만들어 약수 쌍을 나열하거나, 크기를 제한해 경우를 유한개로 줄이거나, 나머지로 해가 없음을 보입니다.

xy + ax + by는 ab를 더해 (x + b)(y + a)로 인수분해합니다. 인수의 부호와 범위, x² − y²에서 두 인수의 홀짝을 반드시 확인합니다.

변수가 여럿이면 x ≤ y ≤ z로 놓고 가장 작은 변수의 범위부터 정합니다. 해가 없음을 보일 때는 나머지가 적게 나오는 법을 고릅니다.
