근과 계수의 관계

수학 올림피아드 S1 예선 · 대수 · 3. 다항식 · 심화 · 약 20분 · 문제 12개

이 레슨 풀어 보기

근을 몰라도 근의 합과 곱은 안다

x² + px + q = 0의 두 근을 α, β라 하면 α + β = −p, αβ = q입니다. x² + px + q = (x − α)(x − β)를 전개해 계수를 비교하면 나옵니다.

삼차방정식 x³ + ax² + bx + c = 0의 세 근 α, β, γ에 대해서는 α + β + γ = −a, αβ + βγ + γα = b, αβγ = −c입니다.

이것을 비에트 정리라고 합니다. 근이 무리수이거나 복소수여도 합과 곱은 계수에서 바로 나오므로, 근을 직접 구하지 않고도 근에 대한 식의 값을 계산할 수 있습니다. 올림피아드에서는 근 자체보다 근들의 대칭식을 묻는 경우가 훨씬 많습니다.

문제 1

x² − 5x + 3 = 0의 두 근을 α, β라 할 때 α² + β²의 값은?

문제 2

α² + β² = (α + β)² − ＿＿＿αβ입니다.

대칭식은 합과 곱으로

α와 β를 바꾸어도 변하지 않는 식을 대칭식이라고 합니다. 대칭식은 언제나 α + β와 αβ만으로 나타낼 수 있습니다.

자주 쓰는 꼴은 α³ + β³ = (α + β)³ − 3αβ(α + β), 1/α + 1/β = (α + β)/(αβ), (α − β)² = (α + β)² − 4αβ입니다.

왜 대칭식만 될까요? α − β처럼 대칭이 아닌 식은 두 근을 바꾸면 부호가 바뀌어, 합과 곱만으로는 어느 쪽인지 정할 수 없습니다. 그래서 α − β 자체 대신 (α − β)²을 구합니다. 차수가 높은 대칭식은 αⁿ + βⁿ = (α + β)(αⁿ⁻¹ + βⁿ⁻¹) − αβ(αⁿ⁻² + βⁿ⁻²)로 한 단계씩 줄여 갑니다.

예제

x² − 3x + 1 = 0의 두 근을 α, β라 할 때 α³ + β³을 구하세요.

  1. 근과 계수의 관계에서 α + β = 3, αβ = 1입니다.
  2. α³ + β³ = (α + β)³ − 3αβ(α + β)입니다.
  3. = 27 − 3 × 1 × 3 = 27 − 9입니다.
  4. 따라서 α³ + β³ = 18입니다.

답: 18

문제 3

x² − 3x + 1 = 0의 두 근을 α, β라 할 때 1/α + 1/β의 값은?

문제 4

x² − 4x + 2 = 0의 두 근을 α, β라 할 때 (α − β)²의 값은?

삼차방정식의 세 근

x³ + ax² + bx + c = 0의 세 근 α, β, γ에 대해 α + β + γ = −a, αβ + βγ + γα = b, αβγ = −c입니다.

제곱의 합은 α² + β² + γ² = (α + β + γ)² − 2(αβ + βγ + γα)로, 역수의 합은 (αβ + βγ + γα)/(αβγ)로 구합니다.

부호를 틀리기 쉬운데, 최고차항 계수가 1일 때 '합은 부호를 바꾸고, 두 개씩 곱한 합은 그대로, 세 개의 곱은 부호를 바꾼다'로 기억하세요. 이는 (x − α)(x − β)(x − γ)를 전개했을 때 나오는 부호가 −, +, − 순서로 번갈아 나오기 때문입니다.

문제 5

문제 6

x³ − 3x² + 4x − 2 = 0의 세 근을 α, β, γ라 할 때 1/α + 1/β + 1/γ의 값은?

근을 바꾼 방정식 만들기

두 근이 α, β인 이차방정식은 x² − (α + β)x + αβ = 0입니다. 그래서 새 근의 합과 곱만 알면 새 방정식을 만들 수 있습니다.

x² − 3x + 1 = 0의 두 근 α, β에 대해 α², β²을 근으로 하는 방정식을 만들어 봅시다. 합 α² + β² = 9 − 2 = 7, 곱 α²β² = 1이므로 x² − 7x + 1 = 0입니다.

2α, 2β라면 합은 2배, 곱은 4배가 됩니다. α + 1, β + 1이라면 합은 (α + β) + 2, 곱은 αβ + (α + β) + 1입니다. 새 근을 직접 구하지 않고 대칭식 계산만으로 방정식을 얻는다는 점이 핵심입니다.

문제 7

x² − 3x + 1 = 0의 두 근 α, β에 대해 α², β²을 두 근으로 하는 방정식을 x² − kx + 1 = 0이라 할 때 k는?

정리

이차방정식 x² + px + q = 0의 두 근의 합은 −p, 곱은 q입니다. 삼차방정식은 합 −a, 두 개씩 곱한 합 b, 곱 −c입니다.

대칭식은 합과 곱으로 나타낼 수 있고, 차수가 높은 αⁿ + βⁿ은 점화식으로 한 단계씩 구합니다.

근을 바꾼 방정식은 새 근의 합과 곱을 계산해 만듭니다. 대칭이 아닌 식(α − β 등)은 제곱하는 등 대칭식으로 바꾼 뒤 다룹니다.
