사잇값 정리

f가 닫힌구간 [a, b]에서 연속이고 k가 f(a)와 f(b) 사이의 값이면, f(c) = k인 c가 a와 b 사이에 적어도 하나 있습니다.

끊어지지 않은 곡선은 두 높이 사이의 모든 높이를 지나기 때문입니다.

직관적으로는 당연해 보입니다. 산 아래(높이 f(a))에서 산 위(높이 f(b))로 걸어 올라가면, 중간 높이는 반드시 한 번 이상 지나갑니다. 다만 순간이동하듯 끊긴 길이라면 중간 높이를 건너뛸 수 있으므로 '연속'이라는 조건이 꼭 필요합니다.

문제 1

f(x) = x³ + x − 1에서 f(0) < 0 < f(1)입니다. 0과 1 사이에 f(x) = 0의 근이 있을까요? (그렇다 1, 아니다 0)

문제 2

f(0)의 값은?

근의 존재

f가 연속이고 f(a)f(b) < 0이면 f(x) = 0의 근이 a와 b 사이에 적어도 하나 있습니다.

f(a)f(b) < 0은 f(a)와 f(b)의 부호가 다르다는 뜻입니다. 한쪽은 x축 아래, 한쪽은 x축 위에 있으므로, 끊기지 않은 그래프는 그 사이에서 x축(높이 0)을 반드시 한 번 이상 지나갑니다. 이것이 방정식의 근의 존재를 보이는 가장 기본적인 방법입니다.

예제

x³ − 2x − 5 = 0이 2와 3 사이에 근을 가짐을 보이세요.

  1. f(x) = x³ − 2x − 5는 다항함수라 연속
  2. f(2) = 8 − 4 − 5 = −1 < 0
  3. f(3) = 27 − 6 − 5 = 16 > 0
  4. f(2)f(3) < 0이므로 사잇값 정리에 의해 (2, 3)에 근이 있음

답: 근이 있다

문제 3

f(x) = x² − 2는 구간 (1, 2)에서 근을 가질까요? (그렇다 1, 아니다 0)

문제 4

문제 5

x³ − 3x + 1 = 0은 구간 (0, 1)에서 근을 가질까요? (그렇다 1, 아니다 0)

근의 개수 어림

연속함수의 부호가 바뀌는 구간마다 근이 적어도 하나씩 있습니다.

부호가 바뀌는 구간이 여러 개이면 각 구간에 근이 적어도 하나씩 있으므로, 근의 개수는 그 구간 수 이상입니다. '적어도'라는 표현에 주의하세요. 한 구간 안에 근이 여러 개 있을 수도 있습니다. 정확한 개수는 증가·감소 등을 추가로 조사해야 알 수 있습니다.

예제

연속함수 f에서 f(0) = 2, f(1) = −1, f(2) = 1, f(3) = −2일 때 f(x) = 0의 실근은 적어도 몇 개일까요?

  1. (0, 1)에서 부호 변화: + → −
  2. (1, 2)에서 − → +, (2, 3)에서 + → −
  3. 부호가 바뀌는 구간 3개
  4. 적어도 3개

답: 3개

문제 6

연속함수 f에서 f(−2) = −1, f(0) = 2, f(1) = −3, f(3) = 4입니다. f(x) = 0의 실근은 적어도 몇 개일까요?

문제 7

연속함수 f에서 f(1) = 3, f(2) = 5이면 (1, 2)에 f(x) = 0의 근이 반드시 있을까요? (그렇다 1, 아니다 0)

이분법

부호가 바뀌는 구간의 가운데 값을 계산해 부호가 바뀌는 쪽 절반만 남기는 일을 반복하면 근의 근삿값을 구할 수 있습니다.

이분법은 사잇값 정리를 반복해 쓰는 방법입니다. 한 번 반복할 때마다 근이 있는 구간의 길이가 절반이 되므로, 10번 반복하면 약 1/1000로 줄어듭니다. 계산기나 컴퓨터가 방정식의 근삿값을 구할 때 실제로 쓰는 방법 중 하나입니다.

예제

x³ = 10의 근을 이분법으로 소수 첫째 자리까지 구하세요.

  1. f(x) = x³ − 10: f(2) = −2, f(3) = 17 → (2, 3)
  2. f(2.5) = 5.625 > 0 → (2, 2.5), f(2.2) = 0.648 > 0 → (2, 2.2)
  3. f(2.1) = −0.739 < 0 → (2.1, 2.2)
  4. f(2.15) ≈ −0.06 < 0 → (2.15, 2.2)이므로 약 2.2

답: 약 2.2

문제 8

문제 9

위 과정을 이어 가면 √2를 소수 첫째 자리까지 나타낸 값은?

정리

사잇값 정리는 근이 '있다'는 것만 알려 줍니다. 근이 몇 개인지나 정확한 값은 따로 구해야 합니다.

사잇값 정리는 존재 정리입니다. 근이 어디에 있는지 범위는 알려 주지만, 정확한 값이나 개수는 알려 주지 않습니다. 부호가 바뀌지 않는 구간에도 근이 두 개(또는 짝수 개) 있을 수 있다는 점도 기억하세요.
