시행과 사건

같은 조건에서 반복할 수 있고 결과가 우연에 의해 정해지는 실험이나 관찰을 시행이라고 합니다.

일어날 수 있는 모든 결과의 집합을 표본공간 S, 그 부분집합을 사건이라고 합니다.

확률을 계산하려면 먼저 '무엇이 일어날 수 있는가'를 빠짐없이 정리해야 합니다. 주사위 던지기의 표본공간은 {1, 2, 3, 4, 5, 6}이고, '짝수가 나온다'는 사건은 그 부분집합 {2, 4, 6}입니다. 이렇게 사건을 집합으로 나타내면 코스 1에서 배운 집합의 연산을 그대로 쓸 수 있습니다.

문제 1

주사위 한 개를 던질 때 표본공간의 원소는 몇 개일까요?

문제 2

동전 두 개를 던질 때 표본공간의 원소는 몇 개일까요?

합사건, 곱사건, 배반사건

A 또는 B가 일어나는 사건이 합사건 A ∪ B, 동시에 일어나는 사건이 곱사건 A ∩ B입니다.

A ∩ B = ∅이면 A와 B는 서로 배반사건입니다. 아래에서 주사위를 던져 A = {2, 4, 6}, B = {1, 2, 3}입니다.

합사건은 '또는'(합집합), 곱사건은 '그리고'(교집합)에 해당합니다. 배반사건은 동시에 일어날 수 없는 사건으로, 주사위에서 '1이 나온다'와 '6이 나온다'가 그 예입니다. 배반이면 두 사건의 경우의 수를 겹침 없이 그대로 더할 수 있습니다.

예제

주사위 한 개를 던질 때 A = {소수}, B = {3의 배수}의 합사건과 곱사건을 구하세요.

  1. A = {2, 3, 5}, B = {3, 6}
  2. 합사건 A ∪ B = {2, 3, 5, 6}
  3. 곱사건 A ∩ B = {3}
  4. A와 B는 3을 함께 가지므로 배반이 아님

답: A ∪ B = {2, 3, 5, 6}, A ∩ B = {3}

A ∩ B의 원소는 몇 개일까요?

문제 4

A ∪ B의 원소는 몇 개일까요?

문제 5

A = {1, 2}와 C = {5, 6}은 서로 배반사건일까요? (그렇다 1, 아니다 0)

여사건

사건 A가 일어나지 않는 사건을 A의 여사건 Aᶜ이라고 합니다. A와 Aᶜ은 항상 서로 배반사건입니다.

여사건은 집합의 여집합과 같습니다. 사건 A와 그 여사건 Aᶜ은 동시에 일어날 수 없고(배반), 둘 중 하나는 반드시 일어납니다(합하면 표본공간). 이 성질 덕분에 복잡한 사건 대신 여사건을 세어 전체에서 빼는 방법을 쓸 수 있습니다.

문제 6

주사위에서 A = {2, 4, 6}의 여사건의 원소는 몇 개일까요?

문제 7

A와 Aᶜ은 서로 배반사건일까요? (그렇다 1, 아니다 0)

사건의 원소 세기

두 개 이상의 결과를 다룰 때는 순서쌍으로 적어 빠짐없이 셉니다.

주사위 두 개나 동전 여러 개처럼 결과가 여러 개 섞이면 (첫째, 둘째)처럼 순서쌍으로 적습니다. 두 주사위가 똑같아 보여도 (1, 2)와 (2, 1)은 서로 다른 결과로 세야 확률이 정확해집니다. 표를 그리면 빠짐없이 셀 수 있습니다.

예제

주사위 두 개를 던질 때 두 눈의 차가 2인 사건의 원소를 모두 쓰세요.

  1. 차가 2인 순서쌍을 큰 수 기준으로: (3, 1), (4, 2), (5, 3), (6, 4)
  2. 순서를 바꾼 (1, 3), (2, 4), (3, 5), (4, 6)
  3. 모두 8개
  4. 주의: (1, 3)과 (3, 1)은 다른 결과

답: 8개

문제 9

동전 세 개를 던질 때 앞면이 정확히 2개인 사건의 원소는 몇 개일까요?

정리

표본공간의 원소가 n개이면 만들 수 있는 사건은 부분집합의 수와 같은 2ⁿ개입니다.

사건은 표본공간의 부분집합이므로 사건의 개수는 부분집합의 개수 2ⁿ과 같습니다. 여기에는 절대 일어나지 않는 공사건 ∅과 반드시 일어나는 표본공간 S 자신도 포함됩니다. 주사위 하나에서만 이미 64가지 사건을 생각할 수 있습니다.

예제

동전 세 개를 던지는 시행에서 '앞면이 적어도 2개'인 사건과 그 여사건을 구하세요.

  1. 표본공간 8개: HHH, HHT, HTH, THH, HTT, THT, TTH, TTT
  2. 앞면 2개 이상: HHH, HHT, HTH, THH (4개)
  3. 여사건(앞면 1개 이하): HTT, THT, TTH, TTT (4개)
  4. 두 사건의 원소 수 합 = 8

답: 각각 4개
