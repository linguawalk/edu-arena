일차방정식과 이차방정식

수학의 기초 · 4. 방정식 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

ax = b의 해

a ≠ 0이면 해는 x = b/a 하나입니다.

a = 0일 때 b = 0이면 해가 무수히 많고, b ≠ 0이면 해가 없습니다.

왜 a = 0일 때 경우가 나뉠까요? 0 × x는 x가 무엇이든 0이므로, 식이 0 = b가 됩니다. b도 0이면 항상 참이라 모든 x가 해이고, b가 0이 아니면 절대 참이 될 수 없어 해가 없습니다.

문제 1

x에 대한 방정식 ax = 2의 해가 없을 때 a의 값은?

문제 2

x에 대한 방정식 (a − 1)x = a² − 1의 해가 무수히 많을 때 a의 값은?

이차방정식 풀기

인수분해가 되면 AB = 0에서 A = 0 또는 B = 0으로 풉니다.

안 되면 근의 공식 x = (−b ± √(b² − 4ac)) / 2a를 씁니다.

AB = 0이면 A = 0 또는 B = 0인 이유는 0이 아닌 두 수를 곱해 0이 될 수 없기 때문입니다. 근의 공식은 ax² + bx + c = 0을 완전제곱식으로 바꿔 x에 대해 푼 결과입니다.

예제

3x² − 5x − 2 = 0을 푸세요.

  1. 인수분해: 곱해서 3 × (−2) = −6, 더해서 −5인 두 수 −6과 1을 이용합니다.
  2. 3x² − 6x + x − 2 = 3x(x − 2) + (x − 2) = (3x + 1)(x − 2)
  3. (3x + 1)(x − 2) = 0에서 x = −1/3 또는 x = 2

답: x = −1/3 또는 x = 2

절댓값이 있는 방정식

|x − a| = b(b > 0)이면 x − a = b 또는 x − a = −b입니다.

좌변과 우변에 모두 x가 있으면 절댓값 안이 0 이상인 경우와 음수인 경우로 나눠 풉니다.

절댓값은 0에서의 거리이므로 |x − a| = b는 'x와 a 사이의 거리가 b'라는 뜻입니다. 수직선에서 a의 오른쪽과 왼쪽으로 b만큼 떨어진 두 점이 해입니다. 경우를 나눈 뒤에는 각 범위에 맞는 해만 남깁니다.

예제

|x − 2| = 2x − 1을 푸세요.

  1. x ≥ 2일 때: x − 2 = 2x − 1에서 x = −1 → x ≥ 2가 아니므로 버림
  2. x < 2일 때: −(x − 2) = 2x − 1에서 −x + 2 = 2x − 1, x = 1 → x < 2이므로 해
  3. 해는 x = 1

답: x = 1

복소수 범위의 근

복소수 범위에서는 모든 이차방정식이 근을 가집니다.

x² + 4 = 0이면 x² = −4, x = ±2i

실수 범위에서 해가 없던 방정식도 i를 쓰면 해를 가집니다. 계수가 실수인 이차방정식의 허근은 항상 p ± qi처럼 켤레복소수 쌍으로 나옵니다.

문제 10

x² + x + 1 = 0의 실근은 몇 개일까요?

이차방정식의 활용

구하는 것을 x로 놓고 식을 세운 뒤, 문제의 조건(길이는 양수 등)에 맞는 근만 답으로 고릅니다.

왜 조건을 확인할까요? 방정식은 식만 보고 풀기 때문에 음수 길이, 자연수가 아닌 개수처럼 문제 상황에 맞지 않는 근도 함께 나옵니다. 마지막에 이런 근을 버려야 합니다.

예제

둘레가 26cm, 넓이가 40cm²인 직사각형의 가로를 구하세요(가로가 더 김).

  1. 가로를 x라 하면 세로는 13 − x
  2. x(13 − x) = 40 → x² − 13x + 40 = 0
  3. (x − 5)(x − 8) = 0에서 x = 5 또는 8
  4. 가로가 더 길어야 하므로 x = 8

답: 8cm
