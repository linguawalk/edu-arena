일차방정식이란

우변의 모든 항을 좌변으로 이항해 정리했을 때 (x에 대한 일차식) = 0 꼴이 되는 방정식을 일차방정식이라고 합니다.

예: 2x + 1 = 5는 2x − 4 = 0이 되므로 일차방정식입니다. x² = 4는 x²이 남으므로 아닙니다.

문제 1

x² + 2x = x² − 4를 정리하면 ＿＿＿x + 4 = 0

문제 2

다음 중 일차방정식은 몇 개일까요? ① 2x + 1 = 5 ② x² − 1 = x² + x ③ 3(x − 1) = 3x − 3 ④ x² = 4 ⑤ 1/x = 2

풀이 순서

① 괄호가 있으면 분배법칙으로 푼다. ② x항은 좌변, 상수항은 우변으로 이항한다.

③ 양변을 정리해 ax = b 꼴로 만든다. ④ 양변을 x의 계수 a로 나눈다.

예제

2(x + 3) = 5x − 3을 푸세요.

  1. 괄호를 풉니다: 2x + 6 = 5x − 3
  2. 이항합니다: 2x − 5x = −3 − 6
  3. −3x = −9
  4. x = 3

답: x = 3

계수가 소수나 분수일 때

계수가 소수이면 양변에 10, 100 등을 곱해 정수로 바꿉니다.

계수가 분수이면 양변에 분모의 최소공배수를 곱합니다. 이때 모든 항에 빠짐없이 곱해야 합니다.

예제

x/3 − 1 = x/4를 푸세요.

  1. 분모 3, 4의 최소공배수 12를 양변의 모든 항에 곱합니다.
  2. 4x − 12 = 3x
  3. 이항: 4x − 3x = 12
  4. x = 12

답: x = 12

해가 없거나 무수히 많은 경우

정리한 결과가 0 × x = b 꼴이 되는 경우가 있습니다.

b ≠ 0이면 어떤 x를 넣어도 성립하지 않아 해가 없습니다. b = 0이면 모든 x가 해이므로 해가 무수히 많습니다.

예제

2(x + 1) = 2x + 3의 해를 구하세요.

  1. 괄호를 풀면 2x + 2 = 2x + 3
  2. 이항하면 2x − 2x = 3 − 2
  3. 0 × x = 1
  4. 어떤 x를 넣어도 0 = 1이 될 수 없으므로 해가 없습니다.

답: 해가 없다
