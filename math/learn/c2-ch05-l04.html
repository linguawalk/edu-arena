무리함수의 그래프

함수와 그래프 · 5. 유리함수와 무리함수 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

y = √x

y = √x의 정의역은 x ≥ 0, 치역은 y ≥ 0입니다. 그래프는 원점에서 시작해 오른쪽 위로 천천히 올라갑니다.

y = √x는 y = x²(x ≥ 0)의 역함수입니다.

y = √x와 y = x²(x ≥ 0)이 역함수 관계라는 점을 이용하면 그래프를 쉽게 그릴 수 있습니다. 포물선의 오른쪽 절반을 직선 y = x에 대하여 대칭이동한 모양입니다.

문제 1

y = √x의 그래프 위에서 x = 9인 점의 y좌표는?

문제 2

y = √(ax)의 그래프가 점 (2, 4)를 지날 때 a의 값은?

평행이동한 무리함수

y = √(a(x − p)) + q는 y = √(ax)를 x축 방향으로 p, y축 방향으로 q만큼 평행이동한 그래프입니다.

그래프의 시작점은 (p, q)입니다.

왜 (p, q)에서 시작할까요? 근호 안 a(x − p)가 0일 때, 즉 x = p일 때 근호 값이 0이 되어 y = q입니다. 그래프는 이 점에서 출발해 한쪽 방향으로만 뻗어 나갑니다.

예제

y = √(2x − 4) + 1의 정의역, 치역, 시작점을 구하세요.

  1. √(2(x − 2)) + 1로 바꿉니다.
  2. 근호 안 ≥ 0: x ≥ 2 (정의역)
  3. 근호 값 ≥ 0이므로 y ≥ 1 (치역), 시작점 (2, 1)

답: 정의역 x ≥ 2, 치역 y ≥ 1, 시작점 (2, 1)

그래프의 방향

y = −√x는 x축 아래로, y = √(−x)는 왼쪽으로 뻗습니다. 근호 앞과 안의 부호가 방향을 정합니다.

근호 안에 −가 있으면 x가 작아지는 쪽(왼쪽)으로 정의되고, 근호 앞에 −가 있으면 y가 0 이하(아래쪽)가 됩니다. 두 부호를 보면 그래프가 시작점에서 어느 방향으로 뻗는지 알 수 있습니다.

예제

y = −√(3 − x)의 정의역과 치역을 구하세요.

  1. 근호 안 3 − x ≥ 0에서 x ≤ 3
  2. 근호 앞이 −이므로 y ≤ 0
  3. 시작점 (3, 0)에서 왼쪽 아래로 뻗습니다.

답: 정의역 x ≤ 3, 치역 y ≤ 0

역함수

y = √(x − p) + q (x ≥ p)의 역함수는 x와 y를 바꿔 제곱한 이차함수의 일부입니다.

역함수를 구할 때 치역에 주의합니다. y = √(x − 1)의 치역은 y ≥ 0이므로, 역함수 y = x² + 1은 정의역이 x ≥ 0으로 제한된 포물선의 일부입니다.

예제

y = √(x + 2) − 1의 역함수를 구하세요.

  1. 치역 y ≥ −1
  2. x에 대해 풀면 √(x + 2) = y + 1, x = (y + 1)² − 2
  3. x와 y를 바꿔 y = (x + 1)² − 2 (x ≥ −1)

답: y = (x + 1)² − 2 (x ≥ −1)

교점과 최대·최소

y = √x는 증가함수이므로 범위의 오른쪽 끝에서 최대입니다.

직선과의 교점은 제곱해 풀되 무연근을 확인합니다.

무리함수와 직선의 교점을 구할 때는 제곱해서 이차방정식을 풀고, 근호 값이 0 이상이 되는지 확인해 무연근을 버립니다. 그래프를 그려 보면 교점의 개수를 미리 알 수 있습니다.
