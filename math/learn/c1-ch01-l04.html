제곱해서 −1이 되는 수

실수 범위에서 x² = −1의 해는 없습니다.

제곱해서 −1이 되는 새로운 수를 i로 정하고 허수단위라고 합니다. i² = −1

왜 새 수가 필요할까요? 음수를 도입해 x + 3 = 1을 풀 수 있게 되었듯이, i를 도입하면 x² + 1 = 0 같은 방정식도 풀 수 있습니다. 수의 범위를 넓혀 모든 이차방정식이 해를 갖게 하는 것입니다.

복소수

a + bi(a, b는 실수) 꼴의 수를 복소수라 하고, a를 실수부분, b를 허수부분이라고 합니다.

두 복소수는 실수부분끼리, 허수부분끼리 각각 같을 때 서로 같습니다.

왜 실수부분과 허수부분을 따로 비교할까요? i는 어떤 실수로도 나타낼 수 없어 실수부분과 허수부분이 서로 섞이지 않습니다. 그래서 두 복소수가 같으려면 각 부분이 따로 같아야 합니다.

복소수의 계산

i를 문자처럼 계산하고 i²이 나오면 −1로 바꿉니다.

(a + bi)(c + di) = (ac − bd) + (ad + bc)i

복소수의 계산은 i를 x처럼 다루는 다항식 계산과 같습니다. 다만 i²이 나올 때마다 −1로 바꾼다는 점만 다릅니다. 곱셈 공식에서 bd 앞의 부호가 −인 것도 i² = −1 때문입니다.

예제

(3 − 2i)(1 + 4i)를 계산하세요.

  1. 분배법칙: 3 + 12i − 2i − 8i²
  2. i² = −1이므로 −8i² = 8
  3. 3 + 8 + (12 − 2)i = 11 + 10i

답: 11 + 10i

켤레복소수와 나눗셈

a + bi의 켤레복소수는 a − bi입니다. (a + bi)(a − bi) = a² + b²으로 실수가 됩니다.

나눗셈은 분모의 켤레복소수를 분모와 분자에 곱해 계산합니다.

왜 켤레복소수를 곱할까요? (a + bi)(a − bi) = a² − (bi)² = a² + b²으로 허수부분이 사라져 실수가 됩니다. 분모의 근호를 없애는 유리화와 같은 아이디어입니다.

예제

(4 + 3i)/(1 + 2i)를 a + bi 꼴로 나타내세요.

  1. 분모의 켤레 1 − 2i를 분모와 분자에 곱합니다.
  2. 분모: (1 + 2i)(1 − 2i) = 1 + 4 = 5
  3. 분자: (4 + 3i)(1 − 2i) = 4 − 8i + 3i − 6i² = 10 − 5i
  4. (10 − 5i)/5 = 2 − i

답: 2 − i

i의 거듭제곱과 음수의 제곱근

i, −1, −i, 1이 네 번마다 반복됩니다. i⁴ = 1

a, b가 모두 음수이면 √a √b = √(ab)가 성립하지 않습니다. 먼저 i로 바꾼 뒤 계산합니다.

왜 √a √b = √(ab)가 음수에서 안 될까요? √(−2) × √(−8) = √2 i × √8 i = 4i² = −4인데, √((−2)(−8)) = √16 = 4로 부호가 달라집니다. 그래서 음수의 제곱근은 반드시 i로 먼저 바꿉니다.

예제

i + i² + i³ + … + i¹⁰의 값을 구하세요.

  1. i, −1, −i, 1이 네 개씩 반복되고 네 개의 합은 0
  2. i¹부터 i⁸까지 두 묶음의 합은 0
  3. 남은 i⁹ + i¹⁰ = i + (−1)
  4. = −1 + i

답: −1 + i
