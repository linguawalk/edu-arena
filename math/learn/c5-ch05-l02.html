기댓값

확률변수의 기댓값(평균)은 E(X) = Σ xᵢpᵢ입니다. 여러 번 반복했을 때 평균적으로 기대되는 값입니다.

왜 확률을 곱해 더할까요? 주사위를 600번 던지면 각 눈이 약 100번씩 나오므로 눈의 합은 약 100 × (1 + 2 + … + 6)이고, 평균은 이를 600으로 나눈 (1 + 2 + … + 6)/6입니다. 이는 각 값에 확률 1/6을 곱해 더한 것과 같습니다. 기댓값은 '무한히 많이 반복했을 때의 평균'입니다.

분산과 표준편차

V(X) = E(X²) − {E(X)}². 표준편차 σ(X) = √V(X)입니다. 값이 기댓값에서 얼마나 흩어지는지를 나타냅니다.

분산은 코스 0에서 배운 '편차의 제곱의 평균'과 같은 개념입니다. 정의대로 계산하면 Σ(xᵢ − m)²pᵢ이지만, 전개해 정리하면 E(X²) − {E(X)}²로 간단해집니다. '제곱의 평균 − 평균의 제곱'이라고 기억하면 됩니다. 표준편차는 분산의 제곱근이라 원래 값과 같은 단위를 가집니다.

예제

P(X = 1) = 0.5, P(X = 2) = 0.3, P(X = 3) = 0.2일 때 E(X), V(X)를 구하세요.

  1. E(X) = 0.5 + 0.6 + 0.6 = 1.7
  2. E(X²) = 0.5 + 1.2 + 1.8 = 3.5
  3. V(X) = 3.5 − 1.7² = 3.5 − 2.89
  4. = 0.61

답: E(X) = 1.7, V(X) = 0.61

문제 5

X가 0과 1을 각각 확률 1/2로 가질 때 σ(X)는? (기약분수로)

aX + b의 평균과 분산

E(aX + b) = aE(X) + b, V(aX + b) = a²V(X), σ(aX + b) = |a|σ(X)

더하는 b는 흩어짐에 영향을 주지 않습니다.

왜 b는 분산에 영향을 주지 않을까요? 모든 값에 b를 더하면 평균도 b만큼 커져 편차(값 − 평균)는 그대로입니다. 반면 a배 하면 편차도 a배가 되어 편차의 제곱인 분산은 a²배가 됩니다. 시험 점수에 모두 10점을 더해도 성적의 흩어짐은 변하지 않는 것과 같습니다.

예제

E(X) = 5, V(X) = 4일 때 Y = 3X − 2의 평균과 표준편차를 구하세요.

  1. E(Y) = 3 × 5 − 2 = 13
  2. V(Y) = 3² × 4 = 36
  3. σ(Y) = 6
  4. 원리: 빼는 2는 흩어짐에 영향을 주지 않음

답: 평균 13, 표준편차 6

게임의 기댓값

상금의 기댓값에서 참가비를 빼면 한 번 할 때 기대되는 이익입니다.

기댓값이 음수인 게임은 한 번은 이길 수 있어도 오래 반복할수록 손해가 쌓입니다. 복권이나 도박의 기댓값이 참가비보다 작은 것이 그 예입니다. 기댓값으로 '장기적으로 유리한가'를 판단할 수 있습니다. 이익의 기댓값이 0인 게임을 공정한 게임이라고 합니다.

예제

동전 두 개를 던져 앞면이 2개이면 1,000원, 1개이면 400원, 0개이면 0원을 받는 게임의 기댓값과 공정한 참가비를 구하세요.

  1. P = 1/4, 1/2, 1/4
  2. E = 1000 × 1/4 + 400 × 1/2 + 0 = 250 + 200
  3. = 450원
  4. 참가비가 450원이면 이익의 기댓값이 0

답: 450원

문제 10

참가비가 150원이라면 이익의 기댓값은 몇 원일까요?

정리

기댓값은 '가중 평균', 분산은 '제곱의 평균 − 평균의 제곱'입니다.

기댓값과 분산을 구할 때는 확률분포표에 x, p 옆에 xp와 x²p 열을 추가해 한꺼번에 계산하면 편리합니다. 합을 구하면 E(X)와 E(X²)이 바로 나오고, 분산은 E(X²) − {E(X)}²로 구합니다. 분산이 음수로 나오면 계산이 틀린 것입니다.
