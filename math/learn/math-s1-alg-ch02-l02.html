n쌍의 코시-슈바르츠

수학 올림피아드 S1 예선 · 대수 · 2. 코시-슈바르츠 부등식 · 심화 · 약 20분 · 문제 11개

짝을 늘리기

실수 a₁, …, aₙ, b₁, …, bₙ에 대해 (a₁² + ⋯ + aₙ²)(b₁² + ⋯ + bₙ²) ≥ (a₁b₁ + ⋯ + aₙbₙ)²이 성립합니다.

등호는 a₁ : ⋯ : aₙ = b₁ : ⋯ : bₙ일 때입니다. (어느 한쪽이 모두 0인 경우도 포함합니다.)

세 변수 문제에서 특히 유용합니다. x² + y² + z² = 1일 때 x + 2y + 2z의 최댓값은 (1 + 4 + 4)(x² + y² + z²) = 9에서 3입니다. 변수가 늘어나도 계수의 제곱합만 계산하면 되므로, 두 쌍일 때와 사용법은 완전히 같습니다.

문제 1

x² + y² + z² = 1일 때 x + 2y + 2z의 최댓값은?

문제 2

앞 문제의 등호 조건은 x : y : z = 1 : 2 : ＿＿＿입니다.

이차식으로 증명하기

n쌍 버전의 가장 깔끔한 증명은 이차식을 쓰는 것입니다. 모든 실수 t에 대해 f(t) = (a₁t − b₁)² + ⋯ + (aₙt − bₙ)² ≥ 0입니다.

전개하면 f(t) = (Σaᵢ²)t² − 2(Σaᵢbᵢ)t + Σbᵢ²입니다. 모든 t에서 0 이상인 이차식은 x축 아래로 내려가지 않으므로 판별식이 0 이하입니다.

D/4 = (Σaᵢbᵢ)² − (Σaᵢ²)(Σbᵢ²) ≤ 0이 곧 코시-슈바르츠입니다. 등호는 f(t) = 0인 t가 있을 때, 곧 모든 i에서 aᵢt = bᵢ인 t가 있을 때입니다. 'f(t) ≥ 0인 이차식의 판별식'이라는 아이디어는 다른 부등식을 증명할 때도 자주 쓰입니다.

예제

모든 aᵢ가 0은 아닐 때, 판별식으로 (a₁² + a₂² + a₃²)(b₁² + b₂² + b₃²) ≥ (a₁b₁ + a₂b₂ + a₃b₃)²을 보이세요.

  1. f(t) = (a₁t − b₁)² + (a₂t − b₂)² + (a₃t − b₃)²은 모든 실수 t에서 0 이상입니다.
  2. A = Σaᵢ², B = Σaᵢbᵢ, C = Σbᵢ²이라 하면 f(t) = At² − 2Bt + C이고, A > 0입니다.
  3. 모든 t에서 0 이상이므로 판별식 D/4 = B² − AC ≤ 0입니다.
  4. 따라서 AC ≥ B²이고, 이것이 증명하려는 부등식입니다.

답: B² ≤ AC

문제 3

f(t) = (t − 1)² + (2t − 3)² = 5t² − 14t + 10의 판별식 D/4의 값은?

문제 4

판별식을 이용한 코시-슈바르츠 증명을 올바른 순서로 배열하세요.

세 변수의 최솟값

x + 2y + 3z = 14일 때 x² + y² + z²의 최솟값은 (x² + y² + z²)(1 + 4 + 9) ≥ 14² = 196에서 14입니다.

등호는 x : y : z = 1 : 2 : 3일 때입니다. x = t, y = 2t, z = 3t를 조건에 넣으면 14t = 14, t = 1이므로 (1, 2, 3)에서 최솟값이 나옵니다.

x + y + z = 6이면 (x² + y² + z²) × 3 ≥ 36에서 최솟값 12입니다. 이것은 앞 장의 제곱평균 ≥ 산술평균과 같은 결과이므로, 코시-슈바르츠가 평균의 사슬을 포함한다는 것도 알 수 있습니다.

문제 6

앞 문제에서 최솟값이 나올 때 z의 값은?

문제 7

x + y + z = 6일 때 x² + y² + z²의 최솟값은?

정리

(Σaᵢ²)(Σbᵢ²) ≥ (Σaᵢbᵢ)²이고, 등호는 두 수열이 비례할 때입니다.

증명은 f(t) = Σ(aᵢt − bᵢ)² ≥ 0의 판별식이 0 이하라는 데서 나옵니다.

변수가 세 개 이상이어도 계수의 제곱합만 계산하면 두 쌍일 때와 같은 방법으로 최댓값·최솟값을 구할 수 있습니다. 등호가 되는 점은 '계수에 비례하는 꼴 xᵢ = t × 계수'를 조건에 넣어 t를 구하는 방식으로 찾습니다.
