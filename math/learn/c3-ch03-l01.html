지수함수의 그래프

지수함수

y = aˣ (a > 0, a ≠ 1) 꼴의 함수를 지수함수라고 합니다.

모든 지수함수의 그래프는 점 (0, 1)을 지납니다.

왜 항상 (0, 1)을 지날까요? 0이 아닌 어떤 양수 a든 a⁰ = 1이기 때문입니다. 그래서 밑이 달라도 모든 지수함수의 그래프는 y축 위의 같은 점 (0, 1)에서 만납니다. 밑 a가 양수이고 1이 아니라는 조건은 로그에서와 같은 이유로 붙습니다.

문제 1

y = 2ˣ의 그래프 위에서 x = 3인 점의 y좌표는?

문제 2

y = aˣ의 그래프가 항상 지나는 점의 y좌표는?

증가와 감소

a > 1이면 x가 커질수록 y도 커지는 증가함수, 0 < a < 1이면 감소함수입니다.

치역은 y > 0이고, x축이 점근선입니다.

a > 1이면 x가 1 커질 때마다 y가 a배가 되므로 계속 커지고, 0 < a < 1이면 매번 a배로 줄어듭니다. 어느 쪽이든 aˣ는 0이 될 수 없고 음수도 될 수 없어서 그래프는 x축에 한없이 가까워지기만 합니다. 이것이 x축이 점근선인 이유입니다.

예제

y = (1/3)ˣ의 그래프가 지나는 점 세 개와 점근선, 증가·감소를 말하세요.

  1. x = −1이면 3, x = 0이면 1, x = 1이면 1/3
  2. 밑 1/3이 0과 1 사이이므로 감소함수
  3. x가 커질수록 0에 가까워지므로 점근선 y = 0
  4. 확인: 치역은 y > 0

답: (−1, 3), (0, 1), (1, 1/3), 점근선 y = 0, 감소

문제 3

문제 4

y = 3ˣ의 그래프의 점근선은 직선 y = ?

평행이동

y = a^(x − p) + q는 y = aˣ를 x축 방향으로 p, y축 방향으로 q만큼 평행이동한 그래프입니다. 점근선은 y = q입니다.

평행이동한 그래프는 대표점과 점근선 두 가지만 따라가면 그릴 수 있습니다. 원래 그래프의 점 (0, 1)은 (p, q + 1)로, 점근선 y = 0은 y = q로 옮겨집니다. 점근선이 바뀌면 치역도 y > q로 바뀝니다.

예제

y = 2^(x + 1) − 3의 그래프의 점근선과 y절편을 구하세요.

  1. y = 2ˣ를 x축 방향으로 −1, y축 방향으로 −3만큼 평행이동한 그래프
  2. 점근선은 y = −3
  3. y절편: x = 0이면 2¹ − 3 = −1
  4. 확인: 점 (0, 1)은 (−1, −2)로 옮겨집니다.

답: 점근선 y = −3, y절편 −1

문제 7

y = 3^(x + 2)의 그래프 위에서 x = −2인 점의 y좌표는?

대칭이동

y = a⁻ˣ = (1/a)ˣ는 y = aˣ를 y축에 대하여, y = −aˣ는 x축에 대하여 대칭이동한 그래프입니다.

y = a⁻ˣ는 x 대신 −x를 넣은 것이므로 y축 대칭입니다. 그리고 a⁻ˣ = (a⁻¹)ˣ = (1/a)ˣ이므로 밑이 역수인 지수함수와 같습니다. 그래서 y = 2ˣ와 y = (1/2)ˣ의 그래프는 y축에 대하여 대칭입니다.

문제 9

최대와 최소

증가함수는 범위의 오른쪽 끝에서, 감소함수는 왼쪽 끝에서 최대입니다.

지수에 이차식이 있으면 지수의 최대·최소부터 구합니다.

지수에 이차식이 있으면 두 단계로 생각합니다. 먼저 지수 부분의 최대·최소를 구하고, 밑이 1보다 크면 지수가 최소일 때 전체도 최소, 밑이 1보다 작으면 지수가 최대일 때 전체가 최소입니다. 4ˣ와 2ˣ가 함께 있으면 2ˣ = t (t > 0)로 치환합니다.

예제

−1 ≤ x ≤ 1에서 y = 4ˣ − 2^(x + 2) + 5의 최댓값과 최솟값을 구하세요.

  1. 2ˣ = t로 치환: −1 ≤ x ≤ 1이면 1/2 ≤ t ≤ 2
  2. y = t² − 4t + 5 = (t − 2)² + 1
  3. t = 2일 때 최솟값 1, t = 1/2일 때 최댓값 (−3/2)² + 1 = 13/4
  4. 주의: t의 범위를 먼저 구해야 합니다.

답: 최댓값 13/4, 최솟값 1
