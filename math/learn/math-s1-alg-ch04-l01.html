등차·등비에서 망원합까지

등차수열의 합은 (항의 수) × (첫째항 + 끝항)/2, 등비수열의 합은 a(rⁿ − 1)/(r − 1)입니다. 교과서에서 배운 이 두 공식이 출발점입니다.

올림피아드에서는 등차도 등비도 아닌 수열의 합을 많이 묻습니다. 이때 가장 강력한 방법은 각 항을 '어떤 수열의 차'로 바꾸어, 더할 때 가운데가 모두 지워지게 하는 망원합입니다.

예를 들어 1/(k(k + 1)) = 1/k − 1/(k + 1)이므로 1/(1 × 2) + ⋯ + 1/(n(n + 1)) = 1 − 1/(n + 1)입니다. 증명의 기초 2장에서 이 결과를 귀납법으로 증명했는데, 망원합은 같은 결과를 한 줄로 보여 줍니다. 핵심은 '항을 f(k) − f(k + 1) 꼴로 쪼갤 수 있는가'입니다.

문제 1

1 + 4 + 7 + ⋯ + 100의 값은?

문제 2

3 + 6 + 12 + ⋯ + 3 × 2⁹의 값은?

항을 차로 쪼개기

1/(k(k + 2))는 1/k − 1/(k + 2)의 절반입니다. 1/k − 1/(k + 2) = 2/(k(k + 2))이기 때문입니다.

그래서 1/(1 × 3) + 1/(3 × 5) + ⋯ + 1/(19 × 21) = ½{(1 − 1/3) + (1/3 − 1/5) + ⋯ + (1/19 − 1/21)} = ½(1 − 1/21)입니다.

분모의 두 인수가 d만큼 차이 나면 1/(k(k + d)) = (1/d)(1/k − 1/(k + d))입니다. 근호가 있는 1/(√k + √(k + 1))도 분모를 유리화하면 √(k + 1) − √k로 차의 꼴이 됩니다. 쪼갠 뒤에는 처음 몇 항과 마지막 몇 항만 남는다는 것을 확인하고, 남는 항을 빠뜨리지 않게 씁니다.

예제

1/(1 × 3) + 1/(2 × 4) + ⋯ + 1/(8 × 10)의 값을 구하세요.

  1. 1/(k(k + 2)) = ½(1/k − 1/(k + 2))이고, k = 1부터 8까지 더합니다.
  2. 1/k − 1/(k + 2)를 더하면 앞에서 1/1, 1/2가 남고, 뒤에서 −1/9, −1/10이 남습니다.
  3. 합은 ½(1 + 1/2 − 1/9 − 1/10) = ½(135/90 − 19/90) = ½ × 116/90입니다.
  4. = 58/90 = 29/45입니다.

답: 29/45

거듭된 곱의 합

k(k + 1)의 합도 망원합으로 구할 수 있습니다. k(k + 1)(k + 2) − (k − 1)k(k + 1) = k(k + 1){(k + 2) − (k − 1)} = 3k(k + 1)이기 때문입니다.

그래서 k(k + 1) = ⅓{k(k + 1)(k + 2) − (k − 1)k(k + 1)}이고, 더하면 Σk(k + 1) = n(n + 1)(n + 2)/3입니다.

같은 방법으로 Σk(k + 1)(k + 2) = n(n + 1)(n + 2)(n + 3)/4입니다. '연속한 정수의 곱'은 인수를 하나 늘린 곱의 차로 쪼갤 수 있다는 것이 요령입니다. 미적분의 적분과 비슷한 구조여서 '이산 적분'이라고 부르기도 합니다.

문제 6

1 × 2 × 3 + 2 × 3 × 4 + ⋯ + 10 × 11 × 12의 값은?

계차수열

aₙ₊₁ − aₙ = bₙ이 주어지면 aₙ = a₁ + b₁ + b₂ + ⋯ + bₙ₋₁입니다. 이웃한 항의 차가 정해진 수열을 계차수열이라고 합니다.

a₁ = 1, aₙ₊₁ = aₙ + 2n이면 a₁₀ = 1 + 2(1 + 2 + ⋯ + 9) = 1 + 90 = 91입니다.

이것도 망원합과 같은 생각입니다. (a₂ − a₁) + (a₃ − a₂) + ⋯ + (aₙ − aₙ₋₁)을 더하면 aₙ − a₁만 남습니다. 합의 문제와 점화식의 문제가 사실 같은 문제의 두 얼굴이라는 점을 기억하면, 다음 레슨부터 점화식을 다루기 쉬워집니다.

문제 7

a₁ = 1, aₙ₊₁ = aₙ + 2n일 때 a₁₀의 값은?

정리

등차·등비 수열은 공식으로, 그 밖의 합은 각 항을 f(k) − f(k + 1) 꼴로 쪼개는 망원합으로 구합니다.

1/(k(k + d)) = (1/d)(1/k − 1/(k + d)), 1/(√k + √(k + 1)) = √(k + 1) − √k, k(k + 1) = ⅓{k(k + 1)(k + 2) − (k − 1)k(k + 1)}가 대표적인 쪼개기입니다.

계차수열 aₙ₊₁ − aₙ = bₙ의 일반항도 같은 원리로 aₙ = a₁ + Σbₖ입니다. 쪼갠 뒤에는 남는 첫 항과 끝 항을 정확히 세고, 작은 n으로 결과를 검산하세요.
