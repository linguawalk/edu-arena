제곱의 합으로 쓰기 (SOS)

수학 올림피아드 S2 본선 · 대수 · 3. SOS와 부등식 전략 · 심화 · 약 25분 · 문제 11개

음이 아님을 보이는 가장 확실한 방법

부등식 A ≥ B를 보이는 가장 확실한 방법은 A − B를 제곱들의 합(Sum of Squares, SOS)으로 쓰는 것입니다. 제곱은 언제나 0 이상이므로 합도 0 이상입니다.

대표 예: a² + b² + c² − ab − bc − ca = ½[(a − b)² + (b − c)² + (c − a)²] ≥ 0. 오른쪽을 전개하면 ½[2a² + 2b² + 2c² − 2ab − 2bc − 2ca]로 왼쪽과 같습니다.

SOS 꼴로 쓰면 등호 조건도 바로 보입니다. 모든 제곱이 0, 곧 a = b = c일 때입니다.

문제 1

a = 1, b = 2, c = 4일 때 ½[(a − b)² + (b − c)² + (c − a)²]는?

문제 2

A − B를 제곱들의 합으로 나타내어 A ≥ B를 보이는 방법을 영어 약자로 ＿＿＿라 합니다.

세제곱의 합

a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) = (a + b + c) · ½[(a − b)² + (b − c)² + (c − a)²]입니다.

그래서 a, b, c ≥ 0이면 a³ + b³ + c³ ≥ 3abc이고, 이것이 세 수의 산술-기하 평균 부등식(x = a³ 등으로 바꾸면)입니다.

또 a + b + c = 0이면 a³ + b³ + c³ = 3abc입니다. 이 항등식은 계산 문제에서 자주 쓰입니다.

예제

a = 1, b = 2, c = 3일 때 a³ + b³ + c³ − 3abc를 두 가지 방법으로 계산하세요.

  1. 직접: 1 + 8 + 27 − 3 × 6 = 36 − 18 = 18입니다.
  2. 인수분해: a + b + c = 6입니다.
  3. a² + b² + c² − ab − bc − ca = 14 − 11 = 3입니다.
  4. 6 × 3 = 18로 같습니다.

답: 18

두 변수의 SOS

x⁴ + y⁴ ≥ x³y + xy³: 차는 x⁴ − x³y − xy³ + y⁴ = x³(x − y) − y³(x − y) = (x − y)(x³ − y³) = (x − y)²(x² + xy + y²)입니다.

x² + xy + y² = (x + y/2)² + 3y²/4 ≥ 0이므로 차는 0 이상입니다.

이처럼 (x − y)²을 인수로 뽑아낸 뒤 남은 인수가 0 이상임을 보이는 것도 SOS의 한 방법입니다.

정리

A − B를 제곱들의 합(SOS)으로 쓰면 A ≥ B와 등호 조건(모든 제곱이 0)이 함께 보입니다.

a² + b² + c² − ab − bc − ca = ½Σ(a − b)², a³ + b³ + c³ − 3abc = (a + b + c) · ½Σ(a − b)²이며, a + b + c = 0이면 a³ + b³ + c³ = 3abc입니다.

두 변수 부등식은 (x − y)²을 인수로 뽑아낸 뒤 남은 인수가 0 이상임을 보입니다.
