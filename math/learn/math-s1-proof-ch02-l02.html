나누어떨어짐을 귀납법으로

'모든 n에 대해 f(n)은 m의 배수이다'를 귀납법으로 보일 때는 f(k + 1)을 'f(k)의 배수 + m의 배수' 꼴로 바꿉니다.

예를 들어 4ᵏ⁺¹ − 1 = 4 × 4ᵏ − 1 = 4(4ᵏ − 1) + 3입니다. 4ᵏ − 1이 3의 배수라는 귀납 가정과 남은 3을 합치면 4ᵏ⁺¹ − 1도 3의 배수입니다.

왜 이렇게 바꿀까요? 귀납 가정은 f(k)에 대한 정보만 줍니다. 그래서 f(k + 1)을 f(k)가 보이는 꼴로 만들어야 그 정보를 쓸 수 있습니다. 거듭제곱이 있으면 밑을 하나 떼어 내고, 다항식이면 f(k + 1) − f(k)를 계산하는 것이 보통의 방법입니다.

부등식을 귀납법으로

부등식의 귀납 단계는 '귀납 가정으로 한 번 줄이거나 늘린 뒤, 남은 부분이 원하는 쪽인지 확인한다'는 두 단계로 이루어집니다.

예를 들어 2ᵏ⁺¹ = 2 × 2ᵏ에서 귀납 가정 2ᵏ ≥ k + 1을 쓰면 2ᵏ⁺¹ ≥ 2(k + 1)이 됩니다.

여기서 끝이 아닙니다. 보여야 할 것은 2ᵏ⁺¹ ≥ (k + 1) + 1 = k + 2이므로, 2(k + 1) ≥ k + 2를 따로 확인해야 합니다. 2k + 2 ≥ k + 2는 k ≥ 0이면 참입니다. 이 두 번째 확인을 빠뜨리는 것이 부등식 귀납법에서 가장 흔한 실수입니다.

예제

모든 자연수 n에 대해 2ⁿ ≥ n + 1임을 증명하세요.

  1. 기저: n = 1이면 2 ≥ 2로 성립합니다.
  2. 귀납 가정: 2ᵏ ≥ k + 1이라고 가정합니다.
  3. 2ᵏ⁺¹ = 2 × 2ᵏ ≥ 2(k + 1) = 2k + 2 ≥ k + 2입니다. (k ≥ 0)
  4. 따라서 n = k + 1일 때도 성립하고, 귀납법에 의해 모든 n에서 성립합니다.

답: 2ⁿ ≥ n + 1

문제 6

f(n) = n³ + 2n일 때 f(3) − f(2)의 값은?

시작점이 1이 아닐 때

어떤 명제는 n이 충분히 클 때부터만 성립합니다. 2ⁿ > n²은 n = 2, 3, 4에서 거짓이지만 n ≥ 5이면 항상 참입니다.

이때는 기저를 n = 5로 잡고, 귀납 단계에서 k ≥ 5라는 조건을 씁니다.

2ᵏ⁺¹ = 2 × 2ᵏ > 2k²이고, 2k² ≥ (k + 1)²이 성립하면 끝납니다. 2k² − (k + 1)² = k² − 2k − 1 = (k − 1)² − 2이고, k ≥ 3이면 (k − 1)² ≥ 4라서 양수입니다. 귀납 단계가 k ≥ 3에서 성립하더라도 기저는 실제로 처음 성립하는 n = 5여야 합니다. 시작점을 어디로 잡았는지 답안에 분명히 쓰세요.

문제 7

n ≥ N인 모든 자연수 n에 대해 2ⁿ > n²이 성립하는 가장 작은 자연수 N은?

문제 8

n ≥ N인 모든 자연수 n에 대해 n! > 2ⁿ이 성립하는 가장 작은 자연수 N은?

정리

나누어떨어짐은 f(k + 1)을 'f(k)의 배수 + m의 배수'로 바꾸어 귀납 가정을 씁니다. 거듭제곱은 밑을 하나 떼어 내고, 다항식은 f(k + 1) − f(k)를 계산합니다.

부등식은 귀납 가정으로 한 번 바꾼 뒤, 남은 부등식을 따로 확인해야 합니다.

명제가 n = N부터 성립하면 기저를 n = N으로 잡고, 귀납 단계에서 쓰는 조건(k ≥ N)을 밝힙니다. 작은 n 몇 개를 먼저 계산해 보면 시작점과 배수를 추측할 수 있지만, 그것만으로는 증명이 아니라는 점은 1장에서 본 그대로입니다.
