단조 부분수열

서로 다른 수 n² + 1개로 이루어진 수열에는 길이 n + 1인 증가 부분수열이나 감소 부분수열이 반드시 있습니다(에르되시-세케레시 정리).

예: 서로 다른 수 10개(n = 3)이면 길이 4인 증가 또는 감소 부분수열이 있습니다. 9개로는 보장되지 않습니다. (3, 2, 1, 6, 5, 4, 9, 8, 7)은 길이 4인 단조 부분수열이 없습니다.

증명은 각 항마다 '그 항에서 시작하는 가장 긴 증가 부분수열의 길이'를 붙이는 극단 원리와 비둘기집 원리를 함께 씁니다.

문제 1

서로 다른 수로 이루어진 수열에서 길이 5인 증가 또는 감소 부분수열을 보장하려면 수가 적어도 몇 개 있어야 하나요?

문제 2

수열에서 몇 개의 항을 순서를 유지한 채 골라 만든 수열을 ＿＿＿이라 합니다.

라벨 붙이기

각 항 aᵢ에 Lᵢ = (aᵢ에서 시작하는 가장 긴 증가 부분수열의 길이)를 붙입니다. 어떤 Lᵢ가 n + 1 이상이면 끝입니다.

모든 Lᵢ가 1부터 n 사이라면, n² + 1개의 항에 n가지 라벨이 붙으므로 비둘기집 원리로 같은 라벨을 가진 항이 n + 1개 이상 있습니다.

같은 라벨 L을 가진 두 항 aᵢ, aⱼ (i < j)에서 aᵢ < aⱼ이면 aᵢ 앞에 붙여 Lᵢ ≥ L + 1이 되어 모순이므로 aᵢ > aⱼ입니다. 그래서 같은 라벨의 항들은 감소 부분수열을 이룹니다.

예제

수열 (5, 1, 4, 2, 3)의 각 항에 '그 항에서 시작하는 가장 긴 증가 부분수열의 길이'를 붙이세요.

  1. 5에서 시작: 5보다 큰 뒤의 항이 없으므로 1입니다.
  2. 1에서 시작: 1, 2, 3으로 3입니다.
  3. 4에서 시작: 1, 2, 3 모두 4보다 작아 1입니다. 2에서 시작: 2, 3으로 2입니다.
  4. 3에서 시작: 1입니다. 라벨은 (1, 3, 1, 2, 1)입니다.

답: (1, 3, 1, 2, 1)

문제 3

수열 (5, 1, 4, 2, 3)에서 라벨이 1인 항(5, 4, 3)이 이루는 감소 부분수열의 길이는?

문제 4

수열 (5, 1, 4, 2, 3)에서 가장 긴 증가 부분수열의 길이는?

최적성: n²개로는 부족하다

n²개로는 길이 n + 1인 단조 부분수열을 보장할 수 없습니다. n개씩 n묶음으로 나누어, 묶음 안은 감소, 묶음끼리는 증가하게 늘어놓으면 됩니다.

n = 3: (3, 2, 1, 6, 5, 4, 9, 8, 7). 증가 부분수열은 각 묶음에서 하나씩만 고를 수 있어 길이 3 이하, 감소 부분수열은 한 묶음 안에서만 가능해 길이 3 이하입니다.

그래서 n² + 1은 가장 작은 보장 개수입니다.

문제 5

수열 (3, 2, 1, 6, 5, 4, 9, 8, 7)에서 가장 긴 감소 부분수열의 길이는?

문제 6

서로 다른 수 26개로 이루어진 수열에서 반드시 존재하는 단조 부분수열의 길이는 적어도 얼마인가요?

문제 7

서로 다른 수 16개로 이루어진 수열에서 길이 5인 단조 부분수열이 없을 수 있나요? 있을 수 있으면 1, 없으면 0을 쓰세요.

정리

에르되시-세케레시 정리: 서로 다른 수 n² + 1개에는 길이 n + 1인 증가 또는 감소 부분수열이 있고, n²개로는 보장되지 않습니다.

증명: 각 항에 그 항에서 시작하는 가장 긴 증가 부분수열의 길이(극단적인 값)를 라벨로 붙이고, 비둘기집 원리로 같은 라벨의 항 n + 1개를 찾으면 그것들이 감소 부분수열을 이룹니다.

극단 원리와 비둘기집 원리를 함께 쓰는 대표적인 예입니다.
