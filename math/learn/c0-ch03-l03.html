연립일차방정식

기초 수학 · 3. 방정식과 연립방정식 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

모르는 것이 두 개

사과와 배의 값을 모두 모를 때, 조건이 하나만 있으면 답이 여러 개 나올 수 있습니다.

미지수가 두 개면 조건도 두 개가 필요합니다. 이 두 조건을 한 쌍으로 묶은 것이 연립방정식입니다.

문제 1

사과 한 개 x원, 배 한 개 y원일 때 사과 2개와 배 1개가 3,000원이면 2x + y = ＿＿＿

문제 2

x + y = 5를 만족하는 자연수 순서쌍 (x, y)는 몇 개일까요?

연립방정식의 해

미지수가 2개이고 차수가 1인 방정식을 미지수가 2개인 일차방정식이라고 합니다.

두 방정식을 한 쌍으로 묶은 것을 연립방정식이라 하고, 두 방정식을 동시에 만족하는 x, y의 값을 연립방정식의 해라고 합니다.

문제 3

(2, 1)이 방정식 x + 3y = a의 해일 때 a의 값은?

문제 4

연립방정식 x + y = 5, x − y = 1을 동시에 만족하는 자연수 해에서 x의 값은?

가감법

두 방정식을 변끼리 더하거나 빼서 한 미지수를 없애는 방법을 가감법이라고 합니다.

없애려는 미지수의 계수의 절댓값이 같지 않으면 먼저 한 식이나 두 식에 적당한 수를 곱해 맞춥니다.

예제

x + 2y = 8, x − y = 2를 가감법으로 푸세요.

  1. x의 계수가 같으므로 두 식을 뺍니다: (x + 2y) − (x − y) = 8 − 2
  2. 3y = 6, y = 2
  3. x − y = 2에 대입: x − 2 = 2
  4. x = 4

답: x = 4, y = 2

대입법

한 방정식을 한 미지수에 대해 푼 뒤 다른 방정식에 대입해 미지수를 없애는 방법을 대입법이라고 합니다.

y = (x에 대한 식) 꼴의 방정식이 있으면 대입법이 편리합니다.

예제

y = x + 3, 2x + y = 12를 대입법으로 푸세요.

  1. 두 번째 식의 y 자리에 x + 3을 넣습니다: 2x + (x + 3) = 12
  2. 3x + 3 = 12, 3x = 9
  3. x = 3
  4. y = 3 + 3 = 6

답: x = 3, y = 6

문제 11

y = 2x − 1, 3x + y = 9의 해는 x = ＿＿＿, y = ＿＿＿

해가 없거나 무수히 많은 연립방정식

x + y = 3과 2x + 2y = 6처럼 한 식에 수를 곱해 다른 식이 되면 해가 무수히 많습니다.

x + 2y = 4와 2x + 4y = 5처럼 좌변은 같아지는데 우변이 다르면 해가 없습니다.

예제

2x + 3y = 13, 3x − 2y = 0을 푸세요.

  1. x의 계수를 맞추려면 첫 식에 3, 둘째 식에 2를 곱합니다.
  2. 6x + 9y = 39, 6x − 4y = 0
  3. 빼면 13y = 39, y = 3
  4. 3x − 6 = 0에서 x = 2

답: x = 2, y = 3
