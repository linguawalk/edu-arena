끝없이 작아질 수는 없다

자연수는 끝없이 작아질 수 없습니다(자연수의 정렬성: 공집합이 아닌 자연수의 집합에는 가장 작은 원소가 있다). 그래서 어떤 해가 있으면 더 작은 해가 또 있다는 것을 보이면 모순이 생깁니다. 이것을 무한 강하법이라 합니다.

예: x² + y² = 3z²의 양의 정수해는 없다. 제곱수를 3으로 나눈 나머지는 0 또는 1이므로 x² + y² ≡ 0 (mod 3)이 되려면 x, y가 모두 3의 배수입니다. x = 3a, y = 3b로 쓰면 3(a² + b²) = z²이라 z도 3의 배수, z = 3c이고 a² + b² = 3c²입니다.

(a, b, c)는 (x, y, z)보다 작은 해이므로 해가 있다면 끝없이 작은 해가 생겨 모순입니다.

문제 1

제곱수를 3으로 나눈 나머지로 가능한 값은 모두 몇 가지인가요?

문제 2

공집합이 아닌 자연수의 집합에는 가장 작은 원소가 있다는 성질을 자연수의 ＿＿＿이라 합니다.

최소 반례

무한 강하법은 '가장 작은 반례'로도 쓸 수 있습니다. 명제가 거짓인 자연수가 있다면 정렬성에 의해 가장 작은 반례 m이 있습니다. m보다 더 작은 반례를 찾으면 모순입니다.

x² + y² = 3z²에서 z가 가장 작은 해를 생각하면, 위의 과정으로 c = z/3 < z인 해가 나와 '가장 작다'에 모순입니다.

이 방법은 강한 귀납법과 같은 힘을 가집니다. 강한 귀납법은 '반례가 없다'를 아래에서 쌓아 올리고, 최소 반례는 위에서 내려오며 모순을 찾습니다.

예제

x² + y² ≡ 0 (mod 3)이면 x, y가 모두 3의 배수임을 보이세요.

  1. 제곱수를 3으로 나눈 나머지는 0 또는 1입니다.
  2. x² + y²의 나머지는 0 + 0, 0 + 1, 1 + 0, 1 + 1 = 0, 1, 1, 2 가운데 하나입니다.
  3. 나머지가 0이 되는 것은 x² ≡ y² ≡ 0일 때뿐입니다.
  4. 제곱이 3의 배수이면 그 수도 3의 배수이므로 x, y는 모두 3의 배수입니다.

답: x, y 모두 3의 배수

문제 3

x, y를 각각 0, 1, 2 가운데서 고를 때(9가지) x² + y²이 3의 배수가 되는 경우는 몇 가지인가요?

문제 4

제곱수를 4로 나눈 나머지로 가능한 값은 모두 몇 가지인가요?

두 제곱수의 합

제곱수를 4로 나눈 나머지는 0 또는 1이므로 두 제곱수의 합의 나머지는 0, 1, 2뿐입니다. 그래서 4k + 3 꼴의 수(3, 7, 11, 15, …)는 두 제곱수의 합이 될 수 없습니다.

이런 '나머지 논법'은 무한 강하법의 첫걸음으로 자주 쓰입니다. 해가 있다면 어떤 수의 배수여야 함을 보이고, 그 수로 나누어 더 작은 해를 만듭니다.

x² = 2y²도 같은 방식입니다. x가 짝수여야 하고, x = 2a로 쓰면 y² = 2a²이라 더 작은 해 (y, a)가 생깁니다. 이것은 √2가 무리수라는 또 다른 증명입니다.

문제 5

1부터 30까지의 자연수 가운데 4k + 3 꼴(두 제곱수의 합이 될 수 없음이 바로 보이는 수)은 몇 개인가요?

문제 6

x² = 2y²의 무한 강하에서 해 (x, y) = (2a, y)로부터 얻는 더 작은 해는 (y, a)입니다. 이때 y² = 2 × 무엇인가요? ① a² ② 2a²

문제 7

x² + y² = 3z²에 양의 정수해가 있다면 x, y, z는 모두 어떤 수의 배수여야 하나요?

정리

자연수의 정렬성 때문에 자연수 해가 끝없이 작아질 수 없습니다. 해가 있으면 더 작은 해가 있음을 보이는 것이 무한 강하법입니다.

최소 반례 논법은 '가장 작은 반례'를 가정하고 더 작은 반례를 찾아 모순을 만듭니다.

첫걸음으로 나머지 논법(제곱수 mod 3은 0, 1, mod 4는 0, 1)을 써서 해가 어떤 수의 배수여야 함을 보이고, 그 수로 나누어 더 작은 해를 만듭니다.

문제 8

제곱수를 8로 나눈 나머지로 가능한 값은 모두 몇 가지인가요?

문제 9

1부터 50까지의 자연수 가운데 세 제곱수의 합이 될 수 없음이 mod 8로 바로 보이는 8k + 7 꼴의 수는 몇 개인가요?

문제 10

x² + y² = 3z²이 양의 정수해를 갖지 않음을 무한 강하법(또는 최소 반례)으로 증명하세요.

문제 11

4k + 3 꼴의 자연수는 두 제곱수의 합이 될 수 없음을 증명하세요.
