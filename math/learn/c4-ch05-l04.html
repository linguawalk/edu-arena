등비급수

미적분 · 5. 수열의 극한과 급수 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

등비급수의 합

첫째항이 a(≠ 0), 공비가 r인 등비급수는 |r| < 1일 때 수렴하고 합은 a/(1 − r)입니다. |r| ≥ 1이면 발산합니다.

왜 a/(1 − r)일까요? 등비수열의 합 Sₙ = a(1 − rⁿ)/(1 − r)에서 |r| < 1이면 rⁿ → 0이므로 Sₙ → a/(1 − r)입니다. |r| ≥ 1이면 rⁿ이 0으로 가지 않아 부분합이 수렴하지 않습니다. 앞 레슨의 등비수열의 극한이 그대로 쓰입니다.

문제 1

1 + 1/2 + 1/4 + …의 합은?

문제 2

1/3 + 1/9 + 1/27 + …의 합은? (기약분수로)

수렴 조건

공비의 절댓값이 1보다 작아야 합니다. 공비에 문자가 있으면 −1 < r < 1을 풉니다.

공비에 문자가 있으면 −1 < r < 1을 풉니다. 등비수열의 수렴 조건(−1 < r ≤ 1)과 달리 r = 1은 제외됩니다. r = 1이면 a + a + a + …로 발산하기 때문입니다. 단, 첫째항이 0이면 모든 항이 0이라 공비와 관계없이 수렴합니다.

예제

Σ(n=1~∞) ((x + 1)/2)ⁿ이 수렴하는 x의 범위를 구하세요.

  1. 공비 r = (x + 1)/2
  2. 수렴 조건: −1 < (x + 1)/2 < 1
  3. −2 < x + 1 < 2
  4. −3 < x < 1

답: −3 < x < 1

문제 4

Σ(n=1~∞) (x − 2)ⁿ이 수렴하는 정수 x는 몇 개일까요?

순환소수

0.777… = 0.7 + 0.07 + 0.007 + …은 첫째항 7/10, 공비 1/10인 등비급수입니다.

순환소수는 등비급수의 대표적인 예입니다. 0.777… = 7/10 + 7/100 + …은 첫째항 7/10, 공비 1/10이므로 합은 (7/10)/(1 − 1/10) = 7/9입니다. 코스 0에서 x로 놓고 10x − x로 풀었던 방법과 같은 결과가 나옵니다.

예제

0.2363636…(36이 반복)을 기약분수로 나타내세요.

  1. 0.2 + 0.036 + 0.00036 + …
  2. 뒤의 부분은 첫째항 0.036, 공비 0.01인 등비급수: 0.036/0.99 = 36/990 = 2/55
  3. 0.2 + 2/55 = 11/55 + 2/55
  4. = 13/55

답: 13/55

도형과 운동의 반복

넓이나 길이가 일정한 비율로 줄어들며 끝없이 반복되면 그 합을 등비급수로 구합니다.

도형이 일정한 비율로 줄어들며 반복되면, 넓이나 길이도 일정한 비율로 줄어드는 등비수열이 됩니다. 이때 넓이의 비는 길이의 비의 제곱이라는 점에 주의합니다. 튀어 오르는 공은 처음 떨어지는 거리만 한 번이고, 그 뒤로는 올라갔다 내려오므로 2배로 셉니다.

예제

한 변이 2인 정삼각형의 각 변의 중점을 이어 작은 정삼각형을 만드는 일을 끝없이 반복할 때 모든 정삼각형의 넓이의 합은?

  1. 처음 넓이 √3 (한 변 2)
  2. 변이 1/2배가 되므로 넓이는 1/4배
  3. √3 + √3/4 + … = √3/(1 − 1/4)
  4. = 4√3/3

답: 4√3/3

문제 8

10m 높이에서 떨어뜨린 공이 매번 떨어진 높이의 1/2만큼 튀어 오릅니다. 공이 움직인 전체 거리는 몇 m일까요?

정리

첫째항과 공비를 정확히 찾는 것이 핵심입니다. 첫째항이 n = 1일 때의 항인지 확인합니다.

등비급수의 합을 구할 때 가장 흔한 실수는 첫째항을 잘못 잡는 것입니다. Σ(n=1~∞) (1/2)ⁿ의 첫째항은 n = 1일 때인 1/2이지, 1이 아닙니다. 식에 n = 1을 직접 넣어 첫째항을 확인하는 습관을 들이세요.
