매개변수와 음함수의 미분

미적분 · 6. 여러 가지 함수의 미분 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

매개변수로 나타낸 함수

x = f(t), y = g(t)처럼 둘 다 t로 나타내면 dy/dx = (dy/dt)/(dx/dt)입니다.

왜 (dy/dt)/(dx/dt)일까요? t가 조금 변할 때 x는 dx/dt배, y는 dy/dt배로 변합니다. 그러면 x가 변하는 양에 대한 y가 변하는 양의 비율은 두 배율의 비가 됩니다. 합성함수의 미분법 dy/dt = (dy/dx)(dx/dt)를 dy/dx에 대해 푼 것입니다.

예제

x = t² + 1, y = 2t³일 때 t = 2에서 dy/dx를 구하세요.

  1. dx/dt = 2t, dy/dt = 6t²
  2. dy/dx = 6t²/(2t) = 3t
  3. t = 2이면 6
  4. 확인: 점 (5, 16)에서의 기울기

답: 6

원의 매개변수 표현

x = cos t, y = sin t는 단위원입니다. dy/dx = cos t / (−sin t)

매개변수를 쓰면 원처럼 y를 x의 함수 하나로 나타낼 수 없는 곡선도 다룰 수 있습니다. t를 시간으로 보면 점 (cos t, sin t)가 원 위를 도는 운동이 됩니다. dy/dx = −cos t / sin t = −x/y는 원 위의 점에서 반지름에 수직인 접선의 기울기와 같습니다.

음함수의 미분

x² + y² = 25처럼 y가 식 속에 섞여 있으면 y를 x의 함수로 보고 양변을 x에 대해 미분합니다.

y²을 미분하면 2y × dy/dx입니다.

왜 y²을 미분하면 2y × dy/dx일까요? y가 x의 함수이므로 y²은 □²에 y를 넣은 합성함수입니다. 겉 □²을 미분하면 2y, 속 y를 x로 미분하면 dy/dx이므로 둘을 곱합니다. 양변을 미분한 뒤 dy/dx에 대해 풀면 됩니다.

예제

x² − xy + y² = 3 위의 점 (1, 2)에서 dy/dx를 구하세요.

  1. 양변을 x로 미분: 2x − (y + x × dy/dx) + 2y × dy/dx = 0
  2. (1, 2) 대입: 2 − 2 − dy/dx + 4 dy/dx = 0
  3. 3 dy/dx = 0
  4. dy/dx = 0 (그 점에서 접선이 수평)

답: 0

음함수와 접선

구한 dy/dx를 기울기로 하여 접선의 방정식을 세웁니다.

음함수의 dy/dx는 보통 x와 y가 함께 들어간 식으로 나옵니다. 곡선 위의 점 (a, b)를 넣으면 그 점에서의 기울기가 되고, 이를 이용해 y − b = (기울기)(x − a)로 접선을 구합니다. 분모가 0이 되는 점에서는 접선이 세로선일 수 있습니다.

역함수의 미분

y = f(x)의 역함수 g에 대해 g′(b) = 1/f′(a) (b = f(a))입니다.

역함수의 그래프는 원래 그래프를 직선 y = x에 대하여 대칭이동한 것이므로, 대응하는 점에서 접선의 기울기도 x와 y가 바뀌어 역수가 됩니다. g(f(x)) = x의 양변을 미분하면 g′(f(x)) × f′(x) = 1에서 공식이 나옵니다.

예제

f(x) = x³ + 3x − 1의 역함수를 g라 할 때 g′(3)을 구하세요.

  1. f(a) = 3인 a를 찾습니다: a³ + 3a − 1 = 3에서 a = 1
  2. f′(x) = 3x² + 3이므로 f′(1) = 6
  3. g′(3) = 1/f′(1)
  4. = 1/6

답: 1/6
