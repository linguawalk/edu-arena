최대공약수와 최소공배수

두 자연수 a, b에 대해 gcd(a, b) × lcm(a, b) = ab입니다. 소인수분해로 보면, gcd는 각 소수의 지수 중 작은 쪽을, lcm은 큰 쪽을 가집니다.

작은 쪽과 큰 쪽을 더하면 원래 두 지수의 합이 되므로 곱이 ab가 됩니다. 12 = 2² × 3, 18 = 2 × 3²이면 gcd = 2 × 3 = 6, lcm = 2² × 3² = 36이고 6 × 36 = 12 × 18입니다.

이 관계를 쓰면 gcd와 lcm 중 하나와 두 수 중 하나만 알아도 나머지를 구할 수 있습니다. 또 gcd(a, b) = g이면 a = gm, b = gn (m, n은 서로소)로 쓸 수 있어서, lcm = gmn이 됩니다. 이 표현은 조건을 만족하는 두 수를 찾는 문제에서 기본입니다.

약수의 개수와 약수의 합

n = p^a × q^b × ⋯로 소인수분해되면 약수의 개수는 τ(n) = (a + 1)(b + 1)⋯입니다. 약수는 각 소수의 지수를 0부터 최대까지 하나씩 고른 것이기 때문입니다.

약수의 합은 σ(n) = (1 + p + ⋯ + p^a)(1 + q + ⋯ + q^b)⋯입니다. 이 곱을 전개하면 모든 약수가 한 번씩 나옵니다.

예를 들어 12 = 2² × 3이면 τ(12) = 3 × 2 = 6이고, σ(12) = (1 + 2 + 4)(1 + 3) = 28입니다. 실제로 12의 약수 1, 2, 3, 4, 6, 12를 더하면 28입니다. 소인수분해 하나로 약수에 관한 대부분의 질문에 답할 수 있습니다.

예제

360의 약수의 개수를 구하세요.

  1. 360 = 2³ × 3² × 5입니다.
  2. 2의 지수는 0~3의 4가지, 3의 지수는 0~2의 3가지, 5의 지수는 0~1의 2가지입니다.
  3. 약수의 개수는 4 × 3 × 2입니다.
  4. 따라서 τ(360) = 24입니다.

답: 24

약수의 개수가 홀수인 수

n의 약수 d는 n/d와 짝을 이룹니다. d ≠ n/d이면 짝이 둘씩 묶이므로 약수의 개수는 짝수가 됩니다.

d = n/d, 곧 d² = n인 약수가 있을 때만 짝이 하나 남습니다. 그래서 약수의 개수가 홀수인 수는 정확히 제곱수입니다.

소인수분해로 보아도 같습니다. (a + 1)(b + 1)⋯이 홀수이려면 모든 지수 a, b, …가 짝수여야 하고, 그것이 곧 제곱수입니다. 같은 결과를 두 가지 방법으로 증명할 수 있다는 점을 기억해 두세요. 짝짓기는 세기 문제에서 자주 쓰는 강력한 아이디어입니다.

약수의 곱

n의 약수를 모두 곱하면 n^(τ(n)/2)입니다. 약수를 d와 n/d로 짝지으면 각 짝의 곱이 n이고, 짝이 τ(n)/2개이기 때문입니다.

12의 약수는 (1, 12), (2, 6), (3, 4)의 세 짝이므로 곱은 12³ = 1728입니다.

제곱수일 때는 짝이 남지 않는 √n이 하나 있지만, 공식은 그대로 맞습니다. 예를 들어 9의 약수 1, 3, 9의 곱은 27 = 9^(3/2)입니다. 이처럼 짝짓기는 개수뿐 아니라 곱을 구할 때도 씁니다.

문제 8

12의 모든 약수의 곱은?

정리

gcd(a, b) × lcm(a, b) = ab이고, gcd(a, b) = g이면 a = gm, b = gn (m, n 서로소), lcm = gmn입니다.

n = p^a q^b ⋯이면 약수의 개수는 (a + 1)(b + 1)⋯, 약수의 합은 (1 + ⋯ + p^a)(1 + ⋯ + q^b)⋯, 약수의 곱은 n^(τ(n)/2)입니다.

약수는 d와 n/d로 짝지을 수 있고, 약수의 개수가 홀수인 수는 제곱수뿐입니다. 약수 문제는 소인수분해부터 하는 습관을 들이세요.
