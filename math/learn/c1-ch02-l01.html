집합

대상을 분명히 정할 수 있는 모임을 집합, 집합을 이루는 대상을 원소라고 합니다.

a가 집합 A의 원소이면 a ∈ A, 원소가 아니면 a ∉ A로 씁니다.

왜 '분명히 정할 수 있는'이 중요할까요? '키가 큰 학생'은 사람마다 기준이 달라 어떤 학생이 들어가는지 정할 수 없습니다. 누가 봐도 속하는지 아닌지가 똑같이 판단되어야 집합입니다.

문제 2

집합을 나타내는 방법

원소나열법: {1, 2, 3, 6}처럼 원소를 모두 나열합니다.

조건제시법: {x | x는 6의 약수}처럼 원소의 조건을 씁니다. 벤 다이어그램으로 그림으로도 나타냅니다.

원소가 적으면 원소나열법이 편하고, 원소가 많거나 끝없이 많으면 조건제시법이 편합니다. 같은 집합을 두 방법으로 바꿔 쓸 수 있어야 문제의 조건을 정확히 읽을 수 있습니다.

예제

{x | x는 15의 약수}를 원소나열법으로 나타내고 n(A)를 구하세요.

  1. 15를 나누어떨어지게 하는 자연수를 찾습니다.
  2. 1, 3, 5, 15
  3. {1, 3, 5, 15}이므로 원소는 4개

답: {1, 3, 5, 15}, n = 4

원소의 개수

유한집합 A의 원소의 개수를 n(A)로 씁니다.

원소가 하나도 없는 집합을 공집합이라 하고 ∅로 씁니다. n(∅) = 0

∅과 {∅}는 다릅니다. ∅은 빈 상자이고, {∅}는 빈 상자 하나가 들어 있는 상자입니다. 그래서 n(∅) = 0이지만 n({∅}) = 1입니다.

예제

A = {x | x² − 5x + 6 = 0}일 때 n(A)를 구하세요.

  1. x² − 5x + 6 = (x − 2)(x − 3) = 0
  2. x = 2 또는 x = 3
  3. A = {2, 3}이므로 n(A) = 2

답: 2

집합의 약속

같은 원소는 한 번만 씁니다. 원소를 쓰는 순서는 상관없습니다.

원소가 끝없이 많은 집합은 무한집합, 셀 수 있게 정해진 집합은 유한집합입니다.

왜 같은 원소를 한 번만 쓸까요? 집합은 '무엇이 들어 있는가'만 따지고 몇 번 들어 있는지는 따지지 않기 때문입니다. {1, 1, 2}와 {1, 2}는 같은 집합입니다.

예제

A = {0, 1, 2}일 때 {xy | x ∈ A, y ∈ A}의 원소를 모두 구하세요.

  1. 가능한 곱을 모두 계산합니다: 0×0, 0×1, …, 2×2
  2. 나오는 값: 0, 1, 2, 4 (0은 여러 번, 2도 두 번 나옴)
  3. 같은 원소는 한 번만 쓰므로 {0, 1, 2, 4}

답: {0, 1, 2, 4}
