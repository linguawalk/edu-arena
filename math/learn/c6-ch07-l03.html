구의 방정식

중심이 (a, b, c)이고 반지름이 r인 구는 (x − a)² + (y − b)² + (z − c)² = r²입니다. 원의 방정식에 z가 더해진 모양입니다.

구는 '중심에서 거리가 r인 공간의 점들'입니다. 점 (x, y, z)와 중심 (a, b, c) 사이의 거리가 r이라는 식을 제곱하면 구의 방정식이 됩니다. 원이 평면에서 중심까지 거리가 일정한 점들이라면, 구는 그 생각을 공간으로 넓힌 것입니다.

문제 2

중심이 (1, 2, 3)이고 반지름이 2인 구는 (x − 1)² + (y − 2)² + (z − 3)² = ＿＿＿

일반형

x² + y² + z² + Ax + By + Cz + D = 0은 완전제곱식으로 바꿔 중심과 반지름을 찾습니다.

일반형은 x끼리, y끼리, z끼리 묶어 각각 완전제곱식으로 만듭니다. 이때 우변(r²)이 양수여야 구가 되고, 0이면 한 점, 음수이면 아무 점도 없습니다. 원의 일반형을 다루던 방법과 똑같습니다.

예제

x² + y² + z² − 4x + 6y − 2z + 5 = 0의 중심과 반지름을 구하세요.

  1. (x − 2)² − 4 + (y + 3)² − 9 + (z − 1)² − 1 + 5 = 0
  2. (x − 2)² + (y + 3)² + (z − 1)² = 9
  3. 중심 (2, −3, 1)
  4. 반지름 3

답: 중심 (2, −3, 1), 반지름 3

조건으로 구하기

원점을 지나면 원점까지의 거리가 반지름, xy평면에 접하면 중심의 |z좌표|가 반지름입니다.

구가 좌표평면에 접하면 중심에서 그 평면까지의 거리가 반지름입니다. xy평면까지의 거리는 |z좌표|, yz평면까지는 |x좌표|입니다. 지름의 양 끝이 주어지면 중심은 두 점의 중점, 반지름은 거리의 절반입니다.

예제

두 점 A(1, −2, 3), B(5, 2, −1)을 지름의 양 끝으로 하는 구의 방정식을 구하세요.

  1. 중심 = AB의 중점 = (3, 0, 1)
  2. AB = √(16 + 16 + 16) = 4√3
  3. 반지름 2√3, r² = 12
  4. (x − 3)² + y² + (z − 1)² = 12

답: (x − 3)² + y² + (z − 1)² = 12

구와 평면의 교선

구를 평면으로 자르면 단면은 원입니다. 중심과 평면 사이의 거리가 d이면 단면의 반지름은 √(r² − d²)입니다.

왜 √(r² − d²)일까요? 구의 중심에서 자르는 평면에 수선을 내리면 그 발이 단면(원)의 중심이 됩니다. 구의 중심, 단면의 중심, 단면 위의 점이 직각삼각형을 이루어 빗변 r, 한 변 d이므로 단면의 반지름은 √(r² − d²)입니다. d = r이면 평면이 구에 접해 단면이 한 점이 됩니다.

문제 9

구 x² + y² + z² = 25를 평면 z = 5로 자른 단면의 반지름은?

정리

구 위의 점과 다른 점 사이 거리의 최대·최소는 중심까지의 거리에서 반지름을 더하거나 뺍니다.

구 위의 점과 구 밖의 점 사이의 거리는 중심을 지나는 직선 위에서 최대·최소가 됩니다. 원에서와 같이 중심까지의 거리 d에 반지름을 더하면 최대, 빼면 최소입니다. 점이 구 안에 있으면 최솟값은 r − d가 됩니다.

예제

구 (x − 1)² + (y − 2)² + (z − 2)² = 16을 xy평면으로 자른 단면의 넓이를 구하세요.

  1. 중심 (1, 2, 2)에서 xy평면까지의 거리 d = 2
  2. 단면의 반지름 √(16 − 4) = √12
  3. 넓이 π × 12
  4. = 12π

답: 12π
