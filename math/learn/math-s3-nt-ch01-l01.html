vₚ(n)은 정수 n을 나누는 p의 최고 거듭제곱의 지수입니다(예: v₂(48) = 4). xⁿ − yⁿ이나 xⁿ + yⁿ이 p로 몇 번 나누어떨어지는지 묻는 문제는 국제 대회 정수론의 단골이며, LTE(Lifting The Exponent, 지수 올리기) 보조정리가 그 답을 한 줄로 줍니다.

선수 지식: S1 '합동식'과 '페르마 소정리', S2 '위수와 원시근'. 특히 'p ∤ n이면 1 + a + ⋯ + aⁿ⁻¹ ≡ n (mod p) (a ≡ 1)' 같은 합동 계산이 익숙해야 합니다.

이 가이드는 정리의 내용, 증명의 두 단계, p = 2일 때의 주의점, 그리고 지수 조건 문제와 위수 문제에 쓰는 법을 다룹니다. 다음 챕터 'p진 평가'와 함께 공부하면 좋습니다.

LTE 보조정리 (p가 홀수 소수)

p가 홀수 소수이고 정수 x, y가 p | x − y, p ∤ x, p ∤ y를 만족하면, 모든 양의 정수 n에 대해 vₚ(xⁿ − yⁿ) = vₚ(x − y) + vₚ(n)입니다.

n이 홀수이고 p | x + y, p ∤ x, p ∤ y이면 y 대신 −y를 넣어 vₚ(xⁿ + yⁿ) = vₚ(x + y) + vₚ(n)도 얻습니다.

증명은 두 단계입니다. ① p ∤ n이면 xⁿ − yⁿ = (x − y)(xⁿ⁻¹ + xⁿ⁻²y + ⋯ + yⁿ⁻¹)이고, x ≡ y이므로 둘째 괄호 ≡ nxⁿ⁻¹ ≢ 0 (mod p)라서 지수가 그대로입니다. ② n = p이면 둘째 괄호가 p로 정확히 한 번 나누어떨어짐을 보여 지수가 1 늘어납니다(아래 문제 4). n을 p의 거듭제곱과 나머지로 나누어 두 단계를 반복하면 정리가 나옵니다.

예제

v₃(10⁹ − 1)을 구하세요.

  1. x = 10, y = 1, p = 3이면 3 | 10 − 1 = 9이고 3 ∤ 10, 3 ∤ 1입니다.
  2. LTE에서 v₃(10⁹ − 1) = v₃(9) + v₃(9) = 2 + 2입니다.
  3. = 4입니다(실제로 999999999 = 3⁴ × 12345679이고, 12345679의 각 자리 합은 37이라 3의 배수가 아닙니다).

답: 4

문제 1

v₅(6²⁵ − 1)의 값은?

p = 2일 때

p = 2이면 공식이 달라집니다. x, y가 홀수이고 n이 짝수이면 v₂(xⁿ − yⁿ) = v₂(x − y) + v₂(x + y) + v₂(n) − 1입니다. n이 홀수이면 v₂(xⁿ − yⁿ) = v₂(x − y)입니다.

n이 짝수일 때 x² − y² = (x − y)(x + y)로 먼저 쪼개야 하는 까닭은, x − y와 x + y가 둘 다 짝수이고 그 가운데 하나만 4의 배수이기 때문입니다. 홀수 p의 공식을 그대로 쓰면 틀린 답이 나옵니다.

예: v₂(3² − 1) = v₂(8) = 3이고, 공식으로는 v₂(2) + v₂(4) + v₂(2) − 1 = 1 + 2 + 1 − 1 = 3입니다. 홀수 p의 공식 v₂(2) + v₂(2) = 2는 틀립니다.

예제

v₂(3¹⁰⁰ − 1)을 구하세요.

  1. x = 3, y = 1은 홀수이고 n = 100은 짝수이므로 p = 2의 공식을 씁니다.
  2. v₂(3 − 1) = 1, v₂(3 + 1) = 2, v₂(100) = 2입니다.
  3. v₂(3¹⁰⁰ − 1) = 1 + 2 + 2 − 1 = 4입니다.

자기 점검과 흔한 실수

LTE를 쓸 때마다 조건 세 가지(p | x − y, p ∤ x, p ∤ y)를 답안에 적었는지 확인하세요. 조건을 적지 않고 공식만 쓰면 감점될 수 있고, 조건이 깨진 곳에 쓰면 틀린 답이 나옵니다(예: p | x이면 성립하지 않음).

p = 2에서 홀수 소수의 공식을 쓰는 실수가 가장 흔합니다. 문제 3처럼 n의 홀짝으로 먼저 나누는 습관을 들이세요.

대회 답안에서는 LTE를 '널리 알려진 보조정리'로 인용해도 되지만, 시간이 있으면 문제 4의 논증을 짧게 덧붙이는 것이 안전합니다.

독학 순서와 참고 자료

추천 순서: ① 문제 4로 정리를 직접 증명해 보고 ② 문제 1·2로 기본 적용 ③ 문제 3으로 p = 2와 크기 비교 ④ 문제 5로 위수 문제에 쓰는 법을 익힙니다. 그다음 'p진 평가' 가이드로 넘어가 르장드르 공식과 함께 씁니다.

더 공부할 주제: aⁿ − 1의 원시 소인수(지그몬디 정리를 결론으로만 쓰는 경우와 그 위험), n | aⁿ + 1 꼴 문제에서 가장 작은 소인수 잡기, 위수와 LTE를 함께 쓰는 문제.
