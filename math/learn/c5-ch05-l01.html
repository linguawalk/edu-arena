확률변수와 확률분포

확률변수

시행의 결과에 따라 값이 정해지는 변수를 확률변수라고 합니다. 동전 두 개를 던져 나오는 앞면의 개수 X는 0, 1, 2 중 하나입니다.

X의 각 값과 그 확률을 나타낸 것을 확률분포라고 합니다.

확률변수는 '결과'를 '수'로 바꿔 주는 규칙입니다. 동전 두 개의 결과 HH, HT, TH, TT를 앞면의 개수 2, 1, 1, 0으로 바꾸면, 확률을 수의 언어로 다룰 수 있어 평균이나 흩어짐을 계산할 수 있게 됩니다. 이름은 '변수'이지만 실제로는 결과마다 값을 정하는 함수입니다.

문제 1

동전 두 개를 던질 때 앞면의 개수 X에 대해 P(X = 1)은? (기약분수로)

문제 2

같은 X에서 P(X = 2)는? (기약분수로)

확률분포의 조건

각 확률은 0 이상이고, 모든 확률의 합은 1입니다.

확률분포의 두 조건은 확률의 기본 성질에서 나옵니다. 각 값이 나올 확률은 0 이상이어야 하고, 확률변수가 가질 수 있는 값들은 표본공간 전체를 빠짐없이 나누므로 확률의 합은 반드시 1입니다. 모르는 상수가 있으면 '합이 1'이라는 조건으로 구합니다.

예제

P(X = k) = c/k (k = 1, 2, 3)가 확률분포일 때 c와 P(X ≥ 2)를 구하세요.

  1. 확률의 합: c(1 + 1/2 + 1/3) = c × 11/6 = 1
  2. c = 6/11
  3. P(X ≥ 2) = (6/11)(1/2 + 1/3) = (6/11)(5/6)
  4. = 5/11

답: c = 6/11, P(X ≥ 2) = 5/11

확률분포 구하기

X가 가질 수 있는 값을 모두 적고, 각 값이 나오는 경우를 세어 확률을 구합니다.

확률분포를 구하는 순서: ① X가 가질 수 있는 값을 모두 적고 ② 각 값이 나오는 경우를 표본공간에서 세어 ③ 확률분포표로 정리한 뒤 ④ 확률의 합이 1인지 확인합니다. 마지막 확인 단계가 계산 실수를 잡아 줍니다.

예제

주사위 두 개를 던져 나온 두 눈의 차의 절댓값 X의 확률분포를 구하세요.

  1. X = 0: 6가지, X = 1: 10가지, X = 2: 8가지
  2. X = 3: 6가지, X = 4: 4가지, X = 5: 2가지
  3. 각각 36으로 나눔: 6/36, 10/36, 8/36, 6/36, 4/36, 2/36
  4. 확인: 6 + 10 + 8 + 6 + 4 + 2 = 36

답: P(X = 1) = 5/18 등

범위의 확률

P(a ≤ X ≤ b)는 그 범위에 있는 값들의 확률을 모두 더합니다.

X의 값들이 나오는 사건은 서로 배반입니다(X가 동시에 1이면서 2일 수 없음). 그래서 범위의 확률은 해당 값들의 확률을 그대로 더하면 됩니다. 범위가 넓으면 여사건 P(X ≥ 2) = 1 − P(X ≤ 1)을 쓰는 것이 빠를 때도 있습니다.

정리

확률분포표를 만들면 확률의 합이 1인지 먼저 확인하는 습관을 들입니다.

확률분포표는 이 챕터의 모든 계산의 출발점입니다. 기댓값, 분산, 범위의 확률 모두 이 표에서 계산합니다. 표를 만든 뒤 합이 1이 아니면 경우를 빠뜨렸거나 중복해서 센 것이므로 다시 셉니다. 표에 누적 확률 열을 하나 더 두면 범위의 확률도 바로 읽을 수 있습니다.

예제

불량품 2개를 포함한 6개 중 3개를 뽑을 때 불량품의 개수 X의 확률분포를 구하세요.

  1. 전체 ₆C₃ = 20
  2. X = 0: ₄C₃ = 4, X = 1: ₂C₁₄C₂ = 12, X = 2: ₂C₂₄C₁ = 4
  3. P = 4/20, 12/20, 4/20 = 1/5, 3/5, 1/5
  4. 확인: 합 1

답: 1/5, 3/5, 1/5
