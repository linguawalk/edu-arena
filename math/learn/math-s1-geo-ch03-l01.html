무게중심

수학 올림피아드 S1 예선 · 기하 · 3. 삼각형의 오심 · 심화 · 약 20분 · 문제 11개

이 레슨 풀어 보기

세 중선은 한 점에서 만난다

삼각형의 꼭짓점과 마주 보는 변의 중점을 이은 선분을 중선이라고 합니다. 세 중선은 한 점 G에서 만나고, 이 점을 무게중심이라고 합니다.

무게중심은 각 중선을 꼭짓점 쪽부터 2 : 1로 나눕니다. 곧 AG : GM = 2 : 1입니다.

좌표로는 G = ((x₁ + x₂ + x₃)/3, (y₁ + y₂ + y₃)/3)으로 세 꼭짓점의 평균입니다. 균일한 삼각형 판을 이 점에서 받치면 균형이 잡히기 때문에 무게중심이라는 이름이 붙었습니다. 2 : 1이라는 비는 중점연결정리 한 번으로 증명됩니다.

문제 1

삼각형의 중선 AM의 길이가 12일 때 꼭짓점 A에서 무게중심 G까지의 거리는?

문제 2

무게중심 G는 중선 AM을 AG : GM = ＿＿＿ : 1로 나눕니다.

여섯 조각의 넓이는 같다

세 중선은 삼각형을 넓이가 같은 작은 삼각형 6개로 나눕니다.

중선 AM은 밑변 BC를 이등분하므로 [ABM] = [ACM]입니다. 같은 이유로 G에서 보면 [GBM] = [GCM]이고, 빼면 [GAB] = [GAC]가 됩니다. 다른 중선에서도 같은 논증을 하면 세 삼각형 GAB, GBC, GCA의 넓이가 모두 같습니다.

그래서 [GBC] = [ABC]/3이고, 여섯 조각 각각은 [ABC]/6입니다. '높이가 같으면 넓이의 비는 밑변의 비'라는 사실 하나로 증명되며, 이 방법은 챕터 4의 넓이 문제에서 계속 씁니다.

예제

넓이가 36인 삼각형 ABC의 무게중심을 G라 할 때 삼각형 GBC의 넓이를 구하세요.

  1. 세 중선은 삼각형을 넓이가 같은 6개의 작은 삼각형으로 나눕니다.
  2. 작은 삼각형 하나의 넓이는 36/6 = 6입니다.
  3. 삼각형 GBC는 그중 2개로 이루어집니다.
  4. 따라서 [GBC] = 12입니다.

답: 12

문제 3

넓이가 48인 삼각형 ABC의 무게중심을 G라 할 때 삼각형 GBC의 넓이는?

문제 4

A(0, 0), B(6, 0), C(3, 9)인 삼각형의 무게중심의 y좌표는?

중선의 길이

삼각형 ABC에서 BC의 중점을 M이라 하면 AB² + AC² = 2(AM² + BM²)입니다. 이것을 중선 정리(파푸스 정리)라고 합니다.

좌표로 M을 원점, B(−m, 0), C(m, 0), A(x, y)로 놓으면 AB² + AC² = 2x² + 2y² + 2m² = 2(AM² + BM²)이 바로 나옵니다.

평행사변형으로 보면 두 대각선의 제곱의 합이 네 변의 제곱의 합과 같다는 성질과 같습니다. AB = 7, AC = 9, BC = 8이면 AM² = (49 + 81)/2 − 16 = 49이므로 AM = 7입니다. 중선의 길이와 무게중심의 2 : 1을 함께 쓰면 AG도 바로 구할 수 있습니다.

문제 5

AB = 7, AC = 9, BC = 8인 삼각형에서 BC의 중점을 M이라 할 때 중선 AM의 길이는?

문제 6

앞 문제의 삼각형에서 무게중심을 G라 할 때 AG의 길이를 분수로 쓰세요.

직각삼각형의 중선

직각삼각형에서 빗변에 그은 중선의 길이는 빗변의 절반입니다. 빗변의 중점은 외접원의 중심이고, 세 꼭짓점까지의 거리가 모두 반지름이기 때문입니다(챕터 2의 지름과 직각).

빗변이 10인 직각삼각형이면 빗변에 그은 중선은 5입니다.

중선 정리로도 확인할 수 있습니다. 두 다리를 a, b라 하면 a² + b² = c²이므로 2(AM² + (c/2)²) = c², 곧 AM² = c²/4입니다. 서로 다른 두 방법이 같은 결과를 주는지 확인하는 것은 좋은 검산 습관입니다.

문제 7

빗변이 10인 직각삼각형에서 직각 꼭짓점에서 빗변에 그은 중선의 길이는?

정리

세 중선은 무게중심 G에서 만나고, G는 각 중선을 꼭짓점 쪽부터 2 : 1로 나눕니다. 좌표로는 세 꼭짓점의 평균입니다.

세 중선은 삼각형을 넓이가 같은 6조각으로 나누므로 [GAB] = [GBC] = [GCA] = [ABC]/3입니다.

중선의 길이는 AB² + AC² = 2(AM² + BM²)로 구합니다. 직각삼각형의 빗변에 그은 중선은 빗변의 절반입니다.
