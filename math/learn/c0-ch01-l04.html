무리수와 실수

기초 수학 · 1. 수 체계 · 레벨1 · 약 15분 · 문제 16개

끝나지 않는 소수

1/4 = 0.25처럼 끝이 있는 소수가 있고, 1/3 = 0.333…처럼 끝없이 이어지는 소수도 있습니다.

0.333…은 끝이 없지만 3이 규칙적으로 되풀이됩니다.

문제 1

1/8을 소수로 나타내세요.

문제 2

0.333…처럼 같은 숫자 배열이 끝없이 되풀이되는 소수를 ＿＿＿소수라고 합니다.

순환소수를 분수로

x = 0.777…이라 하면 10x = 7.777…입니다.

두 식을 빼면 9x = 7, 즉 x = 7/9입니다. 순환마디가 두 자리면 100을 곱하면 됩니다.

이렇게 모든 순환소수는 분수로 바꿀 수 있으므로 유리수입니다.

예제

0.3636…(36이 반복)을 기약분수로 나타내세요.

  1. x = 0.3636…으로 놓습니다.
  2. 순환마디가 두 자리이므로 100을 곱합니다: 100x = 36.3636…
  3. 두 식을 빼면 100x − x = 36, 즉 99x = 36
  4. x = 36/99 = 4/11

답: 4/11

무리수

√2 = 1.41421356…, π = 3.14159265…는 끝없이 이어지면서 순환하지도 않습니다.

이렇게 순환하지 않는 무한소수를 무리수라고 합니다. 분수로 나타낼 수 없는 수입니다.

유리수와 무리수를 통틀어 실수라고 합니다.

예제

√16, √15, 0.5, π/2 중 무리수를 모두 고르세요.

  1. √16 = 4이므로 유리수
  2. 15는 제곱수가 아니므로 √15는 무리수
  3. 0.5 = 1/2이므로 유리수
  4. π가 무리수이므로 π/2도 무리수

답: √15, π/2

문제 6

다음 수 중 무리수는 몇 개일까요? √9, √12, 0.121212…, π, −√16, 3/7, √0.25

실수와 수직선

한 변이 1인 정사각형의 대각선 길이는 √2입니다. 컴퍼스로 이 길이를 수직선에 옮기면 √2를 나타내는 점을 정확히 찍을 수 있습니다.

유리수만으로는 수직선에 빈틈이 남지만, 실수는 수직선을 빈틈없이 채웁니다.

문제 8

−1에서 시작해 한 변이 1인 정사각형의 대각선 길이만큼 오른쪽으로 옮겼습니다. 도착한 점을 표시하세요.

근호의 계산

√a × √b = √(ab), √a ÷ √b = √(a/b) (a, b > 0)

√(k² × a) = k√a. 예: √12 = √(2² × 3) = 2√3

근호 안이 같은 수끼리만 더하고 뺄 수 있습니다. 예: 3√2 + √2 = 4√2

예제

√27 + √12 − √3을 간단히 하세요.

  1. √27 = √(9 × 3) = 3√3
  2. √12 = √(4 × 3) = 2√3
  3. 3√3 + 2√3 − √3 = (3 + 2 − 1)√3
  4. = 4√3

답: 4√3
