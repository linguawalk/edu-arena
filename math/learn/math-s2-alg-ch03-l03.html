삼각형의 변을 바꾸기 (라비 치환)

a, b, c가 삼각형의 세 변이면 a = y + z, b = z + x, c = x + y인 양수 x, y, z가 있습니다(라비 치환). x = s − a, y = s − b, z = s − c (s는 반둘레)입니다.

변이 5, 6, 7이면 s = 9이고 x = 4, y = 3, z = 2입니다. 실제로 y + z = 5, z + x = 6, x + y = 7입니다.

라비 치환을 하면 '삼각형 부등식'이라는 조건이 'x, y, z > 0'이라는 단순한 조건으로 바뀌어, 산술-기하 같은 도구를 바로 쓸 수 있습니다.

문제 1

변이 a = 5, b = 6, c = 7인 삼각형의 라비 치환에서 x = s − a는?

문제 2

삼각형의 세 변을 a = y + z, b = z + x, c = x + y (x, y, z > 0)로 바꾸는 방법을 ＿＿＿ 치환이라 합니다.

헤론 공식과 라비 치환

헤론 공식: 넓이 = √(s(s − a)(s − b)(s − c))입니다. 라비 치환으로 쓰면 s = x + y + z이므로 넓이 = √((x + y + z)xyz)입니다.

변이 5, 6, 7이면 넓이 = √(9 × 4 × 3 × 2) = √216 = 6√6입니다.

abc ≥ 8(s − a)(s − b)(s − c) 같은 부등식은 라비 치환으로 (x + y)(y + z)(z + x) ≥ 8xyz가 되어 산술-기하 평균 세 번으로 끝납니다.

예제

변이 5, 6, 7인 삼각형의 넓이를 라비 치환으로 구하세요.

  1. s = 9, x = 4, y = 3, z = 2입니다.
  2. 넓이 = √((x + y + z)xyz) = √(9 × 24)입니다.
  3. = √216입니다.
  4. = 6√6 ≈ 14.70입니다.

답: 6√6

문제 3

변이 5, 6, 7인 삼각형에서 (x + y + z)xyz (라비 치환, 넓이의 제곱)는?

문제 4

변이 a, b, c인 삼각형에서 abc ≥ 8(s − a)(s − b)(s − c)를 라비 치환하면 (x + y)(y + z)(z + x) ≥ kxyz입니다. k는?

대칭식을 합과 곱으로

두 변수 대칭식은 p = a + b, q = ab로 바꿀 수 있습니다. a² + b² = p² − 2q, a³ + b³ = p³ − 3pq입니다.

t = a + 1/a로 두면 a² + 1/a² = t² − 2, a³ + 1/a³ = t³ − 3t입니다. a > 0이면 t ≥ 2입니다.

치환 뒤에는 변수가 줄거나 조건이 단순해지는지 확인합니다. 그렇지 않으면 다른 치환을 시도합니다.

문제 5

a + 1/a = 3일 때 a² + 1/a²은?

문제 6

a + 1/a = 3일 때 a³ + 1/a³은?

문제 7

a + b = 5, ab = 3일 때 a³ + b³은?

정리

라비 치환 a = y + z, b = z + x, c = x + y는 삼각형 조건을 x, y, z > 0으로 바꾸며, x = s − a 등이고 넓이는 √((x + y + z)xyz)입니다.

두 변수 대칭식은 p = a + b, q = ab로, a와 1/a가 함께 나오면 t = a + 1/a로 바꿉니다.

좋은 치환은 변수를 줄이거나 조건을 단순하게 만듭니다.
