코사인 법칙

삼각형에서 두 변 a, b와 끼인각 C를 알면 세 번째 변 c는 c² = a² + b² − 2ab cos C로 구합니다.

C를 원점, B를 (a, 0), A를 (b cos C, b sin C)로 놓으면 c² = (a − b cos C)² + (b sin C)² = a² + b² − 2ab cos C입니다.

cos 60° = 1/2, cos 90° = 0, cos 120° = −1/2입니다. C = 90°이면 피타고라스 정리가 되므로, 코사인 법칙은 피타고라스 정리를 모든 삼각형으로 넓힌 것입니다. 세 변을 알 때 각을 구하는 데에도 씁니다: cos C = (a² + b² − c²)/(2ab).

문제 2

C = 90°이면 코사인 법칙은 ＿＿＿ 정리가 됩니다.

예제

세 변이 7, 8, 13인 삼각형의 가장 큰 각을 구하세요.

  1. 가장 큰 각은 가장 긴 변 13의 대각입니다.
  2. cos C = (7² + 8² − 13²)/(2 × 7 × 8) = (49 + 64 − 169)/112입니다.
  3. = −56/112 = −1/2입니다.
  4. 따라서 C = 120°입니다.

답: 120°

문제 4

세 변이 4, 5, 6인 삼각형에서 가장 큰 각의 코사인 값을 분수로 쓰세요.

예각인가 둔각인가

가장 긴 변을 c라 하면, cos C의 부호는 a² + b² − c²의 부호와 같습니다.

c² < a² + b²이면 예각삼각형, c² = a² + b²이면 직각삼각형, c² > a² + b²이면 둔각삼각형입니다.

각도를 계산하지 않고 세 변의 제곱만 비교해서 판정할 수 있습니다. 4, 5, 6이면 36 < 16 + 25 = 41이므로 예각삼각형이고, 3, 5, 7이면 49 > 34이므로 둔각삼각형입니다. 외심과 수심의 위치를 판단할 때도 이 판정을 씁니다.

문제 5

세 변이 5, 7, 9인 삼각형은 ＿＿＿삼각형입니다. (예각, 직각, 둔각 중 하나)

사인 법칙

삼각형 ABC의 외접원의 반지름을 R이라 하면 a/sin A = b/sin B = c/sin C = 2R입니다.

B를 지나는 지름 BD를 그으면 ∠BDC = ∠A(같은 호에 대한 원주각)이고 ∠BCD = 90°입니다. 직각삼각형 BCD에서 BC = BD sin(∠BDC), 곧 a = 2R sin A입니다.

사인 법칙은 두 각과 한 변을 알 때 다른 변을 구하는 데 씁니다. 또 외심 공식 R = abc/(4K)와 넓이 공식 K = (1/2)bc sin A를 잇는 다리이기도 합니다.

평행사변형의 대각선

두 변이 a, b이고 한 내각이 θ인 평행사변형의 두 대각선은 코사인 법칙으로 구합니다.

θ를 끼인 대각선은 d₁² = a² + b² − 2ab cos θ이고, 이웃한 각 180° − θ를 끼인 대각선은 d₂² = a² + b² + 2ab cos θ입니다.

더하면 d₁² + d₂² = 2(a² + b²)로, 중선 정리와 같은 식이 나옵니다. 두 변이 5, 8이고 내각이 60°이면 d₁² = 49, d₂² = 129입니다.

문제 8

두 변이 5, 8이고 한 내각이 60°인 평행사변형에서 긴 대각선의 길이의 제곱은?

정리

코사인 법칙 c² = a² + b² − 2ab cos C는 두 변과 끼인각으로 세 번째 변을, 세 변으로 각을 구합니다.

가장 긴 변 c에 대해 c²과 a² + b²을 비교하면 예각·직각·둔각을 판정할 수 있습니다.

사인 법칙 a/sin A = b/sin B = c/sin C = 2R은 두 각과 한 변으로 다른 변을 구하고, 외접원의 반지름과 연결됩니다.
