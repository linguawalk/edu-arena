곱해도 나머지는 섞일 뿐

p가 소수이고 p ∤ a일 때 a, 2a, 3a, …, (p − 1)a를 p로 나눈 나머지는 1, 2, …, p − 1을 순서만 바꾼 것입니다.

예를 들어 p = 7, a = 3이면 3, 6, 9, 12, 15, 18의 나머지는 3, 6, 2, 5, 1, 4입니다.

두 목록의 곱이 같으므로 a^(p − 1) × (p − 1)! ≡ (p − 1)! (mod p)이고, (p − 1)!은 p와 서로소라 양변을 나눌 수 있어 a^(p − 1) ≡ 1이 됩니다. 페르마 소정리는 이렇게 '곱하면 나머지가 섞인다'는 관찰 하나로 증명됩니다.

문제 1

3 × 1, 3 × 2, …, 3 × 6을 각각 7로 나눈 나머지를 모두 더하면?

문제 2

(3·1)(3·2)⋯(3·6) ≡ 1·2⋯6 (mod 7)이므로 3⁶ × 6! ≡ 6!이고, 6!은 7과 서로소이므로 3⁶ ≡ ＿＿＿ (mod 7)입니다.

왜 순서만 바뀔까

ia ≡ ja (mod p)라고 해 봅시다(1 ≤ i < j ≤ p − 1). 그러면 p | (j − i)a이고, p ∤ a이므로 p | j − i입니다.

그런데 0 < j − i < p이므로 불가능합니다. 따라서 p − 1개의 나머지는 모두 다릅니다. 또 p ∤ ia이므로 나머지는 0이 아닙니다.

1부터 p − 1까지 중 서로 다른 값 p − 1개이므로, 정확히 1, 2, …, p − 1이 한 번씩 나옵니다. 'p | xy이면 p | x 또는 p | y'라는 소수의 성질이 여기서 핵심적으로 쓰였습니다. 법이 합성수이면 이 성질이 깨지므로 페르마 소정리도 그대로는 성립하지 않습니다.

문제 3

페르마 소정리의 증명을 올바른 순서로 배열하세요.

예제

모든 정수 n에 대해 n⁵ − n이 30의 배수임을 보이세요.

  1. 30 = 2 × 3 × 5이고 세 수는 서로소이므로 각각의 배수임을 보이면 됩니다.
  2. 페르마 소정리에 의해 n⁵ ≡ n (mod 5)입니다.
  3. n⁵ − n = n(n − 1)(n + 1)(n² + 1)이고, 연속한 세 정수 n − 1, n, n + 1의 곱은 2와 3의 배수입니다.
  4. 따라서 n⁵ − n은 2, 3, 5의 배수이고, 30의 배수입니다.

답: 30의 배수

문제 4

모든 정수 n에 대해 n⁷ − n을 나누는 가장 큰 자연수는?

이항계수와 소수

p가 소수이면 0 < k < p일 때 이항계수 C(p, k) = p!/(k!(p − k)!)는 p의 배수입니다. 분자에는 p가 있지만 분모의 k!과 (p − k)!에는 p보다 작은 수만 있기 때문입니다.

그래서 (a + b)ᵖ ≡ aᵖ + bᵖ (mod p)입니다. 이항정리로 전개한 가운데 항이 모두 p의 배수이기 때문입니다.

이 성질로 페르마 소정리를 귀납법으로도 증명할 수 있습니다. (a + 1)ᵖ ≡ aᵖ + 1 ≡ a + 1 (mod p)이므로, aᵖ ≡ a가 성립하면 a + 1에서도 성립합니다. 같은 정리를 서로 다른 두 방법으로 증명할 수 있다는 것은 정리를 깊이 이해하는 데 도움이 됩니다.

문제 6

(x + 1)⁵ − x⁵ − 1을 전개했을 때 모든 계수를 더한 값은?

역원을 거듭제곱으로

a^(p − 1) ≡ 1 (mod p)를 a × a^(p − 2) ≡ 1로 읽으면, a^(p − 2)가 a의 역원입니다.

3의 7을 법으로 한 역원은 3⁵ = 243 ≡ 5 (mod 7)입니다. 앞 챕터에서 찾은 값과 같습니다.

법이 클 때 역원을 시행착오로 찾기 어렵다면, 이 방법이나 베주 항등식을 씁니다. 거듭제곱은 제곱을 거듭하면 몇 번의 곱셈으로 계산할 수 있어 컴퓨터로도 빠르게 구할 수 있습니다. 실제 암호 계산에서도 이 방법을 씁니다.

문제 7

3⁵을 7로 나눈 나머지(곧 3의 7을 법으로 한 역원)는?

정리

페르마 소정리는 a, 2a, …, (p − 1)a의 나머지가 1, …, p − 1의 재배열이라는 사실로 증명됩니다. 핵심은 'p | xy이면 p | x 또는 p | y'입니다.

0 < k < p이면 p | C(p, k)이고, 그래서 (a + b)ᵖ ≡ aᵖ + bᵖ (mod p)입니다. 이것으로 귀납법 증명도 됩니다.

nᵖ − n이 p의 배수라는 사실과 연속한 정수의 곱을 함께 쓰면 n⁵ − n, n⁷ − n 같은 식을 나누는 수를 구할 수 있습니다. a^(p − 2)는 a의 역원입니다.
