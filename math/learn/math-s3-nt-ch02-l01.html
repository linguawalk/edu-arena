p진 평가 학습 가이드

수학 올림피아드 S3 국제 · 정수론 · 2. p진 평가 · 심화 · 약 120분 · 문제 8개

이 가이드에서 다룰 도구

p진 평가 vₚ(n)은 n에 들어 있는 소인수 p의 개수입니다. vₚ(ab) = vₚ(a) + vₚ(b)이고, vₚ(a + b) ≥ min(vₚ(a), vₚ(b))이며 두 값이 다르면 등호가 성립합니다. 이 세 성질만으로 '어떤 수가 다른 수를 나누는가'를 소수마다 따로 따지는 문제로 바꿀 수 있습니다.

이 가이드는 ① 계승의 평가(르장드르 공식) ② 이항계수의 평가(쿠머 정리) ③ '각 소수에서 지수를 비교'하는 나눗셈 증명을 다룹니다. 앞 챕터 LTE가 xⁿ − yⁿ의 평가였다면, 이 챕터는 n!과 이항계수의 평가입니다.

선수 지식: S1 '소수와 소인수분해', 진법 표기(2진법, 3진법). 바닥 함수 ⌊x⌋(x 이하의 가장 큰 정수)도 씁니다.

르장드르 공식

vₚ(n!) = ⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + ⋯입니다. 1부터 n까지에서 p의 배수가 ⌊n/p⌋개이고, 그 가운데 p²의 배수는 p를 하나 더 가지므로 ⌊n/p²⌋개를 더 세고, 이렇게 계속 세기 때문입니다.

같은 값을 진법으로도 쓸 수 있습니다: vₚ(n!) = (n − sₚ(n))/(p − 1). 여기서 sₚ(n)은 n을 p진법으로 쓴 자릿수의 합입니다. 예를 들어 v₂(n!) = n − s₂(n)이므로 v₂(n!) < n이 언제나 성립합니다.

n!의 끝에 붙은 0의 개수는 min(v₂(n!), v₅(n!)) = v₅(n!)입니다(2가 5보다 많으므로).

예제

v₅(100!)과 100!의 끝자리 0의 개수를 구하세요.

  1. ⌊100/5⌋ = 20, ⌊100/25⌋ = 4, ⌊100/125⌋ = 0입니다.
  2. v₅(100!) = 20 + 4 = 24입니다.
  3. v₂(100!) = 97이 이보다 크므로 끝자리 0은 24개입니다.

쿠머 정리

vₚ(C(m + n, m))은 m과 n을 p진법으로 더할 때 생기는 받아올림의 횟수와 같습니다(쿠머 정리). 르장드르 공식의 진법 꼴에서 vₚ(C(m + n, m)) = (sₚ(m) + sₚ(n) − sₚ(m + n))/(p − 1)이고, 받아올림이 한 번 일어날 때마다 자릿수 합이 p − 1만큼 줄기 때문입니다.

예: 50을 2진법으로 쓰면 110010이고, 50 + 50을 2진법으로 더하면 1이 있는 세 자리에서 각각 받아올림이 생기므로 v₂(C(100, 50)) = 3입니다.

쿠머 정리는 '이항계수가 p로 나누어떨어지는가'를 진법의 받아올림 문제로 바꿉니다. 특히 C(n, k)가 홀수인 것은 k와 n − k를 2진법으로 더할 때 받아올림이 없는 것, 곧 k의 1인 자리가 모두 n에서도 1인 것과 같습니다.

예제

v₃(C(100, 50))을 쿠머 정리로 구하세요.

  1. 50을 3진법으로 쓰면 1212입니다(27 + 18 + 3 + 2).
  2. 1212 + 1212를 아래 자리부터 더하면 2 + 2 = 4(받아올림), 1 + 1 + 1 = 3(받아올림), 2 + 2 + 1 = 5(받아올림), 1 + 1 + 1 = 3(받아올림)입니다.
  3. 받아올림이 4번이므로 v₃(C(100, 50)) = 4입니다.

자기 점검과 흔한 실수

르장드르 공식에서 p²의 배수를 한 번만 세는 실수(⌊n/p⌋만 쓰기)가 가장 흔합니다. 25!에서 25는 5를 두 개 갖습니다.

'a | b를 보여라'는 모든 소수 p에 대해 vₚ(a) ≤ vₚ(b)를 보이는 것과 같습니다. 이 틀로 쓰면 문제 2 같은 부등식이 자연스럽게 나옵니다.

쿠머 정리를 쓸 때는 진법 표기를 답안에 실제로 적고 받아올림을 한 자리씩 보이세요. 채점자가 확인할 수 있어야 합니다.

독학 순서와 참고 자료

추천 순서: ① 문제 1로 르장드르 공식을 직접 증명 ② 문제 3·4로 계산과 부등식 ③ 문제 2로 '각 항이 0 또는 1' 논법 ④ 문제 5로 쿠머 정리를 연습합니다. 문제 2의 부등식은 베르트랑 공준(n과 2n 사이에 소수가 있다)의 초등적 증명에 쓰이는 핵심 단계이니, 관심이 있으면 그 증명을 찾아 읽어 보세요.

더 공부할 주제: 뤼카 정리(C(n, k) mod p를 p진법 자릿수로 계산), 분모의 평가로 유리수 합이 정수가 아님을 보이기(예: 1 + 1/2 + ⋯ + 1/n), LTE와 르장드르 공식을 함께 쓰는 문제.
