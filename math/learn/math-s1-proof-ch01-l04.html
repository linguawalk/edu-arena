모든 경우를 빠짐없이

경우 나누기는 가능한 경우를 몇 가지로 나누어 각각 증명하는 방법입니다. 정수라면 홀수와 짝수, 3으로 나눈 나머지 0, 1, 2처럼 나눕니다.

나눈 경우들이 모든 가능성을 빠짐없이 덮어야 증명이 됩니다.

왜 나머지로 나눌까요? 정수는 무한히 많지만, 3으로 나눈 나머지는 0, 1, 2 세 가지뿐입니다. n = 3k, 3k + 1, 3k + 2의 세 경우만 확인하면 무한히 많은 정수를 한꺼번에 다룬 것이 됩니다. 무한을 유한으로 줄이는 것이 경우 나누기의 핵심입니다.

문제 1

정수를 5로 나눈 나머지로 경우를 나누면 모두 몇 가지 경우가 생기나요?

문제 2

n = 3k + 1이면 n² = 9k² + 6k + 1 = 3(＿＿＿) + 1입니다.

제곱수를 나머지로 보기

제곱수는 나머지가 몇 가지로 제한됩니다. 3으로 나누면 나머지는 0 또는 1, 4로 나누면 0 또는 1입니다.

n = 2k이면 n² = 4k², n = 2k + 1이면 n² = 4(k² + k) + 1이기 때문입니다.

이 사실은 올림피아드에서 '이런 정수는 없다'를 보일 때 가장 자주 쓰는 도구입니다. 예를 들어 4로 나눈 나머지가 3인 수는 두 제곱수의 합이 될 수 없습니다. 제곱수 두 개의 나머지 합은 0, 1, 2 중 하나뿐이기 때문입니다. 어떤 수로 나눌지는 문제의 수에 맞춰 고릅니다.

예제

제곱수를 4로 나눈 나머지는 0 또는 1뿐임을 보이세요.

  1. 정수 n을 짝수와 홀수의 두 경우로 나눕니다.
  2. n = 2k이면 n² = 4k²이므로 나머지는 0입니다.
  3. n = 2k + 1이면 n² = 4k² + 4k + 1 = 4(k² + k) + 1이므로 나머지는 1입니다.
  4. 두 경우가 모든 정수를 덮으므로 제곱수를 4로 나눈 나머지는 0 또는 1입니다.

답: 0 또는 1

구간으로 경우 나누기

절댓값이 있는 식은 절댓값 안이 0이 되는 점을 경계로 구간을 나눕니다. |x − 1| + |x + 2|라면 x = −2와 x = 1이 경계입니다.

구간마다 절댓값을 벗겨 식을 풀고, 얻은 해가 그 구간 안에 있는지 반드시 확인합니다.

경우 나누기에서 감점이 가장 많이 나는 곳은 두 가지입니다. 경계값(x = 1 같은 점)을 어느 경우에도 넣지 않은 것, 그리고 구간 밖의 해를 그대로 답으로 쓴 것입니다. 경우를 나눈 뒤에는 '빠진 경우가 없는가, 해가 구간 안에 있는가'를 점검하는 습관을 들이세요.

예제

|x − 1| + |x + 2| = 5를 푸세요.

  1. x < −2이면 −(x − 1) − (x + 2) = −2x − 1 = 5에서 x = −3이고, 구간 안에 있습니다.
  2. −2 ≤ x ≤ 1이면 −(x − 1) + (x + 2) = 3 = 5가 되어 해가 없습니다.
  3. x > 1이면 (x − 1) + (x + 2) = 2x + 1 = 5에서 x = 2이고, 구간 안에 있습니다.
  4. 따라서 해는 x = −3, x = 2입니다.

답: x = −3, x = 2

정리

경우 나누기는 무한히 많은 경우를 나머지나 구간으로 몇 가지로 줄여 각각 증명하는 방법입니다.

제곱수를 3이나 4로 나눈 나머지는 0 또는 1, 8로 나눈 나머지는 0, 1, 4입니다. '이런 정수는 없다'를 보일 때 자주 씁니다.

나눈 경우가 모든 가능성을 빠짐없이 덮는지, 경계값을 빠뜨리지 않았는지, 얻은 해가 그 경우의 조건에 맞는지 점검하세요. 답안 첫머리에 '정수 n을 3으로 나눈 나머지에 따라 세 경우로 나눈다'처럼 나누는 기준을 밝히면 채점자가 따라가기 쉽습니다.
