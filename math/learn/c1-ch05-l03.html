곱의 부호

두 수의 곱이 음수이면 두 수의 부호가 다르고, 양수이면 부호가 같습니다.

(x − 1)(x − 4) < 0은 x − 1과 x − 4의 부호가 달라야 하므로 x가 1과 4 사이에 있어야 합니다.

왜 1과 4 사이일까요? x < 1이면 두 인수가 모두 음수라 곱이 양수, x > 4이면 모두 양수라 곱이 양수입니다. 1 < x < 4일 때만 x − 1은 양수, x − 4는 음수라 곱이 음수가 됩니다.

이차부등식 풀기

x²의 계수가 양수가 되도록 정리하고 인수분해해 두 근 α < β를 구합니다.

(x − α)(x − β) < 0이면 α < x < β, > 0이면 x < α 또는 x > β입니다.

이차함수 그래프로 보면 더 분명합니다. y = (x − α)(x − β)는 아래로 볼록한 포물선이라 두 근 사이에서는 x축 아래(음수), 바깥에서는 x축 위(양수)에 있습니다.

예제

−x² + x + 6 ≥ 0을 푸세요.

  1. 양변에 −1을 곱해 x²의 계수를 양수로: x² − x − 6 ≤ 0 (방향이 바뀜)
  2. (x + 2)(x − 3) ≤ 0
  3. 두 근 사이이므로 −2 ≤ x ≤ 3

답: −2 ≤ x ≤ 3

문제 5

−x² + 2x + 3 > 0의 해는 ＿＿＿ < x < ＿＿＿

판별식이 0 이하일 때

x² − 4x + 4 = (x − 2)²처럼 완전제곱식이면 항상 0 이상입니다.

판별식이 음수이면 x² + 2x + 5처럼 항상 양수입니다.

왜 항상 양수일까요? x² + 2x + 5 = (x + 1)² + 4로 바꾸면 (x + 1)² ≥ 0이므로 전체는 4 이상입니다. 판별식이 음수이면 그래프가 x축과 만나지 않고 항상 x축 위에 있습니다.

항상 성립할 조건

x² + bx + c > 0이 모든 실수 x에 대해 성립하려면 판별식 D < 0이어야 합니다.

해가 α < x < β인 이차부등식은 (x − α)(x − β) < 0입니다.

모든 x에서 양수라는 것은 그래프가 x축과 한 번도 만나지 않는다는 뜻입니다. 이차방정식이 실근을 갖지 않아야 하므로 D < 0이 조건이 됩니다(≥ 0이면 D ≤ 0).

예제

x² + 2kx + k + 2 > 0이 모든 실수 x에 대해 성립하는 k의 범위를 구하세요.

  1. 모든 x에서 양수 ⇔ D < 0
  2. D/4 = k² − (k + 2) = k² − k − 2 < 0
  3. (k + 1)(k − 2) < 0에서 −1 < k < 2

답: −1 < k < 2

연립이차부등식

각각의 해를 수직선에 나타내 공통 범위를 찾습니다.

연립부등식은 여러 조건을 동시에 만족해야 하므로 해의 교집합입니다. 각 부등식의 해를 한 수직선 위에 겹쳐 그리면 공통 범위를 빠르게 찾을 수 있습니다.

예제

x² − 2x − 3 > 0과 x² − 9 ≤ 0을 동시에 만족하는 x의 범위를 구하세요.

  1. 첫째: (x + 1)(x − 3) > 0에서 x < −1 또는 x > 3
  2. 둘째: (x + 3)(x − 3) ≤ 0에서 −3 ≤ x ≤ 3
  3. 공통부분: −3 ≤ x < −1 (x > 3과 x ≤ 3은 겹치지 않음)

답: −3 ≤ x < −1
