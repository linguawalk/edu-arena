선분의 내분점과 중점

수직선 위의 내분점

선분 AB 위의 점 P가 AP : PB = m : n일 때 P는 AB를 m : n으로 내분한다고 합니다.

A(a), B(b)이면 P = (mb + na)/(m + n). 중점은 (a + b)/2입니다.

왜 (mb + na)/(m + n)일까요? P는 A에서 B 쪽으로 전체 길이의 m/(m + n)만큼 간 점이므로 a + (b − a) × m/(m + n)입니다. 이를 정리하면 (mb + na)/(m + n)이 됩니다. m이 b에 곱해지는 것에 주의합니다.

좌표평면 위의 내분점

x좌표와 y좌표를 따로 내분하면 됩니다.

A(x₁, y₁), B(x₂, y₂)의 중점은 ((x₁ + x₂)/2, (y₁ + y₂)/2)입니다.

좌표평면에서는 가로 방향과 세로 방향의 움직임이 서로 독립이라, x좌표와 y좌표를 각각 수직선에서처럼 내분하면 됩니다. 중점은 1 : 1로 내분한 특별한 경우입니다.

예제

A(−2, 5), B(4, −1)을 1 : 2로 내분하는 점을 구하세요.

  1. x좌표: (1 × 4 + 2 × (−2))/(1 + 2) = 0/3 = 0
  2. y좌표: (1 × (−1) + 2 × 5)/3 = 9/3 = 3
  3. 내분점 (0, 3)

답: (0, 3)

삼각형의 무게중심

세 꼭짓점이 (x₁, y₁), (x₂, y₂), (x₃, y₃)인 삼각형의 무게중심은 ((x₁ + x₂ + x₃)/3, (y₁ + y₂ + y₃)/3)입니다.

무게중심은 각 중선을 꼭짓점에서부터 2 : 1로 내분합니다.

무게중심은 세 꼭짓점 좌표의 평균입니다. 종이로 삼각형을 오려 이 점을 손끝에 올리면 균형을 잡는다고 해서 무게중심이라고 부릅니다.

예제

세 점 (2, 1), (−1, 4), (5, 7)을 꼭짓점으로 하는 삼각형의 무게중심을 구하세요.

  1. x좌표의 평균: (2 − 1 + 5)/3 = 2
  2. y좌표의 평균: (1 + 4 + 7)/3 = 4
  3. 무게중심 (2, 4)

답: (2, 4)

중점의 활용

평행사변형의 두 대각선은 서로를 이등분하므로 두 대각선의 중점이 같습니다.

중점과 한 끝점을 알면 다른 끝점을 거꾸로 구할 수 있습니다.

평행사변형 ABCD에서 AC와 BD의 중점이 같다는 조건을 식으로 쓰면 A + C = B + D(좌표끼리)입니다. 그래서 D = A + C − B로 네 번째 꼭짓점을 바로 구할 수 있습니다.

예제

평행사변형 ABCD에서 A(1, 2), B(5, 3), C(6, 7)일 때 D를 구하세요.

  1. 두 대각선의 중점이 같으므로 A + C = B + D
  2. D = A + C − B = (1 + 6 − 5, 2 + 7 − 3)
  3. = (2, 6)

답: D(2, 6)

비율로 위치 정하기

내분점은 A에서 B 쪽으로 전체의 m/(m + n)만큼 간 점입니다.

내분점을 '비율로 걸어간 위치'로 이해하면 공식을 잊어도 구할 수 있습니다. 1 : 3이면 A에서 B까지 전체 길이의 1/4 지점이므로, A의 좌표에 (B − A) × 1/4을 더하면 됩니다.
