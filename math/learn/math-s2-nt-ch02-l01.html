정수해가 있을 조건

정수해를 구하는 방정식을 디오판토스 방정식이라 합니다. 일차 방정식 ax + by = c는 gcd(a, b) | c일 때, 그리고 그때만 정수해를 가집니다(베주 항등식).

6x + 9y = 100은 gcd(6, 9) = 3이 100을 나누지 않으므로 정수해가 없습니다. 왼쪽은 언제나 3의 배수이기 때문입니다.

해가 하나 (x₀, y₀) 있으면 모든 해는 x = x₀ + (b/d)t, y = y₀ − (a/d)t (d = gcd(a, b), t는 정수)입니다.

문제 1

6x + 9y = 100의 정수해는 몇 개인가요?

문제 2

ax + by = c가 정수해를 가질 필요충분조건은 gcd(a, b)가 ＿＿＿를 나누는 것입니다.

확장 유클리드 호제법

13x + 8y = 1의 해: 13 = 8 + 5, 8 = 5 + 3, 5 = 3 + 2, 3 = 2 + 1로 호제법을 한 뒤 거꾸로 올라갑니다.

1 = 3 − 2 = 3 − (5 − 3) = 2 × 3 − 5 = 2(8 − 5) − 5 = 2 × 8 − 3 × 5 = 2 × 8 − 3(13 − 8) = 5 × 8 − 3 × 13. 그래서 (x, y) = (−3, 5)입니다.

모든 해는 x = −3 + 8t, y = 5 − 13t이고, 예를 들어 t = 1이면 (5, −8)입니다.

예제

3x + 5y = 47의 양의 정수해를 모두 구하세요.

  1. 47 − 3x가 5의 배수여야 하므로 3x ≡ 47 ≡ 2 (mod 5), 곧 x ≡ 4 (mod 5)입니다.
  2. x = 4, 9, 14, …이고 y = (47 − 3x)/5 > 0이어야 합니다.
  3. x = 4 → y = 7, x = 9 → y = 4, x = 14 → y = 1, x = 19 → y < 0입니다.
  4. 양의 정수해는 (4, 7), (9, 4), (14, 1)의 3개입니다.

답: 3개

문제 3

3x + 5y = 47의 양의 정수해는 몇 개인가요?

문제 4

13x + 8y = 1의 정수해 가운데 x가 가장 작은 양수인 해의 x는?

해의 개수 세기

양의 정수해의 개수는 x의 범위를 정한 뒤 등차수열로 셉니다. x는 b/d 간격으로 나타나고, y > 0이 되는 범위에서 끊습니다.

4x + 6y = 50은 양변을 2로 나누어 2x + 3y = 25입니다. x ≡ 2 (mod 3)이므로 x = 2, 5, 8, 11이고 y = 7, 5, 3, 1입니다. 4개입니다.

먼저 gcd로 나누어 간단히 하면 간격을 바르게 셀 수 있습니다.

문제 7

7x + 11y = 100의 양의 정수해에서 x + y는?

정리

ax + by = c는 gcd(a, b) | c일 때만 정수해를 가지며, 한 해 (x₀, y₀)에서 모든 해는 x = x₀ + (b/d)t, y = y₀ − (a/d)t입니다.

특수해는 확장 유클리드 호제법을 거꾸로 올라가 구합니다(13 × (−3) + 8 × 5 = 1).

양의 정수해는 합동식으로 x의 나머지를 정하고, y > 0인 범위에서 등차수열로 셉니다. 먼저 gcd로 나누어 간단히 합니다.
