등비수열의 극한

미적분 · 5. 수열의 극한과 급수 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

rⁿ의 극한

|r| < 1이면 rⁿ → 0, r = 1이면 1, r > 1이면 발산, r ≤ −1이면 진동합니다.

그래서 rⁿ이 수렴할 조건은 −1 < r ≤ 1입니다.

왜 이렇게 나뉠까요? |r| < 1이면 곱할 때마다 절댓값이 줄어 0에 가까워집니다(0.5, 0.25, 0.125, …). r > 1이면 곱할 때마다 커져 발산합니다. r = −1이면 −1, 1을 오가며 진동하고, r < −1이면 부호가 바뀌며 절댓값이 커집니다. r = 1일 때만 1로 일정합니다.

수열 2ⁿ은 수렴할까요? (그렇다 1, 아니다 0)

분수 꼴

밑의 절댓값이 가장 큰 거듭제곱으로 분모, 분자를 나누면 나머지는 0으로 갑니다.

3ⁿ과 2ⁿ은 모두 커지지만 3ⁿ이 훨씬 빨리 커집니다. 3ⁿ으로 나누면 2ⁿ/3ⁿ = (2/3)ⁿ → 0이 되어 사라지고, 3ⁿ⁺¹/3ⁿ = 3처럼 가장 큰 밑의 항만 남습니다. 이것이 '가장 큰 밑이 극한을 결정한다'는 뜻입니다.

예제

lim(n→∞) (5ⁿ⁺¹ − 3ⁿ)/(5ⁿ + 4ⁿ)을 구하세요.

  1. 가장 큰 밑 5ⁿ으로 분모, 분자를 나눕니다.
  2. 분자: 5 − (3/5)ⁿ, 분모: 1 + (4/5)ⁿ
  3. (3/5)ⁿ, (4/5)ⁿ → 0
  4. = 5/1 = 5

답: 5

수렴 조건

(x − 1)ⁿ이 수렴하려면 −1 < x − 1 ≤ 1이어야 합니다.

rⁿ이 수렴할 조건 −1 < r ≤ 1에서 r 자리에 주어진 식을 넣어 부등식을 풉니다. 오른쪽 끝은 등호(r = 1 포함), 왼쪽 끝은 등호 없음(r = −1 제외)이라는 비대칭에 주의하세요. 부등식을 풀 때는 세 변에 같은 계산을 동시에 합니다.

예제

수열 ((2x − 1)/3)ⁿ이 수렴하는 x의 범위를 구하세요.

  1. 수렴 조건: −1 < (2x − 1)/3 ≤ 1
  2. −3 < 2x − 1 ≤ 3
  3. −2 < 2x ≤ 4
  4. −1 < x ≤ 2

답: −1 < x ≤ 2

문제 8

수열 (x/3)ⁿ이 수렴하는 정수 x는 몇 개일까요?

극한으로 정의된 함수

f(x) = lim xⁿ/(1 + xⁿ)처럼 x의 범위에 따라 xⁿ의 극한이 달라지면 범위를 나눠 계산합니다.

xⁿ의 극한은 |x| < 1이면 0, x = 1이면 1, |x| > 1이면 발산이므로, 식 속의 xⁿ이 어떻게 되는지 범위마다 따로 계산합니다. |x| > 1이면 분모, 분자를 xⁿ으로 나눠 1/xⁿ → 0을 이용합니다. 그 결과 함수는 경계에서 끊기는 경우가 많습니다.

예제

f(x) = lim(n→∞) (x²ⁿ⁺¹ + 1)/(x²ⁿ + 1)에서 f(1/2), f(1), f(3)을 구하세요.

  1. |x| < 1: x²ⁿ → 0이므로 f(x) = 1 → f(1/2) = 1
  2. x = 1: (1 + 1)/(1 + 1) = 1
  3. |x| > 1: x²ⁿ으로 나누면 (x + 1/x²ⁿ)/(1 + 1/x²ⁿ) → x → f(3) = 3
  4. 주의: 범위마다 극한이 다릅니다.

답: 1, 1, 3

정리

밑이 1보다 작은 거듭제곱은 사라지고, 가장 큰 밑이 극한을 결정합니다.

등비수열의 극한 문제는 결국 '어떤 밑이 가장 큰가'를 보는 것입니다. 분모와 분자에서 절댓값이 가장 큰 밑의 거듭제곱을 찾아 나누고, 나머지는 0으로 보내면 됩니다. 지수가 n + 1처럼 되어 있으면 먼저 3ⁿ⁺¹ = 3 × 3ⁿ처럼 분리합니다.
