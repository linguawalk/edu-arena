부분적분

곱의 미분법을 거꾸로 하면 ∫ f(x)g′(x) dx = f(x)g(x) − ∫ f′(x)g(x) dx입니다.

미분하면 간단해지는 것을 f(다항식, ln x), 적분하기 쉬운 것을 g′(eˣ, sin x, cos x)으로 고릅니다.

왜 성립할까요? 곱의 미분 (fg)′ = f′g + fg′의 양변을 적분하면 fg = ∫ f′g dx + ∫ fg′ dx이고, 이를 정리하면 공식이 나옵니다. 핵심은 '어려운 적분 ∫ fg′'을 '쉬운 적분 ∫ f′g'로 바꾸는 것입니다. 그래서 미분하면 간단해지는 쪽을 f로 고릅니다.

예제

∫ x sin x dx를 구하세요.

  1. f = x (미분하면 1), g′ = sin x (적분하면 −cos x)
  2. −x cos x − ∫ 1 × (−cos x) dx
  3. = −x cos x + ∫ cos x dx
  4. = −x cos x + sin x + C

답: −x cos x + sin x + C

로그함수의 적분

∫ ln x dx는 ln x × 1로 보고 f = ln x, g′ = 1로 부분적분하면 x ln x − x + C입니다.

ln x는 적분 공식이 바로 없지만 미분하면 1/x로 간단해집니다. 그래서 곱해진 것이 없어도 1을 곱한 것으로 보고 f = ln x, g′ = 1로 부분적분합니다. 그러면 x ln x − ∫ x × (1/x) dx = x ln x − x + C가 됩니다.

예제

∫₁ᵉ x² ln x dx를 구하세요.

  1. f = ln x, g′ = x² (g = x³/3)
  2. [(x³/3) ln x]₁ᵉ − ∫₁ᵉ (x³/3)(1/x) dx = e³/3 − ∫₁ᵉ x²/3 dx
  3. ∫₁ᵉ x²/3 dx = (e³ − 1)/9
  4. e³/3 − (e³ − 1)/9 = (2e³ + 1)/9

답: (2e³ + 1)/9

정적분의 부분적분

∫ₐᵇ fg′ dx = [fg]ₐᵇ − ∫ₐᵇ f′g dx

정적분에서도 같은 공식을 쓰되, fg 부분은 바로 위끝과 아래끝을 넣어 계산하고, 남은 적분은 따로 계산합니다. 두 부분의 부호를 헷갈리지 않도록 [fg] − ∫ f′g 형태를 그대로 적어 두는 것이 좋습니다. 특히 g가 −cos x처럼 음수 부호를 가질 때 주의합니다.

두 번 하는 부분적분

x²eˣ처럼 다항식의 차수가 2이면 부분적분을 두 번 합니다.

다항식은 미분할 때마다 차수가 하나씩 줄어듭니다. x²eˣ는 한 번 부분적분하면 2xeˣ의 적분이 남고, 한 번 더 하면 상수와 eˣ의 적분만 남습니다. 다항식의 차수만큼 반복하면 됩니다. 결과는 (다항식) × eˣ 꼴이 되고, 다항식의 계수는 부호가 번갈아 바뀝니다.

되돌아오는 부분적분

eˣ sin x처럼 두 번 부분적분하면 처음 적분이 다시 나오는 경우, 그것을 미지수로 놓고 풉니다.

eˣ와 sin x는 미분해도 적분해도 사라지지 않아 부분적분을 계속해도 끝나지 않습니다. 대신 두 번 하면 처음과 같은 적분이 다시 나타나므로, I = … − I 꼴의 방정식이 되어 I를 구할 수 있습니다.

예제

∫ eˣ cos x dx를 구하세요.

  1. I = ∫ eˣ cos x dx = eˣ sin x − ∫ eˣ sin x dx
  2. ∫ eˣ sin x dx = −eˣ cos x + ∫ eˣ cos x dx = −eˣ cos x + I
  3. I = eˣ sin x + eˣ cos x − I
  4. I = eˣ(sin x + cos x)/2 + C

답: eˣ(sin x + cos x)/2 + C
