공간에서의 거리

두 점 (x₁, y₁, z₁), (x₂, y₂, z₂) 사이의 거리는 √((x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)²)입니다.

공간의 거리 공식은 평면의 공식에 z 성분이 하나 추가된 것입니다. 두 점을 대각선의 양 끝으로 하는 직육면체를 생각하면, 가로·세로·높이가 각 좌표의 차이이고 대각선의 길이가 두 점 사이의 거리입니다. 피타고라스 정리를 두 번 쓴 결과입니다.

내분점과 중점

평면과 같이 각 좌표를 따로 내분합니다. 중점은 각 좌표의 평균입니다.

공간에서도 x, y, z 방향의 움직임은 서로 독립이라, 각 좌표를 따로 내분하면 됩니다. 공식 (mx₂ + nx₁)/(m + n)을 세 좌표에 똑같이 적용합니다. 위치벡터로 쓰면 (mb + na)/(m + n)으로 평면과 완전히 같습니다.

예제

A(−1, 2, 5), B(5, −4, 2)를 2 : 1로 내분하는 점과 AB의 길이를 구하세요.

  1. x: (2 × 5 + 1 × (−1))/3 = 3
  2. y: (2 × (−4) + 2)/3 = −2, z: (2 × 2 + 5)/3 = 3
  3. 내분점 (3, −2, 3)
  4. AB = √(36 + 36 + 9) = 9

답: (3, −2, 3), 9

무게중심

세 꼭짓점의 각 좌표를 더해 3으로 나눕니다.

무게중심은 세 꼭짓점의 좌표를 각각 평균한 점입니다. 평면에서와 같은 이유로, 중선을 2 : 1로 내분하는 점이 세 꼭짓점의 평균과 일치합니다. 사면체의 무게중심은 네 꼭짓점의 좌표를 평균합니다. 무게중심은 도형의 균형점이라 물리에서 질량중심을 구할 때도 같은 계산을 합니다.

거리 조건

두 점에서 같은 거리에 있는 점은 거리의 제곱이 같다는 식으로 구합니다.

두 점에서 같은 거리에 있다는 조건은 거리의 제곱을 같게 놓아 근호를 없앱니다. 전개하면 x², y², z²이 양변에서 지워져 일차식이 남습니다. 공간에서 두 점에서 같은 거리에 있는 점들은 두 점을 잇는 선분의 수직이등분면을 이룹니다.

예제

두 점 A(1, 0, 2), B(3, 2, 0)에서 같은 거리에 있는 z축 위의 점을 구하세요.

  1. 점 P(0, 0, z)로 놓음
  2. PA² = 1 + 0 + (z − 2)², PB² = 9 + 4 + z²
  3. 1 + z² − 4z + 4 = 13 + z²에서 −4z = 8
  4. z = −2, P(0, 0, −2)

답: (0, 0, −2)

정리

공간의 거리 공식은 평면의 공식에 z 성분만 더한 것입니다.

평면에서 배운 거리, 내분점, 무게중심의 공식이 공간에서도 성분 하나를 더해 그대로 성립합니다. 새 공식을 외우기보다 '평면 공식 + z 성분'으로 기억하면 됩니다. 계산 결과의 z 성분이 0이면 평면의 공식과 같은 답이 나오는지 확인해 보면 검산이 됩니다.

예제

세 점 A(1, 1, 0), B(3, 5, 2), C(2, 0, 4)로 만든 삼각형의 무게중심 G와 AG의 길이를 구하세요.

  1. G = ((1 + 3 + 2)/3, (1 + 5 + 0)/3, (0 + 2 + 4)/3)
  2. = (2, 2, 2)
  3. AG = √(1 + 1 + 4)
  4. = √6

답: G(2, 2, 2), √6
