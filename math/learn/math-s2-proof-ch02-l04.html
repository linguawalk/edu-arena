최댓값·최솟값 답안

부등식과 등호, 두 가지를 모두

'최솟값이 m이다'를 증명하려면 두 가지를 보여야 합니다. ① 모든 경우에 값 ≥ m이다(하한) ② 실제로 값 = m이 되는 경우가 있다(등호 성립).

x > 0일 때 x + 1/x의 최솟값: 산술-기하 평균 부등식으로 x + 1/x ≥ 2√(x · 1/x) = 2이고, x = 1이면 등호가 성립하므로 최솟값은 2입니다.

②를 빠뜨리면 '2보다 작지 않다'만 보인 것이라 최솟값이 2라는 결론이 되지 않습니다. 실제 최솟값이 3일 수도 있기 때문입니다.

문제 2

최솟값을 증명할 때는 하한을 보인 뒤 그 값이 실제로 나오는 경우, 곧 ＿＿＿ 조건을 보여야 합니다.

등호가 안 되는 부등식

x ≥ 2일 때 x + 1/x의 최솟값을 산술-기하 평균으로 구하면 ≥ 2이지만, 등호 조건 x = 1이 범위 밖이라 2는 나오지 않습니다.

이때는 다른 방법을 씁니다. f(x) = x + 1/x는 x ≥ 1에서 증가하므로 x = 2에서 최소이고 최솟값은 2 + 1/2 = 5/2입니다.

그래서 부등식을 쓰기 전에 '등호 조건이 주어진 범위 안에 있는가'를 먼저 확인합니다.

예제

x ≥ 3일 때 x + 9/x의 최솟값을 구하세요.

  1. 산술-기하 평균으로 x + 9/x ≥ 2√9 = 6이고 등호는 x = 3일 때입니다.
  2. x = 3은 범위 x ≥ 3 안에 있습니다.
  3. x = 3이면 3 + 3 = 6이 실제로 나옵니다.
  4. 그래서 최솟값은 6입니다.

곱이 일정하면 합의 최소, 합이 일정하면 곱의 최대

양수 a, b에서 ab가 일정하면 a + b는 a = b일 때 가장 작고, a + b가 일정하면 ab는 a = b일 때 가장 큽니다(산술-기하 평균).

a + b = 10인 양수에서 ab ≤ (10/2)² = 25이고 a = b = 5일 때 등호입니다.

변수가 정수로 제한되면 '가장 고른 정수 배분'에서 극값이 나옵니다(앞 레슨의 abc 최댓값).

정리

최댓값·최솟값 답안은 ① 모든 경우의 부등식(상한·하한)과 ② 그 값이 실제로 나오는 등호 조건을 모두 보여야 합니다.

부등식을 쓰기 전에 등호 조건이 주어진 범위 안에 있는지 확인하고, 범위 밖이면 함수의 증감 같은 다른 방법을 씁니다.

합이 일정하면 곱은 고를 때 최대, 곱이 일정하면 합은 고를 때 최소이며, 답안 끝에 '등호는 … 일 때 성립한다'를 꼭 씁니다.
