유리수와 무리수를 합쳐 실수라고 합니다.

실수는 수직선 위의 점과 하나씩 빠짐없이 대응합니다.

왜 '빠짐없이'일까요? 유리수만으로는 수직선에 구멍이 남습니다. 한 변이 1인 정사각형의 대각선 길이 √2에 해당하는 점은 어떤 분수로도 나타낼 수 없기 때문입니다. 무리수가 그 구멍을 모두 메워 실수가 됩니다.

절댓값을 식으로

a ≥ 0이면 |a| = a, a < 0이면 |a| = −a입니다.

그래서 √(a²) = |a|입니다. 제곱근은 음수가 될 수 없기 때문입니다.

왜 a < 0일 때 −a일까요? 절댓값은 0에서의 거리라 항상 0 이상이어야 합니다. a가 음수이면 앞에 −를 붙여야 양수가 됩니다. 예를 들어 a = −3이면 −a = 3입니다.

예제

x = −4일 때 |x + 1| − |x − 2|를 계산하세요.

  1. x + 1 = −3이므로 |x + 1| = 3
  2. x − 2 = −6이므로 |x − 2| = 6
  3. 3 − 6 = −3
  4. 주의: 절댓값 기호 안의 값을 먼저 계산한 뒤 부호를 정합니다.

답: −3

분모의 유리화

분모에 근호가 있으면 분모와 분자에 같은 수를 곱해 분모를 유리수로 바꿉니다.

1/√a = √a/a, 1/(√a + √b) = (√a − √b)/(a − b)

왜 이렇게 할까요? 분모에 √가 있으면 크기를 어림하거나 다른 수와 더하기가 불편합니다. (√a + √b)(√a − √b) = a − b처럼 근호가 사라지는 곱을 이용해 분모를 정수로 만듭니다.

예제

3/(√5 − √2)의 분모를 유리화하세요.

  1. 분모의 켤레 √5 + √2를 분모와 분자에 곱합니다.
  2. 분모: (√5 − √2)(√5 + √2) = 5 − 2 = 3 (합차 공식)
  3. 분자: 3(√5 + √2)
  4. 3(√5 + √2)/3 = √5 + √2

답: √5 + √2

크기 비교와 정수 부분

양수끼리는 제곱해서 비교할 수 있습니다.

√7은 2와 3 사이에 있으므로 정수 부분은 2, 소수 부분은 √7 − 2입니다.

왜 제곱해서 비교할 수 있을까요? 양수에서는 큰 수의 제곱이 더 크고, 작은 수의 제곱이 더 작습니다. 그래서 양수 두 개의 크기 순서는 제곱해도 그대로 유지됩니다.

예제

2√3과 3√2 중 더 큰 수를 고르고, 2√3의 정수 부분을 구하세요.

  1. 제곱해서 비교: (2√3)² = 12, (3√2)² = 18
  2. 12 < 18이므로 3√2가 더 큽니다.
  3. 2√3 = √12이고 9 < 12 < 16이므로 3 < √12 < 4
  4. 정수 부분은 3

답: 3√2가 더 크고, 2√3의 정수 부분은 3
