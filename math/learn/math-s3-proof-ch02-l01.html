모의고사 진행 방법

이 모의고사는 이틀로 나뉩니다. 1일차 문제 1~3, 2일차 문제 4~6을 각각 4시간 30분 동안 책, 계산기, 인터넷 없이 종이와 필기구만으로 풉니다. 가능하면 실제 대회처럼 오전에 시작하세요.

시간이 끝나면 답안을 고치지 말고 그대로 둔 채, 이 가이드에서 각 문제의 '증명 쓰기' 칸에 답안을 옮기거나 빈칸으로 두고 모범 증명과 채점 기준(7점 만점)으로 스스로 채점합니다.

난이도는 문제 1·4가 IMO 1·4번, 문제 2·3·5·6이 그보다 조금 어려운 수준입니다. 각 날의 첫 문제는 1시간 안에 완전하게 쓰는 것을 목표로 하세요.

채점 원칙

모범 증명과 다른 방법이어도 논리적으로 완전하면 7점입니다. 채점 기준의 항목은 '모범 증명에서 이 단계에 해당하는 내용'을 뜻하므로, 다른 방법이면 같은 무게의 단계가 있는지 보고 점수를 줍니다.

답만 맞히거나 작은 경우를 확인한 것은 0~1점입니다. 핵심 아이디어를 찾았지만 정리하지 못했으면 2~3점, 사소한 빈틈(경우 하나 빠짐, 확인 생략)이 있으면 5~6점이 일반적입니다.

스스로 채점할 때는 관대하지 않게 합니다. '이 줄은 당연하다'고 넘어간 곳이 있다면 실제 답안에 그 근거가 쓰여 있는지 확인하세요.

문제 1

이 모의고사의 1일차 만점은 몇 점인가요?

예제

채점 연습: 문제 6에서 'f(0) = 0이고 f는 홀함수다'까지만 쓰고 시간이 끝난 답안은 몇 점일까요?

  1. 문제 6의 채점 기준은 'f(0) = 0과 홀함수(2점)', 'y = ±1 대입(2점)', 'f(x) = cx 도출(2점)', '확인(1점)'입니다.
  2. 이 답안은 첫 항목만 완전하게 해냈으므로 2점입니다.
  3. 답 'f(x) = cx'를 짐작해 적어 두었더라도, 그것만이 해임을 보이지 않았으면 점수가 더해지지 않습니다. 짐작한 답은 확인 단계와 함께여야 의미가 있습니다.

답: 2점

문제 2

[1일차 · 문제 1 · A] 양의 실수 a, b, c가 a + b + c = 3을 만족할 때 다음을 증명하세요.

a²/(a + 2b) + b²/(b + 2c) + c²/(c + 2a) ≥ 1

문제 3

[1일차 · 문제 2 · C] 칠판에 1, 2, …, 100이 적혀 있습니다. 두 수 a, b를 지우고 ab + a + b를 적는 일을 수가 하나 남을 때까지 되풀이합니다. 마지막 수는 지우는 순서와 상관없이 101! − 1임을 증명하세요.

문제 4

[1일차 · 문제 3 · G] 예각삼각형 ABC의 수심을 H, 변 BC의 중점을 M이라 합니다. H를 M에 대해 대칭시킨 점 H'은 삼각형 ABC의 외접원 위에 있고, AH'은 외접원의 지름임을 증명하세요.

예제

문제 2에서 수가 1, 2, 3, 4뿐이라면 마지막 수는 얼마인지 두 가지 순서로 확인하세요.

  1. 순서 1: (1, 2) → 1·2 + 1 + 2 = 5, (5, 3) → 15 + 8 = 23, (23, 4) → 92 + 27 = 119입니다.
  2. 순서 2: (3, 4) → 12 + 7 = 19, (1, 2) → 5, (5, 19) → 95 + 24 = 119입니다.
  3. 두 순서 모두 119이고, 불변량으로는 (1 + 1)(2 + 1)(3 + 1)(4 + 1) − 1 = 5! − 1 = 119입니다.

답: 119

문제 5

문제 2에서 칠판의 수가 1부터 5까지라면 마지막 수는 얼마인가요?

2일차 안내

2일차는 1일차와 다른 날 같은 시간에 시작하세요. 1일차 답안의 채점은 2일차를 마친 뒤에 함께 하는 것이 실제 대회와 비슷합니다. 1일차 점수를 미리 알면 2일차의 시간 배분이 흔들릴 수 있기 때문입니다.

문제 4는 정수론의 첫 문제로, 작은 경우를 몇 개 계산해 답을 짐작한 뒤 홀짝과 나머지로 나머지 경우를 없애는 전형적인 형태입니다. 문제 5와 6은 각각 조합과 대수에서 귀납법과 대입 전략을 묻습니다.

시작 후 15분 동안은 세 문제를 모두 읽고 작은 경우를 손으로 실험하세요. 어느 문제에 먼저 시간을 쓸지는 그 실험 결과로 정합니다.

모의고사 뒤의 점검

점수를 문제별로 적고, 7점이 아닌 문제마다 '무엇이 빠졌나'를 한 줄로 씁니다. 아이디어를 못 찾은 것인지, 찾았지만 정리하지 못한 것인지, 마지막 확인을 빠뜨린 것인지 구별하세요.

아이디어를 못 찾은 분야는 S3 분야별 가이드로 돌아가고, 정리하지 못한 문제는 모범 증명을 보지 않고 다음 날 다시 써 봅니다. 확인을 빠뜨린 문제는 답안 끝에 '확인' 단락을 쓰는 습관을 들이세요.

같은 형식의 모의고사를 한 달에 한두 번 치르면 시간 배분 감각이 생깁니다. 다른 모의고사 문제는 IMO 예비 문제(Shortlist)나 각국 대회 문제 모음에서 고를 수 있습니다.

문제의 정답과 해설, 힌트는 레슨을 풀면서 확인할 수 있습니다.
