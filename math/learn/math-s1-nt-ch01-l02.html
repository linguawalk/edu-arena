최대공약수를 빠르게 구하기

a = bq + r이면 gcd(a, b) = gcd(b, r)입니다. 그래서 큰 수를 작은 수로 나눈 나머지로 바꾸는 일을 반복하면 최대공약수가 나옵니다. 이것을 유클리드 호제법이라고 합니다.

gcd(252, 198)은 252 = 198 + 54, 198 = 3 × 54 + 36, 54 = 36 + 18, 36 = 2 × 18이므로 18입니다.

소인수분해로 최대공약수를 구하는 방법은 수가 크면 매우 어렵습니다. 호제법은 나눗셈만 반복하므로 수가 커도 금방 끝나고, 무엇보다 문자가 들어 있는 식에도 그대로 쓸 수 있다는 장점이 있습니다. 올림피아드에서는 이 두 번째 장점이 더 중요합니다.

문제 1

gcd(252, 198)의 값은?

문제 2

252 = 198 + 54이므로 gcd(252, 198) = gcd(198, ＿＿＿)입니다.

왜 성립할까

a = bq + r일 때, d가 a와 b를 나누면 d | a − bq = r입니다. 반대로 d가 b와 r을 나누면 d | bq + r = a입니다.

그래서 (a, b)의 공약수와 (b, r)의 공약수는 정확히 같고, 가장 큰 것도 같습니다.

이 증명은 레슨 1의 일차결합 성질 하나로 끝납니다. 나눗셈을 할 때마다 나머지는 엄격히 작아지므로 언젠가 0이 되고, 그때 남은 수가 최대공약수입니다. 이 과정은 반드시 끝난다는 점까지 확인해야 알고리즘이 완성됩니다.

문제 3

'gcd(a, b) = gcd(b, a − bq)'의 증명을 올바른 순서로 배열하세요.

예제

gcd(1071, 462)를 구하세요.

  1. 1071 = 462 × 2 + 147입니다.
  2. 462 = 147 × 3 + 21입니다.
  3. 147 = 21 × 7 + 0입니다.
  4. 따라서 gcd(1071, 462) = 21입니다.

답: 21

문제 4

gcd(3289, 1729)의 값은?

문자가 든 식에서도

gcd(n² + 1, n + 1)을 구해 봅시다. n² + 1 = (n + 1)(n − 1) + 2이므로 gcd(n² + 1, n + 1) = gcd(n + 1, 2)입니다.

따라서 n이 홀수이면 2, 짝수이면 1입니다. 수가 아니라 식을 나누었지만 호제법은 똑같이 작동합니다.

연속한 두 정수 n, n + 1은 gcd(n + 1, n) = gcd(n, 1) = 1이므로 항상 서로소입니다. 이 사실은 앞으로 '연속한 두 수는 공통 소인수가 없다'는 형태로 매우 자주 씁니다. 식에서 호제법을 쓸 때는 나머지의 차수가 낮아지도록 몫을 고릅니다.

문제 6

모든 자연수 n에 대해 gcd(3n + 2, 5n + 3)의 값은?

거듭제곱과 피보나치 수

2ᵃ − 1 = 2ᵃ⁻ᵇ(2ᵇ − 1) + (2ᵃ⁻ᵇ − 1)이므로 gcd(2ᵃ − 1, 2ᵇ − 1) = gcd(2ᵇ − 1, 2ᵃ⁻ᵇ − 1)입니다. 지수만 보면 (a, b)가 (b, a − b)로 바뀌는 호제법과 같습니다.

그래서 gcd(2ᵃ − 1, 2ᵇ − 1) = 2^gcd(a, b) − 1입니다.

피보나치 수열에도 같은 성질 gcd(Fₘ, Fₙ) = F_gcd(m, n)이 있습니다. 두 결과 모두 '연산을 하고 나서 최대공약수를 구하는 것'과 '최대공약수를 구하고 나서 연산을 하는 것'이 같다는 뜻입니다. 지수가 큰 수의 최대공약수를 직접 계산하지 않고 지수의 최대공약수로 바로 구할 수 있습니다.

문제 8

피보나치 수 F₁₂ = 144, F₁₈ = 2584의 최대공약수는?

정리

a = bq + r이면 gcd(a, b) = gcd(b, r)입니다. 나머지가 0이 될 때까지 반복하면 마지막 0이 아닌 나머지가 최대공약수입니다.

호제법은 문자가 든 식에도 그대로 쓰이며, 나머지가 상수가 될 때까지 차수를 낮춥니다. 연속한 두 정수는 항상 서로소입니다.

gcd(2ᵃ − 1, 2ᵇ − 1) = 2^gcd(a, b) − 1, gcd(Fₘ, Fₙ) = F_gcd(m, n)처럼 구조가 호제법과 맞는 수열은 최대공약수가 지수의 최대공약수로 정해집니다.
