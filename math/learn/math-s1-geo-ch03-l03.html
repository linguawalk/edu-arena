세 변에서 같은 거리

삼각형의 세 내각의 이등분선은 한 점 I에서 만나고, I에서 세 변까지의 거리가 모두 같습니다. I를 내심, 그 거리 r을 내접원의 반지름이라고 합니다.

내심과 세 꼭짓점을 이으면 삼각형이 높이가 모두 r인 세 삼각형으로 나뉘므로 넓이 K = r(a + b + c)/2 = rs입니다. 여기서 s는 반둘레입니다.

그래서 r = K/s입니다. 3, 4, 5 직각삼각형이면 K = 6, s = 6이므로 r = 1입니다. 각의 이등분선 위의 점은 두 변에서 거리가 같다는 사실이 내심의 존재를 보장하고, 넓이를 세 조각으로 나누는 것이 r을 구하는 열쇠입니다.

문제 2

삼각형의 넓이 = r × ＿＿＿입니다. (r은 내접원의 반지름, s는 반둘레)

내심에서 보는 각

∠BIC = 90° + ∠A/2입니다. 삼각형 IBC에서 ∠IBC = ∠B/2, ∠ICB = ∠C/2이므로 ∠BIC = 180° − (∠B + ∠C)/2이고, ∠B + ∠C = 180° − ∠A를 넣으면 나옵니다.

∠A = 60°이면 ∠BIC = 120°입니다.

외심의 ∠BOC = 2∠A와 비교해 보세요. 외심은 원주각과 중심각, 내심은 각의 이등분으로 각을 계산합니다. 두 공식을 혼동하지 않도록, 문제에서 점이 '변에서 같은 거리'인지 '꼭짓점에서 같은 거리'인지 먼저 확인하세요.

예제

∠A = 60°인 삼각형 ABC의 내심을 I라 할 때 ∠BIC를 구하세요.

  1. ∠IBC = ∠B/2, ∠ICB = ∠C/2입니다.
  2. ∠B + ∠C = 180° − 60° = 120°이므로 ∠IBC + ∠ICB = 60°입니다.
  3. ∠BIC = 180° − 60°입니다.
  4. = 120°이고, 공식 90° + 60°/2와 같습니다.

답: 120°

문제 4

세 변이 13, 14, 15인 삼각형의 내접원의 반지름은?

접선 조각 다시 보기

챕터 2에서 본 것처럼, 내접원의 접점은 각 변을 s − a, s − b, s − c의 조각으로 나눕니다. 꼭짓점 A에서 내접원까지의 두 접선 조각은 모두 s − a입니다.

직각삼각형에서는 직각 꼭짓점의 접선 조각이 정사각형의 한 변이 되어 r = s − c = (a + b − c)/2입니다.

내심과 외심 사이의 거리는 오일러 공식 OI² = R² − 2Rr로 구할 수 있습니다. 증명은 S2에서 하지만, R ≥ 2r이라는 부등식이 바로 따라 나온다는 점이 흥미롭습니다. 등호는 정삼각형일 때만 성립합니다.

문제 7

세 변이 3, 4, 5인 삼각형의 외심을 O, 내심을 I라 할 때 OI²을 분수로 쓰세요. (OI² = R² − 2Rr)

정리

세 내각의 이등분선은 내심 I에서 만나고, I는 세 변에서 같은 거리 r에 있습니다. 넓이 K = rs이므로 r = K/s입니다.

∠BIC = 90° + ∠A/2입니다. 외심의 ∠BOC = 2∠A와 구분하세요.

접선 조각은 s − a, s − b, s − c이고, 직각삼각형에서 r = (a + b − c)/2입니다. OI² = R² − 2Rr에서 R ≥ 2r이 나옵니다.
