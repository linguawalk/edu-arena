특성방정식

aₙ₊₂ = paₙ₊₁ + qaₙ 꼴의 점화식은 특성방정식 t² = pt + q의 근으로 풉니다. 두 근 r, s가 서로 다르면 aₙ = A × rⁿ + B × sⁿ이고, A, B는 처음 두 항으로 정합니다.

예를 들어 aₙ₊₂ = 5aₙ₊₁ − 6aₙ의 특성방정식 t² − 5t + 6 = 0의 근은 2, 3이므로 aₙ = A × 2ⁿ + B × 3ⁿ입니다.

왜 rⁿ 꼴일까요? aₙ = rⁿ을 점화식에 넣으면 rⁿ⁺² = prⁿ⁺¹ + qrⁿ, 곧 r² = pr + q일 때 성립합니다. 그리고 점화식이 '선형'이라서 두 해의 일차결합도 다시 해가 됩니다. 처음 두 항만 맞추면 나머지 항은 점화식으로 저절로 맞으므로, 이 꼴이 유일한 답입니다.

문제 2

aₙ₊₂ = 5aₙ₊₁ − 6aₙ의 특성방정식 t² − 5t + 6 = 0의 근은 2와 ＿＿＿입니다.

예제

a₁ = 1, a₂ = 5, aₙ₊₂ = 5aₙ₊₁ − 6aₙ의 일반항을 구하세요.

  1. 특성방정식의 근이 2, 3이므로 aₙ = A × 2ⁿ + B × 3ⁿ입니다.
  2. n = 1: 2A + 3B = 1, n = 2: 4A + 9B = 5입니다.
  3. 첫 식에 2를 곱해 빼면 3B = 3, B = 1이고 A = −1입니다.
  4. 따라서 aₙ = 3ⁿ − 2ⁿ입니다.

답: aₙ = 3ⁿ − 2ⁿ

특성근이 중근일 때

특성방정식이 중근 r을 가지면 aₙ = (A + Bn)rⁿ입니다. 예를 들어 aₙ₊₂ = 4aₙ₊₁ − 4aₙ의 특성방정식 (t − 2)² = 0은 중근 2를 가지므로 aₙ = (A + Bn)2ⁿ입니다.

중근일 때는 rⁿ 하나로는 처음 두 항을 맞출 수 없어서 nrⁿ이라는 두 번째 해가 필요합니다.

nrⁿ이 해인지 확인해 봅시다. (n + 2)rⁿ⁺² − 2r(n + 1)rⁿ⁺¹ + r²nrⁿ = rⁿ⁺²{(n + 2) − 2(n + 1) + n} = 0입니다. 여기서 중근일 때 p = 2r, q = −r²임을 썼습니다. 미분방정식에서 중근일 때 xeʳˣ가 나오는 것과 같은 구조입니다.

문제 5

a₁ = 2, a₂ = 8, aₙ₊₂ = 4aₙ₊₁ − 4aₙ일 때 a₅의 값은?

세기 문제에서 점화식 세우기

길이 n인 0과 1의 문자열 중 1이 연속해서 나오지 않는 것의 개수를 f(n)이라 합시다. 마지막 글자가 0이면 앞의 n − 1글자는 조건만 맞으면 되고, 마지막이 1이면 그 앞은 반드시 0이어야 합니다.

그래서 f(n) = f(n − 1) + f(n − 2)이고, f(1) = 2, f(2) = 3입니다. 피보나치 수열과 같은 점화식입니다.

세기 문제에서 점화식을 세우는 요령은 '마지막 한 걸음'으로 경우를 나누는 것입니다. 2 × n 판을 도미노로 채우는 방법, 계단을 한 칸 또는 두 칸씩 오르는 방법도 같은 방식으로 피보나치 점화식이 나옵니다. 점화식을 세운 근거를 문장으로 쓰는 것이 답안의 핵심입니다.

문제 7

2 × 8 크기의 판을 1 × 2 도미노로 빈틈없이 채우는 방법은 몇 가지인가요?

정리

aₙ₊₂ = paₙ₊₁ + qaₙ은 특성방정식 t² = pt + q의 근으로 풉니다. 서로 다른 근 r, s이면 Arⁿ + Bsⁿ, 중근 r이면 (A + Bn)rⁿ입니다.

A, B는 처음 두 항으로 정하고, 얻은 일반항은 세 번째 항으로 검산합니다.

세기 문제는 마지막 한 걸음으로 경우를 나누어 점화식을 세웁니다. 점화식이 두 항 전까지 쓰므로, 일반항을 귀납법으로 증명할 때는 강한 귀납법과 두 개의 기저가 필요하다는 점도 증명의 기초 2장에서 본 그대로입니다.
