평면 운동의 이동 거리

위치가 (x(t), y(t))인 점이 t = a부터 b까지 움직인 거리는 ∫ₐᵇ √(x′² + y′²) dt입니다.

평면 운동의 속력은 √(x′² + y′²)이고, 짧은 시간 dt 동안 움직인 거리는 속력 × dt입니다. 이를 모두 더하면 이동 거리입니다. 점이 지나간 곡선의 길이와 같다고 생각할 수 있습니다(되돌아가지 않는 경우).

곡선의 길이

곡선 y = f(x)의 a ≤ x ≤ b 부분의 길이는 ∫ₐᵇ √(1 + {f′(x)}²) dx입니다. 짧은 직각삼각형의 빗변을 모두 더한 것입니다.

왜 √(1 + f′²)일까요? 곡선을 아주 짧게 잘라 직선으로 보면, 가로 dx, 세로 dy인 직각삼각형의 빗변 √(dx² + dy²)이 그 조각의 길이입니다. dx를 묶어 내면 √(1 + (dy/dx)²) dx이므로, 이를 모두 더한 적분이 곡선의 길이입니다.

예제

곡선 y = (1/2)x² (0 ≤ x ≤ 1)의 길이를 식으로 나타내고 직선과 비교하세요.

  1. y′ = x이므로 길이 = ∫₀¹ √(1 + x²) dx
  2. 양 끝 (0, 0)과 (1, 1/2)를 이은 선분의 길이 √(1 + 1/4) ≈ 1.118
  3. 곡선의 길이 ≈ 1.148 (적분의 근삿값)
  4. 곡선이 휘어 있어 선분보다 조금 깁니다.

답: ∫₀¹ √(1 + x²) dx ≈ 1.148

매개변수 곡선의 길이

x = f(t), y = g(t)로 나타낸 곡선의 길이도 ∫ √(x′² + y′²) dt입니다.

매개변수 곡선은 x, y가 모두 t로 주어지므로 빗변을 √(x′² + y′²) dt로 씁니다. 원 x = r cos t, y = r sin t는 속력이 r로 일정해서 한 바퀴의 길이가 2πr이 되는데, 원의 둘레 공식을 적분으로 확인한 것입니다.

예제

x = t − sin t, y = 1 − cos t (0 ≤ t ≤ 2π)의 길이를 구하세요.

  1. x′ = 1 − cos t, y′ = sin t
  2. 속력² = 2 − 2 cos t = 4 sin²(t/2), 속력 = 2 sin(t/2) (0 ≤ t ≤ 2π)
  3. ∫₀^(2π) 2 sin(t/2) dt = [−4 cos(t/2)]₀^(2π)
  4. = 4 + 4 = 8 (사이클로이드 한 아치의 길이)

답: 8

직선 운동의 이동 거리

수직선 위에서는 ∫|v(t)| dt가 이동 거리, ∫v(t) dt가 위치의 변화입니다.

수직선 위의 운동에서 위치의 변화와 이동 거리가 다른 이유는 방향이 바뀌기 때문입니다. v(t)의 부호가 바뀌는 시각을 찾아 구간을 나누고, 이동 거리는 각 구간의 절댓값을 더합니다. 평면 운동의 거리 공식은 항상 양수인 속력을 적분하므로 자동으로 절댓값이 처리됩니다.

예제

v(t) = cos t일 때 t = 0부터 t = π까지 위치의 변화와 이동 거리를 구하세요.

  1. 위치의 변화: ∫₀^π cos t dt = [sin t]₀^π = 0
  2. t = π/2에서 부호가 바뀜
  3. 거리: ∫₀^(π/2) cos t dt − ∫_(π/2)^π cos t dt = 1 + 1
  4. = 2

답: 위치 변화 0, 거리 2

정리

길이와 거리는 항상 '속력' 또는 '빗변'을 적분합니다.

넓이, 부피, 길이, 거리는 모두 '아주 작은 조각을 구해 모두 더한다'는 하나의 아이디어로 구합니다. 조각이 직사각형이면 넓이, 판이면 부피, 빗변이면 길이, 속력 × 시간이면 거리입니다. 이것이 적분의 핵심이며, 물리의 일과 에너지, 확률의 계산에서도 같은 생각이 쓰입니다.
