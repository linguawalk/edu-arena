두 소수의 기호를 뒤집기

이차 상호 법칙: 서로 다른 홀수 소수 p, q에 대해 (p/q)(q/p) = (−1)^(((p−1)/2)((q−1)/2))입니다.

곧 p, q 가운데 하나라도 1 (mod 4)이면 (p/q) = (q/p)이고, 둘 다 3 (mod 4)이면 (p/q) = −(q/p)입니다.

이 법칙으로 큰 소수의 기호를 작은 소수의 기호로 줄여 빠르게 계산합니다. 가우스가 '황금 정리'라 부르며 여러 가지로 증명했습니다.

(5/11)의 값은? (5 ≡ 1 (mod 4))

문제 2

서로 다른 홀수 소수 p, q에 대해 (p/q)와 (q/p)의 관계를 알려 주는 법칙을 이차 ＿＿＿ 법칙이라 합니다.

계산 순서

(7/19): 7 ≡ 19 ≡ 3 (mod 4)이므로 (7/19) = −(19/7) = −(5/7)입니다. 5 ≡ 1 (mod 4)이므로 (5/7) = (7/5) = (2/5) = −1입니다(5 ≡ −3 (mod 8)). 그래서 (7/19) = −(−1) = 1입니다.

순서: ① 위 수를 아래 수로 나눈 나머지로 줄인다 ② 2와 −1은 따로 처리한다 ③ 홀수 소수끼리는 상호 법칙으로 뒤집는다 ④ 반복한다.

답이 1이면 제곱근을 실제로 찾아 확인할 수 있습니다(8² = 64 ≡ 7 (mod 19)).

예제

(3/13)을 상호 법칙으로 구하세요.

  1. 13 ≡ 1 (mod 4)이므로 (3/13) = (13/3)입니다.
  2. 13 ≡ 1 (mod 3)이므로 (13/3) = (1/3)입니다.
  3. (1/3) = 1입니다.
  4. 그래서 (3/13) = 1입니다(4² = 16 ≡ 3).

답: 1

(3/p)의 규칙

상호 법칙으로 (3/p)의 규칙을 얻습니다. p ≡ 1 (mod 4)이면 (3/p) = (p/3), p ≡ 3 (mod 4)이면 (3/p) = −(p/3)입니다. (p/3)은 p ≡ 1 (mod 3)이면 1, 2이면 −1입니다.

두 조건을 합치면 (3/p) = 1 ⇔ p ≡ ±1 (mod 12)입니다. 예: 11, 13, 23, 37, 47, …

이렇게 상호 법칙은 '(a/p)가 p의 어떤 나머지에 따라 정해지는가'를 알려 줍니다.

정리

이차 상호 법칙: (p/q)(q/p) = (−1)^(((p−1)/2)((q−1)/2)). 하나라도 1 (mod 4)이면 (p/q) = (q/p), 둘 다 3 (mod 4)이면 부호가 바뀝니다.

계산: 나머지로 줄이기 → 2, −1, 제곱 인수 따로 처리 → 상호 법칙으로 뒤집기를 되풀이합니다.

(3/p) = 1 ⇔ p ≡ ±1 (mod 12)처럼, 상호 법칙으로 (a/p)가 p의 나머지에 따라 정해지는 규칙을 얻습니다.
