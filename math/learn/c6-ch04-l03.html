벡터의 성분

기하 · 4. 평면벡터 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

성분으로 나타내기

좌표평면에서 벡터를 a = (a₁, a₂)로 나타내고 크기는 |a| = √(a₁² + a₂²)입니다.

A(x₁, y₁), B(x₂, y₂)이면 AB = (x₂ − x₁, y₂ − y₁)입니다.

좌표평면에서 벡터를 성분으로 나타내면 '오른쪽으로 얼마, 위로 얼마'를 적은 것이 됩니다. AB = (x₂ − x₁, y₂ − y₁)은 A에서 B까지 가로로, 세로로 이동한 양입니다. 크기는 피타고라스 정리로 구합니다. 원점에서 시작하는 위치벡터는 끝점의 좌표와 성분이 같습니다.

성분으로 계산하기

덧셈, 뺄셈, 실수배는 성분끼리 계산합니다.

성분으로 계산하면 그림을 그리지 않아도 벡터를 다룰 수 있습니다. (1, 2) + (3, −1)은 '오른쪽 1, 위로 2' 가고 이어서 '오른쪽 3, 아래로 1' 간 것이므로 합해서 (4, 1)입니다. 기하 문제를 수의 계산으로 바꾸는 것이 성분의 힘입니다.

예제

A(2, −1), B(5, 3)일 때 AB의 성분과 크기, 같은 방향의 단위벡터를 구하세요.

  1. AB = (5 − 2, 3 − (−1)) = (3, 4)
  2. |AB| = √(9 + 16) = 5
  3. 단위벡터 AB/|AB| = (3/5, 4/5)
  4. 확인: (3/5)² + (4/5)² = 1

답: (3, 4), 5, (3/5, 4/5)

평행 조건

(a₁, a₂)와 (b₁, b₂)가 평행하면 성분의 비가 같습니다. a₁ : a₂ = b₁ : b₂

두 벡터가 평행하면 b = ka이므로 b₁ = ka₁, b₂ = ka₂입니다. 그래서 성분의 비가 같습니다. 비례식을 곱셈으로 바꾸면 a₁b₂ = a₂b₁로 쓸 수 있어 0이 들어간 경우에도 편리합니다.

예제

a = (2, −1), b = (k, 3)이 평행할 때 k를 구하세요.

  1. 평행 조건: 2 × 3 = (−1) × k
  2. 6 = −k
  3. k = −6
  4. 확인: b = (−6, 3) = −3a

답: −6

단위벡터

a와 같은 방향의 단위벡터는 a/|a|입니다.

a를 자신의 크기 |a|로 나누면 방향은 그대로이고 크기만 1이 됩니다. 이 단위벡터에 원하는 크기를 곱하면 '같은 방향으로 크기가 k인 벡터'를 만들 수 있습니다. 예를 들어 (3, 4)와 같은 방향으로 크기가 10인 벡터는 10 × (3/5, 4/5) = (6, 8)입니다. 반대 방향이 필요하면 −를 붙입니다.

정리

성분으로 나타내면 벡터 계산이 좌표 계산처럼 간단해집니다.

평행하지 않은 두 벡터 a, b가 있으면 평면의 모든 벡터를 pa + qb 꼴로 나타낼 수 있고, p, q는 하나로 정해집니다. 성분으로 쓰면 연립방정식을 풀어 p, q를 구합니다. 두 벡터가 평행하면 이런 표현이 불가능하므로, 먼저 평행하지 않은지 확인합니다.

예제

a = (1, 2), b = (3, −1)일 때 (5, 3)을 pa + qb로 나타내세요.

  1. 성분 비교: p + 3q = 5, 2p − q = 3
  2. 둘째 식에서 q = 2p − 3을 첫째에 대입: 7p − 9 = 5
  3. p = 2, q = 1
  4. (5, 3) = 2a + b

답: 2a + b
