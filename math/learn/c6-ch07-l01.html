공간의 점

서로 수직인 세 수직선 x축, y축, z축을 기준으로 공간의 점을 (x, y, z)로 나타냅니다.

두 축으로 정해지는 평면을 xy평면, yz평면, zx평면이라고 합니다.

평면의 점을 두 수 (x, y)로 나타냈듯이, 공간의 점은 세 수 (x, y, z)로 나타냅니다. 방의 한 구석을 원점으로, 바닥의 두 벽선을 x축과 y축으로, 기둥 방향을 z축으로 생각하면 됩니다. 점 (a, b, c)는 원점에서 x축 방향으로 a, y축 방향으로 b, z축 방향으로 c만큼 간 위치입니다.

문제 1

점 (2, 3, 4)에서 xy평면에 내린 수선의 발의 z좌표는?

문제 2

점 (2, 3, 4)에서 x축에 내린 수선의 발의 x좌표는?

대칭이동

xy평면에 대하여 대칭이면 z의 부호가, x축에 대하여 대칭이면 y, z의 부호가, 원점에 대하여 대칭이면 모든 부호가 바뀝니다.

대칭이동의 규칙은 '대칭의 기준에 포함된 좌표는 그대로, 나머지는 부호가 바뀐다'로 기억하면 됩니다. xy평면에 대한 대칭은 x, y가 그대로이고 z만 바뀝니다. x축에 대한 대칭은 x만 그대로이고 y, z가 바뀝니다. 원점에 대한 대칭은 기준에 포함된 좌표가 없어 모두 바뀝니다.

예제

점 P(2, −3, 5)를 yz평면, y축, 원점에 대하여 각각 대칭이동한 점을 구하세요.

  1. yz평면: y, z는 그대로, x만 부호 변경 → (−2, −3, 5)
  2. y축: y만 그대로, x, z 부호 변경 → (−2, −3, −5)
  3. 원점: 모두 부호 변경 → (−2, 3, −5)
  4. 원리: 기준에 포함된 좌표는 그대로

답: (−2, −3, 5), (−2, −3, −5), (−2, 3, −5)

좌표평면 위의 점

xy평면 위의 점은 z = 0, yz평면 위의 점은 x = 0, zx평면 위의 점은 y = 0입니다.

좌표평면 위의 점은 그 평면에 없는 축의 좌표가 0입니다. xy평면에는 z축 방향이 없으니 z = 0, yz평면에서는 x = 0입니다. 점에서 좌표평면에 내린 수선의 발은 해당 좌표를 0으로 바꾼 점입니다.

문제 7

yz평면 위의 점의 x좌표는?

좌표평면과 축까지의 거리

점 (a, b, c)에서 xy평면까지의 거리는 |c|, x축까지의 거리는 √(b² + c²)입니다.

xy평면까지의 거리는 수직 방향의 높이 |c|입니다. x축까지의 거리는 점에서 x축에 내린 수선의 발 (a, 0, 0)까지의 거리이므로 √(b² + c²)입니다. 축까지의 거리는 그 축의 좌표를 뺀 나머지 두 좌표로 계산합니다.

예제

점 (3, −4, 12)에서 xy평면, z축, 원점까지의 거리를 구하세요.

  1. xy평면까지: |z| = 12
  2. z축까지: √(3² + (−4)²) = 5
  3. 원점까지: √(9 + 16 + 144) = √169
  4. = 13

답: 12, 5, 13

원점까지의 거리

점 (a, b, c)와 원점 사이의 거리는 √(a² + b² + c²)입니다.

원점까지의 거리 √(a² + b² + c²)은 피타고라스 정리를 두 번 쓴 것입니다. 먼저 바닥에서 (a, b, 0)까지의 거리 √(a² + b²)을 구하고, 이것과 높이 c로 다시 직각삼각형을 만들면 빗변이 √(a² + b² + c²)이 됩니다. 직육면체의 대각선 공식과 같습니다.

예제

  1. B = (1, 2, −3), C = (1, −2, 3)
  2. BC = √(0² + (−4)² + 6²)
  3. = √52
  4. = 2√13

답: 2√13
