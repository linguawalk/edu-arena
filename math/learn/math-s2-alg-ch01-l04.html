정수 위의 함수방정식

수학 올림피아드 S2 본선 · 대수 · 1. 함수방정식 · 심화 · 약 25분 · 문제 11개

이 레슨 풀어 보기

점화식으로 바꾸기

정의역이 정수나 자연수이면 함수방정식은 점화식이 됩니다. f(m + n) = f(m) + f(n) + mn, f(1) = 1에서 n = 1을 넣으면 f(m + 1) = f(m) + m + 1입니다.

f(1) = 1, f(2) = 3, f(3) = 6, …으로 f(m) = m(m + 1)/2입니다(귀납법으로 확인).

정수 문제에서는 n = 1을 넣어 '한 칸씩 이동하는 식'을 얻는 것이 첫걸음입니다.

문제 1

f(m + n) = f(m) + f(n) + mn, f(1) = 1일 때 f(10)은?

문제 2

정수 위의 함수방정식에 n = 1을 넣으면 f(m + 1)을 f(m)으로 나타내는 ＿＿＿을 얻습니다.

f(m + n) = f(m) + f(n) + 2mn

f(m + n) = f(m) + f(n) + 2mn, f(1) = 1이면 n = 1에서 f(m + 1) = f(m) + 2m + 1입니다. f(1) = 1, f(2) = 4, f(3) = 9, …이므로 f(m) = m²입니다.

추측한 f를 원래 식에 넣어 확인합니다: (m + n)² = m² + n² + 2mn.

정수 문제에서는 작은 값을 몇 개 계산해 규칙을 추측하고, 귀납법으로 증명한 뒤, 원래 식에 넣어 확인하는 세 단계를 따릅니다.

예제

f(m + n) = f(m) + f(n) + 2mn, f(1) = 1일 때 f(m)을 구하고 확인하세요.

  1. n = 1을 넣으면 f(m + 1) = f(m) + 2m + 1입니다.
  2. f(1) = 1, f(2) = 4, f(3) = 9로 f(m) = m²을 추측합니다.
  3. 귀납: f(m + 1) = m² + 2m + 1 = (m + 1)²입니다.
  4. 확인: (m + n)² = m² + n² + 2mn이므로 f(m) = m²입니다.

답: m²

문제 3

f(m + n) = f(m) + f(n) + 2mn, f(1) = 1일 때 f(12)는?

문제 4

f(m + n) = f(m) + f(n) + 3, f(1) = 2 (m, n은 자연수)일 때 f(10)은?

곱의 함수방정식과 소인수분해

f(mn) = f(m) + f(n) (자연수 m, n)이면 f는 소인수분해로 정해집니다. n = p₁^a₁ ⋯ p_k^a_k이면 f(n) = a₁f(p₁) + ⋯ + a_kf(p_k)입니다.

예: f(2) = 1, f(3) = 2이면 f(72) = f(2³ × 3²) = 3 × 1 + 2 × 2 = 7입니다. f(1) = 0도 m = n = 1에서 나옵니다.

이런 함수는 '소수에서의 값'만 정하면 모두 정해지므로, 문제의 조건을 소수에서의 값으로 바꾸어 생각합니다.

문제 5

자연수에서 f(mn) = f(m) + f(n), f(2) = 1, f(3) = 2일 때 f(72)는?

문제 6

자연수에서 f(mn) = f(m) + f(n), f(2) = 3, f(5) = 1일 때 f(1000)은?

문제 7

f(m + n) = f(m)f(n), f(1) = 3 (자연수)일 때 f(4)는?

정리

정수 위의 함수방정식은 n = 1을 넣어 점화식으로 바꾸고, 작은 값을 계산해 규칙을 추측한 뒤 귀납법으로 증명하고 원래 식에 넣어 확인합니다.

f(m + n) = f(m) + f(n) + mn → m(m + 1)/2, + 2mn → m², f(m + n) = f(m)f(n) → f(1)ᵐ입니다.

f(mn) = f(m) + f(n)은 소수에서의 값으로 모두 정해지며, f(p₁^a₁⋯) = Σaᵢf(pᵢ)입니다.
