빠짐없이, 겹침 없이

경우를 나눌 때는 모든 경우를 빠짐없이 다루어야 합니다. 정수를 나머지로 나누면 빠짐이 없습니다: n ≡ 0, 1, 2 (mod 3).

예: n² + 2가 3의 배수인 정수 n은? n ≡ 0이면 n² + 2 ≡ 2, n ≡ 1이면 1 + 2 ≡ 0, n ≡ 2이면 4 + 2 ≡ 0입니다. 그래서 n이 3의 배수가 아닐 때입니다.

답안에는 '경우 1', '경우 2', … 로 나누고 마지막에 '모든 경우를 다루었으므로'라고 밝힙니다.

문제 1

1부터 30까지의 정수 n 가운데 n² + 2가 3의 배수인 것은 몇 개인가요?

문제 2

세 변수가 대칭인 식에서 '일반성을 잃지 않고 a ≤ b ≤ c라 하자'처럼 순서를 정해 두는 것을 영어 약자로 ＿＿＿라 합니다.

대칭을 써서 경우 줄이기

a, b, c를 서로 바꾸어도 바뀌지 않는 식(대칭식)이라면, 3! = 6가지 순서 가운데 하나만 다루어도 됩니다. 그래서 '일반성을 잃지 않고 a ≤ b ≤ c'라 둡니다.

단, 식이 정말 대칭인지 확인해야 합니다. a²b + b²c + c²a처럼 순환만 하는(a → b → c → a로 바꿀 때만 같은) 식에서는 a가 가장 크다고는 둘 수 있지만 a ≥ b ≥ c까지 둘 수는 없습니다.

WLOG를 쓸 때는 왜 일반성을 잃지 않는지(대칭이므로) 한 줄로 밝힙니다.

예제

a + b + c = 10, a, b, c는 자연수, abc의 최댓값을 구할 때 경우를 줄이는 방법을 쓰세요.

  1. abc와 조건 a + b + c = 10은 a, b, c에 대해 대칭입니다.
  2. 그래서 일반성을 잃지 않고 a ≤ b ≤ c라 둡니다.
  3. a ≤ 10/3이므로 a = 1, 2, 3만 보면 되고, 각 경우 b ≤ c로 나눕니다.
  4. (3, 3, 4)에서 최댓값 36을 얻습니다.

답: 최댓값 36

문제 4

서로 다른 세 변수 a, b, c를 늘어놓는 순서는 모두 몇 가지인가요?

홀짝과 나머지로 나누기

정수 문제는 홀짝(mod 2)이나 작은 수의 나머지로 경우를 나누는 일이 많습니다. 'n² + n은 언제나 짝수'는 n이 짝수일 때와 홀수일 때로 나누거나, n(n + 1)이 연속한 두 정수의 곱임을 쓰면 됩니다.

경우가 너무 많으면 대칭이나 다른 성질로 줄일 방법을 먼저 찾습니다.

경우마다 결론이 같으면 마지막에 묶어서 결론을 쓰고, 다르면 결과를 표로 정리하면 채점자가 확인하기 쉽습니다.

문제 5

n⁴를 5로 나눈 나머지로 가능한 값은 모두 몇 가지인가요?

문제 6

1부터 100까지의 정수 n 가운데 n² + n + 1이 3의 배수인 것은 몇 개인가요?

문제 7

순환식 a²b + b²c + c²a에서 '일반성을 잃지 않고 a가 가장 크다'고 둔 뒤에도 따로 다루어야 하는 b, c의 크기 순서는 몇 가지인가요?

정리

경우는 빠짐없이 나눕니다. 정수는 나머지(mod m)로 나누면 빠짐이 없고, 답안에는 '모든 경우를 다루었으므로'를 밝힙니다.

대칭식은 '일반성을 잃지 않고(WLOG) a ≤ b ≤ c'로 순서를 정해 경우를 줄이며, 순환식에서는 가장 큰 변수만 정할 수 있습니다.

경우마다의 결과는 표로 정리하면 채점자가 확인하기 쉽습니다.
