'존재함을 보여라'는 예 하나로

'…를 만족하는 수가 존재함을 보여라'는 그런 수를 하나 찾아 실제로 만족하는지 확인하면 됩니다. 이것을 구성적 증명이라고 합니다.

예 하나로 충분하다는 점은 '모든'을 증명할 때와 정반대입니다. 대신 찾은 예가 조건을 모두 만족한다는 확인을 빠짐없이 써야 합니다.

예를 들어 '연속한 다섯 합성수가 존재한다'는 6! + 2, 6! + 3, …, 6! + 6을 제시하면 됩니다. 6! + k는 k로 나누어떨어지고 k보다 크므로 합성수입니다. 숫자를 하나하나 소인수분해하지 않고 '왜 합성수인지'를 한 줄로 보이는 것이 좋은 구성입니다.

문제 1

6! + 2의 값은?

문제 2

6! + k는 2 ≤ k ≤ ＿＿＿인 모든 정수 k에 대해 k로 나누어떨어집니다.

예제

연속한 합성수 세 개가 존재함을 보이세요.

  1. 8, 9, 10을 제시합니다.
  2. 8 = 2 × 4, 9 = 3 × 3, 10 = 2 × 5이므로 셋 다 합성수입니다.
  3. 8, 9, 10은 연속한 세 정수입니다.
  4. 따라서 연속한 합성수 세 개가 존재합니다. (4! + 2, 4! + 3, 4! + 4 = 26, 27, 28도 됩니다.)

답: 8, 9, 10

문제 3

연속한 합성수 세 개 중 가장 작은 것부터 시작하는 묶음의 첫 수는?

무엇인지 모른 채 존재를 보이기

존재는 보이지만 정확히 무엇인지는 알려 주지 않는 증명도 있습니다. 이것을 비구성적 증명이라고 합니다.

'a, b가 무리수인데 aᵇ가 유리수인 경우가 있다'를 생각해 보세요. √2^√2가 유리수이면 a = b = √2로 끝납니다.

√2^√2가 무리수이면 a = √2^√2, b = √2로 놓습니다. 그러면 aᵇ = (√2^√2)^√2 = √2^(√2 × √2) = √2² = 2로 유리수입니다. 어느 경우인지는 모르지만, 두 경우 모두 원하는 a, b가 있으므로 존재가 증명됩니다. 경우 나누기와 존재 증명이 합쳐진 예입니다.

문제 4

(√2^√2)^√2 = √2^(√2 × √2) = √2^＿＿＿ = 2입니다.

유일함을 보이기

'오직 하나 존재한다'는 두 부분입니다. 존재: 하나를 찾는다. 유일성: 두 개가 있다면 같다는 것을 보인다.

유일성은 보통 'a와 b가 모두 조건을 만족한다고 하자'로 시작해 a = b를 이끌어 냅니다.

예를 들어 x³ = 8의 실수해는 x = 2 하나뿐입니다. x³ − 8 = (x − 2)(x² + 2x + 4)이고, x² + 2x + 4 = (x + 1)² + 3 > 0이라 두 번째 인수는 0이 될 수 없기 때문입니다. 존재와 유일성 중 하나만 쓰면 '오직 하나'를 증명한 것이 아니므로, 답안에서 두 부분을 나누어 쓰세요.

예제

x³ = 8을 만족하는 실수 x가 오직 하나임을 보이세요.

  1. 존재: x = 2이면 2³ = 8입니다.
  2. 유일성: x³ − 8 = (x − 2)(x² + 2x + 4)입니다.
  3. x² + 2x + 4 = (x + 1)² + 3 ≥ 3 > 0이므로 x³ = 8이면 x − 2 = 0입니다.
  4. 따라서 실수해는 x = 2 하나뿐입니다.

답: x = 2

최선의 구성 찾기

'최댓값을 구하라'에서 최댓값을 내는 예를 찾는 것도 구성입니다. 작은 경우를 실험해 규칙을 찾고, 그 규칙이 왜 최선인지 설명합니다.

예를 들어 '합이 10인 자연수들의 곱의 최댓값'은 3을 최대한 많이 쓰는 것이 최선입니다.

왜 3일까요? 4 이상인 수 m은 2와 m − 2로 쪼개면 2(m − 2) ≥ m이라 곱이 줄지 않습니다. 1은 곱에 아무것도 보태지 않으니 쓰지 않습니다. 남은 2와 3 중에서는 2 + 2 + 2 = 3 + 3이지만 2³ = 8 < 3² = 9이므로 2는 두 개까지만 씁니다. 이런 '바꾸면 더 좋아진다'는 논증이 최선임을 보이는 표준 방법입니다.

정리

존재는 예 하나를 제시하고 조건을 모두 만족함을 확인합니다. 구성할 때는 '왜 조건을 만족하는지'를 한 줄로 보여 주는 예가 좋습니다.

비구성적 증명은 경우를 나누어 어느 경우든 원하는 대상이 있음을 보입니다.

유일성은 '두 개가 있다면 같다'를 보이며, '오직 하나'는 존재와 유일성을 나누어 씁니다. 최댓값을 내는 구성은 작은 경우 실험으로 찾고, '바꾸면 더 좋아진다'는 논증으로 최선임을 보입니다.
