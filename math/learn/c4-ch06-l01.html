수 e

(1 + 1/n)ⁿ은 n이 커질수록 약 2.718…에 가까워집니다. 이 수를 e라 합니다.

e를 밑으로 하는 로그를 자연로그라 하고 ln x로 씁니다. lim(x→0) (eˣ − 1)/x = 1, lim(x→0) ln(1 + x)/x = 1

e는 복리 계산에서 자연스럽게 나타나는 수입니다. 1원을 연 100% 이자로 1년 맡길 때, 1년에 n번 나눠 복리로 계산하면 (1 + 1/n)ⁿ원이 되는데, n을 한없이 늘려도 약 2.718원을 넘지 못합니다. 두 극한은 eˣ 그래프가 점 (0, 1)에서 기울기가 정확히 1이 되도록 e를 고른 결과입니다.

지수함수의 미분

(eˣ)′ = eˣ. 미분해도 자기 자신이 되는 함수입니다.

(aˣ)′ = aˣ ln a

왜 (eˣ)′ = eˣ일까요? 정의로 계산하면 (e^(x+h) − eˣ)/h = eˣ × (eʰ − 1)/h이고, h → 0이면 (eʰ − 1)/h → 1이므로 eˣ가 남습니다. 밑이 a이면 aˣ = e^(x ln a)로 바꿔 ln a가 곱해집니다. 미분해도 자기 자신이 된다는 성질 덕분에 e는 미적분에서 가장 중요한 밑이 됩니다.

예제

f(x) = 2eˣ − 3ˣ일 때 f′(0)을 구하세요.

  1. (2eˣ)′ = 2eˣ
  2. (3ˣ)′ = 3ˣ ln 3
  3. f′(x) = 2eˣ − 3ˣ ln 3
  4. f′(0) = 2 − ln 3

답: 2 − ln 3

로그함수의 미분

(ln x)′ = 1/x, (logₐ x)′ = 1/(x ln a)

(ln x)′ = 1/x는 역함수의 미분으로 이해할 수 있습니다. y = ln x이면 x = eʸ이고, 양변을 x로 미분하면 1 = eʸ × y′이므로 y′ = 1/eʸ = 1/x입니다. 다른 밑의 로그는 밑변환 logₐ x = ln x / ln a로 바꾸면 1/(x ln a)가 됩니다.

예제

f(x) = ln x + log₃ x일 때 f′(1)을 구하세요.

  1. (ln x)′ = 1/x
  2. (log₃ x)′ = 1/(x ln 3)
  3. f′(1) = 1 + 1/ln 3
  4. 원리: 다른 밑의 로그는 ln a로 나눕니다.

답: 1 + 1/ln 3

극한의 변형

lim(x→0) (e^(ax) − 1)/x = a처럼, 안의 식을 맞추기 위해 분모에 같은 수를 곱하고 나눕니다.

기본 극한 lim (eˣ − 1)/x = 1은 '분모와 지수가 같은 식'일 때만 쓸 수 있습니다. e^(2x) − 1은 지수가 2x이므로 분모도 2x로 맞추려고 2를 곱하고 나눕니다: (e^(2x) − 1)/x = 2 × (e^(2x) − 1)/(2x) → 2.

예제

lim(x→0) ln(1 + 2x)/(3x)를 구하세요.

  1. 안의 식에 맞춰 분모를 2x로: ln(1 + 2x)/(2x) × 2x/(3x)
  2. 앞 부분 → 1
  3. 뒤 부분 2/3
  4. 극한값 2/3

답: 2/3

정리

eˣ는 미분해도 그대로, ln x는 미분하면 1/x이 됩니다. 밑이 e가 아니면 ln a가 곱해지거나 나눠집니다.

밑이 e가 아닌 지수·로그함수를 미분할 때 붙는 ln a는 '밑을 e로 바꾸는 비용'이라고 생각하면 기억하기 쉽습니다. 지수함수는 ln a를 곱하고, 로그함수는 ln a로 나눕니다. 밑이 e이면 ln e = 1이라 아무것도 붙지 않습니다.
