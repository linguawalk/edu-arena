더 강한 명제가 더 쉽다

귀납법이 막힐 때는 오히려 더 강한 명제를 증명하는 것이 쉬울 때가 있습니다. 귀납 가정이 강해져 다음 단계로 넘어갈 힘이 커지기 때문입니다.

예: 1 + 1/2² + ⋯ + 1/n² < 2. 이 그대로는 귀납이 되지 않습니다. 'Sₙ < 2'라는 가정에 1/(k + 1)²을 더하면 2를 넘을 수도 있기 때문입니다.

대신 'Sₙ ≤ 2 − 1/n'을 증명합니다. Sₖ₊₁ ≤ 2 − 1/k + 1/(k + 1)²이고, 1/k − 1/(k + 1)² > 1/k − 1/(k(k + 1)) = 1/(k + 1)이므로 Sₖ₊₁ < 2 − 1/(k + 1)입니다.

문제 1

강화한 명제 Sₙ ≤ 2 − 1/n에서 n = 10일 때 오른쪽 값은? (소수로)

문제 2

귀납법이 막힐 때 증명할 명제를 더 강하게 바꾸어 귀납 가정의 힘을 키우는 방법을 귀납 가정 ＿＿＿라 합니다.

베르누이 부등식

x ≥ −1이고 n이 자연수이면 (1 + x)ⁿ ≥ 1 + nx입니다(베르누이 부등식). 귀납 단계: (1 + x)ᵏ⁺¹ = (1 + x)ᵏ(1 + x) ≥ (1 + kx)(1 + x) = 1 + (k + 1)x + kx² ≥ 1 + (k + 1)x.

여기서 (1 + x) ≥ 0이어야 부등식의 양변에 곱할 수 있으므로 조건 x ≥ −1이 꼭 필요합니다. 조건이 증명의 어디에 쓰이는지 답안에 밝히면 좋은 점수를 받습니다.

부등식의 귀납법에서는 '버리는 항'(여기서는 kx² ≥ 0)이 음이 아님을 확인해야 합니다.

예제

베르누이 부등식으로 1.01¹⁰⁰ ≥ 2임을 보이세요.

  1. x = 0.01, n = 100으로 둡니다(x ≥ −1).
  2. (1 + 0.01)¹⁰⁰ ≥ 1 + 100 × 0.01입니다.
  3. 1 + 100 × 0.01 = 2입니다.
  4. 그래서 1.01¹⁰⁰ ≥ 2입니다(실제 값은 약 2.70).

답: 1.01¹⁰⁰ ≥ 2

문제 4

2ⁿ > n²이 성립하지 않는 가장 큰 자연수 n은? (그 뒤로는 모두 성립)

기저를 어디서 시작할까

n! > 2ⁿ은 n = 1, 2, 3에서 거짓이고 n = 4(24 > 16)부터 참입니다. 그래서 기저를 n = 4로 두고, 귀납 단계 (k + 1)! = (k + 1)k! > (k + 1)2ᵏ ≥ 2ᵏ⁺¹ (k + 1 ≥ 2)를 씁니다.

이처럼 명제가 어떤 수부터 참이면 기저를 그 수로 잡고, 귀납 단계에서 그 범위의 조건(k ≥ 4)을 씁니다.

귀납 단계만 보고 '모든 n에서 참'이라고 하면 안 됩니다. 기저가 성립하는 첫 수를 반드시 확인합니다.

1 + 1/2² + ⋯ + 1/n² ≤ 2 − 1/n의 귀납 단계에서 쓰는 부등식 1/(k + 1)² < 1/(k(k + 1))의 오른쪽은 1/k − 1/(k + 1)과 같습니다. k = 4일 때 1/k − 1/(k + 1)의 값은? (분수로)

정리

귀납이 막히면 더 강한 명제(예: Sₙ < 2 대신 Sₙ ≤ 2 − 1/n)를 증명하면 귀납 가정의 힘이 커져 통할 수 있습니다.

부등식의 귀납 단계에서는 곱하는 수의 부호(베르누이의 1 + x ≥ 0)와 버리는 항의 부호를 확인하고, 조건이 쓰인 곳을 밝힙니다.

명제가 어떤 수부터 참이면 그 수를 기저로 잡고(n! > 2ⁿ은 n = 4부터), 귀납 단계에서 범위 조건을 씁니다.
