삼각함수의 미분

미적분 · 6. 여러 가지 함수의 미분 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

기본 극한

lim(x→0) sin x / x = 1 (x는 라디안). 아주 작은 각에서는 sin x ≈ x입니다.

왜 sin x / x → 1일까요? 반지름 1인 원에서 중심각 x(라디안)인 부채꼴을 그리면, 넓이를 비교해 sin x < x < tan x (0 < x < π/2)가 됩니다. 각 변을 sin x로 나눠 뒤집으면 cos x < sin x / x < 1이고, x → 0이면 cos x → 1이므로 샌드위치 정리로 1이 됩니다. 도(°)를 쓰면 이 극한이 1이 아니므로 반드시 라디안을 씁니다.

사인과 코사인의 미분

(sin x)′ = cos x, (cos x)′ = −sin x

그래프로 확인해 보세요. y = sin x는 x = 0에서 기울기 1로 올라가고(cos 0 = 1), x = π/2에서 꼭대기라 기울기 0(cos (π/2) = 0)입니다. 기울기를 모아 그리면 cos x 그래프가 됩니다. cos x는 x = 0에서 꼭대기라 기울기 0이고 그 뒤로 내려가므로 −sin x가 도함수입니다.

예제

lim(x→0) sin 5x / sin 2x를 구하세요.

  1. 분모, 분자를 x로 나눠 {sin 5x / x} / {sin 2x / x}
  2. sin 5x / x = 5 × sin 5x/(5x) → 5
  3. sin 2x / x → 2
  4. 극한값 5/2

답: 5/2

문제 5

f(x) = cos x일 때 f′(π/2)의 값은?

덧셈정리

sin(α + β) = sin α cos β + cos α sin β, cos(α + β) = cos α cos β − sin α sin β

사인의 미분 공식은 이 덧셈정리와 기본 극한에서 나옵니다.

덧셈정리는 단위원 위의 회전으로 유도할 수 있습니다. 이를 이용하면 sin(x + h) = sin x cos h + cos x sin h이므로 {sin(x + h) − sin x}/h = sin x × (cos h − 1)/h + cos x × (sin h)/h입니다. h → 0이면 첫째 항은 0, 둘째 항은 cos x가 되어 (sin x)′ = cos x가 증명됩니다.

예제

cos 15°를 덧셈정리로 구하세요.

  1. cos 15° = cos(45° − 30°)
  2. = cos 45° cos 30° + sin 45° sin 30°
  3. = (√2/2)(√3/2) + (√2/2)(1/2)
  4. = (√6 + √2)/4

답: (√6 + √2)/4

탄젠트의 미분

(tan x)′ = 1/cos² x

tan x = sin x / cos x이므로 다음 레슨의 몫의 미분법으로 구하면 {cos x × cos x − sin x × (−sin x)}/cos² x = (cos² x + sin² x)/cos² x = 1/cos² x입니다. sin² + cos² = 1이 깔끔하게 정리해 줍니다.

예제

f(x) = 3 sin x − 2 cos x + tan x일 때 f′(0)을 구하세요.

  1. f′(x) = 3 cos x + 2 sin x + 1/cos² x
  2. x = 0: 3 × 1 + 0 + 1/1
  3. = 4
  4. 주의: (cos x)′ = −sin x라 −2 cos x의 미분은 +2 sin x

답: 4

문제 10

lim(x→0) (1 − cos x)/x²의 값은? (기약분수로)

정리

극한 문제는 sin □ / □ 꼴을 만들고, 미분은 sin → cos, cos → −sin 순서로 바뀝니다.

sin □ / □ 꼴을 만들 때는 □에 들어갈 식을 먼저 정하고, 분모를 그 식에 맞춰 곱하고 나눕니다. 미분은 sin → cos → −sin → −cos → sin으로 네 번마다 원래대로 돌아옵니다.
