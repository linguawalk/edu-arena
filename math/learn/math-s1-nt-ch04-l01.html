소수는 어떤 꼴일까

소수는 무한히 많습니다. 증명의 기초 1장에서 귀류법으로 보였듯이, 소수가 유한개라면 모두 곱하고 1을 더한 수의 소인수가 목록에 없기 때문입니다.

3보다 큰 소수는 모두 6k + 1 또는 6k − 1 꼴입니다. 6k, 6k + 2, 6k + 4는 짝수이고 6k + 3은 3의 배수이기 때문입니다.

이런 관찰은 소수가 들어 있는 문제에서 경우를 크게 줄여 줍니다. 'p와 p + 2, p + 4가 모두 소수' 같은 조건은 3을 법으로 보면 셋 중 하나가 3의 배수라는 사실 하나로 답이 정해집니다. 소수 문제를 받으면 먼저 작은 소수 2, 3을 따로 확인하고, 나머지는 6을 법으로 보는 습관을 들이세요.

문제 1

100 이하의 소수는 모두 몇 개인가요?

문제 2

3보다 큰 소수는 6k + 1 또는 6k − ＿＿＿ 꼴입니다.

4k + 3 꼴의 소수도 무한하다

4로 나눈 나머지가 3인 소수(3, 7, 11, 19, …)도 무한히 많습니다. 유한개라고 가정하고 그것을 모두 p₁, …, pₙ이라 합시다.

N = 4p₁p₂⋯pₙ − 1은 4로 나눈 나머지가 3인 홀수입니다. 4로 나눈 나머지가 1인 수끼리 곱하면 나머지가 1이므로, N은 4로 나눈 나머지가 3인 소인수를 적어도 하나 가져야 합니다.

그런데 그 소인수는 어떤 pᵢ도 아닙니다. pᵢ로 N을 나누면 나머지가 −1이기 때문입니다. 유클리드의 증명을 약간 바꾸어 특정한 꼴의 소수가 무한함을 보인 것입니다. '나머지 1끼리의 곱은 나머지 1'이라는 합동식 관찰이 핵심 역할을 했습니다.

예제

4k + 3 꼴의 소수가 무한히 많다는 증명의 흐름을 정리하세요.

  1. 4k + 3 꼴의 소수가 p₁, …, pₙ뿐이라고 가정합니다.
  2. N = 4p₁⋯pₙ − 1은 4로 나눈 나머지가 3인 홀수입니다.
  3. N의 소인수가 모두 4k + 1 꼴이면 N도 4k + 1 꼴이 되므로, 4k + 3 꼴인 소인수 q가 있습니다.
  4. q가 어떤 pᵢ라면 pᵢ | N과 pᵢ | 4p₁⋯pₙ에서 pᵢ | 1이 되어 모순입니다.

답: q는 목록에 없는 새 소수

문제 3

4 × (3 × 7 × 11) − 1 = 923의 소인수 중 4로 나눈 나머지가 3인 것은? (923 = 13 × 71)

소수 판정은 √n까지

n이 합성수이면 n = ab (1 < a ≤ b)로 쓸 수 있고, 이때 a² ≤ ab = n이므로 a ≤ √n입니다.

그래서 n이 소수인지 알려면 √n 이하의 소수로 나누어 보기만 하면 됩니다. 211은 √211 ≈ 14.5이므로 2, 3, 5, 7, 11, 13으로만 나누어 보면 됩니다.

이 사실은 소수 판정뿐 아니라 증명에도 씁니다. '√n 이하의 소인수가 없으면 n은 소수'라는 형태로, 큰 수가 소수임을 보이는 답안에서 확인할 범위를 정해 줍니다. 1013이 소수임을 보이려면 31 이하의 소수 11개로만 나누어 보면 됩니다.

문제 5

소수 사이의 간격

소수 사이의 간격은 얼마든지 커질 수 있습니다. n! + 2, n! + 3, …, n! + n은 연속한 n − 1개의 합성수이기 때문입니다(증명의 기초 3장).

반대로 소수가 너무 드물어지지도 않습니다. 모든 자연수 n에 대해 n < p ≤ 2n인 소수 p가 있다는 것이 알려져 있습니다(베르트랑 공준).

이차식의 값이 소수인지 묻는 문제도 자주 나옵니다. n² + 1 꼴의 소수가 무한한지는 아직 아무도 모르는 문제입니다. 올림피아드 문제는 대개 이런 미해결 문제와 달리, 나머지나 인수분해로 '소수가 될 수 없음'을 보이는 형태로 나옵니다.

문제 6

n! + 2, …, n! + n의 방법으로 연속한 합성수 9개를 만들려면 n은 얼마여야 하나요?

문제 7

1 ≤ n ≤ 10에서 n² + 1이 소수인 n은 몇 개인가요?

정리

소수는 무한히 많고, 4k + 3 꼴의 소수도 무한히 많습니다. 증명은 목록의 소수로 만든 수에서 목록 밖의 소인수를 찾는 방식입니다.

3보다 큰 소수는 6k ± 1 꼴입니다. 소수 조건이 여러 개인 문제는 2, 3을 따로 보고 3이나 6을 법으로 정리합니다.

n이 소수인지는 √n 이하의 소수로만 확인합니다. 소수 사이의 간격은 얼마든지 커질 수 있지만, n과 2n 사이에는 항상 소수가 있습니다.
