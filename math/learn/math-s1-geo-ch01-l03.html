각의 이등분선 정리

수학 올림피아드 S1 예선 · 기하 · 1. 닮음과 비 · 심화 · 약 20분 · 문제 11개

이 레슨 풀어 보기

이등분선은 대변을 이웃한 변의 비로 나눈다

삼각형 ABC에서 ∠A의 이등분선이 BC와 D에서 만나면 BD : DC = AB : AC입니다.

AB = 6, AC = 9, BC = 10이면 BD : DC = 2 : 3이므로 BD = 4, DC = 6입니다.

이 정리는 각의 정보(이등분)를 길이의 정보(비)로 바꾸어 줍니다. 각을 직접 계산하기 어려운 문제에서 길이로 옮겨 풀 수 있게 해 주므로 매우 자주 씁니다. 특히 내심이 각의 이등분선의 교점이라서, 챕터 3의 내심 문제에서 다시 쓰입니다.

문제 1

삼각형 ABC에서 AB = 6, AC = 9, BC = 10이고 ∠A의 이등분선이 BC와 D에서 만날 때 BD의 길이는?

문제 2

∠A의 이등분선이 BC와 D에서 만나면 BD : DC = AB : ＿＿＿입니다.

넓이로 증명하기

△ABD와 △ADC는 A에서 BC까지의 높이가 같으므로 넓이의 비는 BD : DC입니다.

또 D는 ∠A의 이등분선 위에 있으므로 D에서 AB, AC까지의 거리가 같습니다. 그래서 두 삼각형을 각각 밑변 AB, AC로 보면 높이가 같아 넓이의 비는 AB : AC입니다.

같은 넓이의 비를 두 가지로 나타냈으므로 BD : DC = AB : AC입니다. '같은 넓이를 서로 다른 밑변과 높이로 두 번 계산한다'는 이 방법은 챕터 4의 넓이 방법의 출발점입니다. B를 지나 AD에 평행한 직선을 그어 이등변삼각형을 만드는 증명도 있습니다.

예제

AB = 5, AC = 7, BC = 6인 삼각형에서 ∠A의 이등분선이 BC와 만나는 점 D에 대해 BD의 길이를 구하세요.

  1. 각의 이등분선 정리에 의해 BD : DC = 5 : 7입니다.
  2. BD + DC = 6입니다.
  3. BD = 6 × 5/12 = 5/2입니다.
  4. 따라서 BD = 5/2, DC = 7/2입니다.

답: 5/2

문제 3

AB = 8, AC = 12, BC = 15인 삼각형에서 ∠A의 이등분선이 BC와 만나는 점 D에 대해 BD의 길이는?

외각의 이등분선

∠A의 외각의 이등분선이 직선 BC와 E에서 만나면 BE : EC = AB : AC입니다. 이번에는 E가 선분 BC의 바깥에 있습니다(AB ≠ AC일 때).

AB > AC이면 E는 C 쪽 바깥에 있고, BE − EC = BC입니다.

내각의 이등분선의 발 D와 외각의 이등분선의 발 E는 B와 C를 같은 비로 '안에서' 그리고 '밖에서' 나눕니다. 두 이등분선은 서로 수직이라서 ∠DAE = 90°입니다. 이런 짝은 S2의 아폴로니우스 원으로 이어집니다.

문제 5

AB = 6, AC = 9, BC = 10인 삼각형에서 ∠A의 이등분선의 길이를 AD라 할 때 AD²의 값은? (AD² = AB × AC − BD × DC)

이등분선과 내심

세 내각의 이등분선은 한 점 I(내심)에서 만납니다. ∠A의 이등분선 AD 위에서 I는 AI : ID = (AB + AC) : BC로 나눕니다.

삼각형 ABD에서 BI가 ∠B의 이등분선이므로 AI : ID = AB : BD이고, BD = BC × AB/(AB + AC)를 넣으면 이 비가 나옵니다.

이처럼 각의 이등분선 정리를 두 번 연달아 쓰면 내심의 위치를 비로 정할 수 있습니다. 직각삼각형에서 직각의 이등분선이 빗변을 나누는 비도 두 다리의 비입니다. 3, 4, 5 직각삼각형이면 빗변이 15/7과 20/7로 나뉩니다.

문제 6

두 다리가 3, 4이고 빗변이 5인 직각삼각형에서 직각의 이등분선이 빗변을 나눌 때, 다리 3 쪽에 있는 부분의 길이를 분수로 쓰세요.

문제 7

AB = 6, AC = 9, BC = 10인 삼각형의 내심을 I, ∠A의 이등분선과 BC의 교점을 D라 할 때 AI/ID를 분수로 쓰세요.

정리

∠A의 이등분선이 BC와 D에서 만나면 BD : DC = AB : AC이고, 외각의 이등분선은 BC를 밖에서 같은 비로 나눕니다.

증명은 넓이를 두 가지로 계산하거나, 평행선을 그어 이등변삼각형을 만들어서 합니다.

이등분선의 길이는 AD² = AB × AC − BD × DC이고, 내심은 이등분선을 (AB + AC) : BC로 나눕니다. 정리를 두 번 연달아 쓰는 것이 요령입니다.
