해가 없음을 보이는 법

디오판토스 방정식에 해가 없음을 보이는 가장 강력한 도구는 나머지(합동)입니다. 알맞은 법 m으로 양변의 가능한 나머지를 비교해 겹치지 않으면 해가 없습니다.

x² + y² = 2023: 2023 ≡ 3 (mod 4)인데 두 제곱수의 합은 0, 1, 2 (mod 4)뿐이므로 해가 없습니다.

법은 제곱이면 4, 8, 3, 5, 세제곱이면 7, 9처럼 거듭제곱의 나머지가 적게 나오는 수를 고릅니다.

문제 1

x² + y² = 2023의 정수해는 몇 개인가요?

문제 2

세제곱수를 9로 나눈 나머지는 0, 1, ＿＿＿뿐입니다.

지수 방정식

2ˣ + 1 = y²은 2ˣ = (y − 1)(y + 1)로 인수분해합니다. y − 1과 y + 1은 모두 2의 거듭제곱이고 차가 2이므로 2와 4뿐입니다. 그래서 y = 3, x = 3입니다.

3ˣ − 2ʸ = 1: x = 1이면 y = 1입니다. x ≥ 2이면 mod 4나 인수분해로 따져 (x, y) = (2, 3)만 나옵니다(9 − 8 = 1). 이것은 카탈랑 추측(미하일레스쿠 정리)의 가장 간단한 경우입니다.

지수 방정식은 '인수분해 + 2의 거듭제곱의 차' 또는 '작은 법으로 지수의 홀짝 결정'을 자주 씁니다.

예제

2ˣ + 1 = y²의 양의 정수해를 모두 구하세요.

  1. 2ˣ = y² − 1 = (y − 1)(y + 1)입니다.
  2. 두 인수는 모두 2의 거듭제곱이고 차가 2입니다.
  3. 차가 2인 2의 거듭제곱 쌍은 (2, 4)뿐이므로 y − 1 = 2, y + 1 = 4입니다.
  4. y = 3, 2ˣ = 8이라 x = 3입니다. 해는 (3, 3) 하나입니다.

답: (3, 3)

문제 3

2ˣ + 1 = y²의 양의 정수해에서 x + y는?

문제 4

3ˣ − 2ʸ = 1의 양의 정수해 (x, y)는 몇 개인가요?

펠 방정식

x² − 2y² = 1은 무한히 많은 해를 가집니다. 가장 작은 해 (3, 2)에서 (3 + 2√2)ⁿ = xₙ + yₙ√2로 모든 해가 나옵니다.

(3 + 2√2)² = 17 + 12√2이므로 다음 해는 (17, 12), 그다음은 (99, 70)입니다. 점화식으로는 xₙ₊₁ = 3xₙ + 4yₙ, yₙ₊₁ = 2xₙ + 3yₙ입니다.

x² − dy² = 1 (d는 제곱수가 아닌 자연수)을 펠 방정식이라 하며, 언제나 무한히 많은 양의 정수해가 있습니다.

문제 7

x³ + y³ = 35의 정수해 (x, y)는 몇 개인가요? (|x|, |y| ≤ 20에서)

정리

해가 없음은 알맞은 법(제곱 → 4, 8, 3, 5, 세제곱 → 7, 9)으로 양변의 나머지가 겹치지 않음을 보여 증명합니다.

지수 방정식은 인수분해한 뒤 '차가 작은 2의 거듭제곱 쌍'을 찾거나, 작은 법으로 지수의 홀짝을 정합니다(2ˣ + 1 = y² → (3, 3)).

펠 방정식 x² − dy² = 1은 가장 작은 해에서 (x₁ + y₁√d)ⁿ으로 무한히 많은 해를 만듭니다.
