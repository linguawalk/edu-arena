체비셰프 부등식과 응용

평균의 곱보다 곱의 평균이 크다

체비셰프 부등식: a₁ ≤ ⋯ ≤ aₙ, b₁ ≤ ⋯ ≤ bₙ(같은 순서)이면 n(a₁b₁ + ⋯ + aₙbₙ) ≥ (a₁ + ⋯ + aₙ)(b₁ + ⋯ + bₙ)입니다. 곧 '곱의 평균 ≥ 평균의 곱'입니다.

증명: 재배열 부등식으로 Σaᵢbᵢ ≥ Σaᵢbᵢ₊ₖ(첨자를 k만큼 밀어 짝지음)가 k = 0, 1, …, n − 1에서 모두 성립합니다. n개를 더하면 오른쪽은 (Σaᵢ)(Σbᵢ)입니다.

반대 순서이면 부등호가 바뀝니다.

문제 1

a = (1, 2, 3), b = (4, 5, 6)일 때 3(a₁b₁ + a₂b₂ + a₃b₃) − (a₁ + a₂ + a₃)(b₁ + b₂ + b₃)는?

문제 2

같은 순서의 두 수열에 대해 '곱의 평균 ≥ 평균의 곱'을 나타내는 부등식을 ＿＿＿ 부등식이라 합니다.

분수 꼴에 쓰기

양수 a, b, c에서 a ≤ b ≤ c이면 a/(b + c) ≤ b/(c + a) ≤ c/(a + b)이고 순서가 같습니다. 그래서 (a, b, c)와 (1/(b + c), 1/(c + a), 1/(a + b))에 체비셰프를 쓸 수 있습니다.

네스빗 부등식 a/(b + c) + b/(c + a) + c/(a + b) ≥ 3/2도 재배열이나 체비셰프로 증명할 수 있습니다.

응용의 핵심은 '두 수열의 크기 순서가 같다'는 것을 먼저 확인하는 것입니다.

예제

a = 1, b = 2, c = 3일 때 a/(b + c) + b/(c + a) + c/(a + b)를 계산하고 3/2와 비교하세요.

  1. 1/(2 + 3) = 1/5 = 0.2입니다.
  2. 2/(3 + 1) = 2/4 = 0.5입니다.
  3. 3/(1 + 2) = 3/3 = 1입니다.
  4. 합은 1.7로 3/2 = 1.5보다 큽니다(네스빗 부등식).

답: 1.7

문제 3

a = 1, b = 2, c = 3일 때 a/(b + c) + b/(c + a) + c/(a + b)는? (소수로)

문제 4

a = b = c일 때 a/(b + c) + b/(c + a) + c/(a + b)는? (분수로)

재배열로 만드는 여러 부등식

(a, b, c)와 (1/a, 1/b, 1/c)는 반대 순서입니다. 그래서 반대 순서 짝짓기 a · 1/a + b · 1/b + c · 1/c = 3이 최소이고, a/b + b/c + c/a ≥ 3입니다.

같은 방법으로 a²/b + b²/c + c²/a ≥ a + b + c (양수)를 보일 수 있습니다. (a², b², c²)와 (1/a, 1/b, 1/c)는 반대 순서이므로 최소는 a²/a + b²/b + c²/c입니다.

부등식을 보면 '어떤 두 수열의 짝짓기인가, 같은 순서인가 반대 순서인가'를 먼저 물어보세요.

문제 5

a = 1, b = 2, c = 4일 때 a/b + b/c + c/a는? (소수로)

문제 6

a = 1, b = 2, c = 4일 때 (a²/b + b²/c + c²/a) − (a + b + c)는? (소수로)

문제 7

양수 a, b, c에서 a/b + b/c + c/a의 최솟값은?

정리

체비셰프 부등식: 같은 순서이면 nΣaᵢbᵢ ≥ ΣaᵢΣbᵢ, 반대 순서이면 부등호가 바뀝니다. 재배열 부등식을 n번 더해 증명합니다.

(a, b, c)와 (1/a, 1/b, 1/c)는 반대 순서라 a/b + b/c + c/a ≥ 3, a²/b + b²/c + c²/a ≥ a + b + c를 얻습니다.

부등식을 보면 두 수열의 짝짓기로 볼 수 있는지, 순서가 같은지 반대인지부터 확인합니다.

문제 10

양수 a, b, c에 대해 a/b + b/c + c/a ≥ 3을 재배열 부등식으로 증명하세요.

문제 11

체비셰프 부등식 3(a₁b₁ + a₂b₂ + a₃b₃) ≥ (a₁ + a₂ + a₃)(b₁ + b₂ + b₃) (두 수열이 같은 순서)를 재배열 부등식으로 증명하세요.
