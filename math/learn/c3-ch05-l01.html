사인법칙

삼각형 ABC의 외접원의 반지름을 R이라 하면 a/sin A = b/sin B = c/sin C = 2R입니다.

a, b, c는 각 A, B, C와 마주 보는 변의 길이입니다.

왜 2R일까요? 외접원에서 B를 지나는 지름 BD를 그으면, 같은 호 BC에 대한 원주각이라 ∠D = ∠A이고 ∠BCD = 90°(지름에 대한 원주각)입니다. 직각삼각형 BCD에서 sin D = a/2R이므로 a/sin A = 2R입니다. b, c에 대해서도 같은 방법으로 보일 수 있어 세 비가 모두 2R로 같습니다.

문제 2

B = 45°, b = 4인 삼각형에서 2R = ＿＿＿√2

두 각과 한 변

두 각과 한 변을 알면 사인법칙으로 나머지 변을 구할 수 있습니다. b = a sin B / sin A

두 각을 알면 세 번째 각은 180°에서 빼서 바로 구할 수 있으므로, 사실상 세 각과 한 변을 아는 셈입니다. 사인법칙은 '마주 보는 변과 각'의 짝을 이용하므로, 알고 있는 변과 그 대각(마주 보는 각)을 먼저 짝지어 둡니다.

예제

A = 75°, B = 45°, c = 6일 때 b를 구하세요.

  1. C = 180° − 75° − 45° = 60°
  2. 알고 있는 변 c와 짝인 각 C로 2R = c/sin C = 6/(√3/2) = 4√3
  3. b = 2R sin B = 4√3 × √2/2
  4. = 2√6

답: 2√6

문제 5

A : B : C = 1 : 2 : 3인 삼각형에서 c/a의 값은?

변의 비 = 사인의 비

a : b : c = sin A : sin B : sin C입니다.

a = 2R sin A, b = 2R sin B, c = 2R sin C이므로 세 변은 각각 사인값에 같은 수 2R을 곱한 것입니다. 그래서 변의 비와 사인의 비가 같습니다. 주의할 점은 각의 비와 변의 비는 다르다는 것입니다. A : B : C = 1 : 2 : 3이어도 a : b : c = 1 : 2 : 3이 아닙니다.

예제

sin A : sin B : sin C = 2 : 3 : 4이고 둘레가 18인 삼각형의 가장 긴 변은?

  1. 변의 비 = 사인의 비: a : b : c = 2 : 3 : 4
  2. a = 2k, b = 3k, c = 4k로 놓으면 9k = 18, k = 2
  3. 가장 긴 변 c = 8
  4. 주의: 각의 비가 아니라 사인의 비이므로 바로 변의 비가 됩니다.

답: 8

문제 7

외접원의 반지름이 3이고 A = 30°일 때 a의 값은?

삼각형의 모양

사인법칙으로 sin을 변의 길이로 바꾸면 삼각형의 모양을 알 수 있습니다.

sin² A = sin² B + sin² C이면 a² = b² + c²이므로 A = 90°인 직각삼각형입니다.

모양을 판단할 때는 sin A = a/2R처럼 모든 사인을 변으로 바꿔 식을 정리합니다. 2R은 양변에서 약분되어 사라지므로 변 사이의 관계만 남고, 그 관계로 이등변삼각형이나 직각삼각형을 판별합니다.

예제

sin A = 2 sin B cos C를 만족하는 삼각형의 모양을 구하세요.

  1. 사인법칙 sin A = a/2R, sin B = b/2R과 코사인법칙 cos C = (a² + b² − c²)/2ab를 넣습니다.
  2. a/2R = 2 × (b/2R) × (a² + b² − c²)/2ab
  3. 양변에 2Ra를 곱해 정리하면 a² = a² + b² − c², 즉 b² = c²
  4. b = c인 이등변삼각형

답: b = c인 이등변삼각형

문제 9

정리

외접원의 반지름이나 마주 보는 변과 각 한 쌍을 알면 사인법칙을 씁니다.

사인법칙을 쓸 때 조심할 점이 있습니다. 두 변과 한 변의 대각을 알면 sin B의 값에서 B가 예각인 경우와 둔각(180° − B)인 경우가 모두 가능할 수 있어, 삼각형이 두 개 생길 수도 있습니다. 두 경우 모두 세 각의 합이 180°를 넘지 않는지 확인합니다.
