네 가지 평균

양수 a, b에 대해 조화평균 2ab/(a + b), 기하평균 √(ab), 산술평균 (a + b)/2, 제곱평균 √((a² + b²)/2)이 있습니다.

이 넷 사이에는 조화평균 ≤ 기하평균 ≤ 산술평균 ≤ 제곱평균이 성립하고, 모든 등호는 a = b일 때입니다.

평균이 이렇게 여러 개인 이유는 상황마다 '공정한 평균'이 다르기 때문입니다. 같은 거리를 다른 속력으로 오갈 때의 평균 속력은 조화평균이고, 넓이가 같은 정사각형의 한 변은 기하평균입니다. 부등식 문제에서는 이 사슬의 어느 두 고리를 쓰느냐가 풀이를 정합니다.

문제 1

a = 2, b = 8일 때 조화평균 2ab/(a + b)를 분수로 쓰세요.

문제 2

a = 1, b = 7일 때 제곱평균 √((a² + b²)/2)의 값은?

사슬의 증명

산술평균 ≤ 제곱평균은 (a + b)²/4 ≤ (a² + b²)/2와 같고, 정리하면 (a − b)² ≥ 0입니다.

조화평균 ≤ 기하평균은 1/a, 1/b에 AM-GM을 쓰면 나옵니다. (1/a + 1/b)/2 ≥ √(1/(ab))에서 역수를 취하면 2/(1/a + 1/b) ≤ √(ab)입니다.

역수를 취하면 부등호 방향이 바뀌는데, 양변이 양수이기 때문에 가능합니다. 이 사슬에서 자주 쓰는 결과가 둘 있습니다. (a + b)(1/a + 1/b) ≥ 4는 산술평균 ≥ 조화평균이고, a² + b² ≥ (a + b)²/2는 제곱평균 ≥ 산술평균입니다. 세 수 이상에서도 같은 사슬이 성립합니다.

예제

양수 a, b에 대해 (a + b)(1/a + 1/b) ≥ 4임을 보이세요.

  1. 전개하면 1 + a/b + b/a + 1 = 2 + a/b + b/a입니다.
  2. a/b와 b/a는 양수이고 곱이 1이므로 a/b + b/a ≥ 2입니다.
  3. 따라서 (a + b)(1/a + 1/b) ≥ 4입니다.
  4. 등호는 a = b일 때입니다. 이 식은 '산술평균 ≥ 조화평균'을 다르게 쓴 것입니다.

답: ≥ 4

실수 a, b가 a + b = 2를 만족할 때 a² + b²의 최솟값은?

문제 5

a² + b² ≥ (a + b)²/＿＿＿입니다.

평균 속력은 조화평균

같은 거리 d를 갈 때 속력 u, 올 때 속력 v로 움직이면, 전체 시간은 d/u + d/v이고 전체 거리는 2d입니다.

평균 속력은 2d/(d/u + d/v) = 2uv/(u + v)로, u와 v의 조화평균입니다.

많은 사람이 (u + v)/2라고 답하지만, 느린 쪽에서 더 오래 머물기 때문에 평균은 산술평균보다 작습니다. 조화평균 ≤ 산술평균이라는 사슬이 바로 이 직관을 말해 줍니다. 시간이 같으면 산술평균, 거리가 같으면 조화평균이라고 기억하면 됩니다.

문제 6

같은 길을 갈 때 시속 60km, 올 때 시속 40km로 이동했습니다. 왕복 평균 속력(km/h)은?

문제 7

같은 거리를 시속 30km, 시속 60km로 한 번씩 이동했을 때 평균 속력(km/h)은?

정리

양수 a, b에 대해 조화평균 ≤ 기하평균 ≤ 산술평균 ≤ 제곱평균이고, 모든 등호는 a = b일 때입니다.

(a + b)(1/a + 1/b) ≥ 4와 a² + b² ≥ (a + b)²/2는 사슬의 두 끝을 쓴 것으로, 문제에서 매우 자주 나옵니다.

세 수 이상에서는 a² + b² + c² ≥ (a + b + c)²/3, (a + b + c)(1/a + 1/b + 1/c) ≥ 9처럼 쓰입니다. 합이 주어지고 제곱합의 최솟값을 묻는다면 제곱평균 ≥ 산술평균을, 합이 주어지고 역수합을 묻는다면 산술평균 ≥ 조화평균을 먼저 떠올리세요.
