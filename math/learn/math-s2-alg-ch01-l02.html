치환으로 연립하기

x를 바꾸어 식을 하나 더

f(x)와 f(1 − x)가 함께 나오는 식은 x를 1 − x로 바꾸어 식을 하나 더 만들고, 두 식을 연립해 f(x)를 구합니다.

f(x) + 2f(1 − x) = x에서 x → 1 − x로 바꾸면 f(1 − x) + 2f(x) = 1 − x입니다. 두 번째 식에 2를 곱해 첫 식을 빼면 3f(x) = 2(1 − x) − x = 2 − 3x이므로 f(x) = (2 − 3x)/3입니다.

구한 f를 원래 식에 넣어 확인하는 것을 잊지 마세요: (2 − 3x)/3 + 2(2 − 3(1 − x))/3 = (2 − 3x − 2 + 6x)/3 = x.

문제 2

f(x) + 2f(1 − x) = x를 풀면 f(x) = (2 − ＿＿＿x)/3입니다.

1/x로 바꾸기

f(x)와 f(1/x)가 함께 나오면 x → 1/x로 바꿉니다. 2f(x) + f(1/x) = x (x ≠ 0)에서 바꾸면 2f(1/x) + f(x) = 1/x입니다.

첫 식의 2배에서 두 번째 식을 빼면 3f(x) = 2x − 1/x이므로 f(x) = (2x − 1/x)/3 = (2x² − 1)/(3x)입니다.

치환 x → 1 − x, x → 1/x, x → −x는 두 번 하면 제자리로 돌아오므로 식 두 개로 연립이 끝납니다.

예제

2f(x) + f(1/x) = x (x ≠ 0)일 때 f(2)를 구하세요.

  1. x → 1/x로 바꾸면 2f(1/x) + f(x) = 1/x입니다.
  2. 연립하면 f(x) = (2x − 1/x)/3입니다.
  3. x = 2를 넣으면 (4 − 1/2)/3입니다.
  4. = (7/2)/3 = 7/6입니다.

답: 7/6

세 번 돌아오는 치환

x → 1/(1 − x)는 세 번 하면 제자리로 돌아옵니다: x → 1/(1 − x) → (x − 1)/x → x. 그래서 f(x) + f(1/(1 − x)) = g(x) 꼴은 식 세 개를 연립합니다.

예: f(x) + f(1/(1 − x)) = x (x ≠ 0, 1). A = f(x), B = f(1/(1 − x)), C = f((x − 1)/x)라 하면 A + B = x, B + C = 1/(1 − x), C + A = (x − 1)/x입니다.

세 식을 더해 2로 나눈 뒤 B + C를 빼면 A = (x − 1/(1 − x) + (x − 1)/x)/2입니다.

정리

f(x)와 f(φ(x))가 함께 나오면 x를 φ(x)로 바꾸어 식을 더 만들고 연립합니다. φ(x) = 1 − x, 1/x, −x는 두 번, φ(x) = 1/(1 − x)는 세 번 하면 제자리로 돌아옵니다.

식이 k개면 미지수 f(x), f(φ(x)), …도 k개라 일차연립방정식으로 풀립니다.

구한 f는 반드시 원래 식에 넣어 확인합니다.
