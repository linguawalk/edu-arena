점화식으로 일반항 구하기

대수 · 7. 수학적 귀납법 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

aₙ₊₁ = paₙ + q 꼴

α = pα + q를 만족하는 α를 찾으면 aₙ₊₁ − α = p(aₙ − α)가 되어, aₙ − α가 공비 p인 등비수열입니다.

예: aₙ₊₁ = 2aₙ + 1이면 α = −1이므로 aₙ + 1이 공비 2인 등비수열입니다.

왜 α를 찾을까요? aₙ₊₁ = paₙ + q에서 양변에 −α를 하면 aₙ₊₁ − α = paₙ + q − α입니다. α = pα + q이면 q − α = −pα가 되어 aₙ₊₁ − α = p(aₙ − α)로 깔끔하게 정리됩니다. 새 수열 bₙ = aₙ − α가 등비수열이므로 일반항을 구할 수 있습니다.

예제

a₁ = 3, aₙ₊₁ = 3aₙ − 4의 일반항을 구하세요.

  1. α = 3α − 4에서 α = 2
  2. aₙ₊₁ − 2 = 3(aₙ − 2)이므로 aₙ − 2는 첫째항 1, 공비 3인 등비수열
  3. aₙ − 2 = 3ⁿ⁻¹
  4. aₙ = 3ⁿ⁻¹ + 2 (확인: a₂ = 5 = 3 × 3 − 4)

답: aₙ = 3ⁿ⁻¹ + 2

문제 1

a₁ = 1, aₙ₊₁ = 2aₙ + 1일 때 a₆의 값은?

문제 2

a₁ = 2, aₙ₊₁ = 3aₙ − 2일 때 a₄의 값은?

계차가 주어진 점화식

aₙ₊₁ − aₙ = f(n)이면 aₙ = a₁ + Σ(k=1~n−1) f(k)입니다.

계차가 주어진 점화식은 앞 레슨의 '더해 가기'를 Σ로 한 번에 쓴 것입니다. f(k)가 k에 대한 다항식이면 Σk, Σk² 공식으로, 지수식이면 등비수열의 합 공식으로 계산합니다. 더하는 범위가 k = n − 1까지라는 점을 꼭 지킵니다.

예제

a₁ = 1, aₙ₊₁ − aₙ = 2ⁿ의 일반항을 구하세요.

  1. aₙ = 1 + Σ(k=1~n−1) 2ᵏ
  2. Σ(k=1~n−1) 2ᵏ = 2(2ⁿ⁻¹ − 1) = 2ⁿ − 2
  3. aₙ = 2ⁿ − 1
  4. 확인: 1, 3, 7, 15, …

답: aₙ = 2ⁿ − 1

문제 3

a₁ = 2, aₙ₊₁ − aₙ = 2n일 때 a₁₀의 값은?

문제 4

a₁ = 1, aₙ₊₁ − aₙ = 3ⁿ일 때 a₄의 값은?

합 Sₙ이 주어진 경우

aₙ₊₁ = Sₙ₊₁ − Sₙ을 이용해 aₙ 사이의 관계식을 만듭니다.

Sₙ에 대한 식이 주어지면 n 대신 n + 1을 넣은 식을 하나 더 만들어 빼 봅니다. Sₙ₊₁ − Sₙ = aₙ₊₁이므로 합이 사라지고 항들만의 관계식이 남습니다. 첫째항은 S₁ = a₁로 따로 구하고, 구한 관계식이 n = 1부터 성립하는지도 확인합니다.

예제

Sₙ = 3aₙ − 2일 때 일반항을 구하세요.

  1. n = 1: a₁ = 3a₁ − 2에서 a₁ = 1
  2. Sₙ₊₁ − Sₙ: aₙ₊₁ = 3aₙ₊₁ − 3aₙ → 2aₙ₊₁ = 3aₙ
  3. aₙ₊₁ = (3/2)aₙ, 공비 3/2인 등비수열
  4. aₙ = (3/2)ⁿ⁻¹

답: aₙ = (3/2)ⁿ⁻¹

문제 6

Sₙ = n² − n일 때 a₁₀의 값은?

곱의 꼴

aₙ₊₁ = f(n)aₙ은 차례로 곱해 약분합니다.

f(n)이 분수이면 곱할 때 이웃한 분자와 분모가 약분됩니다. 예를 들어 (1/2)(2/3)(3/4)…((n − 1)/n) = 1/n처럼 처음 분자와 마지막 분모만 남습니다. 망원급수의 곱셈 버전이라고 할 수 있으며, 몇 항만 써 보면 약분 규칙이 바로 보입니다.

문제 7

a₁ = 1, aₙ₊₁ = (n/(n + 1))aₙ일 때 a₁₀의 값은? (기약분수로)

문제 8

a₁ = 1, aₙ₊₁ = ((n + 2)/n)aₙ일 때 a₅의 값은?

점화식 세우기

n단계와 n + 1단계의 관계를 식으로 세우면 복잡한 세기 문제도 풀 수 있습니다.

하노이의 탑, 계단 오르기, 평면 나누기처럼 직접 세기 어려운 문제도, n번째와 n + 1번째 상황의 관계만 찾으면 점화식을 세울 수 있습니다. 점화식을 세운 뒤에는 차례로 계산하거나 일반항을 구하면 됩니다.
