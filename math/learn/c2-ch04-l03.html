x축과의 교점

y = ax² + bx + c의 그래프가 x축과 만나는 점의 x좌표는 ax² + bx + c = 0의 실근입니다.

그래프와 방정식을 연결하는 핵심입니다. y = 0인 곳이 x축이므로, 그래프가 x축과 만나는 점을 찾는 것은 ax² + bx + c = 0을 푸는 것과 같습니다. 방정식을 그래프로 보면 해의 개수를 눈으로 확인할 수 있습니다.

문제 3

판별식과 위치 관계

D > 0이면 두 점에서 만나고, D = 0이면 접하고, D < 0이면 만나지 않습니다.

판별식이 그래프에서 무엇을 뜻하는지 연결해 봅니다. D > 0이면 실근 두 개로 x축을 두 번 가로지르고, D = 0이면 중근으로 꼭짓점이 x축 위에 있고, D < 0이면 실근이 없어 x축과 떨어져 있습니다.

예제

y = x² − 2x + k의 그래프가 x축과 서로 다른 두 점에서 만나는 k의 범위를 구하세요.

  1. x² − 2x + k = 0이 서로 다른 두 실근을 가져야 합니다.
  2. D/4 = 1 − k > 0
  3. k < 1

답: k < 1

두 교점 사이의 거리

x축과의 두 교점 사이의 거리는 두 근의 차 |α − β|이고, (α − β)² = (α + β)² − 4αβ로 구할 수 있습니다.

근을 직접 구하지 않아도 근과 계수의 관계로 두 근의 합과 곱을 알면 (α − β)²을 계산할 수 있습니다. 근이 무리수일 때 특히 편리합니다.

예제

y = x² − 6x + 4의 그래프가 x축과 만나는 두 점 사이의 거리를 구하세요.

  1. 근과 계수의 관계: α + β = 6, αβ = 4
  2. (α − β)² = 36 − 16 = 20
  3. |α − β| = √20 = 2√5

답: 2√5

이차부등식과 그래프

ax² + bx + c < 0의 해는 그래프가 x축보다 아래에 있는 x의 범위입니다.

부등식을 그래프로 풀면 부호의 변화를 한눈에 볼 수 있습니다. 아래로 볼록한 포물선은 두 근 사이에서 x축 아래(음수), 바깥에서 x축 위(양수)에 있습니다.

문제 10

그림은 y = (x + 1)(x − 3)의 그래프입니다. −3 ≤ x ≤ 5인 정수 중 y ≥ 0을 만족하는 x는 몇 개일까요?

근의 위치

f(x) = x² + bx + c에서 f(k) < 0이면 그래프가 x = k에서 x축 아래에 있으므로, k는 두 근 사이에 있습니다.

왜 f(k) < 0이면 k가 두 근 사이일까요? 아래로 볼록한 포물선에서 x축 아래에 있는 부분은 두 근 사이뿐입니다. 그래서 근의 위치 문제는 특정한 x에서의 함숫값 부호로 판단할 수 있습니다.

예제

x² − (k + 1)x + k − 3 = 0의 두 근 사이에 1이 있도록 하는 k의 범위를 구하세요.

  1. f(x) = x² − (k + 1)x + k − 3이라 하면 f(1) < 0이어야 합니다.
  2. f(1) = 1 − k − 1 + k − 3 = −3
  3. 항상 −3 < 0이므로 모든 실수 k에서 성립

답: 모든 실수 k
