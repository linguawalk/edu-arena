수열

차례로 나열된 수의 열을 수열이라 하고, n번째 항을 aₙ으로 씁니다.

aₙ을 n에 대한 식으로 나타낸 것을 일반항이라고 합니다.

수열은 자연수 n을 넣으면 수 aₙ이 하나씩 나오는 함수라고 볼 수 있습니다. 정의역이 자연수라서 그래프를 그리면 이어진 선이 아니라 점들이 띄엄띄엄 찍힙니다. 일반항을 알면 몇 번째 항이든 바로 계산할 수 있어, 앞의 항을 모두 적을 필요가 없습니다.

aₙ = 2n + 1일 때 a₅의 값은?

문제 2

1, 4, 9, 16, … 다음 수는?

등차수열

첫째항부터 차례로 일정한 수 d를 더해 만든 수열을 등차수열, d를 공차라고 합니다.

일반항은 aₙ = a + (n − 1)d입니다.

왜 (n − 1)d일까요? 첫째항에서 제n항까지 가는 동안 공차를 더하는 횟수는 n − 1번입니다(제2항에서 1번, 제3항에서 2번…). 그래서 aₙ = a + (n − 1)d입니다. 이 식은 n에 대한 일차식이므로, 등차수열은 기울기가 d인 일차함수의 자연수 부분과 같습니다.

예제

제5항이 14, 제12항이 35인 등차수열의 일반항을 구하세요.

  1. a₁₂ − a₅ = 7d = 35 − 14 = 21
  2. d = 3
  3. a₅ = a + 4d = a + 12 = 14에서 a = 2
  4. aₙ = 2 + 3(n − 1) = 3n − 1

답: aₙ = 3n − 1

등차중항

세 수 a, b, c가 이 순서로 등차수열을 이루면 2b = a + c이고, b를 등차중항이라고 합니다.

등차수열에서 가운데 항은 양옆 항의 평균입니다. b − a = c − b = d이므로 2b = a + c가 됩니다. 세 수가 등차수열이라는 조건이 나오면 가운데 수를 기준으로 a − d, a, a + d로 놓으면 계산이 편합니다.

문제 8

첫째항이 50, 공차가 −3인 등차수열에서 처음으로 음수가 되는 항은 제몇항일까요?

등차수열의 합

첫째항부터 제n항까지의 합은 Sₙ = n(a₁ + aₙ)/2 = n{2a + (n − 1)d}/2입니다.

왜 이 공식일까요? 합 Sₙ을 앞에서부터 쓴 것과 뒤에서부터 쓴 것을 위아래로 더하면, 짝지은 두 항의 합이 모두 a₁ + aₙ으로 같고 그런 짝이 n개 생깁니다. 그래서 2Sₙ = n(a₁ + aₙ)입니다. 가우스가 1부터 100까지를 50 × 101로 계산한 방법과 같습니다.

예제

첫째항이 5, 제15항이 47인 등차수열의 첫째항부터 제15항까지의 합을 구하세요.

  1. Sₙ = n(a₁ + aₙ)/2를 씁니다.
  2. S₁₅ = 15 × (5 + 47)/2
  3. = 15 × 26 = 390
  4. 확인: 공차 d = (47 − 5)/14 = 3

답: 390

문제 11

첫째항이 2, 공차가 3인 등차수열의 첫째항부터 제20항까지의 합은?

합에서 일반항 구하기

aₙ = Sₙ − Sₙ₋₁ (n ≥ 2), a₁ = S₁

Sₙ은 제n항까지의 합이고 Sₙ₋₁은 제(n − 1)항까지의 합이므로 둘의 차가 바로 aₙ입니다. 다만 n = 1이면 S₀이 없으므로 a₁ = S₁을 따로 구하고, 이 값이 aₙ의 식에 n = 1을 넣은 값과 같은지 꼭 확인합니다.

예제

Sₙ = 2n² − n일 때 일반항 aₙ을 구하세요.

  1. n ≥ 2: aₙ = Sₙ − Sₙ₋₁ = (2n² − n) − {2(n − 1)² − (n − 1)}
  2. = 2n² − n − 2n² + 5n − 3 = 4n − 3
  3. n = 1: a₁ = S₁ = 1이고 4 × 1 − 3 = 1로 같음
  4. aₙ = 4n − 3 (공차 4인 등차수열)

답: aₙ = 4n − 3
