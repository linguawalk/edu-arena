항등식과 미정계수

x에 어떤 값을 넣어도 성립하는 등식이 항등식입니다.

양변의 같은 차수 항의 계수를 비교하면 모르는 계수를 찾을 수 있습니다.

왜 계수를 비교할 수 있을까요? 모든 x에서 같은 두 다항식은 사실상 같은 식이므로, 같은 차수의 계수가 하나라도 다르면 어떤 x에서는 값이 달라집니다. 그래서 계수가 모두 같아야 합니다.

문제 1

x² + ax + 3 = (x + 1)(x + b)가 x에 대한 항등식일 때 a의 값은?

문제 2

같은 식에서 b의 값은?

나머지정리

다항식 f(x)를 x − a로 나눈 나머지는 f(a)입니다.

f(x) = (x − a)Q(x) + R에 x = a를 넣으면 f(a) = R이 되기 때문입니다.

나머지정리의 핵심은 '실제로 나누지 않고도 나머지를 안다'는 점입니다. 긴 나눗셈 대신 f(a) 하나만 계산하면 되므로 차수가 높을수록 훨씬 빠릅니다.

예제

f(x) = 2x³ − 3x² + x − 5를 x − 2로 나눈 나머지를 구하세요.

  1. 나머지정리: x − 2로 나눈 나머지는 f(2)
  2. f(2) = 2 × 8 − 3 × 4 + 2 − 5
  3. = 16 − 12 + 2 − 5 = 1

답: 1

문제 4

문제 5

x³ + ax + 2를 x − 1로 나눈 나머지가 5일 때 a의 값은?

인수정리

f(a) = 0이면 f(x)는 x − a로 나누어떨어지고, x − a는 f(x)의 인수입니다.

a³ − b³ = (a − b)(a² + ab + b²), a³ + b³ = (a + b)(a² − ab + b²)

인수정리는 나머지정리에서 나머지가 0인 특별한 경우입니다. f(a) = 0을 찾으면 x − a를 인수로 떼어 낼 수 있어, 고차식을 차수가 낮은 식들의 곱으로 쪼갤 수 있습니다.

x³ − 3x² + kx − 2가 x − 1을 인수로 가질 때 k의 값은?

문제 7

x³ − 1 = (x − 1)(x² + x + ＿＿＿)

문제 8

x³ + 8 = (x + 2)(x² − ＿＿＿x + 4)

고차식의 인수분해

f(1), f(−1), f(2)처럼 상수항의 약수를 넣어 f(a) = 0인 a를 찾고, 조립제법으로 나눕니다.

x² = t처럼 치환하거나, 완전제곱식을 만들어 A² − B² 꼴로 바꾸는 방법도 있습니다.

왜 상수항의 약수를 넣을까요? 계수가 정수이고 최고차항의 계수가 1이면, f(x) = (x − a)(…)에서 상수항은 a와 다른 정수들의 곱이므로 a는 상수항의 약수여야 하기 때문입니다.

예제

x³ − 4x² + x + 6을 인수분해하세요.

  1. 상수항 6의 약수 ±1, ±2, ±3을 넣어 봅니다: f(−1) = −1 − 4 − 1 + 6 = 0
  2. x + 1이 인수 → 조립제법으로 나누면 몫 x² − 5x + 6
  3. x² − 5x + 6 = (x − 2)(x − 3)
  4. 따라서 (x + 1)(x − 2)(x − 3)

답: (x + 1)(x − 2)(x − 3)

문제 12

x⁴ + x² + 1 = (x² + x + 1)(x² − x + ＿＿＿)

이차식으로 나눈 나머지

이차식으로 나눈 나머지는 일차 이하이므로 ax + b로 놓습니다.

f(x) = (x − 1)(x − 2)Q(x) + ax + b에 x = 1, 2를 넣어 a, b를 구합니다.

왜 ax + b로 놓을까요? 이차식으로 나눈 나머지는 이차보다 차수가 낮아야 하므로 일차식이나 상수입니다. 두 경우를 모두 포함하려고 ax + b(a = 0이면 상수)로 놓습니다.

예제

f(x)를 x + 1로 나눈 나머지가 2, x − 3으로 나눈 나머지가 10일 때 (x + 1)(x − 3)으로 나눈 나머지를 구하세요.

  1. 나머지를 ax + b로 놓으면 f(x) = (x + 1)(x − 3)Q(x) + ax + b
  2. x = −1: f(−1) = −a + b = 2
  3. x = 3: f(3) = 3a + b = 10
  4. 두 식을 빼면 4a = 8, a = 2, b = 4

답: 2x + 4
