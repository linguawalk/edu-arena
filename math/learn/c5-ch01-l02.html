중복순열

서로 다른 n개에서 중복을 허락해 r개를 늘어놓는 방법은 nΠr = nʳ입니다. 자리마다 n가지를 고를 수 있기 때문입니다.

순열에서는 한 번 쓴 것을 다시 쓸 수 없어 n, n − 1, n − 2, …로 줄어들었지만, 중복순열은 매번 n가지를 모두 고를 수 있습니다. 그래서 자리마다 n가지를 r번 곱해 nʳ입니다. 중복을 허락하므로 r이 n보다 커도 됩니다.

문제 2

₂Π₅의 값은?

함수의 개수

원소가 m개인 X에서 원소가 n개인 Y로의 함수는 nᵐ개입니다. X의 원소마다 Y의 원소를 하나씩 고르기 때문입니다.

함수는 정의역의 원소마다 공역의 원소를 하나씩 대응시키는 것입니다. 정의역의 m개 원소가 각각 n가지 중 하나를 고르고, 같은 값을 골라도 되므로 중복순열 nᵐ입니다. 일대일함수는 같은 값을 고를 수 없어 순열 nPm이 됩니다.

예제

X = {1, 2, 3}에서 Y = {a, b, c}로의 함수 중 f(1) = a인 것은 몇 개일까요?

  1. f(1)은 a로 정해짐: 1가지
  2. f(2), f(3)은 각각 3가지 중 자유롭게
  3. 1 × 3 × 3 = 9
  4. 비교: 전체 함수는 3³ = 27개

답: 9개

숫자 만들기

중복을 허락하면 자리마다 쓸 수 있는 숫자를 곱합니다. 맨 앞자리 0과 짝수 조건을 먼저 처리합니다.

숫자 만들기에서는 '같은 숫자를 써도 되는가'를 먼저 확인합니다. 써도 되면 자리마다 독립적으로 고를 수 있어 곱하면 되고, 맨 앞자리의 0이나 끝자리의 짝수 같은 조건만 그 자리에서 선택지를 줄여 줍니다.

예제

0, 1, 2, 3, 4로 만드는 네 자리 짝수는? (같은 숫자 사용 가능)

  1. 맨 앞자리: 0 제외 4가지
  2. 끝자리: 0, 2, 4의 3가지
  3. 가운데 두 자리: 각각 5가지
  4. 4 × 5 × 5 × 3 = 300

답: 300개

신호 만들기

길이가 정해지지 않은 신호는 길이별로 중복순열을 구해 더합니다.

신호의 길이가 1, 2, 3, …으로 여러 가지이면 길이마다 경우가 겹치지 않으므로 합의 법칙으로 더합니다. 각 길이에서는 중복순열로 셉니다. 결과는 등비수열의 합이 됩니다. 모스 부호처럼 두 기호로 만드는 신호는 길이 n까지 2 + 4 + … + 2ⁿ가지입니다.

빈 곳이 없게 나누기

서로 다른 공을 서로 다른 상자에 빈 상자 없이 넣는 경우는 전체에서 빈 상자가 있는 경우를 빼서 셉니다.

빈 상자가 없는 경우를 직접 세기는 어렵습니다. 대신 전체 3⁴에서 '적어도 한 상자가 빈' 경우를 뺍니다. 이때 두 상자가 빈 경우가 두 번 빠지므로 다시 더해 주는 포함배제의 원리를 씁니다: 3⁴ − 3 × 2⁴ + 3 × 1⁴.

예제

서로 다른 사탕 5개를 두 아이에게 모두 나눠 줄 때 두 아이 모두 적어도 한 개씩 받는 방법은?

  1. 사탕마다 받을 아이 2가지: 2⁵ = 32
  2. 한 아이가 모두 받는 경우 2가지
  3. 32 − 2 = 30
  4. 원리: 전체에서 빈 경우를 뺌

답: 30
