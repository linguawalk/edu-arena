극대와 극소

f′(x)의 부호가 +에서 −로 바뀌는 점에서 극대, −에서 +로 바뀌는 점에서 극소입니다. 그때의 함숫값이 극댓값, 극솟값입니다.

극대는 '그 근처에서 가장 높은 점', 극소는 '그 근처에서 가장 낮은 점'입니다. 산봉우리와 골짜기처럼 증가하다 감소로 바뀌는 곳이 극대, 감소하다 증가로 바뀌는 곳이 극소입니다. 극댓값이 극솟값보다 항상 큰 것은 아니며, 구간 전체의 최댓값과도 다를 수 있습니다.

문제 2

같은 함수의 극솟값은?

f′(a) = 0이어도 극값이 아닐 수 있다

y = x³은 f′(0) = 0이지만 x = 0 양쪽에서 모두 증가하므로 극값이 아닙니다.

f′(a) = 0은 극값을 가질 필요조건일 뿐 충분조건이 아닙니다. 극값이 되려면 f′의 부호가 a의 양쪽에서 실제로 바뀌어야 합니다. 그래서 f′(x) = 0의 해를 구한 뒤 반드시 증감표로 부호 변화를 확인합니다.

예제

f(x) = x⁴ − 4x³의 극값을 조사하세요.

  1. f′(x) = 4x³ − 12x² = 4x²(x − 3)
  2. x = 0: 양쪽 모두 f′ < 0 (부호 변화 없음) → 극값 아님
  3. x = 3: − → + 로 바뀜 → 극소, f(3) = 81 − 108 = −27
  4. 극댓값은 없고 극솟값 −27

답: 극솟값 −27 (x = 0은 극값 아님)

극값 조건으로 계수 찾기

x = p에서 극값을 가지면 f′(p) = 0입니다. 두 극값 위치를 알면 f′(x) = 3(x − p)(x − q)로 놓을 수 있습니다.

삼차함수 f(x) = x³ + …의 도함수는 최고차항이 3x²인 이차식이고, 극값을 갖는 x가 p, q이면 그 두 근이 p, q입니다. 그래서 f′(x) = 3(x − p)(x − q)로 놓고 전개해 계수를 비교하면 모르는 계수를 한 번에 구할 수 있습니다.

예제

f(x) = x³ + ax² + bx + 1이 x = −1에서 극댓값 6을 가질 때 a, b를 구하세요.

  1. f′(−1) = 3 − 2a + b = 0
  2. f(−1) = −1 + a − b + 1 = a − b = 6
  3. 두 식을 더하면 3 − a = 6, a = −3, b = −9
  4. 확인: f′(x) = 3x² − 6x − 9 = 3(x − 3)(x + 1)에서 x = −1은 + → − (극대)

답: a = −3, b = −9

닫힌구간에서의 최대·최소

구간 안의 극값과 양 끝의 함숫값을 모두 비교해 가장 큰 값과 작은 값을 고릅니다.

왜 양 끝도 비교할까요? 극값은 '근처에서' 가장 크거나 작은 값이라, 구간의 끝에서 그보다 더 큰 값이 나올 수 있습니다. 닫힌구간에서 최댓값·최솟값은 극값 또는 양 끝의 함숫값 중에서 나오므로, 후보를 모두 계산해 비교합니다.

최적화

구하는 양을 한 변수의 함수로 나타내고, 그 변수의 범위에서 최대·최소를 찾습니다.

최적화 문제의 순서: ① 변수 x를 정하고 ② 구하는 양을 x의 함수로 나타내고 ③ x의 범위를 정하고(길이는 양수 등) ④ 미분해 극값을 찾고 ⑤ 범위의 양 끝과 비교합니다. 범위를 빼먹으면 현실에서 불가능한 답이 나올 수 있습니다.

예제

밑면이 정사각형이고 뚜껑이 없는 상자의 겉넓이가 48일 때 부피의 최댓값을 구하세요.

  1. 밑면 한 변 x, 높이 h: x² + 4xh = 48 → h = (48 − x²)/(4x)
  2. V = x²h = (48x − x³)/4 (0 < x < √48)
  3. V′ = (48 − 3x²)/4 = 0에서 x = 4
  4. h = 2, V = 32 (최대)

답: 32
