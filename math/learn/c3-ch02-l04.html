로그방정식

logₐ f(x) = k이면 f(x) = aᵏ로 바꿔 풉니다.

로그방정식의 기본은 로그를 지수 식으로 바꾸는 것입니다. logₐ f(x) = k는 'a를 k제곱하면 f(x)'라는 뜻이므로 f(x) = aᵏ입니다. 이렇게 하면 로그가 사라져 일반 방정식이 됩니다. 구한 해는 진수 f(x)가 양수인지 꼭 확인합니다.

문제 1

log₂ x = 3의 해는?

문제 2

log₃ (x + 1) = 2의 해는?

진수 조건 확인

로그의 성질로 식을 합친 뒤 풀고, 구한 해가 처음 식의 진수를 모두 양수로 만드는지 확인합니다.

logₐ x를 t로 치환하면 이차방정식이 되기도 합니다.

왜 확인이 필요할까요? log₂ x + log₂ (x − 2)를 log₂ x(x − 2)로 합치면, 원래 식에서는 x > 2여야 하는데 합친 식에서는 x(x − 2) > 0이면 되므로 x < 0인 값도 해로 나옵니다. 처음 식의 진수 조건을 먼저 적어 두고 마지막에 해를 걸러야 합니다.

예제

log₃ (x + 2) + log₃ (x − 4) = 3을 푸세요.

  1. 진수 조건: x + 2 > 0, x − 4 > 0 → x > 4
  2. 합치면 log₃ (x + 2)(x − 4) = 3 → (x + 2)(x − 4) = 27
  3. x² − 2x − 35 = 0 → (x − 7)(x + 5) = 0
  4. x > 4이므로 x = 7 (x = −5는 제외)

답: x = 7

문제 5

(log₂ x)² − 3 log₂ x + 2 = 0의 두 해의 곱은?

로그부등식

밑이 1보다 크면 진수의 대소가 그대로, 0과 1 사이이면 반대입니다. 진수 조건도 함께 씁니다.

로그함수 y = logₐ x는 a > 1이면 증가, 0 < a < 1이면 감소합니다. 그래서 밑이 1/2인 부등식은 진수의 대소가 반대가 됩니다. 그리고 로그부등식의 해는 항상 '진수 > 0'이라는 조건과의 공통부분이어야 합니다.

예제

log_(1/3) (x − 1) ≥ −2를 푸세요.

  1. 진수 조건: x − 1 > 0 → x > 1
  2. −2 = log_(1/3) 9이므로 log_(1/3) (x − 1) ≥ log_(1/3) 9
  3. 밑이 1보다 작아 진수의 대소가 반대: x − 1 ≤ 9 → x ≤ 10
  4. 진수 조건과 함께: 1 < x ≤ 10

답: 1 < x ≤ 10

생활 속 로그

pH = −log[H⁺], 소리의 세기 dB = 10 log (I/I₀)처럼 크기 차이가 아주 큰 양은 로그로 나타냅니다.

로그를 쓰면 곱셈적인 차이가 덧셈적인 차이로 바뀝니다. pH가 1 차이 나면 수소 이온 농도는 10배, 2 차이 나면 100배 차이입니다. 지진의 규모, 별의 밝기(등급)도 같은 원리로 나타냅니다.

문제 11

세기 I가 기준 I₀의 10⁶배인 소리는 몇 dB일까요?

몇 번 만에 넘을까

1.1ⁿ ≥ 2처럼 지수에 모르는 수가 있으면 양변에 상용로그를 취해 n ≥ log 2 / log 1.1로 풉니다.

왜 로그를 취할까요? 1.1ⁿ ≥ 2에서 n은 지수에 있어 바로 풀 수 없습니다. 양변에 상용로그를 취하면 n log 1.1 ≥ log 2로 n이 지수에서 내려오고, log 1.1 > 0이므로 나눠서 n의 범위를 구할 수 있습니다.

예제

log 2 ≈ 0.3010, log 3 ≈ 0.4771일 때 매년 50%씩 늘어나는 양이 처음 양의 10배 이상이 되는 것은 몇 년 후일까요?

  1. 1.5ⁿ ≥ 10에서 n log 1.5 ≥ 1
  2. log 1.5 = log 3 − log 2 ≈ 0.1761
  3. n ≥ 1 ÷ 0.1761 ≈ 5.68
  4. 처음으로 넘는 것은 6년 후

답: 6년 후
