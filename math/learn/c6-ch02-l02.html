타원의 방정식

기하 · 2. 타원 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

x²/a² + y²/b² = 1

두 초점이 (±c, 0)이고 거리의 합이 2a인 타원은 x²/a² + y²/b² = 1 (b² = a² − c²)입니다.

장축은 x축 위에 있고 꼭짓점은 (±a, 0), (0, ±b)입니다.

방정식은 정의에서 나옵니다. 점 (x, y)에서 두 초점 (±c, 0)까지의 거리의 합이 2a라는 식 √((x − c)² + y²) + √((x + c)² + y²) = 2a에서 근호를 하나씩 옮겨 두 번 제곱하고 정리하면 x²/a² + y²/(a² − c²) = 1이 됩니다. a² − c²을 b²으로 두면 표준형이 나옵니다.

문제 3

같은 타원의 초점은 (±＿＿＿, 0)

장축이 y축 위에 있을 때

분모가 큰 쪽이 장축입니다. x²/9 + y²/25 = 1은 장축이 y축 위에 있고 초점이 (0, ±4)입니다.

x²/a² + y²/b² = 1에서 x = 0을 넣으면 y = ±b, y = 0을 넣으면 x = ±a입니다. 그래서 분모가 큰 쪽 변수의 축 방향으로 더 길게 늘어난 모양이 되고, 초점도 긴 축 위에 있습니다. 분모를 비교하는 것만으로 장축의 방향을 알 수 있습니다.

예제

타원 x²/16 + y²/41 = 1의 장축의 길이와 초점을 구하세요.

  1. 분모가 큰 쪽이 y이므로 장축은 y축 위
  2. a² = 41, b² = 16, c² = 41 − 16 = 25
  3. 장축의 길이 2√41
  4. 초점 (0, ±5)

답: 장축 2√41, 초점 (0, ±5)

문제 5

같은 타원의 장축의 길이는?

방정식 세우기

a와 c를 찾아 b² = a² − c²으로 b²을 구하거나, 지나는 점을 대입합니다.

방정식을 세울 때는 a², b²만 알면 됩니다. 초점과 장축이 주어지면 b² = a² − c²으로, 꼭짓점이 주어지면 바로, 지나는 점이 주어지면 대입해서 구합니다. 원의 방정식에서 반지름을 구하던 것과 같은 방식입니다.

예제

두 초점이 (±2, 0)이고 점 (2, 3)을 지나는 타원의 방정식을 구하세요.

  1. c = 2이므로 b² = a² − 4
  2. (2, 3) 대입: 4/a² + 9/(a² − 4) = 1
  3. 정리하면 a⁴ − 17a² + 16 = 0에서 a² = 16 (a² > 4)
  4. x²/16 + y²/12 = 1

답: x²/16 + y²/12 = 1

문제 8

타원 x²/a² + y²/4 = 1이 점 (3, 0)을 지날 때 a²의 값은?

평행이동과 일반형

(x − p)²/a² + (y − q)²/b² = 1의 중심은 (p, q)입니다. 계수가 붙은 식은 양변을 나눠 우변을 1로 만듭니다.

4x² + 9y² = 36처럼 계수가 붙어 있으면 양변을 36으로 나눠 x²/9 + y²/4 = 1로 만듭니다. 평행이동한 타원은 괄호 안의 수로 중심을 읽고, a, b, c의 관계는 원래 타원과 같습니다.

예제

9x² + 4y² − 18x + 16y − 11 = 0의 중심과 장축의 길이를 구하세요.

  1. 완전제곱식: 9(x − 1)² − 9 + 4(y + 2)² − 16 − 11 = 0
  2. 9(x − 1)² + 4(y + 2)² = 36
  3. (x − 1)²/4 + (y + 2)²/9 = 1
  4. 중심 (1, −2), 장축의 길이 2 × 3 = 6

답: 중심 (1, −2), 장축 6

정리

a > b일 때 c² = a² − b². 분모가 큰 변수의 축 위에 초점이 있습니다.

타원의 방정식을 보면 먼저 분모를 비교해 큰 쪽을 a², 작은 쪽을 b²으로 정하고, c² = a² − b²으로 초점을 구합니다. 원(a = b)은 타원의 특별한 경우이므로, 원의 방정식도 x²/r² + y²/r² = 1로 볼 수 있습니다.
