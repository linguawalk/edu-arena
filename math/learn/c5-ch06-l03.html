표준화

X ~ N(m, σ²)이면 Z = (X − m)/σ는 평균 0, 표준편차 1인 표준정규분포 N(0, 1)을 따릅니다.

모든 정규분포를 하나의 표로 계산할 수 있게 됩니다.

왜 표준화할까요? 평균과 표준편차가 다른 정규분포마다 표를 따로 만들 수는 없습니다. X에서 평균을 빼면 평균이 0이 되고(평행이동), σ로 나누면 표준편차가 1이 됩니다(크기 조절). 앞 챕터의 E(aX + b), σ(aX + b) 공식을 그대로 쓴 것입니다. 이렇게 하면 모든 정규분포를 표준정규분포표 하나로 계산할 수 있습니다.

문제 1

X ~ N(50, 5²)에서 X = 60을 표준화한 값 Z는?

문제 2

같은 X에서 X = 45를 표준화한 값 Z는?

표 읽기

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

P(Z ≤ 1) = 0.5 + 0.3413처럼 0.5와 표의 값을 더하거나 뺍니다.

표준정규분포표는 보통 P(0 ≤ Z ≤ z), 즉 평균 0에서 z까지의 넓이를 알려 줍니다. 음수 z는 대칭으로 바꿔 읽고, 평균을 넘어가는 구간은 0.5를 더하거나 빼서 계산합니다. 그림을 그려 색칠하면 실수가 크게 줄어듭니다.

예제

P(−0.5 ≤ Z ≤ 1.5)를 구하세요.

  1. 평균 0을 사이에 끼므로 두 넓이를 더함
  2. P(−0.5 ≤ Z ≤ 0) = P(0 ≤ Z ≤ 0.5) = 0.1915
  3. P(0 ≤ Z ≤ 1.5) = 0.4332
  4. 합 0.6247

답: 0.6247

정규분포의 확률 계산

X를 Z로 바꾼 뒤 표의 값을 씁니다. 아래는 X ~ N(70, 10²)입니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

계산 순서는 항상 같습니다: ① X의 경계값을 Z = (X − m)/σ로 바꾸고 ② 구하는 구간을 표준정규분포 그림에 표시하고 ③ 표의 값에 0.5를 더하거나 빼거나, 두 값을 더하거나 뺍니다.

예제

X ~ N(50, 8²)일 때 P(46 ≤ X ≤ 62)를 구하세요.

  1. Z = (46 − 50)/8 = −0.5, Z = (62 − 50)/8 = 1.5
  2. P(−0.5 ≤ Z ≤ 1.5)
  3. = 0.1915 + 0.4332
  4. = 0.6247

답: 0.6247

확률에서 값 찾기

확률이 주어지면 표에서 z를 찾고 x = m + zσ로 되돌립니다.

거꾸로 가는 문제는 표에서 확률에 맞는 z를 먼저 찾고, 표준화 식 z = (x − m)/σ를 x에 대해 풀어 x = m + zσ로 되돌립니다. P(X ≥ a)처럼 꼬리 쪽 확률이 주어지면 0.5에서 빼서 표의 값을 먼저 만듭니다.

예제

점수가 N(72, 8²)을 따를 때 상위 2.28% 안에 들기 위한 최저 점수를 구하세요.

  1. P(Z ≥ z) = 0.0228이면 P(0 ≤ Z ≤ z) = 0.4772, z = 2
  2. x = m + zσ = 72 + 2 × 8
  3. = 88
  4. 88점 이상이면 상위 2.28%

답: 88점

비교와 활용

평균과 흩어짐이 다른 집단의 값을 비교할 때는 표준화한 값 Z로 비교합니다.

표준정규분포표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772, P(0 ≤ Z ≤ 2.5) = 0.4938, P(0 ≤ Z ≤ 3) = 0.4987

표준화한 값 Z는 '평균에서 표준편차 몇 개만큼 떨어졌는가'를 나타냅니다. 그래서 평균과 흩어짐이 다른 두 집단의 점수도 Z로 바꾸면 공정하게 비교할 수 있습니다. 학교의 표준점수가 바로 이 원리입니다. 표: P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 1.5) = 0.4332, P(0 ≤ Z ≤ 2) = 0.4772.
