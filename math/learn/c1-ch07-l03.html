행과 열의 곱

행렬의 곱 AB의 (i, j) 성분은 A의 i행과 B의 j열에서 같은 순서의 성분끼리 곱해 더한 값입니다.

A의 열 개수와 B의 행 개수가 같아야 곱할 수 있습니다.

왜 이렇게 곱할까요? 수량 [3 2]와 가격 [500 ; 1000]을 곱하면 3 × 500 + 2 × 1000으로 총액이 나옵니다. '행의 각 수 × 열의 각 수를 차례로 곱해 더하기'가 실제 계산에서 자연스럽게 필요한 연산이기 때문입니다.

[1 2]와 [3 ; 4]의 곱은? (1 × 1 행렬의 성분)

문제 2

(m × n 행렬) × (n × p 행렬)은 m × ＿＿＿ 행렬입니다.

2 × 2 행렬의 곱

[a b ; c d][p q ; r s] = [ap + br aq + bs ; cp + dr cq + ds]

(i, j) 성분을 구할 때는 A의 i행을 손가락으로 가로로, B의 j열을 세로로 짚으며 순서대로 곱해 더합니다. 네 성분을 하나씩 따로 계산하면 실수가 줄어듭니다.

예제

[2 1 ; 0 3][1 4 ; 2 −1]을 계산하세요.

  1. (1,1): 2 × 1 + 1 × 2 = 4, (1,2): 2 × 4 + 1 × (−1) = 7
  2. (2,1): 0 × 1 + 3 × 2 = 6, (2,2): 0 × 4 + 3 × (−1) = −3
  3. [4 7 ; 6 −3]

답: [4 7 ; 6 −3]

곱셈의 성질

단위행렬은 수의 1처럼 AE = EA = A입니다.

하지만 일반적으로 AB ≠ BA입니다. 곱하는 순서를 바꾸면 결과가 달라질 수 있습니다.

왜 AB ≠ BA일까요? AB는 A의 행과 B의 열을, BA는 B의 행과 A의 열을 곱하므로 계산에 쓰이는 수의 짝이 다릅니다. 그래서 (A + B)² 같은 곱셈공식도 수와 다르게 전개됩니다.

문제 9

이때 AB = BA일까요? (그렇다 1, 아니다 0)

거듭제곱의 규칙

A², A³을 직접 계산해 규칙을 찾으면 Aⁿ을 구할 수 있습니다.

A² = E이면 짝수 제곱은 E, 홀수 제곱은 A입니다.

거듭제곱을 직접 여러 번 곱하기는 번거롭습니다. A², A³ 정도만 계산하면 성분이 일정하게 늘어나거나 E로 돌아오는 규칙이 보여 큰 거듭제곱도 쉽게 구할 수 있습니다.

예제

A = [1 0 ; 2 1]일 때 A², A³을 구하고 Aⁿ의 규칙을 찾으세요.

  1. A² = [1 0 ; 4 1]
  2. A³ = A²A = [1 0 ; 6 1]
  3. (2, 1) 성분이 2씩 늘어나므로 Aⁿ = [1 0 ; 2n 1]

답: Aⁿ = [1 0 ; 2n 1]

문제 13

같은 A에서 A¹⁰⁰의 (1, 2) 성분은?

활용

수량 행렬과 가격 행렬을 곱하면 총액이 나옵니다.

(A + B)² = A² + AB + BA + B²이고, AB ≠ BA이면 A² + 2AB + B²과 다릅니다.

(A + B)² = (A + B)(A + B)를 전개하면 A², AB, BA, B²이 나옵니다. AB와 BA가 다르면 합쳐서 2AB로 쓸 수 없으므로 수의 곱셈공식과 결과가 달라집니다.

예제

A = [1 2 ; 0 1], B = [1 0 ; 3 1]일 때 AB와 BA의 (1, 1) 성분을 비교하세요.

  1. AB의 (1, 1): 1 × 1 + 2 × 3 = 7
  2. BA의 (1, 1): 1 × 1 + 0 × 0 = 1
  3. 7 ≠ 1이므로 AB ≠ BA

답: AB는 7, BA는 1 (AB ≠ BA)
