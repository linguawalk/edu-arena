다항함수의 미분법

미적분 · 2. 미분계수와 도함수 · 레벨1 · 약 15분 · 문제 16개

합, 차, 상수배

{f(x) ± g(x)}′ = f′(x) ± g′(x), {cf(x)}′ = cf′(x). 항마다 따로 미분하면 됩니다.

합과 상수배의 미분법은 극한의 성질에서 바로 나옵니다. 극한이 합과 상수배를 그대로 나눌 수 있으므로, 도함수의 정의 속 극한도 항마다 나눌 수 있습니다. 그래서 다항함수는 각 항을 따로 미분해 더하면 됩니다.

곱의 미분법

{f(x)g(x)}′ = f′(x)g(x) + f(x)g′(x)

왜 (fg)′ = f′g + fg′일까요? 가로 f, 세로 g인 직사각형의 넓이 fg를 생각하면, x가 조금 변할 때 넓이는 가로가 늘어난 부분(f′g)과 세로가 늘어난 부분(fg′)만큼 늘어납니다. (fg)′ = f′g′처럼 곱하는 것은 흔한 실수입니다.

예제

f(x) = (x² + 2)(3x − 1)의 도함수를 곱의 미분법으로 구하세요.

  1. f′ = (x² + 2)′(3x − 1) + (x² + 2)(3x − 1)′
  2. = 2x(3x − 1) + 3(x² + 2)
  3. = 6x² − 2x + 3x² + 6 = 9x² − 2x + 6
  4. 확인: 전개 3x³ − x² + 6x − 2를 미분해도 같음

답: 9x² − 2x + 6

거듭제곱의 미분

[{f(x)}ⁿ]′ = n{f(x)}ⁿ⁻¹ f′(x)

거듭제곱의 미분은 곱의 미분법을 반복한 결과입니다. {f(x)}²′ = f′f + ff′ = 2ff′처럼 나옵니다. 괄호 안의 식 f(x)를 미분한 f′(x)를 마지막에 꼭 곱해야 합니다. 전개해서 미분해도 같지만, 차수가 높으면 이 공식이 훨씬 빠릅니다.

예제

f(x) = (x³ − 2x)⁴일 때 f′(1)을 구하세요.

  1. f′(x) = 4(x³ − 2x)³ × (3x² − 2)
  2. x = 1: 괄호 안 1 − 2 = −1, 도함수 3 − 2 = 1
  3. 4 × (−1)³ × 1 = −4
  4. 주의: 안쪽 식의 도함수 (3x² − 2)를 빠뜨리지 않기

답: −4

미분계수로 계수 찾기

미분계수의 조건을 식으로 세우면 모르는 계수를 구할 수 있습니다.

미분계수의 조건 하나는 방정식 하나를 줍니다. 모르는 계수가 두 개이면 조건도 두 개가 필요합니다. f(a)의 값과 f′(a)의 값처럼 서로 다른 종류의 조건이 함께 주어지는 경우가 많습니다. 조건마다 식을 하나씩 적고 연립하면 됩니다.

문제 10

같은 조건에서 b의 값은?

극한과 미분계수

lim(x→a) (f(x) − f(a))/(x − a) = f′(a)를 이용해 식을 미분계수로 바꿉니다.

(x − a)²으로 나누어떨어진다는 것은 x = a가 f(x) = 0의 중근이라는 뜻이고, 이때 f(a) = 0과 f′(a) = 0이 모두 성립합니다. 그래프로 보면 x = a에서 x축에 접한다는 뜻입니다. 이 성질로 계수를 구할 수 있습니다.

예제

x³ + ax + b가 (x − 1)²으로 나누어떨어질 때 a, b를 구하세요.

  1. f(x) = x³ + ax + b라 하면 f(1) = 0, f′(1) = 0
  2. f′(x) = 3x² + a이므로 3 + a = 0, a = −3
  3. f(1) = 1 − 3 + b = 0에서 b = 2
  4. 확인: x³ − 3x + 2 = (x − 1)²(x + 2)

답: a = −3, b = 2
