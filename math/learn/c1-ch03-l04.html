정의와 정리

용어의 뜻을 명확하게 정한 문장이 정의, 참임이 증명된 명제 중 기본이 되는 것이 정리입니다.

왜 정의가 중요할까요? 증명은 정의에서 출발합니다. 예를 들어 '짝수'의 정의가 '2k 꼴인 정수'이므로, 짝수에 대한 증명은 n = 2k로 놓는 데서 시작합니다.

문제 2

대우를 이용한 증명

원래 명제를 직접 증명하기 어려우면 참, 거짓이 같은 대우를 증명합니다.

'n²이 짝수이면 n은 짝수'는 대우 'n이 홀수이면 n²은 홀수'를 보이면 됩니다.

왜 대우가 편할까요? 'n²이 짝수'라는 가정에서 n을 끌어내기는 어렵지만, 'n이 홀수'라는 가정은 n = 2k + 1로 바로 식으로 쓸 수 있습니다. 가정을 식으로 쓰기 쉬운 쪽을 고르는 것입니다.

예제

'n²이 3의 배수이면 n은 3의 배수'를 대우로 증명하는 방법을 설명하세요.

  1. 대우: 'n이 3의 배수가 아니면 n²은 3의 배수가 아니다'
  2. n = 3k + 1이면 n² = 3(3k² + 2k) + 1
  3. n = 3k + 2이면 n² = 3(3k² + 4k + 1) + 1
  4. 두 경우 모두 3으로 나눈 나머지가 1이므로 대우가 참

답: 대우가 참이므로 원래 명제도 참

절대부등식

모든 실수에 대해 항상 성립하는 부등식을 절대부등식이라고 합니다.

a > 0, b > 0이면 (a + b)/2 ≥ √(ab)이고, 등호는 a = b일 때 성립합니다. 산술평균과 기하평균의 관계입니다.

왜 성립할까요? (√a − √b)² ≥ 0을 전개하면 a − 2√(ab) + b ≥ 0, 즉 a + b ≥ 2√(ab)입니다. 제곱은 항상 0 이상이라는 사실 하나에서 나옵니다. 합이 일정하면 곱의 최댓값을, 곱이 일정하면 합의 최솟값을 구할 때 씁니다.

예제

x > 0일 때 2x + 8/x의 최솟값을 구하세요.

  1. 2x > 0, 8/x > 0이므로 산술평균과 기하평균의 관계를 씁니다.
  2. 2x + 8/x ≥ 2√(2x × 8/x) = 2√16 = 8
  3. 등호는 2x = 8/x, 즉 x = 2일 때

답: 최솟값 8 (x = 2)

다른 절대부등식

a² + b² ≥ 2ab. (a − b)² ≥ 0에서 나옵니다.

(a² + b²)(x² + y²) ≥ (ax + by)². 코시-슈바르츠 부등식입니다.

코시-슈바르츠 부등식에서 등호는 a : b = x : y일 때 성립합니다. 제곱의 합이 정해져 있을 때 일차식의 최댓값, 최솟값을 구하는 데 씁니다.

예제

x² + y² = 10일 때 x + 3y의 최댓값을 구하세요.

  1. 코시-슈바르츠: (1² + 3²)(x² + y²) ≥ (x + 3y)²
  2. 10 × 10 ≥ (x + 3y)²
  3. x + 3y ≤ 10
  4. 등호는 x : y = 1 : 3, 즉 x = 1, y = 3일 때

답: 10
