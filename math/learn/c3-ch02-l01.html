로그

a > 0, a ≠ 1일 때 aˣ = N을 만족하는 x를 logₐ N으로 씁니다. a를 밑, N을 진수라고 합니다.

2³ = 8이므로 log₂ 8 = 3입니다.

왜 로그가 필요할까요? 2ˣ = 8은 x = 3임을 바로 알지만, 2ˣ = 5처럼 정수로 나오지 않는 지수는 기존 기호로 쓸 방법이 없습니다. 그래서 '2를 몇 제곱해야 5가 되는가'라는 수 자체에 log₂ 5라는 이름을 붙인 것입니다. 로그는 지수를 구하는 연산이라고 기억하면 됩니다.

로그의 값 구하기

'밑을 몇 번 거듭제곱해야 진수가 되는가'를 묻는 것입니다. 진수가 분수나 근호이면 지수도 음수나 분수가 됩니다.

로그 값을 구할 때는 진수를 밑의 거듭제곱으로 바꾸는 것이 핵심입니다. 1/4 = 2⁻²이므로 log₂ (1/4) = −2, 2 = 4^(1/2)이므로 log₄ 2 = 1/2입니다. 진수가 1보다 작으면(밑이 1보다 클 때) 로그 값은 음수가 됩니다.

예제

log₃ (1/9)과 log₈ 2를 구하세요.

  1. 1/9 = 3⁻²이므로 log₃ (1/9) = −2
  2. 2 = 8^(1/3) (8 = 2³이므로 ³√8 = 2)
  3. log₈ 2 = 1/3
  4. 확인: 3⁻² = 1/9, 8^(1/3) = 2

답: −2, 1/3

지수와 로그 바꾸기

aˣ = N ⇔ x = logₐ N. 로그 식이 어려우면 지수 식으로 바꿔 생각합니다.

로그 문제가 막히면 지수 식으로 바꿔 보세요. logₓ 49 = 2는 x² = 49가 되어 x = 7(밑은 양수)로 바로 풀립니다. 두 식은 같은 관계를 다른 방향에서 쓴 것뿐입니다. 반대로 지수가 모르는 수인 2ˣ = 5 같은 식은 로그 식 x = log₂ 5로 바꿔 답을 나타냅니다.

예제

log_x 64 = 3과 log₄ x = −1/2을 푸세요.

  1. 첫째: x³ = 64 = 4³에서 x = 4 (밑 조건 x > 0, x ≠ 1 만족)
  2. 둘째: x = 4^(−1/2) = 1/√4 = 1/2
  3. 확인: log₄ (1/2) = −1/2

답: x = 4 / x = 1/2

문제 9

log₂ x = 5일 때 x의 값은?

로그가 정의될 조건

밑은 양수이고 1이 아니어야 하며, 진수는 양수여야 합니다.

왜 이런 조건이 필요할까요? 밑이 음수이면 (−2)^(1/2)처럼 실수가 아닌 값이 생기고, 밑이 1이면 1ˣ가 항상 1이라 로그 값을 하나로 정할 수 없습니다. 진수가 양수인 이유는 양수 밑의 거듭제곱 aˣ가 항상 양수이기 때문입니다.

예제

log_(x−2) (6 − x)가 정의되는 정수 x를 모두 구하세요.

  1. 밑: x − 2 > 0이고 x − 2 ≠ 1 → x > 2, x ≠ 3
  2. 진수: 6 − x > 0 → x < 6
  3. 2 < x < 6, x ≠ 3인 정수: 4, 5
  4. 주의: 밑이 1이 되는 x = 3을 빠뜨리기 쉽습니다.

답: 4, 5

정리

a^(logₐ N) = N, logₐ aˣ = x. 지수와 로그는 서로 되돌리는 관계입니다.

두 식은 지수와 로그가 서로 역함수라는 뜻입니다. log₂ 7은 '2를 몇 제곱하면 7인가'의 답이므로, 2를 그만큼 제곱하면 당연히 7이 됩니다. 이 관계는 로그 식을 간단히 할 때 자주 씁니다.
