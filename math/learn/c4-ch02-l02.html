접선의 기울기

f′(a)는 곡선 y = f(x) 위의 점 (a, f(a))에서 그은 접선의 기울기입니다.

두 점을 이은 직선에서 한 점을 다른 점에 한없이 가깝게 하면 접선이 됩니다.

왜 접선의 기울기일까요? 곡선 위의 두 점 (a, f(a)), (a + h, f(a + h))를 이은 할선의 기울기가 평균변화율입니다. h를 0에 가깝게 하면 두 번째 점이 첫 번째 점에 한없이 다가가고, 할선은 그 점에서 곡선에 살짝 닿는 접선으로 바뀝니다. 그 극한의 기울기가 f′(a)입니다.

미분가능성과 연속성

f′(a)가 존재하면 x = a에서 미분가능하다고 합니다. 미분가능하면 반드시 연속입니다.

하지만 y = |x|처럼 연속이어도 뾰족한 점에서는 미분가능하지 않습니다.

왜 미분가능하면 연속일까요? f(a + h) − f(a) = {(f(a + h) − f(a))/h} × h에서 h → 0이면 앞 부분은 f′(a), 뒤 h는 0이므로 곱은 0입니다. 즉 f(a + h) → f(a)라 연속입니다. 반대로 |x|는 x = 0에서 왼쪽 기울기 −1과 오른쪽 기울기 1이 달라 미분계수가 없습니다.

예제

f(x) = |x − 2|는 x = 2에서 미분가능한지 조사하세요.

  1. x > 2: f(x) = x − 2, 오른쪽 기울기 1
  2. x < 2: f(x) = −(x − 2), 왼쪽 기울기 −1
  3. 좌우 미분계수가 달라 x = 2에서 미분가능하지 않음
  4. 연속이지만 뾰족한 점입니다.

답: 미분가능하지 않다

매끄럽게 이어질 조건

범위마다 식이 다른 함수가 경계에서 미분가능하려면 연속이면서, 양쪽의 미분계수도 같아야 합니다.

경계에서 미분가능하려면 두 가지가 필요합니다. 먼저 끊기지 않아야 하므로(연속) 경계에서 두 식의 값이 같아야 하고, 뾰족하지 않아야 하므로 두 식을 미분한 값도 경계에서 같아야 합니다. 두 조건에서 식이 두 개 나와 모르는 계수 두 개를 구할 수 있습니다.

예제

f(x) = x³ (x < 1), ax + b (x ≥ 1)가 x = 1에서 미분가능할 때 a, b를 구하세요.

  1. 연속: 1 = a + b
  2. 미분계수: 왼쪽 3x²에서 3, 오른쪽 a
  3. a = 3
  4. b = 1 − 3 = −2

답: a = 3, b = −2

접선의 방정식

점 (a, f(a))에서의 접선은 y − f(a) = f′(a)(x − a)입니다.

접선은 '점 하나와 기울기'로 정해지는 직선입니다. 점은 (a, f(a)), 기울기는 f′(a)이므로 코스 2에서 배운 직선의 방정식 y − y₁ = m(x − x₁)에 그대로 넣으면 됩니다. 접점의 y좌표 f(a)를 구하는 것을 잊지 않도록 합니다.

예제

y = x² − 2x 위의 점 (3, 3)에서의 접선의 방정식을 구하세요.

  1. y′ = 2x − 2이므로 x = 3에서 기울기 4
  2. y − 3 = 4(x − 3)
  3. y = 4x − 9
  4. 확인: x = 3이면 y = 3

답: y = 4x − 9

정리

기울기만 필요하면 f′(a), 직선의 식이 필요하면 점과 기울기로 접선의 방정식을 씁니다.

접선 문제의 유형은 세 가지입니다. ① 접점이 주어짐 → f′(a)를 바로 계산 ② 기울기가 주어짐 → f′(x) = 기울기를 풀어 접점을 찾음 ③ 곡선 밖의 점이 주어짐 → 접점을 (t, f(t))로 놓고 접선이 그 점을 지나는 조건으로 t를 찾음.
