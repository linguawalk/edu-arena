합의 기호 Σ

대수 · 6. 수열 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

Σ 기호

a₁ + a₂ + … + aₙ을 Σ(k = 1부터 n까지) aₖ로 줄여 씁니다. 이 레슨에서는 Σ(k=1~n) aₖ로 적습니다.

Σ는 그리스 문자 시그마로, 합(Sum)의 머리글자입니다. Σ 아래의 k = 1은 시작 번호, 위의 n은 끝 번호이고, Σ 옆의 식에 k = 1, 2, …, n을 차례로 넣어 모두 더하라는 뜻입니다. k는 번호를 세는 문자라 다른 문자로 바꿔도 값은 같습니다.

Σ의 성질

Σ(aₖ + bₖ) = Σaₖ + Σbₖ, Σ c·aₖ = c Σaₖ, Σ(k=1~n) c = cn

Σ의 성질은 덧셈의 교환·결합·분배법칙을 줄여 쓴 것입니다. 주의할 점은 곱에 대해서는 성질이 없다는 것입니다. Σ aₖbₖ는 Σaₖ × Σbₖ와 다릅니다. 또 Σ c = cn은 상수 c를 n번 더한 것이므로 n을 곱합니다.

예제

Σ(k=1~n) aₖ = 8, Σ(k=1~n) aₖ² = 20일 때 Σ(k=1~n) (aₖ − 1)²을 n으로 나타내세요.

  1. (aₖ − 1)² = aₖ² − 2aₖ + 1로 전개
  2. Σaₖ² − 2Σaₖ + Σ1 = 20 − 16 + n
  3. = n + 4
  4. 주의: Σ1 = n (1을 n번 더함)

답: n + 4

문제 5

Σ(k=1~10) (k + 1)의 값은?

자연수의 거듭제곱의 합

Σk = n(n + 1)/2, Σk² = n(n + 1)(2n + 1)/6, Σk³ = {n(n + 1)/2}²

Σk는 등차수열의 합 공식에서 바로 나옵니다. Σk²은 (k + 1)³ − k³ = 3k² + 3k + 1을 k = 1부터 n까지 더해 유도할 수 있습니다. Σk³ = (Σk)²이라는 아름다운 관계도 있어, 세제곱의 합은 자연수의 합을 제곱하면 됩니다.

예제

Σ(k=1~6) k³을 구하고 (Σk)²과 비교하세요.

  1. Σk³ = {6 × 7/2}² = 21²
  2. = 441
  3. Σk = 21이므로 (Σk)² = 441로 같음
  4. 확인: 1 + 8 + 27 + 64 + 125 + 216 = 441

답: 441

문제 8

Σ(k=1~10) k²의 값은?

식을 나눠 계산

Σ 안의 식을 전개해 Σk², Σk, Σ(상수)로 나눈 뒤 공식을 씁니다.

Σ 안에 k(k + 1)처럼 곱이 있으면 먼저 k² + k로 전개해야 공식을 쓸 수 있습니다. 전개한 뒤 Σ의 성질로 Σk² + Σk로 나누면 각각 공식에 넣어 계산됩니다. 상수항이 생기면 Σ(상수) = 상수 × n도 잊지 않습니다.

예제

Σ(k=1~10) (k + 1)(k − 2)를 계산하세요.

  1. 전개: k² − k − 2
  2. Σk² − Σk − Σ2 = 385 − 55 − 20
  3. = 310
  4. 원리: 전개한 뒤 항별로 공식을 씁니다.

답: 310

문제 11

Σ(k=1~10) (k² − 1)의 값은?

범위 바꾸기

Σ(k=6~10) k = Σ(k=1~10) k − Σ(k=1~5) k처럼 처음부터의 합에서 빼서 구합니다.

공식은 모두 k = 1부터 시작하는 합이므로, 중간부터 시작하는 합은 '처음부터 끝까지'에서 '처음부터 시작 직전까지'를 뺍니다. Σ(k=6~10)은 Σ(k=1~10) − Σ(k=1~5)이며, 빼는 쪽의 끝이 5(=6 − 1)라는 점에 주의합니다.
