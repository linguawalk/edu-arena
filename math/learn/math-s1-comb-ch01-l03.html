중복조합과 별과 막대

수학 올림피아드 S1 예선 · 조합 · 1. 세기의 원리 심화 · 심화 · 약 20분 · 문제 11개

같은 것을 나누어 담기

x + y + z = 10을 만족하는 음이 아닌 정수 해의 개수를 구해 봅시다. 별 10개를 막대 2개로 세 칸으로 나누는 방법과 같습니다.

별 10개와 막대 2개, 모두 12개의 자리 중 막대가 들어갈 2자리를 고르면 되므로 C(12, 2) = 66개입니다.

일반적으로 x₁ + ⋯ + xₖ = n의 음이 아닌 정수 해는 C(n + k − 1, k − 1)개입니다. '같은 사탕 n개를 아이 k명에게 나누어 주기', '종류가 k가지인 과일을 중복 허용해 n개 고르기'가 모두 같은 문제입니다. 이것을 중복조합이라고 부르고, 별과 막대 그림이 그 증명입니다.

문제 1

x + y + z = 10을 만족하는 음이 아닌 정수 해 (x, y, z)는 몇 개인가요?

문제 2

x₁ + ⋯ + xₖ = n의 음이 아닌 정수 해의 개수는 C(n + k − 1, k − ＿＿＿)입니다.

양수 조건과 하한 조건

x + y + z = 10에서 x, y, z가 모두 1 이상이면, 먼저 각자에게 1씩 나누어 주고 남은 7을 자유롭게 나누면 됩니다. x' = x − 1 등으로 바꾸면 x' + y' + z' = 7의 음이 아닌 해이므로 C(9, 2) = 36개입니다.

x ≥ 2, y ≥ 1처럼 하한이 각각 다르면 그만큼씩 미리 빼고 같은 방법을 씁니다.

양수 해는 별 사이의 틈 n − 1개 중 k − 1개에 막대를 넣는 것으로 보아도 되므로 C(n − 1, k − 1)입니다. 상한 조건(x ≤ 4 등)은 이 방법만으로는 안 되고, 챕터 3의 포함-배제로 다룹니다.

문제 3

x + y + z = 10을 만족하는 자연수 해 (x, y, z)는 몇 개인가요?

문제 4

x + y + z + w = 12를 만족하는 자연수 해는 몇 개인가요?

예제

x + y + z = 10, x ≥ 2, y ≥ 1, z ≥ 0을 만족하는 정수 해의 개수를 구하세요.

  1. x' = x − 2, y' = y − 1로 놓으면 x', y', z ≥ 0입니다.
  2. x' + y' + z = 10 − 2 − 1 = 7입니다.
  3. 음이 아닌 해의 개수는 C(7 + 2, 2) = C(9, 2)입니다.
  4. 따라서 36개입니다.

답: 36

부등식과 단조수열

x + y + z ≤ 10의 음이 아닌 해는 남는 양 w = 10 − (x + y + z) ≥ 0을 넣어 x + y + z + w = 10의 해로 바꿉니다. C(13, 3) = 286개입니다.

1 ≤ a ≤ b ≤ c ≤ 5인 정수 (a, b, c)는 1~5에서 중복을 허용해 3개를 고르는 것과 같습니다. 고른 수를 작은 순서로 늘어놓으면 하나로 정해지기 때문입니다.

중복 허용 선택은 C(5 + 3 − 1, 3) = C(7, 3) = 35개입니다. 각 자리 숫자가 왼쪽에서 오른쪽으로 줄어들지 않는 수, 같은 공을 서로 다른 상자에 넣는 방법 등이 모두 이 꼴입니다. '순서가 정해져 있으면 고르기만 하면 된다'는 관점이 핵심입니다.

문제 5

x + y + z ≤ 10을 만족하는 음이 아닌 정수 해 (x, y, z)는 몇 개인가요?

문제 6

1 ≤ a ≤ b ≤ c ≤ 5를 만족하는 정수 (a, b, c)는 몇 개인가요?

문제 7

사과, 배, 감을 합쳐 8개 사는 방법은 몇 가지인가요? (한 종류도 안 살 수 있음)

정리

x₁ + ⋯ + xₖ = n의 음이 아닌 해는 C(n + k − 1, k − 1)개, 자연수 해는 C(n − 1, k − 1)개입니다(별과 막대).

하한 조건은 미리 빼서 음이 아닌 해로 바꾸고, ≤ 조건은 남는 양을 새 변수로 넣어 등식으로 바꿉니다.

순서가 정해진 수열(a ≤ b ≤ c)과 같은 물건의 분배는 중복조합으로 셉니다. 상한 조건이 있으면 포함-배제가 필요합니다.

각 자리 숫자가 1~9이고 왼쪽에서 오른쪽으로 줄어들지 않는 세 자리 수(예: 113, 259)는 몇 개인가요?

문제 9

같은 사탕 15개를 4명에게 나누어 줄 때 모두 적어도 2개씩 받는 방법은 몇 가지인가요?

문제 10

x₁ + x₂ + ⋯ + xₖ = n의 음이 아닌 정수 해의 개수가 C(n + k − 1, k − 1)임을 증명하세요.

문제 11

x + y + z = 10을 만족하는 자연수 해의 개수가 36임을 증명하세요.
