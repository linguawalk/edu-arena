합성함수

함수와 그래프 · 3. 함수 · 레벨1 · 약 15분 · 문제 16개

합성함수

f를 먼저 하고 그 결과에 g를 하는 함수를 합성함수 g∘f라 하고 (g∘f)(x) = g(f(x))로 씁니다.

g∘f는 '먼저 f, 그다음 g'입니다. 기호에서 오른쪽에 있는 f가 먼저 작용한다는 점이 헷갈리기 쉽습니다. g(f(x))로 쓰면 안쪽 f(x)부터 계산한다는 것이 분명해집니다.

문제 1

f(x) = x + 1, g(x) = 2x일 때 (g∘f)(3)의 값은?

문제 2

같은 f, g에서 (f∘g)(3)의 값은?

합성함수의 식

g(f(x))는 g의 식에서 x 자리에 f(x)를 통째로 넣습니다.

식으로 합성할 때는 바깥 함수의 x를 전부 괄호로 감싼 안쪽 함수로 바꿉니다. g(x) = x²이면 g(f(x)) = (f(x))²이므로 f(x) = x + 1일 때 (x + 1)²이 됩니다.

예제

f(x) = 2x − 1, g(x) = x² + 1일 때 (g∘f)(x)와 (f∘g)(x)를 구하세요.

  1. (g∘f)(x) = g(2x − 1) = (2x − 1)² + 1 = 4x² − 4x + 2
  2. (f∘g)(x) = f(x² + 1) = 2(x² + 1) − 1 = 2x² + 1
  3. 서로 다르므로 g∘f ≠ f∘g

답: 4x² − 4x + 2, 2x² + 1

문제 5

이때 g∘f와 f∘g는 같을까요? (같다 1, 다르다 0)

합성의 성질

일반적으로 g∘f ≠ f∘g입니다. 하지만 h∘(g∘f) = (h∘g)∘f는 항상 성립합니다.

순서를 바꾸면 결과가 달라지는 예: '1 더하고 제곱'은 (x + 1)², '제곱하고 1 더하기'는 x² + 1입니다. 그러나 세 함수를 합성할 때 어느 두 개를 먼저 묶든 결과는 같습니다(결합법칙).

문제 6

f(x) = 2x, g(x) = x − 3, h(x) = x²일 때 (h∘g∘f)(2)의 값은?

문제 7

f(x) = 3x − 1일 때 (f∘f)(1)의 값은?

모르는 함수 찾기

(g∘f)(x)와 f(x)를 알면 f(x)를 한 덩어리로 보고 g를 찾습니다.

g(2x + 1) = 4x + 5처럼 주어지면 우변을 2x + 1로 나타내 봅니다. 4x + 5 = 2(2x + 1) + 3이므로 g(□) = 2□ + 3, 즉 g(x) = 2x + 3입니다.

예제

f(x) = 3x − 2, (g∘f)(x) = 6x − 1일 때 g(x)를 구하세요.

  1. g(3x − 2) = 6x − 1
  2. 우변을 3x − 2로 나타냅니다: 6x − 1 = 2(3x − 2) + 3
  3. g(x) = 2x + 3

답: g(x) = 2x + 3

반복 합성

같은 함수를 여러 번 합성하면 규칙이 생깁니다. 몇 번 해 보고 반복 주기를 찾습니다.

반복 합성은 f, f∘f, f∘f∘f, …를 직접 몇 개 계산해 규칙을 찾습니다. f∘f가 항등함수가 되면 두 번마다 원래대로 돌아오므로 홀수 번은 f, 짝수 번은 항등함수입니다.

예제

f(x) = 1/(1 − x)일 때 f를 3번 합성한 함수를 구하세요.

  1. (f∘f)(x) = 1/(1 − 1/(1 − x)) = (1 − x)/(−x) = (x − 1)/x
  2. (f∘f∘f)(x) = f((x − 1)/x) = 1/(1 − (x − 1)/x) = 1/(1/x) = x
  3. 세 번 합성하면 항등함수

답: x (항등함수)
