기울기와 한 점

기울기가 m이고 점 (x₁, y₁)을 지나는 직선은 y − y₁ = m(x − x₁)입니다.

왜 이 식이 될까요? 직선 위의 점 (x, y)와 (x₁, y₁) 사이의 기울기가 항상 m이어야 하므로 (y − y₁)/(x − x₁) = m입니다. 양변에 x − x₁을 곱하면 y − y₁ = m(x − x₁)입니다.

문제 2

기울기가 −1이고 점 (2, 5)를 지나는 직선은 y = −x + ＿＿＿

두 점을 지나는 직선

두 점 (x₁, y₁), (x₂, y₂)를 지나는 직선의 기울기는 (y₂ − y₁)/(x₂ − x₁)입니다. x₁ = x₂이면 직선 x = x₁입니다.

두 점을 알면 기울기를 먼저 구하고, 두 점 중 하나를 골라 '기울기와 한 점' 공식에 넣습니다. 어느 점을 골라도 같은 직선이 나옵니다. x좌표가 같으면 기울기를 정할 수 없어 세로선 x = x₁이 됩니다.

예제

두 점 (−2, 5), (1, −1)을 지나는 직선의 방정식을 구하세요.

  1. 기울기: (−1 − 5)/(1 − (−2)) = −6/3 = −2
  2. 점 (1, −1)을 이용: y + 1 = −2(x − 1)
  3. y = −2x + 1

답: y = −2x + 1

절편으로 나타내기

x절편이 a, y절편이 b인 직선은 x/a + y/b = 1입니다.

왜 x/a + y/b = 1일까요? x = a, y = 0을 넣으면 1, x = 0, y = b를 넣으면 1이 되어 두 절편을 모두 지납니다. 절편이 주어진 문제는 이 꼴로 바로 쓰면 편리합니다.

문제 6

직선 x/2 + y/4 = 1과 x축, y축으로 둘러싸인 삼각형의 넓이는?

일반형

모든 직선은 ax + by + c = 0 꼴로 나타낼 수 있습니다. b ≠ 0이면 기울기는 −a/b입니다.

a = 0이면 x축에 평행, b = 0이면 y축에 평행한 직선입니다.

일반형은 세로선(x = k)까지 포함해 모든 직선을 한 가지 꼴로 나타냅니다. 기울기를 알고 싶으면 y에 대해 풀어 y = −(a/b)x − c/b 꼴로 바꾸면 됩니다.

예제

직선 3x − 2y + 6 = 0의 기울기, y절편, x절편을 구하세요.

  1. y에 대해 풀면 2y = 3x + 6, y = (3/2)x + 3
  2. 기울기 3/2, y절편 3
  3. y = 0을 넣으면 3x + 6 = 0, x절편 −2

답: 기울기 3/2, y절편 3, x절편 −2

세 점이 한 직선 위에

세 점이 한 직선 위에 있으면 어느 두 점을 골라도 기울기가 같습니다.

세 점이 한 직선 위에 있는지 확인하려면 두 쌍의 기울기를 비교합니다. 기울기가 다르면 한 점이 직선에서 벗어나 삼각형이 만들어집니다.

예제

세 점 (1, 2), (3, 6), (k, 10)이 한 직선 위에 있을 때 k를 구하세요.

  1. (1, 2), (3, 6)의 기울기: 4/2 = 2
  2. (1, 2), (k, 10)의 기울기: 8/(k − 1)
  3. 8/(k − 1) = 2에서 k − 1 = 4, k = 5

답: 5
