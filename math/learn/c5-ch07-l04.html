표본비율

크기 n인 표본에서 어떤 특성을 가진 것이 X개이면 표본비율은 p̂ = X/n입니다.

모비율이 p이면 E(p̂) = p, V(p̂) = p(1 − p)/n입니다.

표본비율 p̂는 앞 챕터의 'X/n' 그 자체입니다. X ~ B(n, p)이므로 E(p̂) = p, V(p̂) = p(1 − p)/n입니다. 즉 표본비율은 평균적으로 모비율과 같고, 표본이 클수록 모비율 근처에 모입니다. 모평균 추정에서 X̄가 하던 역할을 p̂가 합니다.

모비율의 신뢰구간

n이 충분히 크면 모비율 p의 신뢰도 95% 신뢰구간은 p̂ − 1.96√(p̂(1 − p̂)/n) ≤ p ≤ p̂ + 1.96√(p̂(1 − p̂)/n)입니다.

모비율 추정은 모평균 추정과 같은 구조입니다. 가운데는 표본비율 p̂, 반폭은 1.96 × (p̂의 표준편차)입니다. 다만 모비율 p를 모르므로 표준편차 √(p(1 − p)/n)의 p 자리에 표본비율 p̂를 넣어 계산합니다.

예제

900명 중 360명이 찬성했을 때 모비율의 신뢰도 95% 신뢰구간을 구하세요.

  1. p̂ = 360/900 = 0.4
  2. √(p̂(1 − p̂)/n) = √(0.24/900) = √0.24/30 ≈ 0.0163
  3. 1.96 × 0.0163 ≈ 0.032
  4. 0.368 ≤ p ≤ 0.432

답: 약 0.368 ≤ p ≤ 0.432

표본의 크기와 정밀도

표본이 클수록 √(p̂(1 − p̂)/n)이 작아져 신뢰구간이 좁아집니다.

여론조사에서 표본을 늘리면 오차가 줄어들지만, 오차는 1/√n에 비례하므로 오차를 절반으로 줄이려면 표본을 4배로 늘려야 합니다. 1,000명과 4,000명의 조사 결과의 정밀도 차이는 생각보다 크지 않습니다(오차가 절반).

필요한 표본의 크기

오차 1.96√(p(1 − p)/n)이 원하는 값 이하가 되도록 n을 구합니다. p를 모르면 가장 큰 경우인 p = 0.5로 계산합니다.

왜 p = 0.5로 계산할까요? p(1 − p)는 p = 0.5일 때 최댓값 0.25를 가집니다(이차함수의 꼭짓점). 모비율을 모를 때 가장 불리한 경우로 계산해 두면, 실제 비율이 무엇이든 오차가 원하는 값보다 커지지 않습니다.

예제

신뢰도 95%에서 오차를 0.02 이하로 하려면 표본의 크기는 최소 얼마여야 할까요? (p = 0.5로 계산)

  1. 1.96√(0.25/n) ≤ 0.02
  2. 1.96 × 0.5/√n ≤ 0.02에서 √n ≥ 49
  3. n ≥ 2401
  4. 최소 2401명

답: 2401

여론조사 읽기

'신뢰수준 95%에 오차 ±4%p'는 표본비율에서 4%p를 빼고 더한 범위가 95% 신뢰구간이라는 뜻입니다.

뉴스의 '신뢰수준 95%, 표본오차 ±3.1%p'는 1.96√(p̂(1 − p̂)/n) ≈ 0.031이라는 뜻입니다. 1,000명 조사에서 p̂ = 0.5이면 1.96 × √(0.25/1000) ≈ 0.031이 됩니다. 두 후보의 지지율 차이가 오차 범위 안이면 '오차 범위 내 접전'이라고 합니다.

예제

여론조사에서 A 후보 48%, B 후보 44%, 오차 ±3.1%p(신뢰도 95%)일 때 A가 앞선다고 확실히 말할 수 있을까요?

  1. A의 신뢰구간: 44.9% ~ 51.1%
  2. B의 신뢰구간: 40.9% ~ 47.1%
  3. 두 구간이 44.9% ~ 47.1%에서 겹침
  4. 오차 범위 내 접전이라 확실히 말할 수 없음

답: 말할 수 없다
