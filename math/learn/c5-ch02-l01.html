중복조합

서로 다른 n종류에서 중복을 허락해 r개를 고르는 방법은 nHr = n+r−1Cr입니다.

고른 r개와 칸막이 n − 1개를 일렬로 늘어놓는 것과 같기 때문입니다.

왜 n+r−1Cr일까요? 과일 3종류에서 5개를 고르는 상황을 ●●|●|●●처럼 나타내면, 칸막이 2개로 나뉜 세 칸이 각 종류의 개수가 됩니다. 결국 ● 5개와 | 2개, 모두 7자리 중 ●의 자리 5곳을 고르는 문제이므로 7C5입니다. 일반적으로 n종류면 칸막이 n − 1개가 필요해 n+r−1Cr가 됩니다.

문제 2

₄H₃의 값은?

방정식의 정수해

x + y + z = r의 음이 아닌 정수해는 ₃Hᵣ개입니다. 자연수해는 각 변수에 1씩 먼저 주고 나머지를 나눕니다.

x + y + z = r의 음이 아닌 정수해는 '똑같은 1을 r개, x, y, z 세 칸에 나눠 담는 방법'과 같습니다. 그래서 ₃Hᵣ입니다. 자연수해는 각 칸이 적어도 1이어야 하므로 먼저 1씩 담아 두고 남은 r − 3을 자유롭게 나눕니다.

예제

x + y + z = 9를 만족하는 자연수해의 개수를 구하세요.

  1. x, y, z에 1씩 먼저 줌: x′ + y′ + z′ = 6 (음이 아닌 정수)
  2. ₃H₆ = ₈C₆
  3. = ₈C₂ = 28
  4. 원리: 하한을 먼저 채우고 남은 양을 나눕니다.

답: 28

문제 4

문제 5

x + y + z = 7을 만족하는 자연수해는 몇 쌍일까요?

부등식과 하한 조건

x + y + z ≤ 3은 남는 양을 w로 두어 x + y + z + w = 3으로 바꿉니다.

x ≥ 1, y ≥ 2 같은 조건은 먼저 그만큼 빼고 셉니다.

부등식을 등식으로 바꾸는 요령: x + y + z ≤ 3이면 3에서 부족한 양을 새 변수 w(≥ 0)로 두어 x + y + z + w = 3으로 만듭니다. 하한이 있으면 x = x′ + 1처럼 바꿔 새 변수가 0 이상이 되게 합니다. 모두 '음이 아닌 정수해' 꼴로 만드는 것이 목표입니다.

예제

x + y + z ≤ 5를 만족하는 자연수해의 개수를 구하세요.

  1. 자연수이므로 1씩 빼면 x′ + y′ + z′ ≤ 2
  2. 남는 양 w를 두면 x′ + y′ + z′ + w = 2
  3. ₄H₂ = ₅C₂
  4. = 10

답: 10

문제 7

x ≥ 1, y ≥ 2, z ≥ 0이고 x + y + z = 8인 정수해는 몇 쌍일까요?

같은 물건 나누기

똑같은 물건 r개를 n명에게 나누는 방법은 nHr입니다. 모두 1개 이상 받으려면 1개씩 먼저 나눠 줍니다.

사람은 서로 다르고 물건은 똑같으면 '누가 몇 개 받는가'만 정하면 됩니다. 이는 사람 수만큼의 변수의 합이 물건 수가 되는 방정식의 음이 아닌 정수해와 같습니다. 물건이 서로 다르면 중복순열이 되니 구별해야 합니다.

문제 9

중복조합의 활용

(a + b + c)ⁿ을 전개한 항의 개수, a ≤ b ≤ c 같은 순서쌍의 개수도 중복조합입니다.

(a + b + c)⁴의 각 항은 aᵖbᵠcʳ (p + q + r = 4) 꼴이므로 항의 개수는 방정식의 해의 개수 ₃H₄입니다. a ≤ b ≤ c인 순서쌍도 크기순이 정해져 있으므로 '중복을 허락해 고르기'만 하면 되어 중복조합입니다.

예제

1 ≤ a ≤ b ≤ c ≤ 5인 자연수 순서쌍 (a, b, c)의 개수를 구하세요.

  1. 1부터 5까지 5종류에서 중복을 허락해 3개를 고름
  2. 고른 뒤 작은 것부터 a, b, c로 배정하면 순서쌍이 하나로 정해짐
  3. ₅H₃ = ₇C₃
  4. = 35

답: 35
