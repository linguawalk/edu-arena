지수·로그의 방정식과 부등식

대수 · 3. 지수함수와 로그함수 · 레벨1 · 약 15분 · 문제 16개

그래프로 해의 개수 보기

2ˣ = 4 − x처럼 풀기 어려운 방정식은 y = 2ˣ와 y = 4 − x의 교점 개수로 해의 개수를 알 수 있습니다.

대수적으로 풀 수 없는 방정식도 그래프로 해의 개수를 알 수 있습니다. 2ˣ = 4 − x에서 y = 2ˣ는 증가, y = 4 − x는 감소하므로 두 그래프는 딱 한 번 만납니다. 증가·감소를 이용하면 교점의 개수를 확실히 판단할 수 있습니다.

치환하는 지수방정식

a²ˣ과 aˣ가 함께 있으면 aˣ = t (t > 0)로 치환해 이차방정식으로 풉니다.

치환의 핵심은 t의 범위입니다. aˣ = t이면 t > 0이므로, 치환한 이차방정식의 근 중 0 이하인 것은 버립니다. 또 치환해서 구한 t마다 x를 하나씩 되돌려 구해야 하므로, 양수 근의 개수가 곧 원래 방정식의 해의 개수입니다.

예제

4ˣ − 2^(x + 1) − 8 = 0을 푸세요.

  1. 2ˣ = t (t > 0): t² − 2t − 8 = 0
  2. (t − 4)(t + 2) = 0에서 t = 4 (t = −2는 버림)
  3. 2ˣ = 4에서 x = 2
  4. 확인: 16 − 8 − 8 = 0

답: x = 2

치환하는 로그방정식

logₐ x = t로 치환하고, 밑이 다르면 밑변환으로 먼저 맞춥니다.

밑이 다른 로그가 섞여 있으면 밑변환으로 먼저 맞춥니다. log₄ (x + 2) = (1/2) log₂ (x + 2)처럼 밑을 2로 통일하면 양변을 비교할 수 있습니다. 로그방정식은 마지막에 진수 조건으로 해를 걸러야 합니다.

예제

log₃ x = log₉ (2x + 3)을 푸세요.

  1. 진수 조건: x > 0, 2x + 3 > 0 → x > 0
  2. log₉ (2x + 3) = (1/2) log₃ (2x + 3)이므로 2 log₃ x = log₃ (2x + 3)
  3. x² = 2x + 3 → (x − 3)(x + 1) = 0
  4. x > 0이므로 x = 3

답: x = 3

지수·로그부등식

밑이 1보다 크면 부등호 방향 그대로, 0과 1 사이이면 반대입니다. 로그는 진수 조건을 함께 풉니다.

지수·로그부등식은 방정식과 같은 순서로 풀되, 부등호 방향을 정하는 단계가 추가됩니다. 밑을 1보다 큰 수로 바꿔 풀면 방향을 뒤집는 실수를 줄일 수 있습니다. 로그부등식은 진수 조건과의 공통부분이 최종 해입니다.

예제

log₂ (x − 1) + log₂ (x + 1) ≤ 3을 푸세요.

  1. 진수 조건: x − 1 > 0, x + 1 > 0 → x > 1
  2. log₂ (x² − 1) ≤ log₂ 8, 밑 2 > 1이므로 x² − 1 ≤ 8
  3. x² ≤ 9 → −3 ≤ x ≤ 3
  4. 진수 조건과 공통부분: 1 < x ≤ 3

답: 1 < x ≤ 3
