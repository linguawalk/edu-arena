상황에 맞는 함수 고르기

일정하게 늘면 일차함수, 곱이 일정하면 반비례, 넓이처럼 두 길이를 곱하면 이차함수를 먼저 떠올립니다.

현상을 보고 '무엇이 일정한가'를 먼저 찾습니다. 변화량이 일정하면 일차, 곱이 일정하면 반비례, 비율이 일정하면 지수, 두 일차량의 곱이면 이차함수를 떠올립니다.

한 변이 x인 정사각형의 넓이를 y라 할 때 x = 7이면 y는?

문제 2

150km를 x시간에 갈 때 속력 y = 150/x입니다. x = 3이면 y는?

두 모델 비교

두 함수가 같아지는 점을 구하면, 어느 쪽이 유리한지 바뀌는 지점을 알 수 있습니다.

두 요금제 그래프는 교점에서 만납니다. 요금은 그래프가 더 아래에 있을수록 쌉니다. 교점의 왼쪽과 오른쪽에서 어느 그래프가 아래에 있는지 보면 사용량에 따라 유리한 요금제를 알 수 있고, 교점에서 유리한 쪽이 바뀝니다.

예제

A 요금제는 월 30,000원, B 요금제는 기본 12,000원에 1GB당 2,000원입니다. 몇 GB 미만이면 B가 유리할까요?

  1. B 요금: 2000x + 12000
  2. A = B: 2000x + 12000 = 30000에서 x = 9
  3. 9GB 미만이면 B가 더 쌉니다.

답: 9GB 미만

문제 4

100분을 쓴다면 두 요금의 차이는 몇 원일까요?

최적화

구하는 양을 이차함수로 나타내면 꼭짓점에서 최대나 최소를 찾을 수 있습니다.

최적화 문제의 순서: 변수를 정하고 → 구하는 양을 이차함수로 나타내고 → 변수의 범위를 확인하고 → 꼭짓점이 범위 안에 있는지 보고 최대·최소를 구합니다.

예제

둘레가 30인 직사각형의 넓이의 최댓값을 구하세요.

  1. 가로 x이면 세로 15 − x (0 < x < 15)
  2. 넓이 x(15 − x) = −(x − 7.5)² + 56.25
  3. x = 7.5일 때 최댓값 56.25 (정사각형)

답: 56.25

어떤 양이 y = −t² + 6t + 7로 변할 때 y의 최댓값은?

거꾸로 풀기

결과를 알고 원래 값을 구할 때는 역함수를 생각합니다.

결과에서 원인을 찾는 것은 역함수를 쓰는 것과 같습니다. F = 1.8C + 32를 C에 대해 풀면 C = (F − 32)/1.8이 되어, 화씨온도를 섭씨로 바꾸는 함수가 됩니다.

단계가 이어지는 모델

여러 단계를 거치는 변환은 합성함수로 나타낼 수 있습니다. 순서가 바뀌면 결과도 달라질 수 있습니다.

합성함수로 나타낼 때는 먼저 적용되는 함수가 안쪽에 들어갑니다. '20% 이익을 붙인 뒤 할인'과 '할인한 뒤 20% 이익'은 결과가 다르므로 순서를 문장에서 정확히 읽어야 합니다.

예제

물건값에 10%의 부가세를 붙인 뒤 2,000원 쿠폰을 쓰는 경우와, 쿠폰을 먼저 쓰고 부가세를 붙이는 경우의 차이는(원래 20,000원)?

  1. 부가세 먼저: 20000 × 1.1 − 2000 = 20000
  2. 쿠폰 먼저: (20000 − 2000) × 1.1 = 19800
  3. 차이 200원 (순서에 따라 결과가 다름)

답: 200원
