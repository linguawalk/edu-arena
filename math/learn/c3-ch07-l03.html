수학적 귀납법

자연수 n에 대한 명제가 모든 n에서 참임을 보이려면 두 가지를 증명합니다.

① n = 1일 때 참이다. ② n = k일 때 참이면 n = k + 1일 때도 참이다.

왜 두 단계면 충분할까요? ①로 n = 1이 참이고, ②에 k = 1을 넣으면 n = 2가 참, 다시 k = 2를 넣으면 n = 3이 참, … 이렇게 끝없이 이어져 모든 자연수에서 참이 됩니다. 두 단계 중 하나라도 빠지면 증명이 되지 않습니다.

문제 2

1 + 2 + … + n = n(n + 1)/2에서 n = 1일 때 좌변은 ＿＿＿

도미노

첫 번째 도미노가 쓰러지고, 어떤 도미노든 쓰러지면 다음 도미노도 쓰러진다면 모든 도미노가 쓰러집니다. 수학적 귀납법의 원리입니다.

①은 첫 도미노를 넘어뜨리는 것, ②는 도미노 사이의 간격이 충분히 가까워 앞의 것이 쓰러지면 반드시 다음 것도 쓰러진다는 보장입니다. 첫 도미노가 안 넘어지거나 중간에 간격이 먼 곳이 있으면 모두 쓰러지지 않습니다.

문제 3

1 + 2 + … + k에서 n = k + 1일 때 더해지는 항은 ＿＿＿

문제 4

k(k + 1)/2 + (k + 1) = (k + 1)(k + ＿＿＿)/2

합의 공식 증명

n = k일 때의 식에 n = k + 1번째 항을 더해, n = k + 1을 넣은 공식과 같아지는지 보입니다.

증명의 핵심은 'n = k일 때 식'을 가정으로 적극 쓰는 것입니다. n = k + 1일 때 좌변은 'n = k일 때 좌변 + 새 항'이므로, 가정으로 n = k일 때 좌변을 우변의 식으로 바꾼 뒤 새 항을 더해 정리합니다. 목표 식을 미리 적어 두면 방향을 잃지 않습니다.

예제

1 + 2 + … + n = n(n + 1)/2를 수학적 귀납법으로 증명하는 과정을 쓰세요.

  1. n = 1: 좌변 1, 우변 1 × 2/2 = 1로 성립
  2. n = k일 때 1 + … + k = k(k + 1)/2라고 가정
  3. n = k + 1: 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2
  4. n = k + 1일 때도 성립하므로 모든 자연수 n에서 성립

문제 7

1² + 2² + … + n²의 공식 증명에서 n = k + 1일 때 더하는 항은 (k + 1)^＿＿＿

배수임을 증명하기

n = k일 때 배수라고 가정한 식을 n = k + 1일 때의 식 안에서 찾아 만듭니다.

예: 4ᵏ⁺¹ − 1 = 4(4ᵏ − 1) + 3

배수 증명에서는 n = k + 1일 때의 식을 억지로라도 'n = k일 때의 식'이 드러나게 변형합니다. 4ᵏ⁺¹ − 1 = 4 × 4ᵏ − 4 + 3 = 4(4ᵏ − 1) + 3처럼, 가정으로 3의 배수인 부분과 나머지(3의 배수)로 나누면 됩니다.

예제

5ⁿ − 1이 4의 배수임을 보이는 핵심 단계를 쓰세요.

  1. n = 1: 5 − 1 = 4로 4의 배수
  2. 5ᵏ − 1 = 4m이라고 가정
  3. 5ᵏ⁺¹ − 1 = 5 × 5ᵏ − 1 = 5(5ᵏ − 1) + 4 = 20m + 4 = 4(5m + 1)
  4. n = k + 1일 때도 4의 배수

문제 10

n³ − n은 항상 6의 배수입니다. n = 3일 때 n³ − n의 값은?

부등식 증명

모든 n이 아니라 n ≥ a에서만 성립하는 명제는 n = a일 때부터 시작합니다.

시작값을 정할 때는 직접 대입해 봅니다. 2ⁿ > n²은 n = 1(2 > 1), n = 2(4 = 4), n = 3(8 < 9), n = 4(16 = 16), n = 5(32 > 25)이므로 n = 5부터 성립하고 그 뒤로는 계속 성립합니다. n = 1에서 성립해도 중간에 깨지면 시작점이 될 수 없습니다.

예제

2ⁿ > 2n + 1이 성립하기 시작하는 자연수 n을 찾으세요.

  1. n = 1: 2 > 3 (거짓), n = 2: 4 > 5 (거짓)
  2. n = 3: 8 > 7 (참)
  3. n = k에서 참이면 2ᵏ⁺¹ = 2 × 2ᵏ > 4k + 2 > 2k + 3 (k ≥ 1)
  4. n ≥ 3에서 성립

답: n ≥ 3
