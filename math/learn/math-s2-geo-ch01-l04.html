체바 선분이 만드는 넓이

체바·메넬라오스로 구한 비는 넓이 계산에 바로 쓰입니다. 높이가 같은 두 삼각형의 넓이 비는 밑변의 비입니다.

예: AD가 BC를 2 : 1로 나누면 [ABD] : [ADC] = 2 : 1입니다. 여기에 AP/PD = 1/2이면 [PBD] = [ABD] × (PD/AD) = [ABD] × 2/3입니다.

복잡한 그림은 넓이를 한 단계씩 비로 쪼개어 구합니다.

문제 1

넓이가 30인 삼각형 ABC에서 D가 BC를 BD : DC = 2 : 1로 나눌 때 [ABD]는?

문제 2

높이가 같은 두 삼각형의 넓이의 비는 ＿＿＿의 비와 같습니다.

라우스 정리

세 체바 선분이 각 변을 같은 비 x : 1(BD : DC = CE : EA = AF : FB = x : 1)로 나누면, 세 선분이 만드는 안쪽 삼각형의 넓이는 원래의 (x − 1)²/(x² + x + 1)배입니다(라우스 정리의 특수한 경우).

x = 2이면 1/7입니다. 각 변을 2 : 1로 나누는 세 체바 선분은 넓이가 원래의 1/7인 삼각형을 만듭니다.

x = 1이면 0으로, 세 중선이 한 점에서 만나 안쪽 삼각형이 사라지는 것과 맞습니다.

예제

넓이 7인 삼각형에서 각 변을 2 : 1로 나누는 세 체바 선분이 만드는 안쪽 삼각형의 넓이를 구하세요.

  1. x = 2입니다.
  2. (x − 1)²/(x² + x + 1) = 1/(4 + 2 + 1) = 1/7입니다.
  3. 안쪽 삼각형의 넓이는 7 × 1/7입니다.
  4. = 1입니다.

답: 1

문제 3

각 변을 3 : 1로 나누는 세 체바 선분이 만드는 안쪽 삼각형의 넓이는 원래의 몇 배인가요? (분수로)

문제 4

넓이 70인 삼각형에서 각 변을 2 : 1로 나누는 세 체바 선분이 만드는 안쪽 삼각형의 넓이는?

교점으로 나뉜 조각

무게중심 G는 삼각형을 넓이가 같은 6개의 삼각형으로 나눕니다. 각 중선이 넓이를 반으로 나누고, G가 중선을 2 : 1로 나누기 때문입니다. 그래서 [GBC] = [GCA] = [GAB] = [ABC]/3입니다.

일반적인 체바 선분에서는 질량점이나 반 오벨로 구한 비를 써서 조각마다 넓이를 구합니다.

답안에서는 '높이가 같으므로' 같은 근거를 꼭 밝힙니다.

문제 5

넓이 36인 삼각형을 세 중선이 나눈 6개의 작은 삼각형 하나의 넓이는?

문제 6

넓이 30인 삼각형 ABC에서 BD : DC = 2 : 1이고 AD 위의 점 P가 AP : PD = 1 : 2일 때 [PBD]는?

문제 7

넓이 12인 삼각형 ABC에서 무게중심 G에 대해 [GBC]는?

정리

높이가 같은 삼각형의 넓이 비는 밑변의 비이므로, 체바·메넬라오스·질량점으로 구한 비를 넓이로 바로 옮길 수 있습니다.

각 변을 x : 1로 나누는 세 체바 선분의 안쪽 삼각형은 원래의 (x − 1)²/(x² + x + 1)배입니다(x = 2 → 1/7).

무게중심은 삼각형을 넓이가 같은 6조각으로 나누고, [GBC] = [ABC]/3입니다.

문제 8

각 변을 4 : 1로 나누는 세 체바 선분이 만드는 안쪽 삼각형의 넓이는 원래의 몇 배인가요? (분수로)

문제 9

BD : DC = 1 : 2, AE : EC = 1 : 1이고 AD와 BE의 교점 P일 때 BP/PE는?

문제 10

무게중심 G가 삼각형 ABC를 넓이가 같은 6개의 삼각형으로 나눔을 증명하세요.

문제 11

각 변을 2 : 1로 나누는 세 체바 선분(BD : DC = CE : EA = AF : FB = 2 : 1)이 만드는 안쪽 삼각형의 넓이가 원래의 1/7임을 보이세요.
