무리식

근호 안에 문자가 있는 식 중 유리식으로 나타낼 수 없는 식을 무리식이라고 합니다.

실수 범위에서 값을 가지려면 근호 안이 0 이상이어야 합니다.

왜 0 이상이어야 할까요? 실수를 제곱하면 항상 0 이상이므로, 음수의 제곱근은 실수가 아닙니다. 그래서 무리식이 실수 값을 가질 조건은 근호 안이 0 이상인 것입니다.

√(x − 2)의 값이 실수가 되는 x의 최솟값은?

문제 2

√(5 − x) + √(x − 1)의 값이 실수가 되는 정수 x는 몇 개일까요?

분모의 유리화

분모에 √A + √B가 있으면 √A − √B를 분모와 분자에 곱합니다.

(√A + √B)(√A − √B) = A − B이므로 근호가 사라집니다. 분모의 근호를 없애려고 켤레를 곱하는 것이며, 수의 분모의 유리화와 같은 원리입니다.

예제

2/(√5 − √3)의 분모를 유리화하세요.

  1. 분모의 켤레 √5 + √3을 분모와 분자에 곱합니다.
  2. 분모: (√5)² − (√3)² = 5 − 3 = 2
  3. 2(√5 + √3)/2 = √5 + √3

답: √5 + √3

무리식의 값

x = 2 + √3, y = 2 − √3처럼 켤레 꼴이면 x + y와 xy를 먼저 구해 식의 값을 계산합니다.

켤레 꼴에서는 x + y와 xy가 모두 근호 없이 깔끔하게 나옵니다. x² + y² = (x + y)² − 2xy처럼 합과 곱으로 식을 바꾸면 근호를 직접 계산하지 않아도 됩니다.

무리방정식

근호가 있는 방정식은 양변을 제곱해 풉니다.

제곱하면 원래 식을 만족하지 않는 근(무연근)이 생길 수 있으므로 꼭 대입해 확인합니다.

왜 무연근이 생길까요? √(2x − 1) = x − 2에서 좌변은 항상 0 이상인데, 제곱하면 우변이 음수인 경우까지 해로 들어옵니다. 그래서 제곱한 뒤 구한 해를 원래 식에 넣어 확인해야 합니다.

예제

√(x + 2) = x를 푸세요.

  1. 양변을 제곱: x + 2 = x²
  2. x² − x − 2 = (x − 2)(x + 1) = 0에서 x = 2 또는 −1
  3. 확인: x = −1이면 우변이 음수라 무연근
  4. 해는 x = 2

답: x = 2

이중근호

√(a + b + 2√(ab)) = √a + √b (a, b > 0)

왜 성립할까요? (√a + √b)² = a + b + 2√(ab)이므로 양변에 근호를 씌우면 됩니다. 그래서 √(p + 2√q)를 간단히 하려면 더해서 p, 곱해서 q인 두 수 a, b를 찾습니다.

예제

√(5 + 2√6)을 간단히 하세요.

  1. 더해서 5, 곱해서 6인 두 수: 2와 3
  2. 5 + 2√6 = (√3 + √2)²
  3. √(5 + 2√6) = √3 + √2

답: √3 + √2
