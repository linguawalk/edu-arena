도함수의 부호

어떤 구간에서 f′(x) > 0이면 f는 증가하고, f′(x) < 0이면 감소합니다.

왜 도함수의 부호로 알 수 있을까요? f′(x) > 0이면 그 근처에서 접선이 오른쪽 위로 향하므로, x가 조금 커질 때 f(x)도 커집니다. 이것이 구간 전체에서 성립하면 증가함수입니다. 엄밀하게는 평균값 정리로 증명합니다: x₁ < x₂이면 f(x₂) − f(x₁) = f′(c)(x₂ − x₁) > 0.

문제 1

f(x) = x²이 감소하는 범위가 x < a일 때 a의 값은?

문제 2

f(x) = x³은 실수 전체에서 증가할까요? (그렇다 1, 아니다 0)

증감표

f′(x) = 0이 되는 x를 찾고, 그 사이 구간마다 f′의 부호를 조사해 표로 정리합니다.

증감표를 만드는 순서: ① f′(x)를 구해 인수분해 ② f′(x) = 0인 x를 수직선에 표시 ③ 각 구간에 아무 값이나 넣어 f′의 부호 확인 ④ +이면 ↗, −이면 ↘로 표시. 이 표 하나로 그래프의 대략적인 모양이 나옵니다.

예제

f(x) = x³ − 6x² + 9x + 1의 증감표를 만드세요.

  1. f′(x) = 3x² − 12x + 9 = 3(x − 1)(x − 3)
  2. x < 1: f′ > 0 ↗ / 1 < x < 3: f′ < 0 ↘ / x > 3: f′ > 0 ↗
  3. 증가: x < 1 또는 x > 3, 감소: 1 < x < 3
  4. 확인: x = 2이면 f′(2) = −3 < 0

답: x < 1, x > 3에서 증가 / 1 < x < 3에서 감소

항상 증가할 조건

삼차함수가 실수 전체에서 증가하려면 모든 x에서 f′(x) ≥ 0, 즉 이차식 f′(x)의 판별식이 0 이하여야 합니다.

왜 판별식일까요? 삼차함수의 도함수는 이차함수입니다. 이 이차함수가 모든 x에서 0 이상이려면 그래프가 x축 아래로 내려가지 않아야 하므로, 이차방정식 f′(x) = 0이 서로 다른 두 실근을 가지면 안 됩니다. D ≤ 0이 조건입니다. D = 0이면 한 점에서만 f′ = 0이라 여전히 증가합니다.

예제

f(x) = x³ + ax² + 3x가 실수 전체에서 증가하는 a의 범위를 구하세요.

  1. f′(x) = 3x² + 2ax + 3 ≥ 0 (모든 x)
  2. D/4 = a² − 9 ≤ 0
  3. −3 ≤ a ≤ 3
  4. 주의: D = 0이어도 한 점에서만 f′ = 0이라 증가

답: −3 ≤ a ≤ 3

문제 7

구간에서의 증가·감소

주어진 구간 전체에서 f′(x)의 부호 조건이 성립하도록 계수를 정합니다.

구간이 주어진 조건은 '그 구간의 모든 x에서 f′(x) ≥ 0(또는 ≤ 0)'입니다. 계수를 분리해 a ≥ g(x) 꼴로 만들면, a가 구간에서 g(x)의 최댓값 이상이어야 한다는 조건이 됩니다. 구간의 끝점이 포함되는지에 따라 등호를 조심합니다.

예제

f(x) = x³ − ax가 구간 (1, 2)에서 감소하는 a의 최솟값을 구하세요.

  1. f′(x) = 3x² − a ≤ 0 (1 < x < 2)
  2. a ≥ 3x²이 구간의 모든 x에서 성립해야 함
  3. 3x²은 구간에서 12에 한없이 가까워지므로 a ≥ 12
  4. a의 최솟값 12

답: 12

문제 9

f(x) = −x³ + ax²이 구간 (0, 2)에서 증가하는 a의 최솟값은?

정리

f′(x) = 0인 점은 증가와 감소가 바뀔 수 있는 후보입니다. 부호가 실제로 바뀌는지 확인합니다.

f′(x) = 0이라고 해서 증가·감소가 반드시 바뀌는 것은 아닙니다. f′(x) = 3x²처럼 x = 0에서 0이지만 양쪽 모두 양수이면 계속 증가합니다. 그래서 f′ = 0인 점 양쪽의 부호를 꼭 확인해야 합니다.
