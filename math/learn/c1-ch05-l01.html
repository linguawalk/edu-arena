부등식의 성질

양변에 같은 수를 더하거나 빼도, 양수를 곱하거나 나눠도 부등호 방향은 그대로입니다.

양변에 음수를 곱하거나 나누면 부등호 방향이 바뀝니다.

왜 음수를 곱하면 방향이 바뀔까요? 2 < 3에 −1을 곱하면 −2와 −3이 되는데, 수직선에서 −2가 −3보다 오른쪽에 있으므로 −2 > −3입니다. 음수를 곱하면 수직선이 뒤집히기 때문입니다.

문제 1

a < b이면 −2a ＿＿＿ −2b

문제 2

a < b이면 a − 3 ＿＿＿ b − 3

일차부등식 풀기

방정식처럼 이항해 ax > b 꼴로 만든 뒤 a로 나눕니다. a가 음수이면 방향을 바꿉니다.

부등식 풀이는 방정식과 거의 같지만, 음수로 나누는 순간에만 부등호 방향이 바뀝니다. 해는 하나의 값이 아니라 범위이므로 수직선에 나타내 확인하면 좋습니다.

예제

5 − 2x ≥ 3x − 10을 푸세요.

  1. x항은 왼쪽, 상수항은 오른쪽으로 이항: −2x − 3x ≥ −10 − 5
  2. −5x ≥ −15
  3. 음수 −5로 나누므로 부등호 방향이 바뀝니다: x ≤ 3

답: x ≤ 3

ax > b의 해

a > 0이면 x > b/a, a < 0이면 x < b/a입니다.

a = 0이면 0 > b인지에 따라 모든 실수이거나 해가 없습니다.

x의 계수에 문자가 있으면 그 문자가 양수인지, 음수인지, 0인지에 따라 나눠 생각해야 합니다. 부호를 모르는 수로 나누면 부등호 방향을 정할 수 없기 때문입니다.

연립부등식

각 부등식의 해를 구해 수직선에 나타내고 공통 범위를 찾습니다.

A < B < C 꼴은 A < B와 B < C를 연립한 것입니다.

연립부등식은 두 조건을 동시에 만족해야 하므로 해는 두 해의 교집합입니다. 수직선에서 두 범위가 겹치는 부분을 찾고, 끝점에 등호가 포함되는지(●, ○)를 꼭 확인합니다.

예제

2x − 1 < x + 3과 3x + 2 ≥ −4를 동시에 만족하는 x의 범위를 구하세요.

  1. 첫째 부등식: x < 4
  2. 둘째 부등식: 3x ≥ −6, x ≥ −2
  3. 두 범위의 공통부분: −2 ≤ x < 4

답: −2 ≤ x < 4

예제

한 개 1,200원인 빵과 700원인 우유를 합해 12개 사고 10,000원 이하를 내려고 합니다. 빵은 최대 몇 개 살 수 있을까요?

  1. 빵을 x개라 하면 우유는 (12 − x)개
  2. 1200x + 700(12 − x) ≤ 10000
  3. 500x + 8400 ≤ 10000, 500x ≤ 1600, x ≤ 3.2
  4. x는 자연수이므로 최대 3개

답: 3개
