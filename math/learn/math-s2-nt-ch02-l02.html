곱의 꼴로 만들기

xy = x + y + 5처럼 곱과 합이 섞인 방정식은 (x − 1)(y − 1) = 6처럼 두 인수의 곱 = 상수 꼴로 바꿉니다. 양변에 1을 더해 xy − x − y + 1 = 6으로 만든 것입니다.

그다음 6의 약수 쌍을 모두 따져 해를 구합니다. 양의 정수해이면 x − 1, y − 1 ≥ 0이고, 곱이 6이므로 둘 다 양수입니다: (1, 6), (2, 3), (3, 2), (6, 1).

그래서 (x, y) = (2, 7), (3, 4), (4, 3), (7, 2)입니다. 이 방법을 사이먼의 인수분해 요령이라고도 부릅니다.

문제 1

xy = x + y + 5의 양의 정수해 (x, y)는 몇 개인가요?

문제 2

xy = 2x + 3y를 인수분해하면 (x − 3)(y − 2) = ＿＿＿입니다.

제곱의 차

x² − y² = n은 (x − y)(x + y) = n입니다. 두 인수 x − y와 x + y는 홀짝이 같아야 합니다(합이 2x로 짝수).

x² − y² = 45: 45 = 1 × 45 = 3 × 15 = 5 × 9이고 모두 홀수끼리라 가능합니다. 양의 정수해는 (23, 22), (9, 6), (7, 2)입니다.

n ≡ 2 (mod 4)이면 두 인수의 홀짝이 같을 수 없으므로 해가 없습니다. 예: x² − y² = 2026.

예제

x² − y² = 60의 양의 정수해를 모두 구하세요.

  1. (x − y)(x + y) = 60이고 두 인수는 홀짝이 같아야 하므로 둘 다 짝수입니다.
  2. 60 = 2 × 30 = 6 × 10 (x − y < x + y)입니다.
  3. 2 × 30이면 x = 16, y = 14입니다. 6 × 10이면 x = 8, y = 2입니다.
  4. 양의 정수해는 (16, 14), (8, 2)입니다.

답: (16, 14), (8, 2)

문제 4

단위분수 방정식

1/x + 1/y = 1/n (양의 정수)은 양변에 nxy를 곱해 ny + nx = xy, 곧 (x − n)(y − n) = n²입니다.

x, y > n이어야 하므로 x − n과 y − n은 n²의 양의 약수 쌍이고, 해의 개수는 n²의 약수의 개수 d(n²)입니다.

1/x + 1/y = 1/6이면 (x − 6)(y − 6) = 36이고 d(36) = 9개의 해가 있습니다(순서를 구별할 때). x ≤ y로 세면 5개입니다.

정리

곱과 합이 섞인 방정식은 상수를 더해 (x − a)(y − b) = k 꼴로 바꾸고 k의 약수 쌍을 모두 따집니다. 음수 인수 쌍도 범위 안에 있는지 확인합니다.

x² − y² = n은 (x − y)(x + y) = n이며 두 인수의 홀짝이 같아야 합니다. n ≡ 2 (mod 4)이면 해가 없습니다.

1/x + 1/y = 1/n은 (x − n)(y − n) = n²이라 해의 개수는 d(n²)입니다.
