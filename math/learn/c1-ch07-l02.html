덧셈과 뺄셈

꼴이 같은 두 행렬은 같은 위치의 성분끼리 더하거나 뺍니다.

왜 꼴이 같아야 할까요? 덧셈은 같은 위치의 성분끼리 짝을 지어 계산하므로, 짝이 없는 성분이 생기면 더할 수 없습니다. 판매량 표를 합칠 때 같은 가게의 같은 물건끼리 더하는 것과 같습니다.

문제 1

[1 2 ; 3 4] + [5 6 ; 7 8] = [6 ＿＿＿ ; 10 12]

문제 2

[4 1 ; 0 3] − [1 1 ; 2 5] = [3 0 ; ＿＿＿ −2]

실수배

행렬 A에 실수 k를 곱한 kA는 모든 성분에 k를 곱한 것입니다.

실수배는 모든 성분에 똑같이 곱하는 것입니다. 가격표의 모든 가격을 2배로 올리는 것처럼, 표 전체를 같은 비율로 늘리거나 줄이는 계산입니다.

예제

A = [1 −1 ; 2 0], B = [3 2 ; −1 4]일 때 2A − B를 구하세요.

  1. 2A = [2 −2 ; 4 0]
  2. 2A − B의 각 성분: 2 − 3, −2 − 2, 4 − (−1), 0 − 4
  3. [−1 −4 ; 5 −4]

답: [−1 −4 ; 5 −4]

문제 4

연산 법칙

A + B = B + A, (A + B) + C = A + (B + C)가 성립합니다.

A + O = A, A − A = O

행렬의 덧셈은 성분끼리의 수의 덧셈이므로 수의 덧셈 법칙이 그대로 성립합니다. 영행렬 O가 수의 0 역할을 해서 A + O = A, A + (−A) = O가 됩니다.

행렬 방정식

수의 방정식처럼 이항하고 실수로 나눠 X를 구합니다.

행렬 방정식도 수의 방정식처럼 풀 수 있습니다. 2X + A = B에서 A를 이항해 2X = B − A, 양변을 2로 나눠 X = (B − A)/2로 구합니다. 계산은 성분마다 합니다.

예제

3X − A = B, A = [1 2 ; 0 3], B = [5 1 ; 6 3]일 때 X를 구하세요.

  1. 이항: 3X = A + B
  2. A + B = [6 3 ; 6 6]
  3. X = (1/3)(A + B) = [2 1 ; 2 2]

답: [2 1 ; 2 2]

활용

달마다 판매량 행렬을 더하면 합계가, 가격 행렬에 1.1을 곱하면 10% 인상된 가격이 됩니다.

행렬로 나타내면 여러 자료를 한 번에 계산할 수 있습니다. 두 달 판매량을 더하면 성분마다 합계가 나오고, 실수배를 하면 모든 값이 같은 비율로 바뀝니다.

예제

X + Y = [4 2 ; 0 6], X − Y = [2 0 ; 2 2]일 때 X를 구하세요.

  1. 두 식을 더하면 2X = [6 2 ; 2 8]
  2. X = [3 1 ; 1 4]
  3. 수의 연립방정식을 가감법으로 푸는 것과 같습니다.

답: [3 1 ; 1 4]
