근을 이용해 다항식을 정하기

최고차항 계수가 1인 삼차식 P(x)가 P(1) = 1, P(2) = 2, P(3) = 3을 만족한다고 합시다. P(4)를 구하려면 P(x) − x를 봅니다.

P(x) − x는 x = 1, 2, 3에서 0이고, 최고차항 계수가 1인 삼차식이므로 (x − 1)(x − 2)(x − 3)과 같습니다. 그러면 P(4) = 3 × 2 × 1 + 4 = 10입니다.

핵심은 '주어진 값에서 0이 되는 다항식'을 만드는 것입니다. 차수가 n인 다항식은 근이 n개를 넘을 수 없으므로, 근을 n개 알고 최고차항 계수를 알면 다항식 전체가 정해집니다. 직접 계수를 연립해 구하는 것보다 훨씬 빠릅니다.

문제 1

최고차항 계수가 1인 삼차식 P(x)가 P(1) = 1, P(2) = 2, P(3) = 3을 만족할 때 P(4)는?

문제 2

앞 문제에서 P(x) − x = (x − 1)(x − 2)(x − ＿＿＿)입니다.

항등식은 아무 값이나 넣어도 된다

모든 x에 대해 성립하는 등식을 항등식이라고 합니다. 항등식은 아무 x나 넣어도 성립하므로, 계산이 쉬워지는 값을 골라 넣어 계수를 구합니다.

x² + 3x + 5 = a(x − 1)² + b(x − 1) + c에서 x = 1을 넣으면 c = 9가 바로 나옵니다. x²의 계수를 비교하면 a = 1이고, x = 0을 넣으면 5 = 1 − b + 9에서 b = 5입니다.

x − 1의 거듭제곱으로 다시 쓰는 것은 t = x − 1로 치환하는 것과 같습니다. x = t + 1을 넣어 전개해도 됩니다. 값 넣기와 계수 비교를 섞어 쓰면 대부분의 항등식 문제를 빠르게 풀 수 있습니다.

예제

x² + 3x + 5 = a(x − 1)² + b(x − 1) + c가 항등식일 때 a, b, c를 구하세요.

  1. x = 1을 넣으면 1 + 3 + 5 = c이므로 c = 9입니다.
  2. 양변의 x² 계수를 비교하면 a = 1입니다.
  3. x = 0을 넣으면 5 = a − b + c = 1 − b + 9이므로 b = 5입니다.
  4. 따라서 a = 1, b = 5, c = 9이고, (x − 1)² + 5(x − 1) + 9를 전개하면 x² + 3x + 5와 같습니다.

답: a = 1, b = 5, c = 9

문제 3

x³ = a(x − 1)³ + b(x − 1)² + c(x − 1) + d가 항등식일 때 b의 값은?

P(x) − (간단한 식)의 근 찾기

레슨 첫 화면의 방법은 P(k)가 k, k², 2k처럼 규칙적인 값일 때 모두 쓸 수 있습니다. P(x)에서 그 규칙의 식을 빼면 주어진 점들에서 0이 됩니다.

최고차항 계수가 1인 사차식 P(x)가 P(k) = k² (k = 1, 2, 3, 4)를 만족하면 P(x) − x² = (x − 1)(x − 2)(x − 3)(x − 4)입니다.

빼는 식의 차수는 P(x)보다 낮아야 최고차항 계수가 그대로 유지됩니다. 값이 1/k처럼 분수이면 xP(x) − 1처럼 분모를 곱한 식을 만듭니다. 이때 차수가 하나 늘어나고 최고차항 계수를 모르므로, x = 0 같은 다른 값을 넣어 계수를 정합니다.

문제 5

이차 이하의 다항식 P(x)가 P(0) = 1, P(1) = 3, P(2) = 7을 만족할 때 P(3)은?

차분으로 다항식 찾기

P(x + 1) − P(x)를 P의 차분이라고 합니다. 차수가 n인 다항식의 차분은 차수가 n − 1입니다.

그래서 P(x + 1) − P(x) = 2x + 1이라면 P는 이차식입니다. (x + 1)² − x² = 2x + 1이므로 P(x) = x² + c로 놓을 수 있습니다.

c는 P(0) 같은 값 하나로 정해집니다. 이 생각은 수열의 계차와 똑같습니다. 정수 n에서만 보면 P(n) = P(0) + Σ(차분)이고, 귀납법으로 P(n)의 공식을 증명할 수 있습니다. 다음 장의 수열과 점화식이 이 생각을 이어받습니다.

문제 6

다항식 P(x)가 모든 x에 대해 P(x + 1) − P(x) = 2x + 1이고 P(0) = 2일 때 P(5)는?

문제 7

최고차항 계수가 양수인 일차식 P(x)가 P(P(x)) = 4x + 3을 만족할 때 P(5)는?

정리

주어진 점들에서 P(x)가 규칙적인 값을 가지면, 그 규칙의 식을 빼서 근을 만들고 인수분해 꼴로 P(x)를 정합니다.

항등식은 계산이 쉬운 값을 넣거나 계수를 비교해 미지수를 구합니다.

차분 P(x + 1) − P(x)는 차수를 하나 낮추므로, 차분이 주어지면 P의 꼴을 짐작할 수 있습니다. 차수가 n인 다항식은 n + 1개의 값으로 정해진다는 사실이 이 모든 방법의 바탕입니다.
