상용로그

밑이 10인 로그를 상용로그라 하고 밑을 생략해 log N으로 씁니다.

왜 밑이 10일까요? 우리가 쓰는 십진법에서 10의 거듭제곱은 자릿수와 직결됩니다. log 100 = 2, log 1000 = 3처럼 상용로그는 '10을 몇 번 곱했나'를 알려 주므로, 아주 큰 수나 아주 작은 수의 크기를 한눈에 비교할 수 있게 해 줍니다.

log 100의 값은?

문제 2

log 0.01의 값은?

정수 부분과 소수 부분

log N = n + α (n은 정수, 0 ≤ α < 1)로 나타내면 n을 정수 부분, α를 소수 부분이라고 합니다.

log 2 ≈ 0.3010이면 log 2000 = log (2 × 10³) ≈ 3.3010입니다.

왜 정수 부분과 소수 부분으로 나눌까요? log (2 × 10³) = log 2 + 3이므로, 2000, 200, 0.2처럼 숫자 배열은 같고 소수점 위치만 다른 수들은 소수 부분(log 2 ≈ 0.3010)이 모두 같고 정수 부분만 다릅니다. 정수 부분은 소수점의 위치(크기)를, 소수 부분은 숫자의 배열을 알려 줍니다.

예제

log 3 ≈ 0.4771일 때 log 300, log 0.03의 값을 구하세요.

  1. log 300 = log (3 × 10²) = 2 + 0.4771 = 2.4771
  2. log 0.03 = log (3 × 10⁻²) = −2 + 0.4771
  3. = −1.5229
  4. 원리: 소수점 위치만 다르면 소수 부분이 같습니다.

답: 2.4771, −1.5229

자릿수 구하기

N ≥ 1이고 log N의 정수 부분이 n이면 N은 n + 1자리 수입니다.

왜 n + 1자리일까요? N이 n + 1자리 수이면 10ⁿ ≤ N < 10ⁿ⁺¹이고, 상용로그를 취하면 n ≤ log N < n + 1입니다. 그래서 log N의 정수 부분이 n이면 N은 n + 1자리입니다. 2¹⁰⁰처럼 직접 계산할 수 없는 수의 자릿수도 이렇게 알 수 있습니다.

예제

log 2 ≈ 0.3010일 때 2⁵⁰은 몇 자리 수일까요?

  1. log 2⁵⁰ = 50 × 0.3010 = 15.05
  2. 정수 부분 15
  3. 15 + 1 = 16자리
  4. 확인: 10¹⁵ ≤ 2⁵⁰ < 10¹⁶

답: 16자리

소수의 자리

0 < N < 1이고 log N의 정수 부분이 −n이면, N은 소수점 아래 n째 자리에서 처음으로 0이 아닌 숫자가 나옵니다.

음수인 로그는 정수 부분이 음수, 소수 부분이 0 이상이 되도록 나눕니다. log N = −3.01이면 −3 − 0.01이 아니라 −4 + 0.99로 씁니다. 그러면 10⁻⁴ ≤ N < 10⁻³이 되어 소수점 아래 넷째 자리에서 처음 0이 아닌 숫자가 나옵니다.

예제

log 3 ≈ 0.4771일 때 (1/3)²⁰은 소수점 아래 몇째 자리에서 처음 0이 아닌 숫자가 나올까요?

  1. log (1/3)²⁰ = −20 × 0.4771 = −9.542
  2. 정수 부분이 음수, 소수 부분이 0 이상이 되게: −10 + 0.458
  3. 정수 부분 −10이므로 소수점 아래 10째 자리
  4. 주의: −9 − 0.542로 나누면 안 됩니다.

답: 10째 자리

문제 10

log 3 ≈ 0.4771일 때 0.3¹⁰은 소수점 아래 몇째 자리에서 처음으로 0이 아닌 숫자가 나올까요?

로그 값에서 수 찾기

log x = 2.3010 = 2 + 0.3010 = log 10² + log 2이므로 x = 200입니다.

로그 값에서 수를 찾을 때는 정수 부분과 소수 부분으로 나눈 뒤, 소수 부분이 어떤 수의 로그인지 찾습니다. 소수 부분 0.3010은 log 2이므로, 정수 부분 2와 합치면 log (2 × 10²) = log 200입니다.
