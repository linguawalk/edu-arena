한없이 가까워지는 값

x가 a에 한없이 가까워질 때 f(x)가 일정한 값 L에 한없이 가까워지면 lim(x→a) f(x) = L로 씁니다.

x = a에서의 값이 아니라, a 근처에서 어디로 향하는지를 봅니다.

왜 'x = a에서의 값'이 아니라 '근처'를 볼까요? (x² − 1)/(x − 1)은 x = 1에서 분모가 0이라 값이 없지만, x = 0.9, 0.99, 0.999, …를 넣으면 1.9, 1.99, 1.999, …로 2에 한없이 가까워집니다. 극한은 이렇게 값이 없는 곳에서도 '어디로 향하는지'를 말해 주는 도구이고, 미분의 출발점이 됩니다.

좌극한과 우극한

x가 a보다 작은 쪽에서 가까워지면 좌극한 lim(x→a−), 큰 쪽에서 가까워지면 우극한 lim(x→a+)입니다.

좌극한과 우극한이 같을 때만 극한이 존재합니다.

왼쪽과 오른쪽에서 다가갈 때 서로 다른 높이로 향하면, 한 값에 '한없이 가까워진다'고 말할 수 없습니다. 그래서 극한이 존재하려면 두 방향의 극한이 모두 있고 같아야 합니다. 식이 경계에서 바뀌는 함수나 절댓값이 있는 함수는 항상 양쪽을 따로 확인합니다.

예제

f(x) = x² − 1 (x < 2), 2x − 1 (x ≥ 2)에서 lim(x→2) f(x)를 조사하세요.

  1. 좌극한: x < 2의 식에 2를 넣으면 4 − 1 = 3
  2. 우극한: x ≥ 2의 식에 2를 넣으면 4 − 1 = 3
  3. 좌극한 = 우극한 = 3이므로 극한이 존재
  4. lim(x→2) f(x) = 3

답: 3

무한대와 관련된 극한

x → 0일 때 1/x²처럼 한없이 커지면 극한은 ∞(양의 무한대로 발산)입니다.

x → ∞일 때 1/x처럼 0에 가까워지는 경우도 있습니다.

∞는 수가 아니라 '한없이 커진다'는 상태를 나타내는 기호입니다. 그래서 lim = ∞는 극한값이 존재하는 것이 아니라 발산한다는 뜻입니다. 반대로 x → ∞일 때는 x가 한없이 커질 때 함숫값이 어디로 향하는지를 봅니다.

예제

lim(x→0+) 1/x와 lim(x→0−) 1/x를 조사하세요.

  1. x가 0보다 큰 쪽에서 다가가면 1/x는 한없이 커짐: +∞
  2. x가 0보다 작은 쪽에서 다가가면 1/x는 한없이 작아짐: −∞
  3. 두 방향이 다르므로 lim(x→0) 1/x는 존재하지 않음
  4. 비교: 1/x²은 양쪽 모두 +∞

답: +∞, −∞ (극한 없음)

그래프에서 극한 읽기

그래프가 끊어진 곳에서는 왼쪽에서 오는 높이와 오른쪽에서 오는 높이를 따로 읽습니다.

그래프에서 극한을 읽을 때는 x = a의 바로 왼쪽 부분 그래프가 향하는 높이, 바로 오른쪽 부분이 향하는 높이를 따로 봅니다. 빈 점(○)은 그 높이로 향하지만 그 점의 값은 아니라는 뜻이고, 채운 점(●)이 실제 함숫값입니다.

극한값과 함숫값

극한값은 a 근처의 행동이고, 함숫값은 a에서의 값입니다. 둘은 다를 수도 있고, 함숫값이 없어도 극한은 있을 수 있습니다.

극한값과 함숫값이 다르면 그래프에 '구멍'이나 '점프'가 있다는 뜻입니다. 둘이 같은 경우가 다음 레슨에서 배울 연속입니다. 0/0 꼴처럼 함숫값이 없어도 약분하면 극한을 구할 수 있습니다.

예제

f(x) = (x² − 5x + 6)/(x − 2)에서 f(2)와 lim(x→2) f(x)를 비교하세요.

  1. x = 2에서 분모가 0이라 f(2)는 정의되지 않음
  2. x ≠ 2에서 약분: (x − 2)(x − 3)/(x − 2) = x − 3
  3. lim(x→2) (x − 3) = −1
  4. 함숫값은 없어도 극한은 −1로 존재

답: f(2)는 없음, 극한은 −1
