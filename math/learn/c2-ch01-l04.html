평행과 일치

두 직선 y = mx + n, y = m′x + n′은 m = m′, n ≠ n′이면 평행하고, m = m′, n = n′이면 일치합니다.

기울기는 직선의 방향, y절편은 위치를 정합니다. 방향이 같고 위치만 다르면 평행해 만나지 않고, 방향과 위치가 모두 같으면 같은 직선(일치)입니다.

수직

두 직선의 기울기가 m, m′일 때 mm′ = −1이면 두 직선은 수직입니다.

왜 곱이 −1일까요? 기울기가 m인 직선을 90° 돌리면 오른쪽으로 1, 위로 m이던 방향이 위로 1, 왼쪽으로 m이 되어 기울기가 −1/m이 됩니다. 그래서 m × (−1/m) = −1입니다.

예제

점 (2, 3)을 지나고 직선 y = −2x + 1에 수직인 직선의 방정식을 구하세요.

  1. 주어진 직선의 기울기 −2
  2. 수직이므로 기울기 m은 −2 × m = −1에서 m = 1/2
  3. y − 3 = (1/2)(x − 2), y = (1/2)x + 2

답: y = (1/2)x + 2

두 직선의 교점

두 직선의 교점은 두 방정식을 연립한 해입니다.

교점은 두 직선 위에 동시에 있는 점이므로 두 방정식을 모두 만족합니다. 그래서 연립방정식의 해가 곧 교점의 좌표입니다. 해가 없으면 평행, 무수히 많으면 일치입니다.

점과 직선 사이의 거리

점 (x₁, y₁)과 직선 ax + by + c = 0 사이의 거리는 |ax₁ + by₁ + c| / √(a² + b²)입니다.

점과 직선 사이의 거리는 점에서 직선에 내린 수선의 길이입니다. 수선의 발을 직접 구하는 대신 이 공식을 쓰면 한 번에 계산됩니다. 직선은 반드시 ax + by + c = 0 꼴로 바꿔 넣습니다.

예제

점 (3, −1)과 직선 y = 2x + 3 사이의 거리를 구하세요.

  1. 일반형으로: 2x − y + 3 = 0
  2. |2 × 3 − (−1) + 3| / √(2² + 1²) = |10|/√5
  3. 10/√5 = 2√5

답: 2√5

수직이등분선

선분 AB의 수직이등분선은 AB의 중점을 지나고 AB에 수직인 직선입니다. 그 위의 점은 A, B에서 같은 거리에 있습니다.

수직이등분선 위의 점은 A, B까지의 거리가 같으므로, PA² = PB²으로 식을 세워도 같은 직선이 나옵니다. 중점과 수직인 기울기로 구하는 방법과 결과가 같습니다.

예제

A(−1, 2), B(3, 4)의 수직이등분선의 방정식을 구하세요.

  1. 중점: (1, 3)
  2. AB의 기울기 (4 − 2)/(3 + 1) = 1/2이므로 수직인 기울기는 −2
  3. y − 3 = −2(x − 1), y = −2x + 5

답: y = −2x + 5
