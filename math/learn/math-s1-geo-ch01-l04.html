빗변에 내린 높이

∠C = 90°인 직각삼각형 ABC에서 C에서 빗변 AB에 내린 수선의 발을 H라 하면, △ACB, △AHC, △CHB는 모두 닮음입니다. 각각 직각 하나와 공통인 각 하나를 가지기 때문입니다.

AH = p, HB = q, AB = c라 하면 CH² = pq, AC² = pc, BC² = qc가 성립합니다.

세 식은 닮음비에서 바로 나옵니다. △AHC ∽ △CHB에서 AH : CH = CH : HB이므로 CH² = pq입니다. 그리고 AC² + BC² = pc + qc = (p + q)c = c²이므로 피타고라스 정리가 저절로 증명됩니다. 직각삼각형 문제에서 빗변의 높이가 보이면 이 세 식을 먼저 떠올리세요.

문제 1

직각삼각형의 빗변에 내린 높이의 발이 빗변을 4와 9로 나눌 때 높이는?

문제 2

빗변이 p와 q로 나뉘면 (높이)² = p × ＿＿＿입니다.

피타고라스 정리의 증명

AC² = AH × AB는 △AHC ∽ △ACB에서 AH : AC = AC : AB이기 때문입니다. 같은 방법으로 BC² = HB × AB입니다.

두 식을 더하면 AC² + BC² = (AH + HB) × AB = AB²입니다.

피타고라스 정리에는 수백 가지 증명이 있지만, 닮음을 이용한 이 증명이 가장 짧은 편입니다. 또 이 그림은 산술·기하 평균 부등식의 그림 증명도 됩니다. 빗변을 지름으로 하는 원에서 높이 CH = √(pq)는 반지름 (p + q)/2보다 길 수 없기 때문입니다.

예제

두 다리가 6, 8인 직각삼각형에서 빗변에 내린 높이와 높이의 발이 나눈 두 부분의 길이를 구하세요.

  1. 빗변은 √(36 + 64) = 10입니다.
  2. 넓이를 두 가지로 쓰면 6 × 8/2 = 10 × h/2이므로 h = 24/5입니다.
  3. AC² = AH × AB에서 AH = 36/10 = 18/5, HB = 64/10 = 32/5입니다.
  4. 확인: AH × HB = 576/25 = (24/5)²입니다.

답: 높이 24/5, 18/5와 32/5

문제 3

두 다리가 6, 8인 직각삼각형에서 빗변에 내린 높이를 분수로 쓰세요.

문제 4

빗변에 내린 높이의 발이 빗변을 2와 8로 나눌 때, 길이 2인 부분에 이웃한 다리의 길이의 제곱은?

문제 5

두 다리가 3, 4인 직각삼각형에서 다리 3을 빗변에 정사영한 길이를 분수로 쓰세요.

피타고라스 정리의 활용

직육면체의 대각선 길이는 √(a² + b² + c²)입니다. 밑면의 대각선 √(a² + b²)과 높이 c로 다시 직각삼각형을 만들기 때문입니다.

직사각형 ABCD 안의 아무 점 P에 대해 PA² + PC² = PB² + PD²입니다(영국 국기 정리). P에서 각 변에 수선을 내리면 네 거리를 두 수평 거리와 두 수직 거리의 제곱의 합으로 나타낼 수 있기 때문입니다.

좌표로 보면 더 쉽습니다. 직사각형의 꼭짓점을 (0, 0), (a, 0), (a, b), (0, b), P를 (x, y)로 놓으면 양변이 모두 x² + y² + (a − x)² + (b − y)²이 됩니다. 기하 문제가 막히면 좌표를 잡는 것도 좋은 방법입니다.

문제 6

가로, 세로, 높이가 3, 4, 12인 직육면체의 대각선의 길이는?

문제 7

직사각형 ABCD 안의 점 P에 대해 PA = 3, PB = 4, PC = 5일 때 PD²의 값은?

정리

직각삼각형에서 빗변에 높이를 내리면 세 삼각형이 닮음이고, CH² = pq, AC² = pc, BC² = qc입니다. 두 식을 더하면 피타고라스 정리가 나옵니다.

빗변에 내린 높이는 넓이를 두 가지로 계산해 ab/c로 구합니다.

직육면체의 대각선은 √(a² + b² + c²), 직사각형 안의 점은 PA² + PC² = PB² + PD²입니다. 막히면 좌표를 잡아 보세요.
