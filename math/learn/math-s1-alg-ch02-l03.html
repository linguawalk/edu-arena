분수의 합을 한 분수로

양수 x, y에 대해 a²/x + b²/y ≥ (a + b)²/(x + y)가 성립합니다. 세 항 이상에서도 a²/x + b²/y + c²/z ≥ (a + b + c)²/(x + y + z)입니다.

등호는 a/x = b/y (= c/z)일 때입니다.

이것은 코시-슈바르츠를 (a/√x, b/√y)와 (√x, √y)에 적용한 결과입니다. 분자가 제곱이고 분모가 양수인 분수의 합을 보면 바로 떠올리세요. 1/a + 4/b처럼 분자가 1, 4, 9 같은 제곱수인 꼴에 특히 잘 맞습니다. 이 꼴을 엥겔 꼴 또는 티투의 보조정리라고도 부릅니다.

문제 2

분수 꼴 코시-슈바르츠의 등호 조건은 a/x = ＿＿＿/y입니다.

역수 합의 최솟값

양수 a, b가 a + b = 1일 때 1/a + 4/b의 최솟값을 구해 봅시다. 1/a + 4/b = 1²/a + 2²/b이므로 ≥ (1 + 2)²/(a + b) = 9입니다.

등호는 1/a = 2/b, 곧 b = 2a일 때이고, a + b = 1에서 a = 1/3, b = 2/3입니다.

이 문제를 AM-GM으로 풀려면 (a + b)(1/a + 4/b) = 5 + b/a + 4a/b ≥ 5 + 4 = 9처럼 한 단계를 더 거쳐야 합니다. 분수 꼴 코시-슈바르츠는 이 과정을 한 줄로 줄여 줍니다. 분자를 제곱 꼴로 바꿀 수 있는지 먼저 살펴보세요.

예제

양수 a, b가 a + b = 1일 때 1/a + 4/b의 최솟값을 구하세요.

  1. 1/a + 4/b = 1²/a + 2²/b로 씁니다.
  2. 분수 꼴 코시-슈바르츠에서 1²/a + 2²/b ≥ (1 + 2)²/(a + b) = 9입니다.
  3. 등호는 1/a = 2/b, 곧 b = 2a일 때이고 a + b = 1에서 a = 1/3, b = 2/3입니다.
  4. 이때 3 + 6 = 9이므로 최솟값은 9입니다.

답: 9

분모의 합을 맞추기

분수 꼴 코시-슈바르츠의 우변 분모는 '분모들의 합'입니다. 그래서 분모의 합이 상수가 되도록 식을 정리하면 바로 값이 나옵니다.

x + y + z = 6일 때 4/x + 9/y + 25/z ≥ (2 + 3 + 5)²/6 = 100/6 = 50/3입니다.

분모 합이 상수가 아닐 때는 분자와 분모에 같은 것을 곱해 모양을 바꿉니다. 예를 들어 a/(b + c)는 a²/(a(b + c))로 쓰면 분자가 제곱이 되고, 분모의 합은 a(b + c) + b(c + a) + c(a + b) = 2(ab + bc + ca)로 깔끔해집니다. 이 변형이 다음에 볼 네스빗 부등식의 핵심입니다.

문제 7

a = b = c일 때 a/(b + c) + b/(c + a) + c/(a + b)의 값을 분수로 쓰세요.

네스빗 부등식

양수 a, b, c에 대해 a/(b + c) + b/(c + a) + c/(a + b) ≥ 3/2입니다.

a/(b + c) = a²/(a(b + c))로 바꾸면 분수 꼴 코시-슈바르츠에서 합 ≥ (a + b + c)²/(2(ab + bc + ca))입니다.

남은 것은 (a + b + c)² ≥ 3(ab + bc + ca)를 보이는 일입니다. 차를 계산하면 a² + b² + c² − ab − bc − ca = ½{(a − b)² + (b − c)² + (c − a)²} ≥ 0입니다. 그러면 (a + b + c)²/(2(ab + bc + ca)) ≥ 3/2가 되어 증명이 끝납니다. 분자를 제곱으로 만드는 한 줄의 변형이 어려운 부등식을 두 단계로 나눈 셈입니다.

문제 8

실수 a, b, c에 대해 (a + b + c)² ≥ ＿＿＿(ab + bc + ca)입니다.

정리

양수 분모에 대해 a²/x + b²/y + c²/z ≥ (a + b + c)²/(x + y + z)이고, 등호는 a/x = b/y = c/z일 때입니다.

분자가 제곱수(1, 4, 9, …)인 역수 합은 이 꼴로 바로 최솟값을 구할 수 있습니다.

분자가 제곱이 아니면 분자와 분모에 같은 것을 곱해 제곱으로 만들고, 분모의 합이 다루기 쉬워지는지 봅니다. 네스빗 부등식은 a/(b + c) = a²/(a(b + c))라는 변형 하나로 풀립니다.
