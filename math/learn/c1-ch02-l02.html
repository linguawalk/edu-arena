부분집합

A의 모든 원소가 B에 속하면 A를 B의 부분집합이라 하고 A ⊂ B로 씁니다.

왜 ⊂라는 기호를 쓸까요? 벤 다이어그램에서 A의 원이 B의 원 안에 통째로 들어가는 모양을 나타냅니다. A의 원소 중 하나라도 B 밖에 있으면 부분집합이 아닙니다.

문제 1

A = {1, 2}, B = {1, 2, 3}이면 A ＿＿＿ B

문제 2

{a, b}의 부분집합은 몇 개일까요?

부분집합의 개수

∅과 자기 자신은 모든 집합의 부분집합입니다. 자기 자신을 뺀 부분집합을 진부분집합이라고 합니다.

원소가 n개인 집합의 부분집합은 2ⁿ개입니다. 원소마다 넣을지 뺄지 두 가지씩 고르기 때문입니다.

왜 ∅이 모든 집합의 부분집합일까요? '∅의 모든 원소가 B에 속한다'를 반박하려면 B에 속하지 않는 ∅의 원소를 하나 찾아야 하는데, ∅에는 원소가 없어 반박할 수 없기 때문입니다.

예제

{a, b, c}의 부분집합을 모두 나열하고 개수를 세어 보세요.

  1. 원소 0개: ∅
  2. 원소 1개: {a}, {b}, {c}
  3. 원소 2개: {a, b}, {a, c}, {b, c}
  4. 원소 3개: {a, b, c} → 모두 8개 = 2³

답: 8개

서로 같은 집합

A ⊂ B이고 B ⊂ A이면 두 집합의 원소가 모두 같으므로 A = B입니다.

원소가 같은지 확인할 때는 순서가 아니라 구성만 봅니다. {1, a} = {1, 4}에서 1은 이미 짝이 맞았으므로 남은 a가 4와 같아야 합니다.

문제 8

A ⊂ B이고 B ⊂ A이면 A ＿＿＿ B

조건이 붙은 부분집합

특정 원소 k개를 반드시 넣거나 빼야 하면, 나머지 n − k개만 자유롭게 고르므로 2ⁿ⁻ᵏ개입니다.

왜 2ⁿ⁻ᵏ일까요? 반드시 넣거나 반드시 빼야 하는 원소는 선택의 여지가 없어 경우의 수가 1가지입니다. 나머지 n − k개의 원소만 넣을지 뺄지 두 가지씩 고르게 됩니다.

예제

{1, 2, 3, 4, 5, 6}의 부분집합 중 1과 3을 포함하고 6은 포함하지 않는 것은?

  1. 1, 3은 반드시 넣고 6은 반드시 뺍니다.
  2. 자유롭게 고를 원소는 2, 4, 5의 3개
  3. 2³ = 8개

답: 8개

문제 10

문제 11

{1, 2, 3, 4}의 부분집합 중 원소가 2개인 것은 몇 개일까요?

정리

∅ ⊂ A ⊂ A는 모든 집합에서 성립합니다.

'적어도 하나 포함'은 전체에서 '하나도 포함하지 않는 경우'를 빼서 셉니다.

'적어도 하나'는 경우가 여러 갈래로 나뉘어 직접 세기 어렵습니다. 반대인 '하나도 없음'은 한 가지 조건이라 세기 쉬우므로, 전체에서 빼는 방법이 효율적입니다.

예제

{1, 2, 3, 4, 5}의 부분집합 중 홀수를 적어도 하나 포함하는 것은?

  1. 전체 부분집합: 2⁵ = 32개
  2. 홀수(1, 3, 5)를 하나도 포함하지 않는 것: 2, 4만으로 만든 부분집합 2² = 4개
  3. 32 − 4 = 28개

답: 28개
