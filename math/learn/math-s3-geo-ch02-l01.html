기하 문제가 각 추적이나 보조선으로 풀리지 않을 때, 점을 수로 바꾸어 계산으로 증명할 수 있습니다. 국제 대회에서 쓰는 계산 기법은 ① 데카르트 좌표 ② 복소수(특히 단위원) ③ 무게중심 좌표 세 가지이며, 문제의 모양에 맞는 것을 골라야 계산이 짧아집니다.

고르는 기준: 원이 하나 있고 그 위에 점이 많으면 복소수 단위원, 직각과 수직선이 많으면 데카르트 좌표, 삼각형의 오심과 체바 선이 많으면 무게중심 좌표가 좋습니다.

계산으로 푼 답안도 증명입니다. 다만 좌표를 어떻게 잡았는지(일반성을 잃지 않는 이유 포함), 어떤 조건을 식으로 바꿨는지를 분명히 써야 하고, 중간 계산을 채점자가 따라올 수 있게 남겨야 합니다.

복소수 단위원

외접원을 단위원으로 잡으면 꼭짓점 a, b, c는 |a| = |b| = |c| = 1이고 켤레는 ā = 1/a입니다. 이 한 가지 사실 덕분에 켤레가 들어간 식이 쉽게 정리됩니다.

외심이 원점이면 수심은 h = a + b + c, 무게중심은 g = (a + b + c)/3입니다. 수심 공식은 (h − a)/(b − c)가 순허수임을 확인하면 됩니다: (b + c)/(b − c)의 켤레는 (1/b + 1/c)/(1/b − 1/c) = (c + b)/(c − b) = −(b + c)/(b − c)이기 때문입니다.

판정법: 세 점 z₁, z₂, z₃가 한 직선 위 ⇔ (z₃ − z₁)/(z₂ − z₁)이 실수. 두 직선 z₁z₂ ⊥ z₃z₄ ⇔ (z₁ − z₂)/(z₃ − z₄)가 순허수. 실수인지는 '켤레와 같은가', 순허수인지는 '켤레가 −1배인가'로 확인합니다.

예제

단위원 위의 삼각형에서 O, G, H가 한 직선 위에 있고 OH = 3·OG임을 보이세요.

  1. 외심 O = 0, 수심 h = a + b + c, 무게중심 g = (a + b + c)/3입니다.
  2. h = 3g이므로 h − 0 = 3(g − 0)입니다.
  3. 따라서 O, G, H는 한 직선 위에 있고(실수배), OH = 3·OG입니다.

답: h = 3g

문제 1

단위원 위의 세 점 a = 1, b = i, c = −1로 이루어진 삼각형의 수심 h = a + b + c의 허수부는?

데카르트 좌표와 회전

데카르트 좌표는 서로 수직인 두 직선이 문제에 있을 때 가장 강력합니다. 두 직선을 축으로 잡으면 수직 조건이 저절로 들어갑니다. 예를 들어 수직인 두 현이 만나는 점을 원점에 두면 네 끝점이 (p, 0), (−r, 0), (0, q), (0, −s)가 되고, 네 점이 한 원 위에 있다는 조건은 방멱으로 pr = qs가 됩니다.

복소수로 회전을 쓸 수 있습니다: 점 z를 점 w 둘레로 90° 돌리면 w + i(z − w), −90°이면 w − i(z − w)입니다. 정사각형이나 정삼각형을 붙이는 문제는 이 회전으로 거의 바로 풀립니다(60° 회전은 ω = e^(iπ/3)를 곱함).

두 벡터 u, v가 길이가 같고 수직이라는 것은 v = ±iu 하나의 식으로 표현됩니다. 그래서 '길이가 같고 수직'을 한꺼번에 보이는 문제는 복소수가 특히 편합니다.

예제

점 3 + i를 원점 둘레로 90° 돌린 점과, 점 2 둘레로 90° 돌린 점을 구하세요.

  1. 원점 둘레 90° 회전은 i를 곱하는 것이므로 i(3 + i) = 3i − 1 = −1 + 3i입니다.
  2. 점 2 둘레 회전은 2 + i((3 + i) − 2) = 2 + i(1 + i) = 2 + i − 1입니다.
  3. = 1 + i입니다.

답: −1 + 3i, 1 + i

문제 2

점 2 + 4i를 원점 둘레로 −90° 돌린 점의 실수부는?

무게중심 좌표

삼각형 ABC에 대해 점 P를 넓이의 비 (u : v : w) = [PBC] : [PCA] : [PAB]로 나타내는 것을 무게중심 좌표라 합니다(부호 있는 넓이). 좌표의 합을 1로 맞추면 P = uA + vB + wC가 됩니다.

대표적인 점: 무게중심 (1 : 1 : 1), 내심 (a : b : c)(a, b, c는 마주 보는 변의 길이), 변 BC 위의 점 D는 (0 : DC : BD)입니다. 체바 선이 한 점에서 만나는 조건이나 넓이의 비를 다루는 문제에서 특히 편합니다.

세 점이 한 직선 위에 있다는 조건은 세 좌표가 이루는 3 × 3 행렬식이 0이라는 것이고, 세 직선이 한 점에서 만나는 조건도 행렬식으로 씁니다. 이 가이드에서는 내심의 좌표를 증명해 보는 데까지 다룹니다(문제 5).

문제 5

[문제 3] 원에 내접하는 사각형 ABCD의 대각선 AC, BD가 점 P에서 수직으로 만납니다. P를 지나 AB에 수직인 직선은 변 CD의 중점을 지남을 증명하세요.

문제 6

[문제 4] 평면 위의 네 점 A, B, C, D에 대해 AB · CD + AD · BC ≥ AC · BD(프톨레마이오스 부등식)임을 증명하세요.

문제 7

[문제 5] 삼각형 ABC의 변의 길이를 a = BC, b = CA, c = AB라 할 때 내심 I의 무게중심 좌표가 (a : b : c), 곧 I = (aA + bB + cC)/(a + b + c)임을 증명하세요.

자기 점검과 흔한 실수

좌표를 잡을 때 '일반성을 잃지 않고'의 이유를 쓰세요(예: 회전과 평행이동, 확대로 외접원을 단위원으로 만들 수 있다). 문제 3처럼 축을 문제의 직선에 맞추는 것도 마찬가지입니다.

문제 2에서 정사각형이 '바깥쪽'이라는 조건을 회전 방향(±90°)으로 정확히 옮겼는지 확인하세요. 방향을 반대로 잡으면 결론이 달라집니다.

계산이 길어지면 중간 결과를 보조정리로 떼어 두세요. 계산 실수 하나로 전체가 무너지는 것을 막고, 부분 점수를 받을 근거가 됩니다.

독학 순서와 참고 자료

추천 순서: ① 문제 1로 단위원 복소수 ② 문제 2·4로 회전과 항등식 ③ 문제 3으로 데카르트 좌표 ④ 문제 5로 무게중심 좌표를 익힙니다. 같은 문제를 각 추적으로도 풀어 보고 두 풀이의 길이를 비교하면 언제 계산을 택할지 감이 생깁니다.

더 공부할 주제: 단위원에서 현의 교점 공식, 외접원 위의 점의 심슨 직선, 무게중심 좌표의 거리 공식과 원의 방정식, 삼선 좌표.

참고 자료(영문): Evan Chen 『Euclidean Geometry in Mathematical Olympiads』 6장(복소수)·7장(무게중심 좌표), Evan Chen의 'Bashing Geometry with Complex Numbers'(누리집 공개), AoPS의 'Complex bash', 'Barycentric coordinates' 주제 토론.
