x, y에 무엇을 넣을까

함수방정식은 함수 f가 만족하는 식에서 f를 모두 찾는 문제입니다. 첫걸음은 변수에 특별한 값을 넣는 것입니다. x = 0, y = 0, y = x, y = −x, y = 1 같은 값이 자주 쓰입니다.

코시 방정식 f(x + y) = f(x) + f(y)에서 x = y = 0을 넣으면 f(0) = 2f(0)이라 f(0) = 0입니다. y = −x를 넣으면 f(0) = f(x) + f(−x)이므로 f(−x) = −f(x)입니다.

y = x를 거듭 넣으면 자연수 n에 대해 f(nx) = nf(x)이고, 이를 써서 유리수 q에 대해 f(q) = qf(1)을 얻습니다.

문제 1

f(x + y) = f(x) + f(y)이고 f(1) = 3일 때 f(5)는?

문제 2

모든 실수 x, y에 대해 f(x + y) = f(x) + f(y)를 만족하는 함수방정식을 ＿＿＿ 방정식이라 합니다.

유리수에서의 값

코시 방정식에서 f(nx) = nf(x)에 x = 1/n을 넣으면 f(1) = nf(1/n), 곧 f(1/n) = f(1)/n입니다. 그래서 f(m/n) = mf(1/n) = (m/n)f(1)입니다.

음수는 f(−x) = −f(x)로 다룹니다. 결국 모든 유리수 q에서 f(q) = cq (c = f(1))입니다.

실수 전체에서 f(x) = cx임을 보이려면 연속성, 단조성, 유계성 같은 추가 조건이 필요합니다. 이런 조건이 없으면 이상한 해가 존재합니다(선택 공리가 필요한 고급 주제).

예제

f(x + y) = f(x) + f(y), f(1) = 3일 때 f(2/3)을 구하세요.

  1. f(nx) = nf(x)에서 x = 1/3, n = 3을 넣으면 f(1) = 3f(1/3)입니다.
  2. 그래서 f(1/3) = 3/3 = 1입니다.
  3. f(2/3) = f(1/3 + 1/3) = 2f(1/3)입니다.
  4. = 2입니다.

답: 2

문제 4

f(x + y) = f(x) + f(y)이고 f(1) = 3일 때 f(−4)는?

곱으로 된 방정식

f(xy) = f(x) + f(y) (x, y > 0)는 로그와 비슷한 함수를 나타냅니다. x = y = 1을 넣으면 f(1) = 2f(1)이라 f(1) = 0입니다.

y = 1/x를 넣으면 f(1) = f(x) + f(1/x)이므로 f(1/x) = −f(x)입니다. 또 f(xⁿ) = nf(x)입니다.

f(xy) = f(x)f(y)는 거듭제곱 꼴(f(x) = xᵃ 등), f(x + y) = f(x)f(y)는 지수 꼴(f(x) = aˣ 등)의 해를 가집니다.

문제 7

f(x + y) = f(x)f(y)이고 f(1) = 2, f는 0이 아닌 값을 가질 때 f(0)은?

정리

함수방정식은 x = 0, y = 0, y = x, y = −x, y = 1/x 같은 특별한 값을 넣어 f(0), 대칭성, 정수·유리수에서의 값을 차례로 얻습니다.

코시 방정식 f(x + y) = f(x) + f(y)의 해는 유리수에서 f(q) = qf(1)이며, 실수 전체에서 f(x) = cx임을 보이려면 연속성 같은 조건이 필요합니다.

f(xy) = f(x) + f(y)는 로그 꼴(f(1) = 0, f(1/x) = −f(x)), f(x + y) = f(x)f(y)는 지수 꼴(f(0) = 1, 0이 아닌 해)입니다.
