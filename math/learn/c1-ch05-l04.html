부등식의 활용

수학의 기초 · 5. 부등식 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

근의 부호 조건

두 근이 모두 양수이려면 D ≥ 0, α + β > 0, αβ > 0이어야 합니다.

두 근의 부호가 다르려면 αβ < 0이면 충분합니다.

왜 세 조건이 필요할까요? D ≥ 0은 두 근이 실수라는 조건입니다. 두 근이 모두 양수이면 합과 곱이 모두 양수여야 하고, 반대로 합과 곱이 모두 양수이면 두 근이 모두 양수입니다.

문제 1

x² − 2kx + k + 6 = 0의 두 근이 모두 양수가 되는 정수 k의 최솟값은?

문제 2

x² + x + k − 2 = 0의 두 근의 부호가 다른 정수 k의 최댓값은?

실근을 가질 조건

이차방정식이 실근을 가지려면 D ≥ 0이어야 합니다.

x²의 계수에 문자가 있으면 그 계수가 0이 아니라는 조건도 함께 봅니다.

x²의 계수가 문자이면 그 계수가 0일 때는 이차방정식이 아니라 일차방정식이 됩니다. 문제에서 '이차방정식'이라고 했다면 계수 ≠ 0이라는 조건을 반드시 함께 써야 합니다.

예제

x² − 2(k − 1)x + k + 5 = 0의 두 근이 모두 양수가 되는 k의 범위를 구하세요.

  1. D/4 = (k − 1)² − (k + 5) = k² − 3k − 4 ≥ 0 → k ≤ −1 또는 k ≥ 4
  2. 두 근의 합 2(k − 1) > 0 → k > 1
  3. 두 근의 곱 k + 5 > 0 → k > −5
  4. 세 조건의 공통부분: k ≥ 4

답: k ≥ 4

문제 7

위로 던진 공의 t초 후 높이가 20t − 5t²m입니다. 높이가 15m 이상인 시간은 몇 초 동안일까요?

해에서 계수 찾기

해가 α < x < β이면 부등식은 a(x − α)(x − β) < 0(a > 0)과 같은 꼴입니다.

해가 α < x < β인데 부등호가 >이면 x²의 계수가 음수입니다.

해가 α < x < β인 이차부등식은 x²의 계수가 양수이면 (x − α)(x − β) < 0 꼴입니다. 주어진 부등식과 비교해 계수를 맞추면 모르는 계수를 구할 수 있습니다.

예제

ax² + bx + 3 > 0의 해가 −1 < x < 3일 때 a, b를 구하세요.

  1. 해가 두 근 사이인데 부등호가 >이므로 a < 0
  2. a(x + 1)(x − 3) > 0, 즉 a(x² − 2x − 3) > 0
  3. 상수항 비교: −3a = 3에서 a = −1
  4. x의 계수: b = −2a = 2

답: a = −1, b = 2

정수해의 개수

해의 범위를 문자로 나타낸 뒤, 정수가 몇 개 들어가는지 수직선에서 세어 조건을 맞춥니다.

정수해의 개수 문제는 범위의 끝점을 문자로 두고, 끝점이 어느 정수와 어느 정수 사이에 있어야 하는지 수직선에서 조건을 세웁니다. 끝점 포함 여부에 따라 등호가 달라집니다.

예제

2x − 1 < a를 만족하는 자연수 x가 4개일 때 정수 a의 범위를 구하세요.

  1. x < (a + 1)/2
  2. 자연수 1, 2, 3, 4만 포함되려면 4 < (a + 1)/2 ≤ 5
  3. 8 < a + 1 ≤ 10에서 7 < a ≤ 9
  4. 정수 a는 8, 9

답: a = 8 또는 9
