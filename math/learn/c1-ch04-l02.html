판별식

이차방정식 ax² + bx + c = 0에서 D = b² − 4ac를 판별식이라고 합니다.

근의 공식에서 √ 안에 들어가는 값입니다.

왜 '판별'식일까요? 근의 공식 √(b² − 4ac)에서 근호 안의 값이 양수인지, 0인지, 음수인지에 따라 근의 종류가 정해집니다. 방정식을 풀지 않고도 근의 종류를 판별할 수 있게 해 줍니다.

x² − 4x + 1 = 0의 판별식 D의 값은?

문제 2

이 방정식의 실근은 몇 개일까요?

근의 판별

D > 0이면 서로 다른 두 실근, D = 0이면 중근, D < 0이면 서로 다른 두 허근입니다.

D = 0이면 ±√D가 모두 0이라 두 근이 같아져 중근이 됩니다. D < 0이면 √D가 허수가 되어 두 근이 허근입니다. 이 판단은 계수가 실수일 때만 성립합니다.

예제

x² − 4x + k = 0이 서로 다른 두 실근을 가지는 k의 범위를 구하세요.

  1. 서로 다른 두 실근 ⇔ D > 0
  2. D = (−4)² − 4 × 1 × k = 16 − 4k
  3. 16 − 4k > 0에서 k < 4

답: k < 4

근과 계수의 관계

ax² + bx + c = 0의 두 근을 α, β라 하면 α + β = −b/a, αβ = c/a입니다.

왜 성립할까요? 두 근이 α, β이면 ax² + bx + c = a(x − α)(x − β)입니다. 우변을 전개하면 ax² − a(α + β)x + aαβ이므로 계수를 비교하면 α + β = −b/a, αβ = c/a가 나옵니다.

2x² − 6x + 1 = 0의 두 근의 곱은 1/＿＿＿

두 근으로 만든 식의 값

α² + β² = (α + β)² − 2αβ, 1/α + 1/β = (α + β)/αβ, (α − β)² = (α + β)² − 4αβ

아래에서 α, β는 x² − 3x + 1 = 0의 두 근입니다.

근을 직접 구하지 않아도 합과 곱만 알면 여러 식의 값을 구할 수 있습니다. 근이 무리수나 허수라 계산이 복잡할 때 특히 편리합니다.

예제

x² − 5x + 2 = 0의 두 근 α, β에 대해 α² + β²과 1/α + 1/β를 구하세요.

  1. 근과 계수의 관계: α + β = 5, αβ = 2
  2. α² + β² = (α + β)² − 2αβ = 25 − 4 = 21
  3. 1/α + 1/β = (α + β)/αβ = 5/2

답: 21, 5/2

(α − β)²의 값은?

두 근으로 방정식 만들기

두 근이 α, β인 이차방정식은 x² − (α + β)x + αβ = 0입니다.

계수가 실수인 이차방정식의 한 근이 p + qi이면 다른 근은 켤레복소수 p − qi입니다.

왜 켤레복소수가 함께 나올까요? 근의 공식에서 허근은 (−b ± √D)/2a의 ± 부분에서 나오므로 두 근은 허수부분의 부호만 다릅니다. 계수가 실수일 때만 성립하는 성질입니다.

예제

계수가 실수인 이차방정식 x² + ax + b = 0의 한 근이 3 − i일 때 a, b를 구하세요.

  1. 계수가 실수이므로 다른 근은 켤레복소수 3 + i
  2. 두 근의 합: 6 = −a이므로 a = −6
  3. 두 근의 곱: (3 − i)(3 + i) = 9 + 1 = 10 = b

답: a = −6, b = 10
