넓이와 이동 거리

곡선과 x축 사이의 넓이

넓이는 항상 양수이므로 ∫ₐᵇ |f(x)| dx로 구합니다. x축 아래 부분은 부호를 바꿔 더합니다.

정적분은 부호가 있는 넓이이므로, 곡선이 x축 아래로 내려간 부분은 음수로 계산됩니다. 넓이는 항상 양수여야 하므로 그 부분에 −를 곱해 더합니다. 그래서 먼저 곡선이 x축과 만나는 점을 구해 구간을 나누는 것이 첫 단계입니다.

문제 1

y = x² − 1과 x축으로 둘러싸인 부분의 넓이는? (기약분수로)

문제 2

y = x(x − 2)와 x축으로 둘러싸인 부분의 넓이는? (기약분수로)

두 곡선 사이의 넓이

두 곡선 사이의 넓이는 ∫ₐᵇ (위 곡선 − 아래 곡선) dx입니다. 교점의 x좌표가 적분 구간이 됩니다.

두 곡선 사이의 얇은 직사각형 하나의 높이는 (위 곡선 − 아래 곡선)입니다. 이것은 두 곡선이 x축 위에 있든 아래에 있든 항상 양수이므로, x축의 위치와 관계없이 그대로 적분하면 됩니다. 교점에서 위아래가 바뀌면 구간을 나눕니다.

예제

y = x² − 4x + 3과 x축으로 둘러싸인 부분의 넓이를 구하세요.

  1. x축과의 교점: (x − 1)(x − 3) = 0에서 x = 1, 3
  2. 1 < x < 3에서 곡선이 x축 아래이므로 넓이 = −∫₁³ (x² − 4x + 3) dx
  3. ∫₁³ = [x³/3 − 2x² + 3x]₁³ = 0 − 4/3 = −4/3
  4. 넓이 4/3

답: 4/3

위치의 변화와 이동 거리

속도가 v(t)일 때 a부터 b까지 위치의 변화는 ∫ₐᵇ v(t) dt, 움직인 거리는 ∫ₐᵇ |v(t)| dt입니다.

왜 두 가지가 다를까요? 앞으로 3m 갔다가 뒤로 1m 오면 위치의 변화는 2m지만 움직인 거리는 4m입니다. 속도를 그대로 적분하면 앞뒤가 상쇄되어 위치의 변화가, 속력(|v|)을 적분하면 실제로 움직인 총 거리가 나옵니다.

예제

y = x²과 y = 2x로 둘러싸인 부분의 넓이를 구하세요.

  1. 교점: x² = 2x에서 x = 0, 2
  2. 0 < x < 2에서 2x가 위
  3. ∫₀² (2x − x²) dx = [x² − x³/3]₀² = 4 − 8/3
  4. = 4/3

답: 4/3

문제 7

문제 8

같은 운동에서 t = 0부터 t = 4까지 움직인 거리는?

방향이 바뀌는 운동

v(t) = 0이 되는 시각에서 구간을 나눠 각각의 넓이를 더하면 이동 거리입니다.

속도가 0이 되는 시각에 운동 방향이 바뀝니다. 그 시각을 경계로 구간을 나누고, 각 구간의 정적분에 절댓값을 씌워 더하면 이동 거리입니다. 속도 그래프와 t축 사이의 넓이를 모두 양수로 더한다고 생각하면 됩니다.

예제

v(t) = t² − 4t + 3일 때 t = 0부터 t = 3까지 위치의 변화와 움직인 거리를 구하세요.

  1. v = (t − 1)(t − 3): 0 < t < 1에서 +, 1 < t < 3에서 −
  2. 위치의 변화: ∫₀³ v dt = [t³/3 − 2t² + 3t]₀³ = 0
  3. 거리: ∫₀¹ v dt = 4/3, ∫₁³ v dt = −4/3이므로 4/3 + 4/3
  4. 거리 8/3

답: 위치 변화 0, 거리 8/3

문제 10

같은 운동에서 t = 0부터 t = 3까지 움직인 거리는?

정리

넓이와 거리는 절댓값을 적분하고, 위치의 변화는 부호 그대로 적분합니다.

'부호 그대로'인지 '절댓값'인지 구별하는 것이 가장 중요합니다. 넓이와 이동 거리는 절댓값(항상 양수), 위치의 변화와 정적분은 부호 그대로입니다. 문제의 단어가 '넓이', '거리'인지 '위치', '값'인지를 먼저 확인합니다.
