최대공약수는 일차결합으로 나타난다

정수 a, b에 대해 ax + by = gcd(a, b)를 만족하는 정수 x, y가 있습니다. 이것을 베주 항등식이라고 합니다.

그래서 ax + by = c가 정수해를 가질 필요충분조건은 gcd(a, b) | c입니다. 좌변은 항상 gcd의 배수이고, 베주 항등식에 c/gcd를 곱하면 해가 나오기 때문입니다.

예를 들어 3 × 2 + 5 × (−1) = 1이므로 3x + 5y = 1은 해 (2, −1)을 가집니다. 반면 6x + 9y = 20은 좌변이 항상 3의 배수라서 해가 없습니다. 해의 존재 여부를 최대공약수 하나로 판정할 수 있다는 것이 이 정리의 힘입니다.

문제 1

3x + 5y = 1의 정수해 중 x가 가장 작은 자연수일 때 x의 값은?

문제 2

6x + 9y = c가 정수해를 가지려면 c는 ＿＿＿의 배수여야 합니다.

문제 3

4x + 6y = c가 정수해를 가지는 1 이상 20 이하의 정수 c는 모두 몇 개인가요?

호제법을 거꾸로 따라가기

베주 항등식의 x, y는 호제법을 거꾸로 따라가면 구할 수 있습니다. 1071 = 2 × 462 + 147, 462 = 3 × 147 + 21에서 21 = 462 − 3 × 147입니다.

147 = 1071 − 2 × 462를 넣으면 21 = 462 − 3(1071 − 2 × 462) = 7 × 462 − 3 × 1071입니다.

수가 작으면 그냥 x에 값을 하나씩 넣어 보는 편이 빠릅니다. 17x + 5y = 1이라면 17x를 5로 나눈 나머지가 1이 되는 x를 0, 1, 2, 3, 4 중에서 찾으면 됩니다. 어느 방법이든 찾은 해를 원래 식에 넣어 검산하는 줄을 꼭 씁니다.

예제

1071x + 462y = 21의 정수해 하나를 구하세요.

  1. 1071 = 2 × 462 + 147, 462 = 3 × 147 + 21입니다.
  2. 21 = 462 − 3 × 147이고, 147 = 1071 − 2 × 462입니다.
  3. 21 = 462 − 3(1071 − 2 × 462) = 7 × 462 − 3 × 1071입니다.
  4. 따라서 x = −3, y = 7이 해입니다. (검산: −3213 + 3234 = 21)

답: x = −3, y = 7

문제 4

17x + 5y = 1의 정수해 중 0 < x < 5인 해의 x는?

모든 해 구하기

gcd(a, b) = 1이고 (x₀, y₀)가 ax + by = c의 해이면, 모든 정수해는 x = x₀ + bt, y = y₀ − at (t는 정수)입니다.

두 해를 빼면 a(x − x₀) = −b(y − y₀)이고, a와 b가 서로소라서 b | x − x₀이기 때문입니다.

자연수 해를 세는 문제는 이 일반해에서 x > 0, y > 0을 만족하는 t의 범위를 구하면 됩니다. 3x + 5y = 47이라면 x는 5씩, y는 3씩 바뀌므로 x를 5로 나눈 나머지를 먼저 정하고, y가 양수인 동안 차례로 나열합니다.

문제 7

12x + 18y로 나타낼 수 있는 양의 정수 중 가장 작은 것은?

정리

ax + by = gcd(a, b)는 항상 정수해를 가지고(베주 항등식), ax + by = c는 gcd(a, b) | c일 때만 정수해를 가집니다.

해 하나는 호제법을 거꾸로 따라가거나, 작은 수에서는 나머지를 맞추는 값을 넣어 찾습니다.

gcd(a, b) = 1이면 모든 해는 (x₀ + bt, y₀ − at)입니다. 자연수 해의 개수는 x를 한 나머지로 정한 뒤 y가 양수인 동안 나열해 셉니다.
