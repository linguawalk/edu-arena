정의에서 출발하기

직접 증명은 가정에서 출발해 정의와 이미 아는 사실을 차례로 써서 결론에 닿는 증명입니다.

짝수는 정수 k로 2k, 홀수는 2k + 1로 나타냅니다. '3의 배수'는 3k, '3으로 나눈 나머지가 1'은 3k + 1입니다.

왜 정의부터 쓸까요? '홀수'라는 말만으로는 계산할 수 없지만, 2k + 1이라고 쓰는 순간 더하고 곱할 수 있는 식이 됩니다. 증명이 막히면 대부분 이 첫 줄을 쓰지 않았기 때문입니다. 서로 다른 두 수에는 서로 다른 문자(k, m)를 써야 한다는 점도 주의하세요.

문제 1

홀수는 정수 k를 써서 ＿＿＿로 나타냅니다.

문제 2

두 홀수 2a + 1, 2b + 1의 곱은 4ab + 2a + 2b + 1 = 2(＿＿＿) + 1입니다.

직접 증명의 뼈대

직접 증명은 대개 네 줄로 이루어집니다. 가정을 정의로 쓴다, 식을 계산한다, 결론의 꼴로 바꾼다, 결론을 쓴다.

결론의 꼴을 먼저 정해 두면 계산이 어디로 가야 할지 보입니다. '홀수이다'를 보이려면 2(정수) + 1 꼴을 만들면 됩니다.

답안에서는 '2(2ab + a + b) + 1에서 2ab + a + b가 정수이므로'처럼 괄호 안이 정수라는 말을 꼭 씁니다. 이 한 줄이 빠지면 채점에서 감점됩니다. 괄호 안이 정수인 이유는 정수끼리 더하고 곱하면 정수이기 때문입니다.

예제

두 홀수의 합은 짝수임을 증명하세요.

  1. 두 홀수를 2a + 1, 2b + 1 (a, b는 정수)로 놓습니다.
  2. 합은 (2a + 1) + (2b + 1) = 2a + 2b + 2입니다.
  3. 2a + 2b + 2 = 2(a + b + 1)이고 a + b + 1은 정수입니다.
  4. 따라서 두 홀수의 합은 짝수입니다.

답: 2(a + b + 1)

문제 5

연속한 네 정수의 합을 4로 나눈 나머지는?

식을 바꿔 결론의 꼴 만들기

부등식을 증명할 때는 '(무엇)² ≥ 0'이라는 사실을 자주 씁니다. 실수의 제곱은 음수가 될 수 없기 때문입니다.

증명하려는 부등식을 '좌변 − 우변 ≥ 0'으로 옮긴 뒤 완전제곱 꼴로 바꾸는 것이 기본 전략입니다.

왜 이 방법이 강력할까요? 완전제곱식은 0 이상이라는 것이 확실하고, 등호가 언제 성립하는지도 바로 보입니다. (a − b)² ≥ 0에서 등호는 a = b일 때만 성립합니다. 다음 챕터들에서 배울 산술·기하 평균 부등식도 이 아이디어에서 출발합니다.

예제

모든 실수 a, b에 대해 a² + b² ≥ 2ab임을 증명하세요.

  1. 좌변에서 우변을 빼면 a² + b² − 2ab입니다.
  2. a² − 2ab + b² = (a − b)²입니다.
  3. 실수의 제곱은 0 이상이므로 (a − b)² ≥ 0입니다.
  4. 따라서 a² + b² ≥ 2ab이고, 등호는 a = b일 때 성립합니다.

답: (a − b)² ≥ 0

문제 7

실수 x에 대해 x² − 6x + 10의 최솟값은?

정리

직접 증명은 가정을 정의로 쓰고, 계산하고, 결론의 꼴로 바꾸고, 결론을 쓰는 순서로 이루어집니다.

짝수 2k, 홀수 2k + 1, 3의 배수 3k처럼 말을 식으로 바꾸는 것이 첫 줄입니다. 서로 다른 수에는 서로 다른 문자를 씁니다.

부등식은 '좌변 − 우변'을 완전제곱 꼴로 바꾸어 0 이상임을 보입니다. 계산이 끝나면 '괄호 안이 정수이므로', '제곱은 0 이상이므로'처럼 마지막 근거를 꼭 한 줄로 적으세요. 올림피아드 채점에서는 이 근거 한 줄이 점수를 가릅니다.
