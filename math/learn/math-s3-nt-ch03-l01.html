이 가이드에서 다룰 도구

S2 '디오판토스 방정식'에서는 인수분해, 나머지 분석, 부등식으로 범위 좁히기를 배웠습니다. 국제 대회에서는 이 도구들을 겹쳐 쓰고, 여기에 ① 연속한 거듭제곱 사이에 끼우기 ② 지수 방정식의 인수분해(2ᵃ − 2ᵇ 꼴) ③ 이차잉여로 소인수 제한하기 ④ 무한 강하 ⑤ 펠 방정식이 더해집니다.

풀이의 첫 단계는 언제나 작은 해를 손으로 찾는 것입니다. 찾은 해가 '이것뿐'임을 보이는 것이 증명의 본체이고, 해가 무한히 많다면 그 구조(점화식, 거듭제곱)를 보여야 합니다.

선수 지식: S2 '디오판토스 방정식'과 '이차잉여', 이 트랙의 LTE와 p진 평가.

끼우기와 지수 방정식

끼우기: A² < N < (A + 1)²을 보이면 N은 제곱수가 아닙니다. 예를 들어 n > 0이면 n² < n² + n + 1 < (n + 1)²이므로 n² + n + 1은 제곱수가 아닙니다. 식을 완전제곱 꼴로 바꾼 뒤(4를 곱하는 등) 이웃한 제곱수 사이에 끼웁니다.

지수 방정식: 3ˣ − 2ʸ = 1처럼 거듭제곱이 섞인 식은 작은 법(mod 3, 4, 8)으로 지수의 홀짝을 정한 뒤, 짝수 지수를 차의 인수분해(a² − b² = (a − b)(a + b))로 쪼갭니다. 두 인수가 모두 2의 거듭제곱이고 차가 2라면 2와 4뿐이라는 식의 결론이 자주 나옵니다.

인수분해 꼴 만들기: x² + 3x + 7 = y²처럼 이차식이 나오면 4를 곱해 (2x + 3)² + 19 = (2y)²로 바꾸고 (2y − 2x − 3)(2y + 2x + 3) = 19처럼 곱의 꼴로 만듭니다.

예제

x² + 3x + 7 = y²을 만족하는 양의 정수 x, y를 모두 구하세요.

  1. 양변에 4를 곱하면 (2x + 3)² + 19 = (2y)², 곧 (2y − 2x − 3)(2y + 2x + 3) = 19입니다.
  2. 19는 소수이고 2y + 2x + 3 > 0이므로 두 인수는 1과 19이며, 큰 쪽이 2y + 2x + 3 = 19, 작은 쪽이 2y − 2x − 3 = 1입니다.
  3. 더하면 4y = 20에서 y = 5, 빼면 4x + 6 = 18에서 x = 3입니다(9 + 9 + 7 = 25 확인).

답: (x, y) = (3, 5)

문제 1

위 예제의 해에서 x + y의 값은?

이차잉여와 무한 강하

이차잉여로 소인수 제한하기: 소수 q ≡ 3 (mod 4)는 y² + 1을 나눌 수 없습니다(−1이 q를 법으로 제곱수가 아니므로). 그래서 'y² + 1 = (어떤 수)'에서 그 수가 4k + 3 꼴의 소인수를 가지면 모순입니다. 4k + 3 꼴의 수는 반드시 4k + 3 꼴의 소인수를 가집니다(4k + 1 꼴끼리의 곱은 4k + 1 꼴이므로).

무한 강하: 양의 정수해가 있다고 하고 그로부터 더 작은 양의 정수해를 만들 수 있으면, 이를 반복해 양의 정수가 끝없이 줄어드는 모순이 생깁니다. 흔히 '해 가운데 x가 가장 작은 것을 잡자'로 시작해 더 작은 해를 만듭니다.

mod 4, mod 8은 제곱수에서 특히 강력합니다. 제곱수는 mod 4로 0, 1이고, 홀수의 제곱은 mod 8로 1입니다. 그래서 '홀수가 몇 개인가'를 따지면 강하의 첫 단계(모두 짝수)를 얻는 경우가 많습니다.

문제 2

홀수 a에 대해 a²을 8로 나눈 나머지는 언제나 얼마인가요?

펠 방정식

x² − dy² = 1(d는 제곱수가 아닌 양의 정수)을 펠 방정식이라 합니다. 가장 작은 양의 해 (x₁, y₁)을 찾으면 모든 양의 해는 xₙ + yₙ√d = (x₁ + y₁√d)ⁿ으로 주어집니다.

d = 2이면 가장 작은 해는 (3, 2)이고, (3 + 2√2)² = 17 + 12√2이므로 다음 해는 (17, 12), 그다음은 (99, 70)입니다. 점화식으로는 xₙ₊₁ = 3xₙ + 4yₙ, yₙ₊₁ = 2xₙ + 3yₙ입니다.

해가 무한히 많음을 보이는 데는 '곱해도 해가 유지된다'만 보이면 충분합니다. (x² − 2y²)(a² − 2b²) = (xa + 2yb)² − 2(xb + ya)²이라는 항등식이 그 근거입니다. 모든 해가 이 꼴임을 보이는 것은 더 어렵고, 대회에서는 대개 '무한히 많다' 또는 '특정 성질을 가진 해가 있다'를 묻습니다.

예제

x² − 2y² = 1의 해 (17, 12) 다음 해를 점화식으로 구하세요.

  1. xₙ₊₁ = 3xₙ + 4yₙ = 3 × 17 + 4 × 12 = 51 + 48 = 99입니다.
  2. yₙ₊₁ = 2xₙ + 3yₙ = 2 × 17 + 3 × 12 = 34 + 36 = 70입니다.
  3. 확인: 99² − 2 × 70² = 9801 − 9800 = 1입니다.

답: (99, 70)

자기 점검과 흔한 실수

문제 1·2에서 '차가 2인 2의 거듭제곱 쌍은 (2, 4)뿐'이라는 근거를 썼는지 확인하세요(4 이상의 2의 거듭제곱끼리는 차가 4 이상, 1과 3은 3이 2의 거듭제곱이 아님).

문제 3에서 '4k + 3 꼴의 수는 4k + 3 꼴의 소인수를 가진다'는 이유를 한 줄이라도 쓰세요. 문제 4의 강하에서는 '같은 꼴의 더 작은 해'가 되도록 명제를 일반화했는지가 핵심입니다. m을 고정한 채 강하하면 지수가 바뀌어 논리가 끊깁니다.

문제 5에서 '무한히 많다'만 묻는 경우와 '모든 해를 구하라'를 묻는 경우를 구별하세요. 후자는 가장 작은 해에서 거꾸로 내려가는 강하가 필요합니다.

독학 순서와 참고 자료

추천 순서: ① 문제 2·1로 지수 방정식의 인수분해 ② 문제 3으로 이차잉여 논법 ③ 문제 4로 무한 강하 ④ 문제 5로 펠 방정식을 익힙니다. 그다음 '비에타 점프(이차방정식의 다른 근으로 건너뛰는 강하)'를 공부하면 국제 대회의 대표적인 디오판토스 기법을 모두 갖춥니다.

더 공부할 주제: 비에타 점프, 가우스 정수 ℤ[i]에서의 인수분해(x² + y² 꼴), 지그몬디 정리(원시 소인수)를 쓰는 지수 방정식, 연분수와 펠 방정식의 기본해.

참고 자료(영문): Titu Andreescu·Dorin Andrica 『An Introduction to Diophantine Equations』, Titu Andreescu 외 『104 Number Theory Problems』, AoPS의 'Vieta jumping', 'Pell equation' 주제 글.
