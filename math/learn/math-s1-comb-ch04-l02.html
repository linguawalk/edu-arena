올바른 괄호

여는 괄호 n개와 닫는 괄호 n개로 만든 올바른 괄호 배열의 수를 n번째 카탈랑 수 Cₙ이라 합니다. 'n = 3'이면 ((())), (()()), (())(), ()(()), ()()()의 5가지입니다.

올바르다는 것은 왼쪽부터 읽을 때 언제나 닫는 괄호가 여는 괄호보다 많지 않다는 뜻입니다.

카탈랑 수는 Cₙ = C(2n, n)/(n + 1)이고, 1, 1, 2, 5, 14, 42, 132, …로 이어집니다. 놀라운 점은 전혀 다른 듯한 문제들이 모두 이 수로 답이 된다는 것입니다. 대각선을 넘지 않는 격자 경로, 다각형의 삼각분할, 교차하지 않는 현의 짝짓기가 모두 카탈랑 수입니다.

문제 1

괄호 3쌍으로 만든 올바른 괄호 배열은 몇 가지인가요?

문제 2

카탈랑 수는 Cₙ = C(2n, n)/(n + ＿＿＿)입니다.

반사 원리

괄호 배열을 격자 경로로 바꿉니다. 여는 괄호는 오른쪽, 닫는 괄호는 위쪽으로 한 칸 가면, 올바른 괄호는 (0, 0)에서 (n, n)까지 대각선 y = x 위로 올라가지 않는 경로입니다.

나쁜 경로는 처음으로 y = x + 1에 닿는 점이 있습니다. 그 뒤의 부분을 y = x + 1에 대해 뒤집으면 (n − 1, n + 1)로 가는 경로가 되고, 거꾸로 (n − 1, n + 1)로 가는 경로는 반드시 y = x + 1에 닿으므로 같은 방법으로 되돌릴 수 있습니다.

그래서 나쁜 경로는 C(2n, n + 1)개이고, 좋은 경로는 C(2n, n) − C(2n, n + 1) = C(2n, n)/(n + 1)개입니다. '처음 닿은 뒤를 뒤집는다'는 일대일대응 하나로 직접 세기 어려운 것을 세는 대표적인 방법입니다.

예제

(0, 0)에서 (3, 3)까지 대각선 y = x 위로 올라가지 않는 최단 경로의 수를 반사 원리로 구하세요.

  1. 전체 최단 경로는 C(6, 3) = 20개입니다.
  2. 나쁜 경로는 반사하면 (2, 4)로 가는 경로와 일대일대응하므로 C(6, 2) = 15개입니다.
  3. 좋은 경로는 20 − 15 = 5개입니다.
  4. 이는 C₃ = 5와 같습니다.

답: 5

문제 3

(0, 0)에서 (4, 4)까지 대각선 y = x 위로 올라가지 않는 최단 경로는 몇 개인가요?

문제 4

다섯 번째 카탈랑 수 C₅의 값은?

다각형의 삼각분할

볼록 (n + 2)각형을 서로 교차하지 않는 대각선으로 삼각형들로 나누는 방법은 Cₙ가지입니다. 사각형은 2가지, 오각형은 5가지입니다.

한 변을 정하면, 그 변을 포함하는 삼각형의 세 번째 꼭짓점이 다각형을 두 개의 더 작은 다각형으로 나눕니다. 그래서 Cₙ₊₁ = C₀Cₙ + C₁Cₙ₋₁ + ⋯ + CₙC₀이라는 점화식이 나옵니다.

괄호에서도 같은 점화식이 나옵니다. 첫 여는 괄호와 짝이 되는 닫는 괄호를 찾으면, 그 안쪽과 바깥쪽이 각각 더 작은 올바른 괄호가 되기 때문입니다. 서로 다른 문제가 같은 점화식과 같은 첫 값을 가지면 답이 같다는 것이 카탈랑 수가 여기저기서 나오는 이유입니다.

거스름돈 문제

표 한 장이 500원인 매표소에 500원 동전을 가진 사람 n명과 1000원 지폐를 가진 사람 n명이 줄을 섭니다. 매표소에 처음에 거스름돈이 없을 때, 누구도 거스름돈을 못 받는 일이 없도록 줄을 서는 순서(같은 종류끼리는 구별하지 않음)는 Cₙ가지입니다.

500원은 여는 괄호, 1000원은 닫는 괄호와 같습니다. 1000원을 낸 사람까지의 1000원 수가 500원 수보다 많으면 거스름돈이 모자랍니다.

이처럼 문제를 읽고 '언제나 한쪽이 다른 쪽보다 많지 않아야 한다'는 구조를 찾으면 카탈랑 수를 떠올립니다. 등산로 모양(올라가기와 내려가기, 해수면 아래로 내려가지 않음), 투표 개표 과정 문제도 같은 구조입니다.

문제 7

500원 동전을 가진 4명과 1000원 지폐를 가진 4명이 줄을 설 때, 처음 거스름돈이 없는 매표소에서 누구도 거스름돈을 못 받는 일이 없는 순서는 몇 가지인가요? (같은 종류는 구별하지 않음)

문제 8

여섯 번째 카탈랑 수 C₆의 값은?

정리

카탈랑 수 Cₙ = C(2n, n)/(n + 1) = C(2n, n) − C(2n, n + 1)은 1, 1, 2, 5, 14, 42, 132, …입니다.

반사 원리: 대각선을 처음 넘은 뒤를 뒤집어 나쁜 경로를 (n − 1, n + 1)로 가는 경로와 대응시킵니다.

올바른 괄호, 대각선을 넘지 않는 경로, 삼각분할, 거스름돈 문제는 모두 Cₙ₊₁ = Σ CᵢCₙ₋ᵢ를 만족하므로 답이 같습니다. '언제나 한쪽이 다른 쪽보다 많지 않다'는 구조를 찾으세요.
