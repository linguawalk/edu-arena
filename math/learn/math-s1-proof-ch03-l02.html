다섯 가지 흔한 실수

답안에서 가장 많이 감점되는 실수는 다섯 가지입니다. 예 몇 개로 '모든'을 주장하기, 0일 수 있는 식으로 나누기, 결론에서 출발해 거꾸로 쓰기, 경우 빠뜨리기, 최솟값의 등호 확인 빼먹기.

1장에서 본 첫 번째 실수를 빼고, 이 레슨에서는 나머지 네 가지를 차례로 고쳐 봅니다.

왜 따로 연습할까요? 이 실수들은 계산 능력과 상관없이 생깁니다. 문제를 끝까지 푼 학생도 답안 한 줄 때문에 점수의 절반을 잃곤 합니다. 남의 잘못된 증명에서 틀린 줄을 찾는 연습을 하면, 내 답안에서 같은 실수를 찾는 눈이 생깁니다.

문제 1

다음 '증명'에서 처음으로 틀린 단계의 번호는? ① a = b라 하자. ② a² = ab ③ a² − b² = ab − b² ④ (a + b)(a − b) = b(a − b) ⑤ a + b = b ⑥ 2b = b ⑦ 2 = 1

문제 2

앞 '증명'의 ⑤에서 양변을 나눈 식 a − b의 값은 ＿＿＿입니다.

거꾸로 쓴 증명

증명할 부등식에서 출발해 '양변을 제곱하면 …, 정리하면 … ≥ 0, 이것은 참이다'로 끝내는 답안이 많습니다. 이것은 결론을 가정하고 참인 식을 얻은 것이라 그대로는 증명이 아닙니다.

거짓인 식에서도 참인 식이 나올 수 있기 때문입니다. 1 = −1은 거짓이지만 양변을 제곱하면 1 = 1로 참입니다.

고치는 방법은 두 가지입니다. 참인 식에서 출발해 앞으로 쓰거나, 각 단계가 거꾸로도 성립함(⇔)을 근거와 함께 밝힙니다. 제곱이 거꾸로도 성립하려면 양변이 모두 0 이상이어야 합니다. 연습할 때는 거꾸로 생각하되, 답안은 앞으로 쓰는 습관을 들이세요.

예제

양수 a, b에 대해 √a + √b > √(a + b)임을 앞으로 쓰는 답안으로 증명하세요.

  1. a, b > 0이므로 2√(ab) > 0이다.
  2. 양변에 a + b를 더하면 a + b + 2√(ab) > a + b, 곧 (√a + √b)² > (√(a + b))²이다.
  3. √a + √b와 √(a + b)는 모두 양수이므로, 제곱의 대소에서 원래 수의 대소가 나온다.
  4. 따라서 √a + √b > √(a + b)이다.

답: 참인 식 2√(ab) > 0에서 출발

문제 4

'x < 1/x이면 x² < 1이다'는 거짓입니다. 반례가 되는 정수 x 중 가장 큰 것은?

경우를 빠뜨리지 않기

경우를 나눈 답안은 '나눈 경우들이 모든 가능성을 덮는가'를 채점자가 가장 먼저 봅니다.

절댓값이면 경계값을 어느 경우에 넣었는지, 정수면 나머지를 모두 다뤘는지, 짝수·홀수 중 하나만 다루지 않았는지 확인합니다.

예를 들어 |x| + |x − 2| = 2를 x < 0과 x > 2의 두 경우로만 풀면 해가 없다고 결론짓게 됩니다. 그러나 0 ≤ x ≤ 2이면 x + (2 − x) = 2로 항상 성립해 이 구간 전체가 해입니다. 빠진 한 경우에 답 전체가 들어 있었던 셈입니다. 경우를 나누는 줄에 '이 세 경우가 모든 실수를 덮는다'를 적으면 이런 누락을 스스로 점검하게 됩니다.

문제 6

n² + n이 짝수임을 보일 때 짝수인 경우만 다루면 안 됩니다. n = 2k + 1이면 n² + n = 2(＿＿＿)입니다.

최솟값은 두 부분으로

'최솟값을 구하라'의 답안은 두 부분입니다. (가) 모든 경우에 식의 값이 m 이상이다. (나) 식의 값이 실제로 m이 되는 경우가 있다.

(가)만 쓰면 m이 최솟값인지 알 수 없습니다. 'x² + 1 ≥ 0'은 참이지만 x² + 1의 최솟값은 0이 아니라 1입니다.

부등식을 여러 번 써서 하한을 구할 때 특히 위험합니다. 각 부등식의 등호 조건이 서로 맞지 않으면, 얻은 하한에 실제로 도달할 수 없습니다. 그래서 하한을 구한 뒤에는 등호가 동시에 성립하는 값을 찾아 직접 넣어 보는 줄을 반드시 씁니다.

잘못 찾기

양수 a, b가 a + b = 1일 때 (a + 1/a)(b + 1/b)의 최솟값이 4라는 답안의 잘못을 찾으세요.

  1. 답안: a + 1/a ≥ 2, b + 1/b ≥ 2이므로 곱은 4 이상이다.
  2. a + 1/a = 2인 것은 a = 1일 때뿐이고, b + 1/b = 2인 것도 b = 1일 때뿐이다.
  3. a = b = 1이면 a + b = 2라서 조건 a + b = 1에 맞지 않으므로, 곱은 실제로 4가 될 수 없다.
  4. 따라서 4는 하한이지만 최솟값이 아니다. (나) 부분이 빠진 답안이다.

답: 등호 조건이 a + b = 1과 맞지 않음

문제 8

x > 0일 때 x + 9/x의 최솟값은?

정리

식으로 나눌 때는 그 식이 0이 아님을 먼저 밝히거나 0인 경우를 따로 다룹니다. 부등식 양변에 곱할 때는 부호를 확인합니다.

결론에서 출발한 계산은 연습장에 두고, 답안은 참인 식에서 앞으로 씁니다. 제곱하거나 제곱근을 취하는 줄에는 '양변이 양수'라는 근거를 씁니다.

경우를 나누면 모든 가능성을 덮는지, 최솟값은 하한과 실제 도달을 모두 보였는지 점검합니다. 다섯 가지 실수 목록을 답안 검토용 체크리스트로 쓰세요.
