도함수

각 x에 미분계수 f′(x)를 대응시킨 함수를 도함수라고 합니다. f′(x) = lim(h→0) (f(x + h) − f(x))/h

도함수를 구하는 것을 미분한다고 합니다.

미분계수가 '한 점에서의 기울기'라면, 도함수는 '모든 점에서의 기울기를 알려 주는 함수'입니다. f′(x)를 한 번 구해 두면 어떤 점의 미분계수든 x에 값을 넣기만 하면 되므로, 정의로 매번 계산할 필요가 없어집니다.

f(x) = x²이면 f′(x) = ＿＿＿x

문제 2

f(x) = x³이면 f′(x) = ＿＿＿x²

기본 공식

(xⁿ)′ = nxⁿ⁻¹ (n은 자연수), (x)′ = 1, (c)′ = 0 (c는 상수)

왜 nxⁿ⁻¹일까요? (x + h)ⁿ을 이항정리로 전개하면 xⁿ + nxⁿ⁻¹h + (h²이 곱해진 항들)입니다. xⁿ을 빼고 h로 나누면 nxⁿ⁻¹ + (h가 곱해진 항들)이 되고, h → 0이면 nxⁿ⁻¹만 남습니다. 상수의 도함수가 0인 것은 상수함수의 그래프가 수평선이라 기울기가 0이기 때문입니다.

예제

정의를 이용해 f(x) = x²의 도함수를 구하세요.

  1. f(x + h) − f(x) = (x + h)² − x² = 2xh + h²
  2. h로 나누면 2x + h
  3. h → 0이면 2x
  4. 공식 (xⁿ)′ = nxⁿ⁻¹과 일치

답: f′(x) = 2x

도함수에서 미분계수로

도함수를 구한 뒤 x = a를 넣으면 f′(a)입니다. 정의로 매번 계산하는 것보다 훨씬 빠릅니다.

도함수 f′(x)는 함수이고, 미분계수 f′(a)는 그 함수에 a를 넣은 수입니다. 둘을 구별하는 것이 중요합니다. 공식으로 도함수를 먼저 구한 뒤 값을 넣으면 정의로 계산하는 것보다 훨씬 빠르고 실수도 적습니다.

예제

f(x) = x⁵에서 f′(x)와 f′(−1)을 구하세요.

  1. 공식: f′(x) = 5x⁴
  2. x = −1을 넣으면 5 × (−1)⁴
  3. = 5
  4. 주의: 짝수 제곱이라 음수를 넣어도 양수

답: 5x⁴, 5

도함수의 부호

f′(x) > 0인 곳에서는 접선이 오른쪽 위로, f′(x) < 0인 곳에서는 오른쪽 아래로 향합니다.

도함수의 부호는 원래 함수의 증가·감소를 알려 줍니다. f′(x) > 0이면 그 근처에서 함수가 증가하고, f′(x) < 0이면 감소합니다. f′(x) = 0인 곳은 증가에서 감소로(또는 반대로) 바뀔 수 있는 후보가 되며, 다음 챕터의 극값과 연결됩니다.

예제

f(x) = x²에서 도함수가 양수인 범위와 음수인 범위를 구하고 그래프 모양과 연결하세요.

  1. f′(x) = 2x
  2. x > 0이면 f′(x) > 0 → 증가
  3. x < 0이면 f′(x) < 0 → 감소
  4. x = 0에서 f′(0) = 0 → 포물선의 꼭짓점

답: x > 0에서 증가, x < 0에서 감소
