평행과 수직의 조건

영벡터가 아닌 a, b에 대해 a ∥ b ⇔ a = kb, a ⊥ b ⇔ a·b = 0

평행은 '방향이 같거나 반대', 수직은 '내적이 0'으로 판단합니다. 성분으로 쓰면 평행은 a₁b₂ − a₂b₁ = 0, 수직은 a₁b₁ + a₂b₂ = 0입니다. 코스 2에서 기울기로 판단하던 것(같으면 평행, 곱이 −1이면 수직)을 세로선까지 포함하는 방법으로 넓힌 것입니다.

문제 1

(2, k)와 (3, 6)이 수직일 때 k의 값은?

문제 2

(k, 2)와 (3, 6)이 평행할 때 k의 값은?

세 점이 한 직선 위에

세 점 A, B, C가 한 직선 위에 있으면 AC = kAB인 실수 k가 있습니다.

세 점이 한 직선 위에 있다는 것은 AB와 AC가 같은 직선 위의 벡터, 즉 평행하다는 뜻입니다. 그래서 AC = kAB로 쓸 수 있고, 성분으로 쓰면 비례식이 됩니다. 기울기가 같다는 조건과 같은 내용입니다.

예제

세 점 A(2, −1), B(4, 3), C(k, 9)가 한 직선 위에 있을 때 k를 구하세요.

  1. AB = (2, 4), AC = (k − 2, 10)
  2. 평행 조건: 2 × 10 = 4 × (k − 2)
  3. 20 = 4k − 8
  4. k = 7

답: 7

도형에서 직각 판정

두 변을 나타내는 벡터의 내적이 0이면 그 사이의 각이 직각입니다.

삼각형이 직각삼각형인지 확인할 때 피타고라스 정리 대신 두 변 벡터의 내적을 계산하면 빠릅니다. 마름모의 대각선이 수직인 이유도 내적으로 보일 수 있어, 도형의 성질을 계산으로 증명하는 도구가 됩니다. 꼭짓점이 같은 두 변 벡터를 골라야 그 꼭짓점의 각을 판단할 수 있습니다.

문제 6

정사영의 길이

a를 b 방향으로 정사영한 길이는 a·b / |b|입니다. 그림자의 길이라고 생각하면 됩니다.

정사영의 길이는 a를 b 방향에 비친 그림자의 길이입니다. |a|cos θ이고, cos θ = a·b/(|a||b|)를 넣으면 a·b/|b|가 됩니다. 내적 a·b는 '정사영의 길이 × |b|'라고 해석할 수 있습니다.

예제

a = (4, 3)을 b = (1, 1) 방향으로 정사영한 길이와 정사영 벡터를 구하세요.

  1. a·b = 7, |b| = √2
  2. 정사영의 길이 7/√2 = 7√2/2
  3. 정사영 벡터 = (길이) × (b의 단위벡터) = (7/√2)(1/√2, 1/√2)
  4. = (7/2, 7/2)

답: 7√2/2, (7/2, 7/2)

문제 8

정리

평행은 실수배, 수직은 내적 0. 크기의 제곱을 전개할 때도 수직이면 a·b 항이 사라집니다.

수직이면 a·b = 0이므로 |a + b|² = |a|² + |b|²이 되어 피타고라스 정리와 같아집니다. 벡터의 계산이 기하의 정리를 자연스럽게 담고 있다는 좋은 예입니다. 수직이 아니면 2a·b 항이 코사인법칙의 보정항 역할을 합니다.

예제

|a| = |b|이면 (a + b) ⊥ (a − b)임을 보이세요.

  1. (a + b)·(a − b) = a·a − a·b + b·a − b·b
  2. = |a|² − |b|²
  3. |a| = |b|이므로 0
  4. 내적이 0이라 수직 (마름모의 대각선이 수직인 이유)
