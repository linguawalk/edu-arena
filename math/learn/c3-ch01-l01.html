n제곱근

n제곱해서 a가 되는 수, 즉 xⁿ = a를 만족하는 x를 a의 n제곱근이라고 합니다.

2³ = 8이므로 2는 8의 세제곱근입니다.

n제곱근은 거듭제곱을 거꾸로 푸는 연산입니다. 제곱근이 '제곱해서 a가 되는 수'였듯이, n제곱근은 'n번 곱해서 a가 되는 수'입니다. 복소수까지 생각하면 a의 n제곱근은 항상 n개가 있지만, 이 레슨에서는 그중 실수인 것만 다룹니다.

8의 세제곱근 중 실수는?

문제 2

16의 네제곱근 중 실수는 몇 개일까요?

실수인 n제곱근의 개수

n이 홀수이면 실수 a의 n제곱근 중 실수는 하나입니다.

n이 짝수이면 a > 0일 때 둘(±), a = 0일 때 하나(0), a < 0일 때 없습니다.

왜 n의 홀짝이 중요할까요? y = xⁿ의 그래프를 떠올리면 됩니다. n이 홀수이면 그래프가 왼쪽 아래에서 오른쪽 위로 이어져 어떤 직선 y = a와도 한 번 만납니다. n이 짝수이면 그래프가 U자 모양이라 a > 0이면 두 번, a = 0이면 한 번, a < 0이면 한 번도 만나지 않습니다.

예제

−64의 세제곱근과 64의 여섯제곱근 중 실수인 것을 모두 구하세요.

  1. 세제곱(홀수)이므로 실수인 세제곱근은 하나: (−4)³ = −64에서 −4
  2. 여섯제곱(짝수)이고 64 > 0이므로 실수인 것은 둘
  3. 2⁶ = 64이므로 2와 −2
  4. 확인: (−2)⁶ = 64 (짝수 번 곱하면 음수도 양수가 됨)

답: −4 / ±2

기호 ⁿ√a와 성질

a > 0일 때 a의 양의 n제곱근을 ⁿ√a로 씁니다. n이 홀수이면 음수 a에 대해서도 ⁿ√a가 실수입니다.

ⁿ√a × ⁿ√b = ⁿ√(ab), (ⁿ√a)ᵐ = ⁿ√(aᵐ), ᵐ√(ⁿ√a) = ᵐⁿ√a

이 성질들은 지수법칙을 근호로 바꿔 쓴 것입니다. 예를 들어 ⁿ√a × ⁿ√b를 n제곱하면 (ⁿ√a)ⁿ(ⁿ√b)ⁿ = ab이므로 ⁿ√a × ⁿ√b는 ab의 양의 n제곱근, 즉 ⁿ√(ab)입니다. 성질을 외우기보다 이렇게 n제곱해서 확인하는 습관을 들이면 틀리지 않습니다.

예제

⁴√8 × ⁴√2 + ³√(−27)을 계산하세요.

  1. 같은 차수의 근호는 곱해서 하나로: ⁴√8 × ⁴√2 = ⁴√16
  2. 16 = 2⁴이므로 ⁴√16 = 2
  3. ³√(−27) = −3 (홀수 차수는 음수도 가능)
  4. 2 + (−3) = −1

답: −1

거듭제곱근의 크기 비교

근호의 차수를 같게 만들면 안의 수로 비교할 수 있습니다. ³√3 = ⁶√9, √2 = ⁶√8

왜 차수를 맞출까요? 차수가 다르면 근호 안의 수를 바로 비교할 수 없습니다. ³√3과 √2를 모두 여섯제곱하면 9와 8이 되어 비교가 쉬워집니다. 양수끼리는 같은 수만큼 거듭제곱해도 크기 순서가 바뀌지 않기 때문입니다.

예제

√3, ³√5, ⁶√26의 크기를 비교하세요.

  1. 차수 2, 3, 6의 최소공배수 6으로 맞춥니다.
  2. √3 = ⁶√(3³) = ⁶√27, ³√5 = ⁶√(5²) = ⁶√25
  3. ⁶√25 < ⁶√26 < ⁶√27
  4. 확인: 근호 안의 수가 클수록 큽니다(양수).

답: ³√5 < ⁶√26 < √3

정리

근호 안을 거듭제곱 꼴로 나타내면 대부분의 계산이 간단해집니다. 64 = 2⁶, 729 = 3⁶

근호 계산의 요령은 근호 안을 소인수의 거듭제곱으로 바꾸는 것입니다. 729 = 3⁶처럼 바꿔 두면 ³√(√729) = ⁶√(3⁶) = 3으로 바로 계산됩니다. 큰 수를 보면 먼저 2, 3, 5의 거듭제곱인지 확인하세요.
