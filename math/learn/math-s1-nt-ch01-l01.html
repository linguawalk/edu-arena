a가 b를 나눈다

정수 a ≠ 0에 대해 b = ak인 정수 k가 있으면 'a가 b를 나눈다'고 하고 a | b로 씁니다. 3 | 12, 5 | −20, 7 | 0입니다.

기본 성질은 두 가지입니다. a | b이고 b | c이면 a | c입니다. 또 a | b이고 a | c이면 모든 정수 x, y에 대해 a | bx + cy입니다.

두 번째 성질이 정수론 문제의 절반을 풉니다. d가 n + 3과 2n + 1을 모두 나누면 d는 2(n + 3) − (2n + 1) = 5도 나눕니다. 문자가 들어 있는 두 식의 공약수를 구할 때, 문자가 사라지도록 일차결합을 만드는 것이 핵심입니다.

문제 2

d가 n + 3과 2n + 1을 모두 나누면, d는 2(n + 3) − (2n + 1) = ＿＿＿도 나눕니다.

나눗셈 정리

정수 a와 자연수 b에 대해 a = bq + r, 0 ≤ r < b를 만족하는 정수 q, r이 하나씩만 있습니다. q를 몫, r을 나머지라고 합니다.

음수도 같습니다. −17 = 5 × (−4) + 3이므로 −17을 5로 나눈 나머지는 3입니다. 나머지는 항상 0 이상 b 미만입니다.

왜 이 정리가 중요할까요? 모든 정수를 'b로 나눈 나머지'에 따라 b가지로 분류할 수 있게 해 주기 때문입니다. 증명의 기초 트랙에서 정수를 3k, 3k + 1, 3k + 2로 나눈 것이 바로 이 정리를 쓴 것입니다. 다음 챕터의 합동식은 이 분류를 계산 도구로 만든 것입니다.

문제 3

−17을 5로 나눈 나머지는?

예제

자연수 n에 대해 n + 3과 2n + 1의 최대공약수가 될 수 있는 값을 모두 구하세요.

  1. d가 두 수를 모두 나누면 d | 2(n + 3) − (2n + 1) = 5입니다.
  2. 따라서 d는 1 또는 5입니다.
  3. n = 1이면 4와 3으로 최대공약수가 1이고, n = 2이면 5와 5로 최대공약수가 5입니다.
  4. 두 값이 모두 실제로 나오므로 가능한 값은 1과 5입니다.

답: 1, 5

문제 4

n + 3과 2n + 1의 최대공약수가 5가 되는 가장 작은 자연수 n은?

분수가 정수가 되는 조건

(n² + 3)/(n + 1)이 정수가 되는 자연수 n을 찾아 봅시다. n² + 3 = (n + 1)(n − 1) + 4이므로, n + 1 | n² + 3은 n + 1 | 4와 같습니다.

n + 1은 2 이상인 4의 약수, 곧 2 또는 4이므로 n = 1, 3입니다.

이 방법은 '분자를 분모로 나누어 나머지를 상수로 만드는 것'입니다. 다항식의 나눗셈을 하고 나면, 분모가 그 상수의 약수여야 한다는 조건만 남습니다. 약수는 유한개이므로 후보를 모두 확인할 수 있습니다. 분자의 차수가 분모보다 높아도, 두 번 이상 나누면 같은 방식이 됩니다.

문제 6

(2n + 7)/(n + 1)이 정수가 되는 자연수 n은?

aⁿ − bⁿ과 aⁿ + bⁿ

aⁿ − bⁿ = (a − b)(aⁿ⁻¹ + aⁿ⁻²b + ⋯ + bⁿ⁻¹)이므로 a − b | aⁿ − bⁿ입니다.

n이 홀수이면 aⁿ + bⁿ = (a + b)(aⁿ⁻¹ − aⁿ⁻²b + ⋯ + bⁿ⁻¹)이므로 a + b | aⁿ + bⁿ입니다. b를 −b로 바꾸면 앞의 식에서 바로 나옵니다.

이 두 인수분해는 거듭제곱이 큰 수의 약수를 찾을 때 매우 유용합니다. 2¹⁰ − 1 = (2⁵)² − 1 = (2⁵ − 1)(2⁵ + 1) = 31 × 33처럼 지수를 쪼개서 쓸 수도 있습니다. n이 짝수일 때 aⁿ + bⁿ은 a + b로 나누어떨어지지 않을 수 있다는 점(예: 1² + 2² = 5는 3의 배수가 아님)에 주의하세요.

문제 8

n이 홀수이면 3ⁿ + 5ⁿ은 8의 배수입니다. 3³ + 5³을 8로 나눈 몫은?

정리

a | b, a | c이면 a | bx + cy입니다. 문자가 든 두 식의 공약수는 문자가 사라지는 일차결합으로 범위를 좁힙니다.

분수가 정수가 될 조건은 분자를 분모로 나누어 나머지를 상수로 만든 뒤, 분모가 그 상수의 약수인 경우를 모두 확인합니다.

a − b | aⁿ − bⁿ, 그리고 n이 홀수이면 a + b | aⁿ + bⁿ입니다. 나머지는 항상 0 이상 나누는 수 미만으로 쓰고, 음수의 나머지도 이 규칙을 따릅니다.
