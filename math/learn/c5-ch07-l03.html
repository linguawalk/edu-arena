신뢰구간

모표준편차 σ를 알 때, 크기 n인 표본의 평균 x̄로 모평균 m을 추정하는 신뢰도 95% 신뢰구간은

x̄ − 1.96σ/√n ≤ m ≤ x̄ + 1.96σ/√n, 신뢰도 99%는 1.96 대신 2.58을 씁니다.

왜 1.96일까요? X̄ ~ N(m, σ²/n)이고 표준정규분포에서 P(−1.96 ≤ Z ≤ 1.96) = 0.95입니다. 즉 X̄는 95%의 확률로 m ± 1.96σ/√n 안에 들어옵니다. 이를 m에 대해 뒤집으면 x̄ ± 1.96σ/√n 안에 m이 있다고 추정할 수 있습니다. 99%이면 P(|Z| ≤ 2.58) = 0.99에서 2.58을 씁니다.

문제 2

같은 경우 위 끝은?

신뢰구간의 길이

신뢰구간의 길이는 2 × 1.96 × σ/√n (95%)입니다. x̄와 관계없이 σ, n, 신뢰도로 정해집니다.

신뢰구간의 가운데는 표본평균 x̄이고, 양쪽으로 1.96σ/√n씩 펼쳐져 있습니다. 그래서 길이는 x̄와 관계없이 σ, n, 신뢰도만으로 정해집니다. 신뢰도를 높이면 더 넓게 펼쳐야 하므로 구간이 길어집니다.

예제

σ = 12인 모집단에서 크기 36인 표본의 평균이 80일 때 모평균의 신뢰도 95% 신뢰구간을 구하세요.

  1. σ/√n = 12/6 = 2
  2. 1.96 × 2 = 3.92
  3. 80 − 3.92 ≤ m ≤ 80 + 3.92
  4. 76.08 ≤ m ≤ 83.92

답: 76.08 ≤ m ≤ 83.92

문제 4

같은 경우 신뢰도 99% 신뢰구간의 길이는?

표본의 크기와 길이

길이는 1/√n에 비례합니다. n을 4배 하면 길이는 1/2배가 됩니다.

신뢰구간의 길이는 σ/√n에 비례하므로 표본의 크기가 커질수록 짧아져 추정이 정밀해집니다. 하지만 길이를 절반으로 줄이려면 표본을 4배, 1/3로 줄이려면 9배로 늘려야 합니다. 정밀도와 조사 비용 사이에서 균형을 찾는 것이 조사 설계의 핵심입니다.

예제

σ = 10, n = 25일 때와 n = 100일 때 신뢰도 95% 신뢰구간의 길이를 비교하세요.

  1. n = 25: 2 × 1.96 × 10/5 = 7.84
  2. n = 100: 2 × 1.96 × 10/10 = 3.92
  3. 표본을 4배로 늘리니 길이가 1/2
  4. 원리: 길이는 1/√n에 비례

답: 7.84, 3.92

문제 5

표본의 크기를 4배로 늘리면 신뢰구간의 길이는 몇 배가 될까요? (기약분수로)

문제 6

신뢰구간의 길이를 1/3로 줄이려면 표본의 크기를 몇 배로 해야 할까요?

필요한 표본의 크기

원하는 길이 이하가 되도록 2 × 1.96 × σ/√n ≤ (길이)를 풀어 n을 구합니다.

조사를 계획할 때는 '어느 정도 정밀하게 알고 싶은가'를 먼저 정한 뒤 필요한 표본의 크기를 구합니다. 길이 공식 2 × 1.96σ/√n ≤ (원하는 길이)를 √n에 대해 풀고 제곱합니다. n은 자연수이므로 올림합니다.

예제

σ = 20일 때 신뢰도 95% 신뢰구간의 길이를 4 이하로 하려면 표본의 크기는 최소 얼마일까요?

  1. 2 × 1.96 × 20/√n ≤ 4
  2. √n ≥ 19.6
  3. n ≥ 384.16
  4. 자연수이므로 최소 385

답: 385

문제 8

σ = 5일 때 신뢰도 95% 신뢰구간의 길이가 1.96이 되는 표본의 크기는?

신뢰도의 뜻

95% 신뢰구간이란, 같은 방법으로 신뢰구간을 여러 번 만들면 그중 약 95%가 모평균을 포함한다는 뜻입니다.

흔한 오해: '모평균이 이 구간 안에 있을 확률이 95%'가 아닙니다. 모평균은 정해진 값이라 구간 안에 있거나 없거나 둘 중 하나입니다. 95%는 '이 방법으로 구간을 만들면 100번 중 약 95번은 모평균을 포함한다'는 방법의 신뢰도입니다.
