몫과 합성함수의 미분

미적분 · 6. 여러 가지 함수의 미분 · 레벨1 · 약 15분 · 문제 16개

몫의 미분법

{f(x)/g(x)}′ = {f′(x)g(x) − f(x)g′(x)} / {g(x)}², 특히 {1/g(x)}′ = −g′(x)/{g(x)}²

몫의 미분법은 곱의 미분법에서 나옵니다. f/g = f × (1/g)로 보고, 1/g의 도함수 −g′/g²을 먼저 구한 뒤 곱의 미분법을 쓰면 (f′g − fg′)/g²이 됩니다. 분자의 순서(f′g 먼저)를 바꾸면 부호가 뒤집히므로 주의합니다.

예제

f(x) = (x² + 1)/(x − 1)일 때 f′(2)를 구하세요.

  1. f′ = {2x(x − 1) − (x² + 1) × 1}/(x − 1)²
  2. x = 2: 분자 4 × 1 − 5 = −1
  3. 분모 (2 − 1)² = 1
  4. f′(2) = −1

답: −1

합성함수의 미분법

y = f(g(x))이면 y′ = f′(g(x)) × g′(x). 겉함수를 미분하고 속함수의 미분을 곱합니다.

왜 속함수의 미분을 곱할까요? y = f(u), u = g(x)이면 x가 조금 변할 때 u는 g′(x)배로 변하고, u가 변할 때 y는 f′(u)배로 변합니다. 두 변화의 배율이 곱해지므로 dy/dx = (dy/du) × (du/dx)입니다. 톱니바퀴 두 개가 맞물려 도는 비율을 곱하는 것과 같습니다.

예제

f(x) = cos(3x² + 1)의 도함수를 구하세요.

  1. 겉함수 cos □, 속함수 □ = 3x² + 1
  2. 겉을 미분: −sin(3x² + 1)
  3. 속을 미분: 6x
  4. f′(x) = −6x sin(3x² + 1)

답: −6x sin(3x² + 1)

곱과 합성을 함께

여러 법칙이 섞이면 가장 바깥의 연산부터 하나씩 적용합니다.

복잡한 함수는 '마지막에 하는 연산'이 무엇인지 보고 그 법칙부터 씁니다. xeˣ는 x와 eˣ의 곱이므로 곱의 미분법, e^(x²)은 e^□에 x²을 넣은 합성이므로 합성함수의 미분법입니다. 한 단계씩 차례로 적용하면 되며, 각 단계를 따로 적어 두면 실수가 줄어듭니다.

예제

f(x) = x² e^(−x)일 때 f′(x) = 0이 되는 x를 구하세요.

  1. 곱의 미분: 2x e^(−x) + x² × (−e^(−x))
  2. = e^(−x)(2x − x²) = x(2 − x)e^(−x)
  3. e^(−x) > 0이므로 x(2 − x) = 0
  4. x = 0 또는 x = 2

답: x = 0, 2

실수 지수의 미분

모든 실수 r에 대해 (xʳ)′ = rxʳ⁻¹ (x > 0)입니다. √x = x^(1/2)

자연수 지수에서 배운 (xⁿ)′ = nxⁿ⁻¹이 모든 실수 지수로 확장됩니다. xʳ = e^(r ln x)로 바꿔 합성함수의 미분법을 쓰면 증명할 수 있습니다. 근호는 분수 지수로, 분수는 음수 지수로 바꾸면 이 공식 하나로 미분할 수 있습니다.

정리

몫은 '분모 제곱', 합성은 '속을 곱한다'를 기억하면 대부분의 함수를 미분할 수 있습니다.

지금까지의 미분법을 정리하면 합·차·상수배, 곱, 몫, 합성의 네 가지 규칙과 xʳ, eˣ, ln x, sin x, cos x의 기본 도함수만으로 거의 모든 함수를 미분할 수 있습니다. 합성함수는 겉에서 속으로 한 겹씩 벗겨 가며 도함수를 곱합니다.
