참과 거짓을 가릴 수 있는 문장

참인지 거짓인지 분명히 가릴 수 있는 문장을 명제라고 합니다. '7은 소수이다'는 참인 명제, '9는 소수이다'는 거짓인 명제입니다.

'수학은 재미있다'처럼 사람마다 판단이 다른 문장은 명제가 아닙니다.

올림피아드 문제는 대부분 '…임을 보여라'처럼 어떤 명제가 참이라는 것을 증명하게 합니다. 그래서 무엇을 보여야 하는지, 곧 명제가 정확히 무엇을 말하는지 읽어 내는 것이 첫걸음입니다. 이 챕터에서는 명제를 읽고, 거짓임을 보이고, 참임을 보이는 기본 방법을 차례로 익힙니다.

문제 1

'7은 소수이다'는 ＿＿＿인 명제입니다. (참 또는 거짓)

문제 2

'모든 소수는 홀수이다'가 거짓임을 보여 주는 소수는 ＿＿＿입니다.

가정과 결론

'p이면 q이다' 꼴의 명제에서 p를 가정, q를 결론이라고 합니다. 'x² = 4이면 x = 2이다'에서 가정은 x² = 4, 결론은 x = 2입니다.

이 명제가 참이려면 가정을 만족하는 모든 경우에 결론도 성립해야 합니다.

그래서 반례는 '가정은 만족하는데 결론은 만족하지 않는 예'입니다. 가정을 만족하지 않는 예를 들면 반례가 되지 않습니다. 예를 들어 x = 3은 x² = 4를 만족하지 않으므로 'x² = 4이면 x = 2이다'의 반례가 아닙니다.

문제 3

명제 'x² = 4이면 x = 2이다'의 반례가 되는 실수 x의 값은?

반례 하나면 충분하다

'모든 …에 대해 …이다'를 참이라고 보이려면 모든 경우를 다 다루는 증명이 필요합니다. 예를 몇 개 확인하는 것만으로는 부족합니다.

반대로 거짓이라고 보이는 데는 반례 하나면 충분합니다.

왜 예를 많이 확인해도 증명이 되지 않을까요? 식 n² + n + 41은 n = 1부터 39까지 넣으면 모두 소수가 나옵니다. 39번 연속으로 맞았으니 언제나 소수라고 믿고 싶어지지만, n = 40에서 처음으로 깨집니다. 올림피아드에서 '작은 수 몇 개로 확인했다'는 답안은 증명으로 인정받지 못합니다.

예제

모든 자연수 n에 대해 n² + n + 41은 소수인가요?

  1. n = 1이면 43, n = 2이면 47, n = 3이면 53으로 작은 n에서는 소수가 나옵니다.
  2. n = 40을 넣으면 1600 + 40 + 41 = 1681입니다.
  3. 1681 = 41 × 41이므로 소수가 아닙니다.
  4. n = 40이 반례이므로 명제는 거짓입니다.

답: 거짓 (반례 n = 40)

문제 4

명제 '모든 자연수 n에 대해 n² − n + 11은 소수이다'의 반례 중 가장 작은 n은?

문제 5

'n이 소수이면 2ⁿ − 1도 소수이다'는 거짓입니다. 반례가 되는 소수 n 중 가장 작은 것은? (힌트: 2047 = 23 × 89)

'모든'과 '어떤'의 부정

'모든 x에 대해 P이다'의 부정은 'P가 아닌 x가 적어도 하나 있다', 곧 '어떤 x에 대해 P가 아니다'입니다.

'어떤 x에 대해 P이다'의 부정은 '모든 x에 대해 P가 아니다'입니다.

부정을 정확히 쓰는 일은 반례와 귀류법의 출발점입니다. '모든'을 부정하면 '어떤'이 되므로 반례 하나만 찾으면 됩니다. 반대로 '어떤'을 부정하면 '모든'이 되므로, '그런 x는 없다'를 보이려면 모든 x를 다루는 증명이 필요합니다. 이 비대칭이 이 레슨의 핵심입니다.

문제 6

'모든 실수 x에 대해 x² ≥ 0이다'의 부정은 '＿＿＿ 실수 x에 대해 x² ＿＿＿ 0이다'입니다.

문제 7

'어떤 자연수 n은 n² = 2를 만족한다'의 부정은 '모든 자연수 n에 대해 n² ＿＿＿ 2이다'입니다.

정리

명제는 참·거짓을 가릴 수 있는 문장이고, 'p이면 q' 꼴에서 반례는 가정은 만족하고 결론은 만족하지 않는 예입니다.

'모든'으로 시작하는 명제는 반례 하나로 거짓이 되지만, 참임을 보이려면 모든 경우를 다루는 증명이 필요합니다.

'모든'의 부정은 '어떤', '어떤'의 부정은 '모든'입니다. 문제를 받으면 먼저 결론을 부정해 보고, 반례를 찾는 쪽이 쉬운지 증명하는 쪽이 쉬운지 판단하는 습관을 들이세요. 반례를 찾을 때는 0, 1, −1, 2처럼 작은 수와 경계값부터 넣어 봅니다.

반례 찾기 전략

명제 '실수 a, b에 대해 a > b이면 a² > b²이다'의 반례를 찾으세요.

  1. 가정 a > b는 만족하면서 결론 a² > b²는 깨지는 예를 찾습니다.
  2. 양수끼리는 성립하므로 음수를 넣어 봅니다.
  3. a = 1, b = −2이면 1 > −2이지만 a² = 1, b² = 4로 a² < b²입니다.
  4. 따라서 a = 1, b = −2가 반례이고, 명제는 거짓입니다.

답: a = 1, b = −2
