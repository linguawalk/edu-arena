제곱수가 되는 나머지

홀수 소수 p와 p로 나누어떨어지지 않는 a에 대해 x² ≡ a (mod p)가 해를 가지면 a를 mod p의 이차잉여, 해가 없으면 이차비잉여라 합니다.

mod 11에서 1², 2², …, 10²을 구하면 1, 4, 9, 5, 3, 3, 5, 9, 4, 1이므로 이차잉여는 {1, 3, 4, 5, 9}이고 나머지 {2, 6, 7, 8, 10}은 이차비잉여입니다.

x²과 (p − x)²이 같으므로 이차잉여는 정확히 (p − 1)/2개, 이차비잉여도 (p − 1)/2개입니다.

문제 2

x² ≡ a (mod p)가 해를 가지는 a를 mod p의 이차＿＿＿라 합니다.

르장드르 기호

르장드르 기호 (a/p)는 a가 이차잉여이면 1, 이차비잉여이면 −1, p | a이면 0입니다.

mod 11에서 (3/11) = 1, (2/11) = −1입니다. x² ≡ a (mod p)의 해의 개수는 1 + (a/p)입니다(이차잉여면 2개, 아니면 0개).

르장드르 기호는 곱셈적입니다: (ab/p) = (a/p)(b/p). 그래서 (6/13) = (2/13)(3/13)처럼 소수의 기호로 나누어 계산합니다.

예제

mod 13의 이차잉여를 모두 구하고 (10/13)을 구하세요.

  1. 1², 2², …, 6²을 13으로 나눈 나머지는 1, 4, 9, 3, 12, 10입니다.
  2. 그래서 이차잉여는 {1, 3, 4, 9, 10, 12}입니다.
  3. 10은 이 집합에 있습니다(6² = 36 ≡ 10).
  4. 따라서 (10/13) = 1입니다.

답: 1

문제 4

x² ≡ 5 (mod 11)의 해(0 ≤ x < 11) 가운데 작은 것은?

이차방정식의 합동

ax² + bx + c ≡ 0 (mod p) (p ∤ a, p 홀수)는 완전제곱식으로 바꾸어 (2ax + b)² ≡ b² − 4ac (mod p)가 됩니다. 그래서 판별식 D = b² − 4ac가 이차잉여(또는 0)일 때만 해가 있습니다.

x² − 3x + 1 ≡ 0 (mod 11): D = 9 − 4 = 5이고 5는 mod 11의 이차잉여이므로 해가 2개입니다(x = 5, 9).

x² + x + 1 ≡ 0 (mod 5): D = −3 ≡ 2이고 2는 mod 5의 이차잉여가 아니므로(1, 4만 이차잉여) 해가 없습니다.

정리

x² ≡ a (mod p)가 해를 가지면 a는 이차잉여이고, 홀수 소수 p에는 이차잉여와 이차비잉여가 각각 (p − 1)/2개씩 있습니다.

르장드르 기호 (a/p)는 1, −1, 0이며 곱셈적이고, x² ≡ a의 해는 1 + (a/p)개입니다.

이차 합동식 ax² + bx + c ≡ 0은 판별식 b² − 4ac가 이차잉여(또는 0)일 때만 해가 있습니다.
