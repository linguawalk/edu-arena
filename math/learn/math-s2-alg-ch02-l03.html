평균의 함숫값 ≤ 함숫값의 평균

함수 f가 구간에서 아래로 볼록(f'' ≥ 0)이면 젠센 부등식 f((x₁ + ⋯ + xₙ)/n) ≤ (f(x₁) + ⋯ + f(xₙ))/n이 성립합니다. 위로 볼록(f'' ≤ 0)이면 부등호가 반대입니다.

그래프로 보면, 아래로 볼록한 곡선 위 두 점을 이은 선분은 곡선보다 위에 있습니다. 선분의 가운데(함숫값의 평균)가 곡선의 가운데(평균의 함숫값)보다 높습니다.

등호는 x₁ = ⋯ = xₙ일 때(또는 f가 그 구간에서 일차함수일 때) 성립합니다.

문제 2

f''(x) ≥ 0인 구간에서 f는 아래로 ＿＿＿하다고 합니다.

자주 쓰는 볼록함수

x > 0에서 아래로 볼록: x², xᵖ (p ≥ 1), 1/x, eˣ, x ln x. 위로 볼록: √x, ln x, [0, π]에서 sin x.

1/x가 아래로 볼록하므로 양수 a + b + c = 3이면 (1/a + 1/b + 1/c)/3 ≥ 1/((a + b + c)/3) = 1, 곧 1/a + 1/b + 1/c ≥ 3입니다.

ln x가 위로 볼록하므로 (ln a + ln b + ln c)/3 ≤ ln((a + b + c)/3)이고, 이것이 바로 산술-기하 평균 부등식입니다.

예제

양수 a, b, c가 a + b + c = 1일 때 1/a + 1/b + 1/c의 최솟값을 구하세요.

  1. f(x) = 1/x는 x > 0에서 아래로 볼록입니다(f''(x) = 2/x³ > 0).
  2. 젠센: (1/a + 1/b + 1/c)/3 ≥ 1/((a + b + c)/3) = 1/(1/3) = 3입니다.
  3. 그래서 1/a + 1/b + 1/c ≥ 9입니다.
  4. a = b = c = 1/3이면 등호이므로 최솟값은 9입니다.

답: 9

문제 4

f(x) = √x는 x > 0에서 어떤가요? ① 아래로 볼록 ② 위로 볼록

삼각형의 각과 젠센

삼각형의 세 각 A, B, C는 A + B + C = π이고 각각 (0, π)에 있습니다. sin x는 [0, π]에서 위로 볼록이므로 (sin A + sin B + sin C)/3 ≤ sin(π/3) = √3/2입니다.

그래서 sin A + sin B + sin C ≤ 3√3/2이고, 등호는 정삼각형(A = B = C = π/3)일 때입니다.

젠센을 쓸 때는 변수들이 모두 함수가 볼록한 구간 안에 있는지 반드시 확인합니다.

문제 7

f(x) = x² − 4x가 아래로 볼록임을 보이려면 f''(x)를 계산합니다. f''(x)의 값은?

정리

젠센 부등식: f가 아래로 볼록(f'' ≥ 0)이면 f(평균) ≤ (함숫값의 평균), 위로 볼록이면 반대이며, 등호는 모든 변수가 같을 때입니다.

아래로 볼록: x², 1/x, eˣ, 위로 볼록: √x, ln x, [0, π]의 sin x. ln x에 젠센을 쓰면 산술-기하 평균 부등식이 됩니다.

변수가 모두 볼록한 구간 안에 있는지 확인하고, 합이 일정한 조건(a + b + c = k)에서 최솟값·최댓값을 구할 때 씁니다.
