먼저 등호를 추측하라

부등식 문제의 첫걸음은 등호가 언제 성립하는지 추측하는 것입니다. 대칭식이면 a = b = c를 먼저 넣어 보고, 그다음 경계(한 변수가 0이거나 두 변수가 같은 경우)를 확인합니다.

등호 경우를 알면 어떤 도구를 쓸지 정해집니다. 산술-기하 평균은 등호에서 비교하는 항들이 같아야 하므로, 그렇게 되도록 항을 나누거나 묶습니다.

등호가 a = b = c가 아니라 경계에서 나오면 SOS나 젠센 같은 '대칭 도구'만으로는 안 되고, 경우 나누기나 다른 방법이 필요합니다.

문제 1

양수 a, b, c에서 abc = 1일 때 (a + b)(b + c)(c + a)의 최솟값은?

문제 2

부등식을 풀 때 가장 먼저 할 일은 ＿＿＿이 성립하는 경우를 추측하는 것입니다.

코시-슈바르츠로 일차 조건 다루기

a + 2b + 3c = 14일 때 a² + b² + c²의 최솟값은 코시-슈바르츠 (1² + 2² + 3²)(a² + b² + c²) ≥ (a + 2b + 3c)²으로 구합니다. 14(a² + b² + c²) ≥ 196이므로 a² + b² + c² ≥ 14입니다.

등호는 a : b : c = 1 : 2 : 3, 곧 (a, b, c) = (1, 2, 3)일 때입니다.

일차 조건과 제곱의 합이 함께 나오면 코시-슈바르츠를 먼저 떠올리세요.

예제

a + 2b + 2c = 9일 때 a² + b² + c²의 최솟값을 구하세요.

  1. 코시-슈바르츠: (1 + 4 + 4)(a² + b² + c²) ≥ (a + 2b + 2c)²입니다.
  2. 9(a² + b² + c²) ≥ 81입니다.
  3. 그래서 a² + b² + c² ≥ 9입니다.
  4. 등호는 a : b : c = 1 : 2 : 2, 곧 (1, 2, 2)일 때이므로 최솟값은 9입니다.

답: 9

문제 4

양수 a, b, c가 a + b + c = 3일 때 abc의 최댓값은?

경계를 확인하라

음이 아닌 a, b, c가 a + b + c = 1일 때 ab + bc + ca의 최댓값은 a = b = c = 1/3에서 1/3입니다. 그런데 최솟값은 대칭점이 아니라 경계 (1, 0, 0)에서 0입니다.

이처럼 최댓값과 최솟값이 서로 다른 곳에서 나올 수 있으므로, 대칭점과 경계를 모두 확인합니다.

답안에서는 '하한(또는 상한)의 증명'과 '그 값을 이루는 예'를 함께 써야 최솟값(최댓값)을 증명한 것이 됩니다.

문제 7

양수 a, b, c가 ab + bc + ca = 3일 때 a + b + c의 최솟값은?

정리

부등식은 먼저 등호 경우를 추측합니다. 대칭식은 a = b = c를, 그다음 경계(한 변수가 0, 두 변수가 같음)를 확인합니다.

일차 조건과 제곱의 합 → 코시-슈바르츠, 합이 일정한 곱 → 산술-기하, 대칭 이차식 → SOS, 볼록함수의 합 → 젠센.

최댓값·최솟값은 서로 다른 곳(대칭점과 경계)에서 나올 수 있으며, 답안에는 부등식과 그 값을 이루는 예를 모두 씁니다.
