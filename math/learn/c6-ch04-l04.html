벡터의 내적

기하 · 4. 평면벡터 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

내적

두 벡터 a, b가 이루는 각이 θ일 때 a·b = |a||b|cos θ를 내적이라고 합니다. 결과는 벡터가 아니라 수입니다.

내적은 '한 벡터가 다른 벡터 방향으로 얼마나 함께 가는가'를 나타냅니다. |b|cos θ는 b를 a 방향으로 그림자처럼 내린 길이(정사영)이고, 여기에 |a|를 곱한 것이 내적입니다. 물리에서 힘이 한 일 = 힘 × 이동 거리 × cos θ가 바로 내적입니다. 결과는 방향이 없는 수입니다.

문제 1

|a| = 2, |b| = 3이고 이루는 각이 60°일 때 a·b는?

문제 2

두 벡터가 이루는 각이 90°일 때 a·b는?

성분으로 계산

a = (a₁, a₂), b = (b₁, b₂)이면 a·b = a₁b₁ + a₂b₂입니다. a·a = |a|²

왜 a₁b₁ + a₂b₂일까요? 코사인법칙으로 |a − b|² = |a|² + |b|² − 2|a||b|cos θ이고, 성분으로 쓰면 |a − b|² = (a₁ − b₁)² + (a₂ − b₂)²입니다. 두 식을 비교해 정리하면 |a||b|cos θ = a₁b₁ + a₂b₂가 나옵니다. a·a = |a|²은 자기 자신과의 각이 0°이기 때문입니다.

예제

a = (2, 1), b = (1, 3)이 이루는 각을 구하세요.

  1. a·b = 2 + 3 = 5
  2. |a| = √5, |b| = √10
  3. cos θ = 5/(√5 × √10) = 5/√50 = 1/√2
  4. θ = 45°

답: 45°

문제 5

수직과 각

영벡터가 아닌 두 벡터는 a·b = 0일 때 수직입니다. cos θ = a·b / (|a||b|)로 각을 구합니다.

cos 90° = 0이므로 수직인 두 벡터의 내적은 0입니다. 반대로 내적이 0이면 수직입니다. 두 직선이 수직인지 확인할 때 기울기의 곱 대신 방향벡터의 내적을 써도 됩니다. 내적의 부호로 각의 크기도 알 수 있습니다: 양수이면 예각, 음수이면 둔각입니다.

예제

a = (3, −2)에 수직인 단위벡터를 구하세요.

  1. (x, y)·(3, −2) = 3x − 2y = 0이면 수직: (2, 3) 방향
  2. |(2, 3)| = √13
  3. 단위벡터 ±(2/√13, 3/√13)
  4. 확인: 3 × 2 − 2 × 3 = 0

답: ±(2/√13, 3/√13)

크기의 제곱

|a + b|² = |a|² + 2a·b + |b|², |a − b|² = |a|² − 2a·b + |b|²

|a + b|² 공식은 (a + b)·(a + b)를 분배법칙으로 전개한 것입니다. 곱셈공식 (x + y)² = x² + 2xy + y²과 모양이 같아 기억하기 쉽습니다. 크기와 내적 중 두 가지를 알면 나머지를 구할 수 있습니다.

예제

|a| = 2, |b| = 3, |a + b| = √19일 때 a와 b가 이루는 각을 구하세요.

  1. |a + b|² = |a|² + 2a·b + |b|²: 19 = 4 + 2a·b + 9
  2. a·b = 3
  3. cos θ = 3/(2 × 3) = 1/2
  4. θ = 60°

답: 60°

도형에서의 내적

정다각형에서는 변의 길이와 사이각을 이용해 내적을 바로 구합니다.

도형에서 내적을 구할 때는 두 벡터의 시작점을 같게 놓고 사이각을 찾습니다. 정삼각형의 두 변이 이루는 각은 60°, 정사각형의 변과 대각선이 이루는 각은 45°입니다. 시작점이 다르면 평행이동해 맞춘 뒤 각을 읽습니다. 예를 들어 AB와 BC의 사이각은 ∠B가 아니라 그 보각입니다.
