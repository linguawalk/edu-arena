역·이·대우

수학의 기초 · 3. 명제와 증명 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

역, 이, 대우

명제 p → q에 대해 q → p를 역, ~p → ~q를 이, ~q → ~p를 대우라고 합니다.

네 명제의 관계를 한 그림으로 보면, 원래 명제와 대우가 대각선으로 짝을 이루고, 역과 이가 다른 대각선으로 짝을 이룹니다. 대각선끼리 참, 거짓이 같습니다.

문제 1

'p → q'의 역은 '＿＿＿ → ＿＿＿'

문제 2

'x = 2이면 x² = 4'의 역은 'x² = 4이면 x = ＿＿＿'

문제 3

위의 역 (참이면 1, 거짓이면 0)

명제와 대우

명제가 참이면 대우도 참이고, 명제가 거짓이면 대우도 거짓입니다.

P ⊂ Q이면 Qᶜ ⊂ Pᶜ이기 때문입니다.

벤 다이어그램으로 보면 P가 Q 안에 들어 있을 때, Q 밖의 영역(Qᶜ)은 당연히 P 밖(Pᶜ)에 들어 있습니다. 그래서 'q가 아니면 p도 아니다'가 항상 성립합니다.

예제

'x = 3이면 x² = 9'의 역, 이, 대우를 쓰고 참, 거짓을 판별하세요.

  1. 역: x² = 9이면 x = 3 → x = −3이 반례라 거짓
  2. 이: x ≠ 3이면 x² ≠ 9 → x = −3이 반례라 거짓
  3. 대우: x² ≠ 9이면 x ≠ 3 → 원래 명제가 참이므로 참

답: 역 거짓, 이 거짓, 대우 참

문제 4

'p → q'의 대우는 '~＿＿＿ → ~＿＿＿'

문제 5

'x가 짝수이면 x²은 짝수이다'의 대우 (참이면 1, 거짓이면 0)

문제 6

'a = 0이면 ab = 0'의 대우는 'ab ≠ 0이면 a ＿＿＿ 0'

역과 이

역과 이는 서로 대우 관계라 참, 거짓이 같습니다.

명제가 참이어도 역은 참일 수도, 거짓일 수도 있습니다.

역이 거짓인 예: 'x = 2이면 x² = 4'는 참이지만, 역 'x² = 4이면 x = 2'는 x = −2가 반례라 거짓입니다. 명제가 참이라고 역까지 참이라고 착각하는 실수가 흔합니다.

문제 7

명제가 참이면 그 대우는 반드시 참일까요? (그렇다 1, 아니다 0)

문제 8

명제가 참이면 그 역은 반드시 참일까요? (그렇다 1, 아니다 0)

문제 9

'x > 1이면 x > 0'의 역 (참이면 1, 거짓이면 0)

문제 10

'x > 1이면 x > 0'의 이 (참이면 1, 거짓이면 0)

삼단논법

p → q와 q → r이 참이면 p → r도 참입니다.

대우를 함께 쓰면 연결 고리를 찾기 쉬워집니다.

삼단논법은 포함 관계의 연결입니다. P ⊂ Q이고 Q ⊂ R이면 P ⊂ R입니다. 주어진 명제가 대우 꼴이면 먼저 대우로 바꿔 고리가 이어지게 맞춥니다.

예제

p → q와 ~r → ~q가 참일 때 p → r이 참인 이유를 설명하세요.

  1. ~r → ~q의 대우는 q → r이므로 참
  2. p → q와 q → r이 모두 참
  3. 삼단논법으로 p → r도 참

답: 대우를 이용해 고리를 이어 참

문제 11

p → q, q → r이 참이면 ＿＿＿ → r도 참

문제 12

p → q, ~r → ~q가 참이면 p → ＿＿＿도 참

문제 13

p → ~q, r → q가 참일 때 p → ~r (참이면 1, 거짓이면 0)

대우로 판단하기

원래 명제를 직접 판단하기 어려우면 대우로 바꿔 봅니다.

'~이 아니면'처럼 부정이 들어간 명제는 대우로 바꾸면 부정이 사라져 판단하기 쉬워지는 경우가 많습니다. 대우의 참, 거짓이 곧 원래 명제의 참, 거짓입니다.

예제

자연수 n에 대해 'n²이 3의 배수가 아니면 n은 3의 배수가 아니다'를 판별하세요.

  1. 대우: 'n이 3의 배수이면 n²은 3의 배수이다'
  2. n = 3k이면 n² = 9k² = 3(3k²)으로 3의 배수
  3. 대우가 참이므로 원래 명제도 참

답: 참
