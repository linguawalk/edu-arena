원과 직선의 위치 관계

함수와 그래프 · 2. 원과 도형의 이동 · 레벨1 · 약 15분 · 문제 16개

거리로 판단하기

원의 중심과 직선 사이의 거리를 d, 반지름을 r이라 합니다.

d < r이면 두 점에서 만나고, d = r이면 접하고, d > r이면 만나지 않습니다.

왜 거리로 판단할까요? 직선이 중심에서 반지름보다 가까이 지나면 원을 가로지르고, 정확히 반지름만큼 떨어지면 한 점에서 스치고, 더 멀면 원 밖을 지나기 때문입니다.

문제 2

원 x² + y² = 4와 직선 y = 1의 교점은 몇 개일까요?

판별식으로 판단하기

직선의 식을 원의 방정식에 대입해 얻은 이차방정식의 판별식으로도 판단할 수 있습니다.

직선을 원의 방정식에 대입하면 교점의 x좌표에 대한 이차방정식이 됩니다. 실근의 개수가 교점의 개수이므로 D > 0이면 두 점, D = 0이면 접함, D < 0이면 만나지 않습니다.

예제

원 x² + y² = 8과 직선 y = x + k가 접할 때 k를 구하세요.

  1. 중심 (0, 0)과 직선 x − y + k = 0 사이의 거리 = |k|/√2
  2. 접하려면 거리 = 반지름: |k|/√2 = 2√2
  3. |k| = 4, k = ±4

답: k = ±4

접선의 방정식

원 x² + y² = r² 위의 점 (x₁, y₁)에서의 접선은 x₁x + y₁y = r²입니다.

원 x² + y² = r²에 접하고 기울기가 m인 직선은 y = mx ± r√(m² + 1)입니다.

왜 x₁x + y₁y = r²일까요? 접선은 접점을 지나는 반지름에 수직입니다. 반지름의 방향이 (x₁, y₁)이므로 이에 수직이고 (x₁, y₁)을 지나는 직선을 구하면 이 식이 나옵니다.

문제 8

원 x² + y² = 5에 접하고 기울기가 2인 직선 중 y절편이 양수인 것의 y절편은?

현의 길이

중심과 현 사이의 거리가 d이면 현의 길이는 2√(r² − d²)입니다.

중심에서 현에 내린 수선은 현을 이등분합니다. 그래서 반지름 r, 거리 d, 현의 절반이 직각삼각형을 이루고, 피타고라스 정리로 현의 절반 √(r² − d²)을 구합니다.

예제

원 x² + y² = 10 위의 점 (3, 1)에서의 접선을 구하세요.

  1. x₁x + y₁y = r²에 넣습니다.
  2. 3x + y = 10
  3. 확인: 3² + 1² = 10이므로 (3, 1)은 원 위의 점

답: 3x + y = 10

접선의 길이와 거리의 최대·최소

원 밖의 점에서 그은 접선의 길이는 √(d² − r²)입니다. d는 점과 중심 사이의 거리입니다.

원 위의 점과 직선 사이 거리의 최댓값은 d + r, 최솟값은 d − r입니다.

접선의 길이도 직각삼각형으로 구합니다. 중심, 접점, 원 밖의 점이 접점에서 직각을 이루므로 (접선의 길이)² + r² = d²입니다.

예제

원 x² + y² = 25와 직선 3x + 4y = 15가 만나 생기는 현의 길이를 구하세요.

  1. 중심과 직선 사이의 거리 d = |−15|/√(9 + 16) = 3
  2. 현의 절반 = √(25 − 9) = 4
  3. 현의 길이 = 8

답: 8
