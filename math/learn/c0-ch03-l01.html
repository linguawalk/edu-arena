평형을 이룬 저울

저울의 왼쪽에는 무게를 모르는 상자와 3kg 추가, 오른쪽에는 8kg 추가 올려져 있고 저울은 평형입니다.

양쪽 무게가 같다는 사실만으로 상자의 무게를 알아낼 수 있습니다.

문제 1

상자의 무게를 x kg이라 하면 x + 3 = 8입니다. 상자는 몇 kg일까요?

등식, 방정식, 항등식

등호 =를 써서 두 식이 같음을 나타낸 식을 등식이라고 합니다.

x의 값에 따라 참이 되기도 하고 거짓이 되기도 하는 등식을 x에 대한 방정식이라 하고, 참이 되게 하는 x의 값을 해(또는 근)라고 합니다.

x에 어떤 값을 넣어도 항상 참인 등식은 항등식입니다. 예: 2(x + 1) = 2x + 2

예제

x가 0, 1, 2, 3 중 하나일 때 3x − 1 = 5의 해를 찾으세요.

  1. x = 0: 3 × 0 − 1 = −1 (거짓)
  2. x = 1: 3 − 1 = 2 (거짓)
  3. x = 2: 6 − 1 = 5 (참)
  4. x = 3: 9 − 1 = 8 (거짓)

답: x = 2

문제 6

등식 ax + 6 = 3(x + b)가 x에 대한 항등식일 때, a + b의 값은?

등식의 성질

a = b이면 양변에 같은 수를 더하거나 빼도, 같은 수를 곱해도 등식은 성립합니다.

a = b이면 양변을 0이 아닌 같은 수로 나누어도 등식은 성립합니다.

이 성질을 이용해 x만 남을 때까지 식을 바꾸는 것이 방정식 풀이입니다.

예제

x − 4 = 9를 등식의 성질로 푸세요.

  1. x만 남기려면 −4를 없애야 합니다.
  2. 양변에 4를 더합니다: x − 4 + 4 = 9 + 4
  3. x = 13

답: x = 13

방정식 x/3 + 2 = 6의 해는?

이항

등식의 한 변에 있는 항을 부호를 바꾸어 다른 변으로 옮기는 것을 이항이라고 합니다.

5x − 7 = 8에서 −7을 이항하면 5x = 8 + 7입니다. 양변에 7을 더한 것과 같습니다.

예제

4x + 3 = x + 12를 이항으로 푸세요.

  1. x항은 왼쪽, 상수항은 오른쪽으로 이항합니다 (부호가 바뀜).
  2. 4x − x = 12 − 3
  3. 3x = 9
  4. 양변을 3으로 나누면 x = 3

답: x = 3
