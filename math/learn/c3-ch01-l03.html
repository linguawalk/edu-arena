지수법칙

a > 0, b > 0이고 x, y가 실수일 때

aˣaʸ = aˣ⁺ʸ, aˣ ÷ aʸ = aˣ⁻ʸ, (aˣ)ʸ = aˣʸ, (ab)ˣ = aˣbˣ

지수법칙은 자연수 지수에서 '곱하는 횟수'로 이해한 규칙이 실수 지수에서도 그대로 성립하도록 지수를 넓혀 왔기 때문에 성립합니다. 다만 밑이 양수여야 한다는 조건이 붙습니다. 흔한 실수는 aˣ + aʸ = aˣ⁺ʸ처럼 덧셈에 적용하는 것인데, 지수법칙은 곱셈과 나눗셈에만 적용됩니다.

문제 1

2³ × 2⁻¹ = 2^＿＿＿

문제 2

(3^(1/2))⁴의 값은?

문제 3

5^(2/3) × 5^(1/3)의 값은?

계산 연습

밑이 다르면 같은 밑의 거듭제곱으로 바꾼 뒤 지수끼리 계산합니다.

밑이 서로 다른 수가 섞여 있으면 먼저 소인수(2, 3, 5 등)의 거듭제곱으로 바꿉니다. 8 = 2³, 27 = 3³, 9 = 3²처럼 바꾸면 같은 밑끼리 지수를 더하고 뺄 수 있습니다. 최종 답이 정수로 깔끔하게 나오는 경우가 많습니다.

예제

(4^(1/3) × 2^(1/3))³ ÷ 2⁻¹을 계산하세요.

  1. 4 = 2²이므로 4^(1/3) = 2^(2/3)
  2. 괄호 안: 2^(2/3) × 2^(1/3) = 2¹ = 2
  3. 2³ ÷ 2⁻¹ = 2^(3 − (−1)) = 2⁴
  4. = 16

답: 16

문제 7

4^(3/2) × 2⁻²의 값은?

밑을 같게 만들기

8ˣ = (2³)ˣ = 2³ˣ처럼 밑을 통일하면 지수끼리 비교할 수 있습니다.

밑을 통일하는 이유는 '밑이 같으면 지수도 같다'를 쓰기 위해서입니다. 지수함수 y = aˣ(a > 0, a ≠ 1)는 일대일함수이므로 aᵖ = aᵠ이면 p = q입니다. 4ˣ = 32는 2²ˣ = 2⁵이므로 2x = 5입니다.

예제

8^(x + 1) = 4^(2x)을 푸세요.

  1. 밑을 2로: 2^(3(x + 1)) = 2^(2 × 2x)
  2. 지수끼리 같게: 3x + 3 = 4x
  3. x = 3
  4. 확인: 8⁴ = 4096, 4⁶ = 4096

답: x = 3

문제 10

9ˣ = 27일 때 x의 값은? (기약분수로)

aˣ + a⁻ˣ 꼴의 값

(aˣ + a⁻ˣ)² = a²ˣ + 2 + a⁻²ˣ이므로 제곱해서 원하는 식을 만듭니다.

왜 제곱할까요? aˣ와 a⁻ˣ는 곱하면 1이 되는 짝입니다. 그래서 (aˣ + a⁻ˣ)²을 전개하면 가운데 항 2 × aˣ × a⁻ˣ = 2가 상수로 남고, 양 끝은 a²ˣ + a⁻²ˣ가 됩니다. x나 a의 값을 구하지 않고도 원하는 식의 값을 얻을 수 있습니다.

예제

aˣ − a⁻ˣ = 2일 때 a²ˣ + a⁻²ˣ의 값을 구하세요.

  1. 양변을 제곱: (aˣ − a⁻ˣ)² = a²ˣ − 2 + a⁻²ˣ = 4
  2. aˣ × a⁻ˣ = 1이므로 가운데 항은 −2
  3. a²ˣ + a⁻²ˣ = 4 + 2 = 6

답: 6

문제 13

2ˣ = 3일 때 8ˣ의 값은?

정리

지수에 문자가 있어도 지수법칙은 그대로 적용됩니다. 알고 있는 값의 거듭제곱으로 원하는 값을 만듭니다.

지수에 문자가 있으면 모르는 값을 알고 있는 값의 거듭제곱으로 나타냅니다. 2ˣ = 3이면 8ˣ = (2³)ˣ = (2ˣ)³ = 27처럼, 밑을 바꾸고 지수법칙 (aᵖ)ᵠ = (aᵠ)ᵖ을 이용해 주어진 값을 끌어냅니다.
