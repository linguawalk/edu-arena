함수의 그래프 그리기

미적분 · 7. 미분법의 활용 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

그래프를 그리는 순서

정의역 → f′로 증가·감소와 극값 → f″로 볼록과 변곡점 → 절편과 점근선 순서로 조사합니다.

그래프 그리기는 탐정 수사와 비슷합니다. 정의역으로 그릴 범위를 정하고, f′으로 오르내림과 극값의 위치를, f″으로 휘어진 방향을, 절편과 점근선으로 그래프가 지나가거나 다가가는 선을 알아냅니다. 이 정보를 모아 표로 정리하면 계산기 없이도 그래프의 모양을 그릴 수 있습니다.

문제 1

y = x³ − 3x의 극값은 모두 몇 개일까요?

문제 2

y = xeˣ가 극값을 갖는 x는?

점근선이 있는 그래프

y = x + 1/x은 x = 0이 점근선이고, x > 0에서 x = 1일 때 극솟값을 가집니다.

분수 꼴이 있으면 분모가 0이 되는 곳에 세로 점근선이 생깁니다. y = x + 1/x에서 x가 커지면 1/x → 0이라 그래프가 직선 y = x에 가까워지는데, 이런 비스듬한 점근선도 있습니다. 극값은 f′(x) = 1 − 1/x² = 0에서 찾습니다.

예제

y = x²e⁻ˣ의 그래프의 개형을 조사하세요.

  1. y′ = (2x − x²)e⁻ˣ = x(2 − x)e⁻ˣ: x = 0에서 극소 0, x = 2에서 극대 4/e²
  2. x → ∞이면 x²e⁻ˣ → 0 (지수가 더 빨리 커짐), 점근선 y = 0
  3. x → −∞이면 한없이 커짐
  4. 항상 y ≥ 0

답: x = 0 극소 0, x = 2 극대 4/e²

문제 4

y = x + 1/x의 그래프에서 y축과 평행한 점근선은 x = ?

방정식의 실근의 개수

f(x) = k의 실근의 개수는 y = f(x)의 그래프와 직선 y = k의 교점의 개수입니다.

방정식을 직접 풀지 않고 실근의 개수만 알고 싶을 때 그래프가 강력합니다. f(x) = k로 바꿔 놓으면, 직선 y = k를 위아래로 움직이면서 그래프와 몇 번 만나는지 셉니다. 극댓값과 극솟값이 개수가 바뀌는 경계가 됩니다.

예제

x³ − 3x² − 9x = k가 서로 다른 세 실근을 갖는 k의 범위를 구하세요.

  1. f(x) = x³ − 3x² − 9x, f′(x) = 3(x − 3)(x + 1)
  2. 극댓값 f(−1) = 5, 극솟값 f(3) = −27
  3. 직선 y = k가 세 점에서 만나려면 극솟값과 극댓값 사이
  4. −27 < k < 5

답: −27 < k < 5

문제 6

x³ − 3x − 2 = 0의 서로 다른 실근은 몇 개일까요?

부등식의 증명

f(x) ≥ 0을 보이려면 f(x)의 최솟값이 0 이상임을 보입니다.

부등식 f(x) ≥ g(x)를 보이려면 h(x) = f(x) − g(x)로 놓고 h의 최솟값이 0 이상임을 보이면 됩니다. 최솟값은 미분으로 극값을 찾아 구합니다. eˣ ≥ x + 1은 y = eˣ의 그래프가 x = 0에서의 접선 y = x + 1보다 항상 위에 있다는 뜻입니다.

예제

x > 0에서 ln x ≤ x − 1임을 보이세요.

  1. h(x) = x − 1 − ln x로 놓습니다.
  2. h′(x) = 1 − 1/x = 0에서 x = 1, x < 1에서 h′ < 0, x > 1에서 h′ > 0
  3. 최솟값 h(1) = 0
  4. h(x) ≥ 0이므로 ln x ≤ x − 1 (등호는 x = 1)

답: 최솟값이 0이므로 성립
