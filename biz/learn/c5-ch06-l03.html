재공품과 제품의 흐름

회계 실무 · 6. 원가의 흐름과 제조원가명세서 · 레벨1 · 약 15분 · 문제 15개

이 레슨 풀어 보기연습 문제에세이 과제

이번 달 완성품의 원가

공장에는 지난달부터 만들던 물건(월초 재공품)이 있었고, 이번 달 원가를 더 투입했으며, 일부는 완성되고 일부는 아직 만드는 중(월말 재공품)입니다.

이번 달 완성된 제품의 원가를 당기제품제조원가라고 합니다. 재공품 계정의 흐름으로 계산합니다.

문제 1

한 기간 동안 완성된 제품의 원가를 당기제품＿＿＿원가라고 합니다.

당기총제조원가와 당기제품제조원가

당기총제조원가 = 직접재료비 + 직접노무비 + 제조간접비(배부액)입니다. 이번 달에 새로 투입한 제조 원가의 합계입니다.

당기제품제조원가 = 월초(기초) 재공품 + 당기총제조원가 − 월말(기말) 재공품입니다. 이번 달 완성된 제품의 원가입니다.

두 금액은 재공품 재고가 변하지 않을 때만 같습니다.

문제 2

당기제품제조원가 = 기초 재공품 + 당기＿＿＿제조원가 − 기말 재공품

예제

직접재료비 4,000,000, 직접노무비 3,000,000, 제조간접비 2,000,000원, 기초 재공품 1,000,000원, 기말 재공품 1,500,000원입니다. 두 원가는?

  1. 당기총제조원가 = 4,000,000 + 3,000,000 + 2,000,000 = 9,000,000원.
  2. 당기제품제조원가 = 1,000,000 + 9,000,000 − 1,500,000.
  3. = 8,500,000원.

답: 총제조원가 9,000,000원, 제품제조원가 8,500,000원

문제 3

직접재료비 2,500,000원, 직접노무비 1,800,000원, 제조간접비 1,200,000원이면 당기총제조원가는 몇 원일까요?

문제 4

기초 재공품 700,000원, 당기총제조원가 5,500,000원, 기말 재공품 900,000원이면 당기제품제조원가는 몇 원일까요?

제품 계정과 매출원가

완성된 제품은 제품 계정(재고자산)으로 옮겨지고, 팔린 만큼 제품매출원가가 됩니다.

제품매출원가 = 기초 제품 + 당기제품제조원가 − 기말 제품입니다. 상기업의 '기초 상품 + 당기 매입 − 기말 상품'에서 당기 매입 자리에 당기제품제조원가가 들어간 것입니다.

판매 분개: 매출은 (차) 외상매출금 / (대) 제품매출, 부가세예수금, 원가는 (차) 제품매출원가 / (대) 제품입니다(또는 결산 때 한 번에).

문제 5

제품매출원가 = 기초 제품 + 당기제품제조원가 − 기말 ＿＿＿

예제

기초 제품 2,000,000원, 당기제품제조원가 8,500,000원, 기말 제품 1,800,000원입니다. 제품매출원가와 분개는?

  1. 제품매출원가 = 2,000,000 + 8,500,000 − 1,800,000 = 8,700,000원.
  2. (차) 제품매출원가 8,700,000 / (대) 제품 8,700,000.
  3. 제품 계정 잔액은 기말 제품 1,800,000원이 됩니다.

답: 8,700,000원

문제 6

기초 제품 1,500,000원, 당기제품제조원가 6,000,000원, 기말 제품 1,000,000원이면 제품매출원가는 몇 원일까요?

문제 7

이번 달 팔린 제품의 원가 6,500,000원을 매출원가로 옮깁니다. 분개하세요.

거꾸로 구하기

재공품과 제품 계정의 관계식을 이용하면 빠진 금액을 거꾸로 구할 수 있습니다.

예: 제품매출원가 9,000,000원, 기초 제품 1,000,000원, 기말 제품 1,500,000원 → 당기제품제조원가 = 9,000,000 − 1,000,000 + 1,500,000 = 9,500,000원.

이어서 기초·기말 재공품을 알면 당기총제조원가도 구할 수 있습니다. 원가 흐름 문제는 '계정의 들어온 쪽 = 나간 쪽 + 남은 것'으로 풉니다.

예제

제품매출원가 7,000,000원, 기초 제품 800,000원, 기말 제품 1,000,000원, 기초 재공품 500,000원, 기말 재공품 600,000원입니다. 당기총제조원가는?

  1. 당기제품제조원가 = 7,000,000 − 800,000 + 1,000,000 = 7,200,000원.
  2. 당기총제조원가 = 7,200,000 − 500,000 + 600,000.
  3. = 7,300,000원.

답: 7,300,000원

문제 8

제품매출원가 5,000,000원, 기초 제품 700,000원, 기말 제품 900,000원이면 당기제품제조원가는 몇 원일까요?

문제 9

원가가 흐르는 계정을 순서대로 배열하세요.

정리: 재공품과 제품의 흐름

당기총제조원가 = 직접재료비 + 직접노무비 + 제조간접비, 당기제품제조원가 = 기초 재공품 + 당기총제조원가 − 기말 재공품입니다.

제품매출원가 = 기초 제품 + 당기제품제조원가 − 기말 제품이며, 분개는 완성 (차) 제품 / (대) 재공품, 판매 (차) 제품매출원가 / (대) 제품입니다.

문제 10

직접재료비 3,000,000, 직접노무비 2,000,000, 제조간접비 1,500,000, 기초 재공품 800,000, 기말 재공품 1,300,000원이면 당기제품제조원가는 몇 원일까요?

문제 11

기초 재공품 1,000,000원, 당기총제조원가 7,000,000원, 기말 재공품 1,200,000원입니다. 완성품 원가를 제품으로 옮기는 분개를 입력하세요.

문제 12

기초 제품 1,200,000원, 당기제품제조원가 9,000,000원, 기말 제품 2,000,000원, 제품매출 12,000,000원이면 매출총이익은 몇 원일까요?

문제 13

당기제품제조원가 8,000,000원, 기초 재공품 600,000원, 기말 재공품 400,000원, 직접재료비 3,500,000원, 직접노무비 2,700,000원이면 제조간접비는 몇 원일까요?

문제 14

당기총제조원가와 당기제품제조원가가 다를 수 있는 이유를 설명해 보세요.

문제 15

기초 제품 500,000원, 당기제품제조원가 4,000,000원, 기말 제품 700,000원입니다. 결산 때 제품매출원가 분개를 입력하세요.

문제의 정답과 해설, 힌트는 레슨을 풀면서 확인할 수 있습니다.
