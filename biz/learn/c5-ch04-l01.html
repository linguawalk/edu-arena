이연과 발생 실무

회계 실무 · 4. 결산 실무 · 레벨1 · 약 15분 · 문제 15개

이 레슨 풀어 보기연습 문제에세이 과제

회사마다 처리 방법이 다르다

A 회사는 1년치 보험료를 낼 때 '보험료(비용)'로, B 회사는 '선급비용(자산)'으로 기록했습니다. 결산 때 두 회사의 수정 분개는 서로 다릅니다.

처음에 어떻게 기록했는지(비용 처리법 또는 자산 처리법)에 따라 결산 정리 분개가 달라집니다. 결과는 같아야 합니다.

문제 1

선급 비용을 지급할 때 자산(선급비용)으로 기록하는 방법을 ＿＿＿ 처리법이라고 합니다.

비용의 이연: 두 가지 방법

비용 처리법: 지급 때 (차) 보험료 / (대) 현금 → 결산 때 미경과분을 (차) 선급비용 / (대) 보험료.

자산 처리법: 지급 때 (차) 선급비용 / (대) 현금 → 결산 때 경과분을 (차) 보험료 / (대) 선급비용.

어느 방법이든 결산 후 보험료(비용) = 경과분, 선급비용(자산) = 미경과분이 됩니다. 결산 분개 금액만 다릅니다(미경과분 vs 경과분).

문제 2

자산 처리법으로 선급 보험료를 기록했다면 결산 때는 ＿＿＿분을 보험료로 옮깁니다.

예제

10월 1일 1년치 보험료 1,200,000원을 선급비용(자산)으로 기록했습니다. 12월 31일 결산 분개는?

  1. 경과 기간 = 10~12월, 3개월.
  2. 경과분 = 1,200,000 × 3/12 = 300,000원을 비용으로 옮깁니다.
  3. (차) 보험료 300,000 / (대) 선급비용 300,000.

답: (차) 보험료 300,000 (대) 선급비용 300,000

문제 3

7월 1일 1년치 임차료 2,400,000원을 지급하며 선급비용으로 기록했습니다. 12월 31일 결산 분개를 입력하세요.

문제 4

3월 1일 1년치 보험료 600,000원을 지급하며 보험료(비용)로 기록했습니다. 12월 31일 결산 분개를 입력하세요.

수익의 이연: 두 가지 방법

수익 처리법: 받을 때 (차) 현금 / (대) 임대료 → 결산 때 미경과분을 (차) 임대료 / (대) 선수수익.

부채 처리법: 받을 때 (차) 현금 / (대) 선수수익 → 결산 때 경과분을 (차) 선수수익 / (대) 임대료.

결산 후 임대료(수익) = 경과분, 선수수익(부채) = 미경과분이 되는 것은 같습니다.

문제 5

임대료를 받을 때 선수수익(부채)으로 기록했다면 결산 때는 경과분을 ＿＿＿로 옮깁니다.

문제 6

11월 1일 6개월분 임대료 1,800,000원을 받으며 선수수익으로 기록했습니다. 12월 31일 결산 분개를 입력하세요.

문제 7

4월 1일에 1년치 이자 360,000원을 미리 받아 이자수익으로 기록했습니다. 12월 31일 결산 후 선수수익 잔액은 몇 원일까요?

발생과 전산회계의 결산

미지급비용과 미수수익(발생)은 처음 기록이 없으므로 처리법이 하나뿐입니다: (차) 비용 / (대) 미지급비용, (차) 미수수익 / (대) 수익.

전산회계 프로그램에서는 이연·발생 같은 정리 사항을 일반전표에 12월 31일자로 직접 입력합니다(수동 결산). 감가상각비, 대손충당금, 퇴직급여, 매출원가 같은 항목은 결산자료입력 메뉴에 금액을 넣으면 분개가 자동으로 만들어집니다(자동 결산).

결산 정리 후에는 합계잔액시산표와 재무제표를 다시 확인합니다.

예제

12월 31일 결산 정리 사항: ① 12월분 이자 미지급 50,000원 ② 정기예금 이자 미수 80,000원. 분개는?

  1. ① (차) 이자비용 50,000 / (대) 미지급비용 50,000.
  2. ② (차) 미수수익 80,000 / (대) 이자수익 80,000.
  3. 둘 다 일반전표에 12월 31일자로 입력합니다(수동 결산).

답: 미지급비용 50,000원, 미수수익 80,000원

문제 8

다음 결산 항목을 '수동 결산(일반전표 직접 입력)', '자동 결산(결산자료입력)' 순서로 배열하세요.

문제 9

결산일 현재 12월분 수도 요금 75,000원을 아직 내지 않았습니다. 결산 분개를 입력하세요.

정리: 이연과 발생 실무

비용의 이연: 비용 처리법이면 미경과분 → 선급비용, 자산 처리법이면 경과분 → 비용. 수익의 이연: 수익 처리법이면 미경과분 → 선수수익, 부채 처리법이면 경과분 → 수익.

발생은 (차) 비용 / (대) 미지급비용, (차) 미수수익 / (대) 수익입니다. 전산회계에서 이연·발생은 수동 결산, 감가상각·대손·퇴직급여·매출원가는 결산자료입력(자동 결산)으로 처리합니다.

예제

9월 1일 1년치 보험료 2,400,000원을 지급했습니다. 비용 처리법과 자산 처리법의 결산 분개를 각각 쓰세요.

  1. 경과 4개월(800,000원), 미경과 8개월(1,600,000원).
  2. 비용 처리법: (차) 선급비용 1,600,000 / (대) 보험료 1,600,000.
  3. 자산 처리법: (차) 보험료 800,000 / (대) 선급비용 800,000. 결산 후 두 방법 모두 보험료 800,000원, 선급비용 1,600,000원.

답: 결과는 같음

문제 11

10월 1일 1년분 임대료 4,800,000원을 받아 임대료(수익)로 기록했습니다. 12월 31일 결산 분개를 입력하세요.

문제 12

문제 13

문제 14

선급 보험료를 비용 처리법과 자산 처리법 중 어느 방법으로 기록해도 결산 후 결과가 같아야 하는 이유를 설명해 보세요.

문제 15

11월 1일 3개월분 임대료 900,000원을 받아 선수수익(부채)으로 기록했습니다. 12월 31일 결산 분개를 입력하세요.
