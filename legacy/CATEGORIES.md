# edu-arena 카테고리 트리 (개정 — 학력 수준 기반 12개 과정)

지역 구분을 없애고 과목 기준으로 재편. 언어는 lingua-arena, 프로그래밍은 code-arena에서 다루므로 edu-arena는 그 외 교양 과목만 포함.

## 1. 인문사회 (humanities_social) — 6개 과정

| slug | 이름 |
|---|---|
| history | 역사 |
| geography | 지리 |
| society_general | 일반사회 |
| politics_law | 정치와 법 |
| economics | 경제 |
| culture | 문화 |

## 2. STEM (stem) — 6개 과정

| slug | 이름 |
|---|---|
| mathematics | 수학 |
| physics | 물리 |
| chemistry | 화학 |
| biology | 생물 |
| earth_science | 지구과학 |
| engineering | 공학 |

→ **총 12개 과정** (인문사회 6 + STEM 6)

## 3. 레벨 정의 (전 과정 공통, 3단계)

| 레벨 | 기준 |
|---|---|
| 1단계 | 고등학교 졸업 수준 |
| 2단계 | 대학 1년 수료 수준 |
| 3단계 | 대학 2년 수료 수준 |

- 향후 추가되는 모든 과정도 동일하게 3단계 기준 적용
- 언어(lingua-arena), 프로그래밍(code-arena)은 제외
- 신청자가 많은 과목에 한해 추가 과정 개설 (수요 기반 확장)

## 4. 과정당 콘텐츠 규모

| 항목 | 기준 |
|---|---|
| 레벨당 문항 수 | 500문항 |
| 설명 방식 | 별도 학습자료 없이, 문항별 `explanation`을 충실한 해설(200~400자)로 작성 |
| 테스트 방식 | 500문항 풀에서 50문항 무작위 추출 |

- 별도 학습자료(요약 해설 문서)는 제작하지 않음 — 문항과 해설이 분리되지 않아 제작 부담이 줄고, 학습 경험도 "풀면서 배운다"로 통합됨
- 인증/측정용 문항은 별도 제작 없이 학습 문항 풀에서 추출

## 5. 초기 제작 범위

- **1차**: 12개 과정 모두 1단계만 제작
  - 문항: 500 × 12 = **6,000문항** (문항별 충실한 해설 포함)
- 2단계·3단계 확장은 참가자 반응(수요)을 보고 결정
- 신규 과목 개설도 동일하게 수요 기반으로 결정
