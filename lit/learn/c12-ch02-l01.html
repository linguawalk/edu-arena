보통체 부정형

정중체의 ません에 해당하는 보통체 부정형은 어미가 ない로 끝납니다. 食べる → 食べない(먹지 않는다), 見る → 見ない, する → しない, 来る → こない입니다. 반말이나 문장 속에서 쓰이는 기본 형태입니다.

2그룹은 る를 떼고 ない를 붙입니다. 3그룹은 する → しない, 来る → こない로 불규칙하게 바뀝니다. 1그룹은 어미를 あ단으로 바꾸고 ない를 붙입니다. 書く → 書かない, 飲む → 飲まない, 話す → 話さない입니다.

문제 1

2그룹 동사 食べる의 부정형은 たべ＿＿＿입니다.

1그룹: 어미를 あ단으로

1그룹은 어미를 あ단으로 바꾸고 ない를 붙입니다. く → か(書かない), ぐ → が(泳がない), す → さ(話さない), つ → た(待たない), む → ま(飲まない), ぶ → ば(遊ばない), ぬ → な(死なない), る → ら(帰らない)입니다.

어미 う는 あ가 아니라 わ로 바뀝니다. 買う → 買わない, 会う → 会わない, 言う → 言わない입니다. あ가 아니라 わ가 되는 이유는 う단 중에 あ행의 あ가 단독으로 오지 않기 때문입니다.

あ단 + ない라는 규칙에서 う만 例外로 わ가 됩니다.

문제 2

'쓰지 않는다' 書く의 부정형은 か＿＿＿입니다.

문제 3

'사지 않는다' 買う의 부정형은 かわ＿＿＿입니다.

ある와 いる의 부정

ある(있다)의 부정은 ない입니다. ある → ある가 아닌 ない로 바뀌는 불규칙 동사입니다. 本が ない(책이 없다), お金が ない(돈이 없다). いる(있다, 2그룹)는 いない로 규칙적입니다. 人が いない(사람이 없다).

정중체에서는 あります → ありません, います → いません입니다. 보통체의 ない는 형용사처럼 활용하며, ない → なかった(없었다)가 됩니다. 이 활용은 레슨 3에서 확인합니다.

ある는 あらない라고 하지 않고 반드시 ない를 씁니다.

문제 4

ある의 부정형은 규칙을 따르지 않고 ＿＿＿입니다.

문제 5

いる의 부정형은 い＿＿＿입니다.

~ないでください

부정형에 でください를 붙이면 '~하지 말아 주세요'라는 금지 요청이 됩니다. 食べないでください(먹지 말아 주세요), 行かないでください(가지 말아 주세요), 忘れないでください(잊지 말아 주세요)입니다.

~てはいけません보다 부드럽게 부탁하는 표현입니다. ここで 写真を 撮らないでください(여기서 사진을 찍지 말아 주세요), 心配しないでください(걱정하지 마세요)처럼 씁니다.

교실이나 공공장소 안내 방송에서 자주 듣는 표현입니다.

문제 6

'가지 말아 주세요'는 いかない＿＿＿ください입니다.

문제 7

'걱정하지 마세요'는 しんぱいしない＿＿＿ください입니다.

정리

2그룹: る → ない. 3그룹: しない, こない. 1그룹: 어미 → あ단 + ない (う → わ).

ある → ない(불규칙). 부정형 + でください(~하지 말아 주세요).

문제 8

1그룹 동사 중 어미가 う인 동사는 부정형에서 ＿＿＿로 바뀝니다.

예제

'飲む'의 부정형을 만들어 보세요.

  1. 飲む는 1그룹이며 어미는 む입니다.
  2. 어미 む를 ま로 바꿉니다.
  3. 뒤에 ない를 붙여 のまない가 됩니다.

답: のまない

예제

'来る'의 부정형을 말해 보세요.

  1. 来る는 3그룹이며 불규칙입니다.
  2. 来る의 부정은 こない로 바뀝니다.
  3. く가 こ로 바뀝니다.

답: こない

예제

'여기서 사진을 찍지 말아 주세요'를 일본어로 써 보세요.

  1. '찍다'는 とる, 어미 る를 ら로 바꿉니다.
  2. とらないでください로 부탁합니다.
  3. 합치면 ここで しゃしんを とらないでください입니다.

답: ここで しゃしんを とらないでください
