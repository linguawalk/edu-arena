보통체 과거형

보통체 과거형은 연결형의 て를 た로, で를 だ로 바꾸면 됩니다. 食べて → 食べた(먹었다), 見て → 見た(봤다), 書いて → 書いた(썼다), 飲んで → 飲んだ(마셨다), して → した, きて → きた입니다.

정중체의 ました와 같은 뜻의 보통체입니다. 食べました ≒ 食べた, 行きました ≒ 行った(갔다)입니다. 친구와의 대화나 일기에서 자주 씁니다.

문제 1

연결형 食べて의 て를 바꾸면 과거 보통체 食べ＿＿＿가 됩니다.

음편과 과거형

1그룹은 연결형의 음편이 그대로 이어집니다. 買う → 買った, 待つ → 待った, 帰る → 帰った(っ 계열), 読む → 読んだ, 遊ぶ → 遊んだ(ん 계열), 書く → 書いた, 泳ぐ → 泳いだ(い 계열), 話す → 話した입니다.

예외 行く → 行った도 연결형 行って의 규칙을 따릅니다. 3그룹은 する → した, 来る → きた입니다. 따라서 연결형을 외워 두면 과거형도 쉽게 만들 수 있습니다.

て형과 た형은 한 쌍으로 기억하면 학습 효율이 높습니다.

문제 2

飲む의 과거 보통체는 の＿＿＿입니다.

문제 3

行く의 과거 보통체는 い＿＿＿입니다.

명사·형용사의 과거

명사와 な형용사의 보통체 과거는 だった입니다. 学生だ → 学生だった(학생이었다), 静かだ → 静かだった(조용했다)입니다. い형용사는 い를 かった로 바꿉니다. 高い → 高かった, 楽しい → 楽しかった입니다.

いい는 불규칙해서 よかった가 됩니다. 정중체는 でした, かったです이고 보통체는 だった, かった입니다. 문장 끝의 です를 빼면 보통체가 됩니다.

일본어의 정중체와 보통체는 같은 구조에서 끝부분만 다릅니다.

문제 4

い형용사 高い의 과거 보통체는 たか＿＿＿입니다.

문제 5

명사 学生의 과거 보통체는 がくせい＿＿＿입니다.

부정 과거와 일기

부정 과거 보통체는 ない를 なかった로 바꿉니다. 食べない → 食べなかった(먹지 않았다), 行かない → 行かなかった(가지 않았다)입니다. 명사의 부정 과거는 ではなかった입니다.

일기는 보통체로 씁니다. 今日は 朝 七時に 起きた。学校へ 行った。友だちと 昼ごはんを 食べた。とても 楽しかった。(오늘은 아침 7시에 일어났다. 학교에 갔다. 친구와 점심을 먹었다. 아주 즐거웠다.)

일기에서는 문장 끝에 です·ます를 쓰지 않고 보통체로 끝맺는 것이 일반적입니다.

문제 6

'먹지 않았다'는 たべ＿＿＿입니다.

문제 7

일기에서는 문장 끝을 ＿＿＿로 끝맺는 것이 일반적입니다.

정리

연결형 て → た, で → だ. 食べた 飲んだ 行った 書いた 泳いだ 話した した きた.

명사·な형용사 だった, い형용사 かった, 부정 なかった. 일기는 보통체.

문제 8

동사의 과거 보통체는 연결형의 て를 ＿＿＿로 바꿔 만듭니다.

예제

'待つ'의 과거 보통체를 만들어 보세요.

  1. 待つ의 연결형은 まって입니다.
  2. て를 た로 바꿉니다.
  3. 따라서 まった입니다.

답: まった

예제

'読む'의 과거 보통체를 만들어 보세요.

  1. 読む의 연결형은 よんで입니다.
  2. で를 だ로 바꿉니다.
  3. 따라서 よんだ입니다.

답: よんだ

예제

'오늘은 학교에 갔다. 아주 즐거웠다.'를 일본어 보통체로 써 보세요.

  1. '가다'의 과거 보통체는 いった입니다.
  2. '즐겁다'의 과거는 たのしかった입니다.
  3. 합치면 きょうは がっこうへ いった。とても たのしかった입니다.

답: きょうは がっこうへ いった。とても たのしかった
