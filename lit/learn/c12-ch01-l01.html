동사 연결형 만들기

일본어Ⅱ · 1. 동사 연결형 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

연결형이란

일본어 동사에는 문장을 잇거나 요청·진행을 나타낼 때 쓰는 활용형이 있습니다. 어미가 「て」 또는 「で」로 끝나므로 보통 '연결형'이라고 부릅니다. 食べる → 食べて, 見る → 見て, する → して, 来る → きて처럼 만듭니다.

2그룹 동사는 る를 떼고 て를 붙이면 됩니다. 食べる → 食べて, 見る → 見て, 起きる → 起きて입니다. 3그룹은 する → して, 来る → きて로 불규칙하게 바뀝니다. 1그룹은 어미에 따라 음이 바뀌므로 규칙을 따로 외워야 합니다.

문제 1

2그룹 동사 食べる의 연결형은 たべ＿＿＿입니다.

1그룹 동사의 음편

1그룹 동사는 어미에 따라 바뀝니다. 어미가 う·つ·る이면 って(買う → 買って, 待つ → 待って, 帰る → 帰って), 어미가 む·ぶ·ぬ이면 んで(飲む → 飲んで, 遊ぶ → 遊んで, 死ぬ → 死んで)가 됩니다.

어미가 く이면 いて(書く → 書いて), ぐ이면 いで(泳ぐ → 泳いで), す이면 して(話す → 話して)가 됩니다. 단 行く는 예외로 行って가 됩니다. 이런 소리 변화를 음편이라고 합니다.

받침 소리가 들어가는 것(っ, ん)과 い로 바뀌는 것, し가 들어가는 것으로 세 부류로 기억합니다.

문제 2

買う의 연결형은 かっ＿＿＿입니다.

문제 3

飲む의 연결형은 の＿＿＿입니다.

く·ぐ·す와 예외

書く → 書いて, 聞く → 聞いて, 泳ぐ → 泳いで(で가 됨), 話す → 話して, 貸す → 貸して입니다. 어미 ぐ는 で가 붙는다는 점에 주의합니다. 行く는 예외로 行って가 됩니다.

3그룹은 する → して, 勉強する → 勉強して, 来る → きて입니다. 이를 표로 정리하면 う·つ·る → って, む·ぶ·ぬ → んで, く → いて, ぐ → いで, す → して, 行く → 行って입니다.

예외 行く를 빼면 1그룹 규칙은 8가지 어미로 정리됩니다.

문제 4

書く의 연결형은 か＿＿＿입니다.

문제 5

行く의 연결형은 규칙과 달리 い＿＿＿입니다.

연습으로 굳히기

話す(はなす) → 話して, 待つ(まつ) → 待って, 読む(よむ) → 読んで, 遊ぶ(あそぶ) → 遊んで, 泳ぐ(およぐ) → 泳いで, 買う(かう) → 買って, 見る(みる) → 見て, 来る(くる) → きて입니다.

헷갈리면 ます형의 어간을 떠올려 봅니다. 읽다는 よみます이므로 よんで가 됩니다. 연결형은 외우는 데 시간이 걸리지만 가장 자주 쓰므로 반복이 필수입니다.

활용표를 만들어 두고 매일 하나씩 소리 내어 읽는 것이 효과적입니다.

문제 6

話す의 연결형은 はな＿＿＿입니다.

문제 7

泳ぐ의 연결형은 およ＿＿＿입니다.

정리

2그룹: る → て. 3그룹: して, きて. 1그룹: う·つ·る → って, む·ぶ·ぬ → んで, く → いて, ぐ → いで, す → して, 行く → 行って.

食べて 見て 買って 待って 帰って 飲んで 読んで 遊んで 書いて 泳いで 話して して きて 行って.

문제 8

어미 む, ぶ, ぬ인 1그룹 동사는 연결형에서 ＿＿＿로 바뀝니다.

예제

'待つ'의 연결형을 만들어 보세요.

  1. 待つ는 1그룹이며 어미는 つ입니다.
  2. 어미 つ는 っ로 바뀝니다.
  3. 뒤에 て를 붙여 まって가 됩니다.

답: まって

예제

'読む'의 연결형을 만들어 보세요.

  1. 読む는 1그룹이며 어미는 む입니다.
  2. 어미 む는 ん으로 바뀝니다.
  3. 뒤에 で를 붙여 よんで가 됩니다.

답: よんで

예제

'来る'와 'する'의 연결형을 말해 보세요.

  1. 두 동사는 3그룹이며 불규칙입니다.
  2. 来る는 きて로 바뀝니다.
  3. する는 して로 바뀝니다.

답: きて / して
