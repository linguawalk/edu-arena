시조의 형식

국문학Ⅰ · 4. 시조 · 레벨1 · 약 15분 · 문제 15개

이 레슨 풀어 보기연습 문제에세이 과제

700년을 이어 온 노래

'이 몸이 죽고 죽어 일백 번 고쳐 죽어 / 백골이 진토되어 넋이라도 있고 없고 / 임 향한 일편단심이야 가실 줄이 있으랴'. 고려 말 정몽주의 시조입니다.

시조(時調)는 고려 말에 생겨나 조선 시대에 크게 발달하고, 오늘날까지 지어지는 우리 고유의 정형시입니다. 700년 가까이 이어진 살아 있는 갈래입니다.

'시조'라는 이름은 조선 영조 때 가객 이세춘이 붙인 '시절가조(時節歌調, 그 시절에 유행하는 노래)'에서 나왔다고 전합니다. 이 챕터에서는 시조의 형식과 시대별 작품을 읽습니다.

문제 1

시조는 ＿＿＿ 말에 생겨나 조선 시대에 크게 발달했습니다.

3장 6구 45자 내외

시조는 초장, 중장, 종장의 세 장으로 이루어집니다. 각 장은 두 구, 네 음보로 되어 있어 모두 3장 6구 12음보입니다. 글자 수는 45자 안팎입니다.

초장: 이 몸이 / 죽고 죽어 // 일백 번 / 고쳐 죽어. 중장: 백골이 / 진토되어 // 넋이라도 / 있고 없고. 종장: 임 향한 / 일편단심이야 // 가실 줄이 / 있으랴.

각 음보는 대개 3~4글자이고, 3·4조 또는 4·4조의 음수율을 보입니다. 챕터 1에서 배운 4음보의 운율이 시조의 바탕입니다.

문제 2

시조는 초장, 중장, ＿＿＿의 세 장으로 이루어집니다.

문제 3

시조의 각 장은 ＿＿＿음보로 되어 있습니다.

문제 4

시조의 글자 수는 ＿＿＿자 안팎입니다.

예제

'청산리 벽계수야 수이 감을 자랑 마라 / 일도창해하면 다시 오기 어려우니 / 명월이 만공산하니 쉬어 간들 어떠리'(황진이)를 장과 음보로 나누어 보세요.

  1. 초장: 청산리 / 벽계수야 / 수이 감을 / 자랑 마라.
  2. 중장: 일도창해 / 하면 / 다시 오기 / 어려우니. 종장: 명월이 / 만공산하니 / 쉬어 간들 / 어떠리.
  3. 각 장이 네 음보로 이루어진 3장 12음보의 평시조입니다. 종장 첫 음보 '명월이'는 세 글자입니다.

답: 초장·중장·종장 각 4음보, 종장 첫 음보는 세 글자

종장의 규칙

시조의 가장 중요한 규칙은 종장에 있습니다. 종장의 첫 음보는 반드시 세 글자이고, 둘째 음보는 다섯 글자 이상으로 깁니다. '임 향한(3) / 일편단심이야(6)', '명월이(3) / 만공산하니(5)'.

종장 첫 음보에는 '어즈버', '두어라', '아희야' 같은 감탄사나 부르는 말이 자주 옵니다. 챕터 2에서 본 10구체 향가의 낙구가 '아으'로 시작하는 전통이 이어진 것으로 봅니다.

종장은 시상을 마무리하며 주제를 드러내는 곳입니다. 초장에서 시상을 일으키고, 중장에서 펼치고, 종장에서 전환하며 맺습니다.

문제 5

시조 종장의 첫 음보는 반드시 ＿＿＿ 글자입니다.

문제 6

시조 종장의 둘째 음보는 ＿＿＿ 글자 이상으로 깁니다.

시조의 종류

길이에 따라: 평시조는 기본 형식을 지킨 시조입니다. 엇시조는 중장이 조금 길어진 시조, 사설시조는 중장이 크게 길어진 시조입니다. 사설시조는 조선 후기에 많이 지어졌습니다(레슨 4).

수에 따라: 한 수로 된 시조를 단시조, 여러 수가 한 주제로 이어진 시조를 연시조라고 합니다. 맹사성의 「강호사시가」(4수), 윤선도의 「어부사시사」(40수)가 연시조입니다.

시조는 본래 노래로 불렸습니다. 시조를 노래하는 사람을 가객이라 하고, 조선 후기에는 김천택의 『청구영언』, 김수장의 『해동가요』, 박효관·안민영의 『가곡원류』 같은 시조집이 엮였습니다.

문제 7

여러 수가 한 주제로 이어진 시조를 ＿＿＿라고 합니다.

문제 8

1728년 김천택이 엮은 시조집은 『＿＿＿』입니다.

시조의 형식 정리

시조: 고려 말 발생, 조선 시대 발달, 오늘날까지 이어지는 정형시. 이름은 '시절가조'에서.

형식: 3장(초·중·종장) 6구 12음보, 45자 내외, 3·4조·4·4조. 종장 첫 음보 세 글자(어즈버, 두어라, 아희야), 둘째 음보 다섯 글자 이상. 향가 낙구의 전통.

종류: 평시조, 엇시조, 사설시조(중장이 길어짐), 단시조, 연시조. 시조집: 『청구영언』(김천택, 1728), 『해동가요』(김수장), 『가곡원류』(박효관·안민영).

문제 9

중장이 크게 길어진 시조를 ＿＿＿시조라고 합니다.

예제

'오백 년 도읍지를 필마로 돌아드니 / 산천은 의구하되 인걸은 간 데 없다 / 어즈버 태평연월이 꿈이런가 하노라'(길재)에서 종장의 규칙을 확인해 보세요.

  1. 종장은 '어즈버 / 태평연월이 / 꿈이런가 / 하노라'입니다.
  2. 첫 음보 '어즈버'는 세 글자의 감탄사입니다.
  3. 둘째 음보 '태평연월이'는 다섯 글자로, 종장의 규칙을 잘 지켰습니다.

답: 첫 음보 '어즈버'(3자), 둘째 음보 '태평연월이'(5자)

예제

시조 종장 첫머리의 감탄사가 하는 구실은 무엇일까요?

  1. 초장과 중장에서 펼친 시상을 종장에서 마무리합니다.
  2. '어즈버', '두어라' 같은 감탄사는 감정을 한데 모으고 분위기를 바꿉니다.
  3. 그래서 종장 첫머리의 감탄사는 시상을 전환하고 주제를 강조하는 구실을 합니다.

답: 시상을 전환하고 감정을 모아 주제를 강조함
