전기전자 · 9. 논리 게이트와 조합회로 · 레벨1 · 약 15분 · 문제 16개

원하는 동작을 회로로

조합 논리회로는 지금 들어온 입력만으로 출력이 정해지는 회로입니다. 설계는 원하는 동작을 말로 정리하고, 진리표로 옮기고, 논리식을 세운 뒤, 게이트로 그리는 순서로 합니다.

문제 1

조합 논리회로를 설계하는 순서입니다. 차례대로 배열하세요.

논리식

논리식에서 AND는 곱처럼 A·B로, OR는 합처럼 A + B로, NOT은 A'(또는 A 위에 막대)로 씁니다.

계산 순서는 보통 수식처럼 NOT, AND, OR 순입니다. Y = A·B + C는 'A와 B가 모두 1이거나, C가 1이면 Y는 1'이라는 뜻입니다.

예제

Y = A·B + C에서 A = 1, B = 0, C = 1이면 Y는?

  1. A·B = 1·0 = 0입니다.
  2. Y = 0 + 1 = 1입니다.

답: 1

문제 2

논리식에서 A·B는 ＿＿＿ 연산을 뜻합니다.

문제 3

Y = A + B·C에서 A = 0, B = 1, C = 1이면 Y는 얼마일까요?

문제 4

Y = (A + B)·C에서 A = 1, B = 0, C = 0이면 Y는 얼마일까요?

문제 5

Y = A'·B에서 A = 0, B = 1이면 Y는 얼마일까요?

진리표에서 식 세우기

진리표에서 출력이 1인 행을 찾아, 각 행의 입력 조합을 AND로 쓴 뒤 모두 OR로 묶습니다. 이를 곱의 합이라고 합니다. 입력이 0인 변수는 NOT을 붙입니다.

예를 들어 입력 3개 가운데 두 개 이상이 1이면 1을 내는 다수결 회로는 Y = A·B + B·C + C·A로 간단히 쓸 수 있습니다. 두 입력이 1인 경우 가운데 어느 쪽이든 걸리면 1이 됩니다.

예제

다수결 회로 Y = A·B + B·C + C·A에 1, 0, 1을 넣으면?

  1. A·B = 0, B·C = 0입니다.
  2. C·A = 1·1 = 1입니다.
  3. Y = 0 + 0 + 1 = 1입니다.

답: 1

문제 8

입력 3개 다수결 회로의 진리표 8행 가운데 출력이 1인 행은 몇 개일까요?

문제 9

드모르간 법칙에 따르면 (A·B)' = A' ＿＿＿ B'입니다.

간단하게 만들기

드모르간 법칙은 (A·B)' = A' + B', (A + B)' = A'·B'입니다. 전체에 붙은 NOT을 안으로 넣으면 AND와 OR가 서로 바뀝니다.

논리식을 법칙으로 간단히 만들면 게이트 수가 줄어 회로가 작고 빠르고 싸집니다. 오늘날에는 이런 간소화를 설계 소프트웨어가 대신해 주지만, 원리를 알아야 결과를 확인할 수 있습니다.

문제 10

드모르간 법칙에 따르면 (A + B)' = A' ＿＿＿ B'입니다.

예제

세탁기 모터는 문이 닫히고(D), 물이 차 있고(W), 시작 버튼이 눌렸을(S) 때만 돕니다. 논리식은?

  1. 세 조건이 모두 1이어야 합니다.
  2. 모두 1일 때만 1인 것은 AND입니다.
  3. Y = D·W·S입니다.

답: Y = D·W·S
