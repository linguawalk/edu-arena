컴퓨터의 구성

컴퓨터 · 3. CPU 구조 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

다섯 부분

오늘날 거의 모든 컴퓨터는 같은 기본 구조를 가집니다. 계산하고 지시하는 중앙 처리 장치(CPU), 프로그램과 데이터를 담는 메모리, 바깥과 주고받는 입출력 장치, 그리고 이들을 잇는 버스입니다.

CPU 안은 다시 명령어를 해석해 각 부분에 지시하는 제어장치, 계산하는 산술 논리 장치(ALU), 값을 잠시 담는 레지스터로 나뉩니다.

문제 1

컴퓨터에서 명령어를 실행하고 계산하는 핵심 장치를 ＿＿＿라고 합니다.

저장 프로그램 방식

초기의 컴퓨터는 할 일을 바꾸려면 배선을 새로 꽂아야 했습니다. 1940년대에 프로그램도 데이터처럼 메모리에 저장해 두고 CPU가 하나씩 꺼내 실행하자는 생각이 나왔는데, 이를 저장 프로그램 방식이라고 합니다. 이 생각을 정리한 폰 노이만의 이름을 따서 폰 노이만 구조라고도 부릅니다.

덕분에 같은 기계가 프로그램만 바꾸면 계산기도, 게임기도, 문서 편집기도 됩니다. 대신 명령어와 데이터가 같은 버스로 오가서 버스가 병목이 되기 쉬운데, 이를 폰 노이만 병목이라고 합니다.

예제

스마트폰에 새 앱을 깔면 새 기능이 생기는 까닭은?

  1. 앱은 명령어의 모음, 곧 프로그램입니다.
  2. 프로그램을 메모리(저장 장치)에 넣으면 CPU가 꺼내 실행합니다.
  3. 하드웨어를 바꾸지 않고 기능이 늘어납니다. 저장 프로그램 방식 덕분입니다.

답: 저장 프로그램 방식

문제 2

프로그램을 데이터처럼 메모리에 저장해 두고 CPU가 꺼내 실행하는 방식을 ＿＿＿ 프로그램 방식이라고 합니다.

문제 3

그림에서 CPU, 메모리, 입출력 장치를 잇는 공통 통로는 ＿＿＿입니다.

문제 4

CPU 안에서 계산을 맡는 부분은 ＿＿＿입니다.

문제 5

명령어와 데이터가 같은 버스로 오가서 생기는 속도 제한을 폰 노이만 ＿＿＿이라고 합니다.

입출력 장치

입력 장치(키보드, 마우스, 카메라, 마이크, 센서)는 바깥의 정보를 2진 데이터로 바꿔 들여오고, 출력 장치(모니터, 스피커, 프린터)는 데이터를 사람이 알아볼 수 있는 형태로 내보냅니다.

SSD 같은 보조 기억 장치와 네트워크 카드도 CPU 입장에서는 입출력 장치입니다. 메모리보다 훨씬 느리므로, CPU는 입출력을 기다리는 동안 다른 일을 하도록 설계됩니다(챕터 6).

예제

터치스크린은 입력 장치일까요, 출력 장치일까요?

  1. 화면으로 영상을 보여 주므로 출력 장치입니다.
  2. 손가락 위치를 감지해 들여오므로 입력 장치이기도 합니다.
  3. 입출력을 모두 하는 장치입니다.

하나의 칩에 모두

스마트폰에서는 CPU, 그래픽 처리 장치(GPU), 메모리 제어기, 통신 모뎀 등을 한 칩에 담은 SoC(System on Chip)를 씁니다. 구조의 기본은 같지만 거리가 가까워 빠르고 전력이 적게 듭니다.

정리: CPU(제어장치·ALU·레지스터), 메모리, 입출력 장치, 버스, 저장 프로그램(폰 노이만) 구조와 병목, SoC

문제 10

CPU, GPU, 모뎀 등을 한 칩에 담은 것을 ＿＿＿라고 합니다.

예제

게임을 끄고 문서 편집기를 켰더니 같은 컴퓨터가 전혀 다른 일을 합니다. 무엇이 바뀐 것일까요?

  1. CPU, 메모리, 버스 같은 하드웨어는 그대로입니다.
  2. 메모리에 올라간 프로그램이 바뀌었습니다.
  3. CPU는 새 프로그램의 명령어를 꺼내 실행합니다.
