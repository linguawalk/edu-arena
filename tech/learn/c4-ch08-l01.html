인터넷의 주소

MAC 주소는 같은 LAN 안에서만 쓰입니다. 전 세계 어디든 패킷을 보내려면 인터넷 전체에서 통하는 주소가 필요한데, 이것이 IP 주소입니다. 라우터는 패킷의 목적지 IP 주소를 보고 길을 고릅니다.

지금 가장 많이 쓰는 IPv4 주소는 32비트로, 8비트씩 네 부분으로 나누어 10진수로 적습니다. 예: 192.168.0.15. 각 부분은 0부터 255까지입니다.

문제 1

IPv4 주소의 각 부분(8비트)이 가질 수 있는 가장 큰 값은 얼마일까요?

네트워크 부분과 호스트 부분

IP 주소는 앞쪽의 네트워크 부분과 뒤쪽의 호스트 부분으로 나뉩니다. 192.168.0.15/24라고 쓰면 앞 24비트(192.168.0)가 네트워크, 뒤 8비트(15)가 그 네트워크 안의 호스트 번호입니다.

/24 네트워크에는 2⁸ = 256개의 주소가 있습니다. 이 가운데 호스트 부분이 모두 0인 주소(네트워크 자체)와 모두 1인 주소(브로드캐스트)는 장치에 줄 수 없어, 쓸 수 있는 호스트는 254개입니다.

예제

10.1.2.0/26 네트워크에서 장치에 줄 수 있는 주소는 몇 개일까요?

  1. 호스트 부분은 32 − 26 = 6비트입니다.
  2. 2⁶ = 64개 주소가 있습니다.
  3. 네트워크 주소와 브로드캐스트를 빼면 62개입니다.

답: 62개

문제 5

/28 네트워크에는 주소가 모두 몇 개 있을까요?

주소가 모자란다

32비트로 만들 수 있는 IPv4 주소는 2³² ≈ 43억 개뿐이라, 스마트폰과 사물인터넷 장치가 늘면서 모자라게 되었습니다.

그래서 집과 회사 안에서는 사설 주소(192.168.x.x, 10.x.x.x 등)를 쓰고, 공유기가 인터넷으로 나갈 때 공인 주소 하나로 바꿔 주는 NAT를 씁니다. 집 안 장치 여러 대가 공인 주소 하나를 함께 씁니다.

근본적인 해결책은 128비트 주소를 쓰는 IPv6입니다. 2¹²⁸개로 사실상 무한합니다. 2001:db8::1처럼 16진수로 씁니다.

예제

집 안의 노트북(192.168.0.10)과 휴대폰(192.168.0.11)이 모두 인터넷에 접속합니다. 웹 서버에는 어떤 주소로 보일까요?

  1. 192.168.x.x는 사설 주소라 인터넷에서 쓰지 않습니다.
  2. 공유기가 NAT로 두 장치의 패킷을 공유기의 공인 주소로 바꿔 내보냅니다.
  3. 웹 서버에는 둘 다 공유기의 공인 주소로 보입니다.

답: 공유기의 공인 주소

문제 9

IPv4 주소가 모자란 문제의 근본 해결책은 ＿＿＿입니다.

주소를 받는 방법

노트북을 공유기에 연결하면 IP 주소를 직접 입력하지 않아도 자동으로 받습니다. 공유기의 DHCP 기능이 비어 있는 주소를 골라 빌려주기 때문입니다. 함께 기본 게이트웨이(바깥으로 나가는 라우터 주소)와 DNS 서버 주소도 알려 줍니다.

정리: IPv4(32비트, 0~255 네 부분), 네트워크 부분과 호스트 부분(/24는 254개 호스트), 주소 부족, 사설 주소와 NAT, IPv6(128비트), DHCP와 기본 게이트웨이

문제 10

장치에 IP 주소를 자동으로 빌려주는 기능을 ＿＿＿라고 합니다.

예제

172.16.5.130/25는 어느 네트워크에 속하고, 쓸 수 있는 호스트는 몇 개일까요?

  1. /25는 호스트 7비트로 128개씩 나뉩니다: 0~127, 128~255입니다.
  2. 130은 128~255 쪽이므로 네트워크는 172.16.5.128입니다.
  3. 호스트는 128 − 2 = 126개입니다.

답: 172.16.5.128, 126개
