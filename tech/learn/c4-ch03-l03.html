제어장치와 버스

컴퓨터 · 3. CPU 구조 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

지휘자

제어장치는 메모리에서 가져온 명령어를 해석(디코딩)해, 어느 레지스터를 읽을지, ALU가 무슨 연산을 할지, 결과를 어디에 쓸지를 각 부분에 지시하는 신호를 만듭니다. 오케스트라의 지휘자와 같습니다.

명령어는 보통 무엇을 할지 나타내는 연산 코드(opcode)와 무엇에 대해 할지 나타내는 피연산자(레지스터 번호, 주소, 값)로 되어 있습니다.

문제 1

명령어에서 '무엇을 할지'를 나타내는 부분을 ＿＿＿ 코드라고 합니다.

명령어 형식

예를 들어 16비트 명령어의 앞 4비트가 연산 코드라면 2⁴ = 16가지 동작을 구별할 수 있습니다. 나머지 12비트에 레지스터 번호나 값을 담습니다.

레지스터가 8개라면 레지스터 번호 하나에 3비트(2³ = 8)가 필요합니다. 명령어 하나에 레지스터 번호를 3개 담으면 9비트를 씁니다.

예제

32비트 명령어에서 연산 코드가 6비트이면 몇 가지 동작을 구별할 수 있을까요?

  1. 2⁶ = 64가지입니다.

답: 64가지

문제 2

명령어에서 '무엇에 대해 할지'를 나타내는 레지스터 번호, 주소, 값을 ＿＿＿라고 합니다.

문제 3

연산 코드가 5비트이면 몇 가지 동작을 구별할 수 있을까요?

문제 4

레지스터가 16개이면 레지스터 번호 하나에 몇 비트가 필요할까요?

문제 5

16비트 명령어에서 연산 코드 4비트, 레지스터 번호(각 4비트) 2개를 쓰면 남는 비트는 몇 개일까요?

세 가지 버스

버스는 역할에 따라 셋으로 나뉩니다. 주소 버스는 CPU가 읽거나 쓸 메모리 위치를 보내는 선으로, CPU에서 메모리 쪽으로만 갑니다. 데이터 버스는 실제 데이터가 오가는 선으로, 읽을 때와 쓸 때 방향이 바뀌는 양방향입니다. 제어 버스는 읽기·쓰기 신호, 클럭, 인터럽트 같은 제어 신호를 나릅니다.

데이터 버스의 폭(선 수)이 64비트이면 한 번에 8바이트를 옮깁니다. 초당 전송량(대역폭) = 한 번에 옮기는 바이트 × 초당 전송 횟수입니다.

예제

폭 64비트, 초당 1억 번 전송하는 버스의 대역폭은?

  1. 한 번에 64 ÷ 8 = 8바이트입니다.
  2. 8 × 1억 = 8억 바이트/초입니다.
  3. = 800 MB/s입니다(1000 단위).

답: 800 MB/s

문제 7

문제 8

읽기·쓰기 신호와 클럭을 나르는 버스는 ＿＿＿ 버스입니다.

문제 9

폭 32비트 데이터 버스는 한 번에 몇 바이트를 옮길까요?

마이크로 동작

명령어 하나를 실행할 때 제어장치는 여러 개의 작은 단계(마이크로 동작)를 차례로 지시합니다. 예를 들어 '메모리 값을 레지스터에 불러오기'는 주소를 주소 버스에 싣기 → 읽기 신호 보내기 → 데이터 버스의 값을 레지스터에 저장하기로 나뉩니다. 다음 챕터에서 이 흐름을 자세히 봅니다.

정리: 제어장치(디코딩, 제어 신호), 명령어 = 연산 코드 + 피연산자, 연산 코드 n비트 → 2ⁿ가지, 주소 버스(단방향)·데이터 버스(양방향)·제어 버스, 대역폭 = 폭(바이트) × 전송 횟수

문제 10

제어장치가 명령어를 해석하는 것을 ＿＿＿이라고 합니다.

예제

주소 버스 폭이 24비트인 CPU가 가리킬 수 있는 메모리는 최대 몇 MB일까요? (칸당 1바이트, 1 MB = 2²⁰ B)

  1. 2²⁴칸을 가리킬 수 있습니다.
  2. 2²⁴ ÷ 2²⁰ = 2⁴ = 16 MB입니다.

답: 16 MB
