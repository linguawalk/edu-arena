PC를 바꾸는 명령어

분기 명령어는 PC에 새 주소를 넣어 다음에 실행할 명령어를 바꿉니다. JMP k는 무조건 k번 줄로 건너뜁니다. JNZ k는 바로 앞 계산 결과가 0이 아닐 때만(제로 플래그가 꺼져 있을 때) k번 줄로 건너뛰고, 0이면 다음 줄로 갑니다.

조건 분기는 ALU의 플래그(챕터 3)를 보고 결정합니다. 이것으로 '만약 ~이면'과 '~하는 동안 되풀이'를 만듭니다.

문제 1

JNZ는 바로 앞 계산 결과가 0이 ＿＿＿ 때 건너뜁니다.

반복문

다음 프로그램은 A를 3, 2, 1로 줄여 가며 되풀이합니다. 1: MOV A, 3 / 2: SUB A, 1 / 3: JNZ 2 / 4: (끝).

2번 줄에서 A가 2가 되면 0이 아니므로 2번 줄로 돌아가고, 1이 되면 또 돌아가고, 0이 되면 4번 줄로 나갑니다. 2번 줄은 모두 3번 실행됩니다. 이처럼 카운터를 1씩 줄이다 0이 되면 빠져나오는 모양이 가장 흔한 반복입니다.

예제

1: MOV A, 5 / 2: SUB A, 1 / 3: JNZ 2 / 4: (끝) 에서 2번 줄은 몇 번 실행될까요?

  1. A는 5 → 4 → 3 → 2 → 1 → 0으로 줄어듭니다.
  2. 1씩 줄 때마다 2번 줄이 한 번 실행됩니다.
  3. 5번 실행된 뒤 A = 0이라 빠져나옵니다.

답: 5번

반복으로 곱셈

간단한 CPU에는 곱셈 명령어가 없기도 합니다. 그래도 반복으로 곱셈을 만들 수 있습니다. 다음 프로그램은 3 × 4를 계산합니다.

1: MOV A, 0 / 2: MOV B, 3 / 3: MOV C, 4 / 4: ADD A, B / 5: SUB C, 1 / 6: JNZ 4 / 7: (끝). C가 4번 줄어드는 동안 A에 B(3)가 4번 더해져 A = 12가 됩니다. (여기서 SUB C, 1은 C에서 1을 뺍니다.)

예제

앞 곱셈 프로그램에서 MOV B, 3을 MOV B, 7로, MOV C, 4를 MOV C, 5로 바꾸면 A는?

  1. C가 5번 줄어드는 동안 A에 7이 5번 더해집니다.
  2. A = 7 × 5 = 35입니다.

답: 35

곱셈 프로그램에서 B = 5, C = 4이면 모두 몇 줄(명령어)이 실행될까요? (7번 끝 줄은 세지 않음)

조건문

'만약 A가 0이 아니면 X를 하고, 아니면 건너뛴다' 같은 조건문도 분기로 만듭니다. 조건이 거짓일 때 X 부분을 건너뛰는 분기를 두면 됩니다. 고급 언어의 if, while, for는 모두 이런 분기 명령어로 번역됩니다.

정리: JMP(무조건), JNZ(0이 아니면), 플래그를 보고 조건 분기, 카운터를 줄이는 반복, 반복으로 곱셈, if·while·for는 분기로 번역

문제 10

고급 언어의 if, while, for는 기계어의 ＿＿＿ 명령어로 번역됩니다.

예제

1: MOV A, 3 / 2: MOV B, 0 / 3: ADD B, A / 4: SUB A, 1 / 5: JNZ 3 / 6: (끝) 에서 B는? (ADD B, A는 B ← B + A)

  1. A = 3일 때 B = 3, A = 2일 때 B = 5, A = 1일 때 B = 6입니다.
  2. 그다음 A = 0이 되어 빠져나옵니다.
  3. B = 3 + 2 + 1 = 6입니다.

답: 6
