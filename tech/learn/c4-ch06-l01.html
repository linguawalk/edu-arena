운영체제란

컴퓨터 · 6. 운영체제의 역할 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

하드웨어와 프로그램 사이

운영체제(OS)는 하드웨어와 응용 프로그램 사이에서 컴퓨터의 자원을 관리하는 프로그램입니다. CPU 시간, 메모리, 저장 장치, 입출력 장치를 여러 프로그램에 나누어 주고, 서로 방해하지 않게 지킵니다.

PC의 윈도우, macOS, 리눅스, 스마트폰의 안드로이드와 iOS가 운영체제입니다. 응용 프로그램은 하드웨어를 직접 다루지 않고 운영체제에 부탁합니다.

문제 1

하드웨어 자원을 관리하고 응용 프로그램에 나누어 주는 프로그램을 ＿＿＿라고 합니다.

커널과 시스템 호출

운영체제의 핵심으로 늘 메모리에 올라와 자원을 관리하는 부분을 커널이라고 합니다. 응용 프로그램이 파일 읽기, 화면 출력, 네트워크 전송처럼 하드웨어가 필요한 일을 하려면 시스템 호출로 커널에 부탁합니다.

CPU는 두 가지 모드로 동작합니다. 커널은 모든 명령어를 쓸 수 있는 커널 모드에서, 응용 프로그램은 위험한 명령어를 쓸 수 없는 사용자 모드에서 돕니다. 시스템 호출을 하면 잠시 커널 모드로 바뀌어 커널이 일을 처리하고 돌아옵니다.

예제

메모장 프로그램이 파일을 저장할 때 일어나는 일은?

  1. 메모장은 사용자 모드에서 '파일 쓰기' 시스템 호출을 합니다.
  2. CPU가 커널 모드로 바뀌어 커널이 SSD에 씁니다.
  3. 끝나면 사용자 모드로 돌아와 메모장이 이어서 실행됩니다.

답: 시스템 호출로 커널이 대신 쓴다

문제 2

응용 프로그램이 커널에 서비스를 부탁하는 것을 ＿＿＿ 호출이라고 합니다.

문제 3

운영체제의 핵심으로 늘 메모리에 올라와 자원을 관리하는 부분은 ＿＿＿입니다.

문제 4

응용 프로그램은 위험한 명령어를 쓸 수 없는 ＿＿＿ 모드에서 돕니다.

문제 5

하드웨어를 직접 다루는 명령어는 ＿＿＿ 모드에서만 쓸 수 있습니다.

운영체제의 주요 일

프로세스 관리(어떤 프로그램에 CPU를 줄지), 메모리 관리(가상 메모리, 챕터 5), 파일 관리(파일과 폴더), 입출력 관리(장치 드라이버), 보안과 보호(사용자와 권한)가 운영체제의 주요 일입니다.

또 사용자와 컴퓨터가 만나는 창구(명령줄 셸이나 그래픽 화면)도 제공합니다.

예제

음악을 들으며 문서를 쓰고, 동시에 파일을 내려받을 수 있는 것은 운영체제의 어떤 일 덕분일까요?

  1. 세 프로그램이 번갈아 CPU를 씁니다(프로세스 관리).
  2. 각자 자기 메모리를 씁니다(메모리 관리).
  3. 소리 장치, 네트워크, 저장 장치를 나누어 씁니다(입출력 관리).

답: 프로세스·메모리·입출력 관리

문제 6

운영체제가 어떤 프로그램에 CPU를 줄지 정하는 일을 ＿＿＿ 관리라고 합니다.

문제 7

파일과 폴더를 만들고 찾고 지우는 일은 운영체제의 ＿＿＿ 관리입니다.

문제 8

사용자가 명령어를 입력해 운영체제를 다루는 창구를 ＿＿＿이라고 합니다.

문제 9

스마트폰에서 쓰는 운영체제에는 안드로이드와 ＿＿＿가 있습니다.

왜 직접 다루지 못하게 할까

모든 프로그램이 하드웨어를 마음대로 다룬다면, 한 프로그램의 실수가 다른 프로그램의 데이터를 지우거나 컴퓨터 전체를 멈출 수 있습니다. 운영체제가 창구를 하나로 모으면 자원을 공정하게 나누고 서로를 보호할 수 있습니다.

정리: 운영체제 = 자원 관리자, 커널, 시스템 호출, 사용자 모드와 커널 모드, 프로세스·메모리·파일·입출력·보안 관리, 셸과 그래픽 화면

문제 10

운영체제가 하드웨어 접근 창구를 하나로 모으면 프로그램끼리 서로를 ＿＿＿할 수 있습니다.

예제

게임 프로그램이 다른 프로그램의 메모리를 직접 읽으려 하면 어떻게 될까요?

  1. 게임은 사용자 모드에서 돕니다.
  2. 다른 프로그램의 메모리는 게임의 페이지 테이블에 없습니다.
  3. 운영체제가 접근을 막고 보통 게임을 오류로 끝냅니다.

답: 운영체제가 막는다

문제 11

사진 앱이 카메라로 찍으려면 카메라 장치를 직접 다루지 않고 ＿＿＿ 호출로 운영체제에 부탁합니다.

문제 12

시스템 호출을 하면 CPU는 잠시 ＿＿＿ 모드로 바뀝니다.

문제 13

시스템 호출 한 번에 모드 전환이 2번(들어갈 때, 나올 때) 일어납니다. 파일을 100번 나누어 읽으면 모드 전환은 몇 번일까요?

문제 14

파일 1 MB를 4 KB씩 나누어 읽으면 시스템 호출은 몇 번일까요? (1 MB = 1024 KB)

문제 15

프로그램 하나가 멈춰도 운영체제와 다른 프로그램은 계속 돌아가는 것은 운영체제가 프로그램들을 서로 ＿＿＿하기 때문입니다.

문제 16

응용 프로그램이 하드웨어를 직접 다루지 않고 시스템 호출로 운영체제에 부탁하게 하는 이유를 설명해 보세요.

문제의 정답과 해설, 힌트는 레슨을 풀면서 확인할 수 있습니다.
