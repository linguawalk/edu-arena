기본 논리 게이트

전기전자 · 9. 논리 게이트와 조합회로 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

0과 1을 다루는 규칙

논리 게이트는 0과 1의 입력을 받아 정해진 규칙에 따라 0이나 1을 내는 회로입니다. 입력의 모든 조합과 그때의 출력을 표로 정리한 것을 진리표라고 합니다.

예를 들어 AND 게이트는 입력이 모두 1일 때만 1을 냅니다.

문제 1

입력이 모두 1일 때만 출력이 1인 게이트는 ＿＿＿ 게이트입니다.

NOT, AND, OR

NOT 게이트는 입력을 뒤집습니다. 0을 넣으면 1, 1을 넣으면 0이 나옵니다.

AND 게이트는 입력이 모두 1일 때만 1입니다. OR 게이트는 입력 가운데 하나라도 1이면 1입니다.

스위치로 생각하면 쉽습니다. 스위치 두 개를 직렬로 연결한 전구는 둘 다 켜야 불이 들어와 AND와 같고, 병렬로 연결한 전구는 하나만 켜도 불이 들어와 OR와 같습니다.

예제

AND 게이트에 A = 1, B = 0을 넣으면 출력은?

  1. AND는 모든 입력이 1이어야 1입니다.
  2. B가 0이므로 출력은 0입니다.

답: 0

문제 2

입력을 뒤집어 0은 1로, 1은 0으로 내는 게이트는 ＿＿＿ 게이트입니다.

문제 3

OR 게이트에 A = 0, B = 1을 넣으면 출력은 얼마일까요?

문제 4

NOT 게이트에 1을 넣으면 출력은 얼마일까요?

문제 5

스위치 두 개를 직렬로 연결한 전구 회로는 ＿＿＿ 게이트처럼 동작합니다.

NAND, NOR, XOR

NAND는 AND의 출력을 뒤집은 것으로, 입력이 모두 1일 때만 0입니다. NOR는 OR의 출력을 뒤집은 것으로, 입력이 모두 0일 때만 1입니다.

XOR(배타적 OR)는 두 입력이 서로 다를 때만 1입니다. 같으면 0입니다.

NAND 게이트만 여러 개 있으면 다른 모든 게이트를 만들 수 있어, 실제 칩에서는 NAND를 기본 재료처럼 많이 씁니다.

예제

XOR 게이트에 A = 1, B = 1을 넣으면 출력은?

  1. XOR는 두 입력이 서로 다를 때만 1입니다.
  2. 두 입력이 같으므로 출력은 0입니다.

답: 0

문제 6

두 입력이 서로 다를 때만 출력이 1인 게이트는 ＿＿＿ 게이트입니다.

문제 7

NAND 게이트에 A = 1, B = 1을 넣으면 출력은 얼마일까요?

문제 8

NOR 게이트에 A = 0, B = 0을 넣으면 출력은 얼마일까요?

문제 9

XOR 게이트에 A = 1, B = 0을 넣으면 출력은 얼마일까요?

진리표의 크기

입력이 n개인 게이트의 진리표는 2ⁿ행입니다. 입력 2개는 4행, 3개는 8행입니다.

정리: NOT(뒤집기), AND(모두 1), OR(하나라도 1), NAND(AND의 반대), NOR(OR의 반대), XOR(서로 다르면 1)

문제 10

입력이 3개인 게이트의 진리표는 몇 행일까요?

예제

문이 열림(A = 1)과 경비 모드 켜짐(B = 1)이 모두 참일 때만 경보를 울리려면 어떤 게이트를 쓸까요?

  1. 두 조건이 모두 1일 때만 출력이 1이어야 합니다.
  2. 이것은 AND 게이트의 규칙입니다.

답: AND 게이트

문제 11

문제 12

문제 13

계단 위와 아래의 스위치 어느 쪽을 바꿔도 전등 상태가 바뀌는 회로는 ＿＿＿ 게이트와 같습니다.

문제 14

NOT(A AND B)에서 A = 1, B = 1이면 출력은 얼마일까요?

문제 15

입력이 4개인 회로의 진리표는 몇 행일까요?

문제 16
