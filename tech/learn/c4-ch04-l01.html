인출, 해독, 실행

컴퓨터 · 4. 명령어 실행 사이클 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

CPU는 같은 일을 되풀이한다

CPU가 하는 일은 단순합니다. 메모리에서 명령어 하나를 가져오고(인출), 무슨 뜻인지 알아내고(해독), 그대로 실행합니다. 그리고 다음 명령어로 넘어가 이 일을 끝없이 되풀이합니다. 이를 명령어 사이클이라고 합니다.

1초에 수십억 번 이 사이클을 돌아서, 단순한 명령어들이 모여 복잡한 프로그램이 됩니다.

문제 1

명령어 사이클의 단계를 차례대로 배열하세요.

인출 단계

프로그램 카운터(PC)에는 다음에 실행할 명령어의 주소가 들어 있습니다. 인출 단계에서 CPU는 PC의 주소를 주소 버스에 싣고, 메모리에서 명령어를 데이터 버스로 받아 명령어 레지스터(IR)에 넣습니다.

그리고 PC를 다음 명령어의 주소로 늘립니다. 명령어 하나가 4바이트이고 메모리가 바이트 단위 주소라면 PC는 4씩 늘어납니다.

예제

명령어가 4바이트이고 PC = 100입니다. 명령어 하나를 인출한 뒤 PC는?

  1. PC = 100에서 명령어를 가져옵니다.
  2. 다음 명령어는 4바이트 뒤에 있습니다.
  3. PC = 104가 됩니다.

답: 104

해독과 실행

해독 단계에서 제어장치는 IR의 연산 코드를 보고 어떤 명령어인지 알아내고, 필요한 레지스터를 읽을 준비를 합니다.

실행 단계에서는 명령어에 따라 ALU가 계산하거나, 메모리에서 값을 읽어 오거나(불러오기), 메모리에 값을 쓰거나(저장), PC를 바꿔 다른 곳으로 건너뜁니다(분기). 계산 결과를 레지스터에 쓰는 단계를 따로 나누어 쓰기(write back)라고 부르기도 합니다.

예제

'ADD A, B' 명령어는 각 단계에서 무엇을 할까요?

  1. 인출: PC가 가리키는 곳에서 명령어를 가져와 IR에 넣고 PC를 늘립니다.
  2. 해독: 덧셈 명령어이며 A와 B를 쓴다는 것을 알아냅니다.
  3. 실행: ALU가 A + B를 계산해 A에 씁니다.

답: 인출 → 해독 → 실행

한 명령어, 여러 클럭

단순한 CPU에서는 인출, 해독, 실행이 각각 한 클럭 이상 걸려 명령어 하나에 여러 클럭이 듭니다. 메모리에서 값을 읽는 명령어는 메모리가 느려 더 오래 걸립니다. 레슨 4의 파이프라인은 이 단계들을 겹쳐서 속도를 높입니다.

정리: 명령어 사이클 = 인출(PC → 메모리 → IR, PC 증가) → 해독(제어장치) → 실행(ALU, 불러오기·저장, 분기) → 되풀이

문제 10

명령어 인출 뒤 PC는 ＿＿＿ 명령어의 주소를 가리키게 됩니다.

예제

명령어가 4바이트인 CPU에서 PC = 0x10입니다. 명령어 두 개를 실행하면 PC는(점프 없음)?

  1. 0x10 = 16입니다.
  2. 16 + 4 × 2 = 24입니다.
  3. 24 = 0x18입니다.

답: 0x18
