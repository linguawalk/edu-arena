2진수와 16진수

컴퓨터 · 1. 정보의 표현 · 레벨1 · 약 15분 · 문제 16개

이 레슨 풀어 보기연습 문제에세이 과제

자릿값이 2배씩

2진수는 오른쪽부터 자릿값이 1, 2, 4, 8, 16, …처럼 2배씩 커집니다. 2진수 1011은 8 + 0 + 2 + 1 = 11입니다(전기전자 챕터 9에서 다룬 내용).

하지만 2진수는 자릿수가 길어 사람이 읽기 어렵습니다. 그래서 프로그래머는 16진수를 많이 씁니다.

문제 1

2진수 1101은 10진수로 얼마일까요?

16진수

16진수는 숫자 16개를 씁니다. 0~9 다음에 A(10), B(11), C(12), D(13), E(14), F(15)를 씁니다. 자릿값은 1, 16, 256, …처럼 16배씩 커집니다.

2진수 4자리는 0000~1111로 16가지이므로 16진수 1자리와 정확히 대응합니다. 그래서 2진수를 오른쪽부터 4자리씩 끊어 바꾸면 16진수가 됩니다. 1바이트(8비트)는 16진수 2자리입니다.

16진수임을 나타내려고 앞에 0x를 붙이거나 뒤에 h를 붙입니다. 0x2F는 2 × 16 + 15 = 47입니다.

예제

2진수 1010 1111을 16진수로 바꾸면?

  1. 앞 4자리 1010 = 10 = A입니다.
  2. 뒤 4자리 1111 = 15 = F입니다.
  3. 합치면 0xAF입니다.

답: 0xAF

16진수는 어디에 쓰나

웹 색상은 #RRGGBB처럼 빨강, 초록, 파랑을 각각 16진수 2자리(0~255)로 씁니다. #FF0000은 빨강, #FFFFFF는 흰색, #000000은 검정입니다.

메모리 주소, 네트워크 장치의 MAC 주소(예: 3C:22:FB:…), 오류 코드처럼 바이트를 그대로 보여 줄 때도 16진수를 씁니다.

예제

색상 #00FF00은 무슨 색일까요?

  1. 빨강 00 = 0, 초록 FF = 255, 파랑 00 = 0입니다.
  2. 초록만 최대로 켜졌습니다.
  3. 밝은 초록입니다.

답: 초록

문제 9

1바이트는 16진수 몇 자리일까요?

10진수를 16진수로

10진수를 16진수로 바꿀 때는 16으로 나눈 몫과 나머지를 봅니다. 200 ÷ 16 = 12 나머지 8이므로 200 = 0xC8입니다. 2진수로 가려면 16진수 각 자리를 4비트로 풀면 됩니다: C8 = 1100 1000.

정리: 2진수 자릿값 1, 2, 4, 8, …, 16진수 0~9와 A~F, 2진 4자리 = 16진 1자리, 1바이트 = 16진 2자리, 색상 #RRGGBB, 16으로 나눈 몫과 나머지

  2. A = 1010, C = 1100입니다.
