기억하는 회로

컴퓨터 · 2. 플립플롭과 메모리 · 레벨1 · 약 15분 · 문제 16개

조합회로는 기억하지 못한다

전기전자 챕터 9의 가산기 같은 조합회로는 지금 들어온 입력만으로 출력이 정해집니다. 입력이 사라지면 결과도 사라집니다. 하지만 컴퓨터는 계산 결과를 잠시 들고 있다가 다음 계산에 써야 합니다.

지금 입력뿐 아니라 이전 상태에 따라 출력이 정해지는 회로를 순차회로라고 합니다. 순차회로의 가장 작은 기억 소자가 1비트를 저장하는 래치와 플립플롭입니다.

문제 1

이전 상태를 기억해 출력이 정해지는 회로를 ＿＿＿회로라고 합니다.

SR 래치

NOR 게이트 두 개의 출력을 서로의 입력으로 되먹이면 SR 래치가 됩니다. 입력은 S(set)와 R(reset), 출력은 Q입니다.

S = 1, R = 0이면 Q = 1로 설정되고, S = 0, R = 1이면 Q = 0으로 초기화됩니다. S = 0, R = 0이면 Q는 이전 값을 그대로 유지하는데, 이것이 기억입니다. S = 1, R = 1은 결과가 정해지지 않아 쓰지 않는(금지) 입력입니다.

출력을 입력으로 되먹이는 구조(피드백) 덕분에 입력이 사라져도 상태가 남습니다.

예제

Q = 0인 SR 래치에 S = 1, R = 0을 잠깐 넣었다가 S = 0, R = 0으로 돌리면 Q는?

  1. S = 1이 들어오면 Q = 1로 설정됩니다.
  2. S = 0, R = 0은 유지입니다.
  3. Q = 1이 그대로 남습니다.

답: Q = 1

문제 2

SR 래치에서 S = 0, R = 0이면 Q는 이전 값을 ＿＿＿합니다.

문제 3

SR 래치에 S = 0, R = 1을 넣으면 Q는 얼마일까요?

문제 4

SR 래치에서 결과가 정해지지 않아 쓰지 않는 입력은 S = 1, R = ＿＿＿입니다.

문제 5

래치가 입력이 사라져도 상태를 유지하는 것은 출력을 입력으로 되먹이는 ＿＿＿ 구조 때문입니다.

상태표로 따라가기

래치의 동작은 시간 순서대로 입력을 적고 Q를 따라가며 확인합니다. 각 줄에서 S = 1이면 1, R = 1이면 0, 둘 다 0이면 바로 앞 줄의 Q를 그대로 적습니다.

예: 처음 Q = 0 → (S,R) = (1,0) → Q = 1 → (0,0) → 1 → (0,1) → 0 → (0,0) → 0.

예제

처음 Q = 1인 SR 래치에 (S,R) = (0,0), (0,1), (0,0), (1,0) 순으로 넣으면 마지막 Q는?

  1. (0,0): 유지하여 1입니다.
  2. (0,1): 초기화하여 0, (0,0): 유지하여 0입니다.
  3. (1,0): 설정하여 1입니다.

답: Q = 1

문제 6

SR 래치의 S는 Q를 1로 ＿＿＿하는 입력입니다.

문제 7

처음 Q = 0인 SR 래치에 (S,R) = (1,0), (0,0), (0,0) 순으로 넣으면 마지막 Q는 얼마일까요?

문제 8

처음 Q = 1인 SR 래치에 (S,R) = (0,1), (1,0), (0,1) 순으로 넣으면 마지막 Q는 얼마일까요?

문제 9

래치 하나가 저장하는 정보는 몇 비트일까요?

기억의 시작

래치는 1비트 기억의 출발점입니다. 하지만 입력이 바뀌는 즉시 출력이 따라 바뀌어, 여러 비트를 같은 순간에 맞추어 저장하기 어렵습니다. 다음 레슨의 플립플롭은 클럭이라는 신호에 맞추어 정해진 순간에만 값을 받아들입니다.

정리: 조합회로(기억 없음)와 순차회로(기억 있음), SR 래치(S 설정, R 초기화, 00 유지, 11 금지), 피드백, 상태표 따라가기

문제 10

플립플롭이 정해진 순간에만 값을 받아들이게 하는 신호를 ＿＿＿이라고 합니다.

예제

도난 경보기에서 문이 잠깐 열려도 경보가 계속 울리게 하려면 래치를 어떻게 쓸까요?

  1. 문 열림 센서를 S에 연결합니다.
  2. 문이 잠깐 열려도 Q = 1로 설정되어 유지됩니다.
  3. 해제 버튼을 R에 연결해 Q = 0으로 초기화합니다.

답: 센서 → S, 해제 버튼 → R

문제 11
